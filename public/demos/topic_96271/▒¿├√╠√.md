# 积分管家 - 班级积分管理系统

## 1. Demo 简介

**是什么：** 积分管家是一款面向中小学教师的班级积分管理 Web 应用，纯前端实现，无需后端和数据库，浏览器打开即可使用。

**面向谁：** 核心用户是中小学班主任和科任老师，以及协助管理的学生积分管理员。

**主要功能：**

- **积分闭环管理**：支持给学生加分、扣分、兑换奖品，所有操作自动记录并可撤销，彻底杜绝"先拿后扣"的漏洞
- **课程与班级批量加分**：预设课程积分，一键给全班或某课程学生批量加分，大幅减轻登记负担
- **数据安全与备份**：所有数据保存在浏览器本地存储中，支持一键导出 JSON 备份和导入恢复

> 产品截图建议放置位置：登录页、概览面板、积分兑换流程

## 2. Demo 创作思路

**灵感来源：**

在日常教学中，很多老师用纸质本子或 Excel 表格记录学生积分，但经常出现漏记、错记、算错余额的情况。尤其是奖品兑换环节，学生常会说"老师我先拿走了，下次再扣分"，导致管理混乱。我希望能做一款开箱即用、操作简单的工具，让班级积分管理变得清楚、安全、省心。

**想解决的问题：**

- 纸质记录容易丢失，多人管理时数据不同步
- 手工计算积分余额容易出错
- 奖品兑换没有闭环控制，存在"先拿后扣"的漏洞
- 历史记录无法追溯，误操作后难以恢复

**为什么做这个方向：**

教育信息化是大趋势，但市面上很多管理系统过于复杂，需要学校统一部署、老师培训才能上手。积分管家的定位是"轻量级、零门槛"——一个 HTML 文件就能跑，老师打开浏览器就能用，学生也能参与管理。

## 4. TRAE 实践过程

整个项目从 0 到 1 完全通过 TRAE 对话式开发完成。以下是关键开发阶段：

### 阶段一：基础框架搭建

使用 TRAE 构建完整的登录页 + 后台管理界面，包括：
- 趣味登录页（支持注册/登录/快速体验）
- 侧边栏导航 + 多页面切换
- 概览面板（数据统计 + 快捷入口）

### 阶段二：核心功能开发

在 TRAE 的协助下逐步完善各模块：
- 学生管理：增删改查 + 批量导入（支持 CSV/TXT/Excel 文件上传）
- 班级管理：班级维护 + 默认班级切换 + 班级学员查看
- 课程管理：课程设置 + 学员关联 + 班级批量加分
- 奖品管理：奖品维护 + 自定义 emoji/图片图标
- 积分兑换：选学生 → 选奖品 → 确认兑换的闭环流程

### 阶段三：体验优化与移动端适配

- 所有弹窗增加搜索功能（学生搜索）
- 手机端底部导航栏适配
- 登录页和主页面手机端滚动优化
- 侧边栏导航支持独立滚动

### 阶段四：部署与测试

使用 TRAE 协助部署到本地局域网，供多设备访问测试。
