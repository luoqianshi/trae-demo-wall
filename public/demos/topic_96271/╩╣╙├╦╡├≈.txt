班级积分管理系统 - 使用说明
=====================================

一、如何打开
-----------
直接用浏览器打开 index.html 文件即可使用。
不需要安装任何软件，也不需要网络。
支持 Chrome、Edge、Firefox、Safari 等主流浏览器。

二、核心功能
-----------
1. 趣味登录页
   - 打开系统后会先看到“积分管家”登录页面
   - 左侧保留 Logo 和功能介绍，右侧支持“登录 / 注册”切换
   - 注册：填写手机号、验证码、老师姓名和班级名称后进入系统
   - 登录：已注册手机号只需填写手机号和验证码即可进入系统
   - 点击“获取验证码”后，系统会在页面提示本地演示验证码
   - 也可以点击“使用示例身份体验”快速进入
   - 登录信息会保存在当前浏览器中，刷新页面后无需重复填写

2. 概览面板
   - 显示学生人数、积分总存量、今日变动、累计兑换次数
   - 快捷入口：加分、扣分、批量课程加分、兑换奖品、查看记录
   - 展示产品介绍、核心流程、学生积分总览、积分排行榜和班级提醒
   - 老师打开页面后，可以第一眼看到班级积分运行情况

3. 班级管理
   - 添加/编辑/删除班级
   - 可以自由选择某个班级作为当前默认班级
   - 点击班级名称或「点击查看名单」可以查看该班级的所有学生，并看到每个学生正在上的课程
   - 每个班级卡片上都有「添加学员」按钮，点击后可直接给该班级添加学生
   - 添加或编辑学生时，可以从班级列表中直接选择班级
   - 删除有学生的班级时，系统会提示并把学生归为“未分班”

4. 课程管理
   - 添加/编辑/删除课程
   - 每门课程可以设置不同积分，例如语文课5分、体育课3分
   - 页面顶部会显示当前默认班级，以及该班级的学生人数
   - 课程列表会显示每门课在当前默认班级中的学员数量
   - 点击课程名称或「点击查看名单」可以查看该课程的所有学员
   - 每个课程卡片上有「管理学员」按钮，点击后可勾选/取消勾选该课的学生名单
   - 管理课程学员时，支持按学生姓名或班级搜索学员
   - 学生管理页面会显示每个学生上了哪些课
   - 批量课程加分时，选择课程后会自动勾选该课程的学员
   - 页面顶部有「添加学生」按钮，可在此页面直接录入学生
   - 也可以在批量课程加分时临时填写自定义课程

5. 学生管理
   - 添加/编辑/删除学生
   - 支持批量导入学生（上传 CSV/TXT/Excel 文件，或从 Excel 复制粘贴，或手动输入名单）
   - 支持搜索学生
   - 每个学生卡片上会显示该生上了哪些课程（蓝色标签）
   - 班级选择由“班级管理”模块统一维护
   - 快捷加减积分按钮（每个学生右侧的 + 和 - 按钮）
   - 给学生加分、给学生扣分弹窗中支持按姓名或班级搜索学生

6. 奖品管理
   - 添加/编辑/删除奖品
   - 设置兑换所需积分和库存数量
   - 支持从预设图标中选择，也可以自定义输入 emoji 图标
   - 支持上传本地图片作为奖品图标（图片会自动转为 base64 保存，建议不超过 1MB）
   - 库存为0时自动禁止兑换

7. 积分兑换（核心闭环功能）
   - 第一步：选择学生（显示当前积分）
   - 第二步：选择奖品
     * 灰色卡片 = 积分不足或库存为0，无法选择
     * 彩色卡片 = 可以兑换，点击选中
   - 第三步：确认兑换
     * 系统会自动检查：积分够不够？库存还有没有？
     * 两项都满足才会扣减积分、减少库存、生成记录
     * 不满足时直接提示错误，无法完成兑换
   - 彻底杜绝"先拿后扣"的漏洞

8. 历史记录
   - 支持按类型筛选（全部/加分/扣分/兑换）
   - 所有加分、扣分、兑换操作都有记录
   - 支持搜索学生或奖品
   - 每条记录可以撤销，撤销后积分和库存自动回退

9. 课程/班级批量加分
   - 在“课程管理”页面中维护常用课程和对应积分
   - 在首页点击“批量课程加分”
     * 可以从下拉菜单选择预设课程，也可以选择“自定义课程”手动填写课程名称和积分
     * 支持按学生姓名或班级搜索要加分的学生
     * 勾选要给加分的学生（支持全选/取消全选）
     * 确认后系统会给选中的学生统一增加对应积分
   - 在首页点击“班级批量加分”，或在“班级管理”页面点击某个班级的“批量加分”
     * 选择班级后，系统会自动勾选该班所有学生
     * 支持按学生姓名或班级搜索该批次要加分的学生
     * 填写加分数量后，可以给该班学生统一加分
   - 系统会为每位学生生成一条加分记录，方便之后查询和撤销

10. 数据管理
   - 导出备份：生成 JSON 文件，保存到电脑
   - 导入恢复：选择之前导出的 JSON 文件恢复数据
   - 清空数据：一键重置（会二次确认）

三、首次使用
-----------
打开后已预置 5 名示例学生和 6 种示例奖品，
可以直接体验各项功能。
体验完后可以在"数据管理"页面清空数据，
然后添加自己的学生和奖品。

四、数据安全
-----------
所有数据保存在当前浏览器的本地存储中。
换电脑或清除浏览器缓存会导致数据丢失，
建议定期在"数据管理"页面导出备份。

五、使用建议
-----------
1. 兑换流程必须严格按步骤来：
   选学生 -> 选奖品 -> 确认兑换
   学生积分不足或奖品没库存时，系统会自动阻止。

2. 老师可以安排一名学生当"积分管理员"，
   负责登记兑换，老师最后复核记录。

3. 每周导出一次备份，防止意外丢失。

4. 如果要在教室里用，建议用平板或大屏电脑，
   界面已针对触屏做了优化。
