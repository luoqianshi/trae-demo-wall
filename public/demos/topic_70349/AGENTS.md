# AGENTS.md — 项目级规则

本文件是 AI 编码代理在本项目内必须遵守的硬性约束。任何在 `src/`、`data/`、`*.ts` `*.tsx` 中的改动前必须先读本文件与 `DESIGN.md`。

## 1. 产品定位

- **主目标：现有配方反推调整器**。客户输入当前每吨正在喂的原料配方，系统分析缺口后输出推荐新配方及每种原料应增减多少 kg/吨。
- **禁止再写"最小成本配方估算器"作为主目标**。
- 默认中文界面；首屏就是计算器，不做营销落地页、不做英雄大图。
- CTA 文案：**"分析并调整当前配方"**（非"计算最优配方"）。
- Footer 文案：**"现有配方反推调整 · 不能替代营养师复核"**。
- v1 不声称氨基酸、钙磷、维生素、微量元素完整达标 — 只能输出风险提示。

## 2. 标准与数据来源

- 默认营养标准优先级（高 → 低）：
  1. `GB/T 39235-2020 猪营养需要量`（现行）
  2. `GB/T 5915-2020 仔猪、生长育肥猪配合饲料`（现行）
  3. 本地资料（`pig-feed-formula/` 报告等）
  4. `NRC / NASEM 2012`（仅作国际参考）
- `NY/T 65-2004` 已于 2025-01-17 废止。**任何地方出现 NY/T 65-2004 的数值时，必须在 UI 中显示"已废止，参考用"标签**，不得作为默认标准推荐。
- >120kg 阶段无任何现行国标覆盖；UI 必须显示"参考"角标并标 confidence=low。
- 二次育肥（150–180kg）必须显示"料肉比上升 / 数据缺口"风险。

## 3. 单位与精度

- 配方输出以 `1000 kg / 吨` 为基准，显示 `kg/吨`。
- 价格以 `元 / 吨` 录入与显示。
- CP / 水分 以 `%`；DE 以 `MJ/kg`。
- 计算结果四舍五入到 0.1 kg；CP/DE/水分显示 1 位小数；总成本显示 2 位小数 + `¥` 前缀。
- LP 求解内部用浮点；展示层统一 `toFixed` 截断。

## 4. 求解目标（关键约束）

- 决策变量：`recommended_i`（推荐用量）、`increase_i`（增加量）、`decrease_i`（减少量）。
- 平衡约束：`recommended_i - currentKg_i = increase_i - decrease_i`。
- 硬约束：`Σ recommended_i = 1000`、CP ≥ target、DE ≥ target、水分 ≤ target、min ≤ recommended ≤ max。
- 目标函数：优先最小化 `Σ (increase_i + decrease_i)`（保留当前喂法），其次最小化成本。
- `minKgPerTon` / `maxKgPerTon` 语义为"推荐配方允许范围"，不是当前用量。

## 5. UI 视觉规则

- 主色 `#2d7a3e`（绿），辅 `#c0772a`（参考橙），警告 `#d4a017`，危险 `#c0392b`，底色 `#f7f8f5`。
- 字体：标题与正文 `Noto Sans CJK SC`，所有数字与单位 `JetBrains Mono`。
- 按钮：4px 圆角 + 1.5px 描边；主操作填色，次操作镂空。
- 表格表头 sticky；数字右对齐；单位用浅色小字。
- 风险：黄色 Callout；不可行：红色 Callout；参考：橙色徽章。
- 调整动作：增加用绿色 ↑、减少用红色 ↓。

## 6. 代码风格

- TypeScript strict；不写 `any`（必要时用 `unknown` + 收窄）。
- 命名：组件 PascalCase，函数 camelCase，常量 UPPER_SNAKE_CASE，类型 PascalCase。
- 文件：单文件 ≤ 250 行；超长按职责拆分。
- 不写注释解释"做什么"；只在解释"为什么"时写注释。
- 不引入 lodash / dayjs / moment；用原生 API。

## 7. 测试与构建

- 任何新函数必须有对应 Vitest 用例。
- `npm run build` 必须 0 错误 0 警告通过。
- LP 求解结果必须满足 `Σ recommended = 1000 ± 0.1`、`CP >= cpMinPct`、`DE >= deMinMjKg`、上下限。
- `deltaKg = recommendedKg - currentKg`。
- 不可行必须返回结构化 `reasons[]`，UI 不可只显示"求解失败"。

## 8. 范围外（v1 明确不做）

- 账号系统 / 云同步 / 浏览器长期存储
- 氨基酸平衡（赖氨酸/蛋氨酸/苏氨酸/色氨酸）
- 钙磷计算、维生素、微量元素完整配方
- 移动端原生 App、3D 场景
- 多语言切换（仅中文）
- "已有 1 吨混合料上直接额外加料"模式
