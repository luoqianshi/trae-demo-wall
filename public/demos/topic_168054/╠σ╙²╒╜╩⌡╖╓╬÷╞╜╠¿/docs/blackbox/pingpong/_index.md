# 乒乓智析（乒乓球分支）

用户上传乒乓球比赛录像，系统自动过滤非比赛画面，分析球员和球的运动，生成2D落点热力图和3D球路轨迹可视化报告。

输入：
- 用户上传的乒乓球比赛视频文件（MP4/MOV/AVI）

输出：
- 乒乓球3D运动轨迹线（含Z轴高度，可旋转视角）
- 2D落点热力图（球落在球台上的位置分布）
- 两个球员的移动轨迹和站位热力图
- 多球员轨迹对比（不同颜色叠加显示）
- 双滑块时间轴（选择时间段查看轨迹）
- 数据统计面板（击球次数、回合数、球速、落点分布、正/反手使用率、跑动距离等，全部客观数据）
- 非比赛画面自动过滤（只分析真正在打球的片段）
- 战术分析文字报告
- 2D/3D视图切换
