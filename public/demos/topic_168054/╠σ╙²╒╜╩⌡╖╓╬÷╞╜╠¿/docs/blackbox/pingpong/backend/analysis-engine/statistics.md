# 统计计算

根据完整轨迹数据，计算每个球员的客观技术指标。所有数据均为客观计算结果，不含主观判断。

输入：
- 所有球员的完整轨迹序列
- 球的完整3D轨迹序列
- 落点数据
- 比赛帧标记

输出：
- 每个球员的统计数据：
  - 击球次数（球在球员半区弹跳的次数）
  - 回合数（从发球到死球的连续击球段）
  - 平均回合时长
  - 击球频率（每分钟击球次数）
  - 正手使用率（球在球员正手位击球的比例）
  - 反手使用率
  - 跑动距离（球员横向移动总距离，米）
  - 移动速度（平均/最快，m/s）
  - 站位区域分布（近台/中台/远台占比）
  - 落点分布（球台左/中/右的落点比例）
- 球的统计数据：
  - 平均球速（m/s）
  - 最快球速
  - 过网平均高度
  - 弧线类型分布（高吊弧圈/前冲弧圈/扣杀，基于弧线形状客观分类）
- 回合统计：
  - 总回合数
  - 最长回合
  - 变线次数（球路突然从左到右或从右到左的次数）
  - 线路偏好（斜线/直线比例）
