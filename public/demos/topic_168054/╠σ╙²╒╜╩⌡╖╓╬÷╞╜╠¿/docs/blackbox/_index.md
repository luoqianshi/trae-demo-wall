# 绿茵智析

业余球队的赛后战术分析工具，用户上传比赛录像，系统自动分析视频中的球员和足球运动，生成可视化战术分析报告。

输入：
- 用户上传的足球比赛视频文件（MP4/MOV/AVI，最长 40 分钟）

输出：
- 球员跑动热力图（画在球场上的彩色区域，颜色深浅表示活动密度）
- 每个球员的移动轨迹线（按时间顺序连接坐标点形成路径线）
- 足球的运动轨迹线（传球路线、射门路线）
- 多球员轨迹对比（任意勾选多名球员，不同颜色叠在球场上同时显示）
- 双滑块时间轴（0—40 分钟，可选择起点滑块和终点滑块，只显示该时间段内的轨迹）
- 数据统计面板（持球率、跑动距离、传球成功率等关键指标）
- 战术分析文字报告（自动生成的文字总结）
