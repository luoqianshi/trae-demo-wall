# 全局开发规范

## 工作流节点创建规范

工作流画布中的普通节点必须使用统一的六区域结构。后续新增或修改节点时，节点模板和节点渲染都要遵守该结构，避免出现字段缺失、连接点缺失或输出区域样式不一致。

### 节点区域结构

1. 标题区
   - 显示节点图标和节点标题。
   - 标题区统一使用深色头部：`relative overflow-hidden bg-neutral-950 ... text-white`。
   - 标题区必须叠加右上角径向高光层：`absolute inset-0 bg-[radial-gradient(circle_at_top_right,rgba(255,255,255,0.15),transparent_60%)]`。
   - 图标容器使用白色半透明边框和背景：`border-white/15 bg-white/10 text-white`。
   - 标题使用加粗样式。
   - 节点操作按钮只在选中或悬停状态下辅助展示，不占用业务信息区域。

2. 描述区
   - 单独显示节点描述。
   - 描述不得和标题挤在同一行或同一区域。
   - 描述使用较小字号和弱化颜色。

3. 第一条分割线
   - 标题描述区和参数区之间必须有分割线。

4. 参数区
   - 必须完整渲染节点模板中的所有参数，不允许只截取前几个参数。
   - 每个参数都必须独立占一行或一个参数块。
   - 参数名称、类型标签、编辑器必须一一对应。
   - 有输入连接类型的参数必须显示左侧输入连接点。
   - 工具参数必须显示工具连接状态，例如“连接工具”或“已连接 N 个工具”。
   - 高级参数也必须展示，不能因为 `advanced` 标记被隐藏。
   - 例如智能体节点包含“选择模型、工具、输入、智能体指令、添加当前日期工具”等参数，画布节点必须全部显示，不能只显示其中两个。

5. 第二条分割线
   - 参数区和输出区之间必须有分割线。

6. 输出区
   - 输出区使用浅灰背景。
   - 必须完整渲染节点模板中的所有输出，不允许只显示第一个输出。
   - 输出名称使用中文展示。
   - 输出区域只显示“输出”标识和类型标签，不展示实际输出结果、不展示示例、不展示描述文案。
   - 每个输出必须有右侧输出连接点。

### 节点模板要求

- `template` 中定义的参数数量，就是画布节点必须展示的参数数量。
- `outputs` 中定义的输出数量，就是画布节点必须展示的输出数量。
- 如果一个参数支持连接其他节点，必须配置 `input_types`。
- 如果一个参数是必填项，必须配置 `required: true`。
- 模型相关节点统一放入“智能体和模型”单层分组，不允许再做二级分组。
- 新增节点时必须检查“模板参数、画布参数、右侧属性面板参数”三者一致。
- 提示词模板节点只保留提示词模板本身，不默认添加“输入”参数；需要变量时通过模板文本表达。
- 语言模型节点必须包含“工具 / Skills”参数，用于连接工具节点或技能能力。

### 样式约束

- 节点宽度保持统一，普通配置节点默认使用 `w-80`；图片输出类节点可按图片数量自适应宽度。
- 节点主体使用 `bg-background text-foreground`。
- 节点根容器必须使用圆角边框，默认对齐图片输出节点的 `rounded-2xl` 风格，禁止使用直角卡片。
- 标题区统一使用深色头部和右上角径向高光，不使用分类彩色渐变标题。
- 参数区保持白底或主题背景。
- 输出区使用 `bg-muted/30` 这样的浅灰背景。
- 输出区只保留输出名称和类型标签，不渲染运行结果、图片、JSON、示例值或说明文字。
- 图片输出类节点的图片展示区域属于节点主体内容区，不属于输出声明区；图片应直接作为节点内容展示，并提供放大预览和编辑入口。
- 多图输出类节点应横向排列图片，节点宽度可随图片数量增长，而不是在固定小区域内滚动展示。
- 分割线使用 `border-t`。
- 不使用额外的分类彩色标题，避免和节点语义混淆。
