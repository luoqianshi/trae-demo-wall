# 006-项目空间与工作流模板基础功能

## 模块目标

为个人工作流平台补齐项目空间能力：一个项目中可以创建多个工作流，工作流支持空白创建、模板创建、列表管理、进入编辑器、保存画布。项目不包含成员、权限、协作等团队能力。

## 设计原则

- 项目功能轻量化，先解决个人空间组织问题。
- 工作流是核心资产，项目只是归档容器。
- 模板功能作为创建入口，先内置系统模板。
- 优先端到端可用，不深化成员、审计、版本发布等复杂能力。

## 字段规划

### 项目字段

- name：项目名称
- description：项目描述
- icon：项目图标
- color：项目主题色
- scenario：项目场景
- status：active / archived
- sortOrder：排序
- lastWorkflowId：最近打开工作流
- workflowCount：工作流数量
- createTime / updateTime：创建更新时间

### 工作流字段

- projectId：所属项目
- name：工作流名称
- description：工作流描述
- status：draft / active / archived
- version：版本号
- sourceTemplateId：模板来源
- graphJson：画布 JSON
- nodeCount / edgeCount：节点和连线数量
- lastRunStatus：最后运行状态
- createTime / updateTime：创建更新时间

### 模板字段

- name：模板名称
- description：模板描述
- category：模板分类
- tags：标签
- coverColor：封面色
- graphJson：模板画布 JSON
- systemTemplate：是否系统模板

## 接口规划

### 项目接口

- `POST /api/flowProject/add`
- `POST /api/flowProject/list/page`
- `GET /api/flowProject/get?id=`
- `POST /api/flowProject/update`
- `POST /api/flowProject/delete`

### 工作流接口

- `POST /api/workflow/add`
- `POST /api/workflow/create/fromTemplate`
- `POST /api/workflow/list/page`
- `GET /api/workflow/get?id=`
- `POST /api/workflow/saveGraph`
- `POST /api/workflow/delete`

### 模板接口

- `POST /api/workflowTemplate/list/page`
- `GET /api/workflowTemplate/get?id=`

## 前端规划

- 新增 `/projects` 项目空间页面。
- 新增 `/projects/$projectId` 项目详情页面。
- `/flow` 支持 query：`projectId`、`workflowId`。
- 工具栏保存优先调用后端 `saveGraph`，无上下文时保留 localStorage 兜底。
- 项目详情页提供空白创建和模板创建入口。
