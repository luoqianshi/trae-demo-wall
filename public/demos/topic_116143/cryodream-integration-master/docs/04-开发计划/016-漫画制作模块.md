## 模块概述

**模块名称**：漫画制作（Comic Studio）
**模块目标**：在 AI 画布路由组下新增独立的漫画制作画布，基于 `react-konva` 构建多图层、多分格、可拖拽的漫画编辑器。用户可从 ComfyUI 画布生成的图片中导入素材，手动分格并在每个分格内自由叠加图片/对话框/文字/效果图层，最终导出为 PNG 或 PDF。
**计划周期**：2026-07-09 - 2026-07-16（预估，7 天）
**路由位置**：`/canvas/comic`（与 `/canvas/comfyui` 同级）

### 设计依据（来自需求确认）

| 决策项 | 结论 |
|--------|------|
| 模块定位 | AI 画布路由组下新增独立子路由 `/canvas/comic`，与 ComfyUI 画布同级 |
| 存储方案 | **独立后端表 `t_comic_project`**（按项目组织，独立于 ComfyUI 项目，通过 `sourceAssetIds` 与 ComfyUI 素材关联） |
| 首版功能 | ① 多页面 + 手动分格；② 分格内图层编辑；③ 对话框气泡系统；④ 从 AI 画布导入图片；⑤ 导出 PNG/PDF |
| 图层管理 | **PS 风格图层面板**（右侧栏，拖拽排序 / 显隐 / 锁定 / 双击重命名） |
| 技术选型 | **react-konva** — 声明式 React 组件 + 原生 Layer 图层 + 内置 draggable + Transformer 缩放旋转 + `toDataURL()` 一行导出 |
| 页面布局 | 参考 ComfyUI 画布布局：左侧素材/工具栏 + 中央画布 + 右侧图层/属性面板 + 顶部项目栏 |

### 技术方案摘要（react-konva vs Fabric.js vs 纯 HTML）

| 维度 | react-konva（选定） | Fabric.js | 纯 HTML/CSS |
|------|-------------------|-----------|-------------|
| 与 React 集成 | 声明式组件 ⭐⭐⭐⭐⭐ | 命令式，需 useEffect 管理生命周期 ⭐⭐ | 原生 ⭐⭐⭐⭐ |
| 图层支持 | 原生 `<Layer>` ⭐⭐⭐⭐⭐ | 单画布模拟 ⭐⭐⭐ | 手写 z-index ⭐⭐ |
| 拖拽/变换 | `draggable` + `<Transformer>` 内置 ⭐⭐⭐⭐⭐ | 内置 ⭐⭐⭐⭐⭐ | 需 dnd-kit + 手写变换 ⭐⭐ |
| 包体积 | ~35KB gzip ⭐⭐⭐⭐ | ~300KB+ ⭐⭐ | 0 ⭐⭐⭐⭐⭐ |
| 导出图片 | `stage.toDataURL()` ⭐⭐⭐⭐⭐ | 内置 ⭐⭐⭐⭐⭐ | 依赖 html2canvas ⭐⭐ |
| 文字气泡形状 | Path/自定义 Shape ⭐⭐⭐⭐ | 内置 Path ⭐⭐⭐⭐⭐ | SVG ⭐⭐⭐ |

**结论**：react-konva 是与现有 React 19 + Zustand + shadcn 技术栈契合度最高的方案。

### 数据模型

#### 后端表 `t_comic_project`

```sql
CREATE TABLE IF NOT EXISTS t_comic_project (
    id VARCHAR(64) PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    description VARCHAR(500),
    canvas_width INT NOT NULL DEFAULT 1200,
    canvas_height INT NOT NULL DEFAULT 1600,
    -- 完整漫画数据 JSON：pages[] -> panels[] -> layers[]
    comic_data LONGTEXT NOT NULL,
    -- 缩略图（首页第一张分格 base64 或素材路径）
    thumbnail_url VARCHAR(500),
    -- 关联的 ComfyUI 项目 ID（可选，标识素材来源）
    source_comfyui_project_id VARCHAR(64),
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_source_project (source_comfyui_project_id),
    INDEX idx_update_time (update_time DESC)
);
```

#### 前端 TypeScript 数据结构

```ts
// features/comic/types.ts

export interface ComicProject {
  id: string
  name: string
  description?: string
  canvasWidth: number
  canvasHeight: number
  pages: ComicPage[]
  sourceComfyuiProjectId?: string
  thumbnailUrl?: string
  createTime?: string
  updateTime?: string
}

export interface ComicPage {
  id: string
  order: number
  panels: ComicPanel[]
}

// 分格：矩形区域，内部包含独立的图层
export interface ComicPanel {
  id: string
  x: number
  y: number
  width: number
  height: number
  borderColor: string
  borderWidth: number
  cornerRadius: number
  clipContent: boolean         // 是否裁剪分格外的图层内容
  layers: ComicLayer[]         // 分格内的图层，index 越小越靠下
}

export type ComicLayer =
  | ImageLayer
  | SpeechBubbleLayer
  | TextLayer
  | EffectLayer

interface BaseLayer {
  id: string
  name: string                 // 图层名（图层面板显示）
  type: 'image' | 'bubble' | 'text' | 'effect'
  visible: boolean
  locked: boolean
  x: number                    // 相对分格左上角
  y: number
  width: number
  height: number
  rotation: number
  opacity: number
}

export interface ImageLayer extends BaseLayer {
  type: 'image'
  src: string                  // 图片 URL（AI 画布素材或用户上传）
  sourceAssetId?: string       // 来源 AssetNode ID（可选，用于追溯）
}

export interface SpeechBubbleLayer extends BaseLayer {
  type: 'bubble'
  bubbleStyle: 'normal' | 'thought' | 'shout' | 'narration'
  tailDirection: 'left-down' | 'right-down' | 'left-up' | 'right-up' | 'none'
  tailX: number                // 尾巴指向点（相对气泡左上角）
  tailY: number
  text: string
  fontSize: number
  fontFamily: string
  textColor: string
  fillColor: string
  strokeColor: string
  strokeWidth: number
}

export interface TextLayer extends BaseLayer {
  type: 'text'
  text: string
  fontSize: number
  fontFamily: string
  color: string
  strokeColor?: string
  strokeWidth?: number
  align: 'left' | 'center' | 'right'
  fontWeight: 'normal' | 'bold'
  fontStyle: 'normal' | 'italic'
}

export interface EffectLayer extends BaseLayer {
  type: 'effect'
  effectType: 'boom' | 'flash' | 'lines'
  color: string
}
```

### 关键交互设计

#### 1. 分格工具（Panel Tool）

- **手动分格**：工具栏选择"分格工具"，在页面上按住鼠标拖出矩形创建分格
- **分格调整**：选中分格后拖动边框调整位置和大小
- **分格样式**：属性面板可调整边框颜色、粗细、圆角
- **删除分格**：Delete 键或右键菜单删除
- **快速分格模板**：预设 1x1 / 1x2 / 2x2 / 2x3 网格布局，一键生成

#### 2. 图层编辑模式

- **进入方式**：双击分格进入，或工具栏切换为"图层模式"
- **视觉反馈**：进入后画布其他分格半透明，聚焦当前分格
- **添加图层**：
  - 从左侧素材面板拖拽（图片 / 气泡 / 文字）
  - 从工具栏点击"文字"按钮直接添加
- **图层操作**：
  - 点击选中：显示 Konva Transformer 缩放/旋转手柄
  - 拖拽移动：`draggable=true`
  - 双击文字/气泡：进入文本编辑模式
  - Shift 多选：批量移动
- **退出**：ESC 或点击画布空白处

#### 3. 图层面板（PS 风格）

```
┌── 图层 ─────────────────┐
│  ⚙ ┃👁 🔒│ 缩略图 │ 图层名  │
├─────────────────────────┤
│  ≡ ┃👁 🔒│ [文字] │ 主人公台词  │
│  ≡ ┃👁 🔒│ [气泡] │ 对话框-1   │
│  ≡ ┃👁 🔒│ [图片] │ 主人公     │
│  ≡ ┃👁 🔒│ [图片] │ 背景       │  ← 最底层
└─────────────────────────┘
```

- 拖拽排序（dnd-kit）
- 眼睛图标切换 visible
- 锁图标切换 locked
- 双击图层名重命名
- 右键菜单：复制/删除/合并/居中

#### 4. 对话框气泡（SpeechBubble）

自定义 Konva Shape，用 Bezier 曲线绘制气泡+尾巴：

```tsx
// SpeechBubbleNode.tsx 简化示意
<Shape
  sceneFunc={(context, shape) => {
    // 绘制圆角矩形/椭圆/云朵形
    drawBubbleBody(context, style, width, height)
    // 绘制指向尾巴
    drawBubbleTail(context, tailX, tailY, tailDirection)
    context.closePath()
    context.fillStrokeShape(shape)
  }}
  fill={fillColor}
  stroke={strokeColor}
  strokeWidth={strokeWidth}
  draggable={!locked}
/>
<Text
  text={text}
  fontSize={fontSize}
  fill={textColor}
  align="center"
  verticalAlign="middle"
/>
```

四种气泡风格：
- **normal**（普通对话）：圆角矩形 + 尖角尾巴
- **thought**（内心 OS）：云朵形状 + 圆点尾巴
- **shout**（呐喊）：锯齿边缘 + 尖角尾巴
- **narration**（旁白）：矩形无尾巴，通常置于分格顶部

#### 5. 从 AI 画布导入图片

**方式一（推荐）**：漫画编辑器左侧素材面板显示当前项目关联的 ComfyUI 项目的所有 AssetNode 图片
```ts
// 请求：/api/comfyui/project/list-assets?projectId=xxx
// 返回：[{ id, name, url, workflowName }, ...]
```

**方式二**：AI 画布 AssetNode 右键菜单增加 `发送到漫画编辑器 → 选择漫画项目`

拖入后自动创建 ImageLayer 并记录 `sourceAssetId`。

#### 6. 导出

- **单页 PNG**：`stage.toDataURL({ pixelRatio: 2 })` → 下载
- **整册 PDF**：遍历所有页面，切换渲染后逐页 `toDataURL()`，用 `jsPDF` 组装
- **导出对话框**：选择质量（1x/2x/3x DPI）、页面范围、格式

## 关键设计要点

### 1. 分格 + 图层的层级关系

React Flow 是"节点在画布上"，但漫画是"图层在分格内"。用 Konva 的 Group + clipFunc 实现分格局部坐标系：

```tsx
<Group
  x={panel.x}
  y={panel.y}
  clipFunc={(ctx) => {
    ctx.beginPath()
    ctx.rect(0, 0, panel.width, panel.height)
    ctx.closePath()
  }}
>
  {/* 分格边框 */}
  <Rect width={panel.width} height={panel.height} stroke={borderColor} strokeWidth={borderWidth} />
  {/* 图层按 index 顺序渲染，index 越小越靠下 */}
  {panel.layers.map((layer) => renderLayer(layer))}
</Group>
```

### 2. 撤销重做（Command Pattern）

不用 immer patches（对 Konva 引用类型不友好），而是每个操作产生一个 Command 对象：

```ts
interface Command {
  do(): void
  undo(): void
}
// 例：AddLayerCommand / MoveLayerCommand / DeletePanelCommand
```

历史栈上限 50 步。

### 3. 分格裁剪 vs 溢出

- 默认 `clipContent: true` — 图层不能溢出分格（真实漫画感）
- 用户可选关闭 — 例如角色手臂伸出分格边框的艺术效果

### 4. 性能优化

- 每个页面一个独立的 `<Stage>`，非当前页不渲染
- 图片图层用 Konva 内置的 `imageSmoothingEnabled` 优化
- 图层数量 > 30 时提示用户合并

### 5. 与现有 ComfyUI 项目的关联

- 漫画项目创建时可"关联 ComfyUI 项目"作为素材来源
- 一个漫画项目只能关联一个 ComfyUI 项目（避免复杂化）
- 关联后左侧素材面板自动加载 ComfyUI 项目的所有图片
- 未关联时素材面板显示"请先关联 AI 画布项目"

## 风险与不确定性

| 风险 | 影响 | 应对 |
|------|------|------|
| Konva 中文字体渲染兼容性 | 中 | 提前测试常用中文字体，必要时用 web fonts |
| 大图（4K+）导出内存占用 | 中 | 导出对话框限制最大 DPI 3x，提示用户 |
| PDF 中文乱码 | 高 | jsPDF 需嵌入中文字体（noto-sans-sc），或改用 pdf-lib |
| 分格拖拽创建体验 | 中 | 参照 Figma/Miro 的分格工具，多次交互调试 |
| 图层数量过多性能下降 | 低 | 单页图层软上限 30 个 |
| 与 AssetNode 删除后素材失效 | 中 | 图片图层直接存 URL 快照，AssetNode 删除不影响漫画（副本） |
