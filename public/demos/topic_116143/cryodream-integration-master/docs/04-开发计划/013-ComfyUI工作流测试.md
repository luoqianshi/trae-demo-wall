### 第一阶段已完成（2026-06-24）

**路由分组「AI画布」**
- 新建 `canvas` 布局路由，将 ComfyUI 相关页面归入同一分组
- 侧边栏新增「AI画布」分组，包含「绘图画布」和「工作流测试」两个入口
- 路由：`/canvas/comfyui`（绘图画布）、`/canvas/workflow-test`（工作流测试）

**工作流测试页面**
- 工作流选择：下拉选择已导入工作流 + 一键导入本地未导入工作流
- 参数编辑：复用 `ParamEditor` 组件，并支持常用参数与默认折叠的高级参数分组
- 一键调试：`submit` + `progress` 轮询，实时进度条 + 阶段文字
- 结果展示：网格图片展示 + 点击预览大图 + 下载按钮
- 错误处理：执行失败时显示错误信息

### 第二阶段已完成（2026-06-27）

**模板一致性与高级参数分组**
- 工作流测试页继续以已导入模板的 `paramSchema` / `paramValues` 作为唯一测试执行来源
- 画布普通工作流节点改为使用已导入工作流模板创建，不再在添加节点时静默重新导入本地 JSON
- 新增节点参数与工作流测试页保持一致，避免 `qwen图片编辑-单图` 这类模板在测试页和画布节点中参数不一致
- 工作流测试参数区拆分“常用参数 / 高级参数”，`seed`、`steps`、`cfg`、采样器、调度器、denoise、batch_size、megapixels 等默认归入高级参数并折叠

## 需求背景（用户原始诉求）

ComfyUI 的工作流一般没有参数，用户需要：
1. 选择一个工作流
2. 可选择输入、输出
3. 保存测试配置
4. 直接调试，方便验证画布的工作流节点
