# H-B Room Designer

> 黄渤的房间设计器 - 一个极简版在线室内设计工具

## 🚀 快速开始

### 方式一：直接打开（推荐）

由于项目使用原生 HTML/JS，无需构建工具，直接用浏览器打开即可：

```
用浏览器打开 index.html 文件
```

### 方式二：本地服务器（推荐）

为了更好的开发体验和跨域支持，建议使用本地服务器：

```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080

# Node.js
npx serve

# PHP
php -S localhost:8080
```

然后在浏览器中访问：`http://localhost:8080/index.html`

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🛋️ **家具库** | 提供沙发、椅子、双人床、书桌、茶几五种基础家具 |
| 🖼️ **2D 平面编辑** | 网格化房间平面，支持家具拖拽摆放、移动、旋转、删除 |
| 🎯 **3D 实时预览** | Three.js 实时渲染，与 2D 数据完全同步 |
| 🎨 **风格切换** | 北欧风、日式风、工业风三种预设风格 |
| 🔄 **视图切换** | 一键切换 2D/3D 视图模式 |
| 📐 **3D 交互** | 点击选中模型、显示坐标轴、拖拽旋转环 |
| 💡 **光源控制** | 可拖动的光源球体，实时调整光照位置 |
| 📋 **属性面板** | 右侧面板查看和编辑家具位置、旋转、尺寸 |
| 🎲 **随机生成** | 一键随机布置家具 |
| 📷 **截图导出** | 导出当前设计为图片 |

## 🖱️ 操作指南

### 基础操作

| 操作 | 方式 |
|------|------|
| 添加家具 | 从左侧家具库拖拽到画布或 3D 场景 |
| 选中家具 | 单击家具 |
| 移动家具 | 拖拽已选中的家具 |
| 旋转家具 | 点击旋转按钮 / R 键 / 拖拽金色旋转环 |
| 删除家具 | 点击删除按钮 / Delete 键 |
| 切换风格 | 点击顶部风格按钮 |
| 切换视图 | 点击顶部视图按钮 |

### 3D 视图操作

| 操作 | 方式 |
|------|------|
| 旋转视角 | 左键拖拽空白处 |
| 平移视角 | 右键拖拽 |
| 缩放 | 滚轮 |
| 选中家具 | 左键点击家具 |
| 移动光源 | 左键拖拽黄色光球 |
| 旋转视角（快捷） | 拖拽左上角坐标轴指示器 |

### 属性面板

选中家具后，右侧面板显示：
- **位置**：X/Z 坐标（可编辑，自动吸附网格）
- **旋转**：角度（可编辑，自动对齐 90°）
- **尺寸**：宽度/深度/高度（只读）
- **类型**：家具名称（只读）
- **ID**：唯一标识（只读）

## 📁 项目结构

```
├── index.html          # 主页面（HTML + CSS）
├── app.js              # 核心逻辑（JavaScript + Three.js）
├── prd.md              # 产品需求文档
├── package.json        # 项目配置
└── lib/
    └── three/          # Three.js 库文件
```

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **3D 渲染**: Three.js
- **控制**: OrbitControls
- **图标**: Emoji

## 💾 数据持久化

设计数据自动保存在浏览器的 `localStorage` 中，刷新页面不会丢失。

## 📝 快捷键

| 按键 | 功能 |
|------|------|
| R | 旋转选中的家具 |
| Delete / Backspace | 删除选中的家具 |
