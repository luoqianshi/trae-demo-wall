# 陪诊行业商业级 H5 应用方案 — 实施计划

## 一、摘要

为医疗陪诊服务打造一套**商业级 H5 应用方案**，交付两大产物：① 商业方案文档（含行业分析、产品架构、功能模块、运营策略）；② 高保真可交互原型界面（综合平台：用户端 + 陪诊师端 + 管理后台）。

品牌定位为「**暖伴**」（NuanBan），Slogan「就医路上，温暖相伴」，以「专业医疗底色 + 人文陪伴温度」破局竞品普遍的"冷蓝医疗工具感"。设计语言命名为「煦光」设计系统，采用**暖青绿主色 + 晨曦橙辅色**的差异化配色，避免通用 AI 风格，并内置适老化（大字版）机制以服务核心人群（老年人及其子女）。

调研结论支撑：2024 年我国陪诊服务市场规模已突破 800 亿元，2025 年有望迈过千亿门槛；上海已发布规范化陪诊政策（60 岁以上老人 2 小时 99 元起），行业走向政策背书与规范化。竞品（e 陪诊、安心陪诊、无忧三甲等）多缺乏温度感与亲情代付场景，存在差异化机会。

## 四、品牌与设计系统（避免通用 AI 风格的核心）

### 品牌定位
- 品牌名：**暖伴**（NuanBan）
- Slogan：就医路上，温暖相伴
- 设计语言：「煦光」设计系统
- 差异化：竞品冷蓝工具感 → 暖伴专业医疗底色 + 人文陪伴温度

### 视觉语言
**配色 — 暖青绿主色 + 晨曦橙辅色，区别于通用医疗蓝**

```css
:root{
  /* 主色:深愈青 — 可信、宁静、非通用蓝 */
  --color-primary:#1E7A6F;
  --color-primary-deep:#155E55;
  --color-primary-soft:#E8F4F1;
  /* 辅色:晨曦橙 — 人文温度、CTA 高亮 */
  --color-accent:#F2994A;
  --color-accent-soft:#FFEDD8;
  /* 中性:暖灰系 — 拒绝冷感 */
  --color-ink:#2A2A2A;
  --color-text-2:#6B6B6B;
  --color-text-3:#9A9A9A;
  --color-bg:#FAF8F5;
  --color-card:#FFFFFF;
  --color-border:#EDE8E1;
  /* 语义 */
  --color-success:#27AE60;
  --color-alert:#EB5757;
  --color-info:#2D9CDB;
}
```

**反"通用 AI 风格"清单**
- 禁用紫蓝渐变背景、玻璃拟态光斑、emoji 当图标。
- 图标：自绘线性图标集（2px 描边、圆头、与主色同色系）。
- 插画：暖色双色调编辑风插画，而非扁平通用小人。
- 关键 Hero 区：真实摄影（老年人 + 陪诊师互动场景）+ 暖色调滤镜。
- 数字（价格/统计）：DIN 风格等宽数字。
- 圆角：大圆角 16-24px 传递亲和；阴影用低饱和暖色长投影（`0 8px 24px rgba(30,122,111,.12)`）。

### 字体系统
- 中文：HarmonyOS Sans SC / 思源黑体（黑体类符合适老偏好）。
- 数字/英文：DIN Alternate / Inter。
- 字阶：标准 `--fs-base:16px`；适老 `--fs-base:20px`（1.25×），可再放大至 1.4×。
- 触摸目标：标准 44px → 适老 56px；正文对比度 ≥7:1（WCAG AAA）。

### 适老化（大字版）切换机制
- 顶部/我的页提供"长辈模式"开关，切换 `data-theme="elder"`。
- 影响：字号、触摸目标、信息密度（隐藏次要入口）、首页改宫格大图标、强化人工客服入口。

## 八、假设与决策

1. **品牌与设计方向**：采用「暖伴」品牌名 + 「煦光」设计系统 + 暖青绿/晨曦橙配色，区别于竞品冷蓝工具感；此为差异化核心，执行时不偏离。
2. **技术形态**：原型用静态 HTML + 原生 CSS + 少量 JS（非 Vue/React 框架），便于直接预览、降低门槛、聚焦视觉与交互演示。
3. **文档格式**：商业方案以 HTML 报告形式交付（便于阅读、分发、嵌入图表与原型链接），而非纯 Markdown。
4. **适老化为内置而非独立应用**：通过 `data-theme="elder"` 一键切换，不污染标准版美学。
5. **三端统一状态机**：订单状态（待支付→待接单→已接单→服务中→待评价→已完成/退款）作为 mock 数据中枢，保证三端联动一致。
6. **医疗合规边界**：服务报告为"医嘱转述"而非"医疗建议"，文案与功能规避诊疗红线。

## 九、验证步骤

1. **设计系统自检**：逐项核对反 AI 风格清单——无紫蓝渐变、无玻璃拟态 blob、无 emoji 图标；图标为自绘线性集；Hero 区为真实摄影 + 暖色滤镜；数字用 DIN 等宽；阴影为暖色长投影。
2. **适老化验证**：切换长辈模式，确认字号（1.25×）、触摸目标（≥56px）、信息密度（次要入口隐藏）、首页宫格大图标、24h 热线强化入口五项生效。
3. **信任要素核查**：在首屏、陪诊师详情、支付、服务报告四个关键节点，确认资质露出、保障说明、隐私声明均存在。
