## 1. 项目概述

### 1.1 项目背景

随着全球"双碳"目标的推进和中国新型电力系统的建设，分布式光伏与储能的融合已成为能源转型的关键路径。当前市场面临以下痛点：

- **光伏消纳难**：分布式光伏装机量激增，但缺乏智能调度手段，弃光率居高不下；
- **储能利用率低**：用户侧储能多以单一峰谷套利为主，未与光伏、负荷形成协同优化；
- **运维成本高**：光储系统设备品牌繁杂，缺乏统一管控平台，运维依赖人工巡检；
- **电网交互弱**：并网系统多以"自发自用、余电上网"为主，缺乏主动参与电网调节的能力。

华为数字能源作为全球逆变器出货量第一的品牌，其 FusionSolar 生态具备完善的设备接入能力。本项目依托华为逆变器 + 通用光伏组件 + 模块化电池储能 + 自研智能 EMS 控制器，构建"光-储-充-网"四位一体的智慧能源管理系统。

### 1.2 项目目标

| 目标维度 | 具体目标 |
|---------|---------|
| 经济性 | 通过峰谷套利 + 光伏消纳优化，实现用户用电成本降低 ≥30% |
| 可靠性 | 系统可用率 ≥99.9%，离网切换时间 ≤100ms，保障关键负荷不断电 |
| 智能化 | AI 驱动的能源调度策略，自动适应电价政策、天气预测和负荷变化 |
| 开放性 | 兼容 90%+ 主流光伏组件品牌，支持模块化电池扩容至 50kWh+ |
| 安全性 | 通过等保二级认证，数据端到端加密，满足 GDPR 数据合规要求 |

### 1.3 项目范围

**包含范围：**

- 智能 EMS 控制器嵌入式软件及云端管理平台
- 华为 SmartPV / FusionSolar 逆变器通信协议适配层
- 模块化电池储能 BMS 数据采集与控制接口
- 光伏组件运行数据采集与诊断分析
- 云-边协同架构：边缘网关实时控制 + 云端大数据分析与策略优化
- 移动端 App（iOS / Android）及 Web 管理后台
- 电网交互接口（双向计量、防孤岛保护、需量响应）

**不包含范围：**

- 光伏组件、逆变器、电池模组的硬件设计与制造
- 电力工程施工与并网验收审批
- 电网侧调度系统的开发

## 2. 功能需求

### 2.1 FR-01：智能光储调度（Smart PV-Storage Scheduling）

| 属性 | 内容 |
|------|------|
| 需求编号 | FR-01 |
| 需求名称 | 智能光储调度 |
| 优先级 | P0 |
| 状态 | 待开发 |

**需求描述：**

系统应实现光伏发电、电池储能和负荷之间的实时能源路由优化调度，确保光伏优先消纳、储能高效充放电、负荷稳定供电。

**详细要求：**

| 子需求编号 | 子需求名称 | 描述 |
|-----------|-----------|------|
| FR-01-01 | 实时能源路由 | 根据光伏出力、负荷需求、电池 SOC 和电价信号，以 ≤1s 的周期动态调整能源流向（PV→Load / PV→Battery / Battery→Load / Grid↔System） |
| FR-01-02 | 光伏优先消纳 | 默认策略为光伏发电优先供给本地负荷，剩余功率优先充入电池，最后余电上网 |
| FR-01-03 | 电池充放电控制 | 支恒功率充/放电、恒流充/放电、自适应充/放电三种模式；充放电倍率不超过电池额定倍率的 0.5C（可配置） |
| FR-01-04 | SOC 管理策略 | 可配置 SOC 上限（默认 95%）和下限（默认 10%），低于 SOC 下限自动停止放电并触发告警 |
| FR-01-05 | 负荷预测 | 基于历史用电数据和天气预测，提前 24h 预测负荷曲线，预测误差 ≤15% |
| FR-01-06 | 光伏出力预测 | 基于辐照度预报、组件衰减模型和温度系数，提前 24h 预测光伏出力，预测误差 ≤20% |

### 2.2 FR-02：工作模式管理（Work Mode Management）

| 属性 | 内容 |
|------|------|
| 需求编号 | FR-02 |
| 需求名称 | 工作模式管理 |
| 优先级 | P0 |
| 状态 | 待开发 |

**需求描述：**

系统应支持多种工作模式，并实现自动与手动切换，满足不同场景下的能源管理需求。

**详细要求：**

| 子需求编号 | 子需求名称 | 描述 |
|-----------|-----------|------|
| FR-02-01 | 并网模式 | 系统并网运行，光伏余电上网、不足从网购买，电池参与峰谷套利 |
| FR-02-02 | 离网模式 | 电网断开时自动切换至离网运行，光伏+电池独立供电，保障关键负荷 |
| FR-02-03 | 峰谷套利模式 | 在并网条件下，电池于谷时充电、峰时放电，最大化峰谷价差收益 |
| FR-02-04 | 备电优先模式 | 电池保留指定 SOC（可配置，默认 80%）作为备用电源，剩余容量参与套利 |
| FR-02-05 | 自发自用模式 | 光伏全部供给本地负荷，电池仅用于平滑光伏波动，不上网售电 |
| FR-02-06 | 自动/手动切换 | 支持根据电网状态、电价时段、SOC 水平自动切换模式；支持用户手动强制指定模式 |
| FR-02-07 | 模式切换平滑过渡 | 模式切换过程中功率波动 ≤10% 额定功率，切换执行时间 ≤100ms |

### 2.4 FR-04：峰谷套利策略（Peak-Valley Arbitrage Strategy）

| 属性 | 内容 |
|------|------|
| 需求编号 | FR-04 |
| 需求名称 | 峰谷套利策略 |
| 优先级 | P1 |
| 状态 | 待开发 |

**需求描述：**

系统应基于分时电价政策，通过 AI 优化调度电池充放电时序，实现峰谷价差收益最大化。

**详细要求：**

| 子需求编号 | 子需求名称 | 描述 |
|-----------|-----------|------|
| FR-04-01 | 分时电价配置 | 支持配置峰、平、谷时段及对应电价，支持多套电价方案（如一般工商业、大工业），支持自定义时段 |
| FR-04-02 | 电价政策自动更新 | 对接地方发改委/电网公司电价公告，自动识别电价调整并提示用户确认更新 |
| FR-04-03 | AI 套利调度 | 基于负荷预测、光伏出力预测、电价曲线和电池约束，以日收益最大化为目标，生成次日充放电计划 |
| FR-04-04 | 实时策略调整 | 当实际负荷/光伏偏离预测时，以 ≤5min 间隔滚动修正当日剩余时段的调度计划 |
| FR-04-05 | 收益测算 | 实时计算当日/当月/当年峰谷套利收益，与无储能方案对比展示节省金额 |
| FR-04-06 | 需量管理 | 对大工业用户，通过电池放电削减最大需量，降低基本电费，需量控制误差 ≤5% |

### 2.5 FR-05：电网接入管理（Grid Connection Management）

| 属性 | 内容 |
|------|------|
| 需求编号 | FR-05 |
| 需求名称 | 电网接入管理 |
| 优先级 | P0 |
| 状态 | 待开发 |

**需求描述：**

系统应管理光储系统与电网的交互，包括双向计量、余电上网、电网购电及安全保护。

**详细要求：**

| 子需求编号 | 子需求名称 | 描述 |
|-----------|-----------|------|
| FR-05-01 | 双向计量 | 通过双向智能电表计量上网电量和购电电量，数据精度 ±0.5% |
| FR-05-02 | 余电上网 | 光伏发电超出负荷和电池充电需求时，自动将余电并入电网，上网功率不超过并网容量限制 |
| FR-05-03 | 电网购电 | 光伏+电池不足以供给负荷时，自动从电网购电补充，购电功率不超过进线容量 |
| FR-05-04 | 防孤岛保护 | 电网断电时，逆变器在 ≤200ms 内停止向电网送电，防止孤岛运行；系统自动切换至离网模式 |
| FR-05-05 | 频率/电压响应 | 当电网频率偏差 >0.5Hz 或电压偏差 >10% 时，系统主动调整有功/无功出力参与电网调节 |
| FR-05-06 | 并网/离网无缝切换 | 电网故障恢复后，系统自动检测电网参数合规，在 ≤500ms 内完成并网同步和切换 |
| FR-05-07 | 并网容量管理 | 可配置并网点最大容量，当上网功率超限时优先充电，充电功率不足时降额光伏出力 |

| FR-07-09 | 故障录波 | 关键故障发生时自动记录故障前后 10s 的运行数据波形，供故障分析使用 |

### 5.1 并网发电流程

```
开始
  │
  ▼
[检测电网状态] ──── 电网异常 ──→ 转入 5.4 故障切换流程
  │
  │ 电网正常
  ▼
[采集实时数据：光伏出力、负荷需求、电池SOC、电价信号]
  │
  ▼
[EMS 调度决策]
  │
  ├─ 光伏出力 ≥ 负荷需求 ──→ [光伏直供负荷] ──→ 剩余功率？
  │                                            │
  │                            ├─ 有剩余 & SOC未满 ──→ [充电至SOC上限]
  │                            │
  │                            └─ 有剩余 & SOC已满 ──→ [余电上网]
  │
  ├─ 光伏出力 < 负荷需求 ──→ [光伏全部直供负荷] ──→ 缺口功率？
  │                                              │
  │                            ├─ 电价处于谷时 ──→ [从电网购电补缺口]
  │                            │
  │                            ├─ 电价处于峰时 & SOC充足 ──→ [电池放电补缺口]
  │                            │
  │                            └─ 电价处于峰时 & SOC不足 ──→ [从电网购电补缺口]
  │
  ▼
[更新能量流向图和运行数据]
  │
  ▼
[等待下一个调度周期 (≤1s)]
  │
  ▼
返回 [采集实时数据]
```

### 5.2 离网备电流程

```

  │
  ▼
[检测到电网断电 / 收到防孤岛保护信号]
  │
  ▼
[逆变器停止向电网送电 (≤200ms)]
  │
  ▼
[系统切换至离网模式 (≤100ms)]
  │
  ▼
[识别关键负荷和非关键负荷]
  │
  ▼
[切除非关键负荷，保障关键负荷供电]
  │
  ▼
[EMS 离网调度循环]
  │
  ├─ 光伏有出力 ──→ [光伏直供关键负荷]
  │                    │
  │      ├─ 有剩余功率 & SOC未满 ──→ [充电]
  │      │
  │      └─ 负荷不足 & SOC未满 ──→ [光伏优先充电]
  │
  ├─ 光伏无出力 ──→ [电池放电供给关键负荷]
  │
  ▼
[监测 SOC 水平]
  │
  ├─ SOC > 20% ──→ 继续离网调度
  │
  ├─ SOC ≤ 20% ──→ [触发低电量告警，建议关闭非必要负荷]
  │
  ├─ SOC ≤ 5% ──→ [触发紧急告警，仅保留最低限度供电]
  │
  ▼
[持续检测电网恢复]
  │
  ├─ 电网未恢复 ──→ 继续离网调度
  │
  └─ 电网恢复 ──→ 转入 5.1 并网发电流程
```

### 5.3 峰谷套利流程

```
开始
  │
  ▼
[加载分时电价配置：峰时段/平时段/谷时段及对应电价]
  │
  ▼
[获取次日负荷预测曲线和光伏出力预测曲线]
  │
  ▼
[AI 优化引擎：以日净收益最大化为目标]
  输入：负荷预测、光伏预测、电价曲线、电池容量/SOC约束、充放电效率
  输出：次日24h充放电计划（15min粒度）
  │
  ▼
[下发调度计划至边缘 EMS]
  │
  ▼
[按计划执行充放电]
  │
  ├─ 谷时段到来 ──→ [检查SOC < 充电目标值？]
  │                    │
  │      ├─ 是 ──→ [从电网购电充电，充电功率 = 计划值]
  │      │         （同时优先消纳光伏）
  │      └─ 否 ──→ [跳过充电]
  │
  ├─ 峰时段到来 ──→ [检查SOC > 放电下限？]
  │                    │
  │      ├─ 是 ──→ [电池放电供给负荷，放电功率 = 计划值]
  │      │         （光伏不足时电池补充）
  │      └─ 否 ──→ [跳过放电，从电网购电]
  │
  ├─ 平时段到来 ──→ [根据实时情况灵活调度]
  │                    │
  │      ├─ 光伏充足 ──→ [优先充电]
  │      └─ 光伏不足 ──→ [维持当前SOC]
  │
  ▼
[每5min：检测实际值与预测值偏差]
  │
  ├─ 偏差 > 阈值 ──→ [滚动修正剩余时段调度计划]
  │
  └─ 偏差 ≤ 阈值 ──→ [继续执行当前计划]
  │
  ▼
[日终结算：计算当日峰谷套利收益]
  │
  ▼
[生成日报表，更新累计收益和ROI]
```

```
                       [尝试自动重连 (≤30s)]
                          │
                          ├─ 重连成功 ──→ [设备恢复正常]
                          │
                          └─ 重连失败 ──→ [升级告警级别 + 通知运维]
```

### 5.5 设备接入流程

```
开始
  │
  ▼
[物理安装设备：接线、上电]
  │
  ▼
[EMS 控制器总线扫描 / 用户扫码添加]
  │
  ▼
[识别设备类型和型号]
  │
  ├─ 已知设备 ──→ [自动匹配通信协议和驱动]
  │
  └─ 未知设备 ──→ [提示用户手动选择设备类型]
                      │
                      ▼
                   [加载通用协议适配器]
  │
  ▼
[建立通信连接并测试]
  │
  ├─ 通信成功 ──→ 继续
  │
  └─ 通信失败 ──→ [检查接线/地址配置] ──→ 返回 [建立通信连接]
  │
  ▼
[读取设备基础信息：序列号、固件版本、额定参数]
  │
  ▼
[注册设备至系统台账：分配设备ID、记录安装信息]
  │
  ▼
[配置设备参数：通信地址、采样周期、保护阈值等]
  │
  ▼
[设备自检与校准]
  │
  ├─ 自检通过 ──→ [设备状态设为"在线"]
  │                  │
  │                  ▼
  │               [纳入EMS调度管理]
  │                  │
  │                  ▼
  │               [更新系统拓扑图]
  │                  │
  │                  ▼
  │               [接入完成]
  │
  └─ 自检失败 ──→ [设备状态设为"故障"]
                     │
                     ▼
                  [触发告警，等待人工处理]
```

## 6. 验收标准

### 6.1 智能光储调度（FR-01）

| 验收项 | 验收标准 | 测试方法 |
|--------|---------|---------|
| 实时调度响应 | 从数据采集到调度指令发出 ≤1s | 注入阶跃负荷变化，测量响应时间 |
| 光伏优先消纳 | 光伏出力充足时，负荷 100% 由光伏直供或经电池间接供给 | 统计日光伏自消纳率 ≥95% |
| SOC 保护 | SOC 不超过上限/下限 | 长期运行测试，SOC 无越限记录 |
| 负荷预测精度 | 24h 预测 MAPE ≤15% | 连续 7 天对比预测值与实际值 |
| 光伏预测精度 | 24h 预测 MAPE ≤20% | 连续 7 天对比预测值与实际值 |

### 6.2 工作模式管理（FR-02）

| 验收项 | 验收标准 | 测试方法 |
|--------|---------|---------|
| 模式切换时间 | 从发出切换指令到新模式生效 ≤100ms | 模拟电网故障，测量离网切换时间 |
| 模式切换平滑度 | 切换过程功率波动 ≤10% 额定功率 | 功率分析仪记录切换过程波形 |
| 自动切换可靠性 | 100 次自动切换成功率 100% | 自动化测试脚本循环触发 |
| 手动切换响应 | 手动切换后 ≤200ms 界面反馈 | UI 自动化测试 |

### 6.3 实时监控（FR-03）

| 验收项 | 验收标准 | 测试方法 |
|--------|---------|---------|
| 数据刷新延迟 | 界面数据与实际值偏差延迟 ≤2s | 同步对比界面显示与现场仪表 |
| 数据精度 | 功率测量误差 ≤±1%，电量测量误差 ≤±0.5% | 标准源比对校准 |
| 仪表盘加载 | 首屏可交互时间 ≤3s | Lighthouse CI 自动化测试 |
| 历史数据完整性 | 90 天内 1min 粒度数据无缺失 | 数据完整性校验脚本 |

### 6.4 峰谷套利（FR-04）

| 验收项 | 验收标准 | 测试方法 |
|--------|---------|---------|
| 套利收益 | 有储能方案月电费比无储能方案降低 ≥20% | 电费账单对比（标准工况） |
| 策略执行准确率 | 实际充放电曲线与计划曲线偏差 ≤10% | 15min 粒度对比分析 |
| 电价配置灵活度 | 支持自定义 ≥8 个时段/天 | 配置界面功能测试 |
| 需量管理效果 | 月最大需量降低 ≥10% | 对比启用前后的需量数据 |

### 6.5 电网接入（FR-05）

| 验收项 | 验收标准 | 测试方法 |
|--------|---------|---------|
| 防孤岛保护时间 | 电网断电到停止送电 ≤200ms | 继电保护测试仪模拟 |
| 并网恢复时间 | 电网恢复到并网运行 ≤500ms | 电网模拟器测试 |
| 双向计量精度 | 上网/购电电量误差 ≤±0.5% | 标准电表比对 |
| 并网容量合规 | 上网功率不超过配置容量限制 | 满功率运行测试 |
