# 绿电智储（Green Energy Smart Storage）前端/后台管理界面设计文档

> **项目名称**：绿电智储 — 光伏储能并网智能管理系统
> **技术定位**：通用光伏组件 + 华为逆变器 + 模块化电池储能 + 智能 EMS
> **文档版本**：v1.0
> **最后更新**：2026-06-27

---

## 1. 设计原则

### 1.1 数据优先（Data-first Design）

- 界面以数据展示为第一优先级，所有核心指标在首屏即可获取
- 数值型数据使用等宽字体（GeistMono）突出显示，搭配趋势箭头与同比/环比标签
- 关键运行参数（发电功率、SOC、负荷、交换功率）实时刷新，刷新间隔可配置（默认 5s）
- 图表遵循"数据墨水比"原则：去除冗余装饰，最大化数据表达

### 1.2 状态可见（Visibility of System Status）

- 全局设备状态摘要常驻于顶栏右侧，以图标+颜色点标示在线/离线/告警数量
- 所有异步操作（保存、导出、模式切换）提供加载指示器与完成反馈
- 页面切换采用路由过渡动画，避免白屏等待
- 数据刷新状态通过时间戳 + 旋转刷新图标清晰传达

### 1.3 操作高效（Efficiency of Use）

- 高频操作（模式切换、设备搜索、报表导出）不超过 3 次点击完成
- 支持键盘快捷键：`Ctrl+K` 全局搜索、`Ctrl+S` 保存当前表单、`Esc` 关闭弹窗/抽屉
- 批量操作支持多选后一次性执行（批量确认告警、批量导出等）
- 表格默认分页 20 条，支持列排序、列筛选、列固定与密度切换

### 1.4 容错友好（Error Tolerance）

- 危险操作（删除设备、强制离网、重置配置）二次确认，说明不可逆后果
- 表单即时校验，错误信息紧邻字段显示，不使用弹窗阻断
- 网络异常时保留本地缓存数据，展示"数据可能过期"提示而非空白
- 操作失败自动重试 1 次（幂等请求），失败后展示重试按钮与错误详情入口

### 1.5 一致性（Consistency）

- 全系统统一色彩、字体、间距、组件规范，遵循本文档第 5 节
- 相同语义操作使用相同图标与文案（如"导出"始终使用 `Download` 图标）
- 所有列表页遵循统一布局：筛选栏 → 操作栏 → 表格 → 分页
- 所有详情页遵循统一布局：返回按钮 → 标题 → 标签页/分区 → 内容

**侧边栏规格**：
- 展开宽度：240px，收起宽度：64px（仅显示图标）
- 收起/展开切换按钮位于侧边栏底部
- 当前页面菜单项高亮，父级自动展开
- 菜单分组：监控（仪表盘、实时监控）、数据（能源报表）、管理（设备管理、告警中心）、系统（系统设置）

**顶栏规格**：
- 高度：56px，固定于顶部（`position: fixed`）
- 左侧：产品 Logo（收起侧边栏时显示完整名称，展开时仅显示图标）
- 中部：面包屑导航（Home > 当前模块 > 当前页面）
- 右侧：通知铃铛（带未读数量红点）、全屏切换、用户头像+下拉菜单（个人设置、修改密码、退出登录）

├──────────────────────┬───────────────────────────┤

│  24h 发电/消费曲线   │  运行模式切换 + 当前模式  │  ← 底部双栏

**指标卡片规格**：

| 卡片 | 图标 | 主数据 | 单位 | 辅助信息 |
|------|------|--------|------|----------|
| 光伏发电 | ☀️ `Sun` | 实时功率 | kW | 今日累计 kWh，较昨日 ↑↓% |
| 电池 SOC | 🔋 `BatteryCharging` | SOC 百分比 | % | 充/放电功率 kW，预计满/空时间 |
| 负荷消耗 | 🏠 `Home` | 实时功率 | kW | 今日累计 kWh，峰值 kW |
| 电网交互 | ⚡ `Zap` | 交换功率 | kW | 方向标识（购/售），今日净 kWh |

- 每个卡片：白底、圆角 12px、内边距 20px、hover 时微上浮（translateY -2px）+ 阴影加深
- 主数据字号 32px / GeistMono Bold，辅助信息 14px / InstrumentSans

**能量流向图**：
- 中心化布局，展示光伏 → 负荷、光伏 → 电池、电池 → 负荷、电网 ↔ 系统的能量流向
- 流向线使用动态粒子动画，粒子密度与功率成正比
- 各节点显示实时功率值，hover 展示详细参数浮窗
- 点击节点可跳转至对应设备详情

**24h 曲线图**：
- 双 Y 轴面积图：左轴发电量（绿色区域）、右轴消电量（橙色区域）
- X 轴为 0-24 时，当前时间竖线标注
- 支持鼠标悬停显示具体数值 tooltip
- 图例可点击切换显示/隐藏

**运行模式区域**：
- 当前模式大图标 + 名称 + 运行时长
- 模式切换按钮组：并网模式 / 离网模式 / 峰谷套利模式
- 切换时弹出确认对话框，说明切换影响与预计效果

- 并网参数：额定电压、额定频率、功率因数要求
- 保护定值：过压阈值、欠压阈值、过频阈值、欠频阈值、防孤岛保护开关
- 需量管理：契约容量(kW)、需量控制策略

**通知规则**：
- 通知渠道：站内信 / 邮件 / 短信 / 钉钉/企业微信 Webhook
- 告警级别通知映射：紧急→全渠道、重要→站内+邮件、提示→站内
- 通知时段设置（免打扰时段）
- 通知接收人/组管理

## 3. 交互流程

### 3.1 核心交互流程

#### 3.1.1 登录流程

```
用户打开系统 → 展示登录页 → 输入用户名+密码
  → 点击登录 → [Loading] → 验证成功 → 跳转仪表盘首页
                         → 验证失败 → 表单内联错误提示 → 重新输入
```

- 登录失败不使用弹窗，在密码字段下方红色提示"用户名或密码错误"
- 连续 5 次失败后锁定账号 15 分钟，提示"账号已锁定，请15分钟后重试或联系管理员"
- 登录成功后记录登录日志，生成会话 Token，跳转 `/dashboard`

#### 3.1.2 仪表盘模式切换流程

```
用户点击目标模式按钮 → 弹出确认对话框（展示切换影响说明与预计效果）
  → 用户确认 → [Loading 按钮状态] → EMS 下发指令 → 指令执行中（过渡状态，3-10s）
  → 执行成功 → Toast 成功"已切换至XX模式" → 模式卡片更新
  → 执行失败 → Toast 失败"模式切换失败：[原因]" → 保持原模式
```

- 确认对话框内容：当前模式 → 目标模式，预计影响（如"切换至离网模式后，系统将脱离电网，所有负荷由光伏+电池供给"）
- 过渡状态期间模式卡片显示旋转加载图标，禁止再次切换

#### 3.1.3 添加设备流程

```
用户点击[+ 添加设备] → 弹出添加设备弹窗
  → 选择设备类型 → 联动显示对应配置表单
  → 填写表单 → 实时校验（必填、格式、范围）
  → 点击确认 → [Loading] → 提交后端 → 自动连通性检测
  → 添加成功+连通成功 → Toast"设备添加成功" → 刷新设备列表 → 关闭弹窗
  → 添加成功+连通失败 → Toast"设备已添加，但通信未通，请检查地址" → 刷新列表
  → 添加失败 → Toast"添加失败：[原因]" → 保持弹窗，保留已填数据
```

#### 3.1.4 报表生成与导出流程

```
用户选择时间维度（日/月/年）→ 选择日期范围
  → 图表与汇总指标自动加载 → 用户可切换图表类型
  → 点击导出 → 下拉菜单选择格式（Excel/PDF/CSV）
  → [Loading] → 生成文件 → 浏览器下载 → Toast"导出成功"
```

- 导出 PDF 包含图表截图 + 数据表格
- 导出 Excel 包含原始数据 + 汇总统计 Sheet
- 大数据量导出（>10000 条）提示"数据量较大，预计需要X秒"，支持后台导出+下载中心获取

#### 3.1.5 告警处理流程

```
告警触发 → 系统通知（站内/邮件/短信）
  → 运维人员在告警中心查看 → 点击确认告警 → 状态变为"已确认"
  → 现场排查 → 点击开始处理 → 状态变为"处理中"
  → 问题修复 → 填写处理说明 → 点击标记解决 → 状态变为"已解决"
```

- 紧急告警在顶栏铃铛处弹出实时通知气泡
- 已确认但 30 分钟未开始处理的告警，系统发送催办提醒

### 3.2 状态流转

#### 3.2.1 设备状态流转

```
        部署上线
           │
           ▼
       ┌───────┐
  ┌────│ 在线  │◄────┐
  │    └───┬───┘     │
  │        │         │
  │  通信断开    通信恢复
  │        │         │
  │        ▼         │
  │    ┌───────┐     │
  │    │ 离线  │─────┘
  │    └───┬───┘
  │        │
  │  手动/定时巡检
  │        │
  │        ▼
  │    ┌───────┐
  │    │ 维护中│
  │    └───┬───┘
  │        │
  │  维护完成    检测到异常
  │        │         │
  │        ▼         ▼
  └───► 在线     ┌───────┐
                 │  故障  │
                 └───────┘
                     │
               修复后重上线
                     │
                     ▼
                   在线
```

- 状态转换均记录操作日志
- 故障状态自动触发告警
- 离线超过 5 分钟自动触发通信中断告警

#### 3.2.2 告警状态流转

```
  ┌──────────┐
  │  待处理  │  ← 告警触发
  └────┬─────┘
       │ 确认
       ▼
  ┌──────────┐
  │  已确认  │
  └────┬─────┘
       │ 开始处理
       ▼
  ┌──────────┐
  │  处理中  │
  └────┬─────┘
       │ 标记解决
       ▼
  ┌──────────┐
  │  已解决  │
  └────┬─────┘
       │ 重新打开（可选）
       │
       ▼
     待处理
```

- 每次状态变更需填写备注（处理中→已解决为必填）
- 状态变更推送通知给相关运维人员

#### 3.2.3 运行模式流转

```
                 并网模式
                ╱    │    ╲
       切换    ╱     │     ╲  切换
             ╱  电网断开  ╲
            ╱       │       ╲
   离网模式 ◄──────┤────────► 峰谷套利
            ╲       │       ╱
             ╲  电网恢复  ╱
               ╲     │    ╱
                 并网模式

  过渡状态（切换中）：
  ┌──────────┐    ┌──────────┐    ┌──────────┐
  │  并网    │ →  │ 切换中…  │ →  │  离网    │
  └──────────┘    └──────────┘    └──────────┘
                    (3-10s)
```

- 并网↔离网：电网断开/恢复自动触发，也可手动切换
- 并网↔峰谷套利：手动切换，需确认时段配置
- 切换中为过渡状态，UI 显示加载动画，禁止重复操作
- 切换失败自动回退原模式，并触发告警

### 5.6 动效规范

#### 5.6.1 过渡时间

| Token | 时长 | 用途 |
|-------|------|------|
| duration-fast | 150ms | 颜色变化、hover 态切换、小型元素过渡 |
| duration-normal | 250ms | 通用过渡、弹窗出现、抽屉滑入、页面切换 |
| duration-slow | 350ms | 复杂动画、图表过渡、大面积布局变化 |
| duration-entrance | 400ms | 页面首屏入场、骨架屏消失 |

#### 5.6.2 缓动函数

| 名称 | 值 | 用途 |
|------|------|------|
| ease-default | `cubic-bezier(0.4, 0, 0.2, 1)` | 通用过渡（Material Design 标准缓动） |
| ease-in | `cubic-bezier(0.4, 0, 1, 1)` | 元素退出 |
| ease-out | `cubic-bezier(0, 0, 0.2, 1)` | 元素进入 |
| ease-spring | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹窗出现（轻微过冲回弹感） |
| ease-bounce | `cubic-bezier(0.68, -0.55, 0.265, 1.55)` | 特殊反馈（数字跳动、状态切换） |

#### 5.6.3 入场动画

| 场景 | 动画 | 参数 |
|------|------|------|
| 弹窗 | fade-in + scale | opacity 0→1, scale 0.95→1, 250ms ease-spring |
| 抽屉 | slide-in | translateX 100%→0, 250ms ease-out |
| Toast | slide-in-right + fade-in | translateX 20%→0, opacity 0→1, 250ms ease-out |
| 页面切换 | fade-in | opacity 0→1, 150ms ease-default |
| 卡片入场 | slide-up + fade-in | translateY 8px→0, opacity 0→1, 250ms ease-out（交错 50ms） |
| 下拉面板 | scale-y + fade-in | scaleY 0.95→1, transform-origin top, 200ms ease-out |

#### 5.6.4 退场动画

| 场景 | 动画 | 参数 |
|------|------|------|
| 弹窗 | fade-out + scale | opacity 1→0, scale 1→0.95, 200ms ease-in |
| 抽屉 | slide-out | translateX 0→100%, 200ms ease-in |
| Toast | slide-out-right + fade-out | translateX 0→20%, opacity 1→0, 200ms ease-in |

#### 5.6.5 数据动画

| 场景 | 动画 | 参数 |
|------|------|------|
| 数值变化 | Counter 动画 | 数字滚动过渡，600ms ease-out，千分位实时更新 |
| 图表数据更新 | Morph 过渡 | 路径/面积平滑变形，800ms ease-default |
| 进度条变化 | 宽度过渡 | width 过渡，400ms ease-default |
| 状态切换 | 颜色过渡 | background-color/color 过渡，250ms ease-default |
| 列表排序 | FLIP 动画 | 元素位置交换动画，300ms ease-default |

#### 5.6.6 性能约束

- 所有动画使用 `transform` 和 `opacity` 属性（GPU 加速），避免触发 layout/paint
- 动画帧率目标 ≥ 60fps，复杂动画降级策略：`prefers-reduced-motion: reduce` 时禁用所有非必要动画
- 图表动画在大数据量（>500 点）时自动缩短至 200ms 或禁用
- 移动端默认简化动画：取消卡片交错入场、缩短图表过渡至 400ms
