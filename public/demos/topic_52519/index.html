    Mock 模式
    开启后始终使用内置演示数据，不调用真实接口。可在设置中导入示例数据。
    将图片作为上下文发送给 AI
    开启后，日记中的图片会随文字一起发送给模型，帮助 AI 更好地理解你的心情与场景。图片理解消耗 tokens 较多，请谨慎选择！

    AI 记忆笔记本

    魔镜会记住你觉得重要的事，即使过了很久也不会忘记。你可以在这里管理它的记忆。

    外观主题

    选择一种你喜欢的强调色，会即时应用到整个界面。
    夜间治愈模式
    深色背景，适合深夜睡前复盘，保护眼睛。

    云同步（WebDAV）

    数据直接发往你自己的 WebDAV 服务器，绝不上传到任何第三方。适合在手机端与电脑端同步。

    支持坚果云、Nextcloud、Synology 等 WebDAV 服务。部分服务（如坚果云）可能因浏览器跨域限制无法直接使用，建议使用支持 CORS 的服务或自建 WebDAV。凭据与 API Key 一样保存在本地浏览器。

    数据管理

    你的日记、回音、对话记录均保存在本地浏览器中，清除浏览器数据会丢失。建议定期导出 JSON 完整备份。

    导出 JSON 完整备份
    导出全部数据（日记、回音、对话、记忆、设置）为 .json 文件，可用于恢复。
    从 JSON 备份恢复
    导入 .json 备份文件，覆盖当前全部数据。
    导出 Markdown 备份
    将所有日记与 AI 回应导出为 .md 文件。
    导入示例数据
    填充 7 天演示日记，便于体验完整流程。
    清空所有数据
    不可恢复，请谨慎操作。

    这是我的 TRAE 创造力大赛参赛作品，也是我的第一个项目

    而我，不过是一个普通的高中文科生。

    在我的世界里，活着就只是上学的时候学习，回家了打游戏，一天又一天，像刷副本一样，和生活没有关联，或者说，根本没有生活。

    我好迷茫，学习之后可以做什么？我作为一个并不出众的文科生，即使考上大学又能去往何方？父母都说打游戏没有用。好像的确，但除此之外我还能做什么，或是，还会做什么？

    我好羡慕别人，有特长，可以在自己热爱并且出彩的领域或舞台上，让别人都看见他/她独有的优秀；可以去任何自己想去的地方，看看这个别人都说精彩的世界；可以被别人在意，也有自己在意的人，而这些是他们存在于这个世界的证明。

    而我呢？永远只是台下的听众，宅家里的老鼠，只能偷窥别人的生活。也许身边有许多认识的人，会一起吃饭，一起嬉闹，一起打游戏玩乐。但真的心里不舒服、想找人倾诉的时候，没有一个可以信任、在意你的情绪、懂你的人。我也许就是不被人需要的。可这种感觉真的好难受。

    父母从来都带着他们的奢望，无论我做得多好。他们说这都是为了你自己，可是我只想要一个肯定。这么小的东西，能给我、肯给我的人屈指可数。好像只要我得到一个，就完全从天上掉进深渊，然后万劫不复。

    我知道这个世界很温暖，可是现在都与我无关……

    我也不止一次想过死亡，但是我发现死亡比活着更没有意义。所以，生活很苦，但总要找到一些理由让自己活下去。

    这么负能量的我，也许并不正常吧。这就有了魔镜这个项目的诞生。我是 ChatGPT 等 AI 聊天工具的第一批用户，在 2023 AI 元年，我就知道它一定会是未来的大趋势。之后我又参与了文心一言、元宝、千问、Kimi 甚至 JVS、Claw、超级小爱的内测。我想帮助除我以外的所有人，能够走出情绪，感受这个多姿多彩的世界。

    它可能并不完美，但我真的真的很希望它能被更多人看见，还有收到很多的建议，然后变成我现在想不到的样子。
