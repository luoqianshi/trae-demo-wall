# AI 漫剧工坊 — 初赛 Demo

## 简介

一句话故事，自动生成竖屏漫剧 Demo。本提交为单文件 `index.html`，无外部依赖，可直接用浏览器打开。

## 核心能力

- 输入 10–300 字中文故事，或选择内置灵感。
- 极速体验模式：本地确定性生成剧本、角色、六格分镜。
- 三种原创程序化画风：霓虹悬疑、治愈绘本、国风水墨。
- 9:16 竖屏播放器，支持浏览器中文配音与程序化背景音。
- 分镜旁白/对白可编辑，修改后立即生效。
- 导出 720×1280 WebM 成片、SRT 字幕、HTML 文件。
- 发布检查：比例、分辨率、时长、分镜完整性、字幕安全区、音轨状态。
- 真实 AI 模式：可配置 OpenAI 兼容接口（Key 仅保存在页面内存）。

## 使用方式

1. 解压后双击 `index.html`，在 Chrome/Edge 中打开。
2. 左侧输入故事，选择画风，点击「一键生成漫剧」。
3. 切换「成片」标签播放；切换「导出」标签下载 WebM。

## 技术栈

- 原生 HTML5 / CSS3 / ES2020+
- Canvas 2D 程序化绘图
- Web Speech API、Web Audio API、MediaRecorder
- 无框架、无 CDN、无后端
