核心功能

九大模块协同工作，全方位守护通话清静

dark_mode

智能勿扰模式

支持定时开启（如 23:00-07:00），自动静音陌生来电。三级降级策略：完全静音 → 仅紧急放行 → 全部正常响铃。

layers

悬浮窗快捷助手

通话中显示可拖拽悬浮按钮，长按弹出音频选择菜单，一键播放防御语音，无需切换 App。

graphic_eq

渐进式音频引擎

强制扬声器外放，5 秒内从 30% 音量缓慢提升至 100%，避免惊吓。支持麦克风静音。

priority_high

紧急来电判定

15 分钟内同一号码二次来电自动放行（跨天支持），确保不漏接真正紧急的电话。

block

黑白名单管理

黑名单号码直接静音，白名单号码永不拦截。支持手动添加和历史记录一键拉黑。

history

拦截历史与播放记录

完整记录每次拦截/放行的号码、时间和处理结果，播放历史追踪防御语音使用情况。

notifications_active

高优先级紧急通知

紧急来电触发全屏通知 + 强震动（VibrationEffect），确保在勿扰模式下也能察觉。

security

权限引导流程

三步引导用户授予电话状态、悬浮窗、通知权限，首次安装即有清晰指引。

bug_report

调试面板

隐藏的开发者调试入口，可模拟来电状态、测试音频播放、查看服务运行状况。

TRAE 实践过程

从设计稿到可运行 APK，全程使用 TRAE IDE 开发

1. 设计驱动提示词输入

将完整的设计规范（9 大模块、UI 配色、数据库 Schema、导航结构）作为提示词输入 TRAE，同时提供 Stitch 生成的 8 个 HTML 设计稿作为前端参考。

提示词工程

2. 项目脚手架生成

TRAE 根据提示词一次性生成完整项目结构：Kotlin + Jetpack Compose + Room + DataStore，MVVM 架构，30+ 个源文件。

代码生成

3. 核心模块实现

通过多轮对话实现：悬浮窗 WindowManager、AudioPlaybackEngine 渐进音量、二次来电紧急判定算法、三级勿扰降级策略。

智能体编程

4. 代码审查与修复

使用 Task 子代理做全量代码审查，识别并修复 5 个硬编译错误（缺少 import、类型不匹配、变量名冲突等）。

AI 代码审查

通过 TRAE 命令行下载 Gradle 8.5、Android SDK、JDK 17，配置阿里云镜像源，解决国内下载依赖超时问题。
