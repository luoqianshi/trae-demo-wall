核心功能亮点

⚡

3秒记录 + AI 反馈

单行输入即可记录小成功，AI 自动分类打标（小成功/好习惯/进步/感悟），并以雪球精灵口吻给出温暖反馈，支持多轮对话追问。

❄️

雪球成长系统

三阶段进化：雪粒 → 小雪球 → 雪球。记录、完成任务、打卡都会给雪球"添雪"加分。点击雪球触发互动动画，12+ 场景渗透雪球形象。

📊

四象限任务管理

基于艾森豪威尔矩阵的任务优先级管理（立即做/计划做/委托/删除），支持四种任务类型：快速任务、普通任务、长任务/目标、习惯打卡。

🚑

拖延急救系统

输入"想做的事"和"当下状态"，AI 生成 3-8 个可在 2 分钟内完成的原子级过渡步骤，从当前状态无缝衔接到目标动作。

🏆

挑战与成就

三级难度挑战（青铜/白银/黄金），37 个成就覆盖 8 大类别，里程碑奖励机制，支持补签，让成长像游戏一样有趣。

🧠

AI 主动发现

智能检测用户关注主题、对比近期记录变化，主动发现成长加速或需要关怀的时刻。情绪安全网自动检测焦虑/低落并提供关怀建议。

技术架构

🎨 前端技术栈

  • Next.js 16.2.4 + React 19.2.4
  • Tailwind CSS 4.2.2（暖色调设计系统）
  • Framer Motion 12.38.0（丰富动画交互）
  • Recharts 3.8.1（数据可视化）

⚙️ 后端与AI

  • 本地 JSON 持久化（零配置运行）
  • 智谱 AI GLM-4-Flash（主API）
  • OpenAI fallback（高可用保障）
  • Vitest 4.1.5（528+ 单元测试）

工程亮点：Supabase → 本地 JSON 迁移，30 个 API 路由精简，代码量缩减 58%-64%，一行 npm run dev 即可启动
