# Bug 修复报告：任务完成界面跳转与效果丢失

## 修复日期
2026-05-10

## 问题描述
用户报告三个相关问题：
1. **页面强制跳转到顶部**：每确认完成一个任务，界面都会强制返回到最顶部
2. **Demo效果未实现**：任务完成时的光晕效果和浮动文字效果没有显示
3. **任务标题丢失**：标记完成后任务的标题会丢失

## 根因分析

### 1. 页面跳转问题
- **原因**：`useTasks.ts` 中的 `updateTask` 和 `patchTask` 在更新成功后都会调用 `fetchTasks()`，这会重新获取所有任务数据并触发 `setTasks()`
- **后果**：整个任务列表重新渲染，`groupedTasks` 通过 `useMemo` 重新计算，导致页面滚动位置丢失

### 2. Demo效果未实现
- **原因**：`TaskCard` 组件使用本地状态 `showGlow` 和 `showFloatText` 控制效果显示
- **后果**：当 `handleStatusChange` 触发后调用 `fetchTasks()`，整个组件重新渲染，本地状态被重置，光晕和浮动文字效果消失

### 3. 任务标题丢失
- **原因**：`handleStatusChange` 在调用父组件的 `onStatusChange` 时，有时未正确传递 `taskTitle` 参数
- **后果**：父组件中 `saveTitle` 为空字符串，导致记录创建时标题丢失

## 修复方案

### 修复1：保存和恢复滚动位置
在 `tasks/page.tsx` 的 `handleStatusChange` 函数中添加滚动位置保存和恢复逻辑：

```typescript
const handleStatusChange = async (taskId: string, status: Task['status'], taskTitle?: string) => {
  // ... 原有逻辑 ...
  
  // 保存当前滚动位置
  const scrollY = window.scrollY;
  
  if (parentId) {
    await patchTask(taskId, { status });
  } else {
    await updateTaskStatus(taskId, status);
  }
  if (parentId) {
    await loadSubtasks(parentId);
  }
  
  // 恢复滚动位置
  window.scrollTo(0, scrollY);
  
  // ... 后续逻辑 ...
};
```

### 修复2：确保标题正确传递
在 `TaskCard` 组件的 `handleStatusChange` 中确保始终传递 `taskTitle`：

```typescript
const handleStatusChange = async (id: string, newStatus: Task['status'], taskTitle?: string) => {
  if (newStatus === 'completed' && !isCompleted) {
    // 触发光晕效果
    setShowGlow(true);
    setTimeout(() => setShowGlow(false), 1000);
    
    // 触发浮动文字
    setShowFloatText(true);
    setTimeout(() => setShowFloatText(false), 1500);
  }
  // 确保传递taskTitle
  await onStatusChange(id, newStatus, taskTitle || task.title);
};
```

### 修复3：子任务标题传递
确保子任务的状态变更也正确传递标题：

```typescript
<DotCheckbox
  checked={stCompleted}
  onChange={() => onStatusChange(st.id, stCompleted ? 'pending' : 'completed', st.title || '')}
  size={16}
/>
```
