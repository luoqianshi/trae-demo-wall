# Bug 修复报告：新手引导动画播放异常跳转错误页面

## 修复日期
2026-05-16

## 问题描述
新手引导动画播放流程中，出现异常跳转至《出了点小问题》报错界面的错误。用户在完成新手引导的"记录小成功"步骤后，页面异常跳转到全局错误边界页面，导致引导流程中断。

## 根因分析

### 1. 庆祝效果与引导覆盖层冲突（🔴 严重）
- **原因**：`handleOnboardingCreateRecord` 调用 `createRecord` 时未传入 `{ skipCelebration: true }`，导致记录创建后触发 `CelebrationEffect` 和 `GlobalCelebration` 渲染
- **后果**：庆祝效果与 `OnboardingFlow` 的 `z-[100]` 覆盖层同时渲染，产生 z-index 冲突和渲染竞争，可能导致 React 渲染异常
- **触发路径**：StepRecording → `onCreateRecord` → `createRecord` → 庆祝效果渲染 → 与 OnboardingFlow 冲突

### 2. fetchFeedback 未捕获的异步错误（🟡 中等）
- **原因**：`useRecords.ts` 中 `fetchFeedback` 是异步函数，在 `createRecord` 中以 fire-and-forget 方式调用，没有 `.catch()` 处理
- **后果**：当组件在异步操作完成前卸载（如用户快速跳过引导），状态更新可能触发 React 渲染错误
- **触发路径**：`createRecord` → `fetchFeedback` (unhandled promise rejection) → 组件卸载后 setState → 渲染崩溃

### 3. OnboardingFlow 缺少独立错误边界（🔴 严重）
- **原因**：`OnboardingFlow` 组件直接被全局 `ErrorBoundary` 包裹，没有自己的错误边界
- **后果**：引导流程中任何渲染错误都会冒泡到全局 ErrorBoundary，导致整个应用崩溃到《出了点小问题》页面
- **影响**：用户无法从错误中恢复引导流程，只能重新加载页面

### 4. 全局 ErrorBoundary 恢复机制不足（🟡 中等）
- **原因**：全局 `ErrorBoundary` 只提供 `window.location.reload()` 恢复选项
- **后果**：页面刷新会重置所有状态（包括 onboarding 进度），用户可能反复遇到同样的错误

## 修复方案

### 修复1：新手引导创建记录时跳过庆祝效果
**文件**：`src/app/page.tsx`

```typescript
// 修复前
const result = await createRecord({
  content,
  type: 'success',
  mood: 'proud',
  tags: [],
});

// 修复后
const result = await createRecord(
  {
    content,
    type: 'success',
    mood: 'proud',
    tags: [],
  },
  { skipCelebration: true }
);
```

### 修复2：为 OnboardingFlow 添加独立错误边界
**文件**：`src/app/components/OnboardingFlow.tsx`

新增 `OnboardingErrorBoundary` 类组件：
- 捕获引导流程内的渲染错误
- 提供"重试"按钮（重置错误状态，重新渲染子组件）
- 提供"跳过引导"按钮（调用 `onSkip` 回调，直接完成引导）
- 错误界面保持与 OnboardingFlow 一致的视觉风格（半透明背景 + 白色卡片）

### 修复3：改进全局 ErrorBoundary 添加恢复机制
**文件**：`src/app/components/ErrorBoundary.tsx`

- 新增 `errorKey` 状态，重试时递增 key 强制子组件重新挂载
- 新增 `handleRetry` 方法替代 `window.location.reload()`
- 显示错误信息（`error.message`）帮助调试
- "重新加载"改为"重试"（不刷新页面，保留用户状态）

### 修复4：useRecords 中 fetchFeedback 添加错误保护
**文件**：`src/hooks/useRecords.ts`

- `fetchFeedback` 添加 `data` 空值检查：`if (!data || typeof data !== 'object') return`
- `createRecord` 中 `fetchFeedback` 调用添加 `.catch()` 防止未捕获的 Promise 拒绝

### 修复5：page.tsx 中 onboarding 状态管理加固
**文件**：`src/app/page.tsx`

- `handleOnboardingComplete` 移除不必要的 try-catch 包裹 `setShowOnboarding`
- 仅在 localStorage 操作时使用 try-catch
