# 雪球形象融入卡片弹窗与空状态 - 设计文档

> 日期: 2026-05-13
> 状态: 已批准

## 1. 背景与目标

当前卡片弹窗（雪球问你、挑战卡片、完成任务弹窗）和空状态（任务页4种视图、首页侧边栏、记录页）缺少雪球形象，与首页雪球卡片脱节。本次重构将雪球形象融入这些场景，实现：

- 雪球形象与首页雪球卡片阶段同步
- 故事化文案增强用户与雪球的互动感
- 统一视觉语言，强化"雪球陪伴成长"的产品定位

## 2. 设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 方案 | 共享组件 + 文案配置表 | 雪球形象自动跟随阶段变化，零维护成本 |
| 雪球角色 | 第一人称（"我"说话） | 增强陪伴感和互动感 |
| 雪球尺寸 | 大尺寸主视觉式（120-160px） | 视觉冲击力强，雪球作为卡片主角 |
| 文案风格 | 可爱撒娇风 | 符合产品温暖可爱的调性 |
| 挑战卡片 | 保留原布局+雪球替换图标+底部鼓励文案 | 平衡功能信息与雪球元素 |
| 动画程度 | 简单动画（浮动+微旋转） | 资源有限，CSS/framer-motion 即可实现 |

## 3. 技术架构

### 3.1 SnowballCharacter 共享组件

```
src/app/components/SnowballCharacter.tsx
```

**Props**:
```typescript
interface SnowballCharacterProps {
  size: 'sm' | 'md' | 'lg';
  mood?: 'happy' | 'sleepy' | 'excited'; // 预留，暂不实现动画差异
  className?: string;
}
```

**行为**:
- 从 `useSnowball()` 读取当前 `stage`
- 复用 `STAGE_IMAGES` 配置映射图片路径（与 SnowballStageCard 一致）
- framer-motion 动画: `y=[0,-6,0]` 浮动 + `rotate=[0,3,-3,0]` 微旋转
- 尺寸映射: `sm=48px`, `md=120px`, `lg=160px`
- 自带光晕效果（`blur-xl` 渣光，与 SnowballStageCard 一致）

### 3.2 SNOWBALL_STORY_TEXT 文案配置表

```
src/lib/snowball-story-text.ts
```

**结构**:
```typescript
type StoryScene = 'dailyQuestion' | 'celebration' | 'challengeJoin' | 'challengeComplete'
  | 'taskEmptyGoal' | 'taskEmptyList' | 'taskEmptyKanban' | 'taskEmptyQuadrant'
  | 'sidebarBigTaskEmpty' | 'sidebarTodoEmpty' | 'sidebarTodoAllDone'
  | 'recordEmpty';

interface StoryText {
  main: string;   // 主文案（加粗显示）
  sub: string;    // 副文案（灰色小字）
}

// 按场景 × 阶段矩阵
const SNOWBALL_STORY_TEXT: Record<StoryScene, Record<SnowballStage, StoryText>>
```

**辅助函数**:
```typescript
function getStoryText(scene: StoryScene, stage: SnowballStage): StoryText
```
