# API 问题修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复项目中 5 类 API 层问题——Goals 残留清理、任务 API 语义统一、挑战奖励与分数制同步、追问判断改用结构化字段、成就定义统一

**Architecture:** 逐项修复，每项独立可测试。先清理废弃代码（Goals），再修复语义问题（PUT→PATCH），然后统一数据模型（挑战奖励、追问判断、成就定义），最后运行全量测试确认无回归。

**Tech Stack:** Next.js 16 (App Router), TypeScript, Vitest
