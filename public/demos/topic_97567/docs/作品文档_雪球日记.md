## 二、作品信息

**作品名称：** 雪球日记 — 微成功记录助手

**作品简介：**

「雪球日记」是一款以"微成功"为核心的 AI 日记应用，灵感来源于"雪球效应"——每一个微小的进步都像滚雪球一样，越滚越大。用户通过记录生活中的小成功、小确幸，在 AI 的温暖引导下养成积极记录的习惯，见证自己每一天的成长轨迹。

**核心创意：**

1. **微成功理论 + 游戏化成长**：将"小成功记录"与雪球成长可视化结合，每一笔记录都推动雪球变大
2. **AI 智能引导（雪球问你）**：根据时间、用户记录内容，AI 自动生成个性化引导问题，帮助用户发现日常中被忽略的微小成就
3. **挑战体系（铜/银/金）**：三级难度挑战系统，通过完成每日记录逐步解锁里程碑，让记录习惯养成更有成就感

**解决的问题：**

帮助"想做记录但坚持不下来"的人群，用最低的门槛、最温暖的方式，建立起积极记录的习惯，让每一份微小进步都被看见和积累。

## 三、需求分析

**需求痛点：**

在快节奏的现代生活中，人们往往只关注"大目标"和"高成就"，忽略了日常生活中有价值的微小进步。这种认知偏差导致：

- 容易陷入自我否定，忽视自己的成长
- 缺乏持续记录的动力，传统日记门槛太高
- 没有有效的反馈机制，难以形成正向循环
- 缺少个性化引导，不知道记录什么

**目标人群：**

- 想要培养积极记录习惯但坚持不下来的年轻人
- 关注自我成长、希望看到自己进步轨迹的用户
- 喜欢游戏化互动体验的日记初学者
- 需要情绪支持和正向引导的群体

**解决思路：**

- **降低记录门槛**：允许用户随手记录任何微小的成功，哪怕只是一句"今天喝到了一杯好喝的咖啡"也值得记录
- **AI 智能引导**：通过"雪球问你"功能，AI 根据时间和用户行为主动推送个性化问题，帮助用户发现生活中的闪光点
- **游戏化激励**：雪球成长可视化 + 等级挑战 + 成就系统，让记录本身变成一种有趣的成长体验

## 四、功能介绍

### 1. 小成功快速记录

首页提供快速记录入口，用户只需输入一小段文字即可完成记录。系统自动打标签，支持情绪标记（开心、平静、兴奋等），让每一条记录都丰富而有温度。每日首次记录会有特殊庆祝效果。

### 2. 雪球问你（AI 引导提问）

基于智谱 GLM-4-Flash 模型的 AI 提问引擎。根据时间段（早/中/晚）和用户行为自动生成个性化问题。

例如：
- 早晨问："今天有什么小事是你想做的？"
- 中午问："上午有没有哪个瞬间让你觉得还不错？"
- 晚上问："今天最让你惊喜的一件小事是什么？"

用户回答问题后会自动生成记录。同时提供追问功能，深入挖掘用户故事。

### 3. 任务管理系统

支持四种任务类型：

| 任务类型 | 说明 | 完成加分 |
|---------|------|---------|
| 快速任务 | 随手想做的事 | +2 分 |
| 普通任务 | 日常待办事项 | +5 分 |
| 长任务 | 需要拆解的大目标，支持 AI 自动拆分为子任务 | +10 分 |
| 习惯打卡 | 每日习惯追踪，支持连续天数统计 | +5 分 |

提供**列表、看板、四象限**三种视图模式，支持目标和截止日期管理。

### 4. 挑战体系

三级挑战难度：

- **青铜挑战**：每日随机主题，如"感恩瞬间""学习收获"等
- **白银挑战**：7-21 天主题挑战，如"坚持记录""运动打卡"等，含里程碑奖励
- **黄金挑战**：高难度长期挑战，如"21 天突破舒适圈"，完成后获得特殊奖励

每日完成挑战记录即可积累进度，里程碑和完成时触发庆祝效果。

### 5. 雪球成长可视化

积分系统驱动雪球成长：

| 阶段 | 分数区间 | 雪球大小 |
|------|---------|---------|
| 雪粒 | 0-49 分 | 小 |
| 小雪球 | 50-199 分 | 中 |
| 雪球 | 200+ 分 | 大 |

每次加分都有雪球放大动画和粒子特效，让成长看得见。首页雪球角色可交互点击，不同阶段有不同对话文本。

### 6. AI 智能反馈与对话

记录完成后，AI 自动生成个性化反馈（温暖鼓励或建设性追问）。支持连续对话，用户可以在记录的基础上与 AI 深入交流。对话历史保存，形成完整的思考脉络。

### 7. 成就系统

内置 20+ 成就徽章，覆盖记录、任务、挑战、交互等多个维度。成就分为 micro / minor / growth / major / transformation 五个等级。解锁成就时有特殊庆祝效果和成就消息。

### 8. 数据分析与回顾

提供成长时间线、情绪趋势分析、记录频率统计等可视化数据。用户可以在回顾页面看到自己的成长轨迹和变化趋势。

## 五、技术架构

**技术栈：**

| 类别 | 技术选型 |
|------|---------|
| 前端框架 | Next.js 16 (App Router) + React 19 |
| 编程语言 | TypeScript |
| 动画引擎 | Framer Motion |
| 数据可视化 | Recharts |
| AI 模型 | 智谱 GLM-4-Flash |
| 数据存储 | 本地 JSON 文件系统 |
| 开发工具 | Trae AI 编程助手 |

**项目结构：**

采用 Next.js 16 App Router 架构，API 路由与服务端逻辑分离。`local-db.ts` 作为本地数据层，`score-engine.ts` 处理积分事件。前端使用 Context + Hook 模式管理状态，组件按功能模块划分。

**核心数据流：**

```
用户操作 → API 路由 → local-db 数据层 → 响应返回 → 前端状态更新
```

加分系统设计为**纯事件驱动模式**：所有加分操作统一写入 `score_events` 表，总分由事件累加计算，避免多源数据不一致问题。

**测试覆盖：**

25 个测试文件，612 个测试用例，全部通过。
