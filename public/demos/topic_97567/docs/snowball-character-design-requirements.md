# 雪球角色设计需求文档

## 📋 项目概述

**项目名称**：雪球日记 - 拟人化角色设计
**设计目标**：为5个成长阶段设计拟人化角色，体现用户成长旅程
**应用场景**：移动端/桌面端 Web 应用主界面

---

## 🎯 核心设计理念

### 设计原则

1. **有生命的角色**
   - 不是简单的图形或圆形
   - 有表情、有性格、有灵魂
   - 让用户感受到陪伴感

2. **成长可视化**
   - 5个阶段要有明显的成长感
   - 形象变化体现用户进步
   - 每个阶段都有独特的魅力

3. **情感连接**
   - 温馨治愈的风格
   - 让用户想每天来看看它
   - 建立情感纽带

### 设计风格

**参考方向**（仅供参考，设计师可自由发挥）：
- 蜜雪冰城雪王 - 简洁可爱的拟人化
- Line Friends - 温馨治愈的角色设计
- QQ企鹅 - 有性格的吉祥物设计

**风格关键词**：
- 可爱、温暖、亲切
- 有个性、有生命力
- 适合长期陪伴

---

## 📐 5个成长阶段

### 阶段划分

| 阶段 | 记录数 | 尺寸范围 | 成长感 |
|------|--------|----------|--------|
| 阶段1 | 0-3条 | 40-60px | 初生/萌芽 |
| 阶段2 | 4-10条 | 80-100px | 成长初期 |
| 阶段3 | 11-25条 | 140-160px | 成长中期 |
| 阶段4 | 26-50条 | 200-220px | 成熟期 |
| 阶段5 | 51+条 | 260-280px | 完整形态 |

### 设计要求

**核心要求**：
- ✅ 5个阶段要有明显的视觉差异和成长感
- ✅ 每个阶段都要有独特的魅力和个性
- ✅ 整体风格统一，但各阶段有辨识度
- ✅ 适合 Web 端展示（考虑性能和可扩展性）

**设计师自由发挥**：
- 🎨 角色形态完全自由设计（可以是雪球、雪人、精灵、动物等任何形态）
- 🎨 表情、装饰、细节完全自由发挥
- 🎨 成长方式自由定义（可以是变大、变复杂、获得装饰物等）
- 🎨 欢迎提供多个设计方案

## 🎬 动画设计要求

### 必需动画

#### 1. 基础动画（所有阶段）
- **呼吸/脉动感**：体现生命力
- **轻微移动**：让角色"活"起来
- **表情动画**：眨眼、微笑等

#### 2. 交互动画（所有阶段）
- **单击互动**：对用户点击做出反应
- **双击互动**：另一种互动反馈
- **特殊效果**：粒子、光效等（可选）

#### 3. 阶段特色动画
- 每个阶段至少有1-2个独特的动画效果
- 体现该阶段的性格和特征

### 动画参数规范

```javascript
// 动画参数示例
{
  type: 'scale | rotate | translate | opacity',
  from: 1.0,
  to: 1.05,
  duration: 3000, // 毫秒
  easing: 'easeInOut | linear | easeIn | easeOut',
  repeat: 'infinity | number',
  repeatDelay: 2000 // 毫秒
}
```

## 💻 技术规范

### 当前技术栈

- **前端框架**：React 19.2.4
- **动画库**：Framer Motion 12.38.0
- **样式方案**：CSS-in-JS（内联样式）+ Tailwind CSS
- **图形格式**：SVG / CSS 渐变 / Lottie

### 实现方式

#### 方式1：SVG + CSS/Framer Motion（推荐）
- 使用 SVG 绘制角色
- 使用 CSS 动画或 Framer Motion 实现动画
- **优点**：体积小、可缩放、易维护、性能好

#### 方式2：Lottie 动画
- 使用 After Effects 制作动画
- 导出为 Lottie JSON 格式
- 使用 `lottie-react` 库播放
- **优点**：动画效果丰富、设计师可控

#### 方式3：混合方式
- 静态部分使用 SVG
- 复杂动画使用 Lottie
- **优点**：兼顾性能和效果

### 技术限制

**支持**：
- ✅ SVG 矢量图
- ✅ CSS 动画
- ✅ Framer Motion 动画
- ✅ Lottie JSON 动画
- ✅ Canvas（如需要）

**不支持**：
- ❌ Flash
- ❌ GIF（体积大、不可控）
- ❌ 视频（性能差）

### 性能要求

- 单个 SVG 文件 < 50KB（优化后）
- 单个 Lottie 文件 < 100KB
- 动画帧率 ≥ 30fps
- 首次加载时间 < 1秒
