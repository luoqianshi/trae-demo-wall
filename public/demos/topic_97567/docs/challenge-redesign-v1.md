# 🎮 挑战模块重构设计方案

## 📋 设计背景与问题诊断

### 当前问题
1. **定位模糊**："参加挑战" → "去记录" → 完成，本质就是让用户多走一步去记录小成功
2. **缺乏挑战感**：每日挑战 duration_days=1，记录一次就完成 (0/1)，没有难度门槛
3. **与产品定位冲突**：雪球日记核心理念是"积累正向思维"，但当前挑战只是简单记录

### 重构目标
将挑战模块打造成**游戏化成长系统**，通过**多级递进难度 + 混合完成模式**，让用户真正感受到挑战的成就感和成长价值。

---

## 🎯 核心设计理念

### 定位：游戏化成长型挑战系统
- **不是简单的"记录任务"**，而是有明确目标、难度梯度、奖励机制的**成长路径**
- 类似游戏的**任务系统/成就系统**，用户通过完成挑战获得成就感和雪球奖励
- 挑战应该让用户感到"我做到了！"而不是"我又记了一次"

### 难度设计：三级递进（类似游戏关卡）

| 等级 | 名称 | 难度标识 | 完成时间 | 奖励倍率 |
|------|------|----------|----------|----------|
| ⭐ **青铜** | 入门挑战 | 1-2步 | 1天 | 1x |
| 💎 **白银** | 进阶挑战 | 3-5步 | 3-7天 | 2x |
| 👑 **黄金** | 大师挑战 | 6+步 / 特殊条件 | 7-21天 | 3x |

### 完成方式：混合模式

| 难度等级 | 完成方式 | 示例 |
|----------|----------|------|
| **青铜（入门）** | ✍️ 增强版记录 | 记录时需满足条件：最少50字、包含特定关键词、选择情绪标签 |
| **白银（进阶）** | 📝 记录 + 额外条件 | 完成特定主题记录 + 回答引导性问题 + 上传照片/音频 |
| **黄金（大师）** | 🎯 行动任务 + 记录反思 | 先完成实际行动 → 再记录感受和收获（行动是前置条件） |

## 🏆 挑战类型体系

### 1️⃣ 青铜挑战 - 入门级（每日可接）

**特点**：
- 当天完成，门槛低但有要求
- 目标：培养用户"有意识地记录"习惯
- 不是简单记录，而是**有质量的记录**

#### 示例挑战库（轮换展示）：

```
🌟 今日青铜挑战：【深度记录】微笑时刻
├─ 要求：记录一件让你微笑的事
├─ 条件：
│   ✅ 必须包含至少1个情绪标签（😊开心、😄欣慰、🥰感动...）
│   ✅ 必须回答引导问题："这件事为什么让你微笑？"
├─ 奖励：雪球 +5 + 徽章碎片 x1
└─ 时限：今日23:59前完成

🌟 今日青铜挑战：【感恩练习】感谢一个人
├─ 要求：记录一个你想感谢的人
├─ 条件：
│   ✅ 写出具体事件（他/她做了什么）
│   ✅ 写出你的真实感受
├─ 奖励：雪球 +5 + 徽章碎片 x1
└─ 时限：今日23:59前完成

🌟 今日青铜挑战：【学习复盘】新知收获
├─ 要求：记录今天学到的新东西
├─ 条件：
│   ✅ 标注来源（书籍/视频/他人/实践）
│   ✅ 写出一个应用场景
├─ 奖励：雪球 +5 + 徽章碎片 x1
└─ 时限：今日23:59前完成
```

**用户体验流程**：
1. 看到挑战卡片 → 了解要求和奖励
2. 点击"接受挑战" → 进入专用记录界面（带条件检查）
3. 满足所有条件后提交 → 自动验证 → 完成挑战
4. 获得即时反馈：动画效果 + 雪球增加 + 徽章碎片

---

### 2️⃣ 白银挑战 - 进阶级（每周可接）

**特点**：
- 需要3-7天持续完成
- 有明确的阶段性目标
- 结合记录 + 反思 + 分享元素

#### 示例挑战库：

```
💎 本周白银挑战：【7天正向日记】养成计划
├─ 目标：连续7天，每天记录一件积极的事
├─ 每日要求：
│   Day 1-3：记录一件小事
│   Day 4-5：记录并分析积极影响
│   Day 6-7：记录 + 写下本周感悟
├─ 额外条件：
│   ✅ 每天必须在22:00前完成
│   ✅ 至少3天需要上传配图
│   ✅ 第7天需要写总结反思
├─ 奖励：雪球 +20 + 白银徽章「坚持者」
└─ 失败惩罚：中断则重新开始（鼓励但不强制）

💎 本周白银挑战：【健康追踪】运动打卡
├─ 目标：7天内完成5次运动相关记录
├─ 每次要求：
│   记录运动内容（跑步/瑜伽/健身...）
│   记录时长（≥20分钟算有效）
│   记录运动后感受
│   （可选）上传运动截图/照片
├─ 奖励：雪球 +15 + 白银徽章「活力达人」
└─ 特殊机制：可补卡（最多补2次，需详细记录）

💎 本周白银挑战：【社交连接】善意行动
├─ 目标：7天内完成3次帮助他人的行动
├─ 每次要求：
│   记录你做的事情
│   记录对方的反应
│   记录你的感受
│   反思：这个行动对你有什么改变？
├─ 奖励：雪球 +25 + 白银徽章「温暖传递者」
└─ 特殊机制：行动优先（必须先做再记录）
```

**用户体验流程**：
1. 周初看到白银挑战 → 了解7天计划和总奖励
2. 点击"开始挑战" → 进入挑战仪表盘
3. 每天看到当日子任务 → 完成后打勾
4. 进度条实时更新（0/7 → 7/7）
5. 全部完成后触发庆祝动画 + 颁发徽章

### 3️⃣ 黄金挑战 - 大师级（每月/特殊时机）

**特点**：
- 高难度，需要持续21天以上或完成特殊行动
- 有明确的"行动前置"要求
- 奖励丰厚，含稀有徽章和特殊权限

#### 示例挑战库：

```
👑 21天黄金挑战：【习惯养成】早起勇士
├─ 目标：连续21天在7:00前起床并记录
├─ 行动前置（必须先做到）：
│   ✅ 每天7:00前在APP内打卡（拍照/定位验证可选）
│   ✅ 起床后10分钟内完成晨间记录
├─ 记录要求：
│   记录起床时间
│   记录晨间计划（今天要完成的3件事）
│   记录起床时的状态和心情
│   （每周日）写周总结：这周早起带来了什么变化？
├─ 阶段性里程碑：
│   ✓ 第3天：解锁称号「早起新手」+ 雪球+10
│   ✓ 第7天：解锁称号「一周达人」+ 雪球+20
│   ✓ 第14天：解锁称号「半月战士」+ 雪球+30
│   ✓ 第21天：完成挑战！获得黄金徽章「晨光勇士」+ 雪球+50
├─ 特殊机制：
│   允许2次补签（需完成额外任务：写周反思）
│   中断3次以上则挑战失败（可重新开始）
└─ 终极奖励：解锁专属头像框 + 雪球皮肤「晨光」

👑 30天黄金挑战：【感恩日记】心灵修行
├─ 目标：连续30天，每天记录3件值得感恩的事
├─ 行动前置：
│   ✅ 不能重复（30天内不能写相同的事情）
│   ✅ 每件事必须来自不同类别（人/事/物/自己/自然...）
├─ 记录要求：
│   每件感恩之事
│   必须写出"为什么感恩"
│   必须写出"如果这件事没发生会怎样"
│   （每周末）写感恩总结：这周的感恩清单给你的启示
├─ 阶段性奖励：
│   ✓ 第7天：「感恩萌芽」+ 雪球+15
│   ✓ 第14天：「感恩生长」+ 雪球+25
│   ✓ 第21天：「感恩绽放」+ 雪球+35
│   ✓ 第30天：黄金徽章「感恩大师」+ 雪球+60 + 专属背景音乐
└─ 特殊意义：完成后解锁"感恩模式"（可在普通记录中添加感恩标签）

👑 特殊黄金挑战：【突破舒适圈】行动派
├─ 目标：21天内完成7个"第一次"
├─ 行动前置（真正的行动！）：
│   第一次主动和陌生人说话
│   第一次在公众场合发言/表演
│   第一次尝试完全陌生的技能
│   第一次对别人说"不"
│   第一次独自去一个陌生的地方
│   第一次分享自己的脆弱/失败经历
│   第一次帮助一个你不认识的人
├─ 记录要求（行动后24小时内）：
│   详细记录行动过程（发生了什么）
│   记录行动前的恐惧/犹豫
│   记录行动后的感受和发现
│   反思：这次行动教会了你什么？
├─ 奖励：
│   每个"第一次"完成：雪球+8
│   完成4个：白银徽章「勇敢者」
│   完成7个：黄金徽章「破茧成蝶」+ 雪球+100 + 解锁"勇气日记"模板
└─ 特殊机制：可自定义"第一次"列表（需审核合理性）
```

**用户体验流程**：
1. 看到黄金挑战介绍 → 了解高难度和高回报
2. 点击"接受挑战" → 签署"挑战承诺书"（仪式感）
3. 进入长期挑战仪表盘 → 日历视图显示进度
4. 每天完成行动和记录 → 打勾标记
5. 达成里程碑 → 弹窗庆祝 + 即时奖励
6. 最终完成 → 盛大庆祝动画 + 稀有徽章 + 特殊权益

## 🎨 游戏化元素设计

### 1. 奖励体系

#### 🪨 雪球奖励（基础货币）
| 挑战类型 | 基础奖励 | 连续奖励加成 |
|----------|----------|--------------|
| 青铜（每日） | +5 | 连续3天 +50%，连续7天 +100% |
| 白银（每周） | +15~25 | 提前完成 +20% |
| 黄金（月度） | +50~100 | 一次性完成无中断 +50% |

#### 🏅 徽章系统（成就证明）
- **青铜徽章**：完成10个青铜挑战 → 解锁「记录达人」
- **白银徽章**：完成3个白银挑战 → 解锁「坚持之星」
- **黄金徽章**：完成1个黄金挑战 → 解锁「成长大师」
- **传奇徽章**：收集全套同级别徽章 → 解锁特殊称号

#### 💎 徽章碎片（收集要素）
- 每次完成青铜挑战获得1个碎片
- 收集9个碎片可合成1个随机白银徽章
- 增加收集乐趣和期待感

#### 🎁 特殊奖励（稀缺性）
- **专属外观**：头像框、雪球皮肤、背景主题
- **特殊功能**：解锁新记录模板、AI对话特权、数据导出
- **社交展示**：主页展示墙、排行榜位、荣誉证书

## 🛠 技术实现要点

### 数据模型重构

```typescript
// 挑战定义表 challenges
interface Challenge {
  id: string;
  
  // 基本信息
  title: string;
  description: string;
  type: 'bronze' | 'silver' | 'gold';  // 改为难度等级
  category: string;  // emotion/health/social/growth/custom
  
  // 难度和时限
  difficulty: 1 | 2 | 3;  // 1=青铜, 2=白银, 3=黄金
  duration_days: number;  // 1/7/21/30
  is_recurring: boolean;  // 是否循环（青铜每日刷新）
  
  // 完成条件（JSON）
  completion_criteria: {
    record_required: boolean;
    required_tags?: string[];
    required_questions?: string[];
    action_required?: boolean;  // 黄金挑战需要实际动作
    action_description?: string;
    milestones?: Array<{ day: number; reward: any }>;
  };
  
  // 奖励配置
  rewards: {
    snowball_base: number;
    snowball_bonus?: number;  // 连续/提前完成加成
    badge_id?: string;
    badge_fragments?: number;
    special_rewards?: Array<{ type: string; value: any }>;
  };
  
  // 元数据
  is_active: boolean;
  display_order: number;
  created_at: string;
}

// 用户挑战进度 user_challenges
interface UserChallenge {
  id: string;
  user_id: string;
  challenge_id: string;
  
  // 状态追踪
  status: 'pending' | 'active' | 'completed' | 'failed' | 'abandoned';
  progress: number;  // 当前进度（天/步）
  current_day: number;  // 当前第几天（用于多天挑战）
  streak_days: number;  // 连续完成天数
  
  // 时间戳
  started_at: string;
  completed_at: string | null;
  last_progress_at: string;
  
  // 补签机制
  make_up_count: number;  // 已使用补签次数
  max_make_ups: number;  // 最大允许补签次数
  
  // 关联数据
  challenge?: Challenge;
  daily_records?: Array<{  // 每日完成记录
    date: string;
    completed: boolean;
    record_id?: string;
    completed_at?: string;
  }>;
}
```
