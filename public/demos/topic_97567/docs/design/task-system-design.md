## 一、核心概念

### 1.1 任务分类体系

| 类型 | 定义 | 显示位置 | 属性 |
|-----|------|---------|------|
| **快速任务** | 纯文本待办，无属性 | ⚡ 快速任务栏目 | 仅标题 |
| **普通任务** | 有重要性、截止时间的独立任务 | 📋 普通任务栏目 | 标题、描述、重要性、截止时间、紧急度 |
| **长任务** | 可分解的长期目标，含子任务 | 🎯 长任务栏目 | 标题、描述、重要性、截止时间、子任务、子任务紧急度阈值 |
| **习惯** | 每日/每周重复的小习惯 | 🔄 习惯栏目 | 名称、描述、频率、目标次数、提醒时间、连续天数 |

### 1.2 关键理解

- **长任务 = 目标本身**：长任务就是目标，不需要关联到 goals 表
- **子任务 = 普通任务**：子任务本质上是 `type='normal'` 的任务，只是有 `parent_id` 指向父任务
- **快速任务无属性**：不设置重要性、紧急度，也不显示在四象限中
- **紧急度自动计算**：基于截止时间和阈值配置自动计算，用户不直接设置

### 3.2 视图切换按钮

```
[目标视图] [列表] [看板] [📊 四象限]
```

- **目标视图**：按栏目分组显示（长任务/习惯/快速任务/普通任务）
- **列表**：所有任务平铺显示
- **看板**：按状态分三列（待完成/进行中/已完成）
- **📊 四象限**：全局四象限分布图

### 3.3 四象限视图按钮位置

| 位置 | 按钮 | 功能 |
|-----|------|------|
| 页面右上角 | [📊 全局四象限] | 查看所有任务的四象限分布 |
| 每个长任务右侧 | [📊] | 查看该长任务子任务的四象限分布 |
| 普通任务栏目标题右侧 | [📊 四象限视图] | 查看所有普通任务的四象限分布 |

### 3.4 四象限分布方向

```
                    紧急
                      │
    ┌─────────────────┼─────────────────┐
    │                 │                 │
    │    📅 计划做    │    🔥 立即做    │
    │  (重要+不紧急)  │   (重要+紧急)   │
    │                 │                 │
  重要 ───────────────┼─────────────── 不重要
    │                 │                 │
    │    🗑️ 删除      │    📋 委托      │
    │ (不重要+不紧急) │ (不重要+紧急)   │
    │                 │                 │
    └─────────────────┼─────────────────┘
                      │
                   不紧急
```

## 六、数据模型

### 6.1 Task 模型

```typescript
interface Task {
  id: string;
  title: string;
  description?: string;
  type: 'quick' | 'normal' | 'big' | 'habit';
  
  // 状态
  status: 'pending' | 'in_progress' | 'completed';
  
  // 优先级（普通任务/长任务/子任务）
  importance?: 1 | 2 | 3 | 4 | 5;  // 1=极低, 5=极高
  
  // 紧急度（自动计算）
  due_date?: string;           // ISO格式
  urgency?: 'critical' | 'high' | 'medium' | 'low' | 'none';
  quadrant?: 1 | 2 | 3 | 4;    // 四象限位置
  
  // 长任务特有
  parent_id?: string;          // 子任务指向父任务
  progress?: number;           // 0-100，基于子任务完成度
  total_subtasks?: number;
  completed_subtasks?: number;
  thresholds?: {               // 子任务紧急度阈值
    critical: number;
    high: number;
    medium: number;
    low: number;
    none: number;
  };
  
  // 习惯特有
  frequency?: 'daily' | 'weekly' | 'custom';
  target_count?: number;       // 每周目标次数
  current_streak?: number;     // 当前连续天数
  best_streak?: number;        // 最佳连续天数
  reminder_time?: string;      // 提醒时间 HH:MM
  
  // 元数据
  created_at: string;
  updated_at: string;
  completed_at?: string;
}
```

### 6.2 紧急度计算逻辑

```typescript
function calculateUrgency(
  dueDate: string, 
  thresholds: Thresholds
): 'critical' | 'high' | 'medium' | 'low' | 'none' {
  const daysUntilDue = Math.ceil(
    (new Date(dueDate).getTime() - Date.now()) / (1000 * 60 * 60 * 24)
  );
  
  if (daysUntilDue <= thresholds.critical) return 'critical';  // 🔥
  if (daysUntilDue <= thresholds.high) return 'high';          // ⚡
  if (daysUntilDue <= thresholds.medium) return 'medium';      // 📅
  if (daysUntilDue <= thresholds.low) return 'low';            // ⏰
  return 'none';                                               // 🗓️
}

function calculateQuadrant(
  importance: number, 
  urgency: string
): 1 | 2 | 3 | 4 {
  const isImportant = importance >= 4;  // 4或5分为重要
  
  const urgencyLevel = {
    'critical': 4, 'high': 3, 'medium': 2, 'low': 1, 'none': 0
  }[urgency];
  
  const isUrgent = urgencyLevel >= 3;   // critical或high为紧急
  
  if (isImportant && isUrgent) return 1;      // 🔥 立即做
  if (isImportant && !isUrgent) return 2;     // 📅 计划做
  if (!isImportant && isUrgent) return 3;     // 📋 委托
  return 4;                                    // 🗑️ 删除
}
```

## 七、开发注意事项

### 7.1 保持现有设计

- **任务卡片设计不变**：用户已表示对当前任务卡片设计满意
- **仅添加四象限视图按钮到视图切换**：`[目标视图] [列表] [看板] [📊 四象限]`
- **其他UI不做改动**

### 7.2 优先级

1. **P0**: 三步式创建流程、任务分类显示、四象限计算
2. **P1**: 子任务功能、阈值配置
3. **P2**: AI自动分解子任务

### 7.3 兼容性

- 现有任务数据需要迁移，添加 `type` 字段，默认值为 `normal`
- 现有 goals 表中的目标可以转换为 `type='big'` 的任务
