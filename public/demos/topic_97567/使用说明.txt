=====================================
  雪球日记 - 网页版源码
  Snowball Diary
=====================================

【运行前提】
  需要安装 Node.js（LTS 版本）
  下载地址: https://nodejs.org/

【启动方式】

  方式一：双击「一键启动.bat」
    - 自动检查 Node.js 环境
    - 自动安装依赖（首次运行需等待几分钟）
    - 自动启动服务器并打开浏览器

  方式二：命令行启动
    1. 打开命令行，进入本目录
    2. npm install      （首次运行）
    3. npm run dev      （启动开发服务器）
    4. 浏览器打开 http://localhost:3000

【使用说明】
  - 启动后会自动打开浏览器
  - 数据保存在 data/local-db.json
  - 关闭命令行窗口即停止应用

【AI 功能说明】
  AI 功能需要配置 API Key：
  创建 .env.local 文件，填入：
    ZHIPU_API_KEY=你的智谱API密钥
  未配置时 AI 功能使用本地模板，不影响其他功能

【技术栈】
  前端: Next.js 16 + React 19 + Tailwind CSS 4 + Framer Motion
  存储: 本地 JSON 文件（文件锁 + WAL + 事务）
  AI: 智谱 GLM-4-Flash + OpenAI fallback
  测试: Vitest（742+ 单元测试）
