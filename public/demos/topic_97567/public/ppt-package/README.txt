=====================================
  雪球日记 - 项目演示 PPT
  Snowball Diary Presentation
=====================================

【打开方式】
  双击 presentation-final.html 即可在浏览器中播放

【操作说明】
  - 键盘 → / ← ：翻页
  - 点击屏幕右侧/左侧：翻页
  - 触摸屏支持左右滑动
  - 底部圆点可点击跳转

【注意事项】
  需要联网（用于加载 Google 字体）
  推荐使用 Chrome / Edge 浏览器获得最佳效果
