# 评审厅

输入一个想法，AI 组建专家团帮你把想法推演成可落地方案。

## 启动方式

### Windows
双击 `启动服务.bat`，首次启动需 1-3 分钟自动安装依赖，浏览器会自动打开。

### Mac / Linux / 命令行
```
npm install
npm run dev
```
浏览器打开 http://localhost:5173

## 环境要求
- Node.js LTS（未安装会自动提示）：https://nodejs.org

## 首次使用
启动后在设置页配置你的 LLM API Key（支持 OpenAI 兼容接口）。

## 技术栈
React 18 + Vite + Tailwind CSS + Zustand
