📋 Gitee 码云 使用步骤（国内推荐）

  1. 访问 gitee.com 注册/登录账号
  2. 点击右上角头像 → "设置" → "私人令牌"
  3. 点击"生成新令牌"，勾选 projects 和 gists 权限，提交生成
  4. 复制生成的 Token（只显示一次，请保存好）
  5. 把 Token 粘贴到上方输入框，点击"🔗 没有片段？自动创建一个"会自动创建片段
  6. 点击下方"💾 保存配置"完成设置

💡 国内访问速度快，稳定可靠。所有设备使用相同的 片段 ID + Token 即可同步。

⚠️ Token 保存在本机 localStorage，仅发送给 gitee.com。请勿在公共电脑上配置。

📋 GitHub Gist 使用步骤

  1. 访问 GitHub Settings → Personal access tokens
  2. 点击"Generate new token (classic)"
  3. 勾选 repo 和 gist 权限，点击生成
  4. 复制生成的 Token（只显示一次，请保存好）
  5. 把 Token 粘贴到上方输入框，点击"🔗 没有 Gist？自动创建一个"会自动创建 Gist
  6. 点击下方"💾 保存配置"完成设置

💡 所有设备使用相同的 Gist ID + Token 即可同步。GitHub Gist 更稳定，几乎不限请求次数。

⚠️ Token 保存在本机 localStorage，仅发送给 GitHub。请勿在公共电脑上配置。
