## 1. Demo 简介

**是什么：** 一款基于浏览器的实时中国手语双向翻译网页应用，打开网页即可用摄像头识别手语手势，实时转换为文字和语音；也可以输入文字或语音，转化为手语动画演示。

**面向谁：**
- 听障人士与听人之间的日常沟通
- 手语学习者自学练习
- 公共服务窗口（医院、银行、政务大厅）的辅助沟通工具

**主要功能：**

| 功能 | 说明 |
|------|------|
| 手语→文字/语音 | 打开摄像头，实时识别手势，输出文字并朗读 |
| 语音/文字→手语动画 | 输入文字或语音，播放对应手语手势动画 |
| 100词中国手语库 | 覆盖数字、日常用语、情感、动作等高频词汇 |

## 2. Demo 创作思路

**灵感来源：**
一次在地铁站看到一位听障人士用手语向工作人员问路，但工作人员完全看不懂，双方都很焦急。这让我意识到，听障群体在公共场景中面临的沟通壁垒远比想象中普遍。虽然市面上有一些手语翻译 App，但大多依赖人工翻译，无法做到实时、随时可用。

**想解决的问题：**
1. **沟通效率低**：听人不懂手语，听障人士写字/打字速度慢，简单交流也要耗费大量时间
2. **学习门槛高**：普通人想学手语，但缺少即时的反馈和练习工具
3. **公共服务缺失**：医院、银行等场所很少有配备手语翻译人员

**为什么做这个方向：**
- 技术侧：MediaPipe Hands + TensorFlow.js 让浏览器端实时手势识别成为可能，不需要后端服务器，打开网页就能用
- 社会侧：中国有约 2700 万听障人士，手语是他们的母语。一款低成本、零门槛的翻译工具，能直接改善他们的日常沟通体验
- 取舍：没有追求"识别全部手语"的不切实际目标，而是聚焦高频100词，先做精、做可用，再逐步扩展

**Step 1：搭建 MediaPipe 手部检测**

![Step 1 截图](截图占位符4)

**Step 2：设计中国手语识别算法**
在 TRAE 中编写了完整的规则匹配识别引擎，包括：
- 手指伸直/弯曲状态检测（用指尖到手腕距离 vs MCP到手腕距离的比值）
- 食指方向判断（区分"一"、"我"、"你"）
- 掌心朝向判断（用 MediaPipe 的 Z 轴深度信息）
- 4指并拢程度计算（区分"四"和"五"的关键特征）
- 动态手势分析（15帧历史窗口检测移动方向）

![Step 2 截图](截图占位符5)

**Step 3：双向翻译功能实现**
完成手语→文字后，继续用 TRAE 实现了反向翻译：
- Web Speech API 语音识别和语音合成
- Canvas 手语动画绘制（根据词汇显示对应手势分解图）
- 历史记录和置信度显示

![Step 3 截图](截图占位符6)

**Step 4：持续迭代优化精度**
这是开发中耗时最多的环节。通过 TRAE 进行了多轮算法调优：
- 修复拇指伸直/弯曲的误判问题（改用"拇指尖到食指MCP距离"判断）
- 修复"四"被识别为"五"的问题（加入4指并拢间距判断）
- 修复动态手势被识别为数字的问题（动态时数字候选降权30分）
- 修复食指方向无法区分"一"和"我"的问题（加入Z轴"指向摄像头"检测）

### 关键代码片段

**手指状态检测（核心识别逻辑）：**
```javascript
_computeFingerStates(landmarks) {
    const states = [0, 0, 0, 0, 0];
    const wrist = landmarks[0];
    
    // 拇指伸直: 拇指尖到食指MCP距离 > 手掌宽度的 80%
    const thumbTipToIndexMcp = Math.hypot(
        thumbTip.x - indexMcp.x, thumbTip.y - indexMcp.y
    );
    const palmWidth = Math.hypot(
        landmarks[17].x - indexMcp.x, landmarks[17].y - indexMcp.y
    );
    states[0] = thumbTipToIndexMcp > palmWidth * 0.8 ? 1 : 0;
    
    // 食指~小指: tipDist / mcpDist > 1.25 = 伸直
    for (let i = 0; i < 4; i++) {
        const ratio = tipDist / mcpDist;
        states[i + 1] = ratio > 1.25 ? 1 : 0;
    }
    return states;
}
```

**"四"vs"五"区分逻辑：**
```javascript
// "四" = 4指并拢(spread<0.30), "五" = 5指全开(spread>0.40)
_computeFingerSpread(landmarks) {
    const tips = [8, 12, 16, 20];
    let totalGap = 0;
    for (let i = 0; i < tips.length - 1; i++) {
        totalGap += Math.hypot(
            landmarks[tips[i]].x - landmarks[tips[i+1]].x,
            landmarks[tips[i]].y - landmarks[tips[i+1]].y
        );
    }
    return (totalGap / 3) / palmWidth;  // 归一化到手掌宽度
}
```
