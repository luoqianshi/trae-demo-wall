# 唐朝风云 - 大唐王朝治理模拟游戏

## 📁 项目概述

一款基于Web的唐朝历史策略模拟游戏，玩家扮演大唐皇帝，治理国家、处理外交、指挥征战，体验唐朝兴衰历程。

## 🚀 快速开始

### 方式一：直接打开（推荐）

1. 用浏览器打开 `index.html` 文件
2. 或直接打开 `唐朝风云.html` 文件
3. 无需安装任何依赖，无需网络连接

### 方式二：使用本地服务器（可选）

```bash
# 使用Python启动本地服务器
python -m http.server 8080

# 使用Node.js启动本地服务器
npx serve

# 访问 http://localhost:8080
```

### 方式三：一键启动（Windows）

双击运行 `启动游戏.bat` 文件

## 🎮 游戏特色

- **交互式地图**：基于SVG的大唐疆域图，支持缩放、拖拽、城市标记
- **统一邦交系统**：整合外交与军事数据，实现宣战-出征联动
- **沙盘推演战斗**：阵型选择、军法配置、兵种搭配，回合制战斗
- **离线运行**：无需后端支持，本地模拟数据即可完整游戏

## 🖥️ 系统要求

- 操作系统：Windows / macOS / Linux
- 浏览器：Chrome 80+、Firefox 75+、Edge 80+
- 无需网络连接（支持离线模式）

## 📂 文件结构

```
唐朝历史游戏/
```

## ⚠️ 注意事项

1. 游戏首次加载可能需要10-15秒，请耐心等待
2. 如遇网络连接失败提示，游戏会自动切换到本地模式
3. 建议使用Chrome浏览器获得最佳体验
4. 文件较大（约900KB），打开时可能需要稍等
