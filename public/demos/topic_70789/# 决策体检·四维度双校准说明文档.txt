# 决策体检·四维度双校准说明文档


## 一、四维度总体框架

决策体检的核心机制是“双校准”——将同一决策的**外部环境评估**与**内在心理状态**放在同一框架下对比，识别差距最大的维度，定位决策卡点。

四个维度覆盖决策判断的四个核心环节：

| 维度 | 核心问题 | 评估对象 |
|---|---|---|
| **方向感** | 这条路的大势在往哪走？ | 行业趋势、政策方向、资本流向 |
| **确定性** | 这件事的“路况”我清楚吗？ | 信息充足度、参照案例、行业成熟度 |
| **时间感** | 现在是进入这件事的正确时机吗？ | 周期定位（康波/朱格拉/产业生命周期） |
| **代价感** | 如果错了，客观损失有多大？ | 入局成本、失败代价、退出成本 |


## 二、维度一：方向感

### 外部校准

**核心问题：** 这条路的大势在往哪走？

**评估对象：** 行业趋势、政策方向、资本流向

**评分依据（1-5分）：**
- **5分**：国家部委明确发文支持（2026年内）+ 行业处于上升周期 + 资本持续流入
- **4分**：有政策支持或行业明显上升，但缺少两者同时强支撑
- **3分**：行业不温不火，无明显政策信号或下行信号
- **2分**：行业处于下行周期，政策中性或偏紧
- **1分**：行业处于衰退期，政策限制明显，资本持续流出

### 内部校准

**对应心理变量：** 生活意义感（Sense of Life Meaning）+ 真我/真实性（Authentic Self）

**理论依据：**
- **生活意义感**（Frankl, 1946）：个体对人生目的和价值的感知。当人感觉“这条路值得走”时，本质上是在说“这条路与我的意义感连接”。
- **真我/真实性**（Wood et al., 2008）：个体按照自身价值观和信念生活的程度。方向感的核心问题是“这是我的方向还是别人的方向”，真我变量测量的正是决策背后的动机来源——自我导向还是他人导向。

**自评题目（活动专供版）：** “如果完全不需要向任何人解释你的选择，你仍然会走这条路吗？”

**1-5分说明：**

| 分数 | 描述 |
|---|---|
| **5** | 会。即使没有任何人知道或认可，我依然会选择走这条路 |
| **4** | 偏向会。虽然有点犹豫，但内心深处的方向是明确的 |
| **3** | 不确定。一部分想走，一部分觉得“可能不该走”，两边差不多 |
| **2** | 偏向不会。好像更多是“应该走”而非“想走” |
| **1** | 不会。这条路更像是别人期待的，我是在回应他们 |

**完整版对应量表：** MLQ（生命意义感问卷）+ Authenticity Scale（真实性量表）


## 三、维度二：确定性

### 外部校准

**核心问题：** 这件事的“路况”我清楚吗？

**评估对象：** 信息充足度、参照案例、行业成熟度

**评分依据（1-5分）：**
- **5分**：有大量公开可查的成功/失败案例 + 行业标准明确 + 信息高度透明
- **4分**：有较为充足的参照案例，行业模式基本清晰
- **3分**：有参照但行业尚无统一标准，处于“有参照但无定论”阶段
- **2分**：能找到少数案例，但缺乏系统性参照
- **1分**：几乎找不到参照案例，行业处于极早期或信息极度不透明

### 内部校准

**对应心理变量：** 自我效能感（Self-Efficacy）

**理论依据：**
- **自我效能感**（Bandura, 1977）：个体对自己能够完成某项任务的信念和信心。外部确定性再高，如果自我效能感低，人依然会犹豫不决。自我效能感是连接“外部信息”与“内在行动信心”的关键桥梁。

**自评题目（活动专供版）：** “关于实现这个目标的具体路径，你现在能清晰地看到几步？”

**1-5分说明：**

| 分数 | 描述 |
|---|---|
| **5** | 非常清晰。我知道第一步做什么、第二步做什么，也知道卡住时找谁 |
| **4** | 比较清晰。能看清大致路线和主要步骤，少数环节还不确定 |
| **3** | 部分清晰。知道大方向，但具体怎么走、需要什么资源还不明确 |
| **2** | 比较模糊。只有初步想法，但缺少具体路径和可执行的方案 |
| **1** | 非常模糊。几乎不知道怎么走到那里，也不确定从哪开始 |

**完整版对应量表：** GSES（一般自我效能感量表）


## 四、维度三：时间感

### 外部校准

**核心问题：** 现在是进入这件事的正确时机吗？

**评估对象：** 周期定位（康波/朱格拉/产业生命周期）

**评分依据（1-5分）：**
- **5分**：行业处于康波回升期/产业生命周期早期扩张阶段 + 政策窗口打开
- **4分**：周期位置明确有利，但尚未进入爆发期，属于“中等偏早”位置
- **3分**：行业处于过渡期，方向清晰但节奏不确定
- **2分**：行业处于下行周期或泡沫出清阶段
- **1分**：行业处于衰退期，或入场窗口已经关闭

### 内部校准

**对应心理变量：** 希望（Hope）

**理论依据：**
- **希望理论**（Snyder, 1994）：希望包含两个核心成分——路径思维（相信自己能找到路径）和代理思维（相信自己有能力持续行动）。时间感本质上是“对过程的管理能力”：路径思维决定你是否知道这条路要多久、怎么走；代理思维决定你能否坚持走完。

**自评题目（活动专供版）：** “如果这个选择在接下来一段不确定的时间里，都不会出现明确的进展信号，你还会继续走吗？”

**1-5分说明：**

| 分数 | 描述 |
|---|---|
| **5** | 一定会继续。即使没有进展信号，我相信它值得等待和持续投入 |
| **4** | 很可能继续。有坚持的意愿，但需要偶尔的小信号维持动力 |
| **3** | 不确定。取决于这段时间的长短和其他机会的出现情况 |
| **2** | 很可能放弃。我发现自己需要更及时的反馈和阶段性成果才能坚持 |
| **1** | 很可能放弃。我无法接受长时间没有进展或确认的情况 |

**完整版对应量表：** Hope Scale（希望量表）


## 五、维度四：代价感

### 外部校准

**核心问题：** 如果错了，客观损失有多大？

**评估对象：** 入局成本、失败代价、退出成本

**评分依据（1-5分）：**
- **5分**：入局成本极低 + 失败后可快速回归原轨道（≤3个月）+ 损失可逆
- **4分**：入局成本可控 + 失败后损失在可承受范围内 + 回归有一定成本但不致命
- **3分**：代价中等，失败后有较大损失但尚可承受
- **2分**：代价较大，失败后较难回归原轨道
- **1分**：代价极大且不可逆，失败后难以恢复

### 内部校准

**对应心理变量：** 心理韧性（Psychological Resilience）+ 自我同情（Self-Compassion）

**理论依据：**
- **心理韧性**（Masten, 2001）：个体在面对逆境、创伤、压力时成功适应和恢复的动态心理能力。决定“客观损失发生后，人能否撑住”。
- **自我同情**（Neff, 2003）：在困难、挫折、痛苦时以关怀和宽容对待自己，而非严厉批评。决定“失败后是自我摧毁还是自我支持”。

两者共同回答代价感的深层问题：“如果失败了，我承受得住吗？”——韧性提供“扛住”的能力，自我同情提供“不自我摧毁”的能力。

**自评题目（活动专供版）：** “如果这个选择最终没有达到你预期的结果，你更可能倾向于——1=反复回想‘我当初要是……就好了’并因此懊恼；5=尝试理解原因后寻找下一个方向”

**1-5分说明：**

| 分数 | 描述 |
|---|---|
| **5** | 主要倾向寻找下一个方向。会复盘原因，但不会长时间自我责备 |
| **4** | 有些懊恼，但能较快转向“接下来怎么办” |
| **3** | 两种倾向都有。会懊恼，也会尝试理解原因，来回拉扯 |
| **2** | 主要倾向反复回想和懊恼，较难主动转向下一步 |
| **1** | 完全倾向“反复回想‘我当初要是……就好了’”，感觉很难放过自己 |

**完整版对应量表：** CD-RISC（Connor-Davidson心理韧性量表）+ SCS（自我同情量表）


## 六、双校准的同步意义

当内外评分同步呈现时，四个维度可能出现以下几种“撕裂”模式，每种模式指向不同的决策卡点：

| 模式 | 含义 | 提示 |
|---|---|---|
| **外高内低** | 外部环境有利，但内在感受不对 | 某个“部分”在拉刹车——值得倾听，可能是在保护你，也可能是在用旧地图导航 |
| **内高外低** | 内在动力充足，但外部环境不明朗 | 可能有“盲目自信”的风险，需要补充外部信息再判断 |
| **内外一致（均高）** | 内外判断高度统一且积极 | 卡点不在此维度——可能是行动资源不足，或存在其他约束条件 |
| **内外一致（均低）** | 内外判断高度统一且消极 | 这个方向可能真的不对——不是“部分”在干扰，是真我在说不 |

**核心原则：** 差距本身不是问题，差距所在的位置才是需要关注的重点。差距越大，说明那个维度越值得深入观察。
