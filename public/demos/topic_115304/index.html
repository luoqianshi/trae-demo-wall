03使命 · 把"不可能"拆成"能搞定"

这件事拆开看，其实就是五道门。门一道道地开，不要慌。

字

① 文本怎么取

3718 句对白藏在 ROM 的哪个区段？控制码、压缩码、伪码表的边界在哪里？先要把它们一个一个"读"出来。

图

② 字形怎么补

原字库只有日文假名 + 汉字 + 符号，要塞进简体中文，必须在原字模基础上扩展出近 200 个常用汉字和符号的位图。

调

③ 控制码怎么转

换行、等待、清屏、闪烁、人名位、字体切换……每条控制码都要在汉化版里有对应翻译规则，逻辑不能丢。

战

④ 战斗 UI 怎么办

战斗界面的字距、行宽、字符宽度都是日文定制的。换成中文，字数会少一点，节奏会变，需要逐屏微调。

存

⑤ 存档能不能保留

用了官方存档的同胞，Mod 装上不能清档。我们要让 Mod 对原版存档"足够温柔"。

06前后对比 · 给"汉化"一个直观交代

选了一段游戏开场的对白，模拟一下汉化前后的样子。 译法偏直白、偏 80 后能一秒 get 的口吻——这是我们想要的味道。

Before · 原文

「きさま…、まだ生きていたのか。」
「２０年前、ここで負けた恨み、
　きっちり返させてもらうぜ！」

SRC: dialogue #0042 · 0x9C20–0x9C7F

After · 中文 Mod 草译

「你这家伙……居然还没死啊。」
「二十年前在这儿输给你的仇，
　　今天一笔一笔给你算清楚！」

MOD: zh-CN #0042 · 字数 −4 · 控制码 0 变化

更多翻译守则（节选）

  • 人名 沿用日文人名（首次出现附中文注音），不强行本地化——保留原作气质。
  • 敬语 / 粗口 保留语感差异，不为了"顺滑"磨平角色。
  • 战斗术语 用玩家圈通用译法；自造词全部标注原文。
  • 菜单 控制在 4 字以内，宁可删字不破坏节奏。

08意义 · 不只是"一个 Mod"

我反复想，做这件事到底有什么"大意义"？ 想来想去，答案其实挺朴素的：

老游戏是情怀，但情怀不是终点。
情怀是路标，提醒你当初为什么想上路。
一旦这条路走通，后面会有更多的人，沿着同样的脚印， 把他们童年里那些一闪而过的画面，也认认真真翻一遍。 —— 这就是我能想到的最大意义

更现实一点说：

  • 这条"AI 协作汉化"的路子跑通，可以复用到 几十款同类型日文老游戏 上。
  • 每一个走完这条路的人，都是游戏行业 潜在的储备人才。
  • 每一个晚上在 Vibe coding 的人，都在悄悄 圆自己儿时的梦。
  • 我们不是在做一款"复刻"，我们是在 重建一种能力——普通人也能动手做游戏的能力。

所以这件小事，值得认真做。
刻舟求剑的故事，到我们这里就结束吧。

09来一起 · 你能做什么

不需要会写代码，也不需要懂日文—— 只要你心里住着一个 80 后的晚上，就已经够了。

如果你也想参与，有这几种姿势：

👀 围观 / 鼓励

收藏本帖，转发到你当年一起玩 FC 的群，让更多人看到这件事。这本身就是最大的支持。

🀄️ 翻译 / 校对

日语 N2 以上 / 中文母语，能抽晚上半小时通读 50 句对白。越多人分担，每人就轻松一点。

🛠️ 引擎 / 工具

会 Godot / Unity / Tiled / 图像处理，或者就是单纯会用 AI 写点脚本——都是直接的帮助。

🎨 美术 / 字体

中文字体在低分辨率上的"再设计"是隐藏难点。点阵字大佬、字体设计师、汉字体爱好者请直接联系。

🧪 内测玩家

D +90 时会放出 Mod v0.9 内测，能打一整周目并写出 5 条改进意见的同好优先。

💌 单纯想说点啥

留言里聊聊你童年的那个游戏、你当年没看懂的那句话——我会在每一页的更新里挑一两条回。
