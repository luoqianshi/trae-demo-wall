# 汇率实时监控桌面工具

一款轻量级的桌面汇率监控工具，支持桌面悬浮窗显示、系统托盘驻留、汇率波动弹窗警报等功能。

## 功能特点

- **桌面悬浮窗**：无边框小窗口，始终置顶显示，可拖拽调整位置
- **系统托盘图标**：最小化到托盘，右键菜单快速操作
- **实时汇率更新**：默认每30秒自动刷新（可配置）
- **波动警报**：汇率波动超过设定阈值时，桌面居中弹窗提示
- **自定义设置**：支持修改货币对、刷新频率、波动阈值、窗口置顶等

## 默认配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 基础货币 | USD | 美元 |
| 目标货币 | JPY | 日元 |
| 刷新频率 | 30秒 | 自动更新间隔 |
| 警报阈值 | 0.5% | 波动超过此值弹窗提示 |
| 窗口置顶 | 开启 | 悬浮窗始终在最上层 |

## 使用说明

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> **注意**：本工具使用 `tkinter` 作为GUI库。Windows上安装Python时默认已包含。如果缺少，请参考 [Python官方文档](https://docs.python.org/3/library/tkinter.html) 安装。

### 2. 启动工具

```bash
python exchange_rate_monitor.py
```

### 3. 操作说明

| 操作 | 方式 |
|------|------|
| 移动窗口 | 按住鼠标左键拖拽 |
| 打开设置 | 点击悬浮窗右上角 ⚙ 或右键菜单选择"设置" |
| 立即刷新 | 右键菜单选择"刷新" |
| 隐藏到托盘 | 点击悬浮窗右上角 ✕ 或右键菜单选择"隐藏到托盘" |
| 退出程序 | 右键菜单选择"退出" 或托盘菜单选择"退出" |
| 从托盘恢复 | 双击托盘图标或右键选择"显示" |

### 4. 设置说明

在设置面板中可以修改：

- **基础货币 / 目标货币**：支持任意货币代码（如 EUR、CNY、GBP 等）
- **刷新频率**：单位秒，最小10秒
- **警报阈值**：单位百分比，建议 0.1% ~ 2%
- **窗口始终置顶**：开启后悬浮窗不会被其他窗口遮挡
- **启用波动警报**：关闭后不再弹窗提示

设置保存后会立即生效。

## 数据来源

汇率数据来自 [exchangerate-api.com](https://www.exchangerate-api.com/)，免费、稳定、无需API Key。
