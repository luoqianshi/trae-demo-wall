============================================
  HabitatEye | 生境监测平台 初赛 Demo
============================================

【快速开始】

  ■ Windows 用户：
    双击 "启动Demo.bat"
    浏览器会自动打开 http://localhost:5173

  ■ macOS 用户：
    双击 "启动Demo.command"
    浏览器会自动打开 http://localhost:5173


【为什么不能直接双击 index.html？】

  现代浏览器出于安全限制（CORS 策略），不允许通过
  本地文件协议（file://）直接运行 ES Module 类型的
  JavaScript 代码。因此需要通过本地 HTTP 服务器访问。

  本 Demo 提供了自动启动脚本，评委无需手动安装
  或配置任何东西，双击启动脚本即可。

  Windows 10/11 自带 PowerShell，脚本会自动使用
  .NET HttpListener 启动一个迷你 HTTP 服务器。
  如果电脑有 Python，会优先使用 Python 启动。


【注意事项】

  1. 启动后会弹出一个黑色命令行窗口，请勿关闭
  2. 本 Demo 需要联网加载地图瓦片，其余资源均已本地化
  3. 推荐使用 Chrome / Edge 浏览器打开
  4. 关闭命令行窗口即可停止服务
  5. 如果 5173 端口被占用，可修改启动脚本中的端口号


【页面导航】

  左侧导航栏可切换四个核心界面：
  · 全球监测  — 全球物种热点地图，多物种监测点分布
  · 区域详情  — 物种栖息地下钻分析，种群趋势数据
  · 预警演示  — AI 栖息地破坏检测与预警生成流程
  · AI识别   — 上传图片进行物种识别模拟

  支持物种：东北虎、勺嘴鹬、长江江豚
