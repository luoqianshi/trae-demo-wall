# 心迹 - 自定义功能策划案

## 一、策划背景

"心迹"目前是一款功能相对固定的心情记录工具。为了让用户更有"这是我的小窝"的归属感，需要引入自定义功能模块。考虑到目标用户是青少年（13岁左右），自定义功能应当：
- **操作简单** - 不需要复杂配置
- **即时反馈** - 修改后立即看到效果
- **趣味性强** - 有惊喜感和成就感
- **不过度** - 保持产品核心体验的纯粹性

---

## 二、功能模块规划

### 模块一：个人资料设置（优先级：高）

#### 2.1.1 用户昵称
- **功能描述**：设置一个昵称，问候语中会使用昵称
- **示例**：设置昵称为"小明"后，问候语变为"早安小明，今天也要元气满满哦"
- **交互**：点击设置图标 → 弹出输入框 → 输入昵称 → 保存
- **存储**：localStorage `xinji_nickname`
- **默认值**：空（不使用昵称）

#### 2.1.2 生日设置
- **功能描述**：设置生日，生日当天有特殊庆祝
- **生日彩蛋**：
  - 背景增加飘动的🎂和🎈emoji
  - 问候语变为"生日快乐！🎉 今天你是主角～"
  - 选择心情后有特别庆祝动画
- **交互**：日期选择器（可选，不强制填写）
- **存储**：localStorage `xinji_birthday`

---

### 模块二：主题外观自定义（优先级：高）

#### 2.2.1 主题色选择器
- **功能描述**：提供5种预设主题色 + 1个自定义色盘
- **预设主题**：
  - 💜 梦幻紫（当前默认）
  - 💙 深海蓝
  - 💗 樱花粉
  - 💚 森林绿
  - 🧡 暖阳橙
- **自定义色盘**：点击后弹出颜色选择器，可输入HEX色值
- **影响范围**：背景渐变、accent-color、卡片边框、按钮hover等
- **交互**：设置面板中色块网格 → 点击切换 → 实时预览

#### 2.2.2 背景动效开关
- **功能描述**：控制背景粒子效果的显示
- **选项**：
  - 开（默认）：显示当前的浮动粒子
  - 关：纯色背景，更省电
  - 极简：仅显示静态渐变，无动画
- **交互**：设置面板中三选一按钮组
- **注意**：检测 `prefers-reduced-motion`，若用户开启了系统级减少动画，默认关闭

#### 2.2.3 卡片透明度调节
- **功能描述**：调节毛玻璃卡片的透明程度
- **范围**：30%（更透明）~ 90%（更不透明）
- **交互**：滑块拖动，实时预览

---

### 模块三：心情体系自定义（优先级：中）

#### 2.3.1 心情emoji自定义
- **功能描述**：修改5个心情对应的emoji
- **限制**：只能修改为emoji字符，不支持图片
- **交互**：点击心情emoji → 弹出emoji选择面板（常用emoji网格）→ 选择新emoji
- **验证**：确保输入的是有效emoji

#### 2.3.2 心情名称自定义
- **功能描述**：修改5个心情的名称
- **示例**：把"崩溃"改为"很低落"，把"超嗨"改为"超开心"
- **限制**：最多4个汉字
- **交互**：点击心情名称 → 变为输入框 → 输入 → 失焦保存

#### 2.3.3 恢复默认
- **功能描述**：一键恢复心情emoji和名称为默认
- **交互**：设置面板底部"恢复默认"按钮 → 二次确认

---

### 模块四：语录库自定义（优先级：中）

#### 2.4.1 添加自定义语录
- **功能描述**：用户可以添加自己的鼓励语录
- **分类**：对应5种心情类别（崩溃/难过/一般/开心/超嗨）
- **格式**：语录文字 + 可选emoji前缀
- **示例**："难过"分类下添加"🌧️ 雨后总会有彩虹"
- **限制**：单条最多50字，每个分类最多20条自定义语录
- **交互**：
  1. 选择心情分类
  2. 输入语录内容
  3. 点击"添加"
  4. 列表中显示，可删除

#### 2.4.2 语录开关
- **功能描述**：控制是否显示语录弹窗
- **选项**：
  - 开（默认）：记录心情后弹出语录
  - 关：记录心情后不弹出语录，直接显示今日卡片

#### 2.4.3 语录来源选择
- **功能描述**：选择语录从哪个库中随机抽取
- **选项**：
  - 仅使用内置语录
  - 仅使用自定义语录
  - 混合使用（默认）：内置 + 自定义合并随机抽取

---

### 模块五：声音与触感（优先级：中）

#### 2.5.1 音效开关
- **功能描述**：控制点击心情按钮时是否播放音效
- **选项**：开 / 关
- **默认**：开

#### 2.5.2 音效风格选择
- **功能描述**：选择不同的音效风格
- **预设风格**：
  - 柔和钢琴（当前默认）
  - 八位机（像素游戏风格）
  - 自然音（鸟叫、风声等环境音）
  - 极简（仅一个简短提示音）

#### 2.5.3 触觉反馈开关
- **功能描述**：控制手机震动反馈
- **选项**：开 / 关
- **默认**：开
- **注意**：仅在支持振动的设备上显示此选项

---

### 模块六：数据管理（优先级：低）

#### 2.6.1 导出数据
- **功能描述**：将所有心情记录导出为JSON文件
- **已有功能**：保留现有导出功能

#### 2.6.2 清空数据
- **功能描述**：清空所有记录
- **已有功能**：保留现有清空功能，增加"导出备份后再清空"的引导

#### 2.6.3 使用统计
- **功能描述**：显示简单的使用统计数据
- **展示内容**：
  - 累计记录天数
  - 连续记录天数（当前 streak）
  - 最长连续记录天数
  - 最常选择的心情
- **展示位置**：设置面板底部或独立的"我的成就"页面

## 三、交互设计

### 3.1 设置入口

在页面右上角（⚙️ 调试按钮旁或替换调试按钮）增加一个 **设置按钮（齿轮图标）**。
- 点击后从右侧滑出设置抽屉面板
- 面板标题："个性化设置"
- 底部有"恢复所有默认"按钮

### 3.2 设置面板结构


### 3.3 实时预览机制

所有外观类设置（主题色、透明度、动效等）修改后立即在页面背景上预览，不需要点击"保存"。设置值自动保存到 localStorage。

### 3.4 首次使用引导

用户首次打开设置时，显示一个简短的引导提示：
> "这里可以打造属于你的小窝～试试换个喜欢的颜色吧！"

## 四、技术实现方案

### 4.1 数据存储结构

```javascript
// 所有自定义设置统一存储在一个key中
localStorage.setItem('xinji_settings', JSON.stringify({
  nickname: '',
  birthday: '',
  themeColor: 'purple', // purple/blue/pink/green/orange/custom
  themeCustomColor: '', // HEX值
  bgAnimation: 'on', // on/off/minimal
  cardOpacity: 0.65,
  moodEmoji: { 1: '😭', 2: '😔', 3: '😐', 4: '😊', 5: '🤩' },
  moodNames: { 1: '崩溃', 2: '难过', 3: '一般', 4: '开心', 5: '超嗨' },
  quotesEnabled: true,
  quotesSource: 'mixed', // built-in/custom/mixed
  customQuotes: {
    broken: [],
    sad: [],
    okay: [],
    happy: [],
    excited: []
  },
  soundEnabled: true,
  soundStyle: 'piano', // piano/8bit/nature/minimal
  vibrationEnabled: true
}));
```

### 4.2 与现有代码的兼容

- 所有设置读取时提供默认值，兼容旧版本用户
- 心情emoji和名称的修改通过函数动态读取，不硬编码
- 主题色通过CSS变量动态更新

### 4.3 实现优先级

**第一阶段（核心体验）**：
1. 昵称 + 生日设置
2. 主题色选择
3. 背景动效开关

**第二阶段（个性化）**：
4. 心情emoji/名称自定义
5. 语录库自定义
6. 卡片透明度

**第三阶段（高级）**：
7. 音效风格选择
8. 使用统计面板
9. 自定义颜色（色盘）

## 五、风险评估

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 设置过多导致界面复杂 | 中 | 分类折叠，默认只展开第一个 |
| 用户输入不当内容 | 低 | 输入长度限制，emoji验证 |
| localStorage空间不足 | 低 | 自定义语录限制数量，设置数据很小 |
| 与现有数据冲突 | 低 | 设置和心情数据分开存储 |
| 代码复杂度增加 | 中 | 模块化设计，设置单独一个模块 |

---

## 六、验收标准

1. 用户可以成功设置昵称并在问候语中看到
2. 用户可以切换主题色且全页面实时响应
3. 用户可以修改心情emoji和名称
4. 用户可以添加和删除自定义语录
5. 所有设置刷新页面后仍然保留
6. 设置面板在移动端和桌面端都显示正常
7. 提供"恢复默认"功能且工作正常
