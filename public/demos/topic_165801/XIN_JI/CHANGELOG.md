# 心迹 - 更新日志

## v2.0.0 - 2026年6月19日

**大幅动效增强 + 心情音效 + 可重复点击 + 日期切换**

### 🐛 Bug 修复

- **选择"超嗨"时文字与按钮重叠**：增大了签到提示文字的间距和字号，调整了按钮区域与提示文字的 margin，确保"今天你选择了 🤩 超嗨"等任何心情都不会重叠显示。

### ✨ 新增功能

#### 1. 5 种心情专属音效

- 点击不同心情按钮，会播放对应风格的音效：
  - 崩溃 😭：低沉快速的下行音（锯齿波 400Hz→150Hz）
  - 难过 😔：柔和缓慢的下行钢琴式琶音（523→440→349Hz）
  - 一般 😐：中性温暖的纯音（660Hz）
  - 开心 😊：明亮的上行琶音，带愉快泛音
  - 超嗨 🤩：快速高频铃音 + 泛音 + 颤音
- 所有音效通过 Web Audio API 实时合成，无需外部音频文件
- 音量轻柔，不刺耳

#### 2. 主题色随心情切换

- 点击心情后，页面的背景光斑、卡片边框发光、按钮光晕都会变成该心情的主色：
  - 崩溃 → 深灰 / 难过 → 浅蓝 / 一般 → 浅紫 / 开心 → 暖橙 / 超嗨 → 金黄
- 10 秒后，主题色自动渐变回默认的紫色 💜
- 再次点击其他心情会立即切换新的颜色

#### 3. 点击飞出文字 + 心形粒子

- 从被点击的心情按钮位置，飞出 3-5 个小文字串（如"加油""真棒""嗨起来"），呈抛物线向上飘散、旋转、缩小、淡出
- 文字颜色跟随当前心情（橙→暖黄，蓝→冷蓝，以此类推）
- 当心情为"开心 😊"或"超嗨 🤩"时，额外飞出 2-4 个小心形、星星、烟花等 emoji 粒子 ✨❤️🎉⭐

#### 4. 月历可点击切换日期（正式版）

- 月历中的每一天都可以点击，切换到那一天进行查看、补打卡、或修改心情
- 今天的格子持续发光脉冲（原有效果增强）
- 当前正在查看的日期有不同的边框高亮，与"今天"区分
- 切换日期后，签到区的提示文字会显示你正在查看的日期
- 月历格子 hover 时有提示"查看 6月X日"

#### 5. Debug 面板增强

- 新增 `<input type="date">` 日期选择器，可跳转到任意日期（包括未来日期）
- 显示当前 activeDate（正在查看的日期）
- 新增"回到今天"按钮
- "清除当前日期签到"按钮可清除正在查看的这一天的记录（不再局限于今天）

## v2.2.0 - 2026年6月19日

**背景律动/呼吸动画 + 中央鼓励弹窗 + 重复点击简化**

### ✨ 新增功能

#### 1. 背景始终有缓慢流动（默认微光浮动）

- 页面默认使用 `bgDriftSlow` 14 秒循环动画，紫蓝色光斑极缓慢地平移、缩放、淡入淡出
- 像深海里的水光，让页面"活着"但不抢戏
- 默认状态始终存在，无论是否点击过心情

#### 2. 点击心情触发背景律动或呼吸

- **点击开心 😊 / 超嗨 🤩**：切换到温暖明亮的色调（金色/橙色渐变），触发 `heartBeat` 1 秒节奏的律动效果——背景像心跳一样，轻快起伏、脉动。律动持续约 9 秒后自动平复，回到默认缓慢流动。
- **点击难过 😔 / 崩溃 😭**：切换到冷调柔和的色调（深蓝/浅紫渐变），触发 `deepBreath` 6 秒节奏的呼吸效果——背景缓慢亮起再暗下、再亮起再暗下，循环几次后约 11 秒自动恢复默认。
- **点击一般 😐**：切换到中性柔和的色调，只做一次柔和的颜色过渡（约 4 秒），不触发明显律动或呼吸，直接回到默认缓慢流动状态。
- **再次点击（未平复前）**：新效果立即覆盖当前效果，通过 reflow 重置动画计时，不会叠加冲突。
- **平滑过渡**：CSS `transition` 让颜色与动画状态切换自然柔和，不会突变。

#### 3. 中央鼓励弹窗

- 首次签到（当天第一次点击保存）时，屏幕中央弹出带毛玻璃效果的卡片，显示一句温暖的鼓励文字 + 对应心情的 emoji：
  - 超嗨/开心："哇！这兴奋感都快溢出屏幕了 🎉"、"这份好心情是你应得的 🌟"、"笑一笑的样子真好看 😊"…（共 12+ 条）
  - 一般："平平淡淡也是好日子 🌿"、"那就休息一下吧，也很好 🌙"…（共 6 条）
  - 难过/崩溃："今天辛苦了，给你一个大大的抱抱 🤗"、"撑不住就休息，没人要求你一直坚强 💔"…（共 12+ 条）
- 弹窗有柔和的弹出动画（缩放 + 淡入）
- 约 4.5 秒后自动消失，也可点击弹窗任意位置立即关闭

#### 4. 重复点击反馈简化为两条 + 全量 emoji 化

- **第 1 次重复点击**：弹出对应心情的精简语录（"再点亮一次好心情 ✨"、"再抱一次，别怕 🤗"…）
- **第 2 次重复点击**：继续弹出语录或切换为极简 emoji（💙 / 🫂 / 🌸 / ⭐ …）
- **第 3 次及以后**：只弹一个极简 emoji，不再啰嗦
- **所有提示都带 emoji**：首次保存 toast "🤩 已记录，愿你被温柔对待 🌸"
- **Toast 时长 4 秒**：足够看清内容再消失

### 🔧 功能修改

#### 1. handleMoodClick 逻辑重写

- 新增 `sameDayClickCount` 变量，当日内每次点击心情时累加；`setActiveDate` 切换日期时自动归零
- 首次保存：调用 `showEncouragement(mood)` 显示中央弹窗 + 友好 toast
- 重复点击 / 切换心情：根据点击次数在"语录→emoji"之间递减
- 切换心情：仍然会覆盖保存旧值，并重置按钮高亮状态

#### 2. applyThemeColor 扩展为"主题色 + 背景律动"

- 原逻辑（设置 CSS 变量 `--accent-color`、`--accent-color-soft`）保留
- 新增：根据心情等级切换 `body` 的 class（`bg-happy` / `bg-sad` / `bg-calm`），触发对应动画
- 新增：reflow 触发（`void document.body.offsetWidth`）确保同一心情重复点击时动画重新计时
- 时长区分：开心/超嗨 9s → 恢复；难过/崩溃 11s → 恢复；一般 4s → 恢复

### 💡 其他小改进

- `body::before` 背景层改为 `position: fixed; width: 100vw; height: 100vh;`，始终覆盖全窗口
- 中央弹窗 `.center-popup` 的 z-index 4000，确保不被任何组件遮挡
- Toast 字体更大（15px→17px），padding 更宽松，视觉更舒适

### 📝 数据兼容

- localStorage key 格式保持不变：`xinji_mood_YYYY-MM-DD`
- 所有改动纯前端 CSS/JS 增强，完全向后兼容

## v2.3.0 - 2026年6月20日

**全屏背景 + 语录移动抽屉 + 双设备版本 + favicon**

### ✨ 新增功能

#### 1. favicon 与应用名称
- 浏览器标签页图标：紫色爱心 💜（inline SVG）
- 页面顶部增加大号应用名「心迹」+ 副标题「你的心情小窝」
- 应用名字带有温和的心跳脉冲动画

#### 2. 背景延伸至全屏 + 保持心情色
- 点击任意心情后，**整个页面背景**切换为对应心情色（从原来的光斑-only 变成整体渐变）
- 崩溃→深灰 / 一般→淡紫 / 开心→暖橙 / 超嗨→金黄
- 背景色**保持在此状态**，不会自动恢复默认（下次打开页面仍自动恢复当日心情色）
- 律动/呼吸动画也持续运行

#### 3. 语录「弹出-停留-移动」三段式动画
- 首次签到后：**中央放大弹出**鼓励语录（3.5s，带柔和弹跳动画）
- 自动（或点击任意处）：**平滑移动**到签到卡下方的语录停留区 + 缩小成紧凑卡片
- 固定显示：语录永远保留在那个位置，不再消失

#### 4. 抽屉式「本周情绪速写」
- 语录移动到下方后，紧接着从底部**滑出一周心情图谱**（抽屉动画）
- 柱状图从 0 逐条生长
- 顶部的**馆长寄语默认不显示**

#### 5. 点击「导出周报」→ 寄语浮现
- 点击导出按钮：图谱下方的寄语从透明 → 高度展开 → 浮现（fade-in）
- 同时生成纪念卡片下载
- 用户能清晰看到"这就是给我的话"的仪式感

#### 6. 两个独立版本（共享数据）
- **`index.html`** — 通用版本（之前的标准版，可在任意设备使用）
- **`mobile.html`** — 手机竖屏版：更大的心情按钮（56px），更窄的容器（420px），单列单列布局，字体更大，完全 touch 友好
- **`desktop.html`** — 电脑横屏版：两列布局（签到卡 ↔ 月历卡），更宽 1100px，增强的 hover 效果，所有按钮带柔和的缩放/位移过渡

#### 7. emoji 兼容性升级
- 🫂 → 🤗（拥抱）
- 🫖 → ☕（热茶）
- 🫧 → 💫（星光）
- 🪷 → 🌸（花朵）
- 🫀 → 💛（黄心）
- 确保在所有主流浏览器、旧设备上正常显示

### 📝 数据兼容
- 三个版本的文件共享完全相同的 `xinji_mood_YYYY-MM-DD` localStorage key
- 用户在手机版记录的心情，在电脑版打开同一浏览器即可看到（反之亦然）
