## 1. Demo 简介

- **销售数据智能分析大屏** 是一个基于 HTML5 + ECharts 构建的实时数据可视化系统，支持多维度数据分析、图表联动、数据钻取和主题切换。

- **面向谁**：企业数据分析师、销售管理人员、BI开发者、数据可视化学习者。

- **主要功能**：
  - 多维度销售数据分析（时间、地区、销售员、客户、商品）
  - 图表联动与数据钻取（点击任意图表元素，其他图表自动过滤）
  - WebSocket实时数据更新（每5秒自动生成新数据）
  - SQLite数据库持久化存储
  - 5种主题风格一键切换（深空科技、极光幻境、赛博朋克、自然森林、暖阳橙韵）
  - 可交互数据表格（排序、拖拽列、隐藏列）
  - 星空粒子背景动画

## 2. Demo 创作思路

- **灵感来源**：在工作中经常需要给客户做BI大屏演示，但市面上的工具要么太重（需要部署整个平台），要么太简单（只是静态图表）。我就想，能不能做一个轻量级但功能完整的BI大屏Demo？既能让客户直观看到效果，又能作为教学案例展示数据可视化的核心能力。

- **想解决的问题**：
  1. **实时性问题**：传统BI大屏多是定时刷新，我想实现真正的实时数据推送
  2. **联动交互**：点击某个销售员，其他图表自动显示该销售员的数据，这种联动体验很重要
  3. **主题切换**：不同客户喜欢不同风格，能快速切换主题很实用
  4. **轻量部署**：不需要复杂的后端服务，一个Node.js就能跑起来

- **为什么做这个方向**：数据可视化是数据分析的最后一公里，再好的数据分析结果，如果不能直观展示，价值就大打折扣。BI大屏作为数据可视化的重要形式，在企业决策中发挥着越来越重要的作用。我想通过这个Demo，展示如何用纯前端技术栈实现一个功能完整的BI系统。

### 项目亮点

1. **全栈实现**：从前端到后端到数据库，完整的数据可视化解决方案
2. **实时性**：WebSocket实现真正的实时数据推送，不是定时刷新
3. **交互性**：图表联动、数据钻取、主题切换，用户体验流畅
4. **轻量级**：SQLite数据库 + Node.js，无需复杂部署
5. **可扩展**：模块化设计，易于添加新的图表和分析维度

### 技术栈选择理由

- **ECharts**：功能强大、文档完善、社区活跃，适合复杂图表需求
- **SQLite**：轻量级、无需独立服务、适合Demo演示
- **WebSocket**：实现真正的实时通信，比轮询更高效
- **CSS变量**：主题切换的核心技术，动态修改样式变量即可切换主题
- **原生JavaScript**：不依赖框架，代码更轻量，易于理解

### 遇到的挑战与解决方案

1. **挑战**：图表联动状态管理复杂
   - **解决**：设计LinkageEngine统一管理筛选状态，所有图表监听状态变化

2. **挑战**：实时数据更新时图表重绘性能
   - **解决**：只更新变化的数据，使用ECharts的setOption局部更新

3. **挑战**：多主题切换时图表颜色同步
   - **解决**：监听主题变化事件，动态更新ECharts的color配置

4. **挑战**：数据钻取的路径管理
   - **解决**：使用栈结构管理钻取路径，面包屑导航显示当前路径
