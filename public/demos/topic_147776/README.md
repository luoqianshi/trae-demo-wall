# 销售数据智能分析大屏

一个功能完整的销售数据BI大屏系统,支持实时数据更新、多维度分析和多主题切换。

## 功能特性

### 1. 数据存储
- 使用SQLite数据库存储销售数据
- 支持2000+条历史销售记录
- 包含销售员、客户、商品、地区等多个维度

### 2. 实时数据更新
- WebSocket实时通信
- 每5秒自动生成1-3条新销售数据
- 前端自动接收并更新图表
- 显示数据更新通知

### 3. 多维度分析
- 时间维度:年度、季度、月度趋势分析
- 地区维度:中国地图热力分布
- 销售员维度:业绩排行榜
- 客户维度:客户贡献分析
- 商品维度:品类销售分析
- 行业维度:行业分布分析

### 4. 交互功能
- 图表联动:点击任意图表元素,其他图表自动过滤
- 数据钻取:支持从全国钻取到省份、从年份钻取到月份
- 数据表格:可排序、可拖拽列、可隐藏列
- 筛选器:支持年份、品类等多条件筛选

### 5. 主题切换
提供5种精美主题风格,一键切换:
- **深空科技**:蓝色科技感主题(默认)
- **极光幻境**:紫色梦幻主题
- **赛博朋克**:霓虹炫彩主题
- **自然森林**:绿色清新主题
- **暖阳橙韵**:橙色温暖主题

## 技术栈

### 后端
- Node.js + Express
- SQLite数据库(sql.js)
- WebSocket实时通信

### 前端
- HTML5 + CSS3 + JavaScript
- ECharts 5.x 图表库
- 原生WebSocket客户端

## 安装与启动

### 快速启动（推荐）

使用启动脚本一键完成所有操作：

**Windows 系统：**
```bash
start.bat
```

**Linux/Mac 系统：**
```bash
chmod +x start.sh
./start.sh
```

启动脚本会自动完成以下步骤：
1. 检查并安装依赖
2. 检查并初始化数据库
3. 启动服务器
4. 自动打开浏览器访问 http://localhost:3000

### 手动启动

如需手动控制启动过程，可按以下步骤操作：

#### 1. 安装依赖
```bash
npm install
```

#### 2. 初始化数据库
```bash
node init-db.js
```

这会创建SQLite数据库并导入初始数据。

#### 3. 启动服务器
```bash
node server.js
```

服务器将启动在 http://localhost:3000

#### 4. 访问大屏
打开浏览器访问: http://localhost:3000

## API接口

### 获取销售数据
```
GET /api/sales
```

支持查询参数:
- year: 年份筛选
- quarter: 季度筛选
- month: 月份筛选
- salesperson: 销售员筛选
- customer: 客户筛选
- province: 省份筛选
- city: 城市筛选
- productCategory: 商品品类筛选
- product: 商品筛选
- industry: 行业筛选

### 获取KPI统计
```
GET /api/kpi
```

返回总销售额、订单数、客户数、平均订单金额等指标。

### 获取维度数据
```
GET /api/dimensions
```

返回所有维度数据(销售员、客户、商品、地区等)。

## WebSocket通信

连接地址: `ws://localhost:8080`

### 消息类型

#### 服务器推送
```json
{
  "type": "sales_update",
  "data": [...],  // 新增的销售数据
  "timestamp": "2026-07-14T08:30:00.000Z"
}
```

## 使用说明

### 主题切换
页面右上角有主题切换器,点击即可切换不同主题风格。选择的主题会自动保存到浏览器本地存储。

### 数据联动
- 点击地图上的省份,其他图表会自动过滤为该省份的数据
- 点击销售员排行榜的某个销售员,其他图表会显示该销售员的数据
- 点击面包屑导航可以返回上一级

### 数据钻取
- 在时间趋势图上点击年份,可以钻取到该年的季度数据
- 点击季度可以钻取到月度数据
- 在地图上点击省份,可以钻取到该省的城市数据

### 数据表格
- 点击表头可以排序
- 拖拽表头可以调整列顺序
- 点击"列设置"按钮可以显示/隐藏列
- 表格数据与图表联动

## 注意事项

1. 必须先运行 `node init-db.js` 初始化数据库
2. 服务器需要同时运行HTTP服务(端口3000)和WebSocket服务(端口8080)
3. 浏览器需要支持WebSocket和ES6语法
4. 建议使用Chrome、Firefox或Edge浏览器
