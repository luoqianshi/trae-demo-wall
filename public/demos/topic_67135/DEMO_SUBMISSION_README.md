# 今日时光广播 Demo 打开说明

## 推荐打开方式

请将压缩包解压后，用 Chrome、Edge 或 Safari 浏览器打开：

```text
today-time-radio-demo.html
```

建议使用桌面浏览器体验，手机浏览器也可打开，但录音和文件保存能力可能受浏览器权限限制。

## Demo 内容

这个 Demo 展示“今日时光广播”的核心体验：

- 子女端：选择心情、生成问候稿、试听语音、发送给父母。
- 声音档案：可使用预置复刻音色，也可录制 10-12 秒声音进行训练演示。
- 父母端：收听语音问候，或查看文字问候，并进行轻反馈。
- 老照片修复：支持黑白照片上色，以及模糊老照片增强修复。
- 陪伴节奏：支持按家庭习惯设置提醒频率。

## 联网说明

联网时，Demo 会调用云端 AI 服务：

- 文案生成
- TTS 语音合成
- 声音复刻
- 老照片上色/修复

如果云端语音服务不可用，语音试听会自动降级为浏览器内置 TTS。

## 注意事项

- 其他设备首次打开时是全新状态，不会携带开发者本机缓存。
- 麦克风录音需要浏览器授权。
- 老照片修复依赖网络和云端模型额度。
- 建议不要在聊天软件的文件预览器中直接体验，请下载后用浏览器打开。
