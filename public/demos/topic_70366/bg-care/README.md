### **作品名称**

血压管家（BP Care）—— 专为长辈打造的AI智能隐私血压守护小程序

### **项目背景与痛点**

随着老龄化社会的到来，长辈的高血压等慢性病监测成为众多家庭的日常痛点。目前市面上的健康App普遍存在两大阻碍：一是界面复杂、广告繁多，长辈难以独立操作；二是强制要求注册账号并上传健康数据，引发了严重的隐私担忧。这导致许多家庭的血压记录需求无法被妥善满足。

### **核心功能与亮点**

“血压管家”是一款专为长辈设计的微信小程序，主打极简体验、AI赋能与绝对安全：

1. **绝对隐私，零数据上传**：采用纯本地存储机制（wx.setStorageSync），所有血压数据仅保存在长辈的手机本地。无需注册，从根本上杜绝了健康隐私泄露的风险。
2. **极简适老化交互**：专为长辈设计的UI界面，全局大字体、高对比度配色、大圆角按钮。操作路径极短，长辈可轻松独立完成。
3. **双模极速录入**：支持一键手动录入高压、低压与心率；同时创新加入“拍照识别”功能，长辈只需用手机对准传统血压计屏幕拍照，AI即可自动提取数字，极大降低了操作门槛。
4. **AI智能健康分析**：内置AI健康分析助手，自动读取本地血压数据，生成通俗易懂的健康评估报告（如“近期血压平稳”、“建议关注夜间高压”等），让长辈看得懂、能安心。
5. **直观健康趋势**：内置可视化图表，一键生成最近7天的血压波动折线图，为就医提供清晰的数据参考。

### **技术实现与AI赋能**

本项目充分发挥了微信小程序“即用即走”的轻量化优势，并结合 Trae IDE 实现了极速开发：

- **原生架构，极致轻量**：采用微信小程序原生语法开发，长辈在微信内即可直接使用，极大降低了使用门槛。
- **AI辅助提效**：借助 Trae 强大的代码生成能力，在极短时间内完成了适老化UI构建、本地存储逻辑、图表渲染和AI分析模块的完整闭环，验证了AI在解决社会痛点上的巨大潜力。

### **底部导航栏“个人中心”功能规划**

为了支撑你提到的“微信自动授权登录”以及“AI分析”功能，底部的【个人中心】Tab 需要包含以下核心模块：

1. **微信授权登录/个人信息模块**
   - **功能描述**：页面顶部展示用户头像和昵称。首次进入时，引导用户点击“微信一键授权登录”（调用 `wx.getUserProfile` 或最新的头像昵称填写组件）。
   - **适老化设计**：授权按钮要足够大，文案使用“点击授权，开启健康守护”，避免使用生硬的技术词汇。
2. **AI 健康分析对话**
   - **功能描述**：提供一个醒目的“查看AI健康分析”入口。点击后，系统读取本地的血压记录，调用大模型接口（或预设的AI规则引擎），生成一段文字版的健康建议。
   - **适老化设计**：AI的回复必须是大字体、分段落显示，多用“温馨提示”、“建议您”等关怀话术。
3. **数据管理模块**
   - **功能描述**：提供“历史记录查看”、“清空本地数据”功能。
   - **适老化设计**：清空数据按钮必须加上“二次确认”弹窗，防止长辈误触导致数据丢失。
4. **隐私与安全声明**
   - **功能描述**：用显眼的文字向长辈承诺：“您的所有血压数据均保存在当前手机中，绝不上传云端，请放心使用。”
