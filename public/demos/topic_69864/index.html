B 站 UP 主、Vlogger、播客制作者,任何需要把多段音乐串成一段连续作品的人, 都不应该为对齐波形和调淡入淡出耗掉一整个下午。

Problem
到底在解决什么?

音乐爱好者在拼接多段音乐时,核心痛点有三处:衔接处生硬爆破、不同歌曲音量差异大、手动寻找高潮部分耗时费力。三首歌的串烧可能就要花一整天。

市面上几乎没有面向普通用户的自动化工具,专业 DAW 软件(如 Ableton)学习成本极高。

Inspiration
为什么做这件事?

灵感来源于游戏视频剪辑的配乐,很多 B 站 UP 主的视频里,BGM 切换丝滑无感,看完才发现其实拼接了多首曲子。

于是决定把"智能检测高潮 + 自动交叉淡化"封装成零门槛的一键式产品,让任何人都能像剪辑师一样制作专业级的音乐串烧。

Product
它是一个什么样的产品?

一款跨平台的桌面应用程序(Windows / macOS / Linux),同时提供 GUI 图形界面和 CLI 命令行两种操作方式。核心引擎基于 FFmpeg + librosa。

支持 MP3、WAV、FLAC、OGG、M4A 等主流格式的批量导入、自动高潮识别、淡入淡出衔接、响度归一化与最终混音导出。

Audience
谁会用到它?

视频创作者与 Vlogger、播客与有声内容制作者、游戏集锦作者、自学 DJ 与电子音乐爱好者,以及对"沉浸式歌单"有需求的普通听众。

典型场景:旅行 Vlog 用三首风格递进的曲子串联一天;运动健身生成一气呵成的跑步歌单;婚礼派对从暖场到高潮的连续 BGM。

Value
为什么值得做?

传统人工拼接一小时的视频 BGM 需要 3-4 小时,本工具压缩到分钟级。相当于把专业音频工程师的数小时工作浓缩到一个按钮。

本产品让"音乐混剪"这一原本属于专业制作人的技能,下沉到每一位普通创作者手中。降低表达门槛,让中文互联网涌现出更多元、更有创意的视听作品。

librosa + soundfile
03

一次处理,
走完四步。

从原始音频文件到最终混音输出,中间过程完全自动化。 你只需要按下开始。

01
解析
读取音频元数据,转成单声道 44.1 kHz 浮点波形。
load_audio()
02
检测

detect_highlights()
03
合并
节拍吸附 + 调性匹配 + 等功率淡化,生成过渡平滑的拼接音频。
smart_crossfade_merge()
04
导出
响度归一化,编码为 WAV / MP3 / FLAC,写入磁盘。
export_audio()

命令行,
写给 会 用它的人。

Click 构建,子命令清晰。脚本化集成,批处理任务,CI/CD 流水线都能直接调用。

~/projects/music_appender
$ music_appender --help # Usage: music_appender [OPTIONS] COMMAND [ARGS]... Commands: detect-highlight 检测音频高潮部分 info 显示音频信息 load-project 加载项目文件 process 处理音频文件 save-project 保存项目文件 $ music_appender process song1.mp3 song2.mp3 -o output.wav --crossfade 3.0 [OK] song1.mp3 loaded: 4:23, 44.1kHz, 320kbps [OK] song2.mp3 loaded: 3:51, 44.1kHz, 320kbps [OK] BPM detected: 128 / 126 [OK] Crossfade applied at 2:18 [DONE] output.wav written (8:14, 28.4 MB)
CMD
music_appender process song1.mp3 song2.mp3 -o output.wav
处理并合并多个音频文件,输出无缝衔接后的成品。
CMD
music_appender detect-highlight song.mp3
自动检测音频文件的高潮部分位置,输出时间戳。
CMD
music_appender info song.mp3
显示音频文件的详细信息(时长、采样率、码率、声道数)。
CMD
music_appender save-project project.json song1.mp3 song2.mp3
保存当前处理进度到项目文件,下次继续。
CMD
music_appender load-project project.json
加载之前保存的项目文件,恢复处理状态。
