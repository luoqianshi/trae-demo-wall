# 银发守护者 v1.0 - TRAE AI创造力大赛参赛作品

## 1. 项目简介
面向老年人设计的AI辅助工具，集成AI防骗助手、语音问诊、拍照文字识别、吃药提醒、反诈情景模拟五大功能，通过后端中转隐藏大模型API密钥，保护密钥不被前端窃取。

## 2. 技术架构
前端：原生HTML/CSS/JS
后端：Node.js Express（仅做密钥中转、静态资源托管，无数据库）
大模型：阿里云通义千问Qwen3-VL-Plus，Qwen-plus

## 3. 启动使用方法（评委操作步骤）
1. 解压压缩包，打开demo文件夹
2. 双击 run.bat 一键启动后端服务
3. 等待自动弹出浏览器页面 http://127.0.0.1:3001 即可使用全部AI功能

## 4. 项目目录说明
- css/img/js/json：前端页面、素材、交互代码
- env：Node后端代码、密钥配置、依赖清单
- run.bat：一键启动脚本，无需手动输入命令
