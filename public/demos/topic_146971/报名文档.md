## 1. Demo 简介

### 是什么

**非遗守护人**是一款以"学习+收集+闯关"为核心玩法的**非遗文化科普 App**。用户通过每日盲盒抽取非遗项目，在 AI 故事官的引导下了解项目的历史渊源与文化价值，通过答题闯关领取珍藏卡，逐步点亮全国地图、升级段位，最终成为"山河守艺人"。

### 面向谁

- **中小学生及青少年**：通过游戏化方式接触传统文化，完成课外科普学习
- **文化爱好者**：系统了解中国 3610 项国家级非遗，建立完整的知识图谱
- **非遗传承人及研究者**：利用 AI 故事官快速查询名录信息，辅助研究与传播

### 主要功能

#### 功能一：每日盲盒 + AI 故事闯关

用户每天抽取一个非遗盲盒，卡片翻转后揭晓今日项目。进入闯关流程后，AI 故事官会先介绍该项目的地区、门类、历史渊源、文化价值和传承方式，然后抛出 2 道选择题。全部答对即可领取珍藏卡。

> 题目不是固定题库，而是基于 3610 个项目各自的信息动态生成——每个项目都有独特的题目组合，选项也根据题目上下文动态变化（问传承方式就给出传承相关的选项，问表演场合就给出场景相关的选项）。

#### 功能二：珍藏卡收集与地图点亮

答对题目后获得一张珍藏卡，卡片的稀有度由项目信息哈希决定（普通 15%、精良 25%、稀有 30%、史诗 20%、传说 10%）。收集到的卡片会点亮对应省份的地图格子，同时推进等级进度。

> 传说级卡片领取时有粉紫色粒子二次爆发的全屏特效，史诗级有橙色光晕，精良级有蓝色微光——品质越高，视觉反馈越震撼。

#### 功能三：AI 故事官（小匠灵）

基于全量 3610 条非遗名录构建的本地知识问答系统。用户可以问"昆曲是什么门类的""推荐一个我还没收集的江苏项目""帮我出一道关于剪纸的题""生成一张皮影戏的藏品卡文案"……系统通过关键词正则匹配实现零 API 成本的即时回答，同时支持接入豆包或 DeepSeek。

#### 附加功能

- **60 个成就殿堂**：分收藏、闯关、探索、社交四卷，解锁时右上角弹出金色粒子飘浮提示
- **社区互动**：发帖讨论、点赞、投稿未注册非遗项目
- **好友系统**：添加好友、聊天、互访珍藏卡展示墙
- **排行榜**：收藏榜 / 等级榜 / 好友榜，前三名金银铜领奖台可视化
- **每日事件**：7 天轮换（龙舟竞渡、中秋灯谜、窑厂开窑、戏曲鉴赏等）

## 2. Demo 创作思路

### 灵感来源

去年参观了一个非遗展览，展厅里有很多精美的展品，但大多数观众只是走马观花，很少有人能真正记住每个项目背后的故事。我当时就在想：**如果能让这些文化知识像游戏一样好玩，年轻人会不会更愿意主动了解？**

刚好看到 Pokemon GO 和原神的神瞳收集机制，我突然想到：非遗名录不就是现成的"图鉴"吗？3610 个项目，每个都有地区、门类、历史，天然适合做成收集闯关类的应用。

### 想解决的问题

**痛点一：非遗知识门槛高，年轻人缺乏兴趣**

传统的非遗传播主要靠纪录片、博物馆和教材，形式偏严肃，很难吸引年轻人主动接触。我们调研时发现，很多中学生连"非遗有哪 10 大门类"都答不上来。

**痛点二：信息分散，没有系统化的学习路径**

3610 个项目分布在各个地区、各类文献中，普通用户很难建立一个完整的认知框架。想了解家乡有什么非遗？想知道某个门类有哪些代表项目？没有一站式的工具。

**痛点三：非遗传承断层，年轻人参与度低**

很多非遗项目面临传承人老龄化的问题，但年轻人并不知道这些项目的存在，更谈不上参与保护。

### 为什么做这个方向

**判断一：政策红利 + 文化自信的窗口期**

近年来国家大力推动非遗保护，各地学校也在加强传统文化教育。但市场上的非遗类 App 大多是资讯型或电商型，真正以"游戏化学习"为核心体验的产品很少。

**判断二：3610 个项目的规模本身就是护城河**

如果做纯娱乐向的收集游戏，内容很容易枯竭。但非遗名录是国家级权威数据，3610 个项目提供了足够的内容深度，每个项目都可以延伸出故事、题目、卡片、地区关联——这是一个可以持续迭代的内容池。

**判断三：AI + 教育的结合点**

AI 故事官不只是一个聊天机器人，它是基于全量非遗名录的"知识引擎"。用户问任何问题，它都能从 3610 条数据中找到答案。这种"即时问答+游戏反馈"的体验，是传统教育产品很难做到的。

**取舍：**

- 做了**本地优先**的方案：所有数据、进度、收藏都保存在 localStorage，不依赖服务器，打开就能用
- 放弃了复杂的多人在线对战：单机的收集闯关+社区分享已经足够支撑 MVP 体验
- 用**确定性哈希**代替随机抽卡：同一项目每次打开品质相同，避免用户觉得"被算法操控"

## 3. 技术实现亮点（额外补充）

- **纯前端单文件 HTML**：内嵌全部 CSS 与 JavaScript，零后端依赖，部署成本极低
- **Web Audio API 合成音效**：背景音乐、交互音效全部用代码生成，无需外部音频文件
- **跨日自动重置**：每日事件与今日收集数基于北京时间零点自动刷新
- **中国风 UI**：宣纸暖色底、金色边框、书法感字体、 ink wash 渐变、42 个环境浮动粒子营造氛围
