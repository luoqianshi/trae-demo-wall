# 文字动画

文字是 MG 动画的核心。但文字动画不是"选一个效果套上去"——它是将文字的**语义、节奏、情感**翻译为视觉运动的过程。

## 核心原则：动画从文字中生长

不要从"我有哪些动画效果可用"出发，而要从"这段文字在说什么"出发：

- 文字是**结论性陈述**？→ 动画应该有终结感、确定感
- 文字是**过程描述**？→ 动画可以体现流动、推进
- 文字是**对比信息**？→ 动画可以体现张力、分离
- 文字是**情感表达**？→ 动画的节奏应该匹配情绪
- 文字是**数据/事实**？→ 动画应该有精确感、客观感

**每段文字都有自己独特的动画基因，你的任务是发现它，而不是套用预设效果。**

## 可读性底线（不可妥协）

无论设计什么动画，以下规则是底线：

- 文字出场后必须在 0.5 秒内可读——动画服务于可读性，不是牺牲它
- 每个文字块至少完整可见 1.5 秒
- 同一时刻只有一个主文字在活动——不要让多个文字块竞争注意力
- 文字颜色与背景对比度足够（深色背景配浅色文字）

## 动画的维度

不要把文字动画理解为"选一个效果"，而是在这几个维度上做设计决策：

### 揭示方式
文字如何出现在画面上？这个选择应该由文字的语义驱动：

- **逐字揭示**：适合需要"阅读跟随感"的内容（如定义、关键概念）——用 `String.slice()` 实现字符串逐步显示
- **整体显现**：适合短而有力的内容（如标题、结论）——用透明度或缩放一次性呈现
- **分段展开**：适合长文本（如解释、叙述）——按标点拆分，逐段揭示
- **创意入场**：根据文字内容设计独特的入场方式——这才是你应该追求的

**技术约束**：逐字揭示必须用字符串切片（`text.slice(0, n)`），不要为每个字符单独设置透明度——那样性能差且效果不自然。

### 运动方向
文字从哪里来、到哪里去？

- 方向不是随意的——它应该暗示文字的内容方向
- "增长""上升""进步"的内容 → 从下方入场是自然的
- "回顾""过去""历史"的内容 → 从左侧入场暗示时间线
- "结论""最终""结果"的内容 → 从中心展开有终结感
- 但这些只是启发，不是规则——最好的方向选择往往出人意料

### 强调方式
如何让观众注意到关键词？

- 不要总是用同一种强调方式
- 可以是颜色变化、可以是大小变化、可以是位置变化、可以是辅助元素（下划线、高亮条、光晕）
- 强调方式应该匹配词的性质：数字可以用跳动，概念可以用颜色，动作词可以用运动

### 出场方式
文字如何离开？

- 出场和入场同样重要——它为下一个内容腾出注意力空间
- 出场方向可以与入场呼应（对称）或对比（不对称）
- 不要所有场景都用"淡出"——有时"飞出""缩小""溶解"更合适

## 设计思维过程

面对一段文字时，按这个思路思考：

1. **这段文字的核心信息是什么？** 提炼出一个视觉焦点
2. **这段文字的情感基调是什么？** 决定动画的节奏和力度
3. **文字结构有什么特点？** 有没有关键词、数字、对比、递进？
4. **观众应该先看到什么、后看到什么？** 决定揭示顺序
5. **什么样的运动会增强而非干扰理解？** 这是最关键的一步

## 避免的错误

1. **目录式思维**：不要从"我有打字机、高亮、渐变这些效果"出发选效果——要从文字出发设计
2. **所有文字用同一种动画**：不同场景的文字应该有不同的动画个性
3. **动画比文字更抢眼**：动画是仆人，文字是主人
4. **逐字符透明度动画**：用字符串切片代替，性能更好、效果更自然
5. **花哨字体**：视频中用无衬线字体保证可读性
6. **标题过长导致换行**：拆成两个场景，不要缩小字体
