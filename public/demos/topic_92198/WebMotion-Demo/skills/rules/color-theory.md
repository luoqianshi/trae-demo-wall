# 色彩与主题

色彩是情感的直接语言。在观众阅读文字之前，色彩已经传达了情绪。好的配色不是"选一个好看的色板"，而是"选择能强化内容情感的颜色"。

## 核心原则：色彩从内容中诞生

不要从预设色板中选颜色。先感受内容的情感基调，再推导合适的色彩：

- **科技/理性**的内容 → 冷色调（蓝、青、靛）传递精确和信任
- **活力/行动**的内容 → 暖色调（橙、红、黄）传递能量和紧迫
- **自然/生长**的内容 → 绿色系传递生命和有机感
- **创意/想象**的内容 → 紫色/品红传递非传统和灵感
- **沉稳/商务**的内容 → 深蓝/灰传递可靠和专业
- **温暖/人文**的内容 → 暖色低饱和传递亲近感

**但这些只是起点。最好的配色往往是出人意料但恰到好处的——比如用冷静的蓝色表现激烈的内容，制造反差张力。**

## 配色设计方法

### 从情感到色彩

1. 读取文案，提取情感关键词（如"创新""突破""温暖""严肃"）
2. 为每个情感关键词联想色彩（"创新"→ 可能是电光蓝，也可能是活力橙，取决于上下文）
3. 选择一个主色承载核心情感
4. 选择一个强调色制造视觉焦点（可以与主色对比或互补）
5. 背景色应该衬托主色，不抢注意力

### 色彩比例原则

不管选什么颜色，比例关系是通用的设计原则：

- **主色 60%**：背景、大面积色块、主要视觉元素的色调
- **辅助色 30%**：次要元素、装饰、文字背景
- **强调色 10%**：关键数据、CTA、需要突出的焦点

这个比例确保画面有统一的色调，同时有焦点。

### 色彩数量

- 每个场景 3-4 种颜色为宜
- 颜色越多越难控制——少即是多
- 如果需要更多颜色（如数据可视化），确保它们来自同一个色相家族

## 对比度（技术底线）

这是不可妥协的可读性要求：

- 文字与背景对比度至少 4.5:1（WCAG AA 标准）
- 深色背景配浅色文字，浅色背景配深色文字
- 在渐变背景上放文字时，添加半透明遮罩保证对比度
- MG 动画通常用深色背景获得更好的视觉冲击力和文字可读性

## 色彩情感不是固定的

传统色彩心理学给颜色赋了固定情感（蓝=信任，红=危险），但实际中色彩的情感由**上下文**决定：

- 红色在"警告"内容中是危险，在"热情"内容中是活力
- 蓝色在"科技"内容中是理性，在"忧郁"内容中是悲伤
- 你要为每段内容重新定义色彩的情感，而不是查表

## 渐变与深度

- 渐变可以营造空间深度感——但方向和颜色过渡要有意义
- 双色渐变比多色渐变更可控
- 渐变方向暗示视觉流向：左上→右下是最自然的阅读方向
- 使用 `ctx.createLinearGradient()` 和 `ctx.createRadialGradient()`
- 背景装饰用主色的低透明度变体（`utils.color.rgba(mainColor, 0.1)`）

## 跨场景一致性

- 整个视频保持同一色彩语言——不要每个场景换一套色板
- 但可以在同一色板内调整主色和强调色的角色（场景A蓝色为主，场景B橙色为主）
- 转场时色彩过渡应平滑自然

## 工具函数

- `utils.color.rgba(hex, alpha)` — 给颜色加透明度
- `utils.color.lerp(c1, c2, t)` — 在两色之间插值
- `utils.color.hexToRgb(hex)` — 转换颜色格式
