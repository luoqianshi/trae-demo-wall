# 场景构图

构图是"决定什么在哪里"的艺术。好的构图让观众的目光自然流向重要信息，差的构图让观众困惑不知道该看哪里。但构图没有固定模板——它由内容结构决定。

## 核心原则：构图从内容结构中推导

不要从"我有居中、左右、上下三种布局"出发。先分析内容的结构关系：

- 内容有**一个核心要点**？→ 让它成为画面唯一的焦点
- 内容有**对比关系**（A vs B）？→ 用空间分离体现对立
- 内容有**递进关系**（1→2→3）？→ 用方向或位置暗示推进
- 内容有**层级关系**（主→次）？→ 用大小和位置体现层级
- 内容是**单一陈述**？→ 居中聚焦是最自然的

**构图应该让观众一眼就感受到内容的关系结构，而不是看到一个"好看的布局"。**

## 焦点层级

每个场景必须有且只有一个明确的视觉焦点。其他元素都服务于它：

- **主焦点**：承载最核心信息的元素——最大的、最亮的、最先动的
- **辅助元素**：补充说明主焦点的元素——更小、更暗、延迟出现
- **背景氛围**：烘托情绪的元素——最暗、最底层、几乎不被注意

### 如何制造焦点

不要只用一种方式制造焦点。可以组合使用：

- 大小对比（主元素明显更大）
- 色彩对比（主元素最亮或最饱和）
- 运动对比（主元素先动，或动得最明显）
- 空间位置（主元素在视觉重心）
- 但不要所有方式都用——过度强调反而失去焦点

## 空间思维

不要把构图理解为"选一个布局模板"。把画面理解为有重力、有张力的空间：

- **居中**：所有元素围绕一个中心——给人稳定、庄重感
- **不对称平衡**：一边大一边小但视觉平衡——更动态、更有设计感
- **方向性**：元素排列暗示一个方向——引导观众视线移动
- **留白**：空白本身是元素——它给内容呼吸的空间

什么布局好？取决于你想让观众感受到什么。

## 留白的力量

留白不是"空的地方"，而是"让重要内容被看到的空间"：

- 元素之间要有足够的呼吸空间
- 不要因为"有空间"就填充——空本身就是设计
- 如果画面感觉拥挤，优先移除元素，而不是缩小间距
- 留白的分布影响视觉重心——多留一侧的空间可以引导视线

## 元素关系的思考

构图的核心是元素之间的关系，不是元素本身：

- 两个元素并排 → 暗示对比或平等关系
- 一个元素包含另一个 → 暗示从属或组成关系
- 元素沿一条线排列 → 暗示顺序或流程
- 元素围绕一个中心 → 暗示聚焦或汇聚
- 想清楚内容的关系是什么，然后用空间表达它

## 用时间解决空间问题

如果内容多到一个画面放不下——不要缩小元素硬塞，用时间解决：

- 把内容拆到多个场景
- 在同一场景中错时展示（先 A，A 淡出后 B）
- 让次要元素以装饰形式存在，主元素独占焦点

## 常见错误

1. **没有焦点**：多个元素大小相同、亮度相同——观众不知道看哪里
2. **均匀分布**：所有元素等间距排列——像表格而非设计
3. **填满画面**：不留白——画面窒息
4. **装饰抢戏**：背景装饰太亮或太大——本末倒置
5. **跨场景跳动**：元素位置在不同场景间剧烈变化——缺乏连续性
6. **套用模板**：所有场景都用同一种布局——缺乏变化和内容匹配
