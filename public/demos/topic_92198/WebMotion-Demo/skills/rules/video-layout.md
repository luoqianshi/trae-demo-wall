# 视频布局

视频的观看方式与网页完全不同。观众在几秒内从整个画面中快速获取信息，而不是像浏览网页那样逐块阅读。设计时始终从"全帧观看"的视角出发。

## 从帧开始思考

- 每一帧都必须有一个明确的视觉焦点——观众的眼睛应该知道往哪里看
- 善用留白。一个含有一条强烈信息的画面，通常优于塞满装饰元素的画面
- 不要因为"有空间"就填充——视频中的空不是浪费，是呼吸

## 安全区（技术约束）

这些是硬性边界，确保内容不被裁切：

- **1920×1080**：关键内容距左右边缘至少 120px，距上下边缘至少 100px
- **1080×1920 竖屏**：关键内容距左右边缘至少 80px，距上下边缘至少 120px
- 绝对定位的装饰元素（光晕、粒子）可以超出安全区

## 场景内容的设计

不要套用固定的"主文字+辅助视觉+装饰"结构。根据内容需要决定场景包含什么：

- 有时一个画面只需要一句大字——足够有力
- 有时需要文字+图形配合解释概念
- 有时需要数据可视化呈现数字
- 有时需要纯氛围场景做情绪过渡

**内容决定结构，不是结构框住内容。**

## 防止重叠

- 不要用独立的 x、y 坐标手动定位每个元素——容易重叠
- 将内容放入逻辑区域：上部、中心、下部
- 元素从预留位置进出动画，不要动画到被其他元素占据的空间
- 文字长度不确定时，给文字块足够的宽度和垂直空间

## 视频中的文字尺寸

文字必须在观看距离下可读。这是底线，不是建议：

- **主标题**：72-96px（必须大到一眼看到）
- **重要支持文字**：40-56px
- **标签或简短标注**：28-36px
- **正文段落**：24-32px
- 竖屏分辨率下字号增加 20%-30%
- 不确定时往大调——视频中的小字等于看不见
- 如果文字太长放不下——拆成多个场景，不要缩小字体

## 用时间解决拥挤

- 让时间解决布局问题。不要一次性展示所有内容
- 如果画面感觉拥挤：移除元素、放大焦点、或将次要内容移到另一个场景
- 偏好居中或强对齐的构图，而非分散的 UI 布局
- 保持跨场景的视觉一致性：重复的间距、对齐方式、色彩语言

## 避免网页 UI 模式

视频中不要出现这些网页设计模式：

- 大量卡片、徽章、边框、标签——这些是网页 UI 元素，放到视频中显得杂乱
- 仪表盘式布局——视频不是信息面板
- 表格——用动画分步骤呈现代替
- 面包屑导航、分页——视频是线性的，不需要导航元素

## 渲染前自检

生成代码后，检查一个代表性帧：

- 主信息能否在 1 秒内被理解？
- 是否有一个明显的视觉焦点？
- 是否有元素相互接触、重叠或尴尬并排？
- 画面是否过于拥挤或过于空旷？
