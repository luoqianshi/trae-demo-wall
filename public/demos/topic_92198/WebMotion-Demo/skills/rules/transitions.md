# 场景转场

转场不是两个场景之间的"装饰效果"——它是叙事的标点符号。好的转场让观众感受到场景之间的逻辑关系，就像"然而""然后""总之"这些连接词。

## 核心原则：转场从叙事关系中生长

不要从"转场类型表"中选一个。先理解两个场景之间的叙事关系：

- **延续关系**（同一主题的展开）→ 用柔和的过渡（fade），像逗号
- **推进关系**（步骤递进）→ 用方向性运动（slide），像箭头
- **对比关系**（前后对照）→ 用擦除或推入，像"然而"
- **聚焦关系**（从宏观到细节）→ 用缩放，像镜头推进
- **揭示关系**（悬念揭晓）→ 用光圈，像 curtain call
- **总结关系**（收尾归纳）→ 用淡出，像句号

**转场的选择应该让观众下意识感受到内容的逻辑关系，而不仅仅是"好看"。**

## 可用转场类型

这些是引擎提供的工具，了解它们的能力，但选择由叙事驱动：

| 转场 | 视觉效果 | 叙事暗示 |
|------|---------|---------|
| `fade` | 透明度交叉淡入 | 通用过渡，柔和的连接 |
| `slideLeft` | 新场景从右侧滑入 | 时间向前推进、步骤递进 |
| `slideRight` | 新场景从左侧滑入 | 回溯、反向时间线 |
| `slideUp` | 新场景从下方滑入 | 层级上升、信息揭示 |
| `slideDown` | 新场景从上方滑入 | 深入细节、层级下降 |
| `wipe` | 从左到右擦除揭示 | 替换、变化、对比 |
| `zoom` | 缩放淡入/淡出 | 焦点转移、宏观↔微观 |
| `iris` | 圆形扩展/收缩 | 聚光灯、局部揭示 |

## 转场时长

转场时长也是叙事工具：

- 快转场（0.3s）→ 节奏紧凑，场景间关系紧密
- 慢转场（0.8s）→ 节奏舒缓，场景间有情绪过渡
- 转场会重叠相邻场景，总时长 = 场景时长之和 - 转场时长

转场时长不是固定值——根据叙事节奏调整。

## 配置方式

在场景数据中设置 `transition` 和 `transitionDuration` 属性。转场效果由渲染引擎自动应用，场景代码中不需要处理转场逻辑——只需关注场景内的动画。

## 转场期间的元素行为

- 转场前半段：上一个场景逐渐退出
- 转场后半段：下一个场景逐渐进入
- 场景代码中的 `t` 参数始终是场景内的局部时间，不受转场影响

## 不要过度使用转场

- 不是每个场景都需要不同的转场——有时连续的 `fade` 比花哨的混合更专业
- 转场的一致性也是一种设计——同一章节用同一种转场建立节奏感
- 最重要的是叙事清晰，不是转场炫技
