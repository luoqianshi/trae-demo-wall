慧算智控 - 集团全面预算管理系统
交互式 Demo 使用说明
=====================================

【如何运行】
1. 解压本 ZIP 文件到任意文件夹
2. 双击打开 index.html 文件（推荐使用 Chrome / Edge 浏览器）
3. 即可开始体验全部交互功能

【功能概览】

📊 首页
- 预算完成进度总览（全部门/销售部门/职能部门）
- 当前版本信息展示
- 快捷操作入口
- 版本历史记录

🏢 部门管理
- 6 个预置部门（3 销售 + 3 职能）
- 支持新增/编辑/停用/启用部门
- 部门详情页查看预算状态
- 点击部门进入费用明细录入

💰 费用明细录入
- 12 个月预算 + 上年实际对比
- 报表分类、费用项目下拉选择（联动字典）
- 支持添加行、删除行、自动汇总
- 提交/撤回功能

📋 版本管理
- 多版本预算编制支持
- 创建新版本（自动生成版本号）
- 版本对比年设置
- 版本状态切换（填写中/已锁定）

📤 数据导入
- 费用预算 Excel 导入（模拟）
- 人工预算导入与下发
- 标准模板下载
- 部门 + 版本维度选择

📈 汇总报表
- 全集团预算总额统计
- 部门完成情况一览
- 按报表分类占比（ECharts 饼图）
- 月度预算趋势（ECharts 柱状图）
- 分类明细表

⚙️ 基础信息
- 报表分类管理（新增/编辑/停用）
- 费用项目字典（46 项预置标准科目）
- 别名映射配置
- 报表分类关联

【交互特性】
✓ 所有数据本地存储（localStorage），刷新不丢失
✓ 完整的页面导航与面包屑
✓ 模态框表单交互
✓ 实时数据汇总与图表联动
✓ 响应式布局设计
✓ 一键载入示例数据

【重置数据】
如需恢复初始状态，请在浏览器控制台执行：
  localStorage.removeItem('hszk_demo_data'); location.reload();

【技术栈】
- 纯 HTML + CSS + JavaScript（无需后端）
- ECharts 5 数据可视化
- localStorage 本地数据持久化
