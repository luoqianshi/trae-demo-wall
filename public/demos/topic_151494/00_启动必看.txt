【推荐方式一：直接双击打开，零门槛体验】
======================================================
  打开「方式一_直接双击打开（离线模式）」文件夹
  → 直接双击 index.html 即可在浏览器打开
  → 无需安装任何软件，离线也能用！

  说明：
  - 此为预构建版本，使用 Hash 路由，双击直接可用
  - 支持七大功能模块完整页面浏览
  - 包含 AI反诈检测Demo、AI创作Demo 等

  如果双击后白屏：请使用 Chrome / Edge 浏览器打开，
  不要用 IE 浏览器。


【进阶方式二：源码完整开发版（强烈推荐评委使用）】
======================================================
  前置要求：安装 Node.js 18+（https://nodejs.org/zh-cn）

  打开 PowerShell / 终端，进入「方式二_源码完整开发版」目录：
    cd 方式二_源码完整开发版

  第一步：安装依赖
    npm install

  第二步：启动开发模式（代码修改实时热更新）
    npm run dev
    → 访问浏览器：http://127.0.0.1:5173/
    → 体验完整交互：首页欢迎动画、反诈重新检测、创作流程

  或：构建生产版本（可直接双击 dist/index.html）
    npm run build
    → 打开 dist 目录，双击 index.html 即可
