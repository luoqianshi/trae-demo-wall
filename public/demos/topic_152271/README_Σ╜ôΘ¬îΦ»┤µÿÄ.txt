诗轴画布·唐诗流转 Demo 体验说明

1. 解压压缩包
2. 直接双击打开 index.html
3. 页面会优先读取 poems.json 和 similarity_matrix.json
4. 如果本地浏览器限制 file:// 读取，页面会自动回退到内嵌数据，仍可正常体验

建议体验方式：
- 点击星空中的小画轴节点
- 观察解带动画
- 查看独立宣纸诗页中的完整古诗内容
- 关闭当前诗页，体验自动流转到下一首诗

包含文件：
- index.html
- poems.json
- similarity_matrix.json
- calc_similarity.py
- README_体验说明.txt
