Technical Architecture

六大核心技术，全栈端侧

从端侧 LLM 推理到记忆算法，每一项能力都在本地设备上完成。

01
🧠

端侧 LLM 推理

基于 MNN-LLM JNI 桥接，Qwen3-1.7B INT4 量化模型本地运行，支持 Thinking / Non-Thinking 双模式切换，兼顾深度推理与低延迟响应。

MNN-LLMQwen3INT4JNI
02
🎙

统一语音引擎

sherpa-onnx 统一封装 ASR + TTS + VAD，支持 4 种音色与流式合成，端到端语音延迟低于 800ms，全程离线。

sherpa-onnxASRTTSVAD
03
📊

发音评分 Pipeline

ASR 识别 → DTW 音素对齐 → CMU Dict 音素比对 → 综合评分 → LLM 纠错建议，五段式流水线实现音素级精度。

DTWCMU Dict音素级
04
📈

FSRS-5 记忆算法

三组件记忆模型（稳定度/可提取性/难度），4 档评分反馈，"开口锁"机制确保开口训练优先于被动复习。

FSRS-5间隔重复开口锁
05
🔒

隐私优先架构

核心 AI 能力 100% 端侧运行，数据不出设备。三层降级链（MNN 本地 → 云端 API → 规则引擎）保证可用性。

完全离线数据不出设备三层降级
06
🏗

Clean Architecture

UI / Domain / Engine / Data / DI 五层分层架构，Hilt 依赖注入，Room v8 持久化 15 张数据表，单向数据流。

HiltRoom v815 表单向流
// 五层分层架构 · Layered Architecture
01
UI 层 ComposeJetpack Compose 声明式 UI，单屏单任务，无底部导航
02
Domain 层 UseCase业务用例与领域模型，纯 Kotlin，无框架依赖
03
Engine 层 AI 核心LLM / ASR / TTS / 发音评分 / FSRS 引擎封装
04
Data 层 Room v815 张数据表，Repository 模式，本地优先
05
DI 层 Hilt依赖注入与生命周期管理，模块化解耦
Design Philosophy

三条设计原则

区别于传统背单词 App，LingoQuest 重新定义了"开口学英语"的产品形态。

🎯

首页即课堂

无底部导航栏，首页直接呈现今日核心任务。AI 教练决定下一步学什么，单屏单任务，降低选择成本，让用户聚焦"开口练"。

01
🤖

AI 全驱动

学什么、怎么排、哪里错、下一步做什么，全部由 AI 决策。规则引擎只做兜底，确保离线状态下基础体验可用。

02
🔐

隐私优先

核心 AI 能力（LLM/ASR/TTS/发音评分）全部端侧运行，用户语音与学习数据永不离开设备，云端仅为可选增强。

03
