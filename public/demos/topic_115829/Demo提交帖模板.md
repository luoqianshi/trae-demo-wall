## 1. Demo 简介

**是什么：** 一个运行在浏览器中的桌面陪伴宠物 Demo（单文件 HTML，可直接打开运行）

**面向谁：**
- 长时间面对电脑的程序员 / 设计师 / 办公族
- 喜欢萌宠、需要情感陪伴的年轻人
- 想有个桌面小助手帮自己摸鱼回血的打工人

**主要功能：**

### 🖱️ 互动养成
点击程序鸭可以和它互动——它会蹦跶、冒爱心、说随机台词。每一次互动都会增加好感度，越养感情越深~

![互动效果示意]（此处放一张点击互动的截图）

### 💬 聊天对话 + 记忆功能
双击小鸭打开聊天面板，可以和它对话。程序鸭会记住你说的话，越聊越懂你。记忆数据存在本地，完全私密。

![聊天面板示意]（此处放一张聊天的截图）

### ⚙️ 隐私可控
所有敏感功能（屏幕感知、语音、记忆）默认关闭，用户可以在设置面板里自主选择开启哪些。**你的隐私你说了算。**

![设置面板示意]（此处放一张设置的截图）

### 📌 其他特性
- 可拖动到桌面任意位置
- 支持暂时收起 / 重新召唤
- 自动说话功能（可开关）
- 点击音效 + 可选语音朗读
- 数据全部存在本地 localStorage

## 2. Demo 创作思路

**灵感来源：**

每天对着电脑写代码，有时候挺孤独的。就想要一只桌面上的小宠物——不用太复杂，能陪着我、偶尔冒个泡、累了戳两下回血就行。

市面上的桌宠要么太花哨占资源，要么就是纯摆设没有互动感。我想要的是一个**真的"认识我"的伙伴**——它知道我喜欢什么、记得我们聊过什么、在我累的时候会主动来搭话。

**想解决的问题：**
1. **情感陪伴需求**：独居/远程办公人群的孤独感，需要一个低成本的情感出口
2. **久坐提醒**：写代码太投入忘了休息，有个小宠物催你站起来活动活动
3. **隐私焦虑**：AI 产品都在收集数据，但这个小宠物的记忆完全存在你自己电脑上

**为什么做这个方向：**

考虑了好几个方向，最后选了桌面陪伴宠物，因为：
- **痛点真实**：自己每天都有这个需求，不是拍脑袋想出来的
- **技术可行**：用 HTML + JS 就能做出不错的效果，不需要复杂的后端
- **想象空间大**：后续可以加语音包、换装、工作助手、屏幕理解……扩展性很强
- **有温度**：做出来的东西是能带来快乐的，这比单纯炫技更有意义
