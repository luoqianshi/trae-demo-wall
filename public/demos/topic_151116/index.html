完整项目部署

下载完整项目以体验真实 AI 生成功能

完整项目基于 Vite + React + TypeScript 构建，支持 DeepSeek / 通义千问 / 智谱 / OpenAI / Claude 等多种 AI 服务商。部署步骤：

  1. 下载并解压项目压缩包
  2. 运行 npm install 安装依赖
  3. 运行 npm run dev 启动开发服务器
  4. 在设置页面配置你的 AI API Key
  5. 开始标记存档点，体验真实 AI 生成的平行人生
