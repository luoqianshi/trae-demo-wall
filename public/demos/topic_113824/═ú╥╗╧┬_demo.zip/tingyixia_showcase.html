Demo 创作思路

从一个深夜的懊悔，到一段温柔的代码

1

💡 灵感来源

每天晚上刷手机停不下来，一抬头已经凌晨。常常想着看一会儿休息一下，结果直到眼睛痛了脖子硬了才后悔。如果沉浸 20 分钟、30 分钟、1 小时时就有一个温柔的声音喊"停一下"，屏幕变灰，眼睛和脖子才真正得到休息。

2

🎯 想解决的问题

数字时代"用屏成瘾"问题。不是不知道该休息，而是缺少一个"温柔的打断机制"和有效休息方案。现有工具只给冰冷数据，缺少情感共鸣和行动引导——只告诉你"今天用了 8 小时"，却不带你离开屏幕。

3

🌱 为什么做这个方向

从生活健康角度，关注用屏时间过长问题，不是禁止娱乐而是温和提醒合理运动；从防沉迷角度，通过全屏暗色提醒制造短暂停顿，给用户重新选择的机会——把"刷"的惯性，变成"停一下"的觉察。

技术亮点

纯前端实现，零外部依赖

🎵

Web Audio API 音乐合成

纯代码生成轻柔背景音乐，无需音频文件，支持淡入淡出过渡，体积极小且可程序化控制节奏。

纯代码生成
🏃

CSS 动画小人

5 种身体部位对应 5 套独立动画动作，全部用 CSS keyframes 实现，流畅且性能友好。

5 套动作
🔊

SpeechSynthesis 语音合成

调用浏览器原生语音合成 API，清亮声音引导运动节奏，无需任何第三方 TTS 服务。

浏览器原生
🤖

AI 文案系统

5 种语气 × 4 种场景 = 20 种个性化提醒文案组合，根据使用时段与情境动态匹配，告别千篇一律。

5×4=20 组合

踩坑经历与心得

每一个翻车现场，都是一次更懂用户的修正

🎢

3D 透视效果翻车

原本想用 perspective / rotateY 营造手机 3D 旋转效果，结果框元素变形严重、定位错乱。

✅ 放弃 3D 回归 2D，反而更清爽稳定
💪

动画小人手臂位置

手臂一开始从身体中间出发，做动作时像"断裂"，视觉非常违和。

✅ 改为从肩膀位置出发，动作才自然
🌫️

灰屏遮罩遮挡状态栏

灰屏 overlay 的 z-index 设置过高，把手机顶部状态栏也一起盖住了，影响体验。

✅ 调整层级关系，状态栏独立置于灰屏之上
🗣️

语音"哦"字拖音

AI 文案里出现"哦"字时，SpeechSynthesis 会拖长音，听上去黏糊不干脆。

✅ 直接去掉"哦"字，提醒更利落
