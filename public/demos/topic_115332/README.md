# 灵感回流器 · 评委体验指南

> 一个把「散落的想法」重新点燃行动感的小工具：从你的灵感库里，用 AI 碰撞 / 深化出今天就能做的一件具体小事（梦卡）。

## 评委怎么用（点开即用，无需服务器）

1. 解压 `inspiration-reflux-vX.Y.Z.zip`
2. **双击 `index.html`**（用浏览器打开即可，不需要安装任何东西、不需要起服务器）
3. 首次进入会自动加载内置的**演示灵感库**，直接点首页「生成梦卡」即可体验
4. 生成梦卡需要联网调用大模型（已内置演示 Key，开箱即用）

## 关于 AI（重要）

- 本工具是纯前端 Demo，**AI 生成需要联网**（调用大模型 API）。
- 包内**已内置一个专用演示 Key**，评委打开即零配置可用，效果与开发者本地测试一致。
- 演示 Key 仅用于评审期，**赛后会被吊销**；请勿用于生产环境或大量调用。
- 评委也可在「设置 → AI 配置」里把自己的 Key（DeepSeek / 小米 MiMo 等）填进去替换演示 Key。

## 功能速览

- **今日梦卡**：AI 从灵感库碰撞 / 深化出可执行的微行动
- **灵感库**：自由沉淀灵感，支持分类、收藏
- **我的 / 设置**：查看行动轨迹、切换 AI 供应商与模型

## 技术说明

- React 18 + TypeScript + Vite
- 单文件构建（`vite-plugin-singlefile`）：JS / CSS 全部内联进 `index.html`，规避本地双击时 ES module 的 CORS 拦截
- 路由使用 HashRouter + 相对路径 `base: './'`，确保从任意路径 / `file://` 打开都不会 404
- 版本号：`vX.Y.Z`（见页面右下角角标）
