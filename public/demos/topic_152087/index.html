A
三层混合分层架构

类比博物馆：精选展厅 + 楼层导览图 + 完整档案库 — 点击各层查看详情

第一层 · 策展层

项目级索引 — DEV_MEMORY.md

六维提炼后的高价值结论，类比博物馆的精选展厅

包含六维：① 任务与变更摘要 ② 踩坑记录 ③ 探索路径 ④ 最终结论与最佳实践 ⑤ 架构决策记录 ⑥ 环境与依赖信息
每条记忆标记：[日期] [价值星级 ★~★★★] [引用:N] [有效期:日期] [关联:条目]
元数据指纹：维度数/条目数/更正数/健康分 — 一行掌握全局
▼
第二层 · 导航层

会话级摘要 — sessions/YYYY-MM-DD.md

每次会话的一段话摘要 + 上下文链接，类比博物馆的楼层导览图

内容：会话主题、关键动作、学习要点、涉及维度
作用：快速定位某次会话做了什么，不翻 JSONL 就能找到上下文
格式：Markdown 标题 + 段落，人类可读
▼
第三层 · 原始层

消息级记录 — sessions/YYYY-MM-DD.jsonl

每条消息的完整结构化记录，类比博物馆的完整档案库

10 字段 Schema：message_id / timestamp / session_id / intent / actions / outcome / learned / dimensions / references / valid_until
特点：JSONL 格式，程序化处理友好，支持增量追加
作用：完整保留开发过程，支持回溯和审计

横向补充：USER_PROFILE.md（跨会话用户画像+贡献者溯源+设备历史）+ CONFIG.md（配置和注入指引）
