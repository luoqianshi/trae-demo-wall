# 心桥 · 产品功能介绍

## 产品定位

心桥是一款 **AI 亲子沟通预演与推进工具**。

它解决的核心问题不是缺乏沟通工具，而是沟通发生之前的阻塞点：

- 孩子有情绪，但害怕被追问、误解或批评，所以不说
- 家长有担心，但不知道怎么开口才不会让孩子反感
- 双方围绕同一件事各自积累情绪，却始终没有把话说清楚

心桥的策略是：**让双方先分别说，各自先获得可执行建议；AI 再异步识别共同点，匹配成功后分别升级双方的下一步建议**。

---

## 核心功能模块

### 1. 双端私密对话

家长和孩子各自拥有独立的聊天界面，分别与不同角色的 AI 助手交流：

- **家长端**：AI 助手叫「心桥 AI」，语气温和、成熟，像朋友一样陪家长理清担忧
- **孩子端**：AI 助手叫「小桥」，语气亲切、平等，像同龄人一样陪孩子说出心里话

两端的对话内容**完全隔离**，任何一方都看不到对方说了什么，AI 也不会把一方的原话透露给另一方。

### 2. 沟通事件识别

AI 在对话过程中持续分析用户表达，识别当前对话涉及的沟通矛盾类型：

| 事件类型 | 说明 |
|---|---|
| `study_pressure` | 学业压力与成绩追问 |
| `phone_conflict` | 手机使用与边界冲突 |
| `cold_war` | 长期冷战与沟通回避 |
| `emotional` | 情感与人际关系 |
| `boundary` | 隐私边界与信任问题 |
| `school_refusal` | 拒学与学校焦虑 |

事件以**候选**形式逐步建立，随对话深入持续更新置信度和状态，从 `collecting`（收集中）推进至 `ready_for_match`（可匹配）。

### 3. 双端自动匹配

当一端已经获得建议时，系统会同步把该端事件推进到可匹配状态；家长端与孩子端候选都达到阈值后，自动触发**跨端语义匹配**：

- AI 对比双端脱敏摘要，判断是否指向同一个沟通矛盾
- 匹配与建议生成异步进行，不要求双方同时在线或同时发送消息
- 匹配成功后生成内部「沟通进展」记录，并通知双方已识别到共同关注的问题
- 更新版本后重新打开页面，也会自动恢复本地尚未完成的待匹配候选

这一过程在原文隔离前提下完成，双方只知道“系统确认正在关注同一件事”，不会看到对方的具体表达或内部共同摘要。

### 4. 分端建议卡

建议卡分为两个阶段：

1. **单端即时建议**：用户明确询问“怎么办”“怎么做好点”等问题后，AI 会停止继续追问，先显示“正在生成建议”，然后基于本端累计对话整理事件并生成可立即使用的建议；即使前面漏建了事件候选，也会在明确求助时自动补整理。
2. **匹配后升级建议**：双端匹配成功后，移除临时单端卡，再分别为家长和孩子生成更新后的本端建议；生成期间仍显示加载状态并原位替换。

每张建议卡包含：

| 字段 | 内容 |
|---|---|
| 关注重点 | 当前最需要优先关注的一点 |
| 建议回避 | 容易激化矛盾的表达或行动 |
| 参考话术 | 可以直接尝试的一句开场白 |
| 行动建议 | 本周可以做的一个具体小步骤 |

正常聊天中的建议正文由 LLM 根据当前角色的事件摘要和最近对话实时生成，不使用固定知识库模板冒充个性化内容。双端共同信息只用于内部匹配分析，不会把另一端独有事实写进本端建议。

### 5. 情绪日志与记忆档案

每轮对话中，AI 持续记录：

- **情绪日志**：本轮情绪状态、强度、触发因素、风险等级
- **记忆档案**：沟通习惯、表达偏好、行为模式（如"孩子在压力下更需要先被倾听再解释原因"）

这些记录随时间累积，帮助 AI 在后续对话中给出更贴合实际的建议。

### 6. 风险提醒

当对话中出现以下信号时，系统触发风险提醒：

- 危机信号（自伤、轻生相关表达）：立即给出安全支持话术，引导拨打 12355
- 高风险信号（家暴、霸凌、严重安全威胁）：引导联系专业机构
- 关注信号：提示另一端需要留意当前状态

风险提醒独立于建议功能，不受匹配状态影响，随时触发。

### 7. 沟通进展与反馈闭环

匹配成功后形成的「沟通进展」支持：

- 查看事件详情和双端分别的建议
- 标记建议执行结果（有效 / 部分有效 / 没有效果）
- 提交反馈后，AI 根据反馈内容生成新的回应建议

形成「识别 → 建议 → 执行 → 反馈 → 更新」的完整推进闭环。

### 8. 私藏话术库

用户可以将建议卡中的参考话术收藏到私人话术库，方便随时查阅和回顾。

## 隐私与安全设计

| 设计 | 说明 |
|---|---|
| 原文隔离 | 双端对话内容完全独立，AI 不向任何一方泄露对方原文 |
| PII 脱敏 | 进入 AI 提示词的内容自动过滤手机号、邮箱、身份证号等个人信息 |
| 输出安全校验 | AI 回复经过二次检测，拦截自伤方法、暴力指引等高风险内容 |
| 本地存储 | Key 和对话数据仅保存在本地浏览器，不上传服务器 |
| 直连模式 | 请求由浏览器直接发送给模型服务，不经过心桥中间层 |

## 演示模式

无需配置模型即可体验完整功能流程：

- 点击「一键演示」，系统按预设脚本依次展示：注册、家庭连接、双端对话、事件识别、匹配通知、建议生成、反馈闭环
- 演示结束后可继续手动操作
- 当前演示场景覆盖：学业压力（study）、手机使用冲突（phone）、沟通冷战（coldwar）
