# Proposal: 寻味岭南之粤菜点餐助手小程序

## 项目概述
基于自然语言理解的粤菜智能点餐推荐系统。用户输入用餐需求（如"2个人吃，预算200元，想吃清淡的粤菜"），系统自动解析意图并从预设菜品库中匹配推荐1-3道菜品。

## 背景
广东理工学院《人工智能综合能力实训》课程设计第6题。客户报价299元，要求最快速度交付可用产品。

## 功能范围

### 核心功能（Must Have）
1. **自然语言点餐输入** — 文本输入框，支持自由描述用餐需求
2. **意图解析与菜品匹配** — LLM 解析人数/预算/口味/类别，从菜品库匹配1-3道菜
3. **智能推荐结果展示** — 菜品卡片（菜名、图片、价格、标签、推荐理由）
4. **点餐历史概览** — 本地保存历次点餐记录，可回顾

### 不包含（Out of Scope）
- 真实支付/下单
- 用户注册登录
- 多端同步
- AI 生图（用免费图库替代）

## 技术栈

| 层 | 选型 | 理由 |
|---|------|------|
| 前端 | 微信小程序（原生 WXML/WXSS） | 课题要求"小程序"，原生最快 |
| 后端 | FastAPI + Uvicorn | 异步高性能，开发者熟悉 |
| 数据库 | SQLite | 零配置，单文件部署 |
| LLM | DeepSeek API / Qwen API | 意图解析，成本 < 0.01元/次 |
| 菜品图 | Unsplash/Pexels 免费图库 | 避免版权风险 |
