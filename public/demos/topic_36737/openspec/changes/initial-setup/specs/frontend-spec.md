# Frontend Specification

## 设计风格：岭南茶楼 × 现代聊天交互

### 色彩系统
| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#C84B31` | 朱红，岭南建筑常用色 |
| 背景 | `#FFF8F0` | 米白，温暖底色 |
| 辅色 | `#2D5F3E` | 墨绿，植物/自然感 |
| 点缀 | `#D4A853` | 金色，品质感 |
| 文字主 | `#1A1A1A` | 深灰黑 |
| 文字次 | `rgba(26,26,26,0.62)` | 半透明灰 |
| 卡片背景 | `#FFFFFF` | 纯白 |

### 字体
- 正文：系统默认（-apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif）
- 价格数字：等宽对齐

### 圆角与阴影
- AI 气泡圆角：8rpx（左下角特殊处理）
- 用户气泡圆角：8rpx（右下角特殊处理）
- 菜品图片圆角：8rpx
- 输入框圆角：8rpx
- 头像圆角：24rpx（AI）/ 18rpx（消息内）
- AI 气泡阴影：`0 12rpx 34rpx rgba(70,42,26,0.1)`
- 用户气泡阴影：`0 12rpx 28rpx rgba(200,75,49,0.24)`

## 组件说明

### Header
- 固定顶部，z-index: 20
- 背景：`rgba(255,248,240,0.92)` + `backdrop-filter: blur(18rpx)`
- AI 头像：72rpx 方块，墨绿底白字"粤"
- 标题：34rpx 粗体墨绿色
- 副标题：24rpx 半透明

### 消息气泡
- AI 气泡：白色背景 + 阴影，最大宽度 596rpx
- 用户气泡：`#C84B31` 背景 + 白色文字，右对齐
- 消息间距：22rpx
- 自动滚动到最新消息

### 菜品卡片（内嵌在 AI 气泡中）
- 横向布局：左图右文
- 图片：136rpx 正方形，aspectFill
- 菜名：30rpx 墨绿粗体
- 价格：28rpx 朱红粗体
- 描述：24rpx 半透明灰
- 标签：22rpx 金色半透明药丸形
- 卡片间用细分隔线
- 总价行：虚线上边框，合计金额 32rpx 朱红粗体

### 思考动画
- 三个金色圆点弹跳动画（dotBounce keyframes）
- "正在思考" 文字脉冲效果
- 延迟错开：0s / 0.15s / 0.3s

### 输入栏
- 固定底部，z-index: 30
- 背景：`rgba(255,248,240,0.88)` + `backdrop-filter: blur(22rpx)`
- 输入框：白色背景，84rpx 高，圆角 8rpx
- 发送按钮：132rpx × 84rpx，朱红底白字
- 适配安全区域：`env(safe-area-inset-bottom)`

## 交互规范
- 发送消息后自动清空输入框 + 滚动到底部
- 思考期间禁用输入框和发送按钮
- 支持键盘回车发送（confirm-type="send"）
- 推荐失败时显示友好错误消息
- 每道菜的图片 URL 自动拼接 baseUrl 前缀
