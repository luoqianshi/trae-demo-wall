# 全球高端壁炉独立站

面向全球消费者、建筑师、室内设计师、酒店/地产项目方、经销商与安装商的高端壁炉品牌独立站。

本项目不是普通商品商城，而是一个融合 **高端品牌展示、国际电商、项目询价、专业资料中心与售后支持** 的 Headless Commerce 网站。体验以沉浸式品牌叙事建立价值感，以产品筛选、配置、技术资料和项目案例降低决策成本，再根据用户所在市场与产品条件，智能分流至在线购买、预约顾问、项目询价或当地经销商。

## 产品定位

核心体验围绕一句主线展开：**“从一束火，到一个空间的核心。”**

网站需要同时服务四种商业路径：

1. **Direct-to-Consumer**：对标准化、易运输且安装边界清晰的 SKU 开放在线购买。
2. **Consultative Commerce**：对高客单、可定制或需确认现场条件的产品提供配置、询价与预约顾问。
3. **Dealer-assisted Commerce**：按国家、地区或邮编导向授权经销商/安装商，并保留线索来源。
4. **Trade / Project Sales**：为建筑师、设计师、酒店、地产和商业项目提供技术选型、资料下载、批量报价与项目支持。

每个 SKU/配置必须根据市场规则返回明确状态：`BUY_ONLINE`、`QUOTE_REQUIRED`、`CONSULT_REQUIRED`、`DEALER_ONLY` 或 `NOT_AVAILABLE`。未开放市场不得显示无法兑现的购买承诺。

## MVP 范围

### 核心页面

- 首页：滚动定格帧叙事、产品路径、核心价值、主推产品、配置预览、工程可信度、项目案例与分流 CTA
- 产品列表/系列页：多维筛选、排序、地区可售状态和快速对比入口
- 产品详情页：媒体、价格/起售价、配置、适配检查、规格、安装、资料下载、购买/询价
- Product Finder：通过 6–10 个问题推荐并解释适配产品
- 项目案例：住宅、酒店、商业、户外案例列表与详情
- Technology：核心技术、安全、材料、控制、测试与认证信息
- Professionals：建筑师/设计师、酒店/地产、经销商/安装商入口
- Support：安装、操作、安全、维护、FAQ、保修与服务申请
- About：品牌故事、源头制造、研发、质量与可持续性
- 购物车与 Shopify 托管 Checkout
- 隐私、Cookie、条款、运输、退换、保修与可访问性政策页

### 首页模块

1. `S01 Hero`：产品从暗场显现、点火、火焰稳定、细节与完整空间；主 CTA“探索系列”，次 CTA“跳过动画”
2. `S02 产品路径`：按空间、安装方式或燃料进入，并提供 Product Finder
3. `S03 核心价值`：设计、火焰、制造、控制、安全与定制
4. `S04 Signature Products`：3–6 个主推产品
5. `S05 配置体验`：尺寸、可视面、材质与控制方式轻量预览
6. `S06 工程可信度`：认证、测试、研发、制造、质保与全球项目
7. `S07 项目案例`：住宅、酒店、商业与户外
8. `S08 分流 CTA`：购买、预约顾问、项目询价、专业客户或经销商

## 体验与视觉原则

- 高端极简、建筑感、编辑式排版；使用炭黑、暖灰、米白与克制的火焰橙/铜色高亮
- 真实火焰、高级材质与统一光照；避免廉价促销感、无意义炫技和通用模板感
- 大标题与短句叙事负责品牌表达，规格区保持高密度但结构清晰
- 沉浸式体验不能隐藏导航、价格、参数和转化路径
- 动画必须服务产品理解，页面保留原生滚动，并提供暂停/跳过及静态降级

## 推荐技术架构

- 前端：Next.js App Router + React + TypeScript
- 样式：Tailwind CSS 或 CSS Modules + Design Tokens
- Hero 动效：Canvas 2D 图像序列 + GSAP ScrollTrigger + `requestAnimationFrame`
- 3D：Three.js / React Three Fiber，仅在配置器确有自由旋转或材质切换需求时使用
- 商业后台：Shopify + Storefront API + Checkout + Markets
- 内容：Sanity（或 Contentful）
- 媒体：Cloudflare R2 + CDN/Images 或同等级服务
- 搜索：Algolia 或等效多语言搜索
- 部署：Vercel 或等价 Next.js 平台
- CRM：HubSpot、Zoho 或 Salesforce，按企业现有体系接入
- 数据：GA4 + GTM + Search Console + Web Vitals RUM

## 质量门槛

- Core Web Vitals P75：LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1
- 移动端首屏关键资源目标 ≤ 2.0 MB；首屏业务 JavaScript 尽量 ≤ 180 KB gzip
- 产品、系列、案例、技术与文章均有可索引 HTML；Canvas/视频不得承载唯一正文
- 关键用户路径达到 WCAG 2.2 AA，支持键盘、读屏、可见焦点和 `prefers-reduced-motion`
- 首帧优先；动画未加载完成或失败时，页面仍可阅读、滚动和点击
- 支付使用 Shopify 托管结账，前台不存储银行卡数据
- 市场、SKU、库存、运输与合规资格在结账前再次校验
- 所有询价与交易上下文包含来源、产品、配置、市场与语言

## 当前待确认项

以下内容必须由业务方确认后才能从占位数据切换为真实上线配置：

- 品牌正式名称、Logo、字体授权、品牌色与品牌故事
- 首发国家、语言、货币及各市场负责人
- 产品线、SKU、燃料、尺寸、选项、认证和安装限制
- 各 SKU 的在线购买/询价/顾问/经销商/不可售规则
- 海外仓、物流、关税、安装、交期、退换货与保修能力
- Shopify、ERP、CRM、PIM、物流、客服和邮件系统现状
- 经销商区域政策、线索归属与 B2B 价格规则
- 3D 模型、材质、工程图和滚动帧动画制作预算

在这些信息确认前，原型可以使用清楚标记的演示数据，但不得虚构认证、库存、价格、交期、经销商或“全球可售”承诺。
