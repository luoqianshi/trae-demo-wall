# 仙途 — Demo 开发 Prompt

## 项目概述

**仙途**是一款以修仙世界为舞台的游戏化任务管理应用。核心理念：**让无趣变得有趣，而非制造焦虑**。用户扮演修士，通过完成现实任务来修炼功法、提升境界，桌面常驻一只灵兽陪伴修行。

---

## Demo 范围（MVP 最小可用版本）

### 必做（P0）

1. **修士创建**
   - 输入道号（昵称）
   - 选择初始灵兽外观（至少 3 种可选）
   - 自动生成灵根属性（金木水火土，随机）

2. **三种任务类型 + 判定引擎**
   - **锻体任务**（外出/运动）：GPS 定位 + 步数验证，判定轨迹距离和步数是否达标
   - **炼神任务**（专注/冥想）：监测手机锁屏状态，违规次数阶梯判定完成度
   - **符修任务**（写作/记录）：键盘输入监测，统计有效输入时长和字数

3. **境界系统**
   - 炼气期 1-13 层（每层 100 历练点数）
   - 满层后触发筑基突破任务
   - 突破成功 → 筑基期，解锁新外观

4. **奖励结算**
   - 完成度 ≥ 80%：发放灵石 + 历练点数 + 属性点
   - 随机触发"顿悟"（暴击 ×2-5 倍）
   - 连击加成（连续 N 天修炼，灵石 × (1+0.1×N)）

5. **灵兽桌面精灵**（Electron）
   - 透明无边框窗口，始终置顶
   - 3 种动画状态：待机、修炼中、开心
   - 点击互动弹出对话气泡
   - 任务提醒通知

6. **修炼提醒**（替代惩罚）
   - 未完成任务 → 灵兽叹息表情（无实质惩罚）
   - 连击中断 → 灵兽友好提示
   - 连续 3 天未修炼 → 灵兽思念状态

### 不做（Demo 阶段）

- 联网功能（全部单机）
- 音修、丹修、阵修门类
- 手机 APP 和桌面挂件
- 功法装备系统
- 灵兽养成进化
- 成就系统

## 技术栈建议

| 层 | 推荐方案 | 备选 |
|----|---------|------|
| **桌面端框架** | Electron + React/Vue | Tauri（包体更小，但生态较新） |
| **移动端框架** | Flutter | React Native |
| **本地存储** | SQLite（electron-store 或 better-sqlite3） | IndexedDB |
| **精灵动画** | CSS Sprite Animation 或 Lottie | Canvas 逐帧 |
| **图表** | ECharts（修炼统计） | - |
| **传感器** | 通过 Electron 主进程调用系统 API | - |

---

## 关键设计决策（务必遵守）

1. **无惩罚原则**：不做任何数值惩罚（扣点数、扣属性等）。用户不修炼时，灵兽只会表现出思念，不会惩罚用户。
2. **传感器判定优先于手动打卡**：能用系统 API 判定的，不让用户手动勾选。
3. **修仙叙事 > 功能列表**：所有交互文案用修仙语言包装，"完成任务"写作"修炼结束"，"查看统计"写作"修行日志"。
4. **灵兽是情感锚点**：灵兽不是监督者，是陪伴者。对话语气温暖、幽默、偶尔调皮。
5. **历练点数非线性增长**：外出任务奖励远高于居家任务（×3.0），鼓励用户走出去。

## 建议开发顺序

### 第一阶段：核心骨架（1-2 周）
- Electron 项目骨架搭建
- 本地 SQLite 数据模型设计
- 修士创建页面
- 任务创建页面（3 种类型）
- 基础 UI 框架（修仙主题配色）

### 第二阶段：判定引擎（1-2 周）
- 锁屏状态监测（炼神判定）
- 键盘输入监测（符修判定）
- GPS + 步数判定（锻体判定，需移动端配合或模拟）
- 完成度计算与显示

### 第三阶段：奖励与境界（1 周）
- 历练点数计算（权重模型）
- 灵石系统
- 属性点分配
- 境界突破（炼气 1-13 层 → 筑基）

### 第四阶段：桌面精灵（1-2 周）
- 透明窗口 + 置顶
- 精灵动画（待机/修炼/开心）
- 点击交互（对话气泡）
- 任务提醒通知

### 第五阶段：打磨（1 周）
- 修炼统计图表（ECharts）
- 机缘系统（随机暴击）
- 新手引导（修仙叙事）
- UI 动效和音效

## 数据模型（核心表）

```
修士 (cultivator)
  - id, 道号, 灵根类型, 当前境界, 历练点数, 灵石数量
  - 根骨, 身法, 神识, 悟性, 道心, 气运
  - 灵兽类型, 创建时间

修炼记录 (cultivation_log)
  - id, 修士id, 门类, 任务类型, 计划时长, 实际时长
  - 完成度, 历练点数, 灵石, 属性变化
  - 开始时间, 结束时间

境界记录 (realm_log)
  - id, 修士id, 旧境界, 新境界, 突破时间, 道基品质

连击记录 (streak)
  - 修士id, 当前连击天数, 最后修炼日期
```
