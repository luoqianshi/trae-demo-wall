欢迎使用 gits 配置助手！

这是一个帮助你配置和使用 gits 工具的网页助手。gits 是一个多远程仓库管理工具，可以同时推送到多个 Git 远程仓库。

快速开始：

  • 下载对应平台的 gits 可执行文件
  • 将 gits 放入系统 PATH：
    • Windows: C:\Windows\System32
    • Linux/macOS: /usr/local/bin
  • 确保已安装 git 并可在命令行使用
  • 在仓库根目录创建配置文件 .git/gits.toml
  • 使用本页面编辑配置并生成推送命令

配置文件说明：

  • id: 远程仓库唯一标识（必填）
  • url: 远程仓库 URL
  • token: 认证 Token（优先于 password）
  • password: 认证密码
  • user: Git 用户名
  • email: Git 邮箱
  • ssh_key: SSH 私钥路径
  • default_branch: 默认推送分支

常用命令：

  • gits init - 生成配置模板
  • gits list - 列出所有远程
  • gits push - 交互式推送
  • gits push -a - 推送所有远程
  • gits push -m "msg" -b branch remote-id - 指定参数推送
