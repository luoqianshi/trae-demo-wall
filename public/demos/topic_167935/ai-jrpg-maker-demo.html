📖 游戏背景故事

在遥远的王国，美丽的艾琳公主在皇家花园中散步时，被四个凶狠的哥布林团团包围。公主被困在花园中央的石阵之中，生命危在旦夕。

就在这危急时刻，勇者（玩家）挺身而出！你的任务是消灭四个方向的哥布林，解救被困的公主。当你成功消灭所有怪物后，公主会对你的勇气表示赞赏，并任命你为皇家护卫团长！

🎯 游戏设计目标

  • 创建一张皇家花园地图（11x9）
  • 公主位于地图中央，被石阵保护
  • 四个哥布林分别位于东、南、西、北四个方向
  • 玩家从西侧入口进入，需要消灭所有怪物
  • 消灭怪物后与公主对话，获得"护卫团长"称号

🛠️ AI创作过程记录

1

创建地图 - 皇家花园

首先创建一张11x9的地图，命名为"皇家花园"。地图四周用树木作为边界，中间有十字形道路连接四个方向。

create_map garden "皇家花园" 11 9 创建地图：ID为garden，名称为"皇家花园"，宽11格，高9格

然后使用循环填充地形，设置边界树木、中心道路等。

2

设计地形 - 石阵保护公主

在地图中央设计一个石阵，将公主保护在中间。石阵留出四个缺口（门），方便玩家接近公主。

// 公主周围的石头圈（坐标以左上角为原点）
garden.grid[3][4] = 'stone';  // 左上
garden.grid[3][5] = 'stone';  // 上中
garden.grid[3][6] = 'stone';  // 右上
garden.grid[4][3] = 'stone';  // 左中
garden.grid[4][6] = 'stone';  // 右中
garden.grid[5][4] = 'stone';  // 左下
garden.grid[5][5] = 'stone';  // 下中
garden.grid[5][6] = 'stone';  // 右下

// 留出四个缺口作为入口
garden.grid[3][5] = 'door';   // 北门
garden.grid[4][4] = 'door';   // 西门
garden.grid[4][6] = 'door';   // 东门
garden.grid[5][5] = 'door';   // 南门
3

放置怪物 - 四面包围

在四个方向放置哥布林怪物，形成包围态势。怪物位置标记在地图上，玩家靠近时可触发战斗。

create_monster goblin_n "北方哥布林" 30 10 3 20 创建北方哥布林：HP=30, ATK=10, DEF=3, 击杀经验=20
create_monster goblin_s "南方哥布林" 30 10 3 20 创建南方哥布林（属性同上）
create_monster goblin_w "西方哥布林" 30 10 3 20 创建西方哥布林（属性同上）
create_monster goblin_e "东方哥布林" 30 10 3 20 创建东方哥布林（属性同上）

四个怪物数值相同，确保战斗难度均衡。每个怪物击杀后获得20经验，4个怪物共80经验，足够玩家升到2级。

4

创建NPC - 艾琳公主

在地图中央创建公主NPC，并添加两段对话：求救对话和胜利对话。

create_npc princess "艾琳公主" garden 5 4 在花园地图的(5,4)位置创建公主
求救对话（初始状态）
add_npc_dialog princess princess_01 "救命！我被怪物包围了...勇者，你能帮我消灭这些哥布林吗？" princess_02
add_npc_dialog princess princess_02 "我数了一下，一共有四个哥布林，分别在东、南、西、北四个方向。" princess_03
add_npc_dialog princess princess_03 "消灭它们之后，请回来找我，我有重要的事情要告诉你。" null
胜利对话（完成任务后）
add_npc_dialog princess princess_win_01 "太棒了！你竟然真的消灭了所有怪物！" princess_win_02
add_npc_dialog princess princess_win_02 "你的勇气和实力让我深深折服。作为公主，我任命你为皇家护卫团长！" princess_win_03
add_npc_dialog princess princess_win_03 "从今以后，你将守护我们的王国，我相信你一定能胜任这个职位！" null
5

设置游戏起点

将玩家起点设置在花园西侧入口位置。

set_game_start garden 1 4 设置游戏起点：花园地图的(1,4)位置

🎮 游戏玩法说明

目标

消灭四个方向的哥布林，然后与公主对话获得认可。

操作方式

  • look_map - 查看地图全貌
  • move right - 向右移动（靠近公主）
  • move up/down - 上下移动（寻找怪物）
  • debug_battle goblin_n - 与北方哥布林战斗
  • debug_battle goblin_s - 与南方哥布林战斗
  • debug_battle goblin_w - 与西方哥布林战斗
  • debug_battle goblin_e - 与东方哥布林战斗
  • talk princess - 与公主对话（需靠近）

战斗策略

玩家初始属性：Lv1, HP 100, ATK 10, DEF 5
每个哥布林：HP 30, ATK 10, DEF 3
预计每个哥布林需要3-4回合击败，击败后玩家会剩余约60-70 HP。
击败4个怪物后获得80经验，可以升级到Lv2（升级奖励：HP+20, ATK+3, DEF+2）。
