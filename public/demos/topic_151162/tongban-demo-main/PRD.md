## 1. 产品概述

### 1.1 产品简介

**瞳伴**是一款专为视障人士设计的智能出行导航应用，融合AI计算机视觉、语音交互和精准导航技术，帮助视障用户安全出行。

### 1.2 核心价值

- **安全保障**：盲道偏离检测、障碍物识别、危险区域预警
- **便捷操作**：全手势交互、语音控制、一键紧急求助
- **智能导航**：多模式路线规划、实时语音指引、最后一公里精细导航

### 1.3 设计理念

遵循Apple极简设计风格，采用毛玻璃效果、圆角卡片、柔和阴影，确保界面清晰易辨。

## 3. 页面详细需求

### 3.1 唤醒页（Wake Screen）

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 品牌展示 | 显示"瞳伴"品牌名称和标语 | P1 |
| 语音唤醒按钮 | 点击显示唤醒动画，播放"你好，瞳伴" | P0 |
| 搜索输入框 | 灰色圆角背景，搜索图标，"你要去哪里？"占位符 | P0 |
| 搜索覆盖层 | 点击搜索框打开搜索覆盖层 | P0 |
| 欢迎语音 | 包含当前位置广播 | P1 |

**交互逻辑**：
- 长按：位置播报
- 左滑：打开摄像头
- 点击搜索框：打开搜索覆盖层
- 点击语音按钮：语音唤醒

### 3.2 路线规划页（Route Planning）

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 起点/终点输入 | 支持文本输入和语音搜索 | P0 |
| 出行方式切换 | 步行、公交、打车、室内四种模式 | P0 |
| 路线卡片展示 | 时间、距离、路线说明、标签 | P0 |
| 路线选择 | 点击卡片选中（蓝色边框+蓝色背景） | P0 |
| 路线数量播报 | 切换模式时播报可用路线数量 | P1 |
| 危险标记检查 | 步行模式导航前检查路线危险标记 | P0 |

**出行方式说明**：
- **步行**：盲道导航+避障识别
- **公交**：302路、1号线、B1路、有轨电车等
- **打车**：网约车找车+车牌识别
- **室内**：商场/医院楼层导航

### 3.3 导航页（Navigation）

| 需求点 | 描述 | 优先级 |
|--------|------|--------|
| 实时导航指引 | 语音播报当前导航指令 | P0 |
| 进度显示 | 进度条+距离显示 | P0 |
| 暂停功能 | 控制面板按钮触发暂停 | P0 |
| 结束导航 | "结束导航"按钮+右滑手势 | P0 |
| 盲道偏离检测 | 摄像头开启时检测偏离，连续语音指引 | P0 |
| 路线偏离重算 | 偏离路线时自动重算并播报 | P0 |
| 最后一公里模式 | 85%进度时进入，步阶式指引 | P0 |
| 摄像头自动开启 | 步行导航开始即开启，其他模式按节点开启 | P0 |

**摄像头介入时机**：
| 模式 | 进度 | 识别内容 |
|------|------|----------|
| 步行 | 开始 | 盲道状态、障碍物、红绿灯 |
| 打车找车 | 30%-50% | 车牌识别、车门把手 |
| 公交上车 | 20%-40% | 车辆确认、上车门位置 |
| 地铁入口 | 5%-30% | 入口、闸机、电梯 |
| 室内入口 | 0%-30% | 入口、电梯 |

**交互逻辑**：
- 单击：播报当前进度，不暂停
- 双击：重播当前语音指令
- 长按：位置播报
- 左滑：打开摄像头
- 右滑：结束导航返回首页

## 8. 非功能需求

### 8.1 性能要求

- 页面切换响应时间 < 300ms
- 语音合成延迟 < 200ms
- 摄像头启动时间 < 1s

### 8.2 兼容性要求

- 支持iOS 13+
- 支持Android 8+
- 支持主流屏幕尺寸（390x844及以上）

### 8.3 安全要求

- 紧急求助数据本地存储，不上传云端
- 摄像头仅用于环境识别，不保存图像
- 位置数据加密传输
