# 瞳伴 (TongBan)

> TRAE AI 创造力大赛 · 社会服务赛道参赛作品

## 项目简介

瞳伴是一款面向视障人群的 AI 出行辅助 App。通过摄像头实时感知环境、结合地图导航，以**语音 + 手势双模态交互**为用户提供从出发到到达的完整出行引导。

**核心理念：不只是"识别到"，更要"送到终点"。**

## 手势交互

| 手势 | 功能 |
|------|------|
| 长按（>800ms） | 播报当前位置 / 导航状态 |
| 双击 | 重复上一条语音播报 |
| 短按 | 暂停 / 继续导航 |
| 左滑 | 打开 AI 摄像头辅助 |
| 右滑 | 切换出行方式 |
| 摇一摇 | 紧急求助 / 快速联系家人 |

## 技术栈

- React Native + Expo
- expo-camera（摄像头）
- expo-speech（语音合成）
- expo-location（定位）
- expo-haptics（震动反馈）
- expo-sensors（摇一摇检测）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npx expo start

# 用 Expo Go App 扫码预览（iOS/Android）
```

## 开发阶段

1. **第一阶段**：全语音导航 + 手势交互框架
2. **第二阶段**：AI 摄像头辅助（障碍物/盲道/门店识别）
3. **第三阶段**：多出行方式（公交/网约车/室内导航）
4. **第四阶段**：最后一公里引导 + 突发危险预警
