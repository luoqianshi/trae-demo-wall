# 寻剪 - AI视频人物片段自动剪辑工具

## 使用方法

### 方式一：直接打开（推荐）
1. 双击打开 `index.html` 文件
2. 现代浏览器（Chrome、Edge、Firefox）会直接运行
3. **无需任何服务器、无需配置环境**

### 方式二：本地服务器（可选）
```bash
# 需要 Node.js
node server.js
# 然后访问 http://localhost:8000
```

## 功能说明

1. **上传工作台**：上传视频文件 + 人物参考图片（最多6张）
2. **质量评分**：参考图自动评估质量，显示"推荐"/"可用"/"建议更换"标签
3. **AI检测**：使用 face-api.js 进行人脸识别，实时显示检测进度和日志
4. **结果页**：查看匹配片段，支持时间微调、全选、导出
5. **导出功能**：支持合并视频、单独片段ZIP、时间码CSV

## 技术特点

- 单文件 HTML，所有代码内联
- 支持 file:// 协议直接运行
- face-api.js 从 CDN 加载
- 所有计算在浏览器端完成
- 响应式设计，支持手机端

## 注意事项

- 需要网络连接（加载 face-api.js 模型）
- 推荐使用 Chrome 浏览器获得最佳体验
- 视频文件建议控制在 60 秒以内以获得更好的性能

## 文件清单

- `index.html` - 主程序文件
- `server.js` - 可选的本地服务器（如需通过 HTTP 访问）
