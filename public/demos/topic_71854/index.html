核心功能

🪑

智能座位匹配

输入体育场、区域、排数、座位号，快速定位座位位置，获取视野评分和周边限制因素信息。

🎥

第一人称3D视角

坐在选定座位的第一人称视角，模拟真实观演体验，视角限制在人眼正常视野范围内。

📊

视野评分系统

基于座位与舞台距离、楼层高度、遮挡因素等多维度计算视野评分，帮助评估座位质量。

🚧

限制因素标注

标注栏杆遮挡、过道、楼梯、柱子等影响观演体验的因素，提前了解座位周边情况。

🏟️

多场馆支持

已支持北京鸟巢、上海梅赛德斯奔驰文化中心、广州天河体育中心三大顶级场馆。

⚡

流畅交互体验

支持鼠标拖动旋转视角、滚轮缩放，响应式设计适配多种设备。

沉浸式3D全景体验

采用 Three.js 构建真实的3D体育场场景，用户可以从任意座位的视角观看舞台和周边环境。视角控制模拟真人头部转动，左右±135°、上下±75°，符合人眼正常视野范围。

React 18 TypeScript Three.js TailwindCSS Zustand Vite
