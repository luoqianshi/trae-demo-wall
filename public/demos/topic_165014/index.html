核心功能

四大模块形成学习闭环,从错题录入到知识掌握,一站式解决

📸

AI 智能错题整理

拍照上传试卷,PaddleOCR 自动识别题目文本,匹配课程与知识点标签。每分钟可录入 10+ 道错题,完全替代手抄。

🕸️

知识图谱可视化

纯 SVG 绘制 4 门计算机专业课 26 个知识点节点与 35 条关联连线,点击节点高亮关联知识点,直观呈现学习路径。

🤖

AI 智能问答

集成 DeepSeek 大模型,支持自然语言提问,针对错题和知识点提供个性化解答,非流式一次性返回,稳定可靠。

🎨

智能画布(亮点)

上传图片或 PPT 到画布,支持勾画、圈重点、文字批注、框选区域发起 AI 提问。把"看课件 → 划重点 → 问 AI"压缩到同一张画布。

开发流程总览

5 天完成全部开发,通过自然语言对话驱动

DAY 1
环境配置 + 项目骨架
在 TRAE 中生成开发规范、目录结构,搭建 Spring Boot 后端 + UniApp 前端骨架,配置 MySQL 数据源、JWT 拦截器、Knife4j 文档。
DAY 2
OCR 模块 + 错题 CRUD + AI 问答
通过 Runtime.exec 调用 PaddleOCR,实现拍照识别错题。遇到 PaddleOCR 3.x 兼容性 bug,在 TRAE 中排查降级到 2.7.x。集成 DeepSeek API 实现 AI 问答。
DAY 3
学情分析模块
纯 CSS+SVG 实现环形进度、柱状图、折线图、标签云,零依赖完成数据可视化。
DAY 4
知识图谱 + 自习室热力图
纯 SVG 绘制知识图谱节点连线,支持点击高亮关联。自习室热力图 5 级色阶渐变。
DAY 5
联调完善 + UI 美化
登录页动态流动背景,首页功能卡片布局,自定义 tabBar,11 个页面统一视觉规范(CSS 变量管理色值/圆角/阴影)。
新增
智能画布(用户追加需求)
Apache POI 渲染 PPT 为 PNG,Canvas API 实现勾画/批注/圈重点/区域提问。在 TRAE 中修复 5 个 POI 编译错误,解决 UniApp H5 canvas 兼容问题。

TRAE 使用心得

💬
对话即开发

从骨架生成到 Bug 修复,全程自然语言对话驱动,TRAE 自动完成文件创建、代码编辑、终端命令、编译验证闭环。

🧠
上下文记忆

TRAE 记住项目硬约束(如"仅用 MySQL,不上 Redis/Neo4j/ES"),避免反复说明。

📂
多文件协同

一次对话同时修改 controller/service/mapper/vue/js 多个文件,保持分层一致性。

🔧
错误自愈

编译失败后 TRAE 自动分析错误日志、定位问题、给出修复方案并应用,大幅缩短调试时间。

踩坑记录

⚠️ PaddleOCR 3.x 存在 PIR+OneDNN 兼容性 bug,需降级至 2.7.x
⚠️ UniApp H5 下 canvas 被编译成 uni-canvas,需 querySelector 找内部真实 canvas
⚠️ Apache POI 的 Shape 类与 java.awt.Shape 歧义,需用全限定名
⚠️ UniApp static 目录 必须在项目根目录,不能放在 src/static/
⚠️ Vite 需配置 publicDir: 'static' 才能识别 UniApp 静态资源
