功能说明 · 诚实分摊
为避免误导评委，这里说明每个功能的实现状态。
当前 Demo 已真实实现
  • 手动填写停车场、入口、楼层、区域、车位号、附近标志、备注
  • 必填项校验、组合位置实时预览（如 B2 · B 区 · 138）
  • 自动记录保存时间
  • 一键填入“星河广场”演示数据
  • 从相册选择图片，本地 Canvas 压缩（10MB 上限）
  • 调用浏览器原生定位（navigator.geolocation）
  • 所有数据保存在浏览器 localStorage，不上传服务器。清除浏览器数据后记录会消失
  • 历史记录管理：查看、编辑、设为当前、删除、归档
  • 简洁大字模式（本机记忆）
  • 调用浏览器原生分享 / 剪贴板降级
  • 断网检测、记录已删除、存储失败等异常状态提示
当前通过固定数据模拟
  • 停车场示意图（L1 + B2）为固定 SVG 矢量图，非真实地图
  • 导航路线为预置的 7 步固定路径（概念路线）
  • “步行距离 180 米 / 约 3 分钟”是示例数据，非实际测量
  • 蓝色脉冲点表示用户位置，由步骤推进，非真实 GPS 实时跟踪
  • 橙色车辆图标为演示标记，非车辆真实坐标
  • 楼层切换（L1 → B2）为预置步骤，不读取真实室内定位
  • “偏离路线 / 重新规划”需通过演示控制面板手动触发
  • “停车照片”默认使用示例概念图，可手动上传替换
  • 预置的演示记录用固定时间戳，保证重置后状态一致
未来需要外部支持（本 Demo 不含）
  • 真实地图与路径：接入高德/百度等地图 SDK
  • 真实室内定位：接入停车场蓝牙信标 / Wi-Fi 指纹 / UWB 等室内定位系统
  • 实时位置跟踪：需要持续 GPS 信号或停车场硬件支持
  • 车辆鸣笛 / 闪灯 / 远程控制：需要车企开放车机 API（本 Demo 不模拟此能力）
  • AI 识别车牌 / 自动识别停车区域：需要图像识别模型（本 Demo 不含）
  • 云同步 / 跨设备共享车位：需要后端服务器与账号体系（本 Demo 不含）
  • 实时分享位置给家人：需要服务器中转（本 Demo 分享仅复制文字）
  • 多停车场路线数据：需要接入停车场运营商数据
诚实标注：所有模拟内容均会显示“演示数据”“概念路线”“示例预计时间”“浏览器定位”等标签，不会伪装成真实能力。
