# 幽灵会议 GhostCall — 使用说明

> 零服务器 · 零账号 · 零痕迹 — P2P 视频通话，加入即消失

---

## 一、快速开始（30 秒上手）

### 方式 A：双击启动（最简单）

1. 双击 `start.bat`
2. 浏览器自动打开，输入昵称和房间名，点击"进入房间"
3. 把浏览器地址栏的链接发给对方，对方打开后即可视频通话

### 方式 B：单文件运行（无需安装 Node.js）

1. 运行 `npm run build` 生成 `ghostcall.exe`
2. 双击 `ghostcall.exe`
3. 浏览器自动打开
4. 同上

### 方式 C：命令行

```bash
node server.js
```

浏览器打开 http://localhost:8080 即可。

## 二、邀请别人加入

### 局域网内（同一 WiFi）

1. 在你的电脑上打开 PowerShell，执行 `ipconfig`，找到你的 IPv4 地址（如 `192.168.1.100`）
2. 把链接 `http://192.168.1.100:8080/?room=你的房间名` 发给同事
3. 对方浏览器打开即可通话

> 如果对方无法连接，需要在 PowerShell（管理员）中放行防火墙：
> ```powershell
> New-NetFirewallRule -DisplayName "GhostCall" -Direction Inbound -Port 8080 -Protocol TCP -Action Allow
> ```

### 公网（不在同一网络）

1. 从 [Cloudflare](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 下载 `cloudflared-windows-amd64.exe`
2. 把它放在 `ghostcall.exe` 同一目录下
3. 重启 `start.bat` 或 `ghostcall.exe`（server 会自动启动 tunnel）
4. 进入房间后，点击"复制链接"（或按 L 键），链接中包含 `trycloudflare.com` 公网地址
5. 把这个链接发给对方即可

## 三、房间功能

### 密码保护

创建房间时在"密码"栏输入密码。后续加入者必须输入正确密码才能进入。

### 主持人

- 第一个加入房间的人自动成为**主持人**（标记为皇冠图标）
- 主持人可以点击工具栏的"踢人"按钮，选择要移出的成员
- 主持人离开后，资格自动转让给房间内下一个成员

### 工具栏功能

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 麦克风 | 开启/关闭麦克风 | M |
| 摄像头 | 开启/关闭摄像头 | V |
| 屏幕共享 | 共享你的屏幕 | S |
| 复制链接 | 复制邀请链接到剪贴板 | L |
| 踢人 | 弹出成员列表选择踢出（仅主持人） | — |
| 离开 | 退出房间 | — |
| 全屏 | 双击任意视频卡片 | — |

### 状态栏

加入房间后，底部状态栏显示：
- **左侧**：连接状态（绿色=已连接，黄色=重连中，红色=已断开）
- **中间**：LAN IP 地址（自动检测，如 `LAN: 192.168.1.100`），方便告知局域网内其他人
- **右侧**：实时网络统计（丢包率、码率）

## 四、网络不佳时

系统会自动检测网络质量：

- 丢包率 > 2%：自动降低视频码率至 200kbps
- 丢包率 > 10%：进一步降至 80kbps
- 网络恢复后自动提升画质

如果仍然卡顿，可以手动关闭摄像头，使用纯音频模式。

## 五、高级配置

### 修改端口

默认端口 8080。如需修改：

```bash
set PORT=3000
node server.js
```

或修改 `start.bat`，在 `node server.js` 前加一行 `set PORT=3000`。

### 自定义 TURN 服务器

默认使用 Google STUN，在大多数网络下可用。如果双方都在严格 NAT 后面（如公司网络），需要配置 TURN 服务器。

**方式一：URL 参数**
```
http://localhost:8080/?room=test&turnUrl=turn:your-server:80&turnUser=user&turnPass=pass
```

**方式二：申请免费 TURN**

前往 [Metered CA](https://www.metered.ca/tools/openrelay/) 免费申请，然后将凭据填入 URL 参数。

### 获取公网分享链接（API）

如果服务器已启动 Cloudflare Tunnel，可通过 API 获取公网 URL：

```bash
curl https://localhost:8080/api/tunnel-url
# 返回: {"tunnelUrl":"https://xxx-xxx.trycloudflare.com"}
```

### 单文件分发

`ghostcall.exe` 已内嵌证书和前端页面，可脱离 `certs/` 目录独立运行。直接复制 EXE 到任意位置双击即可。

## 六、安全说明

| 特性 | 说明 |
|------|------|
| 无注册 | 不需要账号，输入昵称即可 |
| 无持久化 | 房间数据仅存于内存，关闭服务器即清空 |
| 端到端加密 | WebRTC DTLS 加密，服务器无法窃听 |
| 密码保护 | PBKDF2-SHA512 100000 次迭代哈希 |
| 防滥用 | IP 限速（30 次/10 秒）+ Origin 白名单校验 |

## 七、常见问题

**Q: 双击 start.bat 闪退？**
A: 可能是端口 8080 被占用，或 Node.js 未安装。打开 PowerShell 手动执行 `node server.js` 查看具体错误。

**Q: 浏览器无法开启摄像头？**
A: 点击浏览器地址栏左侧的锁图标，允许"摄像头"和"麦克风"权限。`localhost` 被浏览器视为安全上下文，权限设置会保留。

**Q: 对方听不到我的声音 / 看不到我的画面？**
A: 确认工具栏中麦克风/摄像头按钮未被静音。如果网络双方都在企业 NAT 后面，需要配置 TURN 服务器（见第五节）。

**Q: 想重新打包 ghostcall.exe？**
A: 执行 `node build.js`，需要 Node.js 20+。

**Q: 支持多少人同时通话？**
A: 理论上无上限，采用 Mesh P2P 架构（每人与其他所有人直连）。建议 6 人以内体验最佳，超过 8 人建议使用 SFU 架构的方案。
