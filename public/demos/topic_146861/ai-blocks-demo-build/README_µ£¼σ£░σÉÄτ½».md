# AI积木编程 - 本地后端配置

## 快速开始

### 1. 安装依赖

```bash
cd /Users/zhongcheng/Desktop/AI积木编程
npm install
```

### 2. 配置API Key

复制配置文件：

```bash
cp env配置示例.txt .env
```

然后编辑 `.env` 文件，填入你的火山引擎 API Key：

```
ARK_API_KEY=你的API密钥
```

**获取方式：**
1. 访问 [火山引擎控制台](https://console.volcengine.com/)
2. 注册/登录账号
3. 找到「火山方舟」或「API Key管理」
4. 创建一个新的 API Key
5. 在控制台中开通「豆包大模型」服务

### 3. 启动后端服务

```bash
npm start
```

看到以下信息表示启动成功：

```
╔═══════════════════════════════════════════════════╗
║         AI积木编程 - 本地后端服务                  ║
╠═══════════════════════════════════════════════════╣
║  状态: ✅ API Key 已配置
║  端口: http://localhost:3000
╚═══════════════════════════════════════════════════╝
✨ 服务已启动: http://localhost:3000
```

### 4. 打开前端

双击打开 `AI积木编程_Demo.html`，然后点击右下角的 🤖 按钮开始使用AI助手。

## 故障排除

### 后端连接失败

如果看到以下提示：

```
⚠️ 后端服务未启动，请运行: npm start
```

**解决方法：**
1. 确保后端服务已启动（终端中看到"✨ 服务已启动"）
2. 确保端口3000没有被占用

### API Key无效

如果提示"API Key无效"或调用失败：

1. 检查 `.env` 文件中的 Key 是否正确
2. 确认已在火山引擎控制台开通了豆包大模型服务
3. 确认 Key 没有过期或被禁用

### 查日志

后端服务会在终端输出详细日志：

```
📨 收到请求: 让小猫走路
📨 AI回复: {...}
```

## 常见问题

**Q: 需要一直开着后端吗？**

**Q: 关闭后端会怎样？**
A: 会自动切换到本地模拟回复，但无法使用真正的AI能力。

**Q: API调用收费吗？**
