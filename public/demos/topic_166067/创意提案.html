一扫就会用

面向老年人的家电使用指导工具

🎯项目背景

随着科技的发展，家用电器越来越智能化，但对于60岁以上的老年人来说，复杂的操作界面和说明书让他们望而却步。

据统计，我国60岁以上老年人超过2.8亿，其中大部分不会熟练使用洗衣机、空调、微波炉等常见家电。他们面临着：

  • 看不懂复杂的说明书
  • 记不住不同家电的操作步骤
  • 害怕按错按钮导致危险
  • 子女不在身边时不知道问谁

💡产品理念

「一扫就会用」致力于把复杂的家电说明书，转化为老人看得清、听得懂、能跟着做的一步一步操作指导。

核心价值：围绕老人真实生活场景，比如"我要洗衣服""我要热饭"，直接告诉老人下一步怎么做。

✨核心功能

📷

扫码识别

扫描家电二维码，快速获取操作指导

📖

分步指导

一屏一步，大字清晰，避免信息过载

🔊

语音朗读

点击按钮，语音朗读当前步骤

👨‍👩‍👧

家属求助

遇到困难时，一键联系家人求助

🔄使用流程

1

打开应用

老人打开「一扫就会用」App

2

扫码或选择

扫描家电二维码，或直接选择家电类型

3

选择任务

选择要完成的任务，如"洗日常衣服"

4

跟随指导

按照分步指导操作，可播放语音辅助

5

完成操作

完成所有步骤，家电开始工作

🏠支持家电

  • 滚筒洗衣机：洗日常衣服、洗被单、单独脱水、清洁洗衣机
  • 空调：打开制冷、调高温度、调低温度、关闭空调
  • 微波炉：热米饭、热汤、解冻食物、安全注意事项

🎨设计特点

  • 大字显示（正文不小于20px），方便老人阅读
  • 大按钮设计，适合手指点击
  • 高对比度配色，清晰易辨
  • 页面不拥挤，留白充足
  • 每个页面保留明显的返回按钮
  • 适合手机竖屏展示

📱技术实现

  • 前端框架：React 19 + TypeScript
  • 构建工具：Vite 6
  • 样式：Tailwind CSS 3
  • 语音：浏览器原生 SpeechSynthesis API
  • 数据：本地 Mock 数据，无需后端

🎯项目目标

让每一位老年人都能轻松使用家用电器，享受科技带来的便利生活。
