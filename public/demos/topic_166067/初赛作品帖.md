## 二、产品简介

### 2.1 产品定位

「一扫就会用」是一款面向60岁以上老年人的家电使用指导工具，致力于把复杂的家电说明书转化为老人看得清、听得懂、能跟着做的一步一步操作指导。

### 2.2 核心价值

- **扫码即用**：扫描家电二维码，快速获取操作指导
- **分步指导**：一屏一步，大字清晰，避免信息过载
- **语音朗读**：点击按钮，语音朗读当前步骤
- **家属求助**：遇到困难时，一键联系家人求助

### 2.3 解决的痛点

1. 老年人看不懂复杂的家电说明书
2. 记不住不同家电的操作步骤
3. 害怕按错按钮导致危险
4. 子女不在身边时不知道问谁
5. 智能家电功能太多，界面不够直观

## 四、设计特点

### 4.1 适老化设计

- **大字显示**：正文不小于20px，标题使用32-48px
- **大按钮设计**：按钮高度不小于60px，适合手指点击
- **高对比度配色**：使用蓝色、绿色、暖橙色为主色调
- **页面不拥挤**：充足留白，信息层次分明
- **明显的返回按钮**：每个页面都保留返回按钮
- **手机竖屏优先**：适配手机端展示

### 4.2 交互体验

- 点击反馈：按钮点击时有缩放效果
- 语音状态：播放语音时有脉冲动画指示
- 扫描动效：扫码页面有扫描线动画
- 高亮提示：当前要按的按钮会高亮显示

## 五、技术实现

### 5.1 技术栈

- **前端框架**：React 19 + TypeScript
- **构建工具**：Vite 6
- **样式**：Tailwind CSS 3
- **语音**：浏览器原生 SpeechSynthesis API
- **数据**：本地 Mock 数据，无需后端

### 5.2 项目结构


## 八、作品亮点

1. **专注适老化**：从字体大小、按钮尺寸、配色方案到交互设计，全部围绕老年人使用习惯
2. **场景化指导**：不是展示完整说明书，而是围绕"我要洗衣服""我要热饭"等真实场景
3. **语音辅助**：使用浏览器原生语音合成，帮助视力不佳的老人
4. **家庭协同**：家属求助功能让子女可以远程指导老人操作
5. **无需后端**：纯前端实现，使用Mock数据，方便比赛演示和部署
6. **扫码体验**：模拟扫码流程，展示产品的核心交互方式
