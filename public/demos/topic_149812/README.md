# QualiFlow — 制造质量智能管理平台

> Manufacturing Quality Intelligence Platform v3.1
>
> 当前版本为前端交互原型，所有数据为模拟数据

面向制造业生产线与实验室全流程的质量智能管理平台。覆盖交接班管理、安灯升级、测试管理、设备监控、质量分析、SOP随行、审计追溯等全链路场景。前端交互原型 + API 抽象层，生产部署通过 API 对接 MES/SCADA/ERP 后端。

---

## 快速开始

直接用浏览器打开 `index.html` 即可运行，无需任何构建工具或服务器。

如果需要本地服务器（推荐，以避免浏览器 CORS 限制）：

```bash
# Python 3
python3 -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`

## v3.1 核心升级 — 30年现场管理者视角

### 设计理念

v3.1 由具备 30 年制造业现场管理经验的视角审阅重构，核心目标：

- **现场操作人员的高操作性**：减少操作步骤，关键信息触手可及，异常即时升级
- **管理人员的高监控性**：全局可视、跨线对比、成本透明、全程可溯

### 新增功能矩阵

| 功能 | 所在页面 | 面向角色 | 解决的现场痛点 |
|------|----------|----------|----------------|
| **交接班面板** | 首页 | 操作员/班组长 | 班次交接信息遗漏、责任不清 |
| **安灯升级系统** | 首页/监控 | 操作员/班组长/工程师 | 异常上报靠喊、响应无时限、升级无追踪 |
| **班次绩效对比** | 首页/监控 | 车间主任 | 白班夜班差异不可见、无法定位瓶颈班次 |
| **停机Pareto分析** | 监控/设备 | 设备主管/厂长 | 停机原因不透明、改善无抓手 |
| **扫码录入** | 测试管理 | 操作员 | 手工录入易错、效率低 |
| **响应时效追踪** | 测试管理 | 班组长/质量主管 | 异常处理拖沓、无SLA约束 |
| **SOP随行链接** | 测试管理 | 操作员 | 操作时找不到SOP、标准执行率低 |
| **跨线OEE对比** | 设备管理 | 厂长/生产总监 | 各线绩效不可比、资源分配凭感觉 |
| **COQ质量成本** | 质量分析 | 质量总监/财务 | 质量成本不透明、改善投入无依据 |
| **班次FPY对比** | 质量分析 | 质量主管 | 无法区分班次质量差异、夜班质量隐患 |
| **操作审计追溯** | 报告中心 | 质量主管/合规 | ISO审核无追溯链、操作不可回溯 |
| **班次实时标识** | 全局顶栏 | 所有人 | 不清楚当前班次状态、跨班操作混乱 |

## 功能模块详解

### 1. 首页总览 (index.html)

**v3.0 新增：**
- **交接班面板**：三栏布局（上一班次总结 / 当前班次状态 / 待交接事项清单），确保班次切换零信息遗漏
- **安灯升级按钮**：快捷操作区首位，一键触发安灯，自动通知班组长和产线工程师，5分钟响应倒计时
- **班次绩效对比**：白班A vs 夜班B，5维度对比（产量/FPY/OEE/不良品/停机时长），差异一目了然

**原有功能：**
- 全局 KPI 看板：吞吐量、在测样品、设备稼动率、不良品数
- 6 大功能模块导航卡片
- 产线 A/B/C/D 实时产能进度
- 实验室 HALT/HASS/环境/可靠性/材料分析占用率
- 实时动态流（设备告警、测试进度、环境异常）

### 2. 实时监控 (dashboard.html)

**v3.0 新增：**
- **安灯动态Feed**：实时展示安灯升级记录，含产线/异常类型/响应状态/响应时间徽章，超时自动标红
- **停机分析面板**：5类停机原因Pareto（设备故障45%/换线换型25%/物料等待15%/品质异常10%/人员缺岗5%），总停机时长 vs 目标值对比
- **班次绩效对比**：7天平均数据，白班 vs 夜班5维度（产量/FPY/OEE/停机/异常响应时间）

**原有功能：**
- 生产线/实验室双视图切换
- 24小时产能趋势 SVG 折线图
- 产线实时状态表格（进度条 shimmer 动画）
- 关键设备迷你状态网格
- 车间环境监测（温湿度径向仪表盘）

### 3. 测试管理 (test-management.html)

**v3.0 新增：**
- **扫码录入面板**：模拟条码扫描枪录入样品编号，一键扫码+SOP快速链接，减少手工录入
- **响应时效列**：测试队列新增响应时效列，每条记录标注响应时间徽章（绿色=达标/黄色=接近超时/红色=已超时）
- **异常处理时效面板**：7项时效指标（平均响应/最快响应/超时率/达标率等），超时阈值预警
- **SOP随行面板**：7个SOP快速链接（FCT操作规范/ICT测试规范/异常处理流程/首件检验规范等），操作时一键查阅

**原有功能：**
- 4 KPI + 筛选栏 + 12行测试队列表格
- 测试类型分布 SVG 环形图
- 样品生命周期追踪（6阶段水平stepper）
- 测试排程甘特图（7台设备时间轴）

### 4. 设备管理 (equipment.html)

**v3.0 新增：**
- **停机Pareto分析**：6大停机原因排名（设备故障/换线换型/物料等待/品质异常/人员缺岗/计划停机），总停机1,085分钟，Pareto 80%基准线
- **跨线OEE对比表**：产线A/B/C/D/全厂OEE对比，含可用率/性能率/质量率三维度，最佳线绿色高亮、最差线红色标注

**原有功能：**
- 4 KPI + 10台设备状态卡片（SVG圆环OEE）
- 状态筛选器 + 校准计划表格（11行）
- 维护记录时间线（8条）
- OEE综合效率分析 SVG 柱状图

### 5. 质量分析 (quality.html)

**v3.0 新增：**
- **COQ质量成本面板**：4类质量成本分析（预防成本¥42.5K / 鉴定成本¥68.3K / 内部故障¥75.6K / 外部故障¥50.2K），总成本¥236.6K = 销售额2.1%，行业基准对比

**原有功能：**
- 4 KPI（FPY/Cpk/不良率/首件合格率）

- Pareto 缺陷排列图（8类缺陷+80%基准线）

## 系统架构

### 当前架构：前端交互原型

QualiFlow 当前为前端交互原型，所有展示数据通过内置 MockAPI 提供，无需后端服务即可独立运行。页面中的 KPI、图表、表格数据均为模拟数据，用于演示 UI 交互与视觉设计。

### 生产部署架构

生产部署时，前端通过 REST API 对接 MES / SCADA / ERP 等后端业务系统，实现真实数据采集与展示。

```
┌─────────────────────────────────────────────────────┐
│                   前端 (QualiFlow)                    │
│   HTML + CSS + JavaScript + shared.js (API抽象层)    │
│         MockAPI (演示模式) ↔ RealAPI (生产模式)       │
└──────────────────────┬──────────────────────────────┘
                       │ REST API / WebSocket / MQTT
┌──────────────────────▼──────────────────────────────┐
│                    后端服务层                        │
│   Node.js / Python / Java (REST API 服务)           │
│   WebSocket / MQTT (实时数据推送)                    │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│                    数据层                            │
│   MySQL / PostgreSQL (业务数据)                     │
│   Redis (缓存 / 会话 / 实时状态)                     │
└─────────────────────────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│                  部署与运维                          │
│   Docker / Kubernetes (容器化编排)                   │
└─────────────────────────────────────────────────────┘
```

### API 双层切换机制

`assets/js/shared.js` 中已内置 MockAPI / RealAPI 双层切换，切换方式：

- **演示模式 (IS_DEMO_MODE = true)**：使用内置模拟数据，无需后端，开箱即用
- **生产模式 (IS_DEMO_MODE = false)**：对接真实后端 API，数据实时采集

只需修改 `shared.js` 中的 `CONFIG.IS_DEMO_MODE` 配置项即可完成切换，前端代码无需任何改动。

### 后端技术栈建议

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| API 服务 | Node.js / Python / Java | RESTful API，提供业务数据接口 |
| 实时通信 | WebSocket / MQTT | 设备状态、安灯、告警实时推送 |
| 数据库 | MySQL / PostgreSQL | 业务数据持久化存储 |
| 缓存 | Redis | 会话管理、实时状态缓存、限流 |
| 容器化 | Docker / Kubernetes | 微服务编排与弹性伸缩 |
