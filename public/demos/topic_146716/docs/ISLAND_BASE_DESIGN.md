# 孤岛基地系统设计文档

## 概述

孤岛基地是沙漠地图20波防御完成后的新剧情线。完整链路如下：

```
沙漠20波完成 -> 直升机剧情 -> 孤岛基地 -> 安全区探索 -> 渔夫NPC接捕鱼任务 -> 捕鱼2D小游戏 -> 交付任务触发变异 -> 研究员NPC对话推进剧情 -> 基地升级系统 -> 潜艇深海探险2D游戏(5关+BOSS战) -> 击败BOSS触发毒雾沼泽 -> 新地图
```

## 触发条件

- 完成沙漠地图20波防御
- 触发剧情：直升机救援到达提示
- 玩家选择前往孤岛基地

## 核心系统架构

### 1. 剧情触发系统 (island-story.js)

```
沙漠20波完成 -> 显示剧情面板 -> 直升机到达动画 -> 玩家上直升机 -> 飞行动画 -> 降落孤岛
```

**关键剧情节点：**
- 20波完成后，NPC广播："直升机救援已到达，请前往撤离点"
- 玩家走到直升机位置，按F进入
- 直升机起飞动画（camera移动 + 音效）
- 加载孤岛基地场景

### 2. 孤岛基地场景 (island-base.js)

**场景描述：**
- 海上孤岛，四面环海
- 现代化军事基地，高墙林立
- 安全区：没有僵尸和怪物

**地面高度：**
- 岛屿网格（island mesh）的 `position.y = 0`（之前为 -0.5），所有建筑均放置在 `y = 0` 平面
- 玩家相机起始高度为 `y = 1.7`
- 基地内部地面完全平整，无高低起伏

**NPC配置：**
- 6个巡逻NPC士兵：按预设路线巡逻，玩家靠近时停止并转向玩家，触发对话
- 1个渔夫NPC（老陈）：位于码头小屋附近，负责捕鱼任务
- 1个研究员NPC：鱼类变异剧情触发后出现在指挥中心附近，推进后续剧情

**NPC模型：**
- 老陈（渔夫NPC）采用像素块风格建模，基于 `BoxGeometry` 构建，具备完整的骨骼层级：
  - 头部组（Head）：包含帽子和眼睛细节
  - 身体（Body）：`BoxGeometry` 构成的主躯干
  - 左/右肩组（ShoulderL/ShoulderR）：连接手臂网格
  - 左/右髋组（HipL/HipR）：连接腿部与鞋子网格
  - 鱼竿组（Rod）：挂载于右肩，包含竿身和渔线
  - 待机动画：呼吸起伏、头部微动、手臂自然摆动、鱼竿轻微晃动
  - 行走动画：通过髋部与肩关节联动实现迈步动作
- 士兵NPC同样采用像素块风格（`BoxGeometry` 为基础）。

**建筑列表（6个）：**
| 建筑 | 位置 | 说明 |
|------|------|------|
| 指挥中心 | 中央 (0, 0, -20) | 大型建筑，带天线和红灯 |
| 兵营 | 两侧 (±35, 0, -10) | 长条形建筑，左右各一 |
| 停机坪 | (-30, 0, 20) | 圆形平台，带H标记 |
| 雷达站/瞭望塔 | 四个角落 | 带探照灯 |
| 码头 | (0, 0, 75) | 延伸到海中的平台，带支柱 |
| 码头小屋 | (8, 0, 72) | 渔夫NPC位置，带渔具标志 |

**围墙系统：**
- 四面高墙围绕基地，正面设大门
- 玩家碰撞检测，防止穿墙

**碰撞系统：**
- 使用手动碰撞器注册系统。代码通过 `addCollider()` 以精确坐标逐个注册 Box3 碰撞体，替代了之前基于 `_registerBox3Collider` 的自动注册方式（后者在处理旋转圆柱时会产生过大的 AABB 包围盒）。
- 基地内共注册 17 个碰撞器，明细如下：
  - 围墙：5 个（北墙、南墙左侧、南墙右侧、西墙、东墙）
  - 指挥中心：1 个
  - 兵营：2 个（左右各一）
  - 碉堡：4 个
  - 瞭望塔：4 个
- 南墙在大门处留空：x 坐标 -12 到 +12 区域不设碰撞器，形成可通行的入口。

**NPC对话系统：**
- 士兵NPC：固定对话，无任务功能
- 渔夫NPC（老陈）：4状态任务机
  - `not_started`：可接受捕鱼任务
  - `active`：可进入捕鱼游戏
  - `completed`：可交付任务（需先完成捕鱼）
  - `delivered`：可打开升级面板或再次捕鱼
- 研究员NPC：5状态剧情机
  - `not_started`：未触发
  - `discovered`：发现鱼类变异
  - `investigating`：分析变异样本
  - `briefing`：派出侦察队，准备深海任务
  - `ready`：可进入潜艇深海探险

### 3. 捕鱼任务系统 (fishing-game.js)

**渲染方案：** 完全独立的Canvas 2D渲染，800x600，不干扰Three.js主场景

**玩家控制：**
- 鼠标移动控制潜艇水平位置
- 左键发射武器
- 滚轮切换武器
- 键盘A/D或方向键也可左右移动

**3种武器：**
| 武器 | 弹药 | 特性 |
|------|------|------|
| 渔网 | 50发 | 直接捕获，命中即带走鱼类 |
| 鱼雷 | 5发 | 穿透伤害，带重力下沉效果 |
| 声呐 | 2发 | 范围扩散，过期时造成范围伤害 |

**3种技能（Q/W/E）：**
| 技能 | 按键 | 效果 |
|------|------|------|
| 冰冻 | Q | 全场冻结3秒 |
| 轰炸 | W | 全屏伤害（所有鱼HP-3） |
| 加速 | E | 攻速提升5秒，按住鼠标自动连射 |

**5种鱼类：**
| 鱼类 | 分值 | HP | 移动模式 |
|------|------|-----|----------|
| 小鱼 | 10 | 1 | 直线 |
| 中型鱼 | 25 | 2 | 正弦波 |
| 大型鱼 | 50 | 3 | 锯齿形 |
| 稀有鱼 | 100 | 1 | 快速直线 |
| 深海鱼 | 200 | 5 | 深水慢速 |

**游戏规则：**
- 60秒倒计时
- 连击奖励：每捕获10条鱼额外+50分
- ESC或点击退出，返回基地交付任务
- 结果保存在 `window.lastFishingResult`

### 4. 鱼类变异剧情（集成在island-base.js中）

**触发条件：** 交付捕鱼任务后5秒自动触发

**剧情流程：**
1. 交付任务后，系统延迟5秒弹出警告提示
2. `mutationQuestState` 从 `not_started` 变为 `discovered`
3. 研究员NPC在指挥中心附近生成
4. 玩家与研究员对话，推进4个阶段：
   - `discovered` -> `investigating`：分析变异样本
   - `investigating` -> `briefing`：派出侦察队
   - `briefing` -> `ready`：接受深海任务
   - `ready`：可进入潜艇深海探险

### 5. 海上基地升级系统（集成在island-base.js中）

**4个升级项：**
| 升级项 | 范围 | 费用 |
|--------|------|------|
| 武器等级 | 1-5 | 100/200/400/800 |
| 装甲等级 | 1-5 | 100/200/400/800 |
| 辅助潜艇数量 | 0-4 | 300/500/800/1200 |
| 辅助武器等级 | 1-3 | 150/300 |

**货币系统：** 使用分数作为货币（捕鱼分数 + 潜艇探险分数）

**UI：** 升级面板为覆盖层，显示当前等级、下一级效果、费用和升级按钮

**效果：**
- 武器升级：影响潜艇游戏发射模式（单发/双发/三发散射）和伤害
- 装甲升级：增加玩家血量上限
- 辅助潜艇：随行自动攻击的友方潜艇
- 辅助武器：提升辅助潜艇伤害

### 6. 潜艇深海探险 (submarine-game.js)

**渲染方案：** 完全独立的Canvas 2D渲染，800x600

**5个关卡：**
| 关卡 | 名称 | 敌人数量 | 背景色调 |
|------|------|----------|----------|
| 1 | 浅海区域 | 8 | #001a33 -> #003366 |
| 2 | 中层海域 | 12 | #001122 -> #002244 |
| 3 | 深海区域 | 15 | #000a1a -> #001133 |
| 4 | 深渊地带 | 18 | #000511 -> #000a22 |
| 5 | 病毒源头 | BOSS战 | #0a0000 -> #1a0000 |

**操作方式：**
- WASD/方向键移动
- 鼠标瞄准
- 左键按住自动连射
- ESC退出

**5种敌人：**
| 敌人 | 移动模式 | 特性 |
|------|----------|------|
| 变异水母 | 漂浮 | 缓慢追踪，轻微漂移 |
| 巨型章鱼 | 追踪 | 持续追踪玩家，会发射子弹 |
| 装甲蟹 | 锯齿形 | 左右偏移接近 |
| 深海鳗鱼 | 正弦波 | 快速波浪式移动 |
| 变异鲨鱼 | 蓄力冲锋 | 接近后高速冲锋 |

**辅助潜艇系统：**
- 根据基地升级配置生成随行潜艇
- 自动跟随玩家，保持阵型
- 自动瞄准最近敌人射击
- 可被敌人击毁

**BOSS战（第5关）：**
- BOSS名称：深渊病毒守护者
- HP：2000
- 3个攻击阶段（按HP比例切换）：
  - 阶段1（HP>60%）：散射攻击 + 追踪弹
  - 阶段2（HP 30%-60%）：加速，增加召唤小怪
  - 阶段3（HP<30%）：狂暴化，散射12发，移动速度翻倍
- 攻击模式：
  - `scatter`：环形散射子弹
  - `homing`：追踪弹（带转向逻辑）
  - `summon`：召唤变异水母小怪

**武器升级影响发射模式：**
| 等级 | 模式 |
|------|------|
| Lv1 | 单发 |
| Lv2 | 双发（左右偏移） |
| Lv3+ | 三发散射 |

**小地图：** 右下角显示，包含玩家（蓝点）、敌人（红点）、BOSS（大红点）、辅助潜艇（绿点）

**评级系统（S/A/B/C/D）：**
| 评级 | 分数要求 |
|------|----------|
| S | >= 2000 |
| A | >= 1500 |
| B | >= 1000 |
| C | >= 500 |
| D | < 500 |

### 7. 毒雾沼泽开启

**触发条件：** 击败BOSS后自动触发

**流程：**
1. BOSS击败后，延迟1.5秒显示胜利界面
2. 返回基地后，延迟2秒弹出剧情提示
3. 再延迟3秒显示确认对话框：
   - 文本："前方是一个新的大陆，曾经是某国排放核污水的地方，如今地面已经一片沼泽。"
   - 确认后调用 `MapManager.switchTo('swamp')`

## 技术实现方案

### 文件结构

```
js/systems/
  island-base.js      # 孤岛基地主系统（含NPC对话、升级系统、变异剧情）
  island-story.js     # 剧情触发系统
  fishing-game.js     # 捕鱼小游戏
  submarine-game.js   # 潜艇深海探险
js/maps/
  swamp-map.js        # 毒雾沼泽地图
```

### 2D游戏切换机制

```javascript
// 进入2D游戏时
window.enter2DGame();
// 暂停3D游戏，退出指针锁定，显示2D Canvas

// 退出2D游戏时
window.exit2DGame();
// 隐藏2D Canvas，恢复3D游戏，重新请求指针锁定
```

### 数据持久化

```javascript
// 捕鱼结果
window.lastFishingResult = {
  score: 0,       // 总得分
  fishCaught: 0,  // 捕获数量
  fishTypes: {}   // 各类型鱼数量
};

// 潜艇探险结果
window.lastSubmarineResult = {
  score: 0,          // 总得分
  level: 0,          // 到达关卡
  enemiesKilled: 0,  // 击杀敌人
  bossDefeated: false // 是否击败BOSS
};

// 基地升级数据（保存在IslandBase.baseUpgrades中）
{
  weaponLevel: 1,     // 武器等级 1-5
  armorLevel: 1,      // 装甲等级 1-5
  allyCount: 0,       // 辅助潜艇数量 0-4
  allyWeaponLevel: 1  // 辅助武器等级 1-3
}
```

## 控制台命令

```javascript
_cheats.goto('island')   // 传送到孤岛基地
_cheats.goto('swamp')    // 传送到毒雾沼泽
_cheats.maps()           // 列出所有可用地图

// 碰撞器调试命令
showColliders()          // 显示所有碰撞器可视化辅助线框
listColliders()          // 在控制台列出所有碰撞器的坐标与尺寸信息
clearAllColliders()      // 清除所有已注册的碰撞器（调试用）
```

**快捷键：**
- `F10`：切换碰撞器调试可视化（显示/隐藏所有 Box3 碰撞体的线框边界）
