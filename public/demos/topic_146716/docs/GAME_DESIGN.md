## 1. 游戏概述

### 1.1 游戏简介
《末日幸存者》是一款第一人称射击(FPS)肉鸽(Roguelike)生存游戏。玩家扮演末日幸存者，在无尽的僵尸潮中生存，通过击杀僵尸获取经验升级，选择各种强化能力，挑战越来越强的敌人。

### 1.2 核心玩法循环
```
生存 → 击杀僵尸 → 获取经验 → 升级选择 → 变得更强 → 面对更强敌人
         ↓              ↓
    获得资源 → 带回避难所 → 建造设施 → 研发科技 → 携带工事 → 战场部署
         ↓
    沙漠20波完成 → 直升机前往孤岛基地 → 安全区探索 → 捕鱼任务 → 鱼类变异剧情
         ↓
    基地升级 → 潜艇深海探险 → 海底BOSS战 → 毒雾沼泽新地图
```

### 1.3 游戏特色
- **无尽波次系统**: 僵尸随波次逐渐变强，挑战玩家极限
- **肉鸽升级系统**: 每次升级从随机3个选项中选择强化，招募队友概率提高
- **多样化武器**: 手枪、冲锋枪、霰弹枪、狙击枪、手雷
- **多种僵尸类型**: 31种不同特性的敌人（8种基础型、8种雪山专属、8种沙漠专属、4种沼泽专属、3种特殊敌人）
- **AI队友系统**: 可招募最多8名队友协助战斗，招募后在玩家2米范围内出现
- **基地建设**: 局外养成系统，建造设施、招募幸存者、研发科技
- **防御工事**: 局内策略系统，携带工事进入战场建立防线，炮塔显示血条
- **空投救援事件**: 定时出现的特殊补给事件
- **流场寻路**: 成百上千僵尸智能绕开障碍物追击玩家
- **动态天气系统**: 6种天气影响战斗策略，配合氛围音乐
- **孤岛基地系统**: 沙漠20波后解锁的海上安全区，包含NPC任务、2D小游戏、基地建设
- **捕鱼2D小游戏**: 独立的Canvas 2D捕鱼游戏，60秒倒计时，3种武器3种技能
- **潜艇深海探险2D游戏**: 5关弹幕射击游戏，辅助潜艇系统，BOSS战
- **毒雾沼泽地图**: 全新3D地图，毒雾伤害，4种变异怪物，15波防御

#### 移动技能详解

**二段跳**：二段跳为10级累积解锁型技能。每投入1点增加1级进度，当达到10级时解锁空中二段跳能力——玩家在空中可再次按空格键进行第二次跳跃。10级以下时不具备二段跳能力。

**攀爬**：攀爬技能允许玩家在跳跃后，在空中按住空格键沿建筑物/障碍物墙壁垂直向上移动。每级增加1秒最大攀爬时间（1级=1秒，10级=10秒），攀爬速度为3m/s。攀爬结束后进入10秒冷却时间，冷却期间无法再次攀爬。攀爬与二段跳互斥——使用二段跳后不可立即攀爬，反之亦然。

当所有基础属性达到上限后，升级获得的属性点自动转化为 **精通点**（每次升级3点）。精通系统在属性面板底部显示，有精通点时HUD显示橙色 ★ 提示。

- **视觉**: 雨滴粒子从上方落下，地面微微反光，整体色调偏蓝
- **背景音乐**: 低沉雨声+舒缓钢琴（音量80%）
- **触发概率**: 15%

#### 🌫️ 浓雾
- **视野效果**: **玩家视野缩小50%-70%**（雾浓度大幅增加）
- **敌人效果**: **敌人不受影响**（僵尸靠嗅觉追踪）
- **射程效果**: **射程不受影响**（子弹可以飞出雾外）
- **远程僵尸**: 仍然可以投掷（但玩家难以看到它们）
- **视觉**: 浓重白雾，远处完全不可见，整体色调灰白
- **背景音乐**: 空灵氛围音+远处风声（音量80%）
- **触发概率**: 10%

#### ⛈️ 雷暴
- **移速效果**: 全体移速 -10%
- **落雷机制**（每5-10秒一次）:
  - **60%概率劈中僵尸** → **直接击毙**（无视血量）
  - **20%概率劈中炮塔** → **短暂失灵5秒**（停止攻击，不造成伤害）
  - **20%概率劈中玩家** → **清除全部护盾**（不扣血量）+ **屏幕抖动** + **金黄色闪屏**
- **落雷音效**: 雷声轰鸣（立体声，根据距离衰减）
- **视觉**: 雨滴 + 随机闪电（全屏白光闪烁）+ 暗色调
- **背景音乐**: 紧张鼓点+雷声（音量80%）
- **触发概率**: 8%

#### ❄️ 大雪
- **移速效果**: 玩家移速 -30%，敌人移速 -30%
- **爆炸效果**: **爆炸物范围 -50%**（手雷、爆炸僵尸、导弹塔、无人机等）
- **视觉**: 雪花粒子缓缓飘落，地面逐渐变白，整体色调偏白
- **背景音乐**: 肃穆弦乐+风雪声（音量80%）
- **触发概率**: 7%

#### 🩸 血月
- **敌人强化**: 敌人全属性 +20%（血量、速度、伤害）
- **经验加成**: 击杀经验 +50%
- **视觉**: 天空变红，红色雾气弥漫，敌人身上发出红色微光
- **背景音乐**: 暗黑重低音+心跳声（音量80%）

### 10.2 关键系统

**流场寻路**: 将地图划分为2×2米网格，BFS计算每个格子到玩家的最短路径，所有地面僵尸共用同一张流场地图，性能极高。

**电力系统**: 发电站产出电力，战场击杀/波次积累充能点，可在避难所使用充能效果（护盾充能、电磁脉冲、工事修复）。

**离线收益**: 幸存者离线继续工作，效率为在线的30%，最大离线8小时。

**零件统一**: 工事系统和避难所系统共享同一零件数据源，确保数据一致性。

**天气系统**: 动态天气影响战斗策略，配合氛围音乐和视觉效果，增强游戏沉浸感。
