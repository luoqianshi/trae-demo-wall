## 二、传送门系统

### 2.1 传送门外观与位置

- **外观**：高6米的六边形蓝色光柱，顶部有旋转光环，底部有能量纹路
- **位置**：城市地图四条边的中点各放置一个（东/南/西/北），距边缘5米
- **激活时机**：永久存在但初始为灰色（未激活），20波后全部激活为蓝色
- **激活特效**：激活时全图闪烁蓝光 + 播放电磁音效 + 屏幕中央提示

### 2.2 传送门交互

- **接近距离**：8米内显示提示"按 F 进入传送门"
- **交互**：按F后播放2秒传送动画（粒子吸入效果），进入大地图选择界面
- **20波后每波提示**：波次开始时屏幕上方弹出提示条：

```
📡 收到神秘无线电信号... 传送门已激活，是否前往探索新区域？
[按 Tab 打开大地图] [忽略]
```

### 2.3 大地图选择界面

- **触发**：按 Tab 键打开（20波后解锁）
- **视觉**：俯视角2D平面地图，类似战略地图
- **节点设计**：

```
        [雪山❄️] (已解锁)
           |
    [沙漠🏜️] (未解锁)
           |
[沼泽🌿] — [城市🏙️(当前)] — [雪山❄️] (已解锁)
           |
    [岛屿🏝️] (未解锁)
           |
        [火山🌋] (未解锁)
```

- **节点信息**：悬停显示地图名、难度、当前波次、敌人类型
- **选择后**：播放传送动画，加载新地图

## 三、雪山地图设计

### 3.1 地形系统（已实现）

| 特性 | 参数 | 说明 |
|------|------|------|
| **地图大小** | 300×300 | 实际范围 -300 ~ +300 |
| **地面材质** | 雪地 | 白色 Lambert 材质，接收阴影 |
| **网格细分** | 150×150 | 每段约8米，确保平滑 |
| **坡度系统** | FBM噪声 | 4层叠加，基础频率0.004 |
| **最大高度差** | ~10米 | 基础层×0.6 + 细节层×1.2 |
| **道路** | 十字形雪路 | 宽12米，平坦化系数0.95 |
| **中心平坦区** | 半径80米 | 信号塔周围超平坦 |

### 3.2 地形生成规则（已实现）

```javascript
// FBM平滑噪声（4层叠加）
const h1 = fbm2D(x * 0.004, z * 0.004, 4, 0.5, 2.0) * 12 * 0.6;
const h2 = fbm2D(x * 0.015, z * 0.015, 3, 0.4, 2.0) * 1.2;

// 中心平坦化（信号塔周围）
const centerFlat = max(0, 1 - dist / 80);

// 道路平坦化（十字形）
const roadDist = min(abs(x), abs(z));
const roadFlat = roadDist < 12 ? pow(1 - roadDist / 12, 2) * 0.95 : 0;

// 最终高度
let h = (h1 + h2) * (1 - centerFlat * 0.85);
h = h * (1 - roadFlat);
```

**视觉道路**：两条白色平面（宽12米）十字交叉，模拟雪路

### 3.3 场景装饰

| 元素 | 描述 | 碰撞 |
|------|------|------|
| **废弃汽车** | 雪中半埋的轿车/卡车，5种变体 | 有（可作掩体） |
| **加油站** | 带顶棚的加油岛，有油罐 | 有（可进入） |
| **公路护栏** | 金属护栏，沿道路两侧 | 有 |
| **雪堆** | 自然形成的雪堆 | 有（可翻越，高处滑下） |
| **枯树** | 死去的松树，无树叶 | 有（不可破坏） |
| **冰面** | 冻结的湖面/路面 | 无碰撞，移速+30%但转向-50% |
| **岩石** | 大型裸露岩石 | 有（不可破坏） |

### 3.4 废弃汽车设计

- **轿车**：2×4米，可作低矮掩体（蹲下完全遮挡）
- **卡车**：3×6米，可作大型掩体，车厢可进入
- **油罐车**：3×8米，被击中会爆炸（范围伤害）
- **状态**：随机朝向，部分侧翻，车门可开关
- **搜索**：靠近按F搜索，50%概率获得物资（弹药/零件/血包）

### 3.5 加油站设计

- **结构**：顶棚（4柱支撑）+ 2个加油岛 + 1个便利店建筑
- **便利店**：可进入，内部有货架（搜索物资）
- **油罐**：击中会大范围爆炸（伤害80，半径15米）
- **战术价值**：中心开阔地带，适合防守但易被包围

## 八、雪山任务流程（已实现）

### 8.1 阶段流程

```
探索阶段(explore) → 电源阶段(power) → 回塔阶段(returnToTower) → 防御阶段(defend) → 完成(complete)
```

**1. 探索阶段**
- 玩家出生在地图边缘（0, 0, 270）
- 游荡僵尸在周围巡逻（8只）
- 信号塔在中心（0, 0, 0），靠近触发任务对话
- 小地图显示信号塔绿色箭头指示方向

**2. 电源阶段**
- 需要激活3个电源节点（分布在地图三角位置）
- 每个电源节点有保护僵尸，清除后按F激活
- 小地图显示未激活电源为橙色圆点
- 全部激活后提示返回信号塔

**3. 回塔阶段**
- 返回信号塔触发收音机交互
- 播放剧情对话，开启防御阶段

**4. 防御阶段（15波）**
- 信号塔获得HP条（1000 HP）
- 每波敌人从40-80米外生成，朝信号塔移动
- 波次自动推进（清完当前波后2秒开下一波）
- 小地图显示波次僵尸红点
- 命令行支持：`skipsnow`跳过探索、`wave N`跳波、`kill`清敌

**5. 完成**
- 15波防御成功 → 剧情弹窗 → 解锁"灼热荒漠"节点

### 8.2 独立波次系统

- 城市和雪山各有独立的波次计数器
- 城市波次：继续从离开时的波次推进
- 雪山波次：从第1波开始，防御阶段15波
- 切换地图时当前波次暂停（不重置）

### 8.2 数据保存

```
存档结构：
{
  city: { wave: 25, kills: 150, ... },
  snow: { wave: 12, kills: 80, unlocked: true, ... },
  desert: { wave: 0, kills: 0, unlocked: false, ... },
  global: { iceCrystals: 45, sandCrystals: 0, mapFragments: 2, ... }
}
```

### 8.3 切换流程

```
游戏中按 M → 大地图界面 → 选择目标地图 → 传送 → 新地图加载
```

## 十、毒雾沼泽地图设计（第四章）

### 10.1 地图概述

灼热荒漠的联络塔发出求救信号后，玩家收到了来自"毒雾沼泽"的异常读数。那里有一座废弃的核污水排放设施，周围弥漫着致命的绿色毒雾，变异生物在沼泽中游荡。

| 属性 | 数值 |
|------|------|
| **地图大小** | 200×200 |
| **地形** | 沼泽地面 + 水坑 + 起伏地形 |
| **主建筑** | 废弃核污水排放设施遗迹 |
| **副建筑** | 残墙、管道、警告标志 |
| **防御波次** | 15波 |
| **特殊机制** | 毒雾伤害、变异植物、发光蘑菇 |

### 10.2 场景装饰

| 元素 | 描述 | 碰撞 |
|------|------|------|
| **枯树** | 扭曲树干和树枝，无树叶 | 有 |
| **沼泽水坑** | 反光半透明水面 | 无 |
| **变异植物** | 发光蘑菇和藤蔓，带点光源 | 无 |
| **废弃建筑** | 核污水排放设施遗迹 | 有 |
| **毒雾粒子** | 绿色半透明飘动粒子 | 无 |

### 10.3 沼泽变异怪物

**核心设定**：病毒在核污水与沼泽湿气的双重作用下发生二次变异，产生人类+两栖动物的混合变异体。毒雾不是化学武器，而是病毒在潮湿环境下的气溶胶表现。

| 名称 | HP | 速度 | 伤害 | 攻击范围 | 特性 |
|------|-----|------|------|----------|------|
| **变异蛙人** | 80 | 4.0 | 15 | 2m | 快速近战，绿色皮肤 |
| **毒液喷射者** | 60 | 2.5 | 20 | 15m | 远程毒液攻击，紫色皮肤 |
| **沼泽巨蠕虫** | 200 | 3.0 | 25 | 3m | 地下移动，破土攻击 |
| **辐射僵尸** | 300 | 1.2 | 30 | 2m | 高血量慢速，发光绿色 |

**视觉统一特征**：
- 主色调：绿紫黑（`#2d5a27` ~ `#4a0e4e`）
- 发光材质（眼睛等）→ 毒绿色 `0x39ff14`
- 所有沼泽僵尸标记 `swamp: true`

### 10.4 剧情流程

**前置剧情**：潜艇深海探险击败BOSS后触发，收到来自毒雾沼泽的异常读数...

```
探索阶段 → 遗迹调查 → 防御准备 → 防御15波 → 完成
```

**1. 探索阶段**
- 玩家传送到沼泽边缘
- 沼泽内有游荡的变异生物
- 靠近废弃核污水排放设施遗迹触发剧情对话
- 30秒探索后自动开始15波防御

**2. 遗迹调查**
- 调查废弃核污水排放设施，发现污染源头
- 调查残墙和管道，了解设施历史
- 调查警告标志，获取毒雾信息

**3. 防御准备**
- 设施遗迹启动，发出求救信号
- 同时吸引了大量变异体
- 开始15波防御

**4. 防御阶段（15波）**
- 设施遗迹获得HP条（1000 HP）
- 波次自动推进
- 第15波出现最终BOSS

**5. 完成**
- 成功防御 → 收到外界救援信号
- 解锁新区域"孤岛基地"

## 十一、技术实现要点

### 11.1 地形系统

- 使用 `THREE.PlaneGeometry` + 顶点位移实现坡度
- 高度图用 Simplex Noise 生成
- 碰撞检测需要考虑Y轴高度差
- 玩家/敌人移动时根据坡度调整速度（上坡减速，下坡加速）

### 11.2 场景加载

- 传送时卸载当前地图所有对象
- 加载新地图地形、建筑、装饰物
- 保留：玩家数据、队友、武器、避难所数据
- 加载时间目标：< 3秒

### 11.3 天气与特效

- **雪山**：粒子系统模拟飘雪（已有weather.js可扩展）
- **雪山脚印**：玩家/敌人经过时在地面留下临时印记
- **雪山音效**：雪地行走咯吱声
- **沼泽**：毒雾粒子系统，绿色半透明飘动效果
- **沼泽发光**：变异植物和蘑菇带点光源，营造诡异氛围
