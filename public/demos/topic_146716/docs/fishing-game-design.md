## 1. 设计概述

### 1.1 设计目标

将原本单调的"瞄准-射击"捕鱼玩法，升级为具有完整经济循环、装备成长、场景探索、收集养成和Boss挑战的独立游戏模块。捕鱼小游戏应成为玩家在主游戏循环中主动寻求的"奖励性玩法"，而非被迫参与的枯燥任务。

### 1.2 核心体验目标

| 体验维度 | 目标描述 |
|---------|---------|
| 操作感 | 射击命中时的爽快感，不同武器差异化的手感 |
| 策略性 | 根据鱼群行为、海域特点、天气条件选择装备和策略 |
| 成长性 | 装备升级带来的能力提升可视化，解锁新区域和新鱼种的探索感 |
| 收集欲 | 完整的图鉴系统和稀有鱼收集带来的成就感 |
| 紧张感 | Boss战和限时事件带来的肾上腺素飙升 |
| 经济循环 | 捕鱼收益与主游戏资源系统的正向反馈 |

### 1.3 与主游戏的耦合设计

```
┌─────────────────────────────────────────────────────┐
│                    主游戏（末日Roguelike）              │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  │
│  │ 生存系统     │  │ 战斗系统     │  │ 建造系统     │  │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘  │
│         │                │                │         │
│         └────────────────┼────────────────┘         │
│                          ▼                         │
│              ┌─────────────────────┐               │
│              │   资源接口（单向）    │               │
│              │  - 食物/材料/金币输出  │               │
│              │  - 主游戏货币输入      │               │
│              └──────────┬──────────┘               │
│                         ▼                          │
│              ┌─────────────────────┐               │
│              │   捕鱼小游戏模块      │               │
│              │  （完全独立运行）      │               │
│              └─────────────────────┘               │
└─────────────────────────────────────────────────────┘
```

**接口规范**：
- **输出接口**：捕鱼结束后，将获得的资源（食物、材料、特殊道具）打包返回主游戏
- **输入接口**：主游戏金币可用于购买捕鱼模块内的装备和道具
- **无状态依赖**：捕鱼模块不读取主游戏存档状态，仅通过接口交换资源
- **独立存档**：捕鱼模块有自己的进度存档（图鉴、装备等级、任务进度）

## 2. 核心玩法循环

### 2.1 单局循环（3-8分钟）

```
准备阶段 (30秒) → 捕鱼阶段 (2-6分钟) → 结算阶段 (30秒)
      │                  │                  │
      ▼                  ▼                  ▼
┌──────────┐      ┌──────────┐       ┌──────────┐
│选择海域   │      │观察鱼群   │       │计算收益   │
│装备武器   │      │瞄准射击   │       │获得资源   │
│携带道具   │      │使用技能   │       │更新图鉴   │
│接受任务   │      │应对事件   │       │任务进度   │
└──────────┘      └──────────┘       └──────────┘
```

### 2.2 中长期循环

```
捕鱼获取资源 → 升级装备/解锁海域 → 挑战更强鱼种/Boss → 完成图鉴/任务
      ↑                                                    │
      └──────────────── 稀有掉落/成就奖励 ───────────────────┘
```

### 2.3 核心操作机制

| 操作 | 输入 | 效果 |
|-----|------|------|
| 瞄准 | 鼠标移动 / 右摇杆 | 调整射击方向，显示预测轨迹 |
| 射击 | 鼠标左键 / RT | 发射当前武器弹药 |
| 切换武器 | 数字键1-3 / 方向键 | 在鱼叉/渔网/鱼竿间切换 |
| 使用道具 | Q键 / LB | 使用携带的道具（诱饵、声呐等） |
| 激活技能 | E键 / RB | 激活当前装备的主动技能 |
| 收杆/收网 | 空格 / A键 | 鱼咬钩后进入QTE收杆阶段 |

### 2.4 命中判定与伤害计算

**基础伤害公式**：
```
实际伤害 = 武器基础伤害 × 部位倍率 × 距离衰减 × 暴击倍率 × 鱼类防御系数

部位倍率：
- 头部/要害：2.0x
- 躯干：1.0x
- 尾部：0.7x
- 鱼鳍：0.5x（但可触发"致残"状态）

距离衰减：
- 有效射程内：1.0x
- 超出射程每10%：-0.1x（最低0.3x）

暴击倍率：
- 基础暴击率：5%
- 暴击伤害：1.5x
- 可通过装备和技能提升
```

## 3. 鱼类设计

### 3.1 鱼类属性体系

每条鱼拥有以下核心属性：

| 属性 | 说明 | 影响 |
|-----|------|------|
| 生命值 | 鱼类的耐久度 | 决定需要多少次命中才能捕获 |
| 速度 | 游动速度 | 影响瞄准难度和追击难度 |
| 警觉性 | 对玩家行为的敏感程度 | 高警觉鱼会在玩家瞄准时逃跑 |
| 防御力 | 减伤比例 | 降低武器造成的伤害 |
| 挣脱力 | 被命中后的逃跑倾向 | 影响捕获成功率 |
| 出现深度 | 栖息的水深范围 | 决定出现的海域和深度层 |
| 活动时间 | 活跃的时间段 | 昼夜系统影响出现概率 |
| 稀有度 | 常见/稀有/史诗/传说 | 影响掉落品质和出现频率 |

### 3.3 鱼类AI行为树

```
[Root] 鱼类AI状态机
│
├─ [Idle] 闲置状态
│   ├─ 随机游动（巡逻路径）
│   ├─ 觅食行为（向诱饵移动）
│   └─ 状态转换条件：感知威胁 → [Alert]
│
├─ [Alert] 警觉状态
│   ├─ 停止游动，观察声源方向
│   ├─ 警觉计时器（2-5秒，因鱼而异）
│   ├─ 状态转换：威胁消失 → [Idle]
│   └─ 状态转换：确认威胁 → [Flee] 或 [Attack]
│
├─ [Flee] 逃跑状态
│   ├─ 以最高速度远离威胁源
│   ├─ 随机变向（每1-2秒）
│   ├─ 寻找障碍物/深水区躲避
│   └─ 状态转换：距离足够远 → [Idle]
│
├─ [Attack] 攻击状态（仅敌对鱼类）
│   ├─ 瞄准玩家/目标
│   ├─ 蓄力（0.5-2秒）
│   ├─ 发动攻击（冲撞/撕咬/特殊能力）
│   └─ 状态转换：攻击结束 → [Alert] 或 [Flee]
│
└─ [Hooked] 被钩状态
    ├─ 剧烈挣扎（随机方向冲刺）
    ├─ 挣脱力累计（QTE失败增加）
    ├─ 体力衰减（随时间降低挣脱力）
    └─ 状态转换：挣脱成功 → [Flee]；被捕获 → [Captured]
```

## 8. Boss与稀有鱼设计

### 8.1 变异虎鲨（史诗Boss）

**触发条件**：在深渊裂口区域连续捕获5条鱼类后概率出现，或使用血腥诱饵主动召唤。

**战斗阶段**：

| 阶段 | 血量阈值 | 行为模式 | 应对策略 |
|-----|---------|---------|---------|
| 第一阶段 | 100%-70% | 环绕巡游，偶尔冲撞 | 保持移动，瞄准侧面 |
| 第二阶段 | 70%-30% | 频繁冲撞，释放血雾（视野-50%） | 使用声呐定位，优先攻击眼睛 |
| 第三阶段 | 30%-0% | 狂暴状态，速度+50%，连续冲撞3次 | 利用障碍物躲避，抓住硬直期输出 |

**掉落**：
- 必掉：变异虎鲨肉×5（史诗食物），鲨鱼牙×2（史诗材料）
- 概率掉落：虎鲨猎手模组（鱼叉枪专属，对大型目标伤害+30%）

### 8.2 机械锦鲤（史诗Boss）

**触发条件**：在暴风雨天气的幽灵海湾概率出现。

**特殊机制**：
- EMP脉冲：每20秒释放一次，禁用玩家所有技能和道具3秒
- 自我修复：停止受到攻击5秒后，每秒恢复10点生命
- 召唤无人机：血量低于50%时，召唤2架小型无人机干扰玩家瞄准

**应对策略**：
- 携带抗EMP模组或选择不受EMP影响的鱼竿
- 保持持续输出，不让其进入修复状态
- 优先清理无人机

### 8.3 瘟疫乌贼（史诗Boss）

**触发条件**：在辐射浅滩使用特殊鱼饵"腐化诱饵"召唤。

**特殊机制**：
- 墨汁隐身：喷墨后3秒内完全隐身，但会留下毒雾轨迹
- 触手抓取：触手命中玩家后，玩家3秒内无法移动和射击
- 毒液喷射：向玩家位置喷射毒液，落地后形成持续5秒的毒潭

### 8.4 利维坦遗种（传说Boss）

**触发条件**：完成所有前置任务，在血月+暴风雨的叠加天气下，于利维坦巢穴最深处触发。

**三阶段战斗**：

**第一阶段：触手之舞**
- 利维坦不直接现身，只伸出3-5条触手攻击
- 触手会拍打水面、缠绕船只、投掷巨石
- 玩家需要攻击触手根部，每条触手200生命值
- 摧毁所有触手后进入第二阶段

**第二阶段：吞噬漩涡**
- 利维坦张开巨口，产生巨大漩涡
- 玩家船只被缓慢拉向中心
- 需要一边抵抗拉力一边攻击利维坦的牙齿（每颗牙300生命值，共8颗）
- 摧毁4颗牙齿后漩涡减弱，进入第三阶段

**第三阶段：巨浪滔天**
- 利维坦完全现身，体型占据半个屏幕
- 巨浪攻击：掀起的巨浪需要玩家跳跃躲避
- 声波咆哮：全屏攻击，需要躲在掩体后
- 最终弱点：眼睛暴露时攻击，眼睛1000生命值

**掉落**：
- 必掉：利维坦之肉×10（传说食物，主游戏中可恢复全部状态），利维坦之鳞×3（传说材料，可打造最强装备）
- 必掉：纪念道具"利维坦之眼"（可放置在主游戏基地中作为装饰）
- 必掉：专属称号"弑神者"

## 14. 风险评估与削减方案

### 14.1 风险识别

| 风险 | 等级 | 影响 | 缓解方案 |
|-----|------|------|---------|
| 鱼类AI过于复杂 | 中 | 开发时间超预期 | 使用简化行为树，MVP阶段只做3种行为模式 |
| 水面渲染性能 | 中 | 帧率不稳定 | 使用平面水面+Shader，避免真实物理模拟 |
| 数值平衡困难 | 中 | 经济通胀或紧缩 | 设置软上限，预留调整参数，测试期间每日监控 |
| 与主游戏耦合 | 低 | 影响主游戏稳定性 | 严格接口隔离，独立测试后再集成 |
| 内容量过大 | 高 | 无法按时交付 | 按MVP→扩展分阶段，优先保证核心循环有趣 |

### 14.2 成功指标

| 指标 | 目标值 | 测量方式 |
|-----|--------|---------|
| 单局留存率 | >60% | 开始捕鱼的玩家完成整局的比例 |
| 日活跃捕鱼次数 | >3次 | 每日平均每位玩家捕鱼局数 |
| 装备升级率 | >40% | 升级过至少1件装备的玩家比例 |
| 图鉴完成率 | >20% | 解锁超过50%鱼类的玩家比例 |
| 玩家满意度 | >4.0/5 | 问卷调查 |
