# AI 学习助手

一款基于 AI 技术的智能学习应用，融合背诵记忆、专注计时和个性化设置功能，为用户打造沉浸式学习体验。

## 🎯 项目特色

### 智能背诵模块
- **文档/图片上传**：支持上传学习材料，自动生成记忆卡片
- **重点词汇标注**：AI 智能识别重点词汇，红色加粗高亮显示
- **卡片翻转动画**：流畅的 3D 翻转效果，增强记忆交互体验
- **错题集功能**：自动记录错误卡片，支持针对性复习

### 专注计时模块
- **自定义时间设置**：支持 1-180 分钟自由调节
- **圆形进度环**：醒目的黑色圆环进度指示，实时更新
- **每日励志名言**：随机展示名人名言，激发学习动力
- **番茄工作法**：科学的时间管理，提高学习效率

### AI 伙伴系统
- **个性化形象**：支持用户上传照片生成 Q 版形象
- **拖拽交互**：AI 角色可自由拖拽定位
- **动态动画**：学习过程中展示不同动画效果（写字、摇头）
- **智能反馈**：根据学习状态提供鼓励和提示

### 个性化设置
- **账号管理**：支持登录/登出功能
- **壁纸自定义**：三个页面可分别设置专属壁纸
- **角色尺寸调节**：60%-140% 范围自由调整
- **预设形象选择**：提供多种预设 AI 角色形象

## 🛠️ 技术栈

- **前端框架**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **UI 设计**: 响应式设计，Ins 风格（白色背景 + 黑色按钮）
- **动画效果**: CSS3 动画 + JavaScript 动态交互
- **图标系统**: SVG 矢量图标
- **数据存储**: LocalStorage 本地存储

## 🚀 快速开始

### 本地运行

```bash
# 克隆项目
git clone <repository-url>

# 进入项目目录
cd ai-learning-assistant

# 使用浏览器直接打开
open wireframe.html
```

### 部署上线

```bash
# 使用 Python 简单服务器
python -m http.server 8000

# 或使用 Node.js
npx serve -l 8000
```

访问地址：http://localhost:8000
