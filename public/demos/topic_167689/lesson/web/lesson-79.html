第79课：本地存储 localStorage

JS：学习 setItem、getItem、removeItem、JSON 序列化。localStorage 可以在浏览器中永久保存数据，刷新或关闭页面后依然存在，是做记事本、游戏存档等功能的基础。

localStorage 基本用法

localStorage.setItem(键, 值) 存数据，getItem(键) 取数据，removeItem(键) 删除一条，clear() 清空全部。数据以键值对形式保存，关闭浏览器后依然存在。

代码演示
<button onclick="save()">保存</button> <button onclick="read()">读取</button> <button onclick="del()">删除</button> <script> function save() { localStorage.setItem("name", "小明"); // 存 } function read() { var n = localStorage.getItem("name"); // 取 alert(n); // 小明 } function del() { localStorage.removeItem("name"); // 删 } </script>
localStorage 数据关闭浏览器后依然存在

JSON 序列化存储对象

localStorage 只能存字符串，存对象时要用 JSON.stringify() 把对象转成字符串；读取时用 JSON.parse() 把字符串转回对象。这样才能保存复杂的数据结构。

代码演示
<script> // localStorage 只能存字符串 // 存对象要用 JSON.stringify 转成字符串 var user = { name: "小明", age: 18 }; localStorage.setItem("user", JSON.stringify(user)); // 取出来再用 JSON.parse 转回对象 var str = localStorage.getItem("user"); var obj = JSON.parse(str); console.log(obj.name); // 小明 console.log(obj.age); // 18 </script>
存对象用 stringify，取对象用 parse
