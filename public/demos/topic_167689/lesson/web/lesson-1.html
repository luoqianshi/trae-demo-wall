第1课：HTML 文档结构

欢迎来到 Web 前端开发的第一课！HTML 是构建网页的骨架。本课你将学习 HTML 文档的基本结构，并在下方编辑器中亲手编写代码。

什么是 HTML？

HTML（HyperText Markup Language，超文本标记语言）是用来构建网页结构的标准标记语言。它使用一系列标签来描述页面的各个部分，比如标题、段落、链接、图片等。

代码演示
<html></html>
这是 HTML 的根标签，所有内容都写在里面

基本文档结构

每个 HTML 文档都遵循以下基本结构：

<!DOCTYPE html> — 声明文档类型为 HTML5
<html> — 根元素，包含整个页面
<head> — 头部，存放元数据（标题、字符集等）
<body> — 主体，存放页面可见内容

代码演示
<head></head>
在这里写页面的元信息，如标题、字符集等
代码演示
<body></body>
在这里写页面的可见内容，如文字、图片等
