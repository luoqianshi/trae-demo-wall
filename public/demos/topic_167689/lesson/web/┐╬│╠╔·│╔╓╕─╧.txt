--------------------------------------------------
一、目录结构
--------------------------------------------------
项目根目录/
├── index.html              主页（已引入 lessons.js + common.js）
├── script.js               主页脚本（Web 跳转用 web_lesson 键）
├── lesson/
│   ├── common.js           公共库（localStorage/进度/预览/跳级）
│   └── web/                ← 本文件所在目录
│       ├── lessons.js       课程配置（3 个 JS 数组，本地预览可用）
│       ├── code-editor.js  代码编辑器组件
│       ├── ai.js           AI 功能模块（AICodeCheck + AIChat）
│       ├── 课程生成指南.txt  本文件
│       ├── index.html      课程选择页（3 个分类区域）
│       ├── lesson-N.html    普通课（N=1~80，无 AI）
│       ├── lesson-N-ai.html 普通课 AI 版（有 AI 问答）
│       ├── practice-N.html  小实战（N=1~16，无 AI）
│       ├── practice-N-ai.html 小实战 AI 版（有 AI 问答+代码审查）
│       ├── total-practice-N.html 总实战（N=1~5，无 AI）
│       └── 课程设计.txt     课程大纲

--------------------------------------------------
二、lessons.js 用法
--------------------------------------------------
【作用】供课程选择页读取课程列表，本地预览（file://）可用。

【3 个数组】
    window.WEB_LESSONS          // 80 普通课，每项 { title, desc, type }
    window.WEB_PRACTICES        // 16 小实战，每项 { title, desc }
    window.WEB_TOTAL_PRACTICES  // 5 总实战，每项 { title, desc }

【type 字段】'HTML' / 'CSS' / 'JS'（仅普通课有）

--------------------------------------------------
三、进度跟踪（localStorage，分开计数）
--------------------------------------------------
    web_lesson          普通课进度（1~80）
    web_practice        小实战进度（1~16）
    web_total_practice  总实战进度（1~5）

【相关函数】（common.js）
    CL_Common.markLessonComplete(courseKey, lessonNum)
    CL_Common.getCompletedLessons(courseKey)
    CL_Common.unlockUntil(courseKey, targetNum)

--------------------------------------------------
四、文件命名规则
--------------------------------------------------
    普通课：lesson-N.html（N=1~80）
    小实战：practice-N.html（N=1~16）
    总实战：total-practice-N.html（N=1~5）

    AI 版本（不替换原文件，额外生成）：
    lesson-N-ai.html    普通课 + AI 问答
    practice-N-ai.html  实战课 + AI 问答 + AI 代码审查

--------------------------------------------------
五、普通课模板（lesson-N.html）
--------------------------------------------------
复制 lesson-1.html 作为模板。

【head 引用】（不引入 ai.js）：
    <script src="../common.js"></script>
    <script src="code-editor.js"></script>

【特点】
- 无 task-box，无 AI 面板
- 只有教学内容 + 编辑器"在代码编辑器里试一试吧！"
- lesson-tag：HTML课"Web 前端 · HTML"，CSS课"Web 前端 · CSS"，JS课"Web 前端 · JS"
- lesson-title：第N课：<span class="gradient-text">课程标题</span>
- 进度显示：第 N / 80 课
- script 变量：COURSE_KEY = 'web_lesson'

【编辑器模板（根据 type 选择）】
HTML 课：
    <code-editor default='<!DOCTYPE html>
    <html lang="zh-CN">
    <head>
        <meta charset="UTF-8">
        <title>第N课测试</title>
    </head>
    <body>
        <!--在这里编写代码-->
        
    </body>
    </html>'></code-editor>

CSS 课：
    <code-editor default='<!DOCTYPE html>
    <html lang="zh-CN">
    <head>
        <meta charset="UTF-8">
        <title>第N课测试</title>
        <style>
            /*在这里编写代码*/
            
        </style>
    </head>
    <body>
        <h1>标题</h1>
        <p>段落内容</p>
        <div class="box">容器</div>
    </body>
    </html>'></code-editor>

JS 课：
    <code-editor default='<!DOCTYPE html>
    <html lang="zh-CN">
    <head>
        <meta charset="UTF-8">
        <title>第N课测试</title>
    </head>
    <body>
        <h1>JS测试</h1>
        <p id="demo">段落</p>
        <button id="btn">按钮</button>
        <script>
            //在这里编写代码
            
        </script>
    </body>
    </html>'></code-editor>

六、实战课模板（practice-N.html / total-practice-N.html）
--------------------------------------------------
复制 practice-1.html 作为模板。

【head 引用】（不引入 ai.js）：
    <script src="../common.js"></script>
    <script src="code-editor.js"></script>

【特点】
- 有 task-box（实战任务框）
- 无 AI 面板
- lesson-tag：小实战"实战项目"，总实战"总实战项目"
- script 变量：
  小实战：COURSE_KEY = 'web_practice'
  总实战：COURSE_KEY = 'web_total_practice'

--------------------------------------------------
七、AI 版本模板（-ai 文件）
--------------------------------------------------
在对应基础文件上添加 AI 功能，不替换原文件。

【head 额外引用】：
    <script src="ai.js?v=2"></script>

【lesson-N-ai.html】（普通课 + AI 问答）
- 在编辑器后添加 AI 问答面板（上方聊天框 + 下方输入框）
- AIChat(message, code, task, lessonNum) — 4 参数

【practice-N-ai.html】（实战课 + AI 问答 + AI 代码审查）
- 在编辑器后添加 AI 代码审查面板 + AI 问答面板
- AICodeCheck(code, task, lessonNum) — 3 参数
- AIChat(message, code, task, lessonNum) — 4 参数

--------------------------------------------------
八、AI 功能（ai.js）
--------------------------------------------------
【用户等级自动判断】（根据 lessonNum）
    1~27：初学者，不要求过好
    28~54：中等，提出少量提高建议
    55~80：高等，提出较多提高建议

【AI 代码审查提示词】
    系统提示：检查代码（web）。找出错误，如果有，分条列出问题、改正内容。
    用户提示：用户：[等级]\n题目：[任务]\n用户代码：\n[代码]

【AI 问答提示词】
    系统提示：代码为web。
    用户提示：用户：[等级]\n题目/本课内容：[任务]\n用户代码：\n[代码]\n提问内容：[问题]

--------------------------------------------------
九、课程选择页（index.html）
--------------------------------------------------
3 个分类区域，各有独立进度条：
1. 普通课程（80）：LESSON XX + 类型标签 + 学习按钮 → lesson-N.html
2. 小实战（16）：实战 XX + 开始实战按钮 → practice-N.html
3. 总实战（5）：总实战 XX + 开始实战按钮 → total-practice-N.html

--------------------------------------------------
十、避坑要点
--------------------------------------------------
1. default 属性用单引号，代码内可用双引号；单引号需 &#39; 转义
2. </script> 不要转义为 <\/script>
3. common.js 必须在 code-editor.js 之前引入
4. 所有代码缩进使用 4 空格
5. 普通课不能引入 ai.js
6. 实战课 AI 版的 AICodeCheck 必须 3 参数，AIChat 必须 4 参数
7. CSS 课程模板中 <style> 标签内的注释用 /* */，不能用 <!-- -->
