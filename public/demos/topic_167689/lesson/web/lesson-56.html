第56课：Math 对象

Math 是 JS 内置的数学工具对象，提供圆周率、随机数、取整、最大最小值等常用方法，无需创建实例，直接 Math.方法名() 即可使用。

随机数与取整

Math.random() 返回 0 到 1 之间的小数（包含 0，不包含 1）。配合 Math.floor()（向下取整）可以生成指定范围的随机整数，这是开发中非常常用的技巧。

代码演示
// 生成 1~10 的随机整数 const num = Math.floor(Math.random() * 10) + 1; console.log(num); Math.floor(3.9); // 3 向下取整 Math.ceil(3.1); // 4 向上取整 Math.round(3.5); // 4 四舍五入
Math.random()*10 得到 0~9.x，floor 后是 0~9，加 1 变成 1~10

常用数学方法

Math.max() 和 Math.min() 返回一组数的最大最小值；Math.abs() 返回绝对值；Math.pow() 求幂；Math.PI 是圆周率约 3.14159。

代码演示
Math.max(3, 7, 1); // 7 Math.min(3, 7, 1); // 1 Math.abs(-5); // 5 Math.pow(2, 3); // 8 (2的3次方) Math.PI; // 3.141592653589793
max/min 可以接收任意多个参数
