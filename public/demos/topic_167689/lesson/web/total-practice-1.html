总实战项目

大实战一：个人博客系统

HTML + CSS + JS + localStorage，文章管理系统。综合运用 HTML 结构、CSS 样式、JavaScript 交互和本地存储，从零搭建一个完整的个人博客系统。

实战说明

这是 Web 课程的第一个总实战项目，要求你整合 HTML、CSS、JavaScript 和 localStorage 四大核心技术，实现一个具备发布、编辑、删除、分类、搜索功能的个人博客系统。通过这个项目，你将掌握前后端数据持久化的基础思路，理解完整的页面交互流程。

实战任务

制作个人博客系统

在下方编辑器中编写代码，完成一个具备完整增删改查功能的个人博客系统。要求：

  • 用 HTML 构建博客页面结构（头部、文章列表、文章详情）
  • 用 CSS 美化页面（Flex/Grid 布局、响应式）
  • 用 JS 实现文章的发布、编辑、删除功能
  • 用 localStorage 保存文章数据
  • 实现文章分类和搜索功能

提示：把代码写在 <body> 和 </body> 之间，可以同时写 <style> 和 <script> 标签。
