============================================================
  Coding Land - Web 前端课程设计
  80 普通课 + 16 小实战 + 5 总实战（分开计数）
  HTML + CSS + JS 循序渐进，面向零基础
  前 15 课无 JS，HTML/CSS/JS 交织出现
============================================================

【文件命名规则】
  普通课：lesson-N.html（N=1~80）
  小实战：practice-N.html（N=1~16）
  总实战：total-practice-N.html（N=1~5）

  AI 版本（不替换原文件，额外生成）：
  lesson-N-ai.html（普通课 + AI 问答）
  practice-N-ai.html（实战课 + AI 问答 + AI 代码审查）

【进度跟踪（localStorage）】
  web_lesson：普通课进度（1~80）
  web_practice：小实战进度（1~16）
  web_total_practice：总实战进度（1~5）

【AI 功能区分】
  普通课（lesson-N.html）：无 AI
  普通课 AI 版（lesson-N-ai.html）：AI 问答
  实战课（practice-N.html / total-practice-N.html）：无 AI
  实战课 AI 版（practice-N-ai.html）：AI 问答 + AI 代码审查

【编辑器模板】
  HTML 课：空白 body，注释提示 <!--在这里编写代码-->
  CSS 课：带 <style> 块，body 内预置 HTML 元素
  JS 课：带 <script> 块，body 内预置 HTML 元素

============================================================
  普通课程（lesson-1 ~ lesson-80）
============================================================

第 1 阶段：HTML 基础（lesson-1~5）
  1. HTML 文档结构 — DOCTYPE、html、head、body、title、meta
  2. HTML 标题与段落 — h1~h6、p、br、hr
  3. HTML 文本格式化 — strong、em、u、del、mark、span
  4. HTML 列表标签 — ul、ol、li
  5. HTML 链接与图片 — a、href、img、src、alt

第 2 阶段：CSS 基础（lesson-6~10）
  6. CSS 引入方式 — 行内、内部、外部样式表
  7. CSS 选择器基础 — 元素、类、id 选择器
  8. CSS 字体样式 — font-family、font-size、font-weight
  9. CSS 文本样式 — text-align、line-height、text-decoration
  10. CSS 背景样式 — background-color、background-image

第 3 阶段：HTML + CSS 进阶（lesson-11~15）
  11. HTML 表格基础 — table、tr、td、th
  12. CSS 盒模型基础 — content、padding、border、margin
  13. CSS 边框与圆角 — border、border-radius
  14. HTML 表单基础 — form、input、label
  15. CSS 内外边距深入 — padding/margin 简写、margin 居中

第 4 阶段：布局基础（lesson-16~20）
  16. HTML 语义化标签 — header、nav、main、section、footer
  17. CSS display 属性 — block、inline、inline-block
  18. CSS 浮动 float — float、clear、两栏布局
  19. CSS 清除浮动 — clearfix、overflow
  20. CSS 盒子阴影 — box-shadow

第 5 阶段：选择器与定位（lesson-21~25）
  21. CSS 组合选择器 — 后代、子代、并集、:hover
  22. CSS 伪类与伪元素 — :active、:focus、::before、::after
  23. CSS 定位 position — static、relative、absolute、fixed
  24. CSS 溢出处理 — overflow、text-overflow
  25. HTML 表单进阶 — select、textarea、button、placeholder

第 6 阶段：Flex 布局（lesson-26~30）
  26. Flex 布局基础 — display:flex、flex-direction
  27. Flex 对齐方式 — align-items、align-content
  28. Flex 子元素属性 — flex-grow、flex-shrink、order
  29. CSS 渐变背景 — linear-gradient、radial-gradient
  30. CSS 文本阴影 — text-shadow

第 7 阶段：响应式与动画（lesson-31~35）
  31. CSS 媒体查询 — @media、断点
  32. Flex 响应式布局 — flex-wrap
  33. CSS 过渡 transition — transition 简写
  34. CSS 变换 transform — translate、rotate、scale
  35. CSS 关键帧动画 — @keyframes、animation

第 8 阶段：CSS 变量与 Grid（lesson-36~40）
  36. CSS 变量与 calc — --var、var()、calc()
  37. Grid 布局基础 — grid-template-columns、gap
  38. Grid 行与区域 — grid-template-rows、grid-area
  39. Grid 子元素定位 — grid-column、grid-row、span
  40. CSS 实用技巧 — 居中大全、常见布局

第 9 阶段：JS 基础入门（lesson-41~45）
  41. JS 引入与输出 — script、console.log、alert
  42. 变量与数据类型 — let/const、字符串、数字、布尔
  43. 运算符与表达式 — 算术、比较、逻辑、三元
  44. 模板字符串 — 反引号、${} 插值
  45. 条件语句 — if/else、switch

第 10 阶段：循环与数组（lesson-46~50）
  46. 循环语句 — for、while、break、continue
  47. 数组基础 — 声明、索引、length、push/pop
  48. 数组方法一 — unshift/shift、splice、slice
  49. 数组方法二 — indexOf、includes、sort、join
  50. 字符串方法 — slice、split、replace

第 11 阶段：函数与对象（lesson-51~55）
  51. 函数基础 — 声明、参数、return
  52. 函数表达式与箭头函数 — 匿名函数、箭头函数
  53. 作用域与闭包 — 全局/局部作用域、闭包
  54. 对象基础 — 属性、方法、this
  55. 对象与数组遍历 — for...in、for...of、forEach

第 12 阶段：内置对象（lesson-56~60）
  56. Math 对象 — Math.random、Math.floor
  57. Date 对象 — 获取年月日时分秒
  58. JSON 数据格式 — parse、stringify
  59. 错误处理 try/catch — try、catch、throw
  60. ES6+ 新特性 — 解构赋值、展开运算符

第 13 阶段：DOM 操作（lesson-61~65）
  61. DOM 基础选择 — getElementById、querySelector
  62. DOM 样式与类名 — style、className、classList
  63. DOM 创建与删除 — createElement、appendChild
  64. DOM 属性操作 — getAttribute、setAttribute
  65. DOM 遍历关系 — parentNode、children、nextSibling

第 14 阶段：事件（lesson-66~70）
  66. 事件基础 — onclick、addEventListener
  67. 事件对象 — event、target、preventDefault
  68. 常用事件类型 — mouse、keyboard、form 事件
  69. 事件冒泡与委托 — 冒泡、委托、动态绑定
  70. 表单验证 — oninput、onsubmit、实时验证

第 15 阶段：定时器与 BOM（lesson-71~75）
  71. 定时器 — setInterval、setTimeout
  72. BOM 浏览器对象 — window、location、history
  73. 本地存储 localStorage — setItem、getItem
  74. 动画与 requestAnimationFrame — rAF、缓动
  75. 面向对象 class — class、constructor、extends

第 16 阶段：进阶 API（lesson-76~80）
  76. fetch 与异步请求 — fetch、Promise、async/await
  77. Canvas 绘图基础 — canvas、getContext
  78. Canvas 动画 — 动画循环、清屏
  79. Canvas 交互 — 鼠标交互、碰撞检测
  80. 模块化与代码组织 — 模块思想、最佳实践

============================================================
  设计说明
============================================================

1. 课程分开计数：普通课、小实战、总实战各自独立进度
2. AI 功能：
   - 普通课无 AI，AI 版本（-ai）有 AI 问答
   - 实战课无 AI，AI 版本（-ai）有 AI 问答 + AI 代码审查
3. 编辑器模板按类型区分（HTML/CSS/JS）
4. 用户等级根据普通课进度自动判断：
   - lesson 1~27：初学者，不要求过好
   - lesson 28~54：中等，提出少量提高建议
   - lesson 55~80：高等，提出较多提高建议
5. 兼容本地预览：lessons.js + localStorage，无需服务器
