# 齐鲁志愿罗盘 - 山东新高考可解释志愿规划助手

> 输入山东考生的位次、选科与个人偏好，快速生成可筛选的冲稳保志愿方案，并解释每个学校专业的推荐原因与风险。

## 快速开始

**双击 `index.html` 即可运行**，无需安装任何依赖，无需联网。

支持 Chrome / Edge / Firefox 等主流浏览器。手机和电脑均可浏览。

## 功能

1. **考生信息输入**：总分、总位次、选科、学费上限、省份偏好/排斥、专业偏好/排斥、办学性质排除（民办/中外合作/高收费）
2. **一键体验样例**：内置 3 个预设考生（理科中分段 / 文科高分段 / 理科低分段保本），点击立即出结果
3. **候选池与96志愿方案**：先生成候选志愿池，再一键生成最终96志愿方案（以冲24、稳40、保32为目标比例，某档候选不足时由其他档自动补齐，最终分档数量以页面实际结果为准。新增专业仅作为附加备选，不占96个名额）
4. **冲稳保分档**：基于往年录取位次自动分类——冲档、稳档、保底、新增（独立分档，不挤占保底）
5. **搜索与筛选**：按档位过滤、办学性质过滤、关键词搜索学校/专业/城市
6. **可解释详情**：点击任意志愿查看入选理由、风险提醒、关键数据（位次依据、选科匹配、学费、保研率等）
7. **风险标签**：新增专业、民办、中外合作、高收费、体检/色觉限制、历史波动、单科要求——醒目标识
8. **打印/导出**：支持浏览器打印当前方案

## 冲稳保分档规则

| 档位 | 判定条件 | 说明 |
|---|---|---|
| 冲 | 学校往年位次 < 考生位次 | 录取要求高于考生，尝试 |
| 稳 | 考生位次 ≤ 学校位次 ≤ 稳档上限 | 与考生接近，把握较大 |
| 保底 | 学校位次 > 稳档上限 | 明显低于考生，兜底 |
| 新增 | 新增专业（无往年数据） | 单独标记，不作稳妥保底 |

稳档上限：考生位次 ≤ 25 万时为「位次+3万」；> 25 万时为「位次×1.2」。
