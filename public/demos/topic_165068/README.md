# 📦 校园快递助手 - TRAE AI 创造力大赛初赛 Demo

## 项目简介

校园快递助手是一款面向大学生的微信小程序，旨在解决取快递时查找取件码繁琐分散、物流信息不统一的痛点，提供一站式快递管理解决方案。

## 功能特性

### 📋 核心功能
- **智能聚合取件码**：一键聚合所有平台的取件码，按驿站分类显示
- **实时物流追踪**：输入单号自动识别，实时展示包裹位置和预计送达时间
- **智能提醒系统**：快递到达自动通知，超时提醒，定时提醒
- **校园驿站地图**：内置校园内各快递驿站位置，一键导航
- **代取互助功能**：发布/接收代取任务，顺路帮同学取件
- **AI 路线规划**：选择多个快递，智能规划最优取件路线

### 🔍 查找筛选
- 按商品名称搜索
- 按取件地点筛选（东区、西区、南门、北门、图书馆）
- 按时间筛选（今日、近3天、近一周、超过7天）
- 按状态筛选（待取件、运输中、已取件）

### 📱 取件身份码
- 一键生成取件身份码
- 扫码取件时出示，方便快捷

## 技术栈

- **前端**：HTML5 + CSS3 + JavaScript (ES6+)
- **框架**：原生开发，无第三方框架依赖
- **存储**：LocalStorage（模拟持久化）
- **样式**：响应式设计，移动端优先

## 运行方式

### 方式一：直接打开（推荐）

1. 使用浏览器打开 `index.html` 文件
2. 首次打开会自动加载演示数据（12个快递，6个代取任务）
3. 即可体验所有功能

### 方式二：本地服务器（可选）

```bash
# 使用 Python 启动本地服务器
python -m http.server 8000

# 使用 Node.js
npx http-server -p 8000
```

然后在浏览器访问：`http://localhost:8000`

## 体验路径

### 🎯 核心体验流程

1. **打开应用** → 查看主页快递列表（12个演示快递）
2. **搜索筛选** → 尝试搜索商品名称或按地点筛选
3. **查看详情** → 点击任意快递卡片，查看取件码和物流时间轴
4. **AI 路线规划** → 勾选多个快递，点击底部「生成路线」按钮
5. **取件身份码** → 点击底部「取件身份码」按钮查看二维码
6. **代取互助** → 切换到「互助」Tab，查看和接单任务

### 📋 其他功能

- **添加快递**：智能识别（粘贴短信内容）或手动填写
- **物流追踪**：查看所有快递的实时物流状态
- **驿站地图**：查看校园内各驿站位置和营业时间
- **提醒设置**：设置到达提醒、超时提醒、定时提醒

### 存储方式

所有数据存储在浏览器 LocalStorage 中：
- `kd_packages`：快递列表
- `kd_tasks`：代取任务列表
- `kd_qrCode`：取件身份码
- `kd_reminderSettings`：提醒设置

## 注意事项

1. **首次打开**：建议关闭浏览器缓存后打开，确保加载最新演示数据
2. **浏览器兼容**：推荐使用 Chrome、Edge、Safari 等现代浏览器
3. **移动端体验**：在手机浏览器中打开可获得更好的移动端体验
4. **数据持久化**：本地存储数据会在清除浏览器数据时丢失
