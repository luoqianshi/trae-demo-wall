Bilingual Reader Demo - Instructions
=====================================

Option 1 (Recommended): Double-click "start-demo.bat"
  - Auto starts local server and opens browser
  - Requires Python or Node.js installed
  - Close the black window when done

Option 2: Manual start
  1. Open terminal in this folder
  2. Run: python -m http.server 8080
  3. Open browser: http://localhost:8080

Option 3: Use VS Code
  1. Install "Live Server" extension
  2. Right-click index.html -> Open with Live Server

Note: Double-clicking index.html directly will NOT work (browser security restriction).
