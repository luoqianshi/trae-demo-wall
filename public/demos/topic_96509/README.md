# 合规雷达 v3.0 - 具身智能法规导航台

> 3分钟搞懂你的机器人该遵守什么法规

## 📖 项目简介

合规雷达是一款面向具身智能（人形机器人、服务机器人、工业机器人等）行业的法规合规导航工具。帮助用户快速定位适用的法规标准，并提供官方获取渠道。

## ✨ 核心特性

- **📊 36条已核实标准**：覆盖中国、欧盟、美国、日本四大市场
- **🔍 智能筛选**：按机器人类型、目标市场、标准类别三维过滤
- **✅ 数据来源可靠**：每条标准均来自官方权威渠道，附带验证链接
- **🚀 纯前端部署**：无需后端服务器，静态文件即可运行
- **📱 响应式设计**：适配桌面端和移动端

## 🚀 快速开始

### 方式一：本地打开

直接在浏览器中打开 `index.html` 文件即可使用。

> **注意**：由于浏览器安全限制，直接双击打开 HTML 文件时，`fetch` 请求可能被 CORS 策略阻止。建议使用本地服务器方式运行。

### 方式二：本地服务器（推荐）

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

然后在浏览器访问 `http://localhost:8000`。

### 方式三：部署到服务器

将整个项目目录上传至任意静态文件托管服务（如腾讯云 COS、阿里云 OSS、Vercel、GitHub Pages 等）。

## 📋 法规数据说明

### 数据覆盖

| 市场 | 标准数量 | 来源 |
|------|---------|------|
| 🇨🇳 中国 | 17条 | 国家标准全文公开系统 |
| 🇪🇺 欧盟 | 18条 | ISO / EUR-Lex / CENELEC |
| 🇺🇸 美国 | 9条 | FCC / UL Solutions |
| 🇯🇵 日本 | 2条 | JISC / NITE |
| 🌍 国际 | 8条 | ISO / IEC |

> 注：部分标准覆盖多个市场，因此分类计数之和可能大于总数。

### 数据分类

- **安全标准**（14条）：机器人物理安全、协作机器人安全等
- **信息安全**（5条）：网络安全等级保护、数据加密等
- **EMC电磁兼容**（9条）：辐射测试、抗扰度等
- **功能安全**（4条）：控制系统安全部件设计等
- **AI伦理**（1条）：欧盟AI法案相关
- **环保**（1条）：RoHS等
- **认证**（2条）：CR认证等

### 数据来源铁律

> 所有法规数据必须来自官方权威渠道（国标全文公开系统 / 工信部 / ISO官网等），每条必须带官方链接。

本项目不包含任何标准正文内容，仅提供元数据导航和官方获取链接。如需查看标准全文，请访问对应的官方渠道。

## 🛠️ 技术栈

- **前端**：原生 HTML + CSS + JavaScript（零依赖）
- **数据**：JSON 文件存储，前端动态加载
- **部署**：静态文件，支持任意静态托管
