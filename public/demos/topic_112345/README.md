# 🌙 AI 声境 · Demo

> TRAE AI 创造力大赛初赛作品 · 社会服务赛道

## 📌 项目简介

**AI 声境** 是一款基于 AI 的声音场景智能创作平台。用户用文字描述想要的氛围（如"深夜书房，窗外下着小雨，壁炉里的火偶尔噼啪作响"），AI 实时合成一段独一无二的沉浸式声景，用于助眠、冥想、专注、阅读、放松等场景。

## 🚀 本地运行

直接双击 `index.html` 即可在浏览器中打开使用。

> 推荐使用 Chrome / Edge / Safari 最新版浏览器。音频需用户首次点击"▶"后才会激活（浏览器自动播放策略限制）。

## 🎧 核心功能（v2.0 增强版）

### 1️⃣ 情绪→声景智能映射算法（创新性）
内置 6 种情绪状态（平静/焦虑/疲惫/专注/低落/兴奋），每种情绪对应一套基于"声音疗愈心理学"的音轨配方。例如：
- **焦虑** → 加重低频底噪（85%）+ 颂钵铃音，钵声能调节副交感神经
- **专注** → 雨声+低频底噪，去掉所有干扰元素
- **低落** → 加强壁炉温暖感+铃音，引导情绪上扬

### 2️⃣ 8 个精选场景库（实用性）
按 **助眠/专注/冥想/放松** 四大类组织，分类标签可切换。每个场景都是经过调音的完整混音方案。

### 3️⃣ 文字→声景生成
自定义文字描述，AI 解析关键词并实时合成对应声景。

### 4️⃣ 5 轨独立混音器
雨声 / 壁炉 / 风声 / 低频底噪 / 高频铃音，每个音轨可独立调节音量。

### 5️⃣ 睡眠定时器
15/30/45/60/90 分钟可选，到时间后声景**渐弱退出**（10 秒淡出），避免突然中断影响睡眠。

### 6️⃣ 我的收藏
将调好的混音方案保存到本地，下次一键复用。

### 7️⃣ 使用历史与统计
自动记录最近 50 次使用，统计"最常听的场景""偏好情绪""总聆听时长"。

### 8️⃣ 实时频谱可视化
Canvas 绘制的声景波形反馈。

### 9️⃣ 零依赖
纯 Web Audio API 实时合成，无需任何音频素材文件，无需联网。

## 🛠 技术栈

- **Web Audio API** — 实时音频合成（白噪声 + 滤波 + LFO + 振荡器）
- **Canvas 2D** — 频谱可视化
- **localStorage** — 收藏/历史持久化
- **原生 HTML/CSS/JS** — 无任何外部框架依赖
