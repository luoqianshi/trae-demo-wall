1. Demo 简介

是什么

邻聚（LinkHood）是一个面向小区、大学和朋友圈的真实身份邻圈社交与生活供需交易平台，形态为移动端优先的 Web App，支持 Docker 一键部署。

面向谁

核心用户包括：小区居民（闲置交易、物业反馈、邻里互助）、大学生（校园活动、技能互助、跳蚤市集）、熟人朋友圈（小范围活动、私域交易）。平台通过邻圈身份认证建立信任基础，让陌生人变成熟人，让线上关系落到线下。

主要功能

  • 邻圈管理与身份认证 — 支持小区/大学/朋友圈三种邻圈类型，分别采用定位审核、学籍认证、好友授权三种验证方式，确保圈内成员真实可信
  • 生活供需发布与交易 — 覆盖活动招募、闲置物品、技能服务、居家创业、民生反馈五大分类，支持助力、评论、担保交易订单流程
  • 社交活动与民意反馈 — 活动报名、心情树洞、问答互助、意见反馈助力榜，构建邻里共治的社区生态

技术栈：

原生 HTML/CSS/JS Node.js + Express Sequelize ORM MySQL 8.0 Docker Compose JWT 认证 ColorUI 设计风格

2. Demo 创作思路

灵感来源

在城市生活中，邻里关系日益疏远。小区微信群信息嘈杂、闲鱼交易缺乏本地信任、社区意见难以汇聚推动。我们观察到：人们不是不需要邻里社交，而是缺少一个有信任基础的、垂直化的邻里互动平台。

想解决的问题

  • 信任缺失：陌生人之间不敢交易、不敢让孩子参加活动。通过邻圈身份认证（小区定位、学籍、好友关系）建立信任底座
  • 信息分散：闲置交易在闲鱼、活动在微信群、物业反馈在电话——邻聚把这些场景聚合到一个平台
  • 民意无门：物业维修、社区改造等意见缺乏集中反馈渠道。邻聚的"意见反馈榜"让居民可以助力推动，形成可视化的共治看板
  • 熟人社交断裂：朋友圈仅限线上互动，邻聚将线上关系引导到线下见面（活动、交易、互助）

为什么做这个方向

社区社交是一个高频、刚需但尚未被有效解决的领域。现有产品要么太泛（微信群信息过载），要么太窄（闲鱼只管交易）。邻聚的差异化在于：

  • 以邻圈为信任单位，而非城市级泛社交
  • 将社交 + 交易 + 共治三合一，而非单一功能工具
  • 参考闲鱼担保交易模式，但限定在可信邻圈范围内，降低交易风险
  • 引入信用体系和认证体系，让信任可量化、可累积

4. TRAE 实践过程

整个项目从需求构思到全栈实现、UI 设计、Bug 修复，全程使用 TRAE IDE 完成。以下是关键开发步骤：

1全栈项目搭建与数据库设计

向 TRAE 描述了邻聚平台的核心需求（邻圈社交 + 供需交易 + 身份认证），TRAE 自动生成了完整的项目结构：

  • 后端：Express + Sequelize，9 个数据模型（User、Circle、CircleMember、Need、Order、Activity、Feedback、AuthRecord、Comment）
  • 数据库：MySQL 8.0，9 个迁移文件，1 个种子数据文件（含 7 个用户、3 个邻圈、5 条供需、4 个订单等演示数据）
  • 部署：Docker Compose 一键启动前端、后端、MySQL 三个服务

2UI 设计迭代（Mid-Century → WeUI → ColorUI）

UI 风格经历了三轮迭代，每轮都通过自然语言描述让 TRAE 重写前端代码：

  • 第一轮：1950-60 年代中世纪现代设计美学（暖色调、有机形状）
  • 第二轮：微信小程序 WeUI 风格（绿色主色、列表式布局）
  • 第三轮：ColorUI 风格（蓝色 #0081FF 主色、胶囊按钮、卡片布局）— 最终方案

每次迭代 TRAE 都会完整重写 styles.css 和 app.js，保持功能不变的同时切换视觉风格。还通过 TRAE 完成了移动端适配（430px 宽度约束、底部导航栏 icon+text 格式、扁平 SVG 图标替换 emoji）。

3核心功能开发与业务逻辑

通过 TRAE 逐步实现了以下核心业务逻辑：

  • 邻圈加入审核：根据邻圈类型（community/university/friends）动态展示不同验证方式（定位审核/学籍认证/好友授权）
  • 供需发布与分类：5 大分类（活动、闲置物品、技能服务、居家创业、那些事儿），支持分类筛选和关键词搜索
  • 担保交易流程：接受需求 → 确认时间地点 → 担保支付 → 评价反馈，完整订单状态机
  • 认证体系：实名认证、行业认证、小区认证、大学认证，四类认证独立审核
  • JWT 认证中间件：Token 验证、用户状态管理、登录/登出流程

开发心得：

1. 自然语言驱动开发：不需要手写每一行代码，用中文描述需求，TRAE 能准确理解并生成完整功能模块。从数据库设计到 API 路由到前端页面，一条对话就能完成全栈功能。

2. 快速 UI 迭代：三轮 UI 风格切换，每次只需描述风格关键词（如"ColorUI 风格"、"扁平图标"），TRAE 自动重写全部样式代码，极大降低了设计试错成本。

3. Bug 定位高效：描述现象（"登录后导航栏不见了"），TRAE 能快速定位到 bottomNav() 的条件渲染逻辑和 handleLogin() 的状态同步问题，直接给出修复方案。

4. 踩坑经验：浏览器缓存导致 CSS/JS 修改不生效，需通过 ?v=X 版本号解决；Docker 容器间通信需注意网络配置和健康检查依赖。
