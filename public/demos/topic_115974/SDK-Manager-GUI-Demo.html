SDK Manager GUI

多语言 SDK 桌面管理工具 · 一个界面管好 Node.js / Java / Python / Maven

⬇ 下载体验 v1.0.0 📦 GitHub 仓库
🖥️ Windows 10+ ⚙️ .NET Framework 4.8 🌐 三语界面 📄 MIT License

核心功能

解决 SDK 安装、版本切换、环境变量配置的痛点

📦

多 SDK 统一管理

在一个界面管理 Node.js、Java、Python、Maven 四种 SDK，每版本独立目录，支持多版本共存。

🚀

多镜像源智能下载

内置官方源 + 国内镜像，按优先级 / 延迟 / 成功率 / 失败次数四维排序，故障自动转移。

⚙️

环境变量自动配置

安装后自动配置 PATH 和 HOME 变量，支持用户级 / 系统级，无需手动操作注册表。

🌐

多语言界面

简体中文 / 繁體中文 / English 三语切换，首次启动自动检测系统语言，运行时即时切换。

⏯️

下载任务管理

多任务并行、暂停 / 恢复 / 取消、断点续传、自动重试，实时显示进度和速度。

🔍

镜像源管理

添加 / 删除 / 编辑镜像源、延迟测试、优先级排序，Python / Node.js 支持包管理器镜像。
