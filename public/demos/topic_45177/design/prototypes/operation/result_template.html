成绩计算算法

净成绩 净计时算法

终点时间 - 起点时间 = 净成绩

function netTime(startTime, endTime) {
return endTime - startTime;
}
枪声 枪声成绩算法

终点时间 - 发枪时间 = 枪声成绩

function gunTime(endTime, gunStartTime) {
return endTime - gunStartTime;
}
分段 分段成绩算法

当前计时点时间 - 上一计时点时间 = 分段成绩

function splitTime(currentPoint, prevPoint) {
return currentPoint - prevPoint;
}
配速 平均配速算法

净成绩 ÷ 总距离 = 平均配速

function avgPace(netTime, distance) {
return netTime / distance;
}

成绩修正规则

缺失计时点处理

当选手缺失中间计时点数据时，使用相邻计时点数据进行插值计算

异常成绩过滤

自动过滤超出合理范围的成绩数据（如配速过快或过慢）

重复计时处理

当同一计时点有多条记录时，取最早的有效时间

DNF状态判定

未通过终点计时点的选手自动标记为DNF（未完赛）

DQ状态判定

未通过必要计时点的选手自动标记为DQ（取消资格）
