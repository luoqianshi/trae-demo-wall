报名须知

1. 参赛者须如实填写个人信息，如发现虚假信息将取消参赛资格。

2. 报名成功后不可更改参赛项目，因个人原因无法参赛，报名费不予退还。

3. 需在30分钟内完成支付，超时将自动取消报名。

4. 全马选手需提供近一年内半马以上距离的完赛证书。

5. 组委会有权根据报名情况调整名额分配。

健康要求

1. 参赛者应身体健康，有长期参加跑步锻炼的基础。

2. 以下疾病患者不宜参赛：先天性心脏病、高血压、脑血管疾病、心肌炎等。

3. 建议参赛者在赛前进行体检，确保身体状况适合参赛。

4. 比赛期间如感身体不适，应立即停止比赛并寻求医疗帮助。

领物须知

1. 领物时间：2026.10.18-19 09:00-18:00

2. 领物地点：世纪城新国际会展中心

3. 需携带本人身份证原件及领物码

4. 代领需提供代领委托书及双方身份证复印件
