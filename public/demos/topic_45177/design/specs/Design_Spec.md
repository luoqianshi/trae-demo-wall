# 智慧赛事服务系统 - 设计规范文档

## 1. 设计系统概述

### 1.1 设计愿景

智慧赛事服务系统的设计遵循"专业、高效、直观、可靠"的原则，为赛事组织者、调度员、现场人员和参赛选手提供卓越的用户体验。设计系统确保四大子系统（赛事指挥调度系统、赛事运营管理系统、选手服务小程序、智能设备管理平台）在视觉语言、交互模式和用户体验上保持一致性和连贯性。

### 1.2 设计原则

#### 1.2.1 一致性原则
- **视觉一致性**：统一的配色方案、字体系统、图标风格
- **交互一致性**：相同功能在不同页面保持一致的交互方式
- **语言一致性**：统一的文案风格和术语体系

#### 1.2.2 效率原则
- **快速导航**：常用功能快捷入口，减少操作步骤
- **批量操作**：支持批量处理，提升工作效率
- **智能推荐**：系统辅助决策，降低认知负担

#### 1.2.3 可视化原则
- **数据可视化**：复杂数据通过图表直观展示
- **状态可视化**：实时状态通过颜色、图标清晰标识
- **流程可视化**：操作流程和进度清晰展示

#### 1.2.4 可访问性原则
- **对比度标准**：符合WCAG 2.1 AA级标准
- **键盘操作**：支持键盘全操作
- **屏幕阅读器**：兼容主流屏幕阅读器

### 1.3 目标平台与适配

| 平台类型 | 具体平台 | 设计重点 |
|----------|----------|----------|
| Web端 | 指挥中心大屏、桌面端浏览器 | 大屏可视化、数据密集型界面 |
| 移动端 | iOS、Android | 简洁直观、触摸友好 |
| 小程序 | 微信小程序 | 轻量化、快速访问 |

## 6. 可访问性规范

### 6.1 WCAG 2.1 AA级标准

#### 6.1.1 可感知性

**对比度要求**
- 正常文字：对比度 ≥ 4.5:1
- 大号文字（≥18px或≥14px加粗）：对比度 ≥ 3:1
- UI组件：对比度 ≥ 3:1

**颜色使用**
- 不仅依靠颜色传达信息
- 提供额外的视觉提示（图标、文字、下划线）

#### 6.1.2 可操作性

**键盘操作**
- 所有交互元素可通过键盘访问
- Tab顺序符合逻辑
- 提供可见的焦点指示器

**焦点管理**
- 焦点指示器对比度 ≥ 3:1
- 模态框打开时焦点移至模态框
- 模态框关闭时焦点返回触发元素

#### 6.1.3 可理解性

**错误提示**
- 错误信息清晰易懂
- 提供错误修正建议
- 错误字段高亮标识

**帮助信息**
- 提供上下文帮助
- 表单字段提供标签和说明
- 复杂操作提供引导

### 6.2 ARIA标签

#### 6.2.1 常用ARIA属性

| ARIA属性 | 用途 | 示例 |
|----------|------|------|
| aria-label | 提供无文字元素的标签 | `<button aria-label="关闭">×</button>` |
| aria-describedby | 关联描述元素 | `<input aria-describedby="help-text">` |
| aria-expanded | 标识展开状态 | `<button aria-expanded="true">` |
| aria-hidden | 隐藏装饰性元素 | `<i class="fa fa-icon" aria-hidden="true"></i>` |
| role | 定义元素角色 | `<div role="dialog">` |

### 6.3 屏幕阅读器支持

#### 6.3.1 图片替代文本
- 所有图片提供alt属性
- 装饰性图片使用空alt或aria-hidden
- 复杂图片提供详细描述

#### 6.3.2 链接文本
- 链接文本清晰描述目标
- 避免使用"点击这里"等模糊文本

#### 6.3.3 表格可访问性
- 使用`<th>`定义表头
- 提供`scope`属性
- 提供`<caption>`标题

## 7. 动画和过渡规范

### 7.1 过渡时间

| 类型 | 时长 | 使用场景 |
|------|------|----------|
| 快速 | 150ms | 按钮悬停、焦点变化 |
| 默认 | 200ms | 卡片悬停、下拉菜单 |
| 中等 | 300ms | 模态框、侧滑面板 |
| 慢速 | 500ms | 页面切换、大动画 |

### 7.2 缓动函数

| 缓动函数 | Tailwind类 | 使用场景 |
|----------|------------|----------|
| ease-in | ease-in | 元素消失 |
| ease-out | ease-out | 元素出现 |
| ease-in-out | ease-in-out | 状态切换 |
| linear | linear | 持续动画 |

### 7.3 常用动画

#### 7.3.1 悬停效果
```css
/* 按钮悬停 */
transition-all duration-200 hover:scale-105

/* 卡片悬停 */
transition-all duration-300 hover:shadow-lg hover:-translate-y-1

/* 链接悬停 */
transition-colors duration-200 hover:text-accent
```

#### 7.3.2 点击效果
```css
/* 按钮点击 */
active:scale-95

/* 卡片点击 */
active:scale-98
```

#### 7.3.3 加载动画
```css
/* 旋转加载 */
animate-spin

/* 脉冲加载 */
animate-pulse

/* 弹跳加载 */
animate-bounce
```
