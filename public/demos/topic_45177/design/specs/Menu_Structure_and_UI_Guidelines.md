## 1. 菜单结构总览

本系统采用 **三级菜单结构**，严格按照 Excel 功能清单设计：

| 层级        | 视觉样式                                                 | 作用     |
| --------- | ---------------------------------------------------- | ------ |
| **一级分组**  | 大写、加粗、灰色文字（`text-gray-500 uppercase tracking-wider`） | 模块级分类  |
| **二级分组**  | 小号灰色文字标签（`text-gray-400`）                            | 功能组分类  |
| **三级菜单项** | 可点击链接 + FontAwesome 图标                               | 具体页面入口 |

## 3. UI设计通用规范

### 3.1 色彩规范

| 颜色类型    | 颜色值                               | 用途            |
| ------- | --------------------------------- | ------------- |
| **主色调** | `#0369A1`                         | 强调色、选中状态、操作按钮 |
| **背景色** | `#020617` / `#0F172A`             | 页面背景、侧边栏背景    |
| **文字色** | `#F8FAFC` / `#94A3B8`             | 主要文字、次要文字     |
| **状态色** | `#22C55E` / `#f59e0b` / `#ef4444` | 成功、警告、错误      |

### 3.2 导航菜单样式规范

```css
/* 一级分组标题 */
.menu-level-1 {
    @apply text-xs font-medium text-gray-500 uppercase tracking-wider mb-2 px-2;
}

/* 二级分组标题 */
.menu-level-2 {
    @apply text-xs text-gray-400 mb-1 px-2;
}

/* 三级菜单项 */
.menu-level-3 {
    @apply flex items-center p-2.5 rounded-md hover:bg-dark-lighter transition-colors duration-300;
}

/* 选中状态 */
.menu-level-3.active {
    @apply bg-accent/10 text-accent font-medium;
}
```

### 3.3 图标使用规范

- **图标库**: FontAwesome 4.7.0
- **图标尺寸**: 统一使用 14px-16px
- **图标与文字间距**: `mr-3` (12px)
- **图标选择原则**: 功能语义化、视觉一致性、同模块风格统一

## 5. 交互设计原则

### 5.1 反馈机制

- **操作反馈**: 点击、悬停时要有明确的视觉反馈（颜色变化、阴影、缩放）
- **加载反馈**: 异步操作显示加载动画，避免用户重复点击
- **结果反馈**: 操作成功/失败用不同颜色的Toast通知提示

### 5.2 操作流程

- **关键操作**: 删除、发布等危险操作需要二次确认
- **批量操作**: 支持多选和批量处理，提高效率
- **快捷操作**: 常用功能提供键盘快捷键支持

### 5.3 数据展示

- **长列表**: 使用虚拟滚动或分页
- **状态标识**: 用颜色和图标区分不同状态
- **空状态**: 无数据时显示友好的提示和操作引导

## 6. 响应式设计考虑

| 断点                   | 布局调整                         |
| -------------------- | ---------------------------- |
| **移动端 (< 640px)**    | 侧边栏可折叠收起、表格转为卡片式展示、操作按钮简化为图标 |
| **平板端 (640-1024px)** | 侧边栏宽度可调整、表格列可配置显示/隐藏         |
| **桌面端 (> 1024px)**   | 完整布局展示、充分利用空间显示更多信息列         |
