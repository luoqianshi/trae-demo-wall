## 1. 文档说明

### 1.1 优化说明

本文档在原版基础上进行了以下优化：

| 优化项 | 原版问题 | 优化措施 |

|--------|----------|----------|

| \*\*功能描述细化\*\* | 过于简单，缺少业务场景说明 | 增加业务场景、操作流程、数据关联说明 |

| \*\*UI设计重点深化\*\* | 过于笼统，缺乏具体指导 | 提供布局建议、组件选择、交互细节、状态处理 |

| \*\*页面合并\*\* | 部分功能拆分为多个页面，增加操作成本 | 将紧密关联的功能合并至同一页面，通过标签页/区域划分 |

| \*\*交互原则补充\*\* | 交互规范不够详细 | 增加表单验证、批量操作、实时反馈等具体指导 |

### 1.2 设计原则

1. \*\*效率优先\*\*：减少页面跳转，常用操作控制在3步以内

2. \*\*状态可视\*\*：关键状态用颜色+图标双重标识

3. \*\*反馈及时\*\*：所有异步操作必须提供加载状态和结果反馈

4. \*\*容错设计\*\*：危险操作二次确认，支持撤销/回退

5. \*\*一致性\*\*：同类型页面保持布局和交互方式统一

## 3. 详细页面设计规范

### 3.1 赛事管理

#### 功能描述

- \*\*业务场景\*\*：赛事组织者在赛前创建赛事，填写赛事名称、时间、地点、主办单位等基础信息，并设置赛事状态（规划中/报名中/进行中/已结束）。

- \*\*操作流程\*\*：

1. 点击“新增赛事”按钮，弹出表单

2. 填写赛事基础信息（带\*为必填）

3. 上传赛事LOGO和封面图

4. 保存后进入赛事列表，支持编辑、复制、删除

- \*\*数据关联\*\*：赛事创建后，其下项目、赛程规则、选手报名等均关联该赛事ID。

#### UI设计重点

- \*\*布局\*\*：顶部为筛选区（状态、时间范围、搜索框），右侧“新增赛事”按钮；中部为卡片式列表或表格展示赛事信息。

- \*\*赛事卡片内容\*\*：赛事名称、日期、地点、状态标签（用颜色区分）、操作按钮（编辑、复制、删除）。

- \*\*新增/编辑表单\*\*：左右两列布局，左侧基础信息，右侧图片上传。关键字段（名称、日期、地点）突出显示。

- \*\*状态切换\*\*：提供状态变更下拉框，变更后需二次确认。

- \*\*删除确认\*\*：弹出模态框，提示“删除后关联的项目和赛程规则将被清空，是否继续？”

---

### 3.2 项目管理

#### 功能描述

- \*\*业务场景\*\*：在一场赛事下创建多个竞赛项目/组别（如全程马拉松、半程马拉松、健康跑），为每个项目配置比赛距离、起终点位置、关门时间、报名限额等。

- \*\*操作流程\*\*：

1. 选择赛事后进入项目列表

2. 点击“新增项目”，填写项目信息

3. 支持项目排序、启用/停用

4. 支持批量导入项目（Excel模板）

- \*\*数据关联\*\*：项目关联赛事，选手报名时选择具体项目。

#### UI设计重点

- \*\*布局\*\*：左侧赛事树形选择器（展示所有赛事），右侧项目列表。

- \*\*项目列表\*\*：表格展示，列包括：项目名称、距离、关门时间、报名限额、状态（启用/停用）、操作。

- \*\*新增/编辑表单\*\*：分块布局——基本信息（名称、类型、距离）、时间设置（起跑时间、关门时间）、限额设置（总限额、性别限额）。

- \*\*批量导入\*\*：提供模板下载，导入后展示成功/失败明细，失败原因高亮显示。

---

### 3.3 出发批次管理

#### 功能描述

- \*\*业务场景\*\*：为分枪起跑赛事设置多个出发批次（如A批7:30，B批7:45），配置每批次的出发时间、最大人数、关联计时设备通道。

- \*\*操作流程\*\*：

1. 选择项目和批次号

2. 设置出发时间、人数上限

3. 关联计时设备通道（下拉选择已配置的计时点）

4. 支持拖拽调整批次顺序

- \*\*数据关联\*\*：批次关联计时设备通道，用于区分不同批次的计时数据。

#### UI设计重点

- \*\*布局\*\*：时间轴视图或表格视图，支持切换。默认时间轴视图更直观。

- \*\*时间轴视图\*\*：横向时间线，每个批次为一个卡片，卡片上显示批次名称、出发时间、人数、设备通道。支持拖拽调整顺序。

- \*\*表格视图\*\*：行内编辑，支持批量修改出发时间。

- \*\*冲突检测\*\*：同一项目下批次时间不可重叠，保存时自动校验并提示。

---

### 3.4 计时点网络规划

#### 功能描述

- \*\*业务场景\*\*：在地图上添加、编辑、删除计时点，配置每个计时点的类型（起点/终点/分段点）、名称、里程数、关联的物理设备编号。

- \*\*操作流程\*\*：

1. 地图上点击添加计时点

2. 填写计时点信息（类型、名称、里程数）

3. 关联物理设备编号（从设备平台同步的设备列表中选择）

4. 保存后地图上显示计时点图标

- \*\*数据关联\*\*：计时点与物理设备关联，用于接收设备上报的原始数据。

#### UI设计重点

- \*\*布局\*\*：左侧列表+右侧地图，比例30%:70%。

- \*\*地图操作\*\*：支持缩放、平移、测距，点击地图任意位置可添加计时点。

- \*\*计时点图标\*\*：不同类型用不同颜色/图标区分（起点-绿色旗帜、终点-红色旗帜、分段点-蓝色圆点）。

- \*\*设备关联\*\*：下拉选择时显示设备在线状态（在线/离线/未连接），便于运维确认。

- \*\*网络连接可视化\*\*：在地图上用线条连接相邻计时点，形成网络拓扑。

---

### 3.5 计时钟同步管理

#### 功能描述

- \*\*业务场景\*\*：配置官方计时时钟，向所有关联的官方计时显示屏、网络计时页面同步发送时间校准信号，确保所有计时设备时间一致。

- \*\*操作流程\*\*：

1. 查看当前官方时钟时间

2. 手动校准或设置自动同步时间

3. 点击“一键同步”，向所有设备发送校准信号

4. 查看同步结果反馈（成功/失败设备列表）

- \*\*数据关联\*\*：同步对象包括计时显示屏、计时点设备、网络计时页面。

#### UI设计重点

- \*\*布局\*\*：中央大时钟显示当前官方时间，周围分布设备同步状态面板。

- \*\*时钟面板\*\*：模拟表盘或数字时钟，支持手动调整时间（需管理员权限）。

- \*\*设备状态面板\*\*：以卡片或列表形式展示所有同步设备，显示设备名称、当前时间、同步状态（已同步/待同步/同步失败）。

- \*\*同步操作\*\*：提供“一键同步”大按钮，同步时显示进度条。

- \*\*同步记录\*\*：底部展示历史同步记录（时间、操作人、成功/失败数量）。

---

### 3.6 成绩模板与算法

#### 功能描述

- \*\*业务场景\*\*：定义各项目最终成绩的计算规则（净计时/枪声计时）、各分段点成绩是否显示，配置团队成绩算法（如取前N名平均、团队总分等）。

- \*\*操作流程\*\*：

1. 选择项目

2. 配置成绩计算规则（净计时/枪声计时，取最优成绩等）

3. 配置分段成绩显示规则（显示哪些分段点）

4. 配置团队算法（平均成绩/完赛率/积分制）

5. 保存并预览成绩计算效果

- \*\*数据关联\*\*：成绩计算引擎根据此配置生成最终成绩。

#### UI设计重点

- \*\*布局\*\*：左侧项目选择器，右侧规则配置区，分“个人成绩规则”和“团队成绩规则”两个标签页。

- \*\*规则配置\*\*：提供可视化规则构建器，下拉选择规则项，而非纯文本配置。

- \*\*公式编辑器\*\*：团队积分规则支持自定义公式，如`积分 = 100 - (排名 - 1) \* 2`。

- \*\*预览功能\*\*：点击“预览”弹窗展示模拟成绩计算示例（使用部分选手数据）。

- \*\*模板管理\*\*：支持保存为模板，下次直接加载。

---

### 3.7 选手信息管理（合并页面）

#### 功能描述

- \*\*业务场景\*\*：整合选手导入、信息维护、号码分配三大功能，一站式管理选手数据。

- \*\*页面功能区域\*\*：

- \*\*区域1 - 导入与导出\*\*：下载模板、批量导入、导出当前列表

- \*\*区域2 - 筛选与搜索\*\*：按项目、批次、姓名、号码、状态等多条件筛选

- \*\*区域3 - 选手列表\*\*：表格展示选手信息，支持行内编辑、批量操作

- \*\*区域4 - 号码分配\*\*：支持自动分配（按规则）或手动分配（选中选手后批量或单个设置）

- \*\*数据关联\*\*：选手信息与项目、批次、手环绑定、成绩记录关联。

#### UI设计重点

- \*\*导入导出区\*\*：水平排列按钮，导入时显示进度条和错误明细弹窗。

- \*\*筛选区\*\*：紧凑布局，常用筛选项常驻，高级筛选项可折叠。

- \*\*选手列表\*\*：

- 表格列：复选框 | 号码布 | 姓名 | 性别 | 项目 | 批次 | 手机号 | 手环绑定状态 | 操作

- 手环绑定状态用标签显示（已绑定-绿色、未绑定-灰色）

- 支持批量选中，批量修改项目/批次/分配号码

- \*\*号码分配弹窗\*\*：选择分配范围（所有选手/选中选手），输入起始号码，自动生成并校验冲突。

- \*\*行内编辑\*\*：双击字段可快速编辑（姓名、手机号等），保存时校验格式。

### 3.8 手环绑定管理（合并页面）

#### 功能描述

- \*\*业务场景\*\*：整合批量绑定、状态查询、解绑功能，一站式管理选手与手环的绑定关系。

- \*\*页面功能区域\*\*：

- \*\*区域1 - 绑定操作\*\*：批量绑定（扫描SN码或导入清单）、单个绑定

- \*\*区域2 - 查询筛选\*\*：按选手姓名/号码、手环SN、绑定状态查询

- \*\*区域3 - 绑定列表\*\*：展示绑定关系表，支持解绑操作

- \*\*数据关联\*\*：绑定关系同步至设备平台，用于设备状态追踪。

#### UI设计重点

- \*\*绑定操作区\*\*：

- 批量绑定：提供“扫描绑定”入口（支持扫码枪连续扫描），扫描时实时显示绑定成功/失败提示，失败时提示原因（选手已绑定/手环不存在/手环已绑定其他选手）。

- 导入绑定：支持Excel导入“选手ID-手环SN”对应关系。

- \*\*查询筛选区\*\*：支持手环SN模糊搜索，绑定状态下拉选择（全部/已绑定/未绑定）。

- \*\*绑定列表\*\*：

- 表格列：选手号码 | 姓名 | 项目 | 手环SN | 绑定时间 | 状态 | 操作

- 状态：正常（绿色）、设备异常（黄色-如离线/低电量）、已解绑（灰色）

- 解绑操作需二次确认，解绑后设备平台同步更新设备状态为“未绑定”。

- \*\*实时反馈\*\*：扫描或导入时，用Toast提示成功数量、失败数量，并列出失败明细（可导出）。

### 3.9 分组与跑团管理

#### 功能描述

- \*\*业务场景\*\*：后台管理员创建内部竞赛组别（如企业对抗组、高校校友组）和跑团，手动为跑团添加或移除成员。

- \*\*操作流程\*\*：

1. 创建组别/跑团（名称、类型、LOGO）

2. 从选手列表中选择成员加入

3. 支持批量添加、移除

4. 查看跑团成员列表及聚合数据（人数、平均成绩等）

- \*\*数据关联\*\*：组别/跑团信息用于团队PK排名计算。

#### UI设计重点

- \*\*布局\*\*：左侧树形结构展示所有组别/跑团，右侧展示选中组别的详细信息。

- \*\*左侧树\*\*：组别/跑团分类显示，支持拖拽排序。

- \*\*右侧顶部\*\*：组别/跑团基本信息（名称、类型、LOGO），编辑按钮。

- \*\*成员管理区\*\*：

- 顶部搜索框，从选手列表添加成员（多选）

- 成员表格：号码 | 姓名 | 项目 | 性别 | 加入时间 | 操作

- 支持批量移除

- \*\*聚合数据卡片\*\*：显示该组别/跑团的总人数、已完赛人数、平均成绩（赛后显示）。

### 3.10 跑团PK规则配置

#### 功能描述

- \*\*业务场景\*\*：为指定的跑团竞赛单元设置排名规则，如“按团队平均净成绩排名”、“按团队完赛率排名”、“按团队积分排名”。

- \*\*操作流程\*\*：

1. 选择跑团竞赛单元（多个跑团参与PK）

2. 选择排名规则（平均成绩/完赛率/积分制）

3. 若选积分制，配置积分公式（如按个人名次积分）

4. 保存规则，实时预览排名示例

- \*\*数据关联\*\*：规则用于成绩发布后的团队排名计算。

#### UI设计重点

- \*\*布局\*\*：顶部选择竞赛单元（下拉选择），下方规则配置区。

- \*\*规则选择\*\*：提供三种规则卡片，点击选中后高亮。

- \*\*积分制配置\*\*：

- 提供积分表编辑器：排名范围 → 积分值，支持添加多行

- 示例：第1名100分，第2名90分，第3-5名80分...

- \*\*预览功能\*\*：点击“预览排名”，弹窗展示按当前规则计算的团队排名（使用模拟数据或已完成的部分成绩）。

- \*\*保存\*\*：保存后规则生效，成绩发布时自动计算团队排名。

### 3.11 领物与签名管理

#### 功能描述

- \*\*业务场景\*\*：赛前物资领取时，工作人员扫描选手证件或号码布，系统显示选手信息及待领物资列表，选手电子签名确认后，标记为“已领物”，并同步完成手环绑定确认。

- \*\*操作流程\*\*：

1. 工作人员扫描选手证件/号码布二维码

2. 系统显示选手信息、物资包类型、手环绑定状态

3. 工作人员发放物资

4. 选手在平板/手机上进行电子签名

5. 系统标记“已领物”，并记录签名时间

6. 若手环未绑定，可现场扫码绑定（或确认后台已绑定）

- \*\*数据关联\*\*：领物状态同步至选手信息，电子签名记录存档。

#### UI设计重点

- \*\*布局\*\*：中央为选手信息卡片，底部为签名区，顶部为扫码结果提示。

- \*\*扫码后选手信息卡片\*\*：

- 显示选手照片（如有）、姓名、号码、项目

- 物资列表：勾选已领取物资（可预设）

- 手环绑定状态：已绑定显示绿色，未绑定提供“扫码绑定”按钮

- \*\*签名区\*\*：手写板区域（Canvas），提供“清除”和“确认”按钮。确认后签名图片保存。

- \*\*成功反馈\*\*：提交后显示“领物成功”大提示，自动进入下一个扫码等待状态。

- \*\*离线支持\*\*：页面缓存已签到列表，网络恢复后自动同步。

| \*\*加载状态\*\* | 异步操作显示骨架屏或加载动画，按钮显示loading状态 |

| \*\*成功反馈\*\* | Toast提示，绿色背景，持续3秒自动消失 |

| \*\*错误反馈\*\* | Toast提示，红色背景，或表单内红字提示 |

| \*\*二次确认\*\* | 删除、发布、锁定等危险操作弹出模态框，需用户确认 |

| \*\*表单验证\*\* | 实时验证（输入后失焦），提交时统一验证，错误字段红框+提示文字 |

| \*\*批量操作\*\* | 支持全选/反选，操作前确认，操作后反馈成功/失败数量 |

| \*\*快捷键\*\* | Enter提交表单，Esc关闭弹窗，Ctrl+S保存 |
