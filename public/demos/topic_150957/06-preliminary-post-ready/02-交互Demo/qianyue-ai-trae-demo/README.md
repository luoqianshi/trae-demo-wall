# 迁跃 AI｜TRAE 交互 Demo

## 打开方式

1. 解压 `Qianyue-AI-TRAE-Interactive-Demo.zip`。
2. 进入 `qianyue-ai-trae-demo/`。
3. 双击 `index.html`。

无需安装、无需登录、无需 API Key，也不需要本地服务器。

## 推荐体验路径

选择“林晨”案例，依次点击：

`开始迁移分析 → 查看证据缺口 → 进入唯一追问 → 勾选补证事实 → 二次分析 → 用户确认 → 生成 Transfer Asset`

## 真实性边界

- 本 Demo 来自 TRAE Work 单文件 HTML 产物链。
- 当前使用本地 Mock 流程，未连接真实模型。
- 不持久化输入，刷新页面即清空。
- 林晨、周衡、叶舒及案例指标均为匿名虚构演示内容。
- “证据充分度”不代表录用概率。
