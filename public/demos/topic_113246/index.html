🎯 产品介绍

星网语音助手是一款基于 Windows 的本地语音驱动 AI 桌面助手系统。通过唤醒词触发、语音录制、VAD 自动停录、语音转文字、自动聚焦目标应用并发送指令，实现"说句话就能让 AI 干活"的效率体验。

核心功能

🎯

唤醒词触发

支持 "hey_jarvis" 内置唤醒词和自定义 ONNX 模型，说一声即可激活系统。

🎙️

VAD 智能停录

基于 Silero VAD 的增量端点检测，说完自动停止录音，无需手动操作。

📝

使用 faster-whisper 进行语音转文字，支持中文和英文，GPU 加速。

语音转文字

🤖

多目标支持

支持发送到 Codex、ChatGPT、Cursor、Trae 等多个目标应用，可配置切换。

📍

系统托盘

后台常驻运行，支持暂停/恢复、手动录音、打开设置、开机自启等功能。

⚙️

控制中心

PySide6 图形界面，包含设置、诊断、命令历史、日志查看等功能。

核心代码示例

Pipeline Orchestrator（流程编排）

class VoiceOrchestrator: def __init__(self, engine=None, driver=None): self.engine = engine or create_stt_engine() self.driver = driver or get_default_driver() def process_audio(self, audio: np.ndarray) -> PipelineResult: # 1. 语音转文字 result = self.engine.transcribe_array(audio) text = result.text # 2. 发送到目标应用 sent = False send_error = None if self.send_enabled and text.strip(): try: self.driver.focus() self.driver.send_prompt(text) sent = True except Exception as e: send_error = str(e) # 3. 保存历史记录 append_command_history(text, sent) return PipelineResult(text=text, sent=sent, send_error=send_error)

Executor Router（应用路由）

DRIVER_FACTORIES = { "codex": CodexDriver, "chatgpt": ChatGPTDriver, "cursor": CursorDriver, "trae": TraeDriver, } def create_driver(target=None): key = target or settings.DEFAULT_EXECUTOR_TARGET return DRIVER_FACTORIES[key]()

📦 安装使用

1

克隆项目

git clone https://github.com/你的用户名/VoiceControl.git

2

创建虚拟环境

python -m venv .venv

3

安装依赖

.venv\Scripts\pip.exe install -r requirements.txt

.venv\Scripts\pip.exe install -e .

4

启动应用

.venv\Scripts\pythonw.exe -m voicecontrol.tray_app （后台托盘）

.venv\Scripts\python.exe -m voicecontrol.ui.settings_app （控制中心）

运行命令汇总

# 后台托盘模式（日常使用） .venv\Scripts\pythonw.exe -m voicecontrol.tray_app # 控制中心界面 .venv\Scripts\python.exe -m voicecontrol.ui.settings_app # 桌面宠物悬浮窗 .venv\Scripts\pythonw.exe -m voicecontrol.ui.desktop_pet_app # 前台调试模式（有控制台输出） .venv\Scripts\python.exe -m voicecontrol.main --wake # 只转写，不发送 .venv\Scripts\python.exe -m voicecontrol.main --wake --no-send

使用说明

  • 启动托盘后，说唤醒词 "hey jarvis" 即可激活系统
  • 激活后会听到蜂鸣提示，然后说出你的命令
  • 说完后等待约 3 秒静音，系统自动停止录音并转写
  • 转写完成后自动聚焦目标应用并发送指令
  • 可通过托盘菜单暂停/恢复、手动录音、打开设置
  • 按 F9 可手动开始/停止录音
