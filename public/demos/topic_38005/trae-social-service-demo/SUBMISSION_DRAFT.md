# 初赛提交文档

## 标题

社会服务 + 邻里预审：社区办事材料预审助手

---

## 1. Demo 简介（≤150 字）

“邻里预审”是一款小程序风格的社区办事材料预审工具。居民在手机上选择办事事项（居住证、医保报销、老年优待卡、灵活就业社保补贴），勾选已准备材料后系统自动计算完整度，并根据用户输入的关键词（代办、异地、行动不便等）智能识别场景风险，生成包含缺失项清单、补材料建议、风险提醒和窗口沟通话术的一页式办事清单。社区端同步展示待补材料汇总、高优先级事项和今日预审数量，帮助基层工作人员主动服务。所有判断均标注“仅作预审参考，最终以窗口要求为准”。

---

## 2. 创作思路

### 为什么属于社会服务赛道？

社区办事中，居民最大的痛点不是“不想办”，而是“不知道该带什么”——材料格式不对、缺少盖章、代办手续不明确，导致反复跑窗口。基层工作人员每天大量精力消耗在重复解释材料要求上，而非提供更有价值的服务。

本 Demo 将“材料预审”前移到了手机端，用一个轻量交互工具弥合居民与窗口之间的信息鸿沟：
- **降低居民办事门槛**：提前知道缺什么、怎么补，减少无效往返
- **提升基层服务效率**：社区端概览让工作人员一眼看到待补材料和高风险件，变被动接待为主动提醒
- **关注弱势群体**：内置代办、异地、行动不便等特殊场景识别，确保服务不落一人

这正契合社会服务赛道“用技术优化公共服务、提升社会治理效能”的方向。

## 3. 主要功能清单

| 功能 | 说明 |
|------|------|
| **智能材料预审** | 支持 4 项常见社区办事事项，逐项勾选材料后实时计算完整度（环形进度条），一键生成预审建议 |
| **场景关键词识别与风险提醒** | 自动识别用户输入中的“代办、异地、电子材料、不在本地、老人行动不便”五类关键词，给出针对性办理提示 |
| **一页式办事清单** | 每次预审生成 4~5 条结构化清单：材料完整度 → 补材料具体要求 → 场景风险提醒 → 办事指引 → 窗口沟通话术，居民可复制话术直接使用 |
| **社区端动态概览** | 模拟社区工作台：今日预审数、需补材料数、高优先级事项列表实时联动，用户预审结果置顶展示 |

## 5. 复赛产品路线图

```
初赛 MVP                    复赛 V1.0                    复赛 V2.0
(当前)                      (功能深化)                   (生态扩展)
──────────────────────────────────────────────────────────────────
纯前端静态 Demo              + 后端服务                   + 多端联动
4 项办事事项                 + 接入真实政策库             + 社区网格员主动推送
预设关键词正则匹配           + NLP 语义理解              + AI 对话式办事引导
模拟社区端概览               + 真实社区管理后台           + 数据大屏与压力预警
本地 localStorage 模拟        + 用户体系 & 预审记录        + 与政务平台 API 对接
```

**具体迭代方向：**

1. **智能识别升级**：引入 OCR 识别身份证、发票、病历等材料，自动提取关键信息做格式校验
2. **政策库接入**：对接各地社区办事政策 API，确保材料清单实时更新而非静态预设
3. **适老化与无障碍**：大字体模式、语音输入办事描述、一键拨打窗口电话
4. **社区端深化**：真实用户管理后台，预审记录归档，材料缺失分布热力图，窗口忙闲时段预测
5. **多端联动**：居民端 → 社区端 → 上级政务平台，实现预审结果的跨层级流转
6. **志愿者协作**：为行动不便居民匹配就近志愿者，提供上门帮办、材料代传递服务

## 体验方式

1. 直接在浏览器中打开项目根目录下的 `index.html`
2. 使用 Chrome/Edge 开发者工具切换到移动端视图（推荐 390×844）以获得最佳小程序体验
3. 无需安装任何依赖，纯静态 HTML + CSS + JS
