# 邻里预审 - TRAE AI 创造力大赛初赛 Demo

这是一个小程序风格的静态交互 Demo，项目方向为“社会服务 / 社区办事材料预审助手”。

## 体验方式

直接用浏览器打开 `index.html` 即可体验。

## 初赛帖可写的核心功能

- 选择社区常见办事事项。
- 勾选或模拟上传已准备材料。
- 根据用户情况生成材料缺失项、风险提醒和窗口沟通话术。
- 社区端可查看待补材料和高优先级预审件。

## 建议在 TRAE 中保留的 Session

初赛帖通常需要展示 TRAE 实践过程，并附关键任务对话的 Session ID。建议至少保留：

1. 产品需求与用户流程设计。
2. 小程序风格页面开发。
3. 材料预审逻辑与结果生成优化。
4. 移动端样式和交互细节修复。
