# Global Office · 职场英语互动剧情 Demo

产品形态一句话：这是一个可直接打开体验的 `Web App/H5`（单页网站，纯前端可离线运行），用于验证“把职场英语表达选择做成剧情推进机制”的产品思路。

## 怎么打开体验

### 方式 A：直接双击打开（推荐）

1. 解压后进入目录
2. 双击 `index.html`

### 方式 B：本地起一个静态服务（更稳定）

在该目录下执行（任选其一）：

```bash
# 如果你的电脑有 Python（大多数 Mac 默认有）
python3 -m http.server 8000
```

或：

```bash
# 如果你更习惯 Node.js
npx http-server -p 8000
```

然后访问：

`http://localhost:8000/`

## Demo 里有什么

- 双线入口：`HR 线` / `PM 线`（各 1 章可试玩）
- 每次选择都包含：
  - 英文表达 +（可选）中文对照
  - 语气/后果提示（礼貌、强势推进、风险等）
  - “关系信任 / 时间压力 / 风险暴露”三维局势变化
  - 讲解反馈 + 关键表达沉淀到短语本
- 进度与短语本：使用浏览器 `localStorage` 自动保存（清空进度按钮可重置）

## 参赛上传建议（对应社区要求）

社区支持“交互式可体验的 HTML 文件（Zip 上传）”。你可以直接把整个 `global-office-demo/` 目录打包成 Zip 上传，确保 Zip 里包含：

- `index.html`
- `assets/`（`styles.css`、`app.js`、`story.json`）
