StoryForge 使用说明
第一步：配置 AI
1. 打开 AI 配置
点击页面右上角的 ⚙️ AI配置 按钮。

2. 选择 API 提供商
Coze 扣子：推荐使用，国内访问稳定
OpenAI / 兼容接口：适合有 OpenAI Key 或第三方兼容接口的用户
3. 填写配置信息
如果选 Coze 扣子：

字段	说明
API Endpoint	https://api.coze.cn/open_api/v2/chat
API Key / Token	在 Coze 官网「个人访问令牌」中生成（PAT 开头）
Bot ID	你在 Coze 创建的 Bot 的 ID（一串数字）
用户标识（可选）	随便填，用于区分不同用户，例如 storyforge_user
如果选 OpenAI / 兼容接口：

字段	说明
API Endpoint	https://api.openai.com/v1/chat/completions （或你的兼容接口地址）
API Key	你的 API Key
模型选择	GPT-4o-mini / GPT-4o / GPT-4 / GPT-3.5-turbo
4. 测试连接
填完后点击 🧪 测试连接 按钮，确认配置正确。

5. 保存配置
点击 保存配置，配置会保存在本地浏览器中。

第二步：小说改编模式（基于原著改分支）
1. 选择模式
在创作工作台点击 📖 小说改编模式。

2. 上传小说
把你的小说 TXT 文件拖到上传区域，或点击选择文件。

💡 支持长篇小说：AI 会分段阅读（每段 8000 字），逐段总结后汇总分析，几十万字也能完整理解。

3. 等待 AI 分析
分析过程中会显示进度提示：

AI 正在阅读第 X/N 段...
AI 正在汇总分析全文...
分析完成后，会展示：

小说标题
角色数量、剧情节点数量、总字数
主要角色标签
4. 选择决策主角
在「选择当前决策主角」下拉框中选择你想站在谁的视角做选择。

💡 所有分支选项都是该主角的主动选择，不会假设其他角色改变行为。

5. 选择剧情节点
在故事时间线中点击任意节点，节点会高亮显示。

6. 生成分支
点击节点下方的 ✨ 生成分支 按钮。

AI 会生成 3 个选项，都是决策主角可以主动做出的具体选择（不是笼统的"隐忍路线/反击路线"）。

7. 选择分支，继续探索
点击选项后，AI 会续写接下来的剧情（至少 300 字），并生成新的选项。

如此反复，直到到达结局。

第三步：自由创作模式（从零开始写故事）
1. 选择模式
在创作工作台点击 ✍️ 自由创作模式。

2. 填写设定
字段	说明
角色设定	主要角色的身份、性格、关系等
故事背景	世界观、时代背景、故事起因
故事风格	甜蜜宠溺 / 虐恋情深 / 悬疑推理 / 古风穿越 / 科幻未来
故事篇幅	短篇（约 10 个分支到结局）/ 中篇（约 20 个）/ 长篇（约 30 个）
🎯 当前决策主角	输入主角名字，后续所有选择围绕此角色展开
3. 开始创作
点击 ✨ 开始 AI 引导创作 或 🚀 生成故事 按钮。

AI 会生成初始剧情和 3 个选择选项。

4. 选择分支，续写故事
和小说改编模式一样，选择选项后 AI 续写剧情，直到到达结局。

第四步：剧情树与回溯
查看剧情树
右侧边栏的 📊 剧情树 面板会实时展示你走过的故事路线。

回溯到某个节点
点击剧情树中的任意节点，可以回到那个位置。

重新选择分支
回溯后选择新的选项，旧的后续分支会被自动清除，开启全新的剧情线。

第五步：保存与分享
保存故事
点击右上角 💾 保存故事，给故事起个名字，确认保存。

保存的故事可以在 📚 我的故事 中找到，随时打开继续编辑。

我的故事
点击右上角 📚 我的故事，可以：

打开已保存的故事继续创作
重命名故事
删除故事
导出 demo（生成 demo-story.js 文件）
导出故事文本
在右侧 ⚡ 快捷操作 中点击 📥 导出故事文本，会下载完整的故事文本文件。

生成分享链接
点击 🔗 生成分享链接，复制链接发给朋友。

💡 分享链接打开后是只读模式，对方只能看完整故事线，不能修改。

对比原著结局
点击 ⚖️ 对比原著结局，会显示：

原著结局（概括版，约 150 字）
你的结局（概括版，约 150 字）
可以点击查看完整版本
常见问题
Q：不上传小说能体验吗？ A：可以，页面加载时会自动加载示例 Demo 故事（如果有 demo-story.js 文件）。但完整功能需要配置 AI 并上传小说。

Q：AI 分析失败怎么办？ A：AI 会自动重试最多 3 次。如果还是失败，会提示你选择：重新分析，或使用本地分析（准确率较低）。

Q：保存的故事换电脑还有吗？ A：保存在浏览器 localStorage 中，换电脑会丢失。可以用「导出 demo」功能生成 demo-story.js 文件，拷贝到新电脑的同一目录下，打开页面会自动加载。

Q：能分享给不在同一台电脑的人吗？ A：分享链接只能在同一台电脑的同一浏览器打开（因为数据存在 localStorage）。要跨设备分享，需要导出 demo-story.js 文件，连同整个文件夹一起拷贝给对方。
