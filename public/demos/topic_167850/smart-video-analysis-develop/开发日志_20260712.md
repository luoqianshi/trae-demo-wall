## 1. 项目概览

**项目名称**：多模态视频智能解析与创作辅助系统（Smart Video Analysis, SVA）

**项目目标**：构建一个集视频上传解析、智能转写、关键帧提取、多视频融合、帧级创作等功能于一体的 AI 辅助创作平台。

**技术栈**：
- 后端：Java 17 + Spring Boot 3.2.5 + MyBatis-Plus + MySQL 8.0 + Redis 7 + MinIO + FFmpeg
- 前端：Vue 3 + TypeScript + Vite + Element Plus + Pinia + Axios
- 容器化：Docker Compose（MySQL、Redis、MinIO）

**开发阶段**：Phase 0（脚手架）→ Phase 1（用户认证）→ Phase 2（视频上传解析）→ Phase 3（解析结果/导出/搜素）→ Phase 4（多视频融合）→ Phase 5（帧级创作）

## 5. 问题与解决方案

### 5.1 严重问题

#### 问题 1：VideoUpload.vue 状态码映射错误
- **现象**：视频状态显示为"未知"，操作按钮（解析、查看结果）不显示
- **原因**：`getStatusType`/`getStatusText` 使用字符串键（`uploaded`/`analyzing`/`completed`），但后端返回数字状态码
- **解决方案**：改为数字键映射，对齐后端 `TaskStatus` 枚举（0=已上传, 1=解析中, 2=已完成, 3=失败）
- **文件**：[VideoUpload.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/views/VideoUpload.vue#L345-L367)

#### 问题 2：Video.status 未同步更新
- **现象**：视频解析完成后状态仍停留在 1（解析中），前端永远看不到"查看结果"按钮
- **原因**：`VideoAnalysisMainServiceImpl.completeAnalysis()` 和 `failAnalysis()` 只更新了 `VideoAnalysis` 记录，没有同步更新 `Video.status`
- **解决方案**：在私有方法中增加 `videoService.updateVideoStatus(videoId, TaskStatus.SUCCESS/FAILED.getCode())`
- **文件**：[VideoAnalysisMainServiceImpl.java](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/src/main/java/com/sva/service/impl/VideoAnalysisMainServiceImpl.java#L47-L56)

### 5.2 中等问题

#### 问题 3：字段名不一致
- **现象**：视频上传时间显示为 "-"
- **原因**：模板用 `row.createdAt`，后端 `Video` 实体字段是 `createTime`
- **解决方案**：修改模板为 `createTime`
- **文件**：[VideoUpload.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/views/VideoUpload.vue#L230-L233)

#### 问题 4：MultiFusion.vue 过滤条件错误
- **现象**：已解析视频不显示在融合页面的可选列表中
- **原因**：`analyzedVideos` 过滤 `v.status === 3`（失败），应为 `v.status === 2`（已完成）
- **解决方案**：修正过滤条件
- **文件**：[MultiFusion.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/views/MultiFusion.vue#L291-L293)

#### 问题 5：FusionServiceImpl 状态判断错误
- **现象**：融合任务创建时提示"视频未解析完成"，即使视频已解析
- **原因**：`v.getStatus() != 3` 应为 `v.getStatus() != 2`（SUCCESS=2）
- **解决方案**：修正状态判断
- **文件**：[FusionServiceImpl.java](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/src/main/java/com/sva/service/impl/FusionServiceImpl.java#L47)

### 5.3 交互问题

#### 问题 6：轮询定时器泄漏
- **现象**：离开页面后轮询仍在继续
- **解决方案**：增加 `onUnmounted` 清理定时器，增加最大轮询次数（60 次 = 90 秒）超时保护
- **文件**：[MultiFusion.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/views/MultiFusion.vue#L353-L394)、[FrameWorkspace.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/views/FrameWorkspace.vue)

#### 问题 7：空状态无引导
- **现象**：无已解析视频时页面空白
- **解决方案**：添加 `<el-empty>` 组件，提供"去上传视频"按钮
- **文件**：[MultiFusion.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/views/MultiFusion.vue#L48-L50)

### 5.4 环境问题

#### 问题 8：Windows Winsock 问题
- **现象**：后端重启后卡在 MinIO 初始化，端口监听但无法连接
- **原因**：Windows JDK Socket 缓存问题
- **解决方案**：`netsh winsock reset` + 系统重启；已添加 `CustomSocketFactory.java` 缓解

### 5.5 数据库迁移问题

#### 问题 9：实体类与 SQL 脚本不一致
- **现象**：在另一台机器上开发时，数据库表结构与代码不匹配导致字段缺失或类型错误
- **原因**：V1 初始化脚本中的注释与实际代码行为不一致（如 `t_video.status` 注释说 0=上传中，但代码实际用 0=已上传）；部分字段类型不匹配（`duration` SQL 为 INT，实体为 Double）
- **解决方案**：创建 V2 迁移脚本 `V2__fix_schema.sql`，修正：
  - `t_video.status` 注释：0-已上传 1-解析中 2-已完成 3-失败
  - `t_video.duration` 类型：INT → DOUBLE
  - `t_video.fps` 类型：DECIMAL → DOUBLE
  - 各任务表状态码注释统一对齐
- **文件**：[V2__fix_schema.sql](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/src/main/resources/db/migration/V2__fix_schema.sql)

## 6. 技术栈与架构

### 6.1 后端架构

```
Controller层（REST API）
    ↓
Service层（业务逻辑 + @Async 异步）
    ↓
Mapper层（MyBatis-Plus）
    ↓
Entity层（数据库实体）
    ↓
数据库（MySQL 8.0）
```

**核心配置**：
- 数据库：MySQL 8.0（Docker，端口 13306）
- Redis：7.x（Docker，端口 16379）
- MinIO：latest（Docker，端口 9000/9001）
- 后端服务：Jetty，端口 18080

**安全框架**：Spring Security + JWT

### 6.2 前端架构

```
Vue Router（路由）
    ↓
Pinia Store（状态管理）
    ↓
Axios（HTTP 请求）
    ↓
Element Plus（UI 组件）
```

**页面列表**：
- `/login` - 登录
- `/register` - 注册
- `/video-upload` - 视频上传解析
- `/analysis-result/:id` - 解析结果详情
- `/multi-fusion` - 多视频融合创作
- `/frame-workspace` - 帧级创作工作台
- `/image-search` - 以图搜视频
- `/audio-workspace` - 音频创作工作台（骨架）
- `/online-editor` - 在线剪辑工作台（骨架）
