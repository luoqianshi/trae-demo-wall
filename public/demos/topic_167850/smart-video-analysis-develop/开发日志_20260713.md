## 5. 问题与解决方案

### 5.1 后端编译错误

#### 问题 1：`insertBatchSomeColumn` 方法不存在
- **现象**：`EditorServiceImpl.java` 中调用 `trackMapper.insertBatchSomeColumn(tracks)` 编译失败
- **原因**：MyBatis-Plus 版本问题，`insertBatchSomeColumn` 需要特定版本支持
- **解决方案**：改为循环插入 `trackMapper.insert(track)`
- **文件**：[EditorServiceImpl.java](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/src/main/java/com/sva/service/impl/EditorServiceImpl.java)

#### 问题 2：`LambdaQueryWrapper.query()` 语法错误
- **现象**：`EditorAnalysisServiceImpl.java` 中 `LambdaQueryWrapper.<TimelineTrack>query()` 编译失败
- **原因**：LambdaQueryWrapper 构造方式错误
- **解决方案**：改为 `new LambdaQueryWrapper<TimelineTrack>()`
- **文件**：[EditorAnalysisServiceImpl.java](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/src/main/java/com/sva/service/impl/EditorAnalysisServiceImpl.java)

#### 问题 3：Lombok 注解未生效（严重）
- **现象**：所有使用 `@Data` 注解的实体类都找不到 getter/setter 方法
- **原因**：Maven 编译器插件的 annotationProcessorPaths 配置未正确传递 Lombok
- **解决方案**：在 `pom.xml` 中添加 Maven Compiler 插件配置，指定 Lombok 注解处理器路径；验证单独 javac 编译时需同时指定 `-classpath` 和 `-processorpath`
- **当前状态**：单独测试 javac 编译已验证成功，但 Maven 编译仍失败，需进一步调试
- **文件**：[pom.xml](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/pom.xml)

### 5.2 Socket 连接问题

#### 问题 4：Windows Socket 问题
- **现象**：`Socket operation on nonsocket: socket` 错误
- **原因**：Windows JDK Socket 缓存问题
- **解决方案**：重构 `CustomSocketFactory.java`，移除自定义实现，使用 MySQL 驱动默认配置
- **文件**：[CustomSocketFactory.java](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-server/src/main/java/com/sva/config/CustomSocketFactory.java)

### 5.3 前端构建错误

#### 问题 5：Element Plus 图标导入错误
- **现象**：`Volume` 图标不存在导致构建失败
- **解决方案**：替换为正确图标名称（如 `Mic` 替代 `Volume`）
- **文件**：[PropertyPanel.vue](file:///d:/ai-project/smart-video-analysis/smart-video-analysis-web/src/components/PropertyPanel.vue)

## 8. 运行方式

### 8.1 启动 Docker 服务

```bash
docker-compose -f docker-compose.dev.yml up -d
```

### 8.2 启动后端服务

```bash
cd smart-video-analysis-server
mvn package -DskipTests
java -jar target/smart-video-analysis-server-1.0.0.jar
```

**注意**：当前 Lombok 编译问题未完全解决，可能需要先修复编译问题才能启动

### 8.3 启动前端服务

```bash
cd smart-video-analysis-web
npm install
npm run dev
```

服务地址：http://localhost:5173
