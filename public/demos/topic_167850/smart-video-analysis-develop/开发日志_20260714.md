## 3. 问题与解决方案

### 3.1 Lombok 编译问题

- **现象**：Maven 编译时所有 `@Data` 注解的实体类都找不到 getter/setter
- **原因**：pom.xml 中 Lombok 依赖引入方式有问题
- **解决方案**：Claude Code 修复了 pom.xml 中的依赖配置
- **当前状态**：✅ 已解决，编译通过（123 个源文件）

### 3.2 AudioCreationService 无实现类

- **现象**：Spring Boot 启动时报错 `No qualifying bean of type 'com.sva.service.AudioCreationService'`
- **原因**：接口定义了但没有实现类
- **解决方案**：创建 `AudioCreationServiceImpl.java` 实现类
- **当前状态**：✅ 已解决

### 3.3 Windows Socket 问题

- **现象**：`Socket operation on nonsocket: socket`，Jetty 和 Node.js 都无法启动
- **原因**：Trae 沙箱环境网络限制，非代码问题
- **当前状态**：✅ 已验证 - 在正常环境（Claude Code）中可正常启动，代码本身没问题
- **验证结果**：
  - 启动时间：4.5秒
  - 端口：8080（HTTP）
  - 数据库连接：H2 内存数据库正常
  - Spring Security：正常工作
  - 仅 MinIO 连接失败（服务未运行，非关键）

### 3.4 MinIO 连接失败（非关键）

- **现象**：`Failed to connect to localhost/[0:0:0:0:0:0:0:1]:19000`
- **原因**：MinIO 服务未启动
- **影响**：不影响应用核心功能，仅文件上传下载不可用
- **当前状态**：⚠️ 非关键错误，可忽略

## 6. 运行方式

### 6.1 使用 H2 内存数据库（推荐，无需 Docker）

```bash
# 已默认配置为 h2 profile
cd smart-video-analysis-server
mvn spring-boot:run
```

### 6.2 使用 MySQL（需 Docker）

修改 `application.yml` 中 `active: dev`，然后启动 Docker：

```bash
docker-compose -f docker-compose.dev.yml up -d
cd smart-video-analysis-server
mvn spring-boot:run
```

### 6.3 启动前端

```bash
cd smart-video-analysis-web
npm install
npm run dev
```

### 6.4 关键配置

| 服务 | 端口 | 说明 |
|------|------|------|
| 后端 | 18080 | API 服务 |
| 前端 | 5173 | 开发服务器 |
| H2 控制台 | 18080/h2-console | 内存数据库控制台 |
| Swagger | 18080/doc.html | API 文档 |

### 6.5 注意事项

- 首次启动会自动初始化数据库表结构（使用 H2 时为内存库，重启丢失）
- 默认使用 Spring Security，密码会在启动日志中显示
- MinIO 未启动时文件上传功能不可用，但不影响其他功能
