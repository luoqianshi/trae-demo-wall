# 多模态视频智能解析与创作辅助系统 — 开发计划

> 本文档为项目全周期开发计划，后续开发将严格按照此计划逐步推进。
> 技术选型依据: [技术选型方案.md](./技术选型方案.md)

---

## 一、项目分期总览

| 阶段 | 名称 | 周期 | 交付目标 |
|------|------|------|---------|
| **Phase 0** | 项目脚手架搭建 | 第 1 周 | 基础设施就绪，项目可启动运行 |
| **Phase 1** | 用户系统 + 基础框架 | 第 2 周 | 登录注册、权限基础、前端路由骨架 |
| **Phase 2** | 视频上传与解析 | 第 3–4 周 | 上传、存储、音视频分离、转写、关键帧提取 |
| **Phase 3** | 解析结果 + 以图搜视频 | 第 5 周 | 结果展示、文案导出、图像检索 |
| **Phase 4** | 多视频融合创作 | 第 6–7 周 | 多视频选择、AI 融合方案生成 |
| **Phase 5** | 帧级创作工作台 | 第 8 周 | ComfyUI 对接、帧重绘/插帧/风格迁移 |
| **Phase 6** | 音频创作工作台 | 第 9 周 | TTS 对接、人声克隆、音色转换 |
| **Phase 7** | 在线剪辑工作台 | 第 10–11 周 | 多轨道编辑、素材联动、导出成片 |
| **Phase 8** | 联调测试 + 优化部署 | 第 12 周 | 全流程联调、性能优化、生产部署 |

### 2.3 关键技术点

```
视频上传流程:
  前端 → GET /presign → MinIO 直传 → POST /create 入库 → POST /analyze 触发解析

大文件上传:
  - MinIO 分片上传 (multipart upload)
  - 前端分片读取 + 并行上传 + 合并

异步解析:
  - Redis Stream 消费者组模式
  - 任务状态: PENDING → RUNNING(0~100%) → SUCCESS / FAILED
  - WebSocket 推送进度到前端
```

### 2.4 验收标准

- [ ] 批量上传 3 个文件，全部入库成功

- [ ] 解析完成后，MySQL 中有完整的转写文本和关键帧数据

```
  "sourceStart": 0,    // 源素材起始偏移 ms
  "sourceDuration": 90000,
  "volume": 100,
  "transition": { "in": "dissolve", "out": "fade", "duration": 500 }
}
```

## 十一、开发规范

### 11.1 Git 分支策略

```
main          ← 稳定发布分支
├── develop   ← 开发主分支
│   ├── feature/phase0-scaffold    ← Phase 0 功能分支
│   ├── feature/phase1-auth         ← Phase 1 功能分支
│   ├── feature/phase2-video        ← Phase 2 功能分支
│   ...
│   └── feature/phase7-editor       ← Phase 7 功能分支
├── hotfix/xxx  ← 紧急修复
└── release/v1.0 ← 发布准备
```

### 11.2 后端规范

- 包名: `com.sva`
- Controller 层只做参数校验和路由，业务逻辑在 Service 层
- 统一使用 `R<T>` 作为返回体
- MyBatis-Plus 代码生成器产出基础 CRUD，手写复杂查询
- 所有接口通过 Knife4j 文档化
- 配置项通过 `@ConfigurationProperties` 管理，不硬编码

### 11.3 前端规范

- 组件命名: PascalCase (`VideoPlayer.vue`)
- API 文件按模块拆分，函数名与后端接口路径对应
- Store 按业务域拆分 (user / video / editor)
- 样式使用 UnoCSS / Tailwind，避免内联样式
- 所有用户提示使用 ElMessage / ElNotification

### 11.4 接口命名规范

```
GET    /api/videos                    ← 分页查询
GET    /api/videos/{id}               ← 详情
POST   /api/videos                    ← 创建
PUT    /api/videos/{id}               ← 更新
DELETE /api/videos/{id}               ← 删除
POST   /api/videos/{id}/action        ← 动作 (analyze / export / ...)
GET    /api/videos/{id}/sub-resource  ← 子资源查询
```

## 十二、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| ComfyUI API 不稳定 | 帧级创作功能受阻 | 增加重试机制、超时配置、手动触发回退 |
| Whisper 转写速度慢 | 大视频解析耗时过长 | 限制单文件大小、支持后台运行、进度推送 |
| FFmpeg 导出性能 | 成片导出慢 | 降低默认导出分辨率、提供快速预览模式 |
| 浏览器内存限制 | 时间轴片段过多时卡顿 | 虚拟滚动、懒加载、分页加载帧缩略图 |
| MinIO 磁盘空间 | 大量视频文件占满磁盘 | 定时清理临时文件、配额告警 |
