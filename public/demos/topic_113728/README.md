# AI 会议行动清单助手

## 项目简介

一款面向学习和工作场景的网页工具，用户粘贴会议纪要后，系统自动提取任务、负责人、截止时间、风险提醒，并生成任务看板和会后总结。纯前端实现，无需后端。

## 核心功能

- **会议纪要输入** — 支持粘贴会议纪要、群聊记录等
- **AI 模拟解析** — 关键词规则引擎 + 预设任务匹配
- **任务看板** — 待处理/进行中/已完成三列管理
- **风险提醒** — 5 类风险自动识别
- **会后总结** — 自动生成会议结论和群消息模板
- **复制任务清单 / 导出 Markdown / 导出 CSV**
- **优先级筛选** — 全部/高/中/低/有风险
- **任务详情弹窗与状态修改**

## 技术栈

HTML5 + CSS3 + JavaScript (ES5)，纯前端，无框架、无后端、无付费 API。

## 本地运行方式

**方式一：** 直接双击 `index.html` 在浏览器中打开。

**方式二：** 使用 Python 启动本地服务器：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

**方式三：** 使用 VS Code 的 Live Server 插件打开 `index.html`。

## 打包方式

将 `ai-meeting-assistant` 文件夹整体压缩为 `ai-meeting-assistant.zip`，包含以下文件：

- `index.html`
- `styles.css`
- `app.js`
- `README.md`
