Demo 简介

AI 会议行动清单助手是一款面向学习和工作场景的网页工具。用户粘贴会议纪要后，系统自动提取任务、负责人、截止时间、风险提醒，并生成任务看板和会后总结。纯前端实现，无需后端，即开即用。

创作思路

灵感来自日常会议后行动项不清晰的痛点。目标是把"会议内容"快速转化为"可执行任务"。初赛版本重点验证核心流程：输入 -> 解析 -> 看板 -> 风险 -> 总结 -> 导出，不依赖真实大模型 API，通过前端规则引擎模拟 AI 解析效果。

目标用户

项目经理、研发团队、学生小组、创业团队，以及所有经常开会、需要整理会议纪要的职场人。

核心功能

  • 会议纪要输入：支持粘贴多种格式内容
  • AI 模拟解析：关键词规则 + 预设匹配
  • 任务看板：待处理 / 进行中 / 已完成三列管理
  • 风险识别：5 类风险自动检测与提醒
  • 会后总结：自动生成会议结论和群消息模板
  • 多格式导出：复制、Markdown、CSV

后续升级方向

  • 接入真实大模型 API（如豆包、文心一言）提升解析准确度
  • 支持语音直接录入会议内容
  • 支持飞书 / 钉钉 / 企业微信消息格式自动解析
  • 支持多人协作：共享看板和任务认领
  • 支持历史会议管理和任务完成率统计
  • 支持任务提醒推送和日历同步
