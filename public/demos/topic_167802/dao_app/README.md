# 凡人修仙 · Web 版 Demo

以道教「山·医·命·相·卜」五术为核心的 AI 修行体验小程序 —— **网页版渲染的 App 效果 Demo**。
纯前端（原生 HTML/CSS/JS，零构建），后端数据全部使用 **Mock**，进度保存在浏览器 `localStorage`。

## 运行方式

方式一：直接双击 `index.html` 在浏览器打开即可（file:// 模式，摄像头功能可能受限）。

方式二（推荐，功能完整）：用本地静态服务器打开，避免 file:// 的部分限制：

```bash
cd dao_app
python3 -m http.server 8791
# 浏览器访问 http://localhost:8791/index.html
```

## 功能一览

| 模块 | 入口 | 说明 |
|---|---|---|
| 首页·洞天 | 底部「洞天」 | 境界进度、今日运势、每日修行任务、五术入口 |
| 山·身体修炼 | 「修行」→山 | 功法列表/详情/跟练计时/打卡（按境界解锁） |
| 医·养生保健 | 「修行」→医 | 节气建议、保健贴士、呼吸引导动画 |
| 命·八字命理 | 「玄机」→命 | 生辰排四柱、五行分布、AI 白话解读、分享卡 |
| 相·面相观察 | 「玄机」→相 | 拍照/上传、扫描动画、状态解读、趋势折线 |
| 卜·易经占卜 | 「玄机」→卜 | 摇卦动画、卦象、卦辞建议、问卜日志 |
| 问道·AI | 底部「问道」 | 规则式对话、打字机效果、带模块上下文提问 |
| 我的 | 底部「我的」 | 修行档案、历史记录、改名号、重置数据 |

贯穿全局的成长系统：修为 → 境界（练气→筑基→金丹→元婴），连续打卡、功法解锁、境界突破庆祝动画。

```
├── index.html                 # Demo 入口（手机外壳 + 路由容器）

├── docs/                      # 需求与架构设计文档

    └── js/

        ├── mock/              # 五术 + 运势 + AI 的 Mock 数据层

```
