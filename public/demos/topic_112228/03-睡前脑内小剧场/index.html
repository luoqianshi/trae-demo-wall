Introduction

创意介绍

灵感来源
我睡前习惯性刷短视频，越刷越精神，经常熬到凌晨两点。白噪音太单调，听书内容又太刺激或太无聊，找不到真正贴合自己的睡前内容。
产品形态
一个基于个人生活的定制化睡前故事生成与播放网页应用，把今天的生活变成温柔的睡前故事。
Target Users

目标用户与痛点

面向用户
睡前习惯性刷手机导致失眠的年轻人，喜欢听故事/ASMR入睡，但找不到新鲜且贴合自己的内容。
使用场景
睡前躺在床上，花30秒输入今天的一件小事，AI生成专属故事，配合呼吸动画和进度条，温柔入睡。
核心痛点
刷短视频越刷越精神；听书内容太刺激或太无聊；白噪音单调，难以持续使用；没有「属于自己的」睡前内容。

Value

价值与意义

健康价值：帮助建立健康的睡前仪式，改善睡眠质量；情绪疗愈价值，用专属定制替代算法推荐；把每一天变成可以回味的故事。
