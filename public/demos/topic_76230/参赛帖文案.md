# 正文文案

## 创意简介（一句话）

> 渡川是一个 AI 驱动的沉浸式理财学习 Web 应用，用古风武侠世界观 + 四个核心学习场景，帮 22-35 岁年轻人边玩边学理财。全程使用 Trae CN 开发。

## 灵感来源

这届年轻人（包括我自己），大部分人在学校没学过怎么管钱。工资到账 -> 花完 -> 下个月再来，对"财商"的认知全靠踩坑积累。

做这个产品的初衷就是：**能不能让学理财像玩游戏一样，没有压力，不知不觉就懂了？**

于是有了"渡川"——一个以"江湖"为壳、以"金融素养"为核的AI学习产品。

## 产品介绍

用户扮演初入江湖的少侠，跟随NPC"云伯"体验四个核心场景：

**场景一：医馆·钱包体检**
AI 分析用户的真实消费数据（或Demo预设样本），生成一份"财务体质报告"。不是枯燥的Excel表格，而是江湖郎中的脉案——"客官，你这'月光症'可不轻啊。"

**场景二：茶亭·值不值判官**
用户遇到消费决策时，AI 扮演判官角色，从"必要、需要、想要"三层帮用户分析每一笔开销。让每一块钱的去处都有据可查。

**场景三：观星台·未来推演**
AI 对用户的财务数据进行推演——"如果每月存500块，十年后你能看到什么？"用直观的可视化呈现复利的力量。

**场景四：竹林·成长森林**
用户的每一次学习、每一个好的理财习惯都会培育一棵"财富树"，累积江湖声望（积分），解锁更高阶的理财知识。

## AI 的运用

四个场景全部接入 AI 能力（通义千问 API，支持 simulate 离线模式 + real AI 模式双轨）：

| AI 能力 | 应用场景 |
|---------|---------|
| AI 决策分析 | 钱包体检：根据消费数据生成诊断报告 |
| AI 消费判官 | 茶亭：逐笔分析消费的合理性与优化空间 |
| AI 未来推演 | 观星台：基于当前数据推算长期财务走势 |
| AI 章回体小说生成 | 在"渡川"故事线中融入学习引导 |

同时在底层架构中设计了 **simulate 模式**：就算 API 挂掉或者网络不通，演示也能正常运行，这在 Demo 评审场景中至关重要。

## 技术实现

- **开发工具**：全程 Trae CN
- **架构**：纯前端 Web 应用（HTML + CSS + JavaScript）
- **核心引擎**：app.js 包含数据模型、AI 调用链、剧情生成、任务系统、徽章系统，约 700 行核心逻辑
- **AI 链路**：通义千问 API，simulate 模式离线可用
- **数据持久化**：localStorage
- **运行方式**：打开 index.html 即可体验，无需部署、无需服务器
