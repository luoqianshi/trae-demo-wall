# 救邻 · 黄金 4 分钟急救互助 H5 平台

## 项目简介

这是一个面向社会的急救互助平台 H5 前端演示系统，模拟了从紧急呼救到志愿者接单、AED 调度、120 联动的完整救援流程。

## 功能模块

### 1. 求救者端
- 首页展示附近志愿者、AED 数量、平均响应时间
- 一键 SOS 进入症状选择
- 6 种常见症状选择
- 模拟定位、志愿者匹配、AED 调度、120 同步
- 救援中实时计时、志愿者/AED/120 状态卡片
- 等待期间急救指引

### 2. 志愿者端
- 在线状态切换
- 紧急救援推送通知
- 接单 / 拒绝
- 任务详情与模拟导航
- 个人救助数据统计

### 3. AED 地图
- 简化地图展示用户位置和 AED 设备
- 设备列表展示距离、地址、状态
- 地图标记与列表联动

### 4. AI 急救指引
- 输入症状描述
- 常见症状快捷标签
- 结构化急救步骤输出
- 注意事项提醒

### 5. 个人中心
- 法律保障弹窗（民法典第 184 条）
- 隐私保护、急救培训、使用帮助入口

## 使用方式

1. 直接双击 `index.html` 在浏览器中打开
2. 建议按 F12 切换到手机模拟器体验
3. 通过底部导航切换不同功能模块

## 技术说明

- 纯前端实现，无需后端服务器
- 使用原生 HTML5 / CSS3 / JavaScript
- 移动端优先，适配 375-480px 屏幕
- 所有数据为模拟数据，仅用于演示
