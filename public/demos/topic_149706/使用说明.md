# 救邻 H5 平台使用说明

## 快速体验

1. 解压 `jiulin-h5-system.zip`
2. 双击 `index.html` 进入启动页
3. 点击"进入救邻"进入首页
4. 使用底部导航切换不同功能模块

## 各页面说明

### 首页（home.html）
- 显示附近志愿者数、可用 AED 数、平均响应时间
- 中间红色 SOS 按钮进入求救流程
- 四个快捷入口：附近 AED、AI 急救指引、志愿者入口、法律保障

### 求救流程（sos.html）
1. 选择症状：心脏骤停 / 癫痫 / 昏迷 / 大出血 / 气道异物 / 其他
2. 点击"确认并呼救"
3. 观看定位、志愿者匹配、AED 调度、120 同步动画
4. 进入救援中页面，查看志愿者/AED/120 状态和急救指引

### 志愿者端（volunteer.html）
- 查看个人救助数据统计
- 切换在线接单状态
- 接收紧急救援推送
- 点击"立即接单"查看任务详情和导航

### AED 地图（aed.html）
- 查看简化地图上的 AED 位置
- 点击地图标记或列表项查看设备详情
- 显示距离、地址、可用状态、24小时、公共/个人标签

### AI 急救指引（ai-guide.html）
- 在输入框中描述症状
- 或点击常见症状标签
- 点击"获取急救指引"查看结构化急救步骤和注意事项

### 我的页面（profile.html）
- 点击"法律保障"查看《民法典》第 184 条和平台五重保障

## 演示说明

- 本平台所有数据为模拟数据，不连接真实服务器
- "拨打电话"和"导航"功能在真机上会触发系统行为，演示时不会真实拨号
- 建议使用 Chrome / Edge 浏览器，按 F12 切换到手机模拟器体验

## 常见问题

**Q：为什么有些页面底部有导航，有些没有？**
A：启动页和求救流程页面需要沉浸式体验，所以隐藏了底部导航。其他页面都有底部导航。

**Q：可以修改模拟数据吗？**
A：可以编辑 `js/data.js` 文件，修改志愿者、AED、症状等数据。

**Q：可以自定义样式吗？**
A：可以编辑 `css/common.css` 中的 CSS 变量来修改主题色，或编辑各页面 CSS 文件。
