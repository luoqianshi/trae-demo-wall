😢 难过 🌙 孤单 💢 生气 😰 紧张 😨 害怕 😊 开心

示例同义词：伤心、委屈、失落 → 难过
孤单、孤独、寂寞、一个人 → 孤单
愤怒、发火、烦躁 → 生气

🎮 快速使用步骤

1

打开应用

双击 moodheal-app.html 文件在浏览器中打开

2

输入情绪

在输入框中输入当前感受，或直接点击情绪标签

3

生成故事

点击"✨ 生成专属故事"，开始你的童话之旅

4

做出选择

阅读故事情节，根据感受选择不同的选项

5

收获成长

完成故事后，阅读成长启示，开启新的冒险

📲 多种使用方式

方式一：直接使用 ⭐

双击 moodheal-app.html 即可使用，无需任何配置

方式二：安装到手机

iOS: Safari打开 → 分享 → 添加到主屏幕
Android: Chrome打开 → 菜单 → 安装应用

方式三：AI增强版

需要OpenAI API Key，集成GPT-4o Mini生成更丰富的故事
运行: npm install && npm start
