# 🚀 MoodHeal App 快速启动指南

## 方式一：直接使用（最简单）⭐推荐

### 步骤1：打开应用
双击文件 `moodheal-app.html`

### 步骤2：开始体验
1. 输入或选择你的情绪
2. 点击"生成专属故事"
3. 阅读故事，做出选择
4. 完成故事，收获成长启示

✅ **完成！**

---

## 方式二：安装到手机（可离线使用）

### iPhone / iPad
1. 用 Safari 打开 `moodheal-app.html`
2. 点击 Safari 底部的"分享"按钮 📤
3. 向下滑动，点击"添加到主屏幕" ➕
4. 点击"添加"完成
5. 桌面会出现 MoodHeal 图标 🌈

### Android 手机
1. 用 Chrome 打开 `moodheal-app.html`
2. 点击右上角菜单 ⋮
3. 选择"安装应用"或"添加到主屏幕"
4. 确认安装
5. 桌面会出现 MoodHeal 图标 🌈

---

## 方式三：电脑桌面应用

### Windows / Mac / Linux
1. 安装 Node.js (https://nodejs.org/)
2. 打开终端/命令提示符
3. 进入项目目录
4. 运行：
```bash
npm install -g @electron/cli
npx electron moodheal-app.html
```

---

## 方式四：使用 AI 增强版（可选）

如果想要 AI 生成更丰富的故事：

1. 获取 OpenAI API Key
   - 访问 https://platform.openai.com
   - 注册账号并获取 API Key

2. 安装并运行
```bash
npm install
# 编辑 .env 文件，添加你的 API Key
npm start
```

3. 打开浏览器访问
```
http://localhost:3000/moodheal-app.html
```

## ❓ 常见问题

### Q: 应用需要联网吗？
A: 基本功能不需要联网，离线也可使用。AI增强功能需要联网。

### Q: 支持哪些情绪？
A: 难过、孤单、生气、紧张、害怕、开心，以及它们的同义词。

### Q: 故事有多长？
A: 每个故事约5-8个场景，每个场景2-3个选择。

### Q: 如何保存故事记录？
A: 当前版本本地存储，下次打开会显示历史记录。

### Q: 适合多大年龄？
A: 4-10岁儿童，也可以用于亲子共读。
