# MoodHeal - 情绪治愈互动童话 App

## 📱 应用简介

MoodHeal 是一款专为4-10岁儿童设计的情绪治愈互动童话应用。通过输入情绪关键词，自动生成专属的互动故事，帮助孩子正确表达和舒缓情绪。

## ✨ 核心功能

### 1. 🎭 情绪识别与故事生成
- 支持多种情绪输入：难过、孤单、生气、紧张、害怕、开心
- 智能模糊匹配，同义词自动识别
- 快速标签选择，一键生成故事

### 2. 📖 互动式故事体验
- 丰富的角色设定：小熊贝贝、小兔朵朵、小狐狸闪闪、小鹿斑斑、小猫花花
- 多分支剧情选择
- 每个选择都导向正向结局
- 深刻的成长启示

### 3. 🎨 情感化视觉设计
- 根据情绪变换背景色彩
- 温馨可爱的UI设计
- 流畅的动画效果
- 响应式布局，完美适配移动端

### 4. 💡 正向价值观引导
- 40+种正向结局类型
- 传递友谊、勇气、感恩等核心价值观
- 温柔无压力的情绪疏导

## 🚀 快速开始

### 方法一：直接在浏览器中打开
1. 双击 `moodheal-app.html` 文件
2. 在浏览器中打开即可使用

### 方法二：部署到本地服务器
```bash
# 使用Python启动简单服务器
python -m http.server 8000

# 或使用Node.js
npx serve .

# 然后访问 http://localhost:8000/moodheal-app.html
```

### 方法三：安装为桌面应用
1. 使用 Electron 打包：
```bash
npm install -g electron
npx electron .
```

2. 或使用 Tauri：
```bash
npm install -g @tauri-apps/cli
npm run tauri dev
```

## 📱 移动端安装 (PWA)

### iOS Safari
1. 在 Safari 中打开应用
2. 点击"分享"按钮
3. 选择"添加到主屏幕"
4. 完成安装

### Android Chrome
1. 在 Chrome 中打开应用
2. 点击右上角菜单
3. 选择"安装应用"
4. 或点击底部"添加到主屏幕"提示

## 🎮 使用指南

### 第一步：输入情绪
- 在输入框中输入当前的情绪（如：难过、孤单、生气）
- 或直接点击预设的情绪标签

### 第二步：生成故事
- 点击"✨ 生成专属故事"按钮
- 系统会为你匹配最适合的情绪故事

### 第三步：做出选择
- 阅读故事情节
- 根据自己的感受选择选项
- 每个选择都会引导到不同的场景

### 第四步：收获成长
- 到达正向结局
- 阅读成长启示
- 点击"开始新的故事"继续冒险

## 🔧 API集成（可选）

如果想使用AI生成更丰富的故事，可以集成后端服务：

### 1. 安装依赖
```bash
npm install
```

### 2. 配置API密钥
编辑 `.env` 文件：
```env
OPENAI_API_KEY=your-api-key-here
```

### 3. 启动服务器
```bash
npm start
```

服务器将在 http://localhost:3000 运行，自动使用本地故事模板作为回退。

## 🌟 故事主题

### 😢 难过主题
通过寻找丢失的宝贝，学会表达情感、寻求帮助、培养耐心和感恩之心。

### 🌙 孤单主题
学会打开心扉、主动交友、理解陪伴的温暖。

### 💢 生气主题
学会情绪管理、用行动代替抱怨、培养韧性和智慧。

### 😰 紧张主题
学会自我鼓励、调整心态、享受过程而非结果。

### 😨 害怕主题
学会面对恐惧、寻求支持、建立勇气和安全感。

### 😊 开心主题
学会分享快乐、珍惜友谊、创造美好回忆。
