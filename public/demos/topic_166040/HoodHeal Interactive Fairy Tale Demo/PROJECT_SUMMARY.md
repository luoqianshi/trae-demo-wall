## 🌟 核心功能一览

### 1. 情绪识别系统
- ✅ 支持6种核心情绪
- ✅ 智能同义词匹配
- ✅ 快速标签选择
- ✅ 模糊匹配算法

### 2. 故事生成引擎
- ✅ 6种情绪故事模板
- ✅ 每种情绪8-9个场景

## 🚀 快速开始

### 最简单方式
```
双击 moodheal-app.html → 开始使用
```

### 安装到手机
```
iOS: Safari打开 → 分享 → 添加到主屏幕
Android: Chrome打开 → 菜单 → 安装应用
```

### AI增强版
```bash
npm install
# 配置.env中的API Key
npm start
# 访问 http://localhost:3000
```
