一、各层级编码规则说明
层级 命名规则 示例 长度范围 说明
L1 业务领域 L1- + 英文缩写（3-6位大写字母） L1-DEP 6-9 字符 DEP=Deposit（个人存款），缩写需唯一且易读
L2 价值流 L2- + L1缩写 + -[P/D/C] + 两位序号 L2-DEP-D01 11-13 字符 P=Plan计划 / D=Do执行 / C=Check监督
L3 业务活动 L3- + L1缩写 + - + 三位序号 L3-DEP-003 11-12 字符 序号在同一L1下全局唯一，不可复用
L4 任务 L4- + L1缩写 + - + L3序号 + 两位任务序号 L4-DEP-00302 13-14 字符 在所属L3下顺序编号；删除后编号不回收
API接口 API- + L1缩写 + - + 四位流水号 API-DEP-0021 12-13 字符 全局流水号；同L1下按创建顺序递增
文件服务 FILE- + L1缩写 + - + 四位流水号 FILE-DEP-0088 13-14 字符 文件传输、文件生成类服务使用 FILE 前缀
