SLA 指标参考
调用管理
  • 调用频率限制：单 IP 每秒 ≤ 100 次；单应用每秒 ≤ 500 次
  • 流量控制：超过阈值将触发限流（返回 HTTP 429），建议消费方实现指数退避重试
  • 每日调用量上限：A 级接口 ≤ 100 万次/日；B 级 ≤ 300 万次/日；C 级 ≤ 1000 万次/日
  • 如需提升配额，请在申请时注明业务量预测
数据保护
  • 敏感字段加密：身份证、卡号、手机号等必须使用 AES-256 加密存储；传输层必须使用 HTTPS/TLS1.2+
  • 数据最小化原则：只申请与业务场景必要的字段，禁止"先申请再说"
  • 数据使用协议：申请涉及敏感字段时，需额外签署《数据使用协议》并由合规部门审批
  • 数据落库禁止明文存储原始敏感字段，仅可保留脱敏摘要
