差异影响说明
超时配置差异
DEV 环境超时时间较短（3s/10s），UAT 环境较长（5s/15s）。迁移至生产环境时需根据实际网络延迟调整。
连接池配置差异
UAT 环境数据库连接池最大连接数为 100（DEV 为 50），生产环境建议根据并发量评估后配置。
新功能开关
DEV 环境已启用新风险模型和批量查询功能，UAT 环境尚未配置。建议在 UAT 环境验证后同步开启。
旧版兼容配置
UAT 环境保留了旧版 API 兼容模式，DEV 环境已移除。需确认所有消费方已完成升级后再移除。
