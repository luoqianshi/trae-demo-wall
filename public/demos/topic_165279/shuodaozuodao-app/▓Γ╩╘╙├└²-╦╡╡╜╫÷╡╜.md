## 一、测试概述

### 1.1 测试目标

验证「说到做到」App 各核心功能模块的正确性、稳定性和用户体验，确保产品在以下场景可靠运行：

- 用户创建服务项目
- AI 分析合同与报价单
- 验收清单管理与进度追踪
- 过程留证与证据归档
- 付款前核对与争议材料生成

### 1.2 测试范围

| 模块 | 测试内容 |
|------|---------|
| 首页 | 项目列表展示、核心能力介绍、导航入口 |
| 项目创建 | 服务类型选择、信息填写、文件上传 |
| AI 分析 | 分析进度、承诺提取、模糊条款识别 |
| 承诺提取 | 合同高亮、风险问题展示、建议补齐 |
| 验收清单 | 清单展示、状态切换、进度统计 |
| 过程留证 | 时间线展示、证据附件、添加证据 |
| 付款核对 | 付款节点、完成度核对、补证提醒 |
| 争议材料 | 材料包生成、分类展示、导出功能 |
| 个人中心 | 项目包购买、个人信息、设置 |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 浏览器 | Chrome 120+ / Safari 16+ / 微信内置浏览器 |
| 分辨率 | 375×812（iPhone X）/ 390×844（iPhone 14）/ 360×740（Android） |
| 操作系统 | iOS 16+ / Android 12+ |
| 网络 | WiFi / 4G / 弱网模拟 |
