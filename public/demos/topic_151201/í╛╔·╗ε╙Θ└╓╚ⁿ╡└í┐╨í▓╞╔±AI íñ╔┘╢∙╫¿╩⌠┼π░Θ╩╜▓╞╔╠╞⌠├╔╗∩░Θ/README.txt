小财神AI · 少儿财商启蒙 Demo
============================================

【项目简介】
小财神AI是一款面向4-12岁中国家庭的少儿财商启蒙产品，
通过AI互动、故事化教学、游戏化激励，
帮助孩子建立正确的金钱观、消费观和财富观。

【技术特点】
✅ 纯前端单文件 HTML，零外部依赖
   - 无 CDN、无外部字体、无外部图片
   - 双击即开，无需联网

✅ localStorage 数据持久化
   - 记账数据自动保存
   - 故事/闯关进度保留
   - 金币星星累积

✅ 全响应式适配
   - 手机端（360px+）
   - 平板端
   - PC端

✅ 无障碍体验优化
   - 首屏秒开（懒加载机制）
   - 评审引导浮层
   - 一键重置Demo数据

【文件清单】
demo.html ................... 主文件（单文件Demo，双击即开）
README.txt .................. 本文件
体验指南.txt ................ 评审体验操作指南

【使用方法】
1. 双击 demo.html 用浏览器打开
2. 首次打开会显示"3分钟体验指南"
3. 按引导依次体验各功能模块
4. 点击右上角 🔄 可一键重置Demo数据

【目标用户】
- 4-12岁儿童（使用者）
- 父母/家长（陪伴者）
- 财商教育从业者

【设计理念】
- 故事化：用生活故事讲透财商概念
- 游戏化：闯关+积分激励持续学习
- 亲子化：家长陪伴共同成长
- 本土化：贴合中国家庭场景
