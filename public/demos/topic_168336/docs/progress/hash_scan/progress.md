# 哈希计算与文件扫描模块 - 进度跟踪

## 功能描述
- 文件 MD5 + SHA256 双重哈希计算
- 递归目录扫描
- 重复文件检测
- 文件统计信息查询

## 进度状态：✅ 已完成

### 已完成功能
- [x] 8KB 分块读取大文件哈希计算
- [x] walkdir 递归目录扫描
- [x] MIME 类型检测（基于扩展名）
- [x] 按 MD5+SHA256 分组重复检测
- [x] 统计信息查询（总文件数、总大小、重复数、可节省空间）
- [x] 分批扫描 + 进度上报
- [x] 扫描取消支持（AtomicBool）

### 测试用例
- hash.rs: 小文件哈希计算、大文件哈希计算
- scanner/mod.rs: 带进度回调的扫描测试
- scanner/duplicate.rs: 重复文件检测测试
- scanner/statistics.rs: 统计信息查询测试
