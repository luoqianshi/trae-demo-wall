一、创意介绍

🤔

想解决什么问题

文件越堆越多——重复文件占着空间不敢删，整理文件夹费时费力，删了又怕以后找不到。市面上的文件管理器只会「增删改查」，不会「思考判断」。

💡

为什么会想到做这个

自己有好几个硬盘和网盘，文件散落各处，手动整理几次都放弃了。后来发现很多文件其实重复了，但靠人工根本找不全。于是想：为什么不让 AI 来管文件？

📦

产品形态

跨平台桌面应用（Tauri + Rust + Yew WASM + Python AI），后台常驻运行，无缝接管文件管理器的操作。

二、目标用户及痛点

面向哪些用户

👨‍💼

普通办公族

电脑里文档、图片、下载文件堆积如山，整理起来无从下手

🎨

开发者 / 设计师

项目文件、设计素材散落各个目录，重复文件多

💾

多硬盘 / 多设备用户

同时管理本地磁盘、移动硬盘、网盘，缺乏统一索引

痛点 vs 方案

当前痛点

重复文件排查困难全靠手动，工作量大还容易遗漏
整理耗时分类只能手动建文件夹，移动大文件更慢
删除不可逆没有审计机制，删了就找不回来
跨设备无统一管理多个硬盘/网盘各自为政

我们的方案

双重哈希指纹MD5 + SHA256 自动识别重复文件，准确率 99.9999%+
AI 自动分类TF-IDF + DBSCAN 聚类，一键整理，物理文件不动
删除审计链记录→队列→物理删除，全链路可追溯，杜绝误删
统一索引跨硬盘、跨设备建立统一文件指纹库

四、核心功能

🔍

文件指纹识别

自动计算 MD5 + SHA256 双重哈希，建立全局指纹库，精准识别重复文件。

✅ 完成
🤖

AI 智能分类

基于文件名、路径、类型等多维特征，TF-IDF + DBSCAN 聚类自动分类，支持手动调整。

📋 待开发
📁

虚拟目录管理

物理文件不动，只存引用关系。一个文件可属于多个目录，零拷贝，拖拽即整理。

✅ 完成
🛡️

安全删除追踪

删除先入队列，记录永久保存，最终物理删除需二次确认，全链路可追溯。

✅ 完成
🖥️

跨平台监控

Windows: ReadDirectoryChangesW / Linux: inotify / macOS: FSEvent，实时拦截文件管理器事件。

✅ 完成
⚡

分批扫描 + 进度上报

100 文件一批，通过 Tauri 事件逐批上报进度，支持中途取消扫描操作。

✅ 完成
