# Git 常用命令

## 基础命令
```bash
git init          # 初始化仓库
git add .         # 添加所有文件
git commit -m "message"
git push origin main
```

## 分支管理
```bash
git branch        # 查看分支
git checkout -b feature  # 创建并切换分支
git merge feature        # 合并分支
```

## 远程操作
```bash
git clone <url>   # 克隆仓库
git pull          # 拉取更新
git push          # 推送更新
```
