声桥 VoiceBridge · 初赛交互演示
====================================

使用方法：
  双击 index.html 即可在浏览器中体验，无需安装任何软件，无需联网。

页面内容：
  · 一个纯前端离线交互演示，模拟声桥 VoiceBridge 的完整手机流程。
  · 流程包括：私人配对 → 项目选择 → 系统键盘语音提示 → 创建任务 →
    自动进入详情 → 实时过程（思考摘要 / 计划 / 搜索 / 命令 / 文件活动）→
    两轮追问 → 失败原因 → 电脑端打开。
  · 内置一条示例任务（首页性能优化），展示完整最终结果。
  · 提供"重新演示""切换任务历史""继续追问"等真实可点击交互。
  · 页面内含"作品价值""隐私安全""技术架构"折叠说明。

注意事项：
  · 这是参赛交互演示，不连接真实电脑，也不包含真实账号或私有数据。
  · 所有配对码、项目路径、任务内容均为模拟数据。
  · 页面不展示模型的隐藏思维链，只展示给用户看的简短思考摘要。

浏览器兼容：
  · 推荐 Chrome / Edge / Firefox 等现代浏览器。
  · 适配 390px 手机宽度与桌面宽度。
  · 支持键盘操作与无障碍标签，并尊重系统的"减少动态效果"偏好。

技术说明：
  · 单文件 HTML，不使用任何外部资源或网络请求。
  · 直接双击打开即可离线运行，无需本地服务器。
