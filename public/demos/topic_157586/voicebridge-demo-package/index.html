01 作品价值

声桥 VoiceBridge 让开发者离开电脑后，仍能用手机语音安全地创建、续聊和查看桌面 AI 开发任务。

  • 效率 — 把"回到电脑再操作"缩短为手机上一句话，碎片化时间直接转化为真实任务。
  • 安全 — 手机只拥有最小化任务入口，不暴露完整桌面，不接触 AI 账号凭据。
  • 连续性 — 手机和电脑看到同一任务线程，支持历史结果与多轮追问。
  • 可扩展 — Bridge 与前端解耦，可扩展微信、小程序和其他桌面 Agent。
02 隐私安全

安全是声桥的设计基石，手机端始终处于最小权限状态：

  • 零凭据接触 — 手机不保存也不登录桌面 AI 账号，不接触 Cookie 或密码。
  • 本地监听优先 — Bridge 默认只监听 127.0.0.1，远程走私有 HTTPS 链路。
  • 一次性配对 — 随机配对码、会话令牌、哈希存储、限流与同源校验。
  • 项目白名单 — 手机不能指定任意本地目录，只能选择预配置项目。
  • 最小持久化 — 默认只存任务元数据，不持久化完整 Agent 输出。
  • 沿用桌面沙箱 — 原有桌面沙箱和审批策略保持不变，Bridge 不绕过。

本演示页不连接真实电脑，所有数据均为模拟，不含任何真实账号或私有信息。

03 技术架构

三层架构：手机前端负责输入与展示，本地 Bridge负责鉴权与转发，桌面 AI Agent负责实际执行。

↓ 私有 HTTPS + 配对令牌
🔗 VoiceBridge（Windows 本地服务）
↓ 本机任务/线程协议
🖥️ 桌面 AI Agent
↓
账号 · 代理 · 项目 · 沙箱 · 审批
  • 前端：手机 PWA，调用系统键盘语音听写，不采集音频。
  • Bridge：Windows 本地 Node.js 服务，负责配对鉴权、项目白名单与任务转发。
  • Agent 适配层：当前适配 Codex 桌面端，可扩展其他支持任务/线程协议的 Agent。
04 演示说明

本页面是一个纯前端离线交互演示，用模拟数据还原声桥的完整手机流程：

  • 私人配对 → 项目选择 → 系统键盘语音提示 → 创建任务
  • 自动进入任务详情，展示思考摘要、计划、搜索/命令/文件活动
  • 过程中包含一次失败原因与恢复，以及两轮追问
  • 展示完整最终结果，并模拟"电脑端打开"深链接
  • "切换任务历史"可查看一条已失败的历史任务及其失败原因

页面不展示模型的隐藏思维链，只展示给用户看的简短思考摘要。
