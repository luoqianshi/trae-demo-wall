# 体验链接部署指南

评审版只有一个 `index.html`，不需要构建命令、数据库、模型 Key 或后端。比赛允许直接上传 HTML ZIP，因此公网部署不是硬前提；若要提供公开链接，可任选一种静态托管方式。

## 方案 1｜直接上传社区 ZIP（最快且最稳）

1. 运行 `contest-submission/build-submission.ps1`；
2. 上传 `contest-submission/dist/跨语言沟通助手-初赛HTML体验包.zip`；
3. 在正文写明“解压后双击 index.html”。

这个方案不依赖部署账号，也不会因免费额度、域名或后端休眠而失效。

## 方案 2｜Vercel 静态部署

1. 新建一个只包含 `index.html` 的仓库或项目目录；
2. 将 `contest-submission/demo/index.html` 放在该目录根部；
3. 在 Vercel 导入项目，Framework Preset 选 `Other`；
4. Build Command 留空，Output Directory 留空；
5. 部署后用无痕窗口打开 HTTPS 地址，完整走一遍三个场景。

## 方案 3｜GitHub Pages

1. 新建公开仓库，把 `index.html` 放在仓库根目录；
2. Repository Settings → Pages；
3. Source 选择从默认分支根目录部署；
4. 等待 Pages 地址生效，再用手机网络验证。

## 部署后验收

- 页面首屏能看到“不是替你翻译，是陪你把话说出来”；
- 酒店、餐厅、医院场景切换正常；
- 推进两轮后，YOU / STAFF 和下一句建议顺序正确；
- 浏览器控制台没有未处理错误；
- 断网刷新后仍能运行（若托管平台已缓存页面）；
- 链接公开，无登录、申请访问或过期时间；
- 作品帖同时上传 HTML ZIP 作为兜底。

## 不要做

- 不要把真实 `backend/.env` 或 API Key 上传到静态站点；
- 不要为了一个评审页面临时接数据库、鉴权或不稳定的免费后端；
- 不要把 `http://127.0.0.1`、`192.168.*` 局域网地址当成公开体验链接；
- 不要只发源码仓库链接而没有直接可体验入口。
