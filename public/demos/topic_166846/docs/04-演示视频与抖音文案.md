# 60 秒演示视频与抖音发布文案

## 60 秒演示脚本

| 时间 | 画面 | 旁白 / 字幕 |
| --- | --- | --- |
| 0–5 秒 | 海外酒店前台，用户低头在手机里找翻译；切到眼镜第一视角 | “出国沟通最尴尬的，不只是听不懂，而是听懂后不知道下一句怎么说。” |
| 5–12 秒 | 眼镜界面首屏，左侧下一句、右侧双语对话 | “我做了一个运行在 Rokid AI 眼镜里的跨语言沟通副驾驶。” |
| 12–20 秒 | 用中文描述“酒店入住并申请延迟退房” | “用中文说清场景和目标，它先给出第一句能直接开口的英文。” |
| 20–34 秒 | 连续演示 YOU / STAFF 两轮，右侧出现中文，左侧刷新建议 | “双方对话持续记录；对方每次回答后，下一句建议会根据上下文自动更新。” |
| 34–43 秒 | 按镜腿键暂停/恢复，或展示页面状态变化 | “一次授权后连续同传，镜腿键只控制整段暂停和恢复，不必逐句操作。” |
| 43–52 秒 | 快切餐厅花生过敏、医院挂号场景 | “在过敏和就医这类高压力场景里，关键信息、表达目的和下一句始终都在视线里。” |
| 52–60 秒 | 用户抬头继续与对方交流，结束页显示产品名 | “AI 不必抢走表达。它可以让人更有把握地亲自开口。” |

## 拍摄要点

- 先录一条纯屏幕版，确保界面与字幕清晰；再补眼镜佩戴和镜腿键的实拍；
- 每个镜头只表达一个点，不要把架构、Prompt 和所有功能都塞进 60 秒；
- 第一秒直接出现真实尴尬场景，前 5 秒不要放 Logo 片头；
- 字幕要大，保持高对比；演示视频不要露出 API Key、局域网 IP 或通知栏；
- 明确离线 HTML 是评审体验版，真实设备版才接入连续语音和 Qwen。

## 抖音标题

我把“翻译软件”做进了 AI 眼镜，但它不替你说话

## 抖音正文

出国沟通时，真正让人卡住的往往不是“完全听不懂”，而是看懂翻译后，仍然不知道下一句怎样说得自然又礼貌。

所以我用 TRAE 做了“跨语言沟通助手”：运行在 Rokid AI 眼镜里的现场沟通副驾驶。右侧持续记录双方英文和中文，左侧根据当前场景和对方回复，始终给出我下一句可以亲自说出的英文。

我把酒店入住、餐厅过敏、医院挂号做成了完整可体验闭环。希望 AI 帮人更自然地留在对话里，而不是让两个人一起低头盯着手机。
