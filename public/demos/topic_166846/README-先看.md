# 跨语言沟通助手｜初赛提交包

这是一套按“硬件交互”赛道整理的可提交材料。核心产品是运行在 Rokid AI 眼镜上的跨语言沟通副驾驶；同时提供不依赖眼镜、账号、网络或 API Key 的单文件浏览器 Demo，评审打开即可体验三类场景、连续对话、下一句建议、换一种说法、英文朗读和自定义对方回复。

## 现在已经具备

- AIUI 眼镜端源码：`AGENTS.md`、`app.json`、`app.js`、`pages/`、`lib/`
- FastAPI 安全代理：`backend/`，API Key 只保存在后端
- 单文件评审 Demo：`demo/index.html`
- 可直接粘贴的初赛作品帖：`docs/01-初赛Demo作品帖-可直接发布.md`
- TRAE 三段真实任务与取证方法：`docs/02-TRAE执行与Session取证.md`
- 提交前检查表：`docs/03-提交前检查清单.md`
- 60 秒演示视频与抖音文案：`docs/04-演示视频与抖音文案.md`
- 静态部署方法：`docs/05-体验链接部署指南.md`
- 自动打包脚本：`build-submission.ps1`
- 完整报名材料包：`dist/跨语言沟通助手-初赛报名材料包.zip`

## 最短提交路径

1. 先双击 `demo/index.html`，完整体验一次三个场景。
2. 社区报名帖链接已填写为 `https://forum.trae.cn/t/topic/147579`，发布前确认它仍可公开访问。
3. 在初赛专区选择与报名一致的赛道标签，粘贴作品帖正文。
4. 上传 `dist/跨语言沟通助手-初赛HTML体验包.zip`、3 张产品截图和 3 张 TRAE 过程截图。
5. 发布前按 `docs/03-提交前检查清单.md` 做最后复核。
