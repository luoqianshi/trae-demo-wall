01 · POSITIONING

项目定位

从被动救火到主动闭环，把数据中心告警接进 Harness Engineering Agent。

🎯 我们解决什么问题

数据中心运行 5 大子系统，告警每天爆炸、传统运维 7×24 人工盯屏，效率低、出错率高、留痕难。

  • 🔋 BMS 电池系统——实时电压 / 电流 / 温度
  • 🌡 动环监控——温湿度 / 漏水 / 空调状态
  • 🔥 消防系统——烟感 / 喷淋 / 火警主机
  • 🛡 安防系统——门禁 / 视频 / 入侵检测
  • 🏢 BA 楼宇——冷源 / 空调 / 给排水

目标：告警自动分流、SOP 自动执行、人工只看极少数需要决策的环节。

04 · CLOSED LOOP

核心 7 步闭环流程

从告警触发到 LLM 迭代，每一步都可观测、可干预、可回放。

1️⃣
告警触发

5 大子系统任一节点异常，自动推送到 Agent。

2️⃣
SOP 匹配 125+

在标准作业程序库中语义召回最匹配的预案。

3️⃣
Skill 执行

调起对应 Skill 完成设备指令、状态读取。

4️⃣
飞书 Webhook

结果以卡片消息同步推送给值班工程师。

5️⃣
一次链接拍照

现场设备巡检照片作为强证据归档。

6️⃣
人工反馈

工程师在卡片上一键勾选"通过/失败"。

7️⃣
LLM 迭代

反馈回灌，Skill 版本号自动 +1，越用越准。
