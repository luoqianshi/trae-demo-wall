为什么选择 QIdea？

在 AI 编程时代，你需要一个轻量、快速、专注的好搭档

极致轻量

纯 Rust 后端 + Tauri 框架，告别 Electron 的内存臃肿。 安装包仅约 50MB，空闲内存不到 100MB。

秒级启动

冷启动 1.5 秒内即可开始编辑，热启动更是不到 0.6 秒。 随时打开，随时使用，无需等待。

专注核心

不做臃肿的 IDE，只把文件浏览、代码编辑、Git、终端做到最好。 简单、直接、高效。

AI 互补

完美补充 Codex、GitHub Copilot、Cursor、Trae Solo 等 AI 编程工具。 更好的资源管理器、更快的终端、完整的 Git 支持。

使用场景

两个最常见的开发场景，看看 QIdea 如何提升效率

场景 01

Ctrl + Shift + N 快速查找文件

痛点
  • 大型项目文件成百上千，手动翻找太慢
  • AI 工具的资源管理器不够友好，文件操作不方便
  • 频繁在文件间切换，效率低下
解决方案
  1. 按下 Ctrl+Shift+N 唤出快速跳转面板
  2. 输入文件名关键词，实时模糊匹配
  3. 上下键选择目标文件，回车直接打开
  4. 支持文件扩展名过滤和搜索路径限定

场景 02

Git 可视化 Commit + 终端 Push 可视化查看变更，命令行执行推送

痛点
  • 记不住 git 命令参数，每次都要查
  • commit 前想 review 改动，命令行 diff 不方便
  • AI 编程工具没有 Git 支持
  • push 操作简单，不需要复杂 UI
解决方案
1
Commit 用 UI

左侧 Git 面板树形展示所有变更，点击文件看 Diff，勾选后一键提交

2
Push 用终端

底部终端执行 git push，简单直接，配合历史命令秒调用
