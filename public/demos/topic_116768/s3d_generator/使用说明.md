# S3D建库数据自动生成器

## 软件概述

本软件用于根据材料等级表自动生成SmartPlant 3D (S3D) 建库所需的Excel数据文件。

## 功能特点

1. **材料等级表解析**：自动解析Excel格式的材料等级表
2. **多材料等级支持**：支持同时处理多个材料等级（如YA1B, YA2B, YB1B, YB2B等）
3. **多种零件类型**：支持管材、弯头、三通、异径管、法兰、阀门、垫片、紧固件等
4. **自动映射规则**：
   - 材料等级自动映射到S3D代码
   - 端部准备自动识别（BW/RF等）
   - 压力等级自动转换
   - 壁厚等级自动匹配
5. **批量生成**：一键生成所有S3D数据文件
6. **数据预览**：预览解析结果和生成统计

## 安装要求

- Python 3.8+
- PyQt5
- pandas
- openpyxl

### 安装依赖

```bash
pip install PyQt5 pandas openpyxl
```

## 使用方法

### 1. 启动软件

双击运行 `run.py` 或在命令行执行：

```bash
python run.py
```

### 2. 选择材料等级表

1. 点击"浏览..."按钮
2. 选择材料等级表Excel文件（支持.xlsx和.xls格式）
3. 点击"解析"按钮

### 3. 查看解析结果

- **材料等级信息**：显示所有材料等级的基本信息
  - 管材材料
  - 法兰材料
  - 压力等级
  - 密封面型式
  - 阀体材料
  - 阀内件材料
  - 腐蚀余量

- **零件列表**：显示所有零件的详细信息
  - 零件类型
  - 尺寸范围
  - 压力等级
  - 端部型式
  - 描述
  - 商品编码

### 4. 选择材料等级

在材料等级表格中：
- 点击某行选择单个材料等级
- 按住Ctrl点击多行选择多个材料等级
- 不选择则默认处理所有材料等级

### 5. 生成S3D数据

1. 点击"生成S3D数据"按钮
2. 确认生成信息
3. 等待生成完成

### 6. 查看输出文件

生成的文件保存在输出目录中：

| 文件名 | 内容 |
|--------|------|
| 1a.管材.xlsx | 管材数据 |
| 2a.弯头.xlsx | 弯头数据（90度、45度、短半径） |
| 3b.异径.xlsx | 异径管数据（同心、偏心） |
| 4a.三通.xlsx | 三通数据（等径、异径） |
| 3c.管帽.xlsx | 管帽数据 |
| 6a.法兰.xlsx | 法兰数据（对焊、盲板、8字盲板） |
| 垫片.xlsx | 垫片数据 |
| 7b.紧固件元件.xlsx | 螺栓数据 |
| 8a.阀件及其它.xlsx | 阀门数据（闸阀、截止阀、止回阀） |
| 生成汇总报告.xlsx | 生成统计报告 |

## 支持的零件类型

### 管道元件
- PIPE (管材)
- 45 DEG LR ELBOW (45度长半径弯头)
- 90 DEG LR ELBOW (90度长半径弯头)
- 90 DEG SR ELBOW (90度短半径弯头)
- CON REDUCER (同心异径管)
- ECC REDUCER (偏心异径管)
- EQUAL TEE (等径三通)
- RED TEE (异径三通)
- CAP (管帽)
- WELDOLET (支管台)

### 法兰
- WN FLANGE (对焊法兰)
- BLIND FLANGE (盲板法兰)
- FIGURE-8 BLANK (8字盲板)

### 垫片和紧固件
- SP WOUND GASKET (缠绕垫片)
- STUD BOLT & NUTS (双头螺栓和螺母)

### 阀门
- GATE VALVE (闸阀)
- GLOBE VALVE (截止阀)
- CHECK VALVE (止回阀)

## 注意事项

1. **材料等级表格式**：确保材料等级表符合标准格式
2. **尺寸范围**：软件会自动解析尺寸范围（如.5~8）
3. **商品编码**：优先使用材料等级表中提供的商品编码
4. **输出目录**：确保输出目录有写入权限

## 故障排除

### 无法解析文件
- 检查文件是否为有效的Excel文件
- 检查文件是否被其他程序占用

### 生成数据为空
- 检查材料等级表是否包含零件数据
- 检查零件类型是否在支持列表中

### 编码错误
- 确保文件使用UTF-8编码
- 检查特殊字符是否正确显示
