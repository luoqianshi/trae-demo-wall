为什么 / The Quiet Loss

社区正在悄悄
失去它的记忆

城市在更新，街坊在搬离，老人在老去。那些只存在于口耳之间的故事，正随着每一次告别，永远地消失。

故事随人离去

老人记忆中的社区往事，往往没来得及被讲出，就再也无人知晓。

旧貌不断消失

老街、老店与老建筑在更新中拆除，社区的共同记忆失去了载体。

邻里渐渐疏远

人来人往，新老居民之间缺少连接，社区的归属感日渐稀薄。

如果记忆能生长成一棵树，
它就永远不会被遗忘。

项目介绍 / What is Memory Tree

一棵把社区记忆
种进未来的树

🌳

Memory Tree 是一座由 AI 驱动的社区智能终端与数字记忆网络。它把老人故事、社区历史、儿童梦想与居民记忆，转化为一片片会发光的「数字叶片」，汇聚成一棵不断成长的社区记忆树。

语音交互记录

居民只需对着终端讲述，AI 即可倾听、转写并温柔地追问细节。

视觉识别留存

老照片、旧物件经视觉识别归档，为每段记忆补全画面与时间。

共同记忆网络

每段记忆彼此关联，编织成属于整个社区的、活的记忆图谱。

采集过程 / How Memories Grow

四步，让一段记忆
长成一片叶子

STEP 01

倾听讲述

居民走近社区智能终端，用方言或普通话自然讲述自己的故事。

STEP 02

识别与整理

AI 转写语音、识别老照片，自动补全时间、地点与人物。

STEP 03

生成数字叶片

每段记忆生成一片确权、可检索的数字叶片，挂上记忆树。

STEP 04

连接与生长

叶片彼此关联、被更多人探访，记忆树随社区一起持续生长。
