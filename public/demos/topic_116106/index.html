欢迎来到 InkFlow 演示页

InkFlow 是一款让网页可手写批注的浏览器扩展。本页面是单文件 demo，直接在浏览器打开即可体验全部核心功能——无需安装。

试着选中左上角工具栏里的圆珠笔，然后在这段文字上画圈、做标记；切换到荧光笔涂重点；用形状工具画矩形与箭头；用橡皮擦擦除；用套索框选并拖动笔迹。滚动页面时，笔记会跟随内容同步移动。

提示：按住 Shift 拖动圆珠笔可画直线；形状工具按住 Shift 可约束为正方/正圆/八向直线。

核心特性

亚克力工具栏 · 矢量笔迹渲染 · 跟随滚动锚定 · 多形状与套索 · 双模式橡皮擦 · 滑动确认清空 · 贴边收缩开关 · 自定义光标 · 一键导出 HTML。

使用指南

1. 选择工具

点击浮动工具栏上的图标切换工具。指针工具恢复页面原生滚动与交互；画笔类工具进入书写模式。

2. 设置颜色与粗细

点击工具栏最右侧的颜色+粗细合并按钮，弹出面板可选择 8 种画笔色或 8 种荧光笔色，并拖动滑条调节粗细。面板底部有"贴边收缩"开关。

3. 收起工具栏

把工具栏拖到屏幕左/右边缘会自动吸附并延时收缩为正圆（仅显示拖动柄）；双击正圆可展开恢复。也可直接双击拖动柄原地收缩。

可滚动内容演示

下方内容足够长，方便你验证"笔记跟随页面滚动"的效果——画几笔后滚动页面，笔迹会与文字保持相对位置。

关于锚定

InkFlow 把笔迹以页面绝对坐标存储（视口坐标 + scrollX/Y）。当页面滚动或缩放时，锚定管理器按 rAF 节流重建视口坐标，笔迹随之平移，始终附着于页面内容之上。这与"附着到具体 DOM 元素"不同——更轻量、更稳定，不受页面重排影响。

滚动这一段，观察上方你画的笔记如何跟随移动。

形状与多边形

形状工具支持矩形、直线、虚线、箭头、椭圆与多边形。前五种为拖拽绘制；多边形为多点点击：每次点击确认一个顶点，右键闭合，Esc 取消。

橡皮擦

橡皮擦有两种模式：整图形擦除（点击笔迹即整条删除）与笔触擦除（仅擦除经过的片段，保留两侧）。点击橡皮擦按钮两次可切换模式与大小。

套索选择

套索工具可圈选多条笔迹，选中后拖动可整体移动，按 Delete 删除。选中笔迹周围会显示蓝色虚线边框。

导出

点击右上角"导出 HTML"可下载包含当前页面内容与笔迹的 HTML 文件（笔迹以 SVG 绝对坐标覆盖整篇文档）。"导出 PDF"在 demo 中会提示需安装完整扩展。

更多内容用于滚动

段落一：InkFlow 的工具栏采用 Microsoft Fluent 亚克力质感，半透明模糊背景配合圆角胶囊造型，在不同网页背景下都能保持清晰可读。

段落二：笔迹使用 SVG path 渲染，圆珠笔与荧光笔通过 Catmull-Rom 样条转三次贝塞尔曲线实现平滑笔触。荧光笔采用半透明 multiply 混合模式模拟真实记号笔效果。

段落三：橡皮擦的命中检测基于"点到线段距离"，配合 bbox 快速剔除，保证大量笔迹下的擦除性能。笔触擦除会将原笔迹按命中点分段重建为开放折线。

段落四：套索选择使用射线法判断点是否在多边形内，任一笔记点落入圈选区域即视为选中，支持框选多条笔记后整体移动或删除。

段落五：自定义光标通过 SVG data URL 实现，画笔显示对应颜色与大小的圆形笔尖，橡皮擦显示虚线圆，形状与套索显示十字准星，直观反映当前工具状态。

段落六：贴边吸附基于工具栏边缘到屏幕边缘的最小距离判断，左右贴边时若开启贴边收缩开关，则延时 320ms 自动收缩为正圆，避免遮挡页面内容。

段落七：收缩状态下拖动工具栏离开贴边位置会自动展开恢复完整宽度。展开时若右边缘超出视口，工具栏会自动向左移动以保持在可视范围内。

段落八：颜色与粗细合并为一个按钮，图标内圆形预览的直径随真实大小映射变化（mapDiameter 函数），让用户一眼看出当前粗细量级。

段落九：多边形工具支持实时预览——鼠标移动时末段折线跟随光标，点击确认顶点，右键闭合形成封闭多边形。Esc 随时取消当前绘制。
