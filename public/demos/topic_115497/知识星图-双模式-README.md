# 知识星图 · 2D/3D 双模式知识星系

> **TRAE AI 创造力大赛初赛作品** · 学习工作赛道
>
> 输入任意技能名，自动生成 2D/3D 双模式知识星系——2D 俯瞰全局学习路径，3D 沉浸漫游知识星系，每掌握一个知识点，星系就点亮一颗星。

---

## 核心功能

### 功能一：2D 知识星图（俯瞰全局）

输入技能名（如「数据分析」「吉他」「法语」），自动生成 14-15 节点的学习路径星图。力导向布局让节点自然分散，粒子簇环绕每个知识点，掌握度以颜色区分（灰=未学、金=在学、绿=已掌握）。已掌握节点间自动形成翠绿星座连线，视觉化知识体系逐渐成形。

- 4 层学习路径模板（基础入门 → 进阶实践 → 高级应用 → 拓展延伸）
- 连线单向流光 + 拖尾，暗示学习先后顺序
- 景深映射学习层级（基础远、高级近 + 雾化）
- 发光强度表达掌握度（已掌握更亮更大）

### 功能二：3D 知识星系（沉浸漫游）

一键切换到 3D 模式，知识节点化为 3D 粒子球（每节点 ~80 粒子球面分布），level 映射 Z 轴深度。连线化为 3D 流光粒子单向流动，已掌握节点间翠绿星座连线在 3D 空间延伸。500 粒子环境星尘 + FogExp2 雾化营造宇宙深度感。

- OrbitControls：鼠标拖拽旋转、滚轮缩放、右键平移
- WASD/QE 飞行穿梭：W/S 前后、A/D 左右、Q/E 升降
- Raycaster 射线检测：点击粒子球弹出信息卡（复用 2D）
- 悬停高亮：鼠标悬停节点，该粒子球所有粒子加大加亮
- 自定义着色器：有机运动 + 径向辉光 + 距离衰减

### 功能三：双模式切换（状态实时同步）

顶栏「进入 3D 星系」按钮一键切换。2D/3D 通过 CustomEvent（starmap-ready / mastery-changed / starmap-rebuilt）状态同步，共享 `window.app`（StarMap 实例）。在 2D 切换掌握度，3D 实时更新粒子颜色/尺寸/星座连线。

## 技术栈

| 技术 | 用途 |
|------|------|
| Canvas 2D | 2D 模式粒子渲染（Simplex 流场 + 力导向布局） |
| Three.js r169 | 3D 模式 WebGL 渲染（ES Module + Import Map） |
| 自定义 GLSL 着色器 | 3D 粒子有机运动 + 径向辉光 + 距离衰减 + 悬停高亮 |
| OrbitControls | 3D 相机旋转/缩放/平移 |
| Raycaster | 3D 粒子球点击/悬停检测 |
| CustomEvent | 2D/3D 状态解耦同步 |

## 操作说明

### 2D 模式快捷键

| 按键 | 功能 |
|------|------|
| `N` | 新增节点 |
| `D` | 删除悬停节点 |
| `S` | 聚焦搜索框 |
| `E` | 导出星图为 PNG |
| `F` | 全屏切换 |
| 右键节点 | 循环切换掌握度（0→1→2→0） |
| 双击节点 | 重命名节点 |
| 拖拽节点 | 移动节点位置 |

### 3D 模式操作

| 操作 | 功能 |
|------|------|
| 鼠标拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 右键拖拽 | 平移 |
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 左移 / 右移 |
| `Q` / `E` | 下降 / 升降 |
| 点击粒子球 | 弹出节点信息卡 |

## 运行方式

### 方式一：一键启动脚本（推荐）

**Windows**：双击 `start-知识星图.bat`

**Mac/Linux**：终端运行 `./start-知识星图.sh`

脚本会自动启动 Python HTTP 服务器（端口 8765）并打开浏览器。

### 方式二：手动启动

```bash
cd 星河粒子
python -m http.server 8765
# 浏览器访问 http://localhost:8765/知识星图-双模式.html
```

> 需预装 Python 3.x（因项目使用 ES Module 架构，不能用 file:// 直接打开）

## 环境要求

- Chrome 90+ / Edge 90+ / Firefox 88+
- 支持 WebGL 2.0（3D 模式必需）
- 内存 2GB+ 可用
- Python 3.x（用于启动本地 HTTP 服务器）

---

## 移动端适配

- 2D 模式：自动隐藏左面板，信息卡全宽
- 3D 模式：粒子数减半（45/节点）、星尘减半（250）、仅支持触控 OrbitControls（旋转/缩放）
- 检测条件：`navigator.maxTouchPoints > 0` 或 `window.innerWidth < 768`

## 设计理念

传统学习路径工具（思维导图、甘特图）枯燥无味，学习者缺乏动力。知识星图用粒子云的流动、聚合、点亮来可视化学习进度——

- **景深 z 映射学习层级**：基础知识点在远景（雾化朦胧），高级知识点在近景（清晰醒目）
- **发光强度表达掌握度**：已掌握节点更亮更大，视觉反馈成就感
- **星座连线可视化知识体系**：已掌握节点间自动连线，知识体系逐渐成形
- **流光方向暗示学习顺序**：连线单向流光 + 拖尾，暗示学习先后
- **3D 沉浸漫游提升新颖感**：避免 2D 思维导图的"烂大街"感，WASD 飞行穿梭知识星系
