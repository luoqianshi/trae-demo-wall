## 1. Demo 简介

**是什么**：知识星图是一个 2D/3D 双模式知识星系引擎。输入任意技能名（如「数据分析」「吉他」「法语」），自动生成 14-15 节点的学习路径星图。2D 模式俯瞰全局学习路径（力导向布局 + 粒子簇 + 掌握度颜色），3D 模式沉浸漫游知识星系（粒子球 + 流光 + 星座连线 + WASD 飞行穿梭）。每掌握一个知识点，知识星系就点亮一颗星，已掌握节点间形成翠绿星座连线，知识体系逐渐成形。

**面向谁**：

- 自主学习爱好者，想系统规划学习路径
- K12 学生与大学生，需要可视化学习进度
- 终身学习者，希望用成就感驱动持续学习
- 知识管理从业者，寻找新颖的知识体系可视化方案

**主要功能**（3 个核心）：

### 功能一：2D 知识星图（俯瞰全局学习路径）

输入技能名后自动生成 4 层学习路径星图（基础入门 → 进阶实践 → 高级应用 → 拓展延伸）。力导向布局让节点自然分散，粒子簇环绕每个知识点。掌握度以颜色区分（灰=未学、金=在学、绿=已掌握），已掌握节点间自动形成翠绿星座连线。连线单向流光 + 拖尾暗示学习先后顺序，景深映射学习层级（基础远、高级近 + 雾化）。

![2D 知识星图 - 力导向布局与掌握度颜色](screenshots/knowledge-2d-starmap.png)

*2D 模式 · 「数据分析」学习路径：14 节点力导向布局 + 粒子簇 + 掌握度颜色（灰/金/绿）+ 星座连线*

### 功能二：3D 知识星系（沉浸漫游 + WASD 飞行）

一键切换到 3D 模式，知识节点化为 3D 粒子球（每节点 ~80 粒子球面分布），level 映射 Z 轴深度。连线化为 3D 流光粒子单向流动，已掌握节点间翠绿星座连线在 3D 空间延伸。500 粒子环境星尘 + FogExp2 雾化营造宇宙深度感。支持 OrbitControls 旋转缩放 + WASD/QE 飞行穿梭 + Raycaster 点击节点弹信息卡。

![3D 知识星系 - 粒子球与流光](screenshots/knowledge-3d-galaxy.png)

*3D 模式 · 知识星系：粒子球 + 流光 + 星座连线 + 环境星尘 + Fog 雾化纵深*

### 功能三：双模式切换（状态实时同步）

顶栏「进入 3D 星系」按钮一键切换 2D/3D。通过 CustomEvent（starmap-ready / mastery-changed / starmap-rebuilt）状态同步，共享 StarMap 实例。在 2D 切换掌握度，3D 实时更新粒子颜色/尺寸/星座连线。2D 快捷键（N/D/S/E/F）与 3D WASD 飞行互不冲突（window.is3D 标志隔离）。

![双模式切换 - 2D/3D 实时同步](screenshots/knowledge-dual-mode.png)

*双模式切换 · 2D 俯瞰全局 ↔ 3D 沉浸漫游，掌握度变化实时同步*

## 2. Demo 创作思路

**灵感来源**：

传统学习路径工具（思维导图、甘特图）枯燥无味，学习者缺乏动力。思维导图"烂大街"，甘特图太工程化，都缺乏成就感反馈。我想到：如果能用粒子云的流动、聚合、点亮来可视化学习进度——每掌握一个知识点，知识星系就点亮一颗星，已掌握节点间形成翠绿星座连线，知识体系逐渐成形——是否能让人更愿意坚持学习？

**想解决的问题**：

1. **学习路径可视化同质化**：思维导图/甘特图烂大街，缺乏新颖感与沉浸感
2. **学习进度缺乏成就感反馈**：传统工具只显示"完成/未完成"，没有视觉化的成就感
3. **知识体系缺乏空间隐喻**：平面列表/树形结构无法表达知识的层次与关联深度

**为什么做这个方向**：

选择「2D/3D 双模式知识星系」方向，是因为它同时满足了三个价值：

- **教育价值**：可视化学习路径与进度，帮助学习者系统规划
- **体验价值**：2D 俯瞰全局 + 3D 沉浸漫游双模式，既有全局观又有沉浸感，避免 2D 思维导图的"烂大街"感
- **技术价值**：Canvas 2D + Three.js 3D + 自定义着色器 + WASD 飞行 + Raycaster 交互 + CustomEvent 状态同步，技术完整度高

取舍上，我没有追求"大而全"的知识百科，而是聚焦「学习路径可视化 + 粒子沉浸体验」这一核心——4 层模板自动生成 + 双模式切换 + 掌握度驱动星系点亮，深度优于广度。

## 4. TRAE 实践过程

### 4.1 整体开发流程

整个项目使用 **TRAE IDE** 完成，从创意提案到可体验 Demo 共经历以下阶段：

**阶段一：创意构思与 2D 知识星图原型**

- 使用 TRAE 的 brainstorming 技能梳理创意方向
- 基于报名帖「知识星图·自主学习路径可视化系统」设计 4 层学习路径模板
- 用 TRAE 一次性生成 2D 单文件 HTML 原型（`知识星图-粒子版.html`）
- 包含 Simplex 流场 + 力导向布局 + 粒子簇节点 + 掌握度颜色 + 星座连线

**阶段二：2D 粒子能力深度融合（7 项改动）**

- 用 TRAE 的 Plan 模式规划 2D 视觉升级，对齐 3D 同等水平
- 改动 1：景深 z 映射学习层级（level1 远景 0.35 → level4 近景 0.95 + 雾化）
- 改动 2：掌握度发光强度与尺寸加强（已掌握 1.4x 亮度 + 1.25x 尺寸）
- 改动 3：已掌握节点间星座连线（翠绿 #6ad48a 发光线）
- 改动 4：连线流光方向 + 拖尾（暗示学习先后顺序）
- 改动 5：悬停 alpha 脉冲增亮（hover 时粒子 targetAlpha 提升 + burst 脉冲）
- 改动 6：移动端自动降质（粒子数减半、信息卡全宽）
- 改动 7：远景雾化融合（z<0.5 时叠加半透明背景色圆，模拟 3D Fog）

**阶段三：3D 知识星系引擎（Three.js + 自定义着色器）**

- 用 TRAE 的 Plan 模式规划 3D 引擎架构，新建独立 `knowledge-engine3d.js`
- 3D 节点位置映射：2D 力导向 (x,y) → 3D `(x-cx)*0.4, -(y-cy)*0.4, (level-2.5)*30`
- 3D 粒子球：每节点 ~80 粒子球面分布（r = nodeRadius * (0.4 + rand*0.6)）
- 自定义顶点+片段着色器：有机运动 + 径向辉光 + 距离衰减 + 悬停高亮增亮
- 3D 星座连线 + 流光粒子（每连线 4 粒子 from→to 单向流动）+ 环境星尘（500 粒子）
- OrbitControls 旋转/缩放/平移 + WASD/QE 飞行穿梭 + Raycaster 点击/悬停检测

**阶段四：2D/3D 双模式整合与验证**

- 用 TRAE 的 Plan 模式规划双模式整合方案
- CustomEvent 状态同步（starmap-ready / mastery-changed / starmap-rebuilt）
- 双 canvas 切换（display:none/block）+ 3D 引擎生命周期管理
- 2D/3D 键盘冲突修复（window.is3D 标志隔离 N/D/S/E/F 与 WASD）
- Chrome DevTools MCP 17 项验证（2D 渲染/交互 + 3D 渲染/飞行/点击 + 双模式切换）

### 4.4 开发心得与踩坑

**踩坑 1：2D vs 3D 视觉差距**

- 问题：2D 模式视觉层次感、动态流畅度低于 3D，像"烂大街"的思维导图
- 根因：2D 缺乏景深、发光、雾化等 3D 特有的层次感与氛围感
- 解决：系统对比 7 个维度，实施 7 项深度融合改动（景深映射层级/发光表达掌握度/星座连线/流光方向/悬停脉冲/移动端降质/远景雾化），2D 完全对齐 3D 同等水平
- 记录到 Self-Improving corrections.md：粒子作品交付前必须做 2D/3D 视觉差距检查

**踩坑 2：ES Module 不能用 file:// 打开**

- 问题：直接双击 HTML 报 CORS 错误
- 根因：ES Module 的 import 受浏览器 CORS 限制，file:// 协议被阻止
- 解决：提供 start-知识星图.bat 启动脚本，自动启动 Python HTTP 服务器

**踩坑 3：2D/3D 键盘冲突**

- 问题：2D 快捷键 S（搜索）/D（删除）与 3D WASD 的 S（后退）/D（右移）冲突
- 根因：两个模式的键盘事件监听都在 document 上，同时生效
- 解决：module 脚本中同步 `window.is3D` 标志，2D keydown 处理中检查 `if (window.is3D) return`，实现模式隔离

**踩坑 4：3D Raycaster 点击粒子球不命中**

- 问题：3D 模式点击粒子球有时不弹信息卡
- 根因：Points 对象的 Raycaster threshold 默认太小，粒子点难以命中
- 解决：设置 `raycaster.params.Points.threshold = 4.0`，扩大命中半径
