## 八、已知限制

1. **3D 模式高性能要求**：100K 粒子最高画质在集成显卡上 FPS ≈ 20，需独立显卡才能满速
2. **ES Module 限制**：必须通过 HTTP 服务器运行，不能直接 file:// 打开
3. **字体依赖**：使用 Google Fonts CDN 加载「马善政」「ZCOOL 小薇」字体，首次加载需联网
4. **浏览器兼容**：IE 不支持，需 Chrome 90+ / Edge 90+ / Firefox 88+
