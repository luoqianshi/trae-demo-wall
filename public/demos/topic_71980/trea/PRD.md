# 安诊·智能分诊助手 · 一页纸 PRD

> 老百姓去医院总挂错科，这个网页让用户选身体部位和症状，30 秒推荐该挂的科室、判断紧急程度、给出就医提示。

## 一、痛点与价值

患者缺乏医学常识，面对几十个科室常挂错号，造成时间浪费与病情延误；急诊与普通门诊混淆，危急症状未被及时识别。本产品以零门槛的网页交互，30 秒内给出科室推荐与紧急程度判断，降低就医决策门槛，提升就诊效率，让医疗资源更合理分配。

## 二、核心功能

1. **选身体部位**：人体正反面视图，点击头部/胸部/腹部/四肢等部位进入下一步。
2. **选症状**：基于所选部位展示常见症状列表（如头痛、胸痛、腹痛、皮疹），支持多选。
3. **智能推荐科室 + 紧急程度**：依据内置症状-科室知识库规则匹配，输出推荐科室（如心内科、消化内科、神经内科）与紧急等级（常规 / 尽快 / 急诊）。
4. **就医提示**：给出就诊前准备建议（空腹/携带既往病历/避免剧烈活动等）。
   - **危急症状熔断**：胸痛、呼吸困难、意识丧失、严重出血、剧烈腹痛等触发红色急诊警告弹窗，提示立即拨打 120 / 前往急诊。

## 三、用户流程

`进入首页 → 选择身体部位 → 勾选症状 →（危急？→ 红色急诊警告）→ 输出推荐科室+紧急程度+就医提示 → 查看免责声明`

## 四、技术方案

- **形态**：单个 HTML 文件，纯前端实现，零依赖、零安装，离线可用。
- **实现**：原生 HTML + CSS + JavaScript，无后端、无数据库、无第三方库。
- **知识库**：内置 JSON 格式的「部位—症状—科室—紧急程度」规则表，前端规则匹配。
- **部署**：可直接双击打开，或托管至任意静态资源服务（GitHub Pages / 内网服务器）。
- **隐私**：所有数据仅在本地浏览器处理，不上传任何用户信息。

## 五、免责声明

本工具仅作为挂号前的科室参考，不构成任何医疗诊断或治疗建议；输出结果不能替代医生面诊。危急症状请立即拨打 120 或前往最近急诊。如有疑问，以医疗机构现场分诊为准。
