# 对话收尾 - 子技能

## 定位

**对话收尾门控器。** 像出门前检查钥匙手机钱包一样，不检查完不让走。

解决的问题：AI反复忘记追加 `memory/raw/`，导致对话等于没发生。这不是"不知道要记"的知识问题，而是"到该记的时候没记"的执行问题。

## 触发条件

| 触发信号 | 示例 |
|---------|------|
| 用户说结束/再见/晚安 | "今天先到这""拜拜""晚安" |
| 对话明显收尾 | 用户连续2轮只说"好""嗯""OK" |
| AI准备结束回复且无待办 | 回复末尾没有开放问题 |

## 强制三步检查

### 第一步：追加 raw/

```
1. 读取 memory/raw/YYYY-MM-DD.md（今天的文件）
2. 如果文件不存在 → 先创建
3. 追加本次对话要点：
   ## 事实
   ## 决策
   ## 待办
   ## 情绪
```

**不追加 = 没记，本次对话等于没发生。**

### 第二步：检查 wiki 写入

扫描本次对话，是否有结论需要写入 wiki：
- 战略决策 → wiki/战略记录.md
- 工作进度 → wiki/工作进度.md
- 产品需求 → wiki/需求记录.md
- 重要认知 → wiki/认知知识库.md

有则写入，无则跳过。

### 第三步：更新 short-term.md

如果第二步有 wiki 写入 → 更新 memory/short-term.md 的 wiki-derived 条目。

## 检查清单

- [ ] `memory/raw/YYYY-MM-DD.md` 已追加
- [ ] 如有重要结论，已写入对应 wiki 文件
- [ ] 如有 wiki 写入，已更新 short-term.md

**全部打勾后才能结束对话。缺任何一项 = 对话没结束。**
