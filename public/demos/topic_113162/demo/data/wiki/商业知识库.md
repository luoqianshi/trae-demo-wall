# 商业知识库

> 商业决策的统一参考。投资、赚钱、资产、机会过滤。
> 原则：每个决策必须绑定用户个人情况。

---

## 退出条件

什么情况下不值得继续做一件事：

1. **验证不通过** — 需求三步验证（疼不疼/怎么解决/什么时候能用）任何一关不通过
2. **投入产出失衡** — 连续2周投入时间但无明确产出或反馈
3. **方向偏移** — 与北极星目标（一人公司+AI工具）无关且无战略价值
4. **精力透支** — 连续3天情绪低于3分且与健康恶化相关

## 机会评估框架

| 维度 | 问题 | 判断标准 |
|------|------|---------|
| 疼不疼 | 找到了一个正在疼的人吗？ | 他在抱怨反复出现的问题，不是闲聊 |
| 怎么解决 | 他能描述当前方案的痛点吗？ | "每周手动做XX，花4小时" |
| 什么时候能用 | "下周一给你第一版，能用吗？" | 回答急迫而非犹豫 |
| 与我相关 | 和我的技术栈/领域匹配吗？ | 能用现有能力直接做 |
| 时间成本 | 预估投入时间？ | ≤2周可出MVP |

## 大赛参赛策略

| 策略 | 依据 |
|------|------|
| 痛点优先于功能 | 评委关注"解决什么问题"，不是"有多少功能" |
| 真实使用场景 | 我是TRAE重度用户，痛点来自真实体验 |
| 行业趋势验证 | superset（多Agent并行）和hermes-agent（记忆系统）验证方向 |
| 截图胜于文字 | 创意产物HTML配真实产品截图，比纯文字有说服力 |

## 投资原则

- 只投自己能看懂的方向
- AI/Agent/工具赛道是长期主线
- 单笔不超过可承受损失的10%
