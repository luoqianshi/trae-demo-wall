# 场景感知型新媒体内容创作引擎 - Demo

## 如何体验

1. 解压本 zip 包到任意文件夹
2. 双击 `index.html` 用浏览器打开（推荐 Chrome / Edge / Safari）
3. 即可完整体验所有功能，无需联网、无需服务器

## 体验路径推荐

1. **发现页**（首页）→ 浏览六大场景、案例瀑布流
2. **工作台**（底部 Tab 第二个）→ 在输入框输入「完美日记口红小红书种草」→ 点红色发送按钮
3. **场景确认**→ 查看自动识别结果 → 点「确认生成」
4. **结果页**→ 顶部切换「安全牌/创意牌/实验牌」三方案 → 展开五大模块手风琴 → 查看 11 项自检徽章
5. **底部操作**→ 试试复制全文、收藏、重新生成
6. **历史页**→ 查看创作记录
7. **我的页**→ 查看配额、注册解锁

## 技术栈

React 18 + Vite + TypeScript + TailwindCSS + Zustand + Framer Motion

## 备注

- 本 Demo 为纯前端演示版，内容生成基于规则引擎模拟，未接入真实 LLM
- 历史记录存储在浏览器 LocalStorage 中，清除浏览器数据会丢失
- 推荐使用手机模式浏览（Chrome F12 → 设备切换）以获得最佳移动端体验
