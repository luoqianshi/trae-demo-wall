## 1. 系统总体架构

### 1.1 架构概述

虚实一体仿真系统采用分层分布式架构设计，由基础设施层、通信层、平台服务层、应用层和展示层组成。系统支持单机部署、局域网部署和集群部署三种模式，可根据用户规模和场景复杂度灵活扩展。

## 6. 通信协议支持

### 6.1 Modbus TCP/RTU

| 属性 | 说明 |
|------|------|
| 协议标准 | Modbus Application Protocol V1.1b3 |
| 支持模式 | TCP (端口 502)、RTU over TCP、RTU over Serial |
| 功能码支持 | 01/02/03/04/05/06/15/16/23 |
| 数据类型 | Coil、Discrete Input、Holding Register、Input Register |
| 最大设备数 | 256 (TCP) / 247 (RTU) |
| 轮询周期 | 100ms - 10s 可配置 |
| 并发连接 | 最大 128 个 TCP 连接 |

**配置示例：**

```yaml
protocol:
  type: modbus_tcp
  name: "生产线PLC"
  host: "192.168.1.100"
  port: 502
  unit_id: 1
  timeout: 5000
  poll_interval: 1000
  registers:
    - address: 40001
      type: holding_register
      count: 10
      data_type: float32
      name: "温度传感器"
```

### 6.2 Profinet

| 属性 | 说明 |
|------|------|
| 协议标准 | IEC 61158 / IEC 61784 |
| 支持版本 | Profinet IO RT / IRT |
| 设备类型 | IO-Controller、IO-Device |
| 循环时间 | 1ms - 512ms |
| 最大设备数 | 64 个 IO-Device |
| 数据长度 | 每个设备最大 1440 字节输入/输出 |
| 硬件要求 | 需要专用 Profinet 网卡或兼容交换机 |

### 6.3 TCP/IP 通用协议

| 属性 | 说明 |
|------|------|
| 连接类型 | TCP Client / TCP Server |
| 数据格式 | 二进制 / ASCII / JSON / XML |
| 编码方式 | UTF-8 / GBK / Hex |
| 心跳机制 | 支持自定义心跳包 |
| 断线重连 | 自动重连，间隔可配置 |
| 最大连接 | 1024 个并发连接 |

### 6.4 OPC UA

| 属性 | 说明 |
|------|------|
| 协议标准 | OPC Unified Architecture (IEC 62541) |
| 支持版本 | OPC UA 1.04 |
| 安全模式 | None / Sign / SignAndEncrypt |
| 安全策略 | None / Basic128Rsa15 / Basic256 / Basic256Sha256 |
| 认证方式 | 匿名 / 用户名密码 / X.509 证书 |
| 传输协议 | OPC TCP (端口 4840) / HTTPS |
| 信息建模 | 支持自定义对象类型和变量类型 |
| 订阅机制 | 支持数据变化订阅和事件订阅 |

**安全配置示例：**
