## 1. 系统简介与适用对象

### 1.1 系统简介

虚实一体仿真系统（Virtual-Real Simulation System，简称 VRSS）是一款面向工业自动化、智能制造与职业教育领域的综合性虚实联动仿真平台。系统将数字孪生、工业通信协议、虚拟仿真与真实设备控制深度融合，为用户提供从理论学习、虚拟仿真到真实设备操作的全链条实训体验。

### 1.2 核心功能

- **数字孪生建模**：高精度 3D 模型，支持设备拆解与工艺模拟
- **机器人编程**：示教编程、离线编程、碰撞检测
- **工艺仿真**：布局规划、路径优化、节拍分析、产能评估
- **虚实联动**：虚拟控制真实设备、真实数据驱动虚拟仿真
- **教学管理**：资源管理、任务发布、考核评估、数据分析
- **多协议支持**：Modbus TCP/RTU、Profinet、OPC UA、TCP/IP

### 1.3 适用对象

| 角色 | 典型用户 | 主要用途 |
|------|----------|----------|
| 管理员 | 系统管理员、IT 运维 | 系统配置、用户管理、日志审计 |
| 教师 | 实训指导教师、课程负责人 | 任务发布、资源管理、考核评分 |
| 学生 | 职业院校学生、企业培训学员 | 仿真实训、任务完成、技能考核 |

2. 选择【切换角色】
3. 在弹窗中选择目标角色
4. 点击【确认切换】

### 2.4 个人中心

点击用户头像进入个人中心，可执行以下操作：

- 查看/修改个人信息
- 修改密码

## 3. 快速入门指南

### 3.1 首次登录配置

首次登录后，建议完成以下配置：

1. **完善个人信息**：上传头像、填写真实姓名、联系方式
2. **修改初始密码**：建议设置 8 位以上包含字母、数字和特殊字符的密码

```
登录系统 -> 选择功能模块 -> 打开标签页 -> 配置参数 -> 执行操作 -> 查看结果

### 4.1 基础控制模块

#### 4.1.1 机器人控制

**功能说明**：对工业机器人进行手动控制、关节运动和笛卡尔空间运动。

**界面布局**：

```

├──────────────────────────┬──────────────────────────────────┤
│                          │  关节控制                        │

│                          │  │ J4: [====●====]  0.00°     │ │
│                          │  │ J5: [====●====]  0.00°     │ │

**操作步骤**：

1. 在左侧设备树中选择目标机器人
2. 点击【使能】按钮上电
3. 使用滑块或输入数值控制各关节角度
4. 或切换至笛卡尔模式控制末端位姿
5. 点击【运行】执行运动指令

**注意事项**：

- 操作前确认机器人工作空间内无障碍物
- 速度建议从 10% 开始逐步增加
- 遇到异常立即点击【急停】

#### 4.1.2 设备监控

**功能说明**：实时监控所有接入设备的运行状态、数据点和报警信息。

**界面布局**：

- 左侧：设备树状列表（按产线/工作区分组）
- 中部：设备状态卡片（在线/离线/报警）
- 右侧：实时数据点表格
- 底部：报警历史列表

**设备状态卡片说明**：

| 颜色 | 状态 | 说明 |
|------|------|------|
| 绿色 | 在线 | 设备正常运行 |
| 灰色 | 离线 | 设备未连接 |
| 红色 | 报警 | 设备故障或异常 |
| 黄色 | 维护 | 设备维护中 |
| 蓝色 | 待机 | 设备待机中 |

**操作步骤**：

1. 展开设备树，浏览所有设备
2. 点击设备名称查看详情
3. 在数据点表格中查看实时数值
4. 点击【历史趋势】查看数据曲线
5. 报警发生时，点击报警条目查看详情和处理建议

### 4.2 数字孪生模块

#### 4.2.1 拆解视图

**功能说明**：对 3D 设备模型进行爆炸图拆解，展示内部结构和零部件关系。

**操作步骤**：

1. 在设备树中选择要拆解的设备
2. 点击【拆解视图】标签页
3. 使用拆解滑块控制拆解程度（0% - 100%）
4. 点击零部件可查看详细信息：
   - 零件名称和编号
   - 材质和规格
   - 装配关系
   - 替换件信息
5. 点击【自动拆解】观看完整拆解动画
6. 点击【复位】恢复原始装配状态

**功能按钮**：

| 按钮 | 功能 |
|------|------|
| 自动拆解 | 按预设顺序自动播放拆解动画 |
| 逐步拆解 | 每次点击拆解一个层级 |
| 爆炸视图 | 所有零件沿轴线均匀散开 |
| 剖面视图 | 显示内部剖面结构 |
| 标注显示 | 显示零件编号和名称标注 |
| 复位 | 恢复初始装配状态 |

#### 4.2.2 工艺模拟

**功能说明**：模拟工业生产流程，展示物料流动、工艺步骤和设备协作。

**操作步骤**：

1. 选择要模拟的工艺流程
2. 配置模拟参数：
   - 生产节拍
   - 物料数量
   - 设备速度
3. 点击【开始模拟】
4. 在 3D 视图中观察工艺过程
5. 查看实时统计数据：
   - 当前工序
   - 完成进度
   - 设备利用率
   - 在制品数量
6. 点击【暂停】可暂停模拟进行分析
7. 点击【重置】重新开始模拟

**支持的工艺类型**：

| 工艺类型 | 说明 |
|----------|------|
| 装配工艺 | 零部件装配流程模拟 |
| 焊接工艺 | 焊接路径和参数模拟 |
| 喷涂工艺 | 喷涂轨迹和厚度模拟 |
| 打磨工艺 | 打磨路径和力控模拟 |
| 搬运工艺 | 物料搬运和码垛模拟 |
| 检测工艺 | 质量检测流程模拟 |

### 4.3 编程调试模块

#### 4.3.1 示教编程

**功能说明**：通过图形化界面进行机器人示教编程，支持点动示教、轨迹记录和程序编辑。

**界面布局**：

```

│ 示教编程                                                    │
├──────────────────────────┬──────────────────────────────────┤
│                          │  程序编辑器                      │
│   [3D 仿真视图]            │  ┌────────────────────────────┐ │
│                          │  │ 1  MOVEJ  P1  VJ=50%       │ │
│   [工具坐标系显示]          │  │ 2  MOVEL  P2  VL=200mm/s   │ │
│                          │  │ 3  MOVEL  P3  VL=200mm/s   │ │
│   [轨迹预览]               │  │ 4  MOVEC  P4  P5  V=100    │ │

│                          │  └────────────────────────────┘ │
│                          │                                  │
│                          │  点位列表                        │
│                          │  P1: X=500 Y=200 Z=300...      │
│                          │  P2: X=600 Y=300 Z=400...      │

│                          │  [添加点] [插入] [删除] [修改]   │
└──────────────────────────┴──────────────────────────────────┘
```

**操作步骤**：

1. 选择目标机器人和工具
2. 在 3D 视图中手动移动机器人到目标位置
3. 点击【记录点位】保存当前位姿
4. 在程序编辑器中选择指令类型：
   - MOVEJ：关节运动
   - MOVEL：直线运动
   - MOVEC：圆弧运动
   - DOUT：数字量输出
   - DIN：数字量输入
   - TIMER：延时等待
5. 设置运动参数（速度、加速度）
6. 重复步骤 2-5 完成程序编写
7. 点击【仿真运行】验证程序
8. 确认无误后点击【下载到设备】（需授权）

**支持的指令类型**：

| 指令 | 说明 | 参数 |
|------|------|------|
| MOVEJ | 关节空间运动 | 目标点、速度百分比 |
| MOVEL | 直线运动 | 目标点、线速度 |
| MOVEC | 圆弧运动 | 中间点、终点、速度 |
| DOUT | 数字输出 | 端口号、ON/OFF |
| DIN | 数字输入等待 | 端口号、状态、超时 |
| TIMER | 延时 | 时间 (秒) |
| CALL | 子程序调用 | 子程序名 |
| IF/ELSE | 条件判断 | 条件表达式 |
| WHILE | 循环 | 循环条件 |
| LABEL | 标签 | 标签名 |
| JUMP | 跳转 | 目标标签 |

#### 4.3.2 碰撞检测

**功能说明**：在仿真环境中检测机器人与周围环境、工件之间的碰撞，预防实际运行中的安全事故。

**操作步骤**：

1. 加载机器人和工作场景
2. 点击【碰撞检测】标签页
3. 配置检测参数：
   - 检测精度
   - 碰撞阈值
   - 忽略对象列表
4. 运行仿真程序
5. 系统实时检测碰撞并高亮显示
6. 碰撞发生时：
   - 仿真自动暂停
   - 显示碰撞位置和深度
   - 记录碰撞日志
7. 调整程序或布局消除碰撞
8. 重新运行验证

**碰撞检测结果**：

| 碰撞等级 | 颜色 | 说明 | 处理建议 |
|----------|------|------|----------|
| 严重碰撞 | 红色 | 已发生实体穿透 | 必须修改程序 |
| 接近碰撞 | 橙色 | 距离小于安全阈值 | 建议优化路径 |
| 安全距离 | 绿色 | 距离大于安全阈值 | 无需处理 |

### 4.4 工艺拓展模块

#### 4.4.1 布局规划

**功能说明**：在 3D 环境中进行工厂/产线布局设计，拖拽摆放设备、调整位置和方向。

**操作步骤**：

1. 点击【布局】标签页
2. 从设备库中拖拽设备到 3D 场景
3. 选中设备后使用操作手柄调整：
   - 移动：沿 X/Y/Z 轴平移
   - 旋转：绕各轴旋转
   - 缩放：调整设备尺寸
4. 使用对齐工具精确对齐设备
5. 设置设备属性（名称、参数）
6. 保存布局方案
7. 导出布局图纸（PDF/DWG）

**布局分析功能**：

| 分析项 | 说明 |
|--------|------|
| 空间利用率 | 计算设备占用面积比例 |
| 物流路径 | 分析物料搬运路径长度 |
| 安全距离检查 | 检查设备间安全距离 |
| 干涉检查 | 检查设备间物理干涉 |

#### 4.4.2 路径规划

**功能说明**：为机器人或 AGV 规划最优运动路径，支持避障和多点路径优化。

**操作步骤**：

1. 选择运动对象（机器人/AGV）
2. 设置起点和终点
3. 添加中间途经点（可选）
4. 配置约束条件：
   - 避障区域
   - 速度限制
   - 加速度限制
   - 关节限位
5. 点击【生成路径】
6. 查看生成的路径曲线
7. 查看路径参数：
   - 总长度
   - 预计时间
   - 最大速度
   - 能量消耗
8. 点击【优化】进行路径优化
9. 满意后保存路径

#### 4.4.3 节拍分析

**功能说明**：分析生产线的节拍时间，识别瓶颈工序，优化生产平衡。

**操作步骤**：

1. 加载产线布局
2. 设置各工序的标准工时
3. 点击【计算节拍】
4. 查看分析结果：
   - 产线节拍 (Cycle Time)
   - 瓶颈工序
   - 工序平衡率
   - 产能 (UPH)
5. 查看节拍柱状图和山积图
6. 调整工序分配或设备参数
7. 重新计算对比优化效果

**关键指标**：

| 指标 | 公式 | 说明 |
|------|------|------|
| 节拍时间 | max(各工序时间) | 产线瓶颈时间 |
| 平衡率 | 总工时 / (节拍 x 工位数) | 产线平衡程度 |
| UPH | 3600 / 节拍 | 每小时产能 |
| 线效率 | 实际产出 / 理论产出 | 产线效率 |

#### 4.4.4 产能评估

**功能说明**：基于设备参数和布局方案，评估产线的理论产能和实际产能。

**操作步骤**：

1. 选择评估对象（单设备/产线/工厂）
2. 输入生产参数：
   - 每日工作时长
   - 设备综合效率 (OEE)
   - 产品换型时间
   - 计划停机时间
3. 点击【开始评估】
4. 查看评估报告：
   - 理论产能
   - 实际产能
   - 设备利用率
   - OEE 分解
5. 导出评估报告 (PDF/Excel)

#### 4.4.5 焊接工艺

**功能说明**：模拟焊接过程，配置焊接参数，生成焊接程序。

**操作步骤**：

1. 选择焊接机器人和焊枪
2. 导入焊接工件模型
3. 在工件上标注焊缝位置
4. 配置焊接参数：
   - 焊接电流/电压
   - 焊接速度
   - 摆动参数
   - 保护气体流量
5. 生成焊接路径
6. 运行焊接仿真
7. 查看焊缝成型效果
8. 导出焊接程序

**焊接参数配置**：

| 参数 | 单位 | 典型范围 |
|------|------|----------|
| 焊接电流 | A | 50 - 500 |
| 焊接电压 | V | 15 - 40 |

## 5. 操作步骤示例

### 5.1 完成一次实训的完整流程

以下以"机器人搬运实训"为例，演示从任务接收到完成提交的完整流程。

#### 步骤 1：接收任务

1. 学生登录系统
2. 点击【任务】标签页
3. 在【我的任务】中找到"机器人搬运实训"
4. 查看任务详情：
   - 任务目标：使用机器人完成物料从 A 点到 B 点的搬运
   - 评分标准：操作规范 30%、完成效率 20%、结果准确 30%、安全 20%
   - 截止时间：2026-06-20 23:59

#### 步骤 2：准备环境

1. 点击【开始任务】进入实训环境
2. 系统自动加载预设场景：
   - 机器人模型（ABB IRB 1200）
   - 搬运工件
   - 起点和终点托盘
3. 检查设备状态：
   - 机器人状态：在线
   - 夹爪状态：正常
   - 传感器状态：正常

#### 步骤 3：编写程序

1. 切换到【示教编程】标签页
2. 设置工具坐标系（夹爪中心）
3. 记录关键点位：
   - P1：安全位置（Home）
   - P2：取料位置上方
   - P3：取料位置
   - P4：放料位置上方
   - P5：放料位置
4. 编写程序：

```
 1  MOVEJ  P1  VJ=50%       // 回到安全位置
 2  MOVEJ  P2  VJ=50%       // 移动到取料上方
 3  MOVEL  P3  VL=100mm/s   // 下降到取料位置
 4  DOUT   OG#(1)  ON       // 夹紧工件
 5  TIMER  T=1.0            // 等待夹紧
 6  MOVEL  P2  VL=100mm/s   // 抬起
 7  MOVEJ  P4  VJ=50%       // 移动到放料上方
 8  MOVEL  P5  VL=100mm/s   // 下降到放料位置
 9  DOUT   OG#(1)  OFF      // 松开工件
10  TIMER  T=1.0            // 等待松开
11  MOVEL  P4  VL=100mm/s   // 抬起
12  MOVEJ  P1  VJ=50%       // 回到安全位置
```

#### 步骤 4：仿真验证

1. 点击【碰撞检测】标签页
2. 启用碰撞检测
3. 点击【仿真运行】
4. 观察机器人运动轨迹
5. 确认无碰撞报警
6. 查看仿真数据：
   - 循环时间：12.5 秒
   - 路径长度：3.2 米
   - 无碰撞

#### 步骤 5：优化程序

1. 分析仿真结果
2. 调整运动速度参数
3. 优化路径减少空行程
4. 重新仿真验证
5. 确认优化效果：
   - 循环时间：10.2 秒（优化 18%）

#### 步骤 6：提交任务

1. 点击【提交任务】
2. 确认提交信息
3. 系统自动记录：
   - 程序代码
   - 仿真结果
   - 操作记录
   - 耗时统计
4. 提交成功，等待评分

#### 步骤 7：查看评分

1. 教师评分完成后收到通知
2. 点击【考核】标签页
3. 查看评分详情：

| 维度 | 得分 | 满分 | 反馈 |
|------|------|------|------|
| 操作规范性 | 28 | 30 | 程序结构清晰，注释完整 |
| 完成效率 | 18 | 20 | 循环时间优秀 |
| 结果准确性 | 27 | 30 | 搬运精度达标 |
| 安全 | 20 | 20 | 无碰撞，安全规范 |
| **总分** | **93** | **100** | **优秀** |

## 6. 故障处理指南

### 6.1 常见故障及处理

| 故障现象 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 无法登录 | 用户名/密码错误 | 检查大小写，点击"忘记密码"重置 |
| 页面加载缓慢 | 网络延迟或服务器负载高 | 刷新页面，检查网络连接 |
| 3D 场景黑屏 | WebGL 不支持或显卡驱动过旧 | 更新显卡驱动，更换浏览器 |
| 设备连接失败 | IP 地址错误或设备离线 | 检查网络连接，确认设备 IP |
| 仿真运行卡顿 | 场景复杂度过高 | 简化场景，降低渲染质量 |
| 程序下载失败 | 设备未授权或通信中断 | 检查设备授权状态，重新连接 |
| 数据不同步 | 通信延迟或丢包 | 检查网络质量，调整同步参数 |
| 碰撞检测误报 | 模型精度或阈值设置不当 | 调整碰撞阈值，检查模型尺寸 |
