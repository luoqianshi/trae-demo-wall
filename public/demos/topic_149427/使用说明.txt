金鉴 · 黄金事件智能分析 Web Demo
======================================

一、这是什么
金鉴是一款「事件驱动型」黄金投资参考工具的 Web 原型。
本压缩包为可独立运行的演示版本（Demo），无需联网、无需配置 API Key，
所有数据为内置 Mock 演示数据。

二、如何打开（最简单）
  解压后，双击 index.html 即可在浏览器中直接打开。
  · 已使用单文件打包技术，所有 JS/CSS 内联进 index.html
  · 无需启动服务器，无需任何配置
  · 支持 Chrome / Edge / Firefox / Safari 等主流浏览器
  · 离线可用（字体降级为系统字体，不影响功能）

  如遇白屏（极少数浏览器限制 file://），可改用本地服务器：
    python3 -m http.server 8099
  然后浏览器访问 http://localhost:8099

三、Demo 包含的页面
  · 首页（事件雷达）：金价卡片（演示数据）+ 事件时间轴 + 黄金资讯
  · 事件库：全部黄金事件列表，支持类型/等级/方向筛选
  · 事件详情：事件背景 + 历史相似案例 + 因子拆解 + 复盘记录
  · 历史对比：当前事件与历史案例价格曲线叠加对比
  · 我的：数据源配置 + 关注订阅 + 复盘记录 + 历史准确率

四、关于数据
  · 行情、资讯、翻译均使用内置 Mock 数据演示
  · 原项目支持接入 AllTick（金价）+ NewsAPI（资讯）+ Google 翻译
  · 接入真实数据需在源码 .env 中配置 Token 并重新构建

五、技术栈
  React 18 + TypeScript + Vite + TailwindCSS + Zustand + Recharts
  路由：HashRouter（支持 file:// 直接打开）
  打包：vite-plugin-singlefile（单文件内联）
