小日常·健康List — 星辰绽放动效预览
=====================================

【文件说明】
- competition-preview.html          主页面（单文件，含全部 UI 和动画逻辑）
- Achievement award star animation.json   Lottie 星星成就动效
- Task complete tick.json           Lottie 打勾完成动效


【如何查看】

注意：由于动画素材是外部 JSON 文件，不能直接双击 HTML 打开（浏览器会拦截本地文件请求）。
请用以下任一方式启动本地服务器：

方式一：Python（推荐，大多数电脑已预装）
  1. 把这三个文件放在同一文件夹
  2. 打开命令行（Windows 按 Win+R 输入 cmd）
  3. cd 进入该文件夹
  4. 运行：python -m http.server 8765
  5. 浏览器打开：http://localhost:8765/competition-preview.html

方式二：Node.js
  1. cd 进入该文件夹
  2. 运行：npx serve
  3. 按提示打开浏览器


【操作指引】
- 点击顶部「🎉 触发星辰绽放」按钮可直接预览庆祝动效
- 点击圆圈完成打卡项，全部完成后自动触发庆祝
- 底部 Tab 切换 4 个页面（今日/日历/清单/我的）
- 点击 🎯 选职业定制清单
