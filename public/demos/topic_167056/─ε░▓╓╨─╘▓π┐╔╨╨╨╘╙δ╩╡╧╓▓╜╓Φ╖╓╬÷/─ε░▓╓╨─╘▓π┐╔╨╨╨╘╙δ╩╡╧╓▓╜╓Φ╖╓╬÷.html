14 条服务链

WF_SOS 紧急求助链

项目内容
触发条件SOS 按键触发、高危词命中（摔倒、胸痛、喘不过气、站不起来、快来帮我）
子分类跌倒/受伤、胸痛/呼吸困难、意识异常、明确求助、严重出血/烫伤
风险/优先级SOS 按键 = 紧急（立即 4G 发送）；高危词 = 高（1 分钟内推送）；疼痛非急症 = 中（5 分钟内）
步骤流程识别（硬规则，不等分类） → 4G/eSIM 独立发送 SOS → 语音安抚 → 家属端高优先级推送 → 误触处理 → 留痕
规则与红线SOS 不经过分类；4G 独立发送不依赖手机；不做医疗判断；误触不惩罚

WF_HEALTH_SYMPTOM 健康症状追踪链

项目内容
触发条件分类为 health_symptom
子分类症状、睡眠、饮食、疼痛、复诊/检查
风险/优先级高（胸闷+头晕同时出现）→ 即时；中（单一症状反复）→ 当天；低（偶发轻微）→ 归档
步骤流程识别与抽取 → 风险分级 → 健康卡生成（含辅助参考前缀） → 趋势分析 → 医疗建议汇总 → 红线过滤
规则与红线不诊断疾病；趋势不是诊断；用药记录不等于医嘱

WF_HEALTH_DATA 健康数据记录链

项目内容
触发条件分类为 health_data（血压/血糖/体温/心率/睡眠/体重）
子分类血压、血糖、体温、心率、睡眠时长、体重
风险/优先级收缩压 >= 180 或体温 >= 38.5 → 高风险推送
步骤流程正则提取数值 → 识别测量时段 → 阈值检查 → 入指标库 → 趋势图 → 周期总结
规则与红线阈值不是诊断；数值来源标注；异常值优先推送

WF_MEDICATION 用药管理链

项目内容
触发条件分类为 medication
子分类药快没了、忘吃药、药物不适、药物关联
步骤流程识别药品 → 关联既往用药记录 → 生成家属待办 → 用药记录入健康时间线
规则与红线记录老人说了什么药，但不建议增减剂量；不替代医嘱

WF_EMOTIONAL 情感陪伴链

评分机制

  • 关键词评分：每个分类的关键词出现 +0.2，上限 3 个 = 0.6 分
  • 模式评分：正则匹配 +0.2，上限 2 个 = 0.4 分
  • Meta 融合：近场有人 → social_contact +0.2；NFC + 健康 → health_data/medication +0.15

硬件连接：BLE + 4G/eSIM 双模

SOS 是念安的安全承诺，不能依赖 BLE + 手机方案。

连接负责什么可靠性功耗
BLE（蓝牙）日常数据通道：录音上传、缓存同步、近场识别、家属端实时查看依赖手机在身边且蓝牙开启低
4G/eSIM安全通道：SOS 独立发送、离线告警、缓存补传、低频定位上报不依赖手机，几乎任何场景可用SOS 瞬时高但极短；日常极低频心跳

功耗策略：日常走 BLE 省电；BLE 长时间未连接时激活 4G 低频心跳；SOS 触发时 BLE 和 4G 同时尝试，4G 确保送达。4G 月流量极小（月均 < 50MB），物联网卡月租 3-10 元可覆盖。

主照护人查看健康趋势、待办、医疗建议、重要提醒不能默认查看所有私密记忆和敏感物品位置
普通家属查看被分享的记忆、日记、部分待办不能默认查看健康详情、精确定位、证件/存折
医生/护理人员查看老人授权导出的医疗建议或健康摘要不能访问家庭记忆、物品位置、完整私密时间线
紧急联系人在 SOS 或高风险场景下接收必要信息不能因一次紧急授权获得长期全量访问

核心安全机制

最小权限

每个家属默认只能看被授权的数据，不默认全家共享。

场景授权

看诊、急救、探访、纪念等场景使用不同权限。

敏感物品保护

识别高敏感内容（身份证、银行卡、存折、钥匙），自动提高保护级别。

访问留痕

谁在什么时候查看了健康、位置、物品位置和记忆材料，都有记录。

设备丢失冻结

账号可在家属端冻结；新设备绑定后恢复数据；旧设备本地敏感缓存失效。

SOS 临时例外

可以临时向紧急联系人展示必要位置和健康摘要，但只限本次事件。
