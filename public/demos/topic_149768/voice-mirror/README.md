# 声临其境 —— 云端声音训练与实时模拟器

**TRAE AI 创造力大赛 · "声临其境" 项目初赛 Demo**

---

## 项目简介

"声临其境" 是一个纯前端网页应用，模拟云端 AI 声音训练与实时语音合成的完整流程。用户上传音频文件后，系统模拟云端训练过程，训练完成后即可输入文字进行语音合成播放。

## 技术栈

- HTML5 + CSS3 + JavaScript（ES6+）
- Web Speech API（浏览器内置语音合成）
- Web Audio API（备用音频合成）
- localStorage（声音库持久化存储）
- 纯前端，零依赖，无需后端服务器

## 打开方式

### 方式一：直接打开（推荐）
在 Chrome 浏览器中直接双击 `index.html` 文件即可运行。

### 方式二：本地服务器
```bash
# 使用 Python 启动本地服务器
cd voice-mirror
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能说明

### 1. 声音上传
- 点击上传区域或拖拽音频文件到上传区
- 支持 WAV / MP3 格式，最大 20MB
- 上传后显示文件名和时长，可移除重选

### 2. 云端训练
- 点击"开始训练"按钮触发模拟训练
- 进度条动画展示训练过程（约 5 秒）
- 训练完成后显示绿色对勾动画
- 训练完成的声音自动保存到声音库

### 3. 语音合成
- 训练完成后，在文本框中输入文字
- 点击"合成语音"按钮，使用浏览器内置语音引擎朗读
- 支持 500 字以内的文字输入
- 播放时显示音频可视化动画

### 4. 声音库
- 展示所有已训练的声音列表
- 预置一个 Demo 演示声音，可直接使用
- 点击声音条目可切换当前使用的声音
- 数据通过 localStorage 持久化存储

## 浏览器兼容性

- Chrome 90+（推荐）
- Edge 90+
- Safari 15+
- Firefox 90+

> 语音合成功能依赖 Web Speech API，建议使用 Chrome 浏览器以获得最佳体验。

## 注意事项

- 本项目为纯前端应用，所有"训练"过程均为模拟演示
- 语音合成使用浏览器内置的 TTS 引擎，效果因浏览器和操作系统而异
- 声音库数据存储在浏览器 localStorage 中，清除浏览器数据会丢失记录
- 无需网络连接即可使用（首次加载后）
