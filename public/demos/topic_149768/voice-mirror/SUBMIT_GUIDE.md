## 1. 项目结构说明

```
voice-mirror/
├── index.html          # 主页面，所有功能入口
├── style.css           # 深色科技感样式，蓝紫渐变主题
├── script.js           # 核心逻辑：上传、训练模拟、语音合成、声音库管理
├── README.md           # 项目说明文档
└── SUBMIT_GUIDE.md     # 提交指南（本文件）
```

- **index.html**：单页应用入口，包含四个功能区域（上传、训练、合成、声音库）的 HTML 结构
- **style.css**：独立样式文件，实现深色科技感背景、蓝紫渐变、玻璃拟态卡片、动画效果
- **script.js**：独立逻辑文件，包含文件上传（拖拽+点击）、模拟训练进度条、Web Speech API 语音合成、localStorage 声音库管理

## 2. 如何本地打开运行

### 最简单方式（推荐）
直接在 Chrome 浏览器中**双击 `index.html`** 文件即可打开运行。

> 无需安装任何依赖，无需启动服务器，无需联网。

### 验证步骤
1. 双击 `index.html`，浏览器自动打开页面
2. 确认页面显示"声临其境"标题和四个功能卡片
3. 确认声音库中已有"Demo 演示声音"条目
4. 直接在文本框中输入文字，点击"合成语音"测试语音合成

## 3. 功能使用步骤

### 完整操作流程

**第一步：上传声音**
1. 点击"声音上传"卡片中的上传区域
2. 选择一个 WAV 或 MP3 音频文件（或拖拽文件到上传区）
3. 确认文件信息（文件名、时长）显示正确

**第二步：训练声音**
1. 点击"开始训练"按钮
2. 观察进度条动画（约 5 秒模拟训练过程）
3. 训练完成后显示"训练完成！"对勾动画
4. 声音自动保存到"声音库"中

**第三步：合成语音**
1. 在"语音合成"卡片的文本框中输入文字
2. 点击"合成语音"按钮
3. 浏览器将使用内置语音引擎朗读输入的文字
4. 播放时显示音频可视化动画

**提示**：也可以直接使用预置的"Demo 演示声音"，跳过上传和训练，直接进入合成步骤。
