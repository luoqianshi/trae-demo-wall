# AI 速读助手 📖

> 一款纯前端 + Python 后端的智能文本分析工具，粘贴文本即可一键获取关键词、摘要、金句、阅读分析和思维导图，帮你快速吃透任何一篇文章。

## ✨ 功能特性

| 模块 | 说明 |
|------|------|
| 🔑 **关键词提取** | 基于 TF-IDF 算法，自动提取文本核心关键词并归一化权重 |
| 📝 **摘要生成** | 基于句子重要度评分（词频覆盖 + 位置加权 + 长度加权），提取核心摘要 |
| 💎 **金句提炼** | 自动识别修辞特征（对比、排比、递进等），筛选最有冲击力的短句 |
| 📊 **阅读分析** | 字数统计、预估阅读时间、句子长度分布、信息密度评分 |
| 🧠 **思维导图** | 基于关键词共现聚类，自动生成层级结构数据，可视化展示文本脉络 |
| 😊 **情感分析** | 内置中文情感词典 + 否定词反转 + 程度副词加权，判断文本情感倾向 |
| 🌡️ **段落热力图** | 逐段计算信息密度并转换为 0-100 分，直观展示各段落"干货"浓度 |

## 🛠 技术栈

- **后端**: Python 3.12 + Flask 3.x
- **中文分词**: jieba 0.42
- **前端**: 纯 HTML / CSS / JavaScript（无框架依赖）
- **跨域**: flask-cors

> 核心卖点：**零外部 AI API 依赖**，所有分析算法均为纯 Python 本地计算，离线可用。

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/your-username/AI-Speed-Reader.git
cd AI-Speed-Reader
```

### 2. 安装依赖

```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

### 3. 启动服务

**方式一：一键启动（推荐）**

双击 `start.bat` 即可自动创建虚拟环境并启动服务。

**方式二：手动启动**

```bash
python server.py
```

启动后浏览器访问 **http://localhost:5000** ，粘贴文本，点击分析即可。

## 💡 TRAE IDE 开发说明

本项目使用 **[TRAE IDE](https://trae.ai)** 进行开发，充分利用 AI 辅助编码能力：

- **算法迭代**: 通过 TRAE IDE 的 AI 对话快速迭代 TF-IDF 权重归一化、句子重要度评分等算法逻辑
- **前端调试**: 利用 AI 辅助快速定位和修复布局、样式、交互问题
- **代码审查**: 借助 TRAE 的代码分析能力发现潜在 Bug 和优化点
- **文档生成**: README 等文档也由 TRAE AI 辅助生成

TRAE IDE 的核心优势在于**对话式开发**——用自然语言描述需求，AI 直接在编辑器中生成和修改代码，极大提升了开发效率。

## 📸 效果说明

> 由于是纯前端项目，建议克隆后本地运行体验。以下是各模块的效果描述：

- **关键词模块**: 以气泡图/标签云形式展示 Top 10 关键词，气泡大小对应权重，一目了然
- **摘要模块**: 从原文中提取 3 句核心句子，保持原文顺序，快速把握全文要点
- **金句模块**: 卡片式展示 5 条最有力的短句，标注修辞特征（对比、递进、排比等）
- **阅读分析**: 柱状图展示句子长度分布，数值面板显示字数/句数/段数/阅读时间/信息密度
- **思维导图**: 可交互的树形图，展示关键词之间的语义关联和层级关系
- **情感分析**: 仪表盘式显示正/负面比例，列出触发情感词的具体词汇
- **段落热力图**: 颜色深浅直观映射每段信息密度，快速定位"干货"段落
