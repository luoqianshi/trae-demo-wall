==============================================
            ANDA FMEA 智能质量工作台 - 演示版
==============================================

一、系统简介
本演示包包含 ANDA FMEA 系统的完整前端界面，使用 Mock Service Worker (MSW)
模拟后端API响应，无需部署后端服务器或数据库即可体验完整功能。

二、使用方法（仅需一步）

1. 解压本压缩包到任意目录
2. 双击运行 start.bat 文件
3. 浏览器将自动打开 http://localhost:3003

三、登录信息
用户名：admin （任意用户名均可登录）
密码：任意输入

四、功能模块
- APQP项目管理：5个阶段的项目进度跟踪与检查清单
- DFMEA设计失效模式与影响分析
- PFMEA过程失效模式与影响分析
- 控制计划管理：试生产控制计划、生产控制计划
- SPC统计过程控制：控制图、过程能力分析
- 8D报告管理：完整的8D问题解决流程
- 知识库管理：质量知识文档管理
- 流程图绘制：过程流程图编辑

五、注意事项
- 演示数据为模拟数据，刷新页面后会重置
- 部分功能（如文件上传、图片预览）可能无法完全模拟
- 建议使用 Chrome、Edge 或 Firefox 浏览器
- 关闭浏览器后，按 Ctrl+C 停止服务器窗口

六、技术支持
如有问题，请联系开发团队。
