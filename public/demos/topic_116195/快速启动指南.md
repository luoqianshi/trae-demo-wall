# AI代码导师 - 快速启动指南

## 项目简介

基于大语言模型的学生代码自动诊断与过程型可视化反馈平台。集成在线代码编辑器、安全执行环境、自动评测系统、AI智能诊断和过程型可视化反馈，专为中学Python编程教学场景设计，支持完全离线部署。

---

## 环境准备

### 1. 安装 Python 3.8+

下载地址：https://www.python.org/downloads/

验证安装：
```bash
python --version
```
> 需要 Python 3.8 及以上版本

### 2. 安装 Redis（缓存与消息队列）

- **Windows**：下载 Redis for Windows，安装后默认运行在 `localhost:6379`
- **Mac**：`brew install redis && brew services start redis`
- **Linux**：`sudo apt install redis-server && sudo systemctl start redis`

验证安装：
```bash
redis-cli ping
```
> 应返回 `PONG`

### 3. 安装 Ollama（本地LLM，可选但推荐）

下载地址：https://ollama.com/download

安装后拉取模型：
```bash
ollama pull qwen2.5-coder:7b
```

验证安装：
```bash
ollama list
```
> 应看到 `qwen2.5-coder:7b`

> **说明**：如果不安装 Ollama，平台仍可运行，但 AI 诊断功能会自动降级为规则模板诊断（覆盖11种常见错误类型）。代码执行、自动评测、可视化反馈等功能不受影响。

## 安装步骤

### 第1步：创建虚拟环境

```bash
# 进入项目根目录
cd AI_Code_Mentor

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```

### 第2步：安装依赖

```bash
pip install -r requirements.txt
```

### 第3步：配置环境变量

复制示例配置文件：
```bash
# Windows:
copy .env.example .env
# Mac/Linux:
cp .env.example .env
```

默认配置即可用于开发环境，无需修改。如需自定义：
- `SECRET_KEY`：生产环境务必修改
- `DEBUG`：生产环境设为 `False`
- `OLLAMA_BASE_URL`：Ollama 服务地址（默认 `http://localhost:11434`）
- `OLLAMA_MODEL`：模型名称（默认 `qwen2.5-coder:7b`）
- `REDIS_HOST` / `REDIS_PORT`：Redis 地址和端口

### 第4步：初始化数据库

```bash
# 生成数据库表结构
python manage.py migrate
```

### 第5步：创建测试数据

```bash
# 创建测试用户（1名教师 + 1名学生）
python manage.py create_test_users

# 创建样例题目（3道Python编程题）
python manage.py create_sample_data
```

测试账号：
| 角色 | 用户名 | 密码 |
|------|--------|------|
| 学生 | student001 | student123 |
| 教师 | teacher001 | teacher123 |

### 第6步：启动开发服务器

```bash
python manage.py runserver
```

### 第7步：访问平台

打开浏览器访问：**http://localhost:8000**

## 核心功能体验流程

1. 用学生账号登录
2. 进入题目列表，选择一道题目
3. 在代码编辑器中编写Python代码
4. 点击「运行代码」在浏览器端（Pyodide）快速测试
5. 点击「提交」进行完整评测（后端沙箱执行）
6. 在结果反馈页查看：通过率、过程时间线、错误详情
7. 点击「AI诊断」获取智能诊断建议（需启动Ollama）
8. 用教师账号登录查看班级统计数据和错误洞察

## 可选：启动 Celery 异步任务（支持异步AI诊断）

新开一个终端窗口：

```bash
# 激活虚拟环境
venv\Scripts\activate

# 启动 Celery Worker
celery -A config worker --loglevel=info
```

> **说明**：不启动 Celery 时，AI 诊断使用同步模式（等待约10-30秒）。启动后可使用异步诊断模式。

## 常见问题

### Q: 启动时报错 ModuleNotFoundError
确保已激活虚拟环境并安装依赖：`pip install -r requirements.txt`

### Q: AI诊断一直返回模板结果
检查 Ollama 是否已启动：`ollama list`，确认 `qwen2.5-coder:7b` 模型已拉取

### Q: Redis连接失败
检查 Redis 服务是否运行：`redis-cli ping`，应返回 `PONG`

### Q: 提交代码后页面一直转圈
可能是后端沙箱执行超时（默认5秒），检查代码是否有死循环

### Q: Windows下中文乱码
确保终端编码为UTF-8，PowerShell中执行：`chcp 65001`
