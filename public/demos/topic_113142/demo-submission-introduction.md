# 食刻搭子 Demo 设计介绍

## 1. Demo 简介

### 是什么

「食刻搭子」是一款面向大学生和独居青年的智能饮食决策小程序原型，通过定位、食材管理、预算分析和推荐算法，帮助用户更快决定“今天吃什么”。

### 面向谁

核心用户是大学生、独居青年和刚开始独立生活的人。他们经常在宿舍、出租屋、校园周边、下课后、下班后或月底预算紧张时使用这个产品。

### 主要功能

1. 智能饮食推荐  
   系统根据用户当前位置、预算、已有食材和当前场景，推荐“自己做、点外卖、吃食堂、混合搭配”等方案。

2. 附近商家与食堂识别  
   用户进入“附近”页面后，可以看到周边外卖商家、校园食堂窗口、价格、距离和配送时间，并支持按“500m 内、1km 内、1.5km 内、3km 内”距离范围，以及“20 元内、轻食、30 分钟内、可到店”等条件筛选。

3. 食材管理与后端推荐逻辑  
   用户可以添加已有食材和保质期，系统会优先推荐快过期食材的使用方案，并通过后端设计中的用户服务、食材服务、商家服务和推荐服务支撑整个推荐流程。

4. 随机选择吃什么  
   当用户不想继续纠结时，可以点击“随机帮我选”，系统会先播放快速轮换的抽取动画，再从自制、外卖、食堂和混合搭配中随机给出一个饮食建议，并同步说明推荐理由。

5. 室友投票与偏好调整  
   用户可以在“帮我选”页面参与室友投票，且每人只能投一次；也可以在“我的”页面更改省钱、减少浪费、清淡饮食等偏好开关，偏好变化后首页推荐和推荐理由会同步变化。

## 2. Demo 创作思路

### 灵感来源

这个创意来自大学生和独居青年非常常见的生活场景：每天到了饭点，都要在“点外卖、吃食堂、自己做饭、便利店随便买点”之间纠结。很多时候用户不是没有选择，而是选择太多，同时还要考虑价格、距离、配送时间、健康程度和自己冰箱里有没有快过期的食材。

### 想解决的问题

当前用户主要有三个痛点：

1. 吃什么很难决定  
   外卖平台和食堂窗口选择很多，但用户很难快速判断哪个选择最适合当下。

2. 预算和健康难兼顾  
   大学生和独居青年常常想省钱，但长期吃低价外卖又容易营养不均衡。

3. 食材容易被浪费  
   独居生活中买菜经常买多，冰箱里有食材却忘记吃，最后过期浪费。

### 为什么做这个方向

我没有把产品做成单纯的外卖推荐工具，而是选择“食材管理 + 定位商家 + 饮食推荐”的方向。这样可以同时覆盖大学生和独居青年的真实生活：有时适合点外卖，有时适合吃食堂，有时适合用已有食材简单做一顿，有时适合“家里主食 + 外卖荤菜”的混合搭配。

这个方向的优势是更贴近生活，也更容易体现创意价值。它不是简单地告诉用户附近有什么，而是进一步判断“现在什么最适合你”。

## 4. TRAE 实践过程

### 开发流程

1. 创意构思  
   先通过 TRAE 梳理作品方向，确定产品名称为「食刻搭子」，并明确核心用户为大学生和独居青年。

2. 创意方案完善  
   在原有“食材管理”创意基础上，加入定位能力、附近外卖商家识别、校园食堂、预算控制和独居生活场景，使产品更符合年轻用户真实需求。

3. HTML 原型生成  
   使用 TRAE 生成交互式 HTML 原型，包含手机端界面、底部导航、首页推荐、附近商家、食材管理、方案对比和我的页面。

4. 交互增强  
   继续用 TRAE 增加场景模式切换、商家筛选、商家详情弹窗、添加食材表单、拼单投票、本周饮食观察等交互。

5. 后端设计补充  
   在原型基础上补充后端设计，包括用户服务、食材服务、定位服务、商家服务、推荐服务、记录服务和拼单服务，让作品不仅有前端界面，也有完整的系统设计思路。

## 总结

「食刻搭子」通过交互式 HTML 原型展示了一个面向大学生和独居青年的饮食决策产品。它结合定位、外卖商家、校园食堂、食材管理、预算控制和后端推荐逻辑，帮助用户在真实生活场景中更快、更省钱、更合理地决定一餐吃什么。
