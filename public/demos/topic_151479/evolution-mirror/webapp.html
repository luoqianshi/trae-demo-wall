Docker 部署指引（FunASR 本地模型）
如何启动 FunASR 服务 
docker run -d -p 10095:10095 \
  registry.cn-hangzhou.aliyuncs.com/funasr_repo/funasr:funasr-runtime-sdk-online-cpu-0.1.12

启动后 FunASR 在 10095 端口提供服务。确保 Docker 已安装并正在运行，执行上述命令后将自动下载并启动 FunASR 容器。首次启动可能需要一些时间下载镜像。
