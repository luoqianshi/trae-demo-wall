📌 基本流程

1. 上传 CSV/Excel 文件，或直接粘贴 Excel 数据

2. 选择「文件名字段」「经度字段」「纬度字段」

3. 选择内容类型（地图导航 / 网址 / WiFi / 名片等）

4. 调整样式 → 刷新预览 → 开始生成

5. 在「导出」中选择 ZIP打包 / PDF合集 / HTML索引页 / 打印

✏️ 自定义文字组合

在「文字设置→文字内容」框中，用 {字段名} 引用CSV中的任意列。

  • 单行示例: {社区名称}
  • 多行组合: {社区名称} 换行 地址: {地址}
  • 混合固定文字: 【{社区名称}】 换行 联系人: {负责人}

🗺️ 坐标说明

CSV中的坐标可在「坐标系」中选择 WGS84/GCJ-02/BD-09，程序自动转换为所选地图适配的坐标系。

  • WGS84: GPS原始坐标
  • GCJ-02: 火星坐标系（高德/腾讯）
  • BD-09: 百度坐标系

🎨 样式技巧

  • 圆点模块 + 径向渐变 = 科技感
  • 圆角模块 + 浅色背景 = 简约风
  • 添加Logo + 阴影 + 边框 = 品牌宣传
  • 容错率选 H(30%) 可容纳更大Logo
  • 点击「推荐」按钮自动推荐最佳容错率

📦 导出选项

  • ZIP打包: 所有二维码+生成报告打包下载
  • PDF合集: 每页一个二维码+名称，适合打印张贴
  • HTML索引页: 带表格的网页，在线扫码
  • 打印: 打印优化样式，A4贴标

⚡ 高级功能

  • 名称前缀/后缀: 批量添加统一前后缀
  • 自动编号: 序号+名称组合
  • 批量查找替换: 对名称列操作
  • 动态配色: 按字段值自动分配颜色
  • jsQR校验: 生成后自动验证可扫性
  • 配置自动保存: 刷新页面不丢失设置

关于

批量二维码生成器

powered by trae

功能：读取CSV/Excel表格，将WGS84坐标转换为GCJ-02，生成以name命名的二维码图片。支持自定义样式、颜色、字体、Logo、阴影等效果。

支持地图导航、网址链接、WiFi共享、名片vCard、邮件、短信、电话等多种内容类型。

技术栈：HTML5 + Canvas + qr-code-styling + PapaParse + SheetJS + JSZip + jsPDF + jsQR

所有数据在浏览器本地处理，不上传服务器。
