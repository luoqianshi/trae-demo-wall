# 安陵导览参赛推进说明

## 项目定位

项目名称：安陵导览：AI 陵园导航与祭扫辅助系统

一句话介绍：帮助扫墓家属快速、体面、安心地找到亲人的安息位置。

目标用户：扫墓家属、老人、外地亲属、陵园工作人员、陵园管理方。

## 第一版 Demo 已包含

1. 项目首页：说明真实痛点、产品定位和核心能力。
2. 智能寻墓：支持通过姓名、墓区、自然语言描述匹配墓位。
3. 园区导航：展示虚拟陵园地图、路线节点和步骤说明。
4. 语音式指引：浏览器支持时可播放中文路线提示。
5. AI 助手：模拟问路、鲜花点、停车场、老人友好路线等对话。
6. 园区后台：模拟录入墓位数据，展示陵园管理方如何维护系统。
7. 参赛说明：内置 3 分钟演示脚本和提交建议。

## 3 分钟演示顺序

1. 打开项目首页，说明问题：清明、冬至、忌日祭扫时，很多人很难在大型陵园里找到亲人墓位。
2. 进入智能寻墓，输入“我想找陈明远，松柏园三区”，展示 AI 如何识别姓名和墓区线索。
3. 进入园区导航，展示从东门到松柏园三区 B 排 18 号的路线。
4. 点击“播放语音指引”，说明老人和外地亲属不用看复杂地图也能跟着走。
5. 进入 AI 助手，提问“老人腿脚不方便怎么走”或“最近的鲜花点在哪”。
6. 进入园区后台，说明陵园管理方可维护墓位、道路和服务设施数据。
7. 最后讲落地：先服务单个陵园，再扩展到陵园集团、殡葬服务机构和民政公共服务场景。

## 下一步完善优先级

高优先级：

1. 把虚拟陵园地图做得更像真实导览图。
2. 增加“上传纸质园区图，AI 辅助识别区域”的演示入口。
3. 增加“隐私保护和家属授权查询”的说明页面。
4. 准备 1 分钟、3 分钟、5 分钟三个版本的讲解稿。

中优先级：

1. 增加移动端小程序样式页面。
2. 增加更多墓区、服务点、路线数据。
3. 增加“老人少台阶路线”和“最短路线”的对比。
4. 增加一页商业落地路径。

低优先级：

1. 接入真实地图服务。
2. 增加账号登录。
3. 增加真实数据库。
4. 增加后台权限管理。

## 需要你准备的素材

1. 你发现这个痛点的真实经历，用 100 到 200 字写出来。
2. 你希望项目名字是否保留“安陵导览”，或者换成更温和的名字。
3. 你打算报名时选择的赛道名称。
4. 如果比赛要求视频，准备一段 3 分钟以内的屏幕录制。

## 注意事项

1. 参赛 Demo 不使用真实逝者姓名和真实墓位，避免隐私风险。
2. 对外表达要庄重、克制，不要使用“找坟”等不体面的说法。
3. 重点强调“帮助家属减少焦虑、帮助陵园提升服务效率”。
4. 如果官方报名规则有具体格式，以官方规则为准。
