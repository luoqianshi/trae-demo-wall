    使用说明

    随手语音记账助手 · 完整指南

    功能概览

    这是一个完全在浏览器本地运行的记账工具。所有数据只保存在你的设备上，不会上传任何服务器。支持语音记账、手动录入、预算管理、固定支出、账单筛选、批量操作、自定义标签、CSV 导入/导出、JSON 备份/恢复、数据健康检查、深色模式等功能。

    语音记账

    • 在文本框输入文字，或点击麦克风按钮开始语音输入
    • 点击「智能识别」自动解析金额、类目、日期和备注
    • 支持一句话包含多笔消费，例如「早餐十元，肯德基三十五元，打车二十八块」
    • 识别后可以手动修改类目、日期、标签后再保存
    • 系统会记住你改过的类目，下次同样关键词自动归对

    预算管理

    • 在「本月预算」卡片设置每月总预算
    • 支持为每个类目设置单项预算（餐饮、交通、购物等）
    • 预算条实时显示支出进度和剩余金额
    • 超预算时会有提示

    固定支出

    • 管理每月固定支出，如房租、会员、水电、话费等
    • 新增固定支出时填写名称、金额、类目、标签、每月日期
    • 每个固定支出支持「生成本月账单」
    • 支持「一键生成本月未生成」，自动跳过已生成项目
    • 同一个固定支出每月只能生成一次，避免重复入账
    • 删除固定支出不会影响已生成的账单

    数据洞察

    • 月报总结：自动概括本月消费情况、日均、最大单笔等
    • 类目占比：饼图展示各消费类目分布
    • 7天趋势：近七日每日支出柱图
    • 标签统计：按标签汇总消费并给出控制建议
    • 点击洞察中的类目或标签可跳转筛选对应账单

    账单筛选

    • 支持按时间段（今天 / 本月 / 全部）筛选
    • 支持按类目、标签筛选
    • 支持关键词搜索备注、类目、标签、金额
    • 一键重置筛选，恢复全部账单
    • 筛选结果自动分页，每页 20 条

    批量操作

    • 点击「批量模式」进入批量操作状态
    • 每条账单左侧出现复选框
    • 支持「选择当前筛选」一键全选
    • 支持批量修改类目、标签
    • 支持批量删除，可撤销
    • 再次点击「批量模式」退出

    自定义标签

    • 默认提供：普通支出、必要支出、可减少、冲动消费、可报销、固定支出
    • 可在「智能设置」中新增自定义标签
    • 支持从常用标签建议中一键添加
    • 自定义标签会自动同步到记账、筛选、批量修改和统计
    • 默认标签不可删除，自定义标签可删除

    数据导入 / 导出

    • 导出表格：当前筛选结果导出为 CSV，可用 Excel 打开
    • 导入表格：支持导入 CSV 文件，导入前会预览数据和检测重复
    • 备份数据：导出全部账单为 JSON 文件，包含固定支出、预算和自定义标签
    • 恢复数据：从 JSON 备份文件恢复全部数据
    • 建议定期备份数据，防止误删或设备更换导致丢失

    数据健康检查

    • 扫描全部账单，找出疑似重复、金额异常、备注为空、未来日期等问题
    • 每条问题支持一键跳转查看、删除重复、修正日期
    • 未使用的自定义标签也会被列出，可一键清理
    • 录入新账单时自动检测疑似重复并提示

    外观设置

    • 支持跟随系统（自动根据手机深浅色切换）
    • 支持手动切换浅色或深色模式
    • 选择后自动记住你的偏好

    安装到手机 / 电脑

    Android Chrome 浏览器
    1. 用 Chrome 打开此页面
    2. 页面底部会弹出「添加到主屏幕」的提示，点击安装
    3. 如未弹出，点击右上角 ··· 菜单
    4. 选择「添加到主屏幕」或「安装应用」
    5. 桌面出现「语音记账」图标，以后直接点击打开
    iPhone Safari 浏览器
    1. 用 Safari 打开此页面
    2. 点击底部分享按钮（方框 + 向上箭头）
    3. 向下滑动找到添加到主屏幕
    4. 可选修改名称，默认显示「语音记账」
    5. 点击右上角添加，桌面出现图标
    电脑 Chrome / Edge
    1. 用 Chrome 或 Edge 打开此页面
    2. 地址栏右侧出现安装图标（+ 号或电脑图标）
    3. 点击后确认安装
    4. 安装后以独立窗口打开，支持离线使用

    安装后首次打开会自动缓存，之后即使无网络也能正常使用。所有记账数据保存在本地，无需联网。

    隐私说明

    所有账单数据、分类记忆、预算和标签都只保存在你当前浏览器的本地存储（localStorage）中，不会上传到任何服务器。清理浏览器缓存或更换设备后数据会丢失，建议定期使用「备份数据」功能导出 JSON 文件保存。
