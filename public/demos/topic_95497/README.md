# 城市说明书修复局 Demo

《城市说明书修复局》是一个社会服务赛道的可交互 HTML Demo。

它把难懂的公共通知、办事流程、医院指引、学校公告、社区说明，修复成普通人能照着做的说明书。

## 如何体验

1. 解压 Zip。
2. 双击 `index.html`。
3. 粘贴一段难懂通知，或点击示例按钮。
4. 选择读者模式：普通人版、老人版、外地人版、学生版、发布者版。
5. 点击“生成城市说明书”。

## 核心功能

- 生成行动步骤：告诉用户现在要做什么、去哪、带什么。
- 标出风险：指出原文里的模糊词、缺失信息和可能误解。
- 生成追问话术：用户可以直接拿去问窗口、物业、老师或工作人员。
- 生成修复后通知：帮助发布者把通知写得更清楚。

## 提交社区

社区作品帖可以使用 `Demo作品帖.md` 作为基础文案。

上传体验文件时，请上传打包后的 Zip 文件。评审解压后打开 `index.html` 即可体验。

## 注意事项

作品帖中还需要你补充：

- 不少于 3 张 TRAE 开发关键步骤截图。
- 不少于 3 个关键任务对话的 Session ID。
- 已通过审核的报名帖链接。
