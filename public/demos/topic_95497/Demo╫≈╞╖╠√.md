## 1. Demo 简介

这是一个可交互体验的 HTML 网站 Demo，名字叫《城市说明书修复局》。它面向看不懂公共通知、办事流程、医院指引、学校公告、社区说明的普通用户，也面向需要发布通知的社区、学校、医院、物业和政务服务人员。

主要功能有 3 个：

- 难懂通知翻译：把一段公共通知转成“我现在要做什么、要带什么、去哪办、什么时候截止、看不懂该问谁”。
- 人群模式切换：支持普通人版、老人版、外地人版、学生版、发布者版。
- 可读性修复报告：指出原文哪里容易误解，并生成更清楚的通知版本。

## 2. Demo 创作思路

灵感来自日常生活里经常看到的公共通知：很多内容每个字都认识，但读完仍然不知道自己到底该做什么。比如“请相关人员携带有效证件于规定时间内完成核验，逾期将影响后续办理”，用户会困惑自己是不是相关人员、要带什么、去哪里、错过后会怎样。

我想解决的问题是公共信息的可读性。很多通知并不是缺少信息，而是没有把信息组织成普通人能照着做的步骤。这个 Demo 的取舍是先不做“大而全的城市服务平台”，而是聚焦一个很具体的体验：把难懂公共信息修复成一份能执行的说明书。

选择这个方向，是因为它既有社会服务价值，也适合做成可体验 Demo。评审打开 HTML 后，只要输入一段通知，就能马上看到“原文”和“修复后”的差异。
