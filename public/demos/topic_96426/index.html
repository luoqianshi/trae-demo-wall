// CORE FEATURES

四大核心功能

[照]

照片转剪纸

上传任意照片（宠物、风景、人物），AI 自动提取主体轮廓，转化为剪纸艺术风格的黑白/红白底稿。支持自定义细节精细度，从极简剪影到精致纹样均可生成。

[折]

折叠方法图解

根据图案对称性自动推荐最佳折叠方式（对折/四折/六折/八折），提供 3D 折叠步骤动画。蓝色虚线标注折叠位置，确保每次折叠都精准无误。

[剪]

剪切路线标注

红色实线标注剪切线，红色填充标注保留区域。AI 自动规划最优剪切顺序（从内到外、从细到粗），附带分步教程，新手也能一次成功。

[级]

难度分级系统

每个底稿自动标注难度等级（1-5 星），根据图案复杂度、细节数量和剪切难度综合评估。支持按难度筛选，从幼儿入门到大师挑战都有合适的方案。
