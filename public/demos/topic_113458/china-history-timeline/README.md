# 中国历史学习网站

这是一个多页面静态网站，`index.html` 是单独的网站首页，只负责进入三个功能网页。

## 页面结构

- `index.html`：单独网站首页，包含三个网页入口。
- `timeline.html`：历史时间线网页，展示 125 个历史事件。
- `balance.html`：独立的利弊评析系统。
- `roleplay.html`：独立的历史人物选择系统。
- `people.html`：独立的历史人物搜索网页。
- `wars.html`：独立的战争盘点网页，展示交战双方及双方影响。
- `china-history-timeline.html`：旧版单页备份。

## 功能

- 首页单独展示五个网页入口
- 点击历史事件标题展开事件
- 史家解读
- 利弊简析与独立利弊评析网页
- 独立历史人物选择网页
- 独立人物搜索网页，扩充到 1000 名以上历史人物
- 独立战争盘点网页，展示双方影响
- 历史事件保留为 125 个精选事件
- 做完选择后显示后果和分析
- 搜索、时代筛选、全部展开、全部收起

## 使用

本地查看时，打开 `index.html` 即可。部署时，将整个文件夹上传到 GitHub Pages、Netlify、Vercel 或任意静态服务器。
