# ICM 智能合规监控系统 - TRAE 创造者初赛 Demo

## 项目简介

**ICM（Intelligent Compliance Monitoring）** 是一款面向金融机构的智能合规监控系统，通过 AI 技术自动跟踪监管政策动态、解析政策条款、匹配业务合规要求，并生成整改建议与行动计划。

### 核心能力

1. **政策动态监控** - 自动获取央行、银保监会、外汇局、证监会等官方渠道政策动态
2. **AI 智能解读** - 基于 DeepSeek 大模型拆解政策条款，生成结构化解读
3. **合规影响评估** - 自动匹配业务条线，生成合规差距分析报告
4. **整改任务管理** - 自动生成整改建议与行动计划，支持任务推送与跟踪
5. **知识图谱关联** - 构建政策-业务知识图谱，可视化展示关联关系

## 技术栈

### 后端
- Java 1.8 + Spring Boot 2.3.12
- Spring Data JPA + MySQL 8.0
- Spring Security + JWT 认证
- Jsoup 网页爬虫
- DeepSeek AI API

### 前端
- Vue 3.4（Composition API）
- Element Plus 2.5
- ECharts 5.5
- Axios + Vue Router

本 Demo 展示了系统的 8 个核心功能模块：

## 使用说明

### 快速体验

1. 直接在浏览器中打开 `icm-demo.html` 文件
2. 点击左侧菜单切换不同功能模块
3. 所有数据均为模拟数据，用于展示系统交互效果

### 注意事项

- Demo 为纯前端实现，使用 ECharts CDN 进行图表渲染
- 需要联网以加载 ECharts 库（约 1MB）
- 最佳浏览器：Chrome、Edge、Firefox 最新版本
- 支持响应式设计，适配不同屏幕尺寸
