## 项目简介

知学是你的私人 AI 教师。它解决的核心问题是：**没有老师懂你**——你报过班、下过书、列过计划，但没有一个老师真的懂你学到哪、哪里不会。

知学通过知识库存储你的学习知识和个人学习情况，让 AI 记住你的学习状态和能力，为你定制学习计划，让你高效学习。

### 核心能力

- **能教学**：/teach 九步高效教学（前测诊断→ZPD定位→适配讲解→示范→检索练习→即时反馈→费曼复述→知识连接→元认知反思）
- **能出题**：/assess 四来源出题 + 错题四分类归因
- **能追踪**：/mastery 掌握度图谱（0-5 级 × 三维度量化）
- **能推荐**：/recommend 三因子加权推荐（ZPD 0.4 + 错题 0.4 + 使命 0.2）
- **能度量融会贯通**：五指标综合度量

### Demo 数据

本 Demo 以"复利思维"为主题，预填了完整的 16 个文件数据：

| 数据类型 | 数量 | 说明 |
|---|---|---|
| 知识点 | 6 个 | 复利公式基础 / 复利计算 / 72 法则 / 指数函数 / 投资应用 / 跨领域应用 |
| 题目 | 5 道 | ASSESS-0001~0005（选择/填空/简答/应用） |
| 错题 | 2 条 | ERR-0001 概念混淆、ERR-0002 计算错误 |
| 外部记录 | 2 条 | EXT-0001 自测 85 分、EXT-0002 作业 90 分 |
| 课程 HTML | 1 课 | 复利公式与直觉建立（Tufte 风格） |
| 速查表 HTML | 1 张 | 复利思维速查表（打印友好） |

### 九步学习闭环

1. /learn 复利思维 → 初始化工作区（15+1 文件骨架）
2. /teach 复利公式 → 九步高效教学
3. /assess 复利公式 → 出题测试 + 错题归因
4. /recommend → 三因子推荐 + 生成 TASK-QUEUE
5. /mastery → 展示掌握度图谱
6. /review → 复习调度（固定艾宾浩斯曲线：1/3/7/15/30 天）
7. /import-external → 导入外部测试成绩
8. /daily → 每日学习简报（五源聚合）
9. /plan → 生成 3 天学习计划

## 核心理念传承

本项目脱胎于 [Matt Pocock 的 /teach skill](https://github.com/matt-pocock/teach) 核心理念——**文件系统即学习状态，跨会话不依赖记忆依赖磁盘**。

在原版 9 文件模型基础上，扩展出 8 个教育专用文件，形成 15+1 文件数据模型，将"教学 skill"升级为"教育工作区"。
