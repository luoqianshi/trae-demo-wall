## 如何记录 TRAE Session ID

1. 在 TRAE 中按 `contest/game-demo/TRAE_SESSION_PROMPTS.md` 的 prompt 启动一个新 Session。
2. 完成该 Session 的任务后，从 TRAE 界面复制该 Session 的真实 Session ID。
3. 在下方对应位置填入真实 Session ID 与简要完成说明。
4. 同一 Session 不要重复记录；不同 Session 不要合并。
