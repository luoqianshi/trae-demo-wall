# 机闹工厂 - Demo 使用说明

## 方式一：直接打开（推荐）

1. 解压本 Zip 到任意文件夹
2. 双击 `index.html` 即可开始游戏

## 方式二：本地服务器打开（备选）

如果方式一无法正常显示，请用以下方法：

1. 在本文件夹内打开终端（CMD / PowerShell）
2. 运行以下命令之一：
   ```
   python -m http.server 8080
   ```
   或
   ```
   npx serve .
   ```
3. 浏览器访问 http://localhost:8080

## 游戏操作

- 点击「产线线长」或「仓库管理员」选择岗位开始游戏
- 点击机器人进行互动操作
- 处理随机触发的事件弹窗
- 应对跨角色互动对话

## 技术说明

- 纯静态 HTML/JS 应用，无后端依赖
- 支持 Chrome / Edge / Firefox 等现代浏览器
