# 合同帮帮 - AI合同分析助手

## 作品简介

**合同帮帮**是一款基于 Web 的 AI 合同分析助手，用户拍照上传合同后，AI 自动识别文字、分析合同内容，将专业法律术语翻译成大白话，并通过文字卡片和语音播报双重方式提示风险。

## 面向用户

- **老年人** - 保健品协议、理财合同防骗，大字体+语音提示
- **求职者/大学生** - 劳动合同检查，五险一金、试用期条款识别
- **农民工群体** - 运输合同、劳务合同关键条款分析
- **中小型老板** - 商业合同、合作协议风险排查

## 核心功能

### 1. 多方式合同导入
- 拍照上传合同图片
- 支持 Word / PDF / 图片 / 纯文本文件导入
- 支持复制粘贴合同文本

### 2. AI 智能风险识别
- 自动识别合同类型（劳动合同、购房合同、租房合同、运输合同、保健品协议、理财合同等10种）
- 关键条款提取（五险一金、试用期、违约金、免责条款、管辖权、退款政策等）
- 风险等级评估（高风险 / 中风险 / 低风险）

### 3. 大白话翻译 + 语音播报
- 法律专业术语翻译成通俗易懂的日常语言
- 语音播报核心风险点，适合老年人使用
- 一句话总结"这份合同对你有什么影响"

### 4. 多维度选择配置
- 身份选择：求职者、老年人、大学生、农民工、中小型老板、自定义
- 年龄选择：6个年龄段
- 地域选择：国内合同、国际合同、港澳台合同
- 角色选择：甲方、乙方、保险人、被保险人、自定义

## 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite 5
- **样式方案**：TailwindCSS 3
- **路由管理**：React Router v6
- **图标库**：Lucide React
- **语音合成**：Web Speech API

## 使用说明

1. 选择身份（求职者/老年人/大学生/农民工/中小型老板/自定义）
2. 选择合同类型（劳动合同/购房合同/租房合同/运输合同等）
3. 选择年龄段、地域、角色
4. 选择导入方式（拍照/Word/PDF/图片/粘贴文本）
5. 等待 AI 扫描和分析
6. 查看风险识别结果，可语音播报

## 声明

本工具分析结果仅供参考，不构成法律意见。如遇重大合同签署，建议咨询专业律师。
