财智毛利通 - 投资人演示Demo
================================

【最简启动方式】
双击「一键启动.bat」文件，浏览器会自动打开演示页面。
（需要电脑已安装 Python 或 Node.js，二选一即可）

【手动启动方式】
如果一键启动不成功，可以手动操作：

方法一：使用 Python
  1. 在此文件夹打开命令行（按住Shift+右键，选择"在此处打开命令窗口"）
  2. 输入：python -m http.server 8899
  3. 浏览器访问：http://localhost:8899/demo.html

方法二：使用 Node.js
  1. 安装 http-server：npm install -g http-server
  2. 在此文件夹打开命令行
  3. 输入：npx http-server -p 8899
  4. 浏览器访问：http://localhost:8899/demo.html

【注意事项】
1. 推荐使用 Chrome 或 Edge 浏览器
2. 请勿关闭启动后的命令行窗口，关闭则演示结束
3. 所有数据均为演示数据，非真实业务数据

【Demo模块说明】
1. 引导介绍  - 平台概览、市场规模、核心能力
2. 驾驶舱    - KPI卡片、收支趋势、业务占比、Top排行
3. 数据管理  - 一键读取演示、银行流水表格
4. 财务核算  - 核算明细、分类汇总树、流量毛利
5. 风控分析  - 风控KPI、收支结构、预警清单、财税审计
6. 融资概览  - 融资趋势、偿债压力改善
7. 合作伙伴  - 客户/供应商管理
8. 技术亮点  - 技术架构、算法流程、对比表

【引导模式】
进入任意页面后，点击右上角"引导模式"按钮，可开启步骤导航，
按顺序浏览各模块功能。
