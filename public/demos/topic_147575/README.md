# 藏·趣 - TRAE 创造力大赛 Demo
生活娱乐赛道 · 面向中小学生的收藏品展示与诚信交换平台

## 使用方法
下载后请保持 index.html 与 assets 文件夹在同一目录，双击 index.html 即可体验 Demo。
推荐使用 Chrome / Edge / Safari 浏览器打开。

## 体验流程
创建安全账户 → 发布藏品 → 检查风险 → 展示墙 → 发起交换 → 生成确认卡 → 家长确认 → 完成交换并互评

## 功能说明
- **上传**：4 张照片 + 物品状态 + 诚信承诺；照片少于 2 张禁止发布，2-3 张仅可发布为仅展示，满 4 张才可标记为可交换
- **展示**：三列网格，支持筛选全部/我的/同好/仅展示
- **交换**：风险雷达（地点/隐私/物品/违禁物品）+ 家长确认 + 互评
- **违禁物品检测**：物品名称、瑕疵说明、交换愿望中包含食品、药品、现金、账号、贵重物品、电子产品、学生证、日记、家庭住址、微信、QQ、手机号等关键词时，自动标为仅展示
- **数据**：localStorage 本地保存，可随时重置

## 家长端密码说明（评委请注意）
- **首次进入家长端**时需要设置 4-8 位家长密码（建议体验时设置为 `1234`）
- 进入家长端或确认交换时需要输入该密码验证身份
- 密码保存在浏览器 localStorage 中，关闭页面后不会丢失
- 如忘记密码，可通过验证弹窗底部的「忘记密码？重置演示数据」链接重置所有数据后重新设置

## 确认交换流程
家长端点击「同意交换」后，需要完成以下步骤才能最终确认：
1. 勾选「我是孩子的家长/监护人，已了解本次交换的物品信息」
2. 勾选「我已仔细阅读所有风险提示，确认物品、地点、聊天均安全」
3. 勾选「我承诺交换当天会陪同孩子前往，并当面检查物品」
4. 输入确认文字：`我已确认，同意交换`
5. 输入家长密码

全部完成后「确认同意交换」按钮才会启用。

## 照片上传规则
| 照片数量 | 发布状态 | 交换标记 |
|---------|---------|---------|
| 0-1 张  | 禁止发布 | - |
| 2-3 张  | 可发布   | 仅展示（待补充照片） |
| 4 张    | 可发布   | 可交换（无其他风险时） |
