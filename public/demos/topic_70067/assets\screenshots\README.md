# 关键步骤截图占位

请把发帖用的关键步骤截图按以下命名放到本目录：

- `01-hero.png` 首屏主视觉
- `02-role-picker.png` 角色选择 + 颜色文化卡互动
- `03-prompt-builder.png` 混元3D 提示词生成器（含一键复制）
- `04-3d-preview.png` 3D 脸谱预览旋转效果（或离线占位环）
- `05-print-params.png` 3D 打印参数卡
- `06-scenes.png` 场景 Tab 切换

建议分辨率：1440 × 900 或 1920 × 1080，PNG，单张控制在 1MB 以内。

补充建议：另截一张 TRAE 对话窗口，里面包含 Session ID，作为过程真实性佐证（命名 `99-trae-session.png`）。
