Sensei Demo 体验说明

打开方式：
1. 解压 Zip。
2. 双击 index.html，即可在本地浏览器打开。
3. 不依赖外部 CDN，不需要启动服务。

建议体验流程：
首页 → 单问题故事收集 → 羊皮纸草稿 → Sensei 批注 → 表达方向选择 → 歌词与和弦 → 预生成音乐 Demo 预览 → 练习计划 → 作品卡片。

可用快捷体验：
首页点击“体验一段完整故事”，会直接生成羊皮纸草稿元素。确认后继续。进入歌词页后，先点击“准备音乐 Demo”，再播放预生成中文歌曲示例《慢慢回家》并进入练习计划。

3 分钟体验路径：
1. 打开 index.html。
2. 点击首页的“体验一段完整故事”。
3. 在答案之书式故事页逐题回答，每题只出现一个问题；下一题会根据上一题答案变化。
4. 点击漂浮气泡，生成联想短语，并查看它们落在羊皮纸上。
5. 查看最终生成的创作动机，再进入 Sensei 批注页。
6. 选择一种表达方向，生成歌词、和弦和节奏建议。
7. 点击“准备音乐 Demo”，播放《慢慢回家》。
8. 进入练习计划，并在作品卡片页查看最终结果。

建议重点体验页面：
1. 首页
2. 答案之书故事收集页
3. Sensei 批注页
4. 歌词与音乐 Demo 预览
5. 作品卡片

已知说明：
1. 本 Demo 为纯前端规则生成，音乐 Demo 预览使用预先生成并嵌入的中文歌曲《慢慢回家》，用于展示未来接入中文音乐模型后的听感；当前页面不会实时调用音乐生成 API。
2. 作品卡片按钮用于提示用户截图保留，暂未实现图片导出。
3. 输入过程被设计成答案之书式动态收集：每题一个问题，下一题根据上一题答案生成，气泡会产生联想短语，答案与线索沉淀为羊皮纸草稿元素。
4. 当前 Demo 使用前端规则模拟 LLM 动态提问。真实产品建议接入 GPT-5.5，让 Sensei 以“会听故事的答案之书 + 克制的 AI 音乐老师”人设生成下一题、气泡短语和创作动机。

真实产品技术架构（从故事到可弹奏成品的完整链路）：
整体分为四段，前两段产出结构化文本，后两段产出可听与可练的成品。

第一段 故事收集与创作动机：
1. 接入大语言模型（建议 GPT-5.5），以 Sensei 人设进行答案之书式动态追问。
2. 每题依据上一题答案生成，输出结构化创作动机（人物、场景、未说出口的话、情绪、和弦色彩倾向）。

第二段 歌词与音乐参数：
1. 由 GPT-5.5 基于创作动机生成歌词、和弦进行、BPM、拍号与段落结构（主歌/副歌/桥段）。
2. 此段产出全部为结构化数据，作为后续成曲与曲谱生成的统一输入。

第三段 成曲试听（Suno 5.5）：
1. 真实产品使用 Suno 5.5 实时生成民谣。民谣编制简单、情绪驱动，契合 Sensei 温柔克制的私人记忆调性，出稳定听感的成功率高。
2. 将歌词、风格（中文民谣/指弹氛围）、BPM 等参数传给 Suno 5.5，返回成曲音频；当前 Demo 以预生成的《慢慢回家》替代该步骤。

第四段 吉他练习曲谱（Coding 模型）：
1. 因为和弦进行、BPM、拍号、歌词分段在第二段已确定，生成曲谱本质是确定性的格式转换与编排任务，非常适合代码模型，且结果可程序化校验。
2. 由 Coding 模型输出：和弦图指位、扫弦/分解节奏型（依据 BPM 与拍号推导）、和弦标注在歌词音节上方的歌词和弦谱。
3. 乐谱以 MusicXML / ABC / VexTab 等结构化格式输出，前端使用 VexFlow 或 OpenSheetMusicDisplay 渲染为六线谱/五线谱，使练习计划页从文字建议升级为真实可弹奏的吉他练习谱。

技术分工小结：
1. 文本与创作推理：GPT-5.5（动态提问、歌词、和弦、BPM）。
2. 成曲试听：Suno 5.5（中文民谣实时生成）。
3. 练习曲谱：Coding 模型（结构化曲谱生成 + 前端乐谱渲染）。
