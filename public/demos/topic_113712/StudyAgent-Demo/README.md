# StudyAgent - 面向大学生作业全过程的垂直 Agent

> TRAE AI 创造力大赛初赛作品

普通 Agent 负责回答问题，**StudyAgent** 负责陪大学生完成一项作业。

---

## 🚀 快速开始（三种入口）

| 入口 | 适用场景 | 依赖环境 |
|------|---------|---------|
| **[推荐] 双击 `一键离线演示.bat`** | 比赛评审、快速体验 | ❌ 无需任何环境，解压即用 |
| **双击 `一键真实模型.bat`** | 接入真实大模型测试 | ✅ 需要 Python 3.7+ |

## 核心差异

StudyAgent 的竞争力不在于底层模型，而在于围绕"大学生作业"这一垂直场景构建的三层能力：

1. **作业 Prompt 路由** —— 根据作业类型（PPT/实验报告/论文/解题/复习提纲/答辩准备）自动匹配专业 Prompt 模板，而不是把所有任务都扔给通用对话模型
2. **结构化作业工作台** —— 不同任务类型呈现不同专属 UI（PPT 16:9 幻灯片预览、实验报告分节结构、解题分步骤引导等），而非普通聊天窗口
3. **持续跟进与版本迭代** —— 围绕同一份作业记录多个版本，支持版本切换、差异对比、跟进时间线，让用户可以逐步打磨

## 一键演示完整工作流

首页右上角或主视觉区有醒目的 **"一键体验完整工作流"** 按钮。点击后会自动演示完整过程：

1. 自动填入 PPT 示例任务（"人工智能在大学生学习中的应用"，8页，5分钟）
2. 模拟上传《人工智能课程作业要求.pdf》
3. 依次展示任务识别 → Prompt 匹配 → 初稿生成状态动画
4. 生成 8 页 PPT V1（含标题、要点、配图建议、设计建议、演讲稿、答辩问题）
5. 自动滚动到结果区，等待评委主动操作
6. **提示用户点击「改成10页」快捷按钮**（保留一次主动交互，让评委感受跟进能力）
7. 用户点击后自动识别为"改成10页并补充演讲稿"组合指令，生成 V2
8. 展示版本差异对比（新增页面、页数变化、演讲稿变化等绿色/黄色标签标识）
9. 显示版本切换器，可在 V1/V2 之间自由切换
10. 展示任务统计与 Agent 跟进时间线

演示过程中所有状态变化均按真实工作流顺序依次展示，不会瞬间全部出现。

## 两种运行模式

### 一、离线演示模式（默认，推荐比赛使用）

双击 `一键离线演示.bat`，或直接双击 `index.html`。

- 页面顶部状态栏显示："离线演示模式：当前使用本地 Mock 引擎。"
- 所有 AI 响应由前端内置 Mock 引擎生成
- 根据用户输入的主题、页数、时长、要求等动态变化（非固定内容）
- **无需 Python、Node.js 或任何依赖**，评委解压即可体验
- 文件区域提示："当前静态Demo仅展示文件名，不会上传文件内容。"

### 二、本地服务模式（真实模型代理）

双击 `一键真实模型.bat`，脚本会自动：

1. 检测 Python 环境（如未安装会提示使用离线演示）
2. 检查端口占用，避免重复启动
3. 后台启动 Python 后端（使用标准库，**无需 pip install**）
4. 等待服务就绪后自动打开浏览器到 `http://127.0.0.1:8765`
5. 后端同时托管前端静态文件和 API 代理，**无 CORS 问题**

启动后页面顶部状态栏变为绿色："本地服务模式：真实模型请求由本地后端代理。"

**配置真实 API Key：**

1. 复制 `backend/config.example.json` 为 `backend/config.json`
2. 在 `config.json` 中填入你的 API Key、Provider、Base URL、Model
3. 双击 `停止服务.bat` 后重新双击 `一键真实模型.bat` 重启后端
4. 在前端「API 设置」中选择「Local Backend」模式并保存

API Key 只保存在后端本地配置文件中，不会返回给浏览器，不会写入代码仓库。

### 三、直连 Real API 模式（不推荐）

在「API 设置」中选择「直连 Real API」，浏览器直接请求模型服务。
- 可能遇到 CORS 跨域限制
- API Key 保存在浏览器 localStorage 中
- 建议仅用于本机快速测试，正式使用请走 Local Backend 模式

### 停止服务

双击 `停止服务.bat`，脚本会读取 `backend/server.pid` 精确关闭 StudyAgent 后端，不会影响其他 Python 进程。

## 核心模块

| 模块 | 说明 |
|------|------|
| WorkflowStepper | 可视化工作流进度条（提交→识别→匹配Prompt→生成初稿→跟进修改→导出） |
| PromptRouterService | 根据 taskType + 作业要求 + 文件名 + 页数 + 时长 + 课程名称 匹配 Prompt 模板 |
| PPT 工作台 | 16:9 幻灯片预览，每页包含标题、要点、配图/设计建议、演讲稿、预计时长 |
| VersionSwitcher | 版本切换器，支持 V1/V2/V3 多版本切换 |
| VersionDiffCard | 版本差异对比，用绿色"新增"、黄色"已修改"标签标注变化 |
| AgentTimeline | Agent 跟进时间线，记录创建、识别、生成、修改、保存等事件 |
| TaskStatsCard | 任务统计（识别要求数、使用模板、页数、演讲稿数、修改轮数、预计节省时间） |
| DemoGuide | 四步演示引导浮层，帮助首次使用者快速理解 |
| Local Backend | Python HTTP 后端，同源托管前端+代理API请求，避免CORS |

## 支持的作业类型

- **PPT 生成**（核心王牌场景）：课程汇报、答辩展示、主题演讲 —— 生成结构化幻灯片方案
- **实验报告**：包含实验目的、原理、步骤、数据记录、结论分析等标准章节
- **论文结构**：生成摘要、引言、文献综述、方法论、结果、讨论、参考文献框架
- **分步骤解题**：理科/工科题目，分步骤推导、思路分析、易错点提示
- **复习提纲**：按知识点整理复习要点、重点标注、练习题建议
- **答辩准备**：陈述提纲、常见提问预判、回答思路、展示建议

## 后端 API 说明

本地后端启动后提供以下接口（同源，无 CORS）：

| 路径 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 返回前端 index.html |
| `/api/health` | GET | 健康检查 |
| `/api/agent` | POST | Agent 请求代理（转发至配置的LLM） |
| `/api/test-connection` | POST | 测试LLM连接 |
| `/api/config` | GET | 获取安全配置（不含API Key） |

后端默认使用 Mock 模式（返回 `{"mode":"mock"}`），前端会使用内置 Mock 引擎处理，保证演示稳定。配置真实 API Key 后才会转发到真实LLM。

## 导出能力

- **下载 HTML 版**：可在浏览器中打开，支持打印为 PDF
- **打印 / 导出 PDF**：直接调用浏览器打印功能
- **复制演讲稿**：一键复制所有页面的演讲备注
- **复制完整文案**：复制 PPT 全部文字内容到剪贴板

## 隐私与学习诚信

- 静态 Demo 模式下仅展示文件名，不会上传任何文件内容
- Local Backend 模式下 API Key 保存在本地 `backend/config.json`，不暴露给浏览器
- 启用真实 API 后，输入内容会通过本地后端发送至所配置的模型服务
- StudyAgent 用于帮助学生理解任务、组织结构和完善表达
- **生成内容建议在理解后修改，不应直接作为最终作业提交**

## Demo 边界

当前为初赛静态 Demo，以下为 Demo 边界说明：

- Mock 引擎为规则式生成，非真实大模型推理
- 文件上传仅记录文件名，不读取文件内容
- 版本记录保存在内存中，刷新页面后清空
- 时间线为本地任务记录，非后台长期自动监控
- "预计节省整理时间"为演示估算，非真实研究结论
- 后端默认 Mock 模式，真实 LLM 调用需自行配置 API Key
