详情

StudyAgent 用于帮助学生理解任务、组织结构和完善表达。生成内容建议在理解后修改，不应直接作为最终作业提交。

API 设置

💡 使用 Local Backend： 双击项目根目录下的 一键真实模型.bat 启动本地后端（需 Python 环境）， 启动成功后浏览器会自动打开 http://127.0.0.1:8765。 API Key 在 backend/config.json 中配置，不会暴露给浏览器。
Mock 模式为默认推荐。比赛评审请使用 Mock 模式或一键离线演示，确保稳定离线体验。启用真实API后，输入内容会发送至所配置的模型服务。API Key 不要写在代码里。
