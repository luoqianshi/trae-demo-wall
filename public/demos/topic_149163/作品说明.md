# 办事通——AI 政务材料预审与办理导航助手

## 体验方式

双击 `index.html` 即可在浏览器离线运行，不需要安装软件、不需要联网、不依赖后端。

推荐体验路径：

1. 选择“深圳市”和“居住证办理”。
2. 选择个人情况，点击“AI 生成我的办理清单”。
3. 勾选部分材料，观察准备度变化。
4. 点击下一步，选择“使用模拟材料”。
5. 点击“开始智能预审”，查看风险报告。
6. 点击“生成补充清单”，体验结果交付。
7. 可尝试页面右上角“朗读”和“长辈模式”。

## Demo 边界

- 当前版本为初赛前端交互 Demo，使用示例化政务规则与模拟 OCR 结果，用于展示核心产品流程和价值。
- 页面不会上传或保存用户选择的文件。
- 预审结果仅供参考，最终要求与审核结果以当地官方部门为准。

## 核心技术设想

- 大语言模型：政策解释、意图识别与个性化问答。
- RAG 知识库：检索官方指南，管理地区、版本、生效时间和引用来源。
- OCR：识别证件、表单、日期和关键字段。
- 规则引擎：校验材料完整性、有效期和字段一致性。
- 隐私保护：最小化采集、脱敏、加密、权限审计和处理后清除。
