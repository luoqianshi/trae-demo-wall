# 快速上手（30 秒开始体验）

## 一、打开应用

双击 `参赛作品-不良数据智能统计分析平台.html`，在 Chrome / Edge / Firefox 中打开即可。
无需安装、无需联网、无需后端，所有数据在浏览器本地处理。

## 二、试用测试数据

本压缩包内置 3 份测试数据，对应平台 3 个内置模板，开箱即用：

| 测试数据文件 | 对应模板 | 数据规模 | 演示要点 |
|---|---|---|---|
| `不良分析测试数据.xlsx` | 不良分析模板 | 45 行 / 6 个月 | 帕累托效应：少数线体/型号/类型占多数 |
| `销售分析测试数据.xlsx` | 销售分析模板 | 58 行 / 6 个月 | 趋势分析：6 个月销售波动；含销售额+成本可算利润 |
| `考勤分析测试数据.xlsx` | 考勤分析模板 | 308 行 / 1 个月 | 数据概览：缺失率展示；研发部加班明显多 |

## 三、5 步体验完整流程

1. 打开 HTML → 点击"新建数据库" → 选择对应模板（如"销售分析模板"）→ 填写数据库名 → 完成
2. 点击"选择 Excel/CSV/JSON" → 上传对应的测试数据 Excel（如 `销售分析测试数据.xlsx`）
3. 列映射界面会自动识别（表头与模板一致），直接点"确认导入"
4. 进入"驾驶舱"面板，一屏查看指标卡 + 柱图 + 趋势折线 + TopN
5. 点击柱状图的柱子 → 自动钻取到明细数据；切到"AI 分析"用自然语言提问（如"每个区域的销售额是多少？"）

## 四、8 大功能面板

- 数据概览：行列数、各列统计、缺失率、TopN 分布
- 数据驾驶舱：一屏总览，含指标卡 + 主维度柱图 + 趋势折线 + TopN
- 汇总分析：单维度聚合 + 帕累托模式（80% 分界线）
- 交叉分析：行 × 列双维度透视
- 图表分析：柱/饼/折线图，支持点击钻取
- 数据预览：明细表 + 列筛选 + 全文搜索
- SQL 查询：自由编写 SQL + 快捷示例
- AI 分析：自然语言转 SQL（纯前端，离线可用）
