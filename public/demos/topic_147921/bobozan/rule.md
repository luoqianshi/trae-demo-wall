# 蓄能对决 · 游戏规则

> 一款预判、蓄力、一击必杀的回合制对战游戏

---

## 一、基础设定

| 项目     | 说明                          |
| -------- | ----------------------------- |
| 对战形式 | 双方回合制对战（人机 / 双人 / 联机） |
| 胜利条件 | 将对方 HP 降至 0              |
| 初始 HP  | 双方各 **3 HP**               |
| 初始蓄力 | 双方各 **0 蓄**               |

---

## 二、基础动作

每回合双方同时选择一个动作，根据动作等级与类型结算伤害。

| 动作     | 消耗蓄 | 等级 | 类型 | 说明           |
| -------- | ------ | ---- | ---- | -------------- |
| 蓄       | -1     | 0    | 攻防 | 获得 1 蓄力    |
| 普攻     | 1      | 1    | 攻击 | 1 级攻击       |
| 防       | 0      | 1    | 防御 | 1 级防御       |
| 二级攻击 | 3      | 2    | 攻击 | 2 级攻击       |
| 二级防御 | 1      | 2    | 防御 | 2 级防御       |

### 战斗结算规则

- **高级攻击** 打败 **低级攻防** → 低级方直接死亡（-1 HP）
- **同等级攻击对撞** → 双方同归于尽（各 -1 HP）
- **攻击 vs 防御** → 高级攻击破低级防御；同级则被挡下
- **非攻击对非攻击** → 双方按兵不动，无伤害

---

## 三、特殊技能 · 遁术

### 火遁 / 水遁

| 属性     | 说明                                   |
| -------- | -------------------------------------- |
| 消耗蓄   | 2                                      |
| 等级     | 1（特殊）                              |
| 克制关系 | 克制 1 级攻防与蓄；被 2 级攻击击破；被 2 级防御反弹 |

### 雾化效果

> 当 **火遁** 遭遇 **水遁**，水火交融产生雾气，双方各 **+1 HP**。

---

## 四、终极技能 · 风遁

| 属性     | 说明                                       |
| -------- | ------------------------------------------ |
| 消耗蓄   | 8                                          |
| 效果     | **秒杀对方**，无视一切防御与遁术           |
| 双风遁   | 双方同时使用则 **相互抵消**，无伤害        |

---

## 五、分身术 · 开花术

| 属性         | 说明                                                |
| ------------ | --------------------------------------------------- |
| 使用次数     | 一局 **仅一次**                                     |
| 使用条件     | 当前 HP **≥ 3**                                     |
| 效果         | 将自己分裂为 **两个 2 HP 的分身**                   |

### 分身死亡规则

- **风遁** 仅可秒掉 **一个** 分身
- 一个分身死亡时：
  1. **丢弃所有蓄力**（本轮新加的蓄不算）
  2. 自动切换到 **新分身** 继续战斗（新分身 2 HP）
- 当所有分身死亡，玩家彻底失败

---

## 六、动作优先级一览

```
风遁（秒杀） > 二级攻击/防御 > 火遁/水遁 > 一级攻击/防御 > 蓄
```

> **核心理念**：资源管理 + 心理博弈。蓄力越久越强，但对手也在积蓄杀机。
