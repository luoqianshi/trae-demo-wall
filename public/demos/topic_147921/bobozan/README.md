# 蓄能对决

> 预判 · 蓄力 · 一击必杀

基于经典课间博弈玩法优化而来的线上回合制策略小游戏，支持 PVE（Minimax AI）、本地双人、在线联机三种模式。

---

## 环境依赖

- **Node.js** >= 18（[下载地址](https://nodejs.org/)）
- **npm** >= 9（随 Node.js 自带）

> 轻量版（单文件 HTML）无需任何环境依赖，双击即可运行。

---

## 快速开始

### 方式一：一键启动（推荐）

双击运行 `start.bat`，脚本会自动安装依赖并启动前后端服务，浏览器访问 `http://localhost:5173/` 即可开始游戏。

### 方式二：手动启动

```bash
# 1. 安装依赖（仅首次）
npm install

# 2. 启动前端开发服务器
npm run dev

# 3. 如需联机功能，另开终端启动游戏服务器
npm run server
```

### 方式三：轻量版（单文件 HTML）

直接双击 `蓄能对决-轻量版.html`，零依赖、零安装，即开即玩。仅包含 PVE 模式，保留全部游戏规则，文件约 23 KB。

## 界面介绍

### 顶部导航栏

| 控件 | 说明 |
|------|------|
| **模式切换**（PVE / PVP / 联机） | 切换游戏模式，PVE 模式下可额外选择 AI 难度（简单 / 中等 / 困难） |
| **规则按钮**（📖） | 查看完整游戏规则弹窗 |
| **回合计数器** | 显示当前对战回合数 |
| **重置按钮**（↻） | 重新开始当前对局 |

### 对战区域

- **上方**：对手信息区（HP 血条、蓄力值、分身数、已选动作）
- **中央**：双方动作卡牌展示区（出牌阶段显示卡背，结算阶段翻面揭晓）
- **下方**：玩家信息区（HP 血条、蓄力值、分身数、技能按钮）

### 技能按钮

9 个技能按钮以 3×3 网格排列，当前回合不可用的技能会自动置灰：

| 行 | 技能 |
|----|------|
| 蓄 · 普攻 · 防 | 基础动作，低消耗 |
| 二级攻击 · 二级防御 · 火遁 | 进阶动作，中等消耗 |
| 水遁 · 风遁 · 开花术 | 特殊技能，高消耗或有限制 |

### 联机大厅

选择「联机」模式后进入大厅，可创建房间（生成 4 位房间码）或加入已有房间。双方均准备后自动开始对战，支持再来一局。

### 结算弹窗

每局结束后弹出结果面板，显示胜方、回合数，支持再来一局或返回大厅。

## 游戏模式

| 模式 | 说明 |
|------|------|
| **PVE** | 与 Minimax AI 对战，支持简单 / 中等 / 困难三档难度 |
| **PVP** | 同屏双人热座对战，双方轮流选择动作 |
| **联机** | 通过 4 位房间码在线对战，需启动 WebSocket 服务器 |

## 游戏规则

### 基础设定

- 双方初始 **3 HP**，HP 归零即败
- 每回合双方同时选择动作，结算后进入下一回合
- 高级攻击打败低级攻防，同等级攻击/防御对撞双方无伤

### 基础动作

| 动作 | 消耗 | 等级 | 说明 |
|------|------|------|------|
| 蓄 | +1 蓄 | 0 级 | 获得 1 点蓄力 |
| 普攻 | 1 蓄 | 1 级 | 基础攻击 |
| 防 | 0 | 1 级 | 基础防御 |
| 二级攻击 | 3 蓄 | 2 级 | 高级攻击，克制一级和蓄 |
| 二级防御 | 1 蓄 | 2 级 | 高级防御，克制一级攻击 |

### 特殊技能

| 技能 | 消耗 | 说明 |
|------|------|------|
| 火遁 | 2 蓄 | 克制一级攻防与蓄 |
| 水遁 | 2 蓄 | 克制一级攻防与蓄 |
| 风遁 | 8 蓄 | 秒杀对方（无视一切） |
| 开花术 | 0 | 一局一次，HP ≥ 3 时使用，分裂为两个 2 HP 分身 |

### 元素克制

- 火遁 vs 水遁 → **雾化**，双方各 +1 HP
- 火遁 vs 火遁 / 水遁 vs 水遁 → 相互抵消
- 风遁 vs 风遁 → 相互抵消

### 分身机制

- 开花术需 HP ≥ 3，一局限一次
- 分身死亡时丢弃所有蓄力，使用新分身继续战斗
- 风遁仅可秒杀一个分身
