# 硬件赛道 | Coin Kids — 多胞胎孩子好习惯培养系统

***

## 一、Demo 简介

**产品形态**：一套软硬件结合的家庭儿童习惯养成系统，包含 M5Stack CoreS3 嵌入式终端（ESP32 固件）+ Go 后端 API 服务 + React 管理前端。

**面向用户**：多子女家庭（尤其是双胞胎/多胞胎家庭）的家长和孩子。家长通过 Web 管理端配置作息、奖惩规则、查看打卡统计；孩子通过实体终端刷卡打卡、答数学题、完成睡前检测。

**核心功能**：

1. **RFID 刷卡打卡 + 数学题验证** — 孩子刷 RFID 卡后，设备自动识别身份，随机生成三位数四则运算题，需在触摸屏上正确作答方视为打卡成功，最多 5 次重试机会，有效防止代打卡。
2. **睡觉声音检测 + 智能提醒** — 在指定时间段内，设备通过内置麦克风实时监测环境声音，绘制实时声音波形图。当声音超过阈值时，自动触发蜂鸣器提醒，分两次渐进式提醒（睡前 20 分钟/10 分钟）。
3. **Web 管理端全功能管理** — 家长可通过 Web 页面管理孩子信息、配置作息计划（含模板一键生成）、设置奖惩规则（自动关联零花钱）、查看打卡统计图表（ECharts 按周/月汇总）、管理设备与 RFID 绑定、远程下发设备指令等。

## 二、Demo 创作思路

**灵感来源**：团队中有多位初为人父母的同事，经常讨论如何培养孩子的好习惯，尤其是双胞胎家庭。市面上已有的习惯养成 App 都依赖手机，孩子容易借机玩手机；而传统打卡机又太机械，缺乏趣味性和亲子互动。于是想到用 M5Stack CoreS3 这种带屏幕、触摸、RFID、麦克风的硬件终端，做一个"孩子能用、家长能管"的软硬一体系统。

**想解决的问题**：

- **手机依赖**：孩子不用接触手机，只需要刷卡 + 触摸屏答题，物理交互更专注
- **代打卡作弊**：数学题验证机制确保孩子必须亲自操作，且随机出题 + 限时作答有效防止投机
- **多子女公平管理**：每个孩子独立 RFID 卡，独立作息计划、奖惩规则、零花钱账户，家长端统一管理
- **睡前习惯养成**：通过声音检测 + 渐进式提醒，帮孩子建立按时作息的意识

**为什么做这个方向**：

- 软硬结合在教育场景中能提供比纯软件更好的体验——物理交互的仪式感是手机 App 无法替代的
- M5Stack CoreS3 生态完善（UIFlow2/MicroPython），ESP32 成本低、功耗低，适合家庭场景长期使用
- Web 管理端 + 硬件终端分离，家长可以远程管理和查看，无需接触设备

### 开发心得

1. **硬件 API 适配是最大挑战**：UIFlow2 的 API 与标准 MicroPython 有差异，显示、RFID、麦克风、摄像头的调用方式都需要对照官方文档逐项核对修复。
2. **状态机设计很关键**：ESP32 固件涉及 RFID 读卡、数学题作答、声音检测、拍照上传等多个并发任务，用非阻塞状态机 + 线程锁的方式比传统阻塞式编程稳定得多。
3. **Trae 的上下文能力大幅提升效率**：从后端 API 设计到前端页面开发，再到嵌入式固件调试，整个全栈 + 硬件项目在同一个 IDE 中完成，无需切换工具，大大降低了上下文切换成本。
