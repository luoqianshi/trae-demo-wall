# 硬件交互（MQTT）模块

## 功能描述
MQTT 通信服务，连接 ESP32 设备与后端服务器，实现 RFID 刷卡、答题结果、声音检测、照片上传等数据的实时传输。

## 技术栈
- Go MQTT 客户端（paho.mqtt.golang）
- Mosquitto/EMQX Broker

## MQTT 话题
| 方向 | 话题 | 说明 |
|------|------|------|
| 发布 | `coin-kids/device/{id}/rfid` | RFID 刷卡 UID |
| 发布 | `coin-kids/device/{id}/result` | 答题结果 |
| 发布 | `coin-kids/device/{id}/sound` | 声音检测 |
| 发布 | `coin-kids/device/{id}/enroll` | RFID 录入 |
| 发布 | `coin-kids/device/{id}/photo_meta` | 照片元数据（文件名、大小、时间戳） |
| 发布 | `coin-kids/device/{id}/photo` | 照片二进制数据（JPEG） |
| 订阅 | `coin-kids/device/{id}/child_info` | 孩子信息 |
| 订阅 | `coin-kids/device/{id}/command` | 设备指令 |
| 订阅 | `coin-kids/device/{id}/sleep-config` | 睡觉检测配置 |
| 订阅 | `coin-kids/device/{id}/error` | 错误消息 |

## HTTP API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/devices/:id/photos` | 列出设备所有照片 |
| GET | `/api/v1/devices/:id/photos/:filename` | 获取照片文件 |
