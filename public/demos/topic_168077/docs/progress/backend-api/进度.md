# 后端 API 模块

## 功能描述
基于 Go 1.21 + Gin + GORM 的 RESTful API 后端，提供孩子管理、作息管理、零花钱、奖惩、打卡、设备管理、统计、系统设置、节日主题等接口。

## 测试用例
- `internal/festival/`: 19 个测试用例（阳历/农历节日、日期范围、结构体字段）
- `internal/handler/`: 完整 API 测试
