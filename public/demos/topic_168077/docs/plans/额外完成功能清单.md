# 额外完成功能清单

> 本文件记录 coin-kids 项目中超出原始设计文档（coin-kids-post.html）范围的功能。

## 1. 核心增强功能

### 1.1 节日/生日提醒系统
- **后端**: 阳历/农历节日计算、生日 API（独立 birthday-api 服务）
- **前端组件**:
  - `FestivalBanner` — 节日横幅展示
  - `FestivalCountdown` — 下次节日倒计时
  - `BirthdayReminder` — 孩子生日提醒
- **文件**: `backend/internal/festival/`, `frontend/src/components/FestivalBanner.tsx`, `frontend/src/components/FestivalCountdown.tsx`, `frontend/src/components/BirthdayReminder.tsx`

### 1.2 管理员/孩子双角色权限系统
- **AuthContext**: 全局角色状态管理（admin/child），切换密码保护
- **路由守卫**: `ProtectedRoute` 组件限制孩子角色访问管理页面
- **页面适配**: 所有页面根据角色显示/隐藏操作按钮（CRUD 权限控制）
- **文件**: `frontend/src/context/AuthContext.tsx`, `frontend/src/App.tsx`

### 1.3 AI 自然语言输入
- 通过大模型 API 将自然语言解析为结构化数据
- 支持孩子管理、作息管理、奖惩规则三个场景
- **文件**: `frontend/src/components/AIAssistant.tsx`

### 1.4 语音输入
- 基于浏览器原生 Web Speech API（webkitSpeechRecognition）
- 集成到各页面表单输入框
- **文件**: `frontend/src/components/VoiceInput.tsx`

### 1.5 主题切换系统
- 多主题管理、自动切换、localStorage 持久化
- CSS 变量驱动的主题样式
- **文件**: `frontend/src/context/ThemeContext.tsx`, `frontend/src/themes.css`

## 2. 设备管理增强

### 2.1 设备管理（含指令下发）
- 设备 CRUD + 远程指令发送（wake/sleep/reset/enroll/calibrate）
- **文件**: `frontend/src/components/DeviceManager.tsx`, `backend/internal/handler/device.go`

### 2.2 RFID 绑定管理
- 孩子 RFID 卡绑定/解绑 CRUD
- **文件**: `frontend/src/components/RFIDBindingManager.tsx`

### 2.3 睡觉检测配置
- 睡觉时间段、提醒时间、声音阈值配置弹窗
- **文件**: `frontend/src/components/SleepConfigModal.tsx`

### 2.4 作息模板管理
- 作息模板 CRUD、从模板一键生成每日作息
- **文件**: `frontend/src/components/ScheduleTemplateManager.tsx`

## 3. 数据统计增强

### 3.1 统计看板（ECharts）
- 按周/月汇总打卡数据
- 柱状图（按时段统计）+ 饼状图（完成/未完成/跳过比例）
- 流水明细表格（含筛选/排序）
- **文件**: `frontend/src/pages/StatsPage.tsx`, `frontend/src/components/StatsChart.tsx`

## 4. 头像选择器

- 按性别过滤推荐头像（男/女/动物分类）
- **文件**: `frontend/src/components/AvatarSelector.tsx`

## 5. 测试覆盖

- **前端**: 33 个测试文件，182 个测试用例（Vitest）
- **后端 festival**: 19 个测试用例
- **后端 handler**: 完整 API 测试
- 覆盖组件渲染、交互操作、API 调用、错误处理、权限控制等场景

## 6. MQTT 与 ESP32 固件

- **MQTT 通信服务**: 支持 RFID 刷卡、答题结果上报、声音检测、指令下发
- **ESP32 统一固件**: 集成 RFID 读卡、数学题验证、睡觉检测、阈值校准、录入模式
- **文件**: `backend/internal/service/mqtt.go`, `esp32/cores3/main.py`, `esp32/common/mqtt.py`

## 7. 孩子模型扩展

- 增加 Gender（性别）、School（学校）、Class（班级）、Birthday（生日）、Avatar（头像）字段
- **文件**: `backend/internal/model/child.go`
