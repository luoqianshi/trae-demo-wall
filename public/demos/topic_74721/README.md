# 中华梗典 · Demo 体验说明

> 2026 TRAE AI 创造力大赛 · 初赛作品 · 生活娱乐赛道

## 怎么打开

直接双击 `中华梗典_Demo.html`，浏览器自动打开（推荐 Chrome / Edge / Safari）。

## 怎么玩

| 页面 | 操作 |
|---|---|
| **首页** | 看新梗榜 Top 5 → 点击进入梗详情 |
| **详情页** | 点赞 ♡ / 提交评论 / 收藏 ☆ |
| **探索** | 顶部搜索 / 12 类别 / 11 个年份时光机 / 16 个标签云 |
| **社区** | 投稿入口（Demo 提示）/ 贡献榜 / 讨论列表 |
| **我的** | 每日签到 + 积分 / 收藏 / 浏览历史 / 8 枚勋章 |

## 数据说明

- 收录 **50 条 2026 年视角下的真实中文互联网梗**（2017-2026 跨年）
- 2025-2026 真实新梗 23 条 / 长青梗 27 条
- 数据来源：国家语言资源监测中心 / 人民日报 / 主流媒体公开榜单

## 技术说明

- 单文件 HTML + 原生 CSS + 原生 JS（无任何依赖）
- 480px 移动端视口，桌面端居中显示"手机窗口"
- 数据持久化：localStorage（收藏 / 历史 / 积分 / 签到）
- 大小：~80KB / 1400 行代码

## 核心亮点

1. **新梗榜** — 2026 真新梗 Top 5 实时排行（DeepSeek / 卡牌大师 / 你说啥意思…）
2. **时间机器** — 11 个年份 tab 一键穿越 2014-2026
3. **评论互动** — 8 位用户评论池 + 输入框实时提交
4. **签到积分** — 连续签到 + 积分体系 + 8 枚勋章解锁
5. **分享卡片** — 品牌化卡片样式（红色头部 + 绿色例句 + 底部 logo）
6. **零部署** — 单文件 HTML，下载即玩，无需后端
