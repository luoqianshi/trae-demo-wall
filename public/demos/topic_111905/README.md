# 人工智能原生企业系统 UI 设计 V7

V7 是一套新建网页端设计，不覆盖 V6。它补齐官网、文档、更新日志、版本定价、0 元体验支付、诊断、报告、试点方案、专业版、企业版和平台运营后台。

## 页面清单

- `pages/index.html`：官网入口，含产品视觉图、企业语义层、任务中心运行图和三类转化入口。
- `pages/docs.html`：文档页，解释 AI 原生企业、企业语义层、任务中心和演示边界。
- `pages/changelog.html`：独立更新日志页。
- `pages/professional-pricing.html`：专业版介绍与定价。
- `pages/enterprise-pricing.html`：企业版介绍与定价。
- `pages/checkout.html`：0 元体验假支付页。
- `pages/free-diagnosis.html`：AI 转型诊断。
- `pages/report-ai-transformation.html`：AI 转型路径报告。
- `pages/pilot-plan-professional.html`：专业版试点方案。
- `pages/professional.html`：专业版工作台与只读模拟闭环。
- `pages/enterprise.html`：企业版集团治理与客服浮窗。
- `pages/platform-operations.html`：平台运营后台。

## 关键原则

- 专业版和企业版入口先进入介绍与定价页，再经 0 元体验进入产品。
- 免费诊断通过对话引导查看报告、试点方案和模拟闭环。
- 专业版仪表盘面向企业所有者和高级管理者，不展示能力总览。
- 企业版展示企业自身集团/关联租户治理，平台运营另设独立页面。
- 模拟闭环为只读静态分步引导，不执行真实动作。
