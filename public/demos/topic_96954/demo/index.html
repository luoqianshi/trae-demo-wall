系统架构 硬件交互赛道

整套系统由 PC 端后端 + 嵌入式前端组成，通过 HTTP API 通信：

Trae CN (多窗口 AI 编程) ↑↓ 协议 Trae Control Hub (Python 后端, 端口 8765) ├─ 监听窗口状态 (state_tracker) ├─ 命令总线 (command_bus) ├─ DOM 规则热更新 (dom_rules.json) └─ WebSocket 状态推送 ↑↓ HTTP REST API (/api/windows, /api/command...) RK3506 控制面板 (C + LVGL, 800×480 触摸屏) ├─ DRM/KMS 显示 + evdev 触摸 ├─ FreeType 中文字体渲染 ├─ libcurl 轮询 Hub API ├─ ALSA 语音采集 + Base64 └─ 内嵌 HTTP Server (端口 8090) 远程配置

真实运行数据（取自 status_cache/latest.json 快照）

  • jiance 窗口：dom_rules.py - jiance - Trae CN，模型 GLM-5.1，状态从 idle → running("命令运行中") → running("命令执行完毕，正在规划下一步")
  • rk3506 窗口：lv_drivers.h ↔ New lv_drivers.h - rk3506 - Trae CN，模型 gpt-5.5，状态 completed("任务完成")
  • 状态枚举：空闲 / 运行中 / 等待批准 / 中止 / 报错 / 卡住 / 完成（来自 GET /api/statuses）

技术栈

PC 后端（Trae Control Hub）

  • 语言：Python 3.13 + Cython 编译（.pyd 加速）
  • 通信：读取 Trae 窗口状态
  • 核心模块：trae_sdk / trae_manager / state_tracker / command_bus / dom_rules
  • 进程守护：launcher_guard + process_watcher 自动接管裸启动 Trae
  • HTTP API + WebSocket 推送，端口 8765

嵌入式前端（RK3506 控制面板）

  • 语言：C 语言交叉编译 (arm-buildroot-linux-gnueabihf)
  • UI 框架：LVGL v9.2（FreeType 中文字体 + DRM/KMS 显示 + evdev 触摸）
  • 网络：libcurl + cJSON，轮询 GET /api/windows
  • 音频：ALSA 采集 + WAV 封装 + Base64，POST /api/projects/{project}/voice-input
  • 调试：内嵌 HTTP Server（端口 8090）远程修改 Hub 地址
