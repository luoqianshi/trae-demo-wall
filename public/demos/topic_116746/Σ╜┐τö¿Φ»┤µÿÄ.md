## 本地运行

交付给体验者时，只需要发送 `release/EmoBridge-Demo` 文件夹的压缩包。Windows 和 macOS 解压后直接双击 `EmoBridge-Demo.html`，不需要安装任何软件，也不需要启动本地服务。

`start-demo.bat` 仅作为 Windows 开发调试的备用启动方式，不需要放进对外演示包。

也可以手动执行：

```bash
npm install
npm run dev:h5
```

## 推荐演示流程

1. 使用演示账号登录。
2. 首页输入“孩子一写作业就哭，说我们根本不懂他”，开始情绪分析。
3. 查看情绪与需求分析，进入四步话术。
4. 标记“我用了这句”，进入实战陪跑。
5. 录入孩子回应，例如“我就是不想写，你们根本不懂我”。
6. 切换孩子状态与快速/思考图标，继续录入“好吧，我愿意试试”。
7. 结束陪跑并保存记录，在记录列表打开刚生成的复盘详情。
8. 在“我的”查看成长与徽章，设置中可恢复初始演示数据或退出账号。

## 数据与隐私

- 所有演示数据保存在当前浏览器的本地存储中。
- 项目不会发起业务 API 请求，不包含小程序 AppID、DeepSeek Key 或其他服务密钥。
- “本地演示助手”使用项目内置的四步法知识库和关键词规则，仅用于产品流程展示，不作心理或医学诊断。
