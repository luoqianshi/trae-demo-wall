1. 创意名称 + 创意介绍

  • 想解决什么问题：每天到了饭点就纠结"今天吃什么"，外卖翻半天、冰箱看几遍也下不了决定，浪费时间还影响心情。
  • 灵感来源：自己和身边同事、朋友高频出现的"选择困难症"，希望有一个简单、有趣、能快速给出完整方案的小工具。
  • 产品形态：一款基于 Python + PyQt6 的桌面端随机选餐程序，支持早、中、晚三餐，午餐更可自由搭配几菜几汤几主食。

2. 目标用户及痛点

  • 面向用户：上班族、学生、家庭主妇/主夫、租房独居人群，以及所有每天为"吃什么"发愁的人。
  • 使用场景：中午不知道点什么外卖；晚上想做饭但不知道买什么菜；周末想尝试新菜式却缺乏灵感。
  • 当前痛点：没有产品时，用户往往反复打开外卖软件、刷短视频找灵感，决策成本高；即便决定做饭，也常因搭配不均衡而随便凑合。

3. 价值与意义

效率提升

点击一次按钮即可生成完整餐食方案，把决策时间从几分钟缩短到几秒。

搭配均衡

午餐可分别指定菜、汤、主食数量，帮助用户形成更合理的饮食结构。

丰富多样

收录 1300+ 道菜品，覆盖家常菜、面食、米饭、汤品、异国料理等，避免重复。

lightweight

无需联网、无需安装复杂环境，本地运行即可使用，保护隐私。

核心数据

1300+ 道菜品
3 餐别覆盖
20 最大菜品数

技术亮点

  • 使用 PyQt6 构建现代化桌面 GUI，界面美观、响应流畅。
  • 菜品库按早餐、午餐（菜/汤/主食）、晚餐分类，结构清晰。
  • 随机抽取时自动去重，避免同一餐出现重复菜名。
  • 结果区域采用可滚动文本框，即使选择大量菜品也能完整展示。
  • 提供 Windows 批处理文件（.bat），双击即可运行。
