## 1. Demo 简介

### 是什么

一款**微信小程序风格的 H5 文创工具**，用户上传自己的照片，选择梁平癞子锣鼓的经典曲牌，系统自动生成带有声纹纹样的专属文创海报，可一键保存分享至朋友圈/小红书/抖音。

### 面向谁

| 用户类型 | 典型场景 |
|---------|---------|
| **梁平本地人 / 在外游子** | 过年过节想发点有家乡味的朋友圈，用癞子锣鼓海报表达乡愁 |
| **非遗文化爱好者** | 对国潮、传统文化感兴趣，想用新颖的方式了解非遗 |
| **社交分享用户** | 单纯觉得海报好看、有文化内涵，想生成独特的内容发社交平台 |

### 主要功能

#### 功能一：声纹海报生成

上传照片 → 选择曲牌 → 生成带声纹纹样的文创海报

- 声纹纹样基于锣鼓节奏波形生成，融合传统云纹设计
- 海报包含：用户照片 + 声纹装饰 + 曲牌名称 + 文化金句 + 品牌标识
- 支持一键下载保存

#### 功能二：十八曲牌选择

提供「闹年夜」「迎亲调」「薅草歌」「冲天炮」等经典曲牌，每个曲牌配有：
- 文化背景介绍（什么场合用、有什么寓意）
- 场景标签（过年/婚礼/劳动/节日）
- 对应的声纹纹样预览

#### 功能三：非遗文化体验

在生成海报之前，用户可以先沉浸式了解梁平癞子锣鼓：
- 完整介绍页面（非遗简介、艺术特色、乐器配置、曲牌名录）
- 视听体验区（传统乐谱展示、演奏技法介绍、传承人故事）
- 权威链接跳转（中国非物质文化遗产网、重庆文旅等官方平台）

> 📎 **产品截图**：见项目文件 `index.html`（项目介绍页）、`梁平癞子锣鼓-完整版.html`（主页面）、`鼓韵声纹文创工坊.html`（文创工坊）

## 2. Demo 创作思路

### 灵感来源

这个项目的起点，是我过年回家时看到的一幕：村里的锣鼓队又在广场排练，但围观的大多是老人，年轻人都在低头刷手机。

我突然意识到，癞子锣鼓不是不够好，而是**它根本没出现在年轻人的世界里**。我们在抖音上听各种 BGM，但没人知道家乡的锣鼓声也可以很潮、很酷、很适合发朋友圈。

于是我萌生了一个想法：**能不能让锣鼓声"看得见"？** 把声音变成视觉纹样，让用户把自己的照片和非遗文化结合在一起，生成一张既有家乡情怀、又能发朋友圈的文创海报。

### 想解决的问题

| 痛点 | 具体表现 |
|------|---------|
| **非遗文化传播渠道窄** | 传统锣鼓靠线下演出传播，受限于时间地点，年轻人接触不到 |
| **文化认同感缺失** | 很多梁平年轻人不知道家乡有国家级非遗，更不了解其文化内涵 |
| **缺少数字化载体** | 非遗内容数字化程度低，没有适合社交分享的轻量化产品 |
| **情感表达匮乏** | 游子想表达对家乡的思念，缺少有文化符号的表达方式 |

### 为什么做这个方向

**做文创海报而不是做音乐 App：**

我一开始也想过做一个能播放锣鼓音乐的 App，但很快放弃了。原因是：
- 播放音乐的门槛太低，用户听完就过去了，没有留存
- 真正能让用户主动传播的，是**能代表自己身份的内容**
- 一张带有家乡文化符号的个人海报，比一段音频更有分享价值

**选择 H5 而不是原生小程序：**

- 降低使用门槛：无需下载安装，打开链接就能用
- 快速验证想法：不需要审核上架，迭代成本低
- 传播便捷：一个链接就能分享到微信群、朋友圈

**聚焦"声纹可视化"核心体验：**

我刻意没有堆砌太多功能（比如社区、评论、排行榜），而是把精力集中在：
- 如何让声纹纹样既像音乐波形，又有中国传统美学
- 如何让海报生成过程简单到"30秒出图"
- 如何让每个元素（金句、曲牌、配色）都有文化出处

**用国潮风格连接传统与现代：**

配色上选用了中国红 + 鎏金 + 深棕，既有传统节庆氛围，又符合当下流行的"新中式"审美。我希望年轻人看到这个海报时，第一反应是"好看"，第二反应是"原来这是家乡的文化"。
