# 鼓韵声纹 · 梁平癞子锣鼓文创工坊 - 产品需求文档

## 1. 产品概述

**项目名称：** 鼓韵声纹 · 梁平癞子锣鼓文创工坊

**项目简介：** 一款微信小程序风格的 H5 文创工具，用户上传照片后，系统结合国家级非遗"梁平癞子锣鼓"的声纹纹样，生成具有文化内涵的专属文创海报，可分享至社交平台。

**目标用户：**
- 核心用户：在重庆外地上学/打工的年轻人、梁平本地人
- 兴趣用户：喜欢国潮、对非遗好奇的朋友
- 泛用户：单纯觉得海报好看、想发社交平台的网友

**核心价值：**
- 为非遗传承搭建数字化桥梁
- 30秒生成有文化、有故事、有颜值的文创海报

---

## 2. 功能模块

### 2.1 页面结构

| 页面 | 功能描述 |
|------|----------|
| 首页 | 品牌展示 + 主交互入口（上传照片） |
| 曲库页 | 选择癞子锣鼓曲牌（过年、迎亲、劳动等场景） |
| 生成页 | 预览声纹海报、添加文化金句、下载/分享 |

### 2.2 核心交互流程

1. **首页** → 用户点击"制作我的声纹海报"按钮
2. **上传照片** → 支持本地上传 + 示例图片
3. **选择曲牌** → 从曲库中选择一段癞子锣鼓（每个曲牌有简介）
4. **生成预览** → 系统生成带声纹纹样的海报
5. **添加金句** → 从预设金句库选择或自定义
6. **保存分享** → 生成带二维码的最终海报

## 5. 设计规范

### 5.1 视觉风格

- **美学方向：** 新中式 + 国潮风格，融合传统纹样与现代设计
- **主色调：** 中国红 #C41E3A、正红 #E8372B
- **辅助色：** 金色 #D4A84B、深棕 #3D2914、墨色 #1A1A1A
- **背景色：** 米白 #FDF8F0、浅金 #F5E6C8

### 5.2 字体规范

- **标题字体：** ZCOOL XiaoWei（站酷小薇体）/ Noto Serif SC
- **正文字体：** Noto Sans SC
- **金句字体：** 方正古朴宋体风格

### 5.3 声纹纹样设计

- 基于癞子锣鼓的节奏波形生成的视觉纹样
- 纹样风格：传统云纹 + 音波曲线的融合
- 颜色：金色渐变，叠加于照片之上

### 5.4 海报布局

```
┌─────────────────────────────┐
│                             │
│         用户照片             │
│    （叠加声纹云纹装饰）        │
│                             │
│  ┌─────────────────────┐    │
│  │   文化金句           │    │
│  └─────────────────────┘    │
│                             │
│  曲牌名称    二维码           │
│  品牌LOGO                  │
└─────────────────────────────┘
```

## 6. 技术实现（Demo 版本）

### 6.1 技术栈

- **前端：** 单页 HTML + CSS + JavaScript（Canvas 实现声纹生成）
- **声纹生成：** 基于音频波形的 Canvas 绑定可视化
- **图片处理：** HTML5 Canvas 合成
- **二维码：** QRCode.js 库

### 6.2 核心功能实现

1. **照片上传与预览**
2. **曲牌选择（带音频预览占位）**
3. **声纹纹样生成（Canvas 波形绘制）**
4. **海报合成与导出**
5. **模拟二维码生成**

### 6.3 响应式设计

- 移动端优先，适配微信内置浏览器
- 桌面端可正常访问

## 8. 动效设计

- **页面加载：** 鼓槌敲击动画入场
- **按钮悬停：** 微微放大 + 阴影加深
- **曲牌选中：** 边框发光 + 轻微缩放
- **海报生成：** 声纹从中心向外扩散的动画
- **金句出现：** 淡入 + 轻微上移

## 9. Demo 限制说明

本 Demo 为概念验证版本：
- 声纹纹样为基于随机波形生成的模拟效果
- 二维码为占位符，非实际可扫描链接
- 不涉及后端存储，数据均在本地处理
