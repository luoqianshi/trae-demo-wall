## 1. 产品概述

### 1.1 产品名称
蛋仔学园（EduDZ）- 寓教于乐的小学学习冒险平台

### 1.2 产品定位
面向小学 3-5 年级学生的互动学习平台，以蛋仔派对风格的游戏角色为核心，通过闯关冒险式学习体验，让小朋友在游戏中掌握数学和英语知识。内容严格对标苏教版教材。

### 1.3 核心理念
- **寓教于乐**：学习嵌入游戏，不是做题而是冒险
- **角色陪伴**：蛋仔伙伴让学习有温度、有动力
- **即时反馈**：每一步都有金币、星星、等级等正向激励
- **家长安心**：可视化学习进度，可控的学习时长

### 1.4 目标用户
| 角色 | 年龄 | 需求 |
|------|------|------|
| 学生 | 8-11岁（小学3-5年级） | 有趣的学习体验、角色养成、成就感 |
| 家长 | 30-45岁 | 了解学习进度、控制使用时间、内容权威性 |

## 2. 世界观设定

蛋仔们生活在一个由"知识星球"组成的宇宙中。每个星球代表一个学习领域。小朋友选择一个蛋仔伙伴，在星球之间冒险闯关。

- **数学星球**（橙红色）：加减乘除、几何、逻辑推理
- **英语星球**（青绿色）：单词、语法、阅读、听力
- **语文星球**（金黄色）：识字、拼音、阅读、写作（第二期）
- **科学星球**（紫色）：自然科学、趣味实验（第二期）

## 3. 交互设计

### 3.1 游戏大厅模式

采用**游戏大厅式**交互，替代传统的逐级页面导航。小朋友登录后直接看到一个沉浸式的游戏场景。

#### 大厅场景元素
- 蓝天白云绿草地的 2D 场景背景
- 蛋仔角色站在画面中央偏下位置
- 4 个知识星球浮动在场景中（左右上分布）
- 底部快捷功能栏

#### 交互流程
```
登录 → 游戏大厅（直接看到场景）
  ↓
点击星球 → 关卡选择气泡浮出（3-5个关卡卡片）
  ↓
选择关卡 → 直接进入游戏（无需页面跳转，场景切换过渡）
  ↓
游戏中遇到知识门/宝箱/NPC → 弹出互动题目
  ↓
答对继续前进 / 答错角色提示鼓励可重试
  ↓
完成关卡 → 星星评级 + 金币奖励 + 返回大厅
```

#### 关键交互原则
- 最多 **2 次点击** 即可开始学习游戏
- 所有页面切换使用**场景过渡动画**，而非浏览器页面跳转
- 弹出式题目面板，不离开游戏上下文
- 底部快捷栏常驻，一键访问核心功能

### 3.2 底部快捷栏
| 按钮 | 功能 |
|------|------|
| 金币+星星 | 显示当前数量 |
| 每日签到 | 领取每日金币奖励 |
| 装扮商店 | 购买角色皮肤和配件 |
| 排行榜 | 查看好友排名（第二期） |
| 我的蛋仔 | 个人中心、角色、成就 |
| 家长端 | 密码保护的家长控制面板 |

## 4. 核心功能模块

### 4.1 用户系统

#### 注册与登录
- 手机号/家长微信扫码注册
- 简化的儿童友好界面（大按钮、图标导航）
- 选择年级（3年级 / 4年级 / 5年级）

#### 角色选择
- 初始提供 **4 个基础蛋仔角色**，各有不同外观和性格
- 角色外观：圆润Q弹造型，类似蛋仔派对的可爱风格（原创设计，避免版权问题）
- 角色特性：仅影响外观，不影响游戏数值
- 支持后续解锁更多角色

### 4.2 数学星球（MVP 核心模块）

#### 内容标准
- 严格对标 **苏教版教材** 小学 3-5 年级数学大纲
- 题目来源：苏教版教材课后练习 + 教学大纲知识点

#### 年级与关卡设计

**三年级（5关）**
| 关卡 | 知识点 | 游戏类型 |
|------|--------|----------|
| 1-1 | 万以内加减法 | 计算闯关：限时答题，答对前进 |
| 1-2 | 有余数的除法 | 除法弹射：选择正确答案弹射蛋仔 |
| 1-3 | 多位数乘一位数 | 乘法消消乐：配对算式和结果 |
| 1-4 | 长方形和正方形 | 几何拼图：拼出目标图形 |
| 1-5 | 分数初步认识 | 分数切蛋糕：操作切分正确比例 |

**四年级（5关）**
| 关卡 | 知识点 | 游戏类型 |
|------|--------|----------|
| 2-1 | 三位数乘两位数 | 计算跑酷：跑动中答题闯关 |
| 2-2 | 除数是两位数的除法 | 除法塔防：正确答案消灭障碍 |
| 2-3 | 运算律（交换律、结合律） | 规律连线：找出等式关系 |
| 2-4 | 三角形、平行四边形 | 几何寻宝：在图形迷宫中找出口 |
| 2-5 | 小数的意义和性质 | 小数跳跳乐：按大小顺序跳跃 |

**五年级（5关）**
| 关卡 | 知识点 | 游戏类型 |
|------|--------|----------|
| 3-1 | 小数乘除法 | 计算竞赛：限时答题对战NPC |
| 3-2 | 简易方程 | 方程天平：平衡左右两边 |
| 3-3 | 多边形面积 | 面积农场：计算并种植正确面积 |
| 3-4 | 统计（平均数、折线图） | 数据收集者：整理数据画图表 |
| 3-5 | 因数与倍数 | 因数树探险：找因数路径 |

### 4.3 英语星球（MVP 核心模块）

#### 内容标准
- 对标 **苏教版（译林版）牛津英语** 小学 3-5 年级教学大纲
- 词汇和语法严格遵循教材单元内容

#### 年级与关卡设计

**三年级（5关）**
| 关卡 | 知识点 | 游戏类型 |
|------|--------|----------|
| 1-1 | Unit 1-2 问候与自我介绍 | 单词消消乐：配对中英文 |
| 1-2 | Unit 3-4 颜色与动物 | 听力选择：听发音选图片 |
| 1-3 | Unit 5-6 数字与水果 | 数字连连看：按顺序连接英文数字 |
| 1-4 | Unit 7-8 身体与五官 | 拼装蛋仔：听指令给蛋仔加部件 |
| 1-5 | Unit 1-8 综合复习 | 对话闯关：选择正确回答继续对话 |

**四年级（5关）**
| 关卡 | 知识点 | 游戏类型 |
|------|--------|----------|
| 2-1 | Unit 1-2 学校科目与时间 | 时间表挑战：排列正确的时间表 |
| 2-2 | Unit 3-4 日常活动 | 动作配对：英文动词与动画配对 |
| 2-3 | Unit 5-6 食物与饮料 | 餐厅点餐：听对话选择正确食物 |
| 2-4 | Unit 7-8 天气与季节 | 天气预报：读英文选正确天气图标 |
| 2-5 | Unit 1-8 综合复习 | 故事填空：在故事中选择正确单词 |

**五年级（5关）**
| 关卡 | 知识点 | 游戏类型 |
|------|--------|----------|
| 3-1 | Unit 1-2 国家与职业 | 世界探险：读线索猜国家 |
| 3-2 | Unit 3-4 交通与问路 | 地图导航：听指令移动蛋仔 |
| 3-3 | Unit 5-6 形容词比较级 | 比较大赛：选择正确的比较级形式 |
| 3-4 | Unit 7-8 过去时态 | 时间旅行：选择正确的过去式 |
| 3-5 | Unit 1-8 综合复习 | 综合挑战赛：限时多题型混合 |

### 4.4 游戏内嵌入式答题

题目不单独出现在"做题页面"，而是嵌入游戏场景中：

- **知识门**：闯关路径上的大门，需要答对题目才能通过
- **宝箱NPC**：场景中的宝箱角色，对话后弹出题目，答对获得额外奖励
- **障碍物**：跑酷途中的障碍，答题消除
- **弹出面板设计**：
  - 半透明遮罩，题目浮在游戏场景上层
  - 蛋仔角色在题目旁边做加油/鼓励动画
  - 答对：绿色闪烁 + 金币飞入动画 + 角色欢呼
  - 答错：温和提示 + 正确答案讲解 + 角色鼓励（无惩罚）
  - 支持重试，不限次数

### 4.5 独立学习模块（补充）

除了游戏闯关，大厅中也提供"学习中心"入口，小朋友可以：
- 按知识点单独练习（脱离游戏场景，纯答题模式）
- 查看知识点讲解（动画演示）
- 错题回顾（自动收集做错的题目）

### 4.6 奖励与养成系统

| 奖励类型 | 获取方式 | 用途 |
|----------|----------|------|
| 金币 | 完成关卡、每日签到、答对题目 | 购买装扮 |
| 星星 | 关卡评级（1-3星） | 解锁新关卡、成就 |
| 经验值 | 完成任何学习活动 | 角色升级 |
| 成就徽章 | 特定里程碑 | 成就墙展示 |

#### 关卡评级
- **3星**：首次通关且全部答对
- **2星**：通关但有错题
- **1星**：通关但重试超过3次

#### 装扮商店（MVP 期 8-10 件）
- 帽子类：皇冠、魔法帽、飞行员帽
- 眼镜类：墨镜、望远镜、星星眼镜
- 背饰类：小翅膀、火箭背包、蝴蝶结
- 服装类：恐龙装、宇航服、超人披风

### 4.7 家长端

- 需要家长密码才能进入
- 功能：
  - 学习进度总览（各星球通关百分比）
  - 知识点掌握情况（正确率统计，标注重难点）
  - 每日/每周学习时长记录
  - 设置每日学习时长上限（可选 15/30/45/60 分钟）
  - 错题查看（了解孩子薄弱环节）

### 5.1 技术栈

model User {

model Level {
  id        String   @id @default(cuid())

  grade     Int      // 年级
  levelNum  Int      // 关卡编号
  title     String
  topic     String   // 知识点

model Progress {
  id         String @id @default(cuid())

  levelId    String

model Question {
  id        String   @id @default(cuid())

  content   String   // 题目内容
  options   Json     // 选项（选择题）或答案（填空题）

model Purchase {
  id        String @id @default(cuid())

  cost      Int    // 花费金币

}

model Achievement {

## 6. 设计规范

### 6.1 视觉风格

- **整体色调**：明亮、饱和、温暖，以蓝天白云为基调
- **色彩系统**：
  - 主色：天蓝色 `#4ECDC4`（活力）、珊瑚橙 `#FF6B6B`（热情）
  - 辅色：金黄 `#FFD200`（奖励）、紫色 `#A18CD1`（探索）
  - 背景：浅蓝渐变 `#87CEEB → #E8F4FF`
- **圆角设计**：所有卡片和按钮使用大圆角（16-24px）
- **字体**：思源黑体（Noto Sans CJK SC）或类似圆润中文字体
- **蛋仔角色风格**：
  - 椭圆形身体，圆润边缘
  - 大眼睛（有高光点），腮红
  - 丰富的表情动画（开心、惊讶、鼓励、加油）
  - 色彩鲜明，每个角色有独特的主色

### 6.2 交互规范

- 所有可交互元素：悬停放大 5% + 轻微弹跳动画
- 按钮点击：按下缩小 5% + 触感反馈（支持设备振动）
- 页面切换：淡入淡出 + 轻微缩放
- 答题反馈：
  - 正确：绿色光晕 + 金币飞入音效 + 蛋仔跳跃欢呼
  - 错误：温和橙色闪烁 + 蛋仔做加油动作 + "没关系，再来一次！"
- 无任何惩罚机制（不扣金币、不扣星星、不倒退）

### 6.3 音效设计

- 背景音乐：轻快明亮的8-bit风格或童趣纯音乐
- 关卡开始：鼓舞人心的短音效
- 答对：叮~金币收集音效

## 8. 风险与注意事项

### 8.1 版权合规
- 所有蛋仔角色均为**原创设计**，风格借鉴蛋仔派对的圆润可爱特征，但不使用任何官方角色名称、形象或素材
- 游戏场景和 UI 完全自主设计
- 产品名称"蛋仔学园"需进行商标查询

### 8.2 内容准确性
- 数学题库严格对标苏教版教材，由教师审核
- 英语题库对标译林版牛津英语教材
- 每道题目附带解析，确保教学正确性

### 8.3 儿童安全
- 不展示任何广告
- 不收集不必要的个人信息
- 家长端密码保护
- 每日使用时长限制选项
- 社交功能（排行榜）不显示真实姓名
