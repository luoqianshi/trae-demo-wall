《山河文脉：AI 文明传播时空地图》初赛 Demo 上传包

打开方式：
1. 解压 ZIP。
2. 双击打开 shanhe-wenmai-demo.html。
3. 页面加载后会自动弹出 5 步体验引导。

包内文件：
- shanhe-wenmai-demo.html：主 Demo 文件。
- assets/china_map_ai_readable.svg：中国版图与行政区划参考底图。

本版更新：
- AI 讲解支持用户输入新问题。
- 未配置真实 API 时，会使用本地知识引擎按问题关键词生成针对性回答。
- 例如输入“三国的分界线有什么地理屏障？”，页面会自动切换到三国时期，并回答秦岭、巴山、汉中、长江、三峡、荆州、淮河、江淮水网等地理屏障与交通节点。

体验建议：
- 首屏先跟随自动引导浮层完成 2 分钟体验。
- 可选择“我是学生 / 我是旅行者 / 我是博物馆观众”查看不同解释入口。
- 可拖动时间轴，查看不同时期的文明节点、路线、迁徙和行政范围变化。
- AI 讲解默认提供本地演示回答；如需真实 AI，可在页面中点击“配置真实 AI”，填入 DeepSeek、智谱 GLM 或自定义代理接口。

说明：
- 当前 Demo 数据为创意展示示意，不代表完整学术结论。
- 正式产品将接入权威资料来源，并为每条内容标注出处、可信度和审核状态。
