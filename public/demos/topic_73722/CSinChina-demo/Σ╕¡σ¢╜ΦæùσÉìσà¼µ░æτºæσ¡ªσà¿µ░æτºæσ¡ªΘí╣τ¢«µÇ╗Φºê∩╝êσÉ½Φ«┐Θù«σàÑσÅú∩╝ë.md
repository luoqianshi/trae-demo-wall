## 使用建议（怎样快速找到并参与这些项目）

1. **优先用“官网/数据库”入口**
   - 想系统了解项目背景、规则与数据情况，优先访问：PSP、LENSFINDER、中国观鸟记录中心、中国自然观察、声景中国、CKB等的官网或数据库页面。
   - 这些站点通常也会链接到最新的报名通知、使用说明和数据查看入口。
2. **微信生态是中国公民科学的主战场**
   - 对于强调公众参与的项目，如“我的自然百宝箱”“全国鸟撞公民科学项目”“上海貉口普查”“路杀生物调查”等，**长按招募推文中的二维码 / 在微信直接搜索小程序名**是最常见、也是官方推荐的入口方式。
   - 典型入口名：
     - “听见万物”小程序 —— 我的自然百宝箱主入口 [5]
     - “引力透镜搜寻LENSFINDER”小程序 —— LENSFINDER 的便捷入口 [16]
     - “防鸟撞行动网络”公众号 / 小程序 —— 全国鸟撞项目的常用入口
3. **线下+线上结合的调查项目，关注“年度招募”关键词**
   - 上海貉口普查、CBBS、中国部分路杀调查等往往按年度组织，多在春季或夏季集中发布“招募公告”。
   - 建议定期在以下站点 / 关键词下搜索：
     - 山水自然保护中心官网“资讯”栏目（貉口普查、鸟撞、多种公民科学项目）[3][23]
     - 质兰基金会项目页及微信公众号（CBBS 等）[7]
     - 各地自然保护组织 / 观鸟会的公众号（城市级调查、CBBS 城市站等）
4. **尚无稳定公众入口的早期项目**
   - 如“河流守望者”和目前公开信息有限的 CAS@home，更多是从历史和制度演进上理解其意义，如需参与同类型活动：
     - 可关注本地生态环保组织、水务局、生态环境局的“河流志愿监测”“河湖长制公众参与”等栏目；
     - 志愿计算方向，可关注中科院高能所、国内天文/物理相关BOINC项目的最新公告。
