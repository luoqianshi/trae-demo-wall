# ReadMate 产品需求文档（PRD）

> 文档版本：v1.0 · 最后更新：2026-07-05

## 1. 产品概述

### 1.1 产品定位

ReadMate 是一款常驻 Windows 桌面的**屏幕阅读伴侣**。它打破"复制 → 切窗口 → 粘贴 → 提问"的传统 AI 问答流程，让用户在任意应用中**选中即问**，AI 即时响应。

### 1.2 一句话价值主张

> 你在看什么，AI 就懂什么；选中即问，零输入懂你。

### 1.3 解决的问题

| 用户痛点 | 传统方案 | ReadMate 方案 |
|---|---|---|
| 看到陌生概念想查询 | 复制 → 打开浏览器/ChatGPT → 粘贴 → 提问 | 选中 → 点「解释」 |
| 阅读外文资料 | 复制 → 翻译软件 → 粘贴 | 选中 → 点「翻译」 |
| 长文阅读理解 | 全文复制粘贴给 AI | 选中段落 → 点「总结」 |
| 代码/数据想分析 | 截图或复制到 AI 工具 | 选中 → 点「分析」 |
| 上下文断片 | AI 不知道你正在看什么 | 屏幕记忆提供上下文 |

### 1.4 目标用户

- **知识工作者**：研究员、分析师、产品经理，频繁阅读各类文档
- **开发者**：阅读技术文档、源码、报错信息
- **学生**：阅读论文、教材、外文资料
- **跨语言工作者**：需要频繁翻译的用户

## 2. 功能需求

### 2.1 核心功能（P0）

#### F1 · 选中即问
- 用户在任意应用中选中文字
- 鼠标抬起后 200ms 内，鼠标旁浮出「问一问 Agent」按钮
- 按钮位置自动避让屏幕边缘
- 取消选择后 1 秒，按钮自动消失

#### F2 · 预设快捷动作
- 「解释」：用通俗语言解释选中内容
- 「翻译」：自动识别语种，翻译为中文（中文则翻译为英文）
- 「总结」：提炼要点
- 「分析」：从多个维度深度分析

#### F3 · 自定义提问
- 浮动按钮内含输入框，用户可输入任意问题
- 问题与选中内容一起提交给 AI

#### F4 · 流式回答
- 答案面板从按钮位置平滑展开（280ms 动画）
- AI 回答逐字流式显示，不显示思考过程
- 自动滚动到底部

#### F5 · 多轮追问
- 答案面板底部输入框支持追问
- 保留多轮对话上下文

#### F6 · 屏幕上下文
- 基于 screenpipe 捕获最近屏幕内容
- AI 回答时结合屏幕上下文，更精准

### 2.2 辅助功能（P1）

#### F7 · 历史记录
- SQLite 持久化所有问答记录
- 托盘菜单可查看最近 20 条记录
- 支持统计信息（累计、今日）
- 支持清空历史

#### F8 · 自由交互
- 答案面板支持鼠标拖动
- × 按钮关闭
- ESC 键关闭

### 2.3 体验要求（非功能）

| 维度 | 要求 |
|---|---|
| **响应性** | 选区检测 ≤ 200ms，首字流式 ≤ 1s |
| **无干扰** | 不抢走原应用焦点，不影响 Ctrl+C/V |
| **稳定性** | 7×24 小时常驻不崩溃，异常自恢复 |
| **兼容性** | Windows 10/11，DPI 缩放 100%-200% |
| **隐私性** | 历史记录本地存储，不上传 |

## 3. 用户流程

### 3.1 主流程

```
用户选中文字
   ↓
[200ms 内] 浮动按钮在鼠标旁出现
   ↓
用户选择动作 ──┬── 点击预设动作（解释/翻译/总结/分析）
              ├── 输入自定义问题 → 点 →
              └── 不操作 → 1 秒后自动消失
   ↓
答案面板从按钮位置展开
   ↓
AI 流式回答 ──→ 同步保存到历史记录
   ↓
用户操作 ────┬── 在输入框追问
             ├── 拖动面板位置
             ├── 点 × 关闭
             └── 按 ESC 关闭
```

### 3.2 启动流程

```
用户运行 python run.py
   ↓
托盘图标出现，提示"ReadMate 已启动"
   ↓
后台：屏幕记忆开始捕获
   ↓
后台：选区监听开始
   ↓
用户在任意应用选中文字 → 进入主流程
```

## 4. 配置项

| 配置键 | 默认值 | 说明 |
|---|---|---|
| `minimax_api_key` | `""` | MiniMax API 密钥 |
| `minimax_model` | `MiniMax-M3` | 模型名称 |
| `popup_timeout` | `5.0` | 浮动按钮超时秒数 |
| `screen_capture_interval` | `30.0` | 屏幕捕获间隔秒数 |
| `max_history_records` | `1000` | 最大历史记录条数 |

配置优先级：环境变量 > 配置文件 > 默认值。
配置文件路径：`~/.readmate/config.json`。

---

## 5. 非目标（明确不做）

- ❌ 不做 macOS / Linux 支持（依赖 Windows SendInput）
- ❌ 不做云端同步（隐私优先）
- ❌ 不做插件市场（保持单机简洁）
- ❌ 不做 OCR 图片识别（当前仅支持文字选中）

---

## 6. 验收标准

- [x] 选中文字 200ms 内出现浮动按钮
- [x] 取消选择 1 秒后按钮自动消失
- [x] 4 个预设动作可正常触发 AI 流式回答
- [x] 自定义提问可正常工作
- [x] 答案面板可拖动、可关闭（× 或 ESC）
- [x] 不抢走原应用焦点，不影响复制粘贴
- [x] 历史记录正确保存与查询
- [x] 7×24 小时常驻运行不崩溃
- [x] 单元测试覆盖率 ≥ 关键模块
- [x] CI 在 Python 3.10/3.11/3.12 全部通过
