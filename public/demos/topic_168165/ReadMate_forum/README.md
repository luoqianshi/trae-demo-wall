# ReadMate · 屏幕阅读伴侣

> TRAE AI 创造力大赛初赛 Demo · 生活娱乐赛道

**ReadMate** 是一款桌面 AI 助手。选中屏幕任意文字 → 自动弹出浮动按钮 → 一键获得 AI 解释、翻译、总结、追问。**让"看到一段好内容想问 AI"从 4 步变成 1 步**。

## 体验方式（评审用）

### Windows 10/11 用户（最简单）

1. 解压 `ReadMate_forum.zip` 到任意目录
2. **双击 `start.bat`**
3. 首次运行会自动：
   - 创建 Python 虚拟环境
   - 安装依赖（PyQt6 + requests + pyperclip + pygments + 选区监听库）
   - 启动 ReadMate
4. 应用启动后**最小化到托盘**，按 `Ctrl+Q` 退出

### 体验流程

1. 打开任意应用（浏览器、记事本、PDF 阅读器）
2. **用鼠标选中一段中文**（比如一段新闻、文档）
3. 选中后会在鼠标附近弹出**青色浮动按钮**「问 AI」
4. 点按钮 → 弹出答案面板 → AI 实时流式回答
5. 答案面板支持：
   - 拖动（标题栏/内容区空白）
   - 折叠/展开（− 按钮）
   - 放大/缩小（□ 按钮）
   - 追问（底部输入框 + 发送按钮）
   - Markdown 渲染（标题/列表/代码块/链接）

## 配置 LLM API Key

首次启动会弹窗要求配置 API Key（OpenAI 兼容格式）。可以填：

- OpenAI 官方 key
- 任何兼容 OpenAI Chat Completion 接口的服务（Moonshot / DeepSeek / 通义千问 等）

如果**不想配自己的 Key**，Demo 自带一个免费体验 key（限 100 次调用），够评审完整体验。

## 核心功能

| 功能 | 说明 |
|---|---|
| 选区监听 | 跨应用监听剪贴板，识别文本选中事件 |
| 浮动按钮 | 鼠标位置附近弹出，半透明渐变，按需动作行 |
| 流式输出 | LLM 流式响应实时渲染，支持 Markdown |
| 追问/自定义提问 | 不限于选中文本，可自由提问 |
| 历史记录 | 自动保存所有问答，可回看 |
| 屏幕记忆 | 滚动/切换应用时不丢失上下文 |
| 托盘常驻 | 不抢占主屏幕，后台运行 |

## 技术栈

- **GUI**: PyQt6
- **LLM**: OpenAI Chat Completion API（兼容模式）
- **流式**: threading + Qt signal
- **打包**: 源码 + venv 一键启动（评审友好）

## 隐私说明

- 选区监听只在**用户主动选中文本时**读取剪贴板，不持续监听
- 文本发给 LLM 时附带应用名（帮助 AI 理解上下文），不附带屏幕其他内容
- 历史记录存在本地 SQLite，不上传云端
- 配 API Key 后才会发起 LLM 请求

## 已知限制

- macOS 选区监听需要额外配置（暂时只完整支持 Windows）
- exe 打包版跨线程流式输出有兼容问题，建议用源码版（start.bat）
