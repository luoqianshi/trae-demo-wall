# 《球场心跳》05 · 剪辑合成阶段

对应平台任务：工程整理、动效、字幕、音画同步、特效调色、成片输出

## 2. 画面动效规范

| 类型 | 用法 | 参数建议 |
|------|------|----------|
| 缓慢推近 | 情绪、特写 | 110s 内推 5–8% 缩放 |
| 轻微手持 | 球场、拥挤 | 振幅小，避免晕 |
| 匹配剪 | 球鞋→舞台灯 | 动作方向一致 |
| 叠化 | 时空缓和转场 | 8–12 帧 |
| 闪白 | 仅蒙太奇 | ≤3 帧 |
| 视差 | 分层背景 | 前景动幅 > 后景 |

**第 1 集必做动效**
- 镜 08 快切：缩放脉冲  
- 镜 15 撞击：2 帧 shake  
- 镜 22：慢推 + 可选心跳叠加  
- 镜 24：光斑粒子慢飘  

---

## 3. 字幕规范

```text
字体：思源黑体 / 阿里巴巴普惠体 中粗
字号：竖屏安全，约占屏宽 70% 内
位置：下方 15%–20% 安全区，避开脸
颜色：白字 + 深灰描边或半透明底
关键词：可局部上色橙色（人名、绝杀等）
出现：比气口早 2–3 帧；消失随气口
```

**花字（克制）**
- 周凯「陆神今日成神！」可用弹跳花字 1 次  
- 心动点不要满屏「扑通」——最多一个小心跳图标  

**集末字幕**
```text
第 1 集 完
下集：三分线外的旁听生
```

---

## 4. 音画同步要点

| 检查项 | 方法 |
|--------|------|
| 对白 | 嘴动峰值对齐波形 |
| 入网 | 球进框帧对齐 SFX |
| 掌声 | 落在笑点/金句后 2–4 帧 |
| BGM 鼓点 | 开场哨、绝杀可卡点 |
| 雨戏 | 雨声先入 0.5s 再切画面 |

**第 1 集卡点建议**
- 0:00 哨 + 鼓  
- 递麦指尖：BGM 换成 M02，环境声 duck  
- 自语名字后：BGM 渐隐 → 字幕  

---

## 5. 调色

| 场景 | 倾向 |
|------|------|
| 篮球馆 | 略暖，对比中等，木地板橙增强 |
| 礼堂舞台 | 青紫对比，人物肤色单独保护 |
| 走廊夜 | 低饱和蓝，人物加一点暖边光 |
| 心动特写 | 整体 +0.3 曝光微暖，高光柔 |

统一：**不要每镜不同滤镜**；最多 2 套 LUT（日/夜）。

---

## 6. 成片输出规格

```text
分辨率：1080 × 1920（9:16）
帧率：30 fps（或 25，全季统一）
码率：建议 8–15 Mbps H.264
音频：AAC 320kbps / 48kHz
时长：第1集 100–120s（含头尾）
封面帧：镜23 双人姓名 或 镜22 指尖（加标题字）
```

**导出文件名**
`球场心跳_EP01_庆功会上的意外_v1.mp4`
