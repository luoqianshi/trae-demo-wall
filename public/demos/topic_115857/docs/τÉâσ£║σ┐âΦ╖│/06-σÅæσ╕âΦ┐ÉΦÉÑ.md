**复盘问题**
1. 钩子是否在 3 秒内成立？  
2. 哪句对白被截图最多？  
3. 男/女主谁更吸粉？下集镜头是否倾斜？  
4. 是否需要加花字或减对白密度？  

**迭代规则**
- 完播低：砍开场前史，更快进相遇  
- 评论少：标题改成选择题/冲突句  
- 女主反馈强：增加舞台特写与应援戏
