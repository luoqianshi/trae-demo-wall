# 《球场心跳》漫剧全案

> 项目配套剧本案，严格对应陪跑平台六大阶段：编剧 → 分镜 → 绘画 → 配音 → 剪辑 → 发布运营。  
> 题材：校园青春甜宠｜时长规划：12 集 × 约 90–120 秒｜画风：日系校园漫 · 暖色系

## 一句话卖点

**篮球少年 × 舞台少女，一场庆功晚会的意外相识，点燃整个夏天。**

## 主线节奏（12 集）

```
1 相遇庆功会 → 2 球场偶遇 → 3 合唱邀请（钩子）
→ 4 第一次合练 → 5 误会（打篮球 vs 排练冲突）
→ 6 雨夜坦白 → 7 校庆彩排危机 → 8 星野替她站台
→ 9 决赛前夜 → 10 双线高潮（决赛+舞台）
→ 11 告白 → 12 夏天未完（开放式甜结局）
```

## 使用方式（对接本平台）

1. 打开陪跑平台 → **编剧阶段**，对照 `01` 勾选任务并粘贴到笔记区。  
2. **分镜 / 绘画 / 配音** 可直接用文档中的镜头号与提示词调用 AI。  
3. 成片规格与发布文案见 `05`、`06`。  
4. 建议先做完 **第 1 集样片** 再批量推进 2–12 集。
