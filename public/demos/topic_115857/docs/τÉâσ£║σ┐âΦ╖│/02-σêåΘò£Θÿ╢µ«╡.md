## 2. 重点镜头构图说明（storyboard-2）

### 镜 15–18　相遇（核心）

```text
镜15 近景 平视 微手持感
画面：星野后退半步，肩线入画；念歌从画右入，两人形成「V」字负空间
光线：舞台侧逆光，轮廓光勾边
运动：固定，结束时轻微推近

镜17 近景 略俯
画面：手持麦从念歌手到星野掌心，三分法交点在手部
景深：背景观众虚化成光斑（散景）

镜18 特写
画面：耳尖、侧颈；浅景深
色调：暖一点，对比后景冷蓝舞台灯
```

### 镜 22　指尖（心动）

```text
景别：大特写
角度：平视
运动：极慢推
画面：两指尖相触占画面 60%；可加 1 帧「电流」线特效（克制）
音效：环境声骤弱 + 单心跳
```

### 镜 19　救场发言

```text
景别：中景 → 缓推近景
角度：微仰（舞台感）
画面：念歌居中偏左，星野虚在她右后方半身
情绪：她稳、他紧
```

### 镜 32–33　收束

```text
掌心特写用顶光；自语近景留头部上方空间（呼吸感）
转场：淡出到黑 → 字幕
```

## 3. 节奏时间轴（storyboard-3）

```text
第 1 集 目标总长：01:50（110s）

00:00–00:12  开场热血（镜01–08）        快切，鼓点
00:12–00:28  女主后台（镜09–12）        节奏放缓
00:28–00:55  相遇救场（镜13–25）        中速，对白清晰
00:55–01:25  走廊邀约（镜26–30）        轻松
01:25–01:50  情绪尾巴+字幕（镜31–34）  慢，留白
```

**节奏原则**
- 打球段：镜头 1–2.5s
- 对白段：以气口切，不抢词
- 心动特写：给满 1–1.5s，勿碎

## 4. 特效与转场（storyboard-4）

| 位置 | 类型 | 说明 |

## 5. 分镜审核要点（storyboard-5）

- [ ] 10 秒内建立「谁赢了球」

- [ ] 相遇动作清晰（撞→递麦→指尖→姓名）

- [ ] 集末钩子：邀约看比赛 + 他记住名字  
- [ ] 无连续 3 个以上同景别
