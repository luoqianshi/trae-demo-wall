二十签 - 使用说明

二十签是一款多 Agent 协同的个性化技能操练 PWA 应用，核心理念来自乔希·考夫曼的"20小时学会新技能"理论。

打开方式：直接双击 index.html 即可在浏览器中运行，无需安装任何软件或启动服务器。

快速开始

1 打开应用
双击打开 index.html 文件，应用将在浏览器中运行。
2 输入学习目标
在首页输入框中输入你想学习的技能，例如：
  • "我想学会 React，并独立做出一个小应用"
  • "我想提升人像摄影能力"
  • "我想在工作汇报时表达得更清楚"
3 完成诊断
系统会提出 3-5 个自适应问题，了解你的当前水平和学习目标，然后生成专属的 20 签训练路线。
4 查看训练路线
系统会生成 20 个渐进式训练单元，每个单元约 1 小时，都有明确的成果目标和验签标准。
5 进入训练场
点击"开始今日训练"，体验四阶段训练流程：
  1. 确认任务：明确今天要做什么
  2. 最小认知：获取必要的知识框架
  3. 做出成果：动手完成实际作品
  4. 提交验签：上传证据，等待 AI 验签
6 查看验签结果
验签 Agent 会根据冻结标准评价你的成果，给出通过、待修正或证据不足等结论，并更新能力图谱。

核心功能演示

多 Agent 协同

系统包含 6 大 Agent 分工协作：

  • 诊断 Agent：自适应提问，形成能力画像
  • 路线 Agent：生成 20 个渐进训练单元
  • 审校 Agent：检查路线合理性
  • 训练 Agent：管理每日训练流程
  • 验签 Agent：根据冻结标准评价成果
  • 归档 Agent：更新能力档案，调整后续路线

20 段能力标记

首页顶部的 20 个模块代表 20 张日签，完成一签后模块会从灰色变为信号朱红色，形成可视化的成长轨迹。

动态路线调整

根据你的每日表现，系统会动态调整后续路线。你可以替换、排序和局部重做训练单元。

技术说明

提示：这是一个纯前端 PWA 应用，所有数据保存在浏览器本地存储中。清除浏览器数据会导致学习记录丢失。
  • 技术栈：React 18 + TypeScript + Vite
  • 状态管理：React Context + useReducer
  • 样式方案：CSS Modules
  • 数据存储：localStorage
  • 响应式：支持桌面端和移动端

浏览器兼容性

推荐使用以下现代浏览器：

  • Chrome 90+
  • Firefox 88+
  • Safari 14+
  • Edge 90+
注意：本演示版本使用 Mock Agent，模拟 AI 生成内容。实际产品将接入真实的大语言模型 API。
