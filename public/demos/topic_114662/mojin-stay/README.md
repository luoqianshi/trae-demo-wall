# 墨金旅居微信小程序

这是一个面向旅居、民宿、长短租房源运营者的房租收费管理小程序原型。

## 当前功能

- 首页经营概览：本月实收、待收金额、入住率和待处理账单
- 房源管理：房态、房客、租金、押金和水电单价
- 房源详情：租住信息、费用标准和快捷操作
- 收租单：按房源生成房租、水费、电费、服务费和优惠后的应收金额
- 账单管理：全部、待收、逾期、已收筛选，支持本地模拟确认收款
- 水电抄表：录入水表、电表读数，预留拍照识别入口
- 退租结算：押金、维修扣款、保洁费、未结费用和应退金额
- 经营统计：年度实收、费用、逾期账单和近 6 月收入趋势
- 我的：微信资料授权入口、收款账户、消息提醒、合同模板、数据备份

## 导入方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹 `mojin-stay`。
4. 测试体验可以使用测试号。
5. 正式发布时，把 `project.config.json` 中的 `appid` 替换成你自己的小程序 AppID。

## 上线前需要接入

- 用户登录与房东身份
- 后端数据库
- 真实房源、房客和合同数据
- 微信支付或收款确认
- 短信/订阅消息提醒
- 水电拍照识别
- 数据导出和权限管理
