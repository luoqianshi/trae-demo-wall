# 科学育儿助手 App Demo

一个跨平台的科学育儿助手应用演示，支持根据天气、孩子年龄、体重、身体状况自动生成每日穿衣指导、辅食方案、疫苗提醒和养护注意事项。

## 快速体验

### 方式一：浏览器预览（推荐）

直接打开 `demo/index.html` 文件，或在本地启动服务器：

```bash
cd demo
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

### 方式二：Flutter 运行

需要 Flutter SDK 环境：

```bash
flutter pub get
flutter run
```

## 功能概览

### 🏠 首页仪表盘
- 动态天气卡片（温度、湿度、紫外线、空气质量）
- 孩子头像切换栏（支持多孩管理）
- 今日穿搭建议卡片
- 今日辅食方案简表
- 疫苗到期提醒
- 每日须知综合卡片

### 🍽️ 辅食方案
- 根据月龄、体重、天气、过敏源生成三餐两点
- 每餐附带烹饪建议
- 营养搭配提示

### 💉 疫苗管理
- 内置国家免疫规划疫苗程序
- 自动计算接种日期
- 到期提醒（提前3天）
- 身体状况暂缓提示

### 💬 社区功能
- 帖子列表展示
- 分类Tab切换（推荐/辅食/疫苗/穿搭/护理）
- 点赞、评论、分享
- 发布新帖

### 👤 个人中心
- 用户登录/注册
- 个人信息编辑（头像上传、昵称、身份）
- 孩子档案管理（添加/编辑/删除）
- 过敏源设置
- 手机定位城市
- 每日提醒时间设置

## 技术栈

- **前端框架**: Flutter (iOS/Android跨平台)
- **状态管理**: Riverpod
- **本地存储**: SharedPreferences + JSON
- **天气API**: 和风天气 / OpenWeatherMap
- **本地通知**: flutter_local_notifications
- **Web Demo**: 单文件HTML + CSS + JavaScript

## 核心规则

### 穿衣建议规则
- 新生儿(<1月): 保暖优先，比成人多一层
- 婴儿(1-12月): 洋葱穿衣法
- 幼儿(1-3岁): 活动量大，比成人少半件
- 参考温度阈值：>25℃短袖短裤；20-25℃长袖T恤；15-20℃薄外套；5-15℃毛衣厚外套；<5℃羽绒服

### 辅食建议规则
- 6月以下: 纯母乳/配方奶
- 6-12月: 泥糊状过渡，高铁米粉、菜泥、肉泥
- 1-3岁: 软饭、小馄饨，营养搭配
- 3岁以上: 接近成人饮食，清淡少盐

### 疫苗程序
- 一类疫苗：乙肝、卡介苗、脊灰、百白破、麻风、麻腮风、甲肝、流脑、乙脑
- 二类疫苗： Hib、水痘、肺炎、轮状病毒、流感
