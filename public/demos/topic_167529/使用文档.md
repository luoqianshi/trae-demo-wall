# 筱筱的成长日记 — 使用文档

## 一、快速开始

### 访问方式（任选其一）
1. **本地浏览器直接打开**：双击 `index.html`，用 Chrome/Edge 打开
2. **本地服务**：在文件夹下执行 `python -m http.server 9988`，浏览器访问 `http://localhost:9988/index.html`
3. **部署上线**：把 `index.html` 拖到 [Netlify Drop](https://app.netlify.com/drop) 即可获得公网链接

### 首次进入
1. 选择身份（妈妈/爸爸/奶奶/爷爷/月嫂）
2. 填写宝宝出生天数
3. 选择喂养方式（混合/纯配方奶/纯母乳）
4. 点击「开始记录 🌸」进入主应用

> 首次进入会自动预置 3 天示例数据，方便预览效果。清空数据方法见下文「数据管理」。

## 二、主应用结构

### 底部 4 个 Tab

| Tab | 功能 |
|-----|------|
| 👶 宝宝 | 今日喂养倒计时、卡片总览（喂养/睡眠/排泄/体温）、最近记录时间线 |
| 💗 关怀 | 8 张母亲状态卡片 + 产后康复模块（腹式呼吸/凯格尔运动） |
| 📖 知识 | 4 分类知识库 + 详情 + 社区评论 + 实用性投票 |
| 📊 数据 | 4 张图表（喂养柱状/体重曲线/情绪饼图/吸奶趋势）+ 导入导出 |

### 右下角 FAB（悬浮按钮）
点击展开 5 种快速记录：
- 🍼 喂养记录（支持配方奶/母乳双模式）
- 🍼 吸奶记录
- 💤 睡眠记录（开始/结束两态）
- 🧷 排泄记录
- 🌡️ 体温记录

**FAB 交互逻辑**：
- 点击 FAB → 展开 5 个选项
- 选择记录类型 → FAB 选项收起 + FAB 淡出隐藏 + 底部弹窗滑入
- 填写完毕点保存 或 点遮罩/✕ 关闭 → 弹窗滑出 + FAB 淡入恢复
- 点击 FAB 外的遮罩区域 → 收起选项

### 左上角头像
点击打开侧边抽屉：
- 修改宝宝信息（昵称/性别/出生日期/体重/喂养方式/目标奶量）
- 切换身份
- 切换主题（粉嫩/夜间/薄荷）
- 首页卡片显示开关
- 贴士显示开关
- 数据导出/导入（JSON）

## 三、核心功能详解

### 1. 喂养记录
- 配方奶：输入奶量（ml），快捷 ±10/±30，套用上次奶量
- 母乳：左/右/双侧 + 时长
- 可调整记录时间（默认当前时间）
- 「喂完睡着」勾选后自动创建一条睡眠记录
- 距离上次喂养超 3 小时首页会显示倒计时提醒

### 2. 睡眠记录
- 开始睡眠：点击创建「开始」状态的记录
- 结束睡眠：点击正在进行的记录，自动计算时长
- 未结束的睡眠记录不计入统计

### 3. 产后康复（关怀页）
- **腹式呼吸**：产后即可练习，记录每次时长，累计总分钟
- **凯格尔运动**：产后 6 周、恶露干净后开始，记录每次时长
- 点击卡片打开弹窗：累计时长、本次时长输入（快捷 5/10/15/20 分）、动作要领
- 数据持久化保存

### 4. 知识库
- 4 分类：喂养/睡眠/发育/产后
- 每张知识卡详情页含：完整内容、社区评论、「好用」/「不适用」投票
- 不适用比例超 50% 显示警示提示
- 仅自己可补充经验（区别于社区评论）

### 5. 数据图表
- 喂养柱状图：近 7 天每日总奶量
- 体重曲线：散点 + 折线
- 情绪饼图：近期情绪分布
- 吸奶趋势：近 7 天每日总量

## 四、数据管理

### 清空所有数据（重新开始）
浏览器控制台（F12 → Console）执行：
```js
localStorage.removeItem('xiaoxiao_diary_v1'); location.reload();
```

### 导出数据
左上角头像 → 抽屉底部「导出数据」→ 下载 JSON 文件

### 导入数据
左上角头像 → 抽屉底部「导入数据」→ 选择之前导出的 JSON 文件

### 数据存储位置
浏览器 `localStorage`，key 为 `xiaoxiao_diary_v1`

## 五、常见问题

### Q: 打不开页面 / 白屏？
A: 确保用 Chrome/Edge 浏览器。页面已内置 CSS 兜底，即使 Tailwind CDN 加载失败也能正常使用。

### Q: 手机上能用吗？
A: 可以。手机连同一 WiFi，浏览器输入电脑 IP:9988（需用 `python -m http.server 9988 --bind 0.0.0.0` 启动服务）。

### Q: 数据会丢吗？
A: 数据存在浏览器 localStorage，清除浏览器缓存会丢失。建议定期用「导出数据」备份。

### Q: 多人能共享数据吗？
A: 单设备单浏览器独立存储。多人共享需部署到云端并用同一浏览器（不推荐），或各自记录后导出合并。
