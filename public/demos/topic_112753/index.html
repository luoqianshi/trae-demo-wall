分层架构

采集层 (mobile/) — Flutter 原生 App：常亮锁、权限、镜像预览、站姿框、MediaPipe 推理、WS 客户端（配对码 + 心跳重连）
传输层 (core/transport/) — protocol 编解码与校验 · ws_server 鉴权 · frame_buffer 掉帧插值 · time_axis 时间轴重建
处理层 (core/filters/ + core/retarget/) — 1€ 滤波去抖 · 脚/头约束 · 坐标适配器 · 主演员锁定 · 重定向引擎 v1（同拓扑 + 比例缩放）
功能层 (core/features/) — T-Pose 校准 + 骨骼 profile · 录制/回放/裁剪/镜像 · 动作事件识别 · 快捷键映射 · 会话持久化
输出层 (core/exporters/ + core/web/) — BVH / glTF / ASCII FBX writer · FastAPI + Three.js 实时显示与调试面板 · cli 命令行

运行方式

电脑端：run.bat（Windows）/ start.sh（Linux·macOS）→ 自动 pip install -r requirements.txt 并启动 uvicorn + ws_server，浏览器打开 localhost:8000。
手机端：进入 mobile/ 执行 flutter pub get && flutter run 真机运行（需本地 Flutter 环境）。

已知限制：单目深度为估算值，转身/重叠动作会抖（仅缓解）；33 点无手指/精细足部；阶段一重定向仅同拓扑；局域网无 TLS（公有云前阶段二补合规）。
