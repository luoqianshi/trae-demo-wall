# 广东医保报销速查助手

广东省城乡居民基本医疗保险报销速查与估算工具，覆盖全省 21 个地级市，整合基本医保、大病保险、医疗救助三重保障。

## 功能特性

### 核心功能
- **报销估算**：支持普通门诊、普通住院、门诊特殊病种三种就医类型
- **三重保障**：基本医保 + 大病保险（分段递增）+ 医疗救助（困难群体）
- **21 地市覆盖**：全省统一基准 + 21 个地级市差异化政策参数
- **特殊病种细分**：53 种病种按 4 档参数（一般/重大/精神/结核）区分
- **多次住院起付线递减**：第 2 次 50%、第 3 次及以上 0
- **年度累计扣减**：本年度已报销金额扣减封顶线
- **连续参保激励**：满 4 年/5 年享受大病保险额度提升
- **历史记录**：localStorage 保存最近 5 次估算
- **结果导出**：打印、复制到剪贴板、语音播报

### 无障碍与适老化
- **长辈模式**：大字体、高对比度、大触控区，localStorage 持久化偏好
- **语音识别**：Web Speech API，口音容错（maxAlternatives=3），支持中文数字转换
- **语音合成**：SpeechSynthesis，长辈模式语速 0.8x、音调 1.1，慢速清晰播报
- **交互简化**：语音指令解析（10+ 指令），实时状态反馈，操作引导
- **无障碍**：完整 ARIA 属性、键盘导航、WCAG AA 对比度
- **响应式**：PC/移动端自适应，移动端标签页横向滚动

### 药品查询模块
- **常见药品数据库**：内置 200+ 种常见药品，按 4 类分组
  - 常用药品（51 种）：抗生素、解热镇痛、心血管、降糖降脂等
  - 慢性病用药（40 种）：高血压、糖尿病、哮喘、风湿等长期用药
  - 儿童用药（30 种）：儿童感冒、退热、肠道、维生素等
  - 急救用药（30 种）：升压、解毒、抗心律失常、抗惊厥等
- **药品搜索**：按名称或分类实时过滤
- **官方目录查询**：一键跳转国家医保服务平台查询药品目录
- **药品比价入口**：21 个地市比价小程序入口聚合

### 业务办理入口
- **异地就医备案**：跳转粤医保小程序办理
- **实际报销查询**：跳转粤医保"健康档"查看消费明细
- **医保码激活**：跳转国家医保服务平台激活医保电子凭证
- **参保凭证打印**：跳转粤医保在线打印
- **医保关系转移**：跳转粤医保办理转移接续
- **家庭共济绑定**：跳转国家医保服务平台绑定亲情账户
- **医保服务热线**：12393 一键拨打入口

### 政策更新与反馈
- **政策更新检查**：检查更新按钮，提示访问广东省医保局官网查看最新公告
- **用户反馈通道**：FAQ 页面反馈表单，本地存储反馈记录，支持分类与联系方式

### 技术特性
- **离线可用**：纯静态资源，断网可用（语音识别除外，需联网）
- **XSS 防护**：所有动态内容通过 `escapeHtml` 转义
- **CSP 安全策略**：内容安全策略防护
- **深链接跳转**：所有外部链接使用 `target="_blank" rel="noopener noreferrer"`

## 使用方法

### 快速开始
直接用浏览器打开 `广东医保报销速查助手.html` 即可，无需服务器或构建工具。

### 本地预览（推荐）
```bash
python -m http.server 8000
# 访问 http://localhost:8000/广东医保报销速查助手.html
```

### 长辈模式使用
1. 点击右上角"长辈模式"按钮开启
2. 界面将切换为大字体、高对比度显示
3. 自动展开语音操作指南
4. 可点击"语音输入"按钮，用语音指令操作
5. 偏好将自动保存，下次访问自动恢复

### 语音指令示例
- "计算报销" — 开始估算
- "总费用五千元" — 设置医疗总费用
- "比例百分之七十" — 设置医保目录内占比
- "住院" / "门诊" — 切换就医类型
- "广州" — 切换参保地市
- "读结果" — 语音播报估算结果
- "药品查询" — 切换到药品查询页
- "业务办理" — 切换到业务办理页
