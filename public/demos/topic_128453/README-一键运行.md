# 墨问 · 古籍智慧对话引擎 v2.0

## 一键运行说明

### 系统要求
- Windows 电脑
- 已安装 Python 3.9 或更高版本
- 已配置豆包 API Key（已填好 API Key，只需要改推理接入点ID）

### 运行步骤

1. **解压压缩包**
   - 下载后直接解压到任意目录，路径不要有中文空格

2. **配置 API Key**
   - 打开 `backend/.env` 文件
   - 把 `DOUBAO_MODEL_ID=ep-你的推理接入点ID` 中的占位符换成你在火山方舟创建的推理接入点ID
   - API Key 已经填好了你的：`ark-efc23f35-de48-422d-9f26-fdb2d3d6bcdd-47195`

3. **启动服务**
   - 双击 `start.bat`
   - 等待安装依赖（第一次需要几分钟）
   - 最后会显示：`Uvicorn running on http://0.0.0.0:8000`

4. **打开浏览器访问**
   ```
   http://localhost:8000
   ```

### 停止服务
- 在命令窗口按 `Ctrl+C`，或者直接关闭窗口

### 功能特性

✅ 21位圣贤按学派分组展示  
✅ 智能匹配：匹配古籍语料 + LLM大模型解读  
✅ 社区问答：支持社区共问共答  
✅ 多轮对话：上下文感知，持续交流  
✅ 登录注册：账号系统，本地存储不丢数据  
✅ 收藏功能：随时收藏喜欢的问答  
✅ 古籍语料库完整（SQLite 文件）  
✅ 支持豆包免费模型，每日 200 万 Tokens 免费  
✅ 双击运行，不需要 node.js，不需要前端编译

### 注意事项

- 第一次启动会自动安装 Python 依赖，需要几分钟，请耐心等待
- 如果依赖安装失败，检查网络连接，重新运行 `start.bat` 即可
- 如果浏览器打不开，检查防火墙设置，允许 Python 访问网络
- 豆包每天 200 万 Tokens 免费，对一般使用完全够用了
