# 阅知AI Demo - 使用指南

## 🎯 快速开始

### 方式一：一键启动（推荐）

双击 `启动Demo.bat` 即可自动完成：
- ✅ 检查 Node.js 环境
- ✅ 自动安装依赖（首次运行）
- ✅ 初始化演示数据
- ✅ 启动后端服务和前端服务
- ✅ 自动打开浏览器

### 方式二：手动启动

```bash
# 1. 启动后端
cd backend
npm install
npx tsx src/index.ts

# 2. 启动前端（新开一个终端）
cd frontend
npm install
npm run dev
```

## ✨ 功能体验指南

### 1. 产品首页
访问 http://localhost:5173/ 查看精美的产品介绍页面，了解：
- 六大核心功能
- 五级难度体系
- 使用流程介绍

### 2. 登录体验
- 点击「免费体验」或「登录账号」进入登录页
- 使用演示账号登录，或注册新账号
- 注册时可选择备考阶段（中考/高考/四级/六级/考研）

### 3. 首页推荐
- 登录后自动展示适配你难度的推荐文章
- 点击刷新按钮获取更多文章
- 每篇文章显示难度、分类、字数、预计阅读时间

### 4. 文章阅读
- 点击文章进入阅读页面
- 左侧浮动答题面板（核心交互设计）
- 中英文对照阅读
- 完成阅读理解题目

### 5. 答题与解析
- 作答后提交查看成绩
- 每道题都有详细的答案解析
- 错题自动加入复习

### 6. 生词本
- 阅读中遇到生词可一键添加
- 智能复习算法（连续5次掌握自动移除）
- 随时查看和管理生词

### 7. 阅读历史
- 完整记录所有阅读过的文章
- 查看每篇文章的得分情况
- 追踪学习进度

## ⚙️ 系统要求

- **操作系统**: Windows 10/11
- **Node.js**: v18.0 或更高版本
- **内存**: 至少 2GB
- **磁盘**: 至少 1GB 可用空间

### 安装 Node.js
如果系统没有安装 Node.js，请先下载安装：
1. 访问 https://nodejs.org/
2. 下载 LTS 版本
3. 双击安装包完成安装
4. 重新运行 `启动Demo.bat`

## ❓ 常见问题

### Q: 启动后浏览器没有自动打开？
A: 手动在浏览器中访问 http://localhost:5173/

### Q: 提示找不到 Node.js？
A: 请先安装 Node.js v18+，参考上方「系统要求」部分。

### Q: 文章加载不出来？
A: 确认后端服务是否正常启动（后端窗口显示服务运行在3000端口）。

### Q: 可以修改AI配置吗？
A: 可以，在 `backend/.env` 中配置智谱AI或OpenAI的API Key，配置后新采集的文章会使用AI生成。

### Q: 如何添加更多文章？
A: 后端集成了RSS自动采集功能，配置AI后可自动采集和生成文章。
