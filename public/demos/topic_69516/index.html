Changelog

版本更新

迭代日志 · 见证产品的每一次进化

V1.0.3 LATEST 2026-07-02
新增 🔧 MCP构建器 Phase 5-7 上线：代码语法高亮（highlight.js）、GitHub/数据库预设模板（自动生成客户端）、AI辅助规划（自然语言生成配置）
新增 GitHub 工具集模板：5个预配置工具（search_repos、get_repository、list_pull_requests、create_issue、get_file_content），自动生成 Octokit 客户端
新增 数据库工具模板：5个 CRUD 工具，SQL 注入防护（参数化查询 + 表名净化），execute_query 强制只允许 SELECT
新增 AI 辅助规划：自然语言描述需求 → LLM 自动生成工具配置 JSON，双模式 UI 区分（全规划 neon-cyan vs 补充绿色）
新增 代码语法高亮：highlight.js + atom-one-dark，支持 TypeScript/JSON/Bash，「复制运行命令」和「发送到聊天」按钮
新增 模块化技能池架构，所有技能拆分为独立插件文件，支持用户自建SKILL
新增 持久激活模式，MCP构建器装备后自动激活，关闭面板保持挂载，脉冲动画提示状态
修复 highlight.js 重复高亮 warning、getLangFromFilename TypeError、AI 规划对话框 z-index 层级问题
优化 两阶段发送流程，用户按下Enter后一帧内看到消息+思考动画，消除等待感
优化 流式渲染爆发模式，首字后300ms内60fps渲染，长文本体验提升4倍
修复 AI回复不显示、O(n²)全量重渲染、滚动卡顿等多个性能和体验问题
