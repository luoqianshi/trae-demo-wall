伴伴 - AI 生活伴侣
==================

一、快速启动
----------
方式1（推荐）：双击「启动伴伴.bat」
方式2：命令行运行 python 启动.py

首次启动会自动：
- 检查并安装所需依赖
- 创建本地数据库
- 加载演示种子数据（可在设置中切换到真实数据模式）
- 打开浏览器访问 http://127.0.0.1:9527
- 首次打开显示引导问卷，完成后进入主界面

二、系统要求
----------
- Python 3.9 或更高版本
- Windows 10/11
- 麦克风（用于语音交互，可选）
- 网络连接（用于AI服务）

三、功能说明
----------
1. 引导问卷：首次打开请完成简短问卷，伴伴将了解你的基本情况
2. 时间罗盘：今日时间全景与事件概览
3. 无边画布：无限画布与任务看板
4. 今日计划：时间规划、构成与节奏
5. 周规划总览：一周日程看板
6. 今日时间线：活动地图与AI分析
7. 早间简报/晚间复盘：定时回顾与规划
8. AI助手：随时对话交流

四、数据模式切换
--------------
默认使用「演示模式」（含种子数据，展示完整功能）。
如需使用真实数据：
1. 点击左侧边栏「设置」
2. 在「隐私与数据」中找到「演示模式」开关
3. 关闭开关，确认后切换到真实数据模式
4. 真实数据模式下，通过截图分析获取真实活动数据

五、依赖安装
----------
如果自动安装依赖失败，可以手动运行：
pip install -r requirements.txt

六、注意事项
----------
- 数据存储在用户目录下的 .banban 文件夹中
- 语音功能需要麦克风设备
- AI功能需要网络连接
- 端口9527需要保持可用
