完整功能矩阵

从基础聊天到语音通话、文件传输，满足局域网内多种沟通场景

群聊大厅

所有在线用户默认进入群聊大厅，实时收发消息，显示用户加入/离开系统通知。

私聊模式

左侧用户列表点击任意在线用户即可进入私聊，消息仅双方可见，未读消息自动计数。

语音通话

私聊窗口顶部点击电话图标发起 WebRTC 语音通话，支持接听、拒绝、静音、挂断。

表情包

输入框左侧笑脸按钮可打开 emoji 面板，内置百余常用表情，点击即可插入消息。

文件互传

支持发送任意类型文件，群聊单文件 ≤ 500MB，私信单文件 ≤ 1GB，带上传进度条与下载按钮。

系统信息

Sidebar 用户信息右侧点击信息按钮，屏幕中央弹出系统信息框，显示麦克风权限、连接状态等。

技术架构

前后端分离，Socket.IO 实时通信，WebRTC 语音传输

前端

  • React 18 + TypeScript
  • Vite 构建工具
  • Tailwind CSS
  • Zustand 状态管理
  • Lucide React 图标

后端

  • Node.js + Express
  • Socket.IO 实时消息
  • WebRTC 语音信令
  • Multer 文件上传
  • Nanoid 文件 ID

启动器

  • .NET 8 控制台应用
  • 自包含单文件 exe
  • 自动检测依赖安装
  • 服务就绪自动开浏览器
  • 关闭窗口即停止服务

使用流程

从启动到聊天，只需四步

1

启动程序

双击 局域网聊天软件.exe，等待服务就绪并自动打开浏览器。

2

输入昵称

在登录页输入昵称，点击「加入聊天」进入群聊大厅。

3

选择聊天对象

左侧列表选择「群聊大厅」或任意在线用户，即可发送消息、表情、文件。

4

语音通话

在私聊窗口点击右上角电话图标发起语音通话，对方接听后即可通话。

详细说明

语音通话原理

基于 WebRTC RTCPeerConnection 实现点对点语音传输，Socket.IO 负责 offer/answer/ICE candidate 信令交换。 使用 STUN 服务器辅助 NAT 穿越，首次通话时浏览器会请求麦克风权限。

文件传输机制

文件通过 HTTP 上传到 Node 服务器临时目录，大小校验后生成唯一 fileId。文件元数据经 Socket.IO 广播， 接收方点击文件消息即可通过 /api/file/download/:fileId 下载原文件。

系统信息检测

调用浏览器 Permissions API 实时检测麦克风授权状态，同时展示当前用户、在线人数、WebSocket 连接状态及浏览器信息， 帮助用户快速排查语音通话无法使用等问题。
