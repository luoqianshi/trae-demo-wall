# 萌宠学堂 — 陪伴式虚拟宠物学习应用（MVP 演示版）

## 快速启动

```bash
cd mengchong-xuetang
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 核心路径测试

1. **宠物选择** → 首次打开自动进入，选择蛋生/卵生/种子类型 → 确认
2. **首页浏览** → 查看推荐视频和热门视频
3. **视频播放** → 点击任意视频卡片 → 进播放器 → 进度自动推进
4. **答题触发** → 播放至 1/3 和 2/3 处自动弹出答题 → 选择答案 → 提交
5. **宠物成长** → 答题正确后成长值增加 → 达到阈值自动进化
6. **家长中心** → 点击"家长中心"按钮 → 查看学习报告/管控设置
7. **宠物小屋** → 点击顶部宠物名称/图标 → 切换背景/家具/服饰
8. **成长记录** → 家长管控页中点击"成长记录"
9. **远程休息** → 家长端点击"该睡觉了" → 播放器中显示休息提示

## TV 遥控器操作

- **方向键（←→↑↓）**：在可聚焦元素间导航
- **确认键（Enter）**：点击当前聚焦元素
- **返回键（Escape/Backspace）**：返回上一页面

## 技术架构

| 文件 | 职责 |
|------|------|
| `index.html` | 应用入口，ECharts 图表初始化 |
| `css/style.css` | 完整样式系统（TV 焦点、动画、响应式） |
| `js/data.js` | 数据层（视频库、题库、宠物定义、房间装饰） |
| `js/app.js` | 核心逻辑（状态管理、路由、TV 引擎、全部屏幕渲染） |
| `assets/` | 图片资源（宠物成长插画、房间背景） |

## 合规设计要点

- 不设积分、不设等级、不设排行榜
- 宠物仅被动响应学习行为，不索取不催促
- 宠物小屋页面标注"不可交易、不可兑换法定货币、不可在用户间转让"
- 仅采集学习行为数据（观看/答题记录），不采集敏感信息
- 无广告、无外链、无第三方导流
- 22:00-06:00 法定不可用时段
