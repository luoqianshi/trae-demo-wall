高校智慧图书馆管理系统

智阅书馆

博观而约取 · 厚积而薄发

一套面向高校场景的智慧图书馆管理系统，采用前后端分离架构，涵盖智能身份识别、全流程借阅追踪、逾期催还推送、60天续借硬限制等核心能力，让图书管理从"被动记录"走向"主动服务"。

Vue 3 Element Plus Pinia Vue Router Axios ECharts Spring Boot MyBatis JWT MySQL 前后端分离 RESTful API

Core Features

十一大核心功能模块

从智能登录到逾期催还，覆盖图书馆管理全链路

🔐
MODULE 01

统一登录系统

智能身份识别

一个登录页面同时支持管理员和读者登录。后端 unifiedLogin() 方法先查 admin 表，再查 reader 表，自动判断身份返回 role 字段（ADMIN/USER），前端根据 role 跳转不同首页。无需区分入口，一个账号搞定一切。

📊
MODULE 02

管理员仪表盘

数据一目了然

ECharts 可视化数据看板，实时展示馆藏总量、可借总量、读者总数、活跃读者数、借阅中数量、逾期数量、总借阅次数、分类数量等核心指标。一键更新逾期状态，管理员决策有数据支撑。

📚
MODULE 03

图书管理

全生命周期管控

图书的增删改查，支持按书名/作者/ISBN关键词搜索和分类筛选。分页展示，库存状态实时更新。借阅时自动减少可借数量，归还时自动增加，库存一致性有保障。

🗂️
MODULE 04

分类管理

知识体系构建

图书分类的增删改查，分类与图书一对多关联。支持分类筛选查询，让馆藏结构清晰有序。

👥
MODULE 05

读者管理

精细化权限控制

读者信息的增删改查，支持关键词搜索。每个读者可设置最大借阅量（默认5本）、启用/禁用状态，精准管控借阅权限。

📋
MODULE 06

借阅管理

全流程追踪

管理员端查看全馆借阅流水，支持关键词搜索和状态筛选（借阅中/已归还/已逾期）。管理员可代借代还、一键更新逾期状态、对逾期记录发送催还通知。

📖
MODULE 07

读者自助借阅

一键完成

读者在图书查询页搜索图书，点击借阅按钮，选择借阅天数（1-90天），确认后在线完成借阅。系统自动校验：图书存在 → 库存充足 → 读者正常 → 未达借阅上限。借阅额度实时提醒，达到上限自动预警。

🔄
MODULE 08

智能续借

60天硬限制

读者可在线续借，选择续借天数。前后端双重校验：使用 ChronoUnit.DAYS.between() 按日历天精确计算，总借阅天数（含续借）不超过60天。逾期图书也可续借，续借后状态自动恢复为借阅中。

🔔
MODULE 09

逾期催还系统

主动提醒机制

管理员对逾期记录点击"催还"，系统标记 reminded=1。读者下次登录进入系统时，自动弹出催还提醒弹框，显示逾期书名和应还日期。读者确认后清除提醒。从"被动等待"到"主动推送"。

✍️
MODULE 10

读者注册

合规校验

读者自主注册，自动生成借书证号（格式：R+年月日+序号）。完整表单校验：用户名（3-20位字母数字下划线）、密码（6-20位含字母和数字）、确认密码一致性、姓名（2-10位中文英文）、性别、手机号（11位1[3-9]开头）、邮箱（合法格式）。

🔑
MODULE 11

JWT双端独立鉴权

安全隔离

管理员与读者使用独立Token，路由守卫自动分流。请求拦截器根据URL前缀自动选择对应Token，401响应也区分跳转。双端互不干扰，安全性更高。

TRAE Experience

TRAE使用心得

五条实战经验，让AI辅助开发更高效

01

分层架构先搭骨架再填肉

先用TRAE生成Controller-Service-Mapper的基础框架和CRUD模板，验证数据库连通后再逐模块追加业务逻辑。每次只做一层，出bug的概率大幅降低。

02

提示词要包含完整的数据库表结构

给TRAE的提示词不是"帮我做个借阅功能"，而是完整的表结构（字段名、类型、约束）+ 业务规则（借阅上限5本、续借最长60天、逾期自动标记）。结构越清晰，生成的代码越准确。

03

Bug修复要描述症状而非猜测原因

用户端点击图书查询跳转到管理员登录页，描述的是"点击后页面跳转到了/login而非/user/home"，TRAE分析出是"请求走了/api/categories用了管理员Token，401后跳管理员登录页"，给出了新增/api/user/categories接口的修复方案。

04

前后端同时开发时注意Token隔离

管理员和读者使用不同Token（localStorage的token和userToken），请求拦截器需要根据URL前缀自动选择。这个设计决策在初期就要确定，否则后期改造成本很高。

05

数据库字段变更要同步三处

新增reminded字段时，需要同步修改：Entity类（加字段）、Mapper XML（加resultMap映射）、init.sql（加列定义）。漏改任何一处都会报"Unknown column"错误。TRAE可以帮助批量修改，但需要明确指出所有需要修改的文件。
