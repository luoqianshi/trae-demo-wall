# UI 实现说明 — 快讯包装生成器

## 设计决策

### 1. 框架选择：纯原生 HTML/CSS/JS

- 零依赖，无需 npm install
- 单文件 index.html 即可运行
- 所有 JS 模块通过 IIFE 模式挂载到 `window` 对象
- 模块间通过全局 `AppState` 通信

### 2. 状态管理：发布/订阅模式

- `AppState` 提供 `get` / `set` / `on` 方法
- 每个模块监听自己关心的状态变化
- 避免模块间直接依赖

### 3. CSS 架构

- CSS 变量管理所有颜色、尺寸、间距 Token
- BEM 命名规范
- 主题切换通过 `data-theme` 和 `data-accent` 属性控制 CSS 变量覆盖
- 6 个 CSS 文件按职责分离

### 4. 主题系统

两层主题切换：
- **亮度主题**：`data-theme="dark"` / `data-theme="light"`
- **强调色主题**：`data-accent="amber"` / `data-accent="blue"`
- 两层独立切换，组合出 4 种视觉效果

## 组件状态流

### 文稿输入区
```
初始状态 → 输入文本 → 字数更新 → 点击"AI 识别" → 按钮 loading
         → 识别完成 → 按钮恢复 → 结果卡片出现
         → 识别失败 → Toast 错误提示
```

### 识别结果卡片
```
空状态 → 有结果 → 渲染卡片列表
卡片点击 → 选中高亮 → 预览区更新
删除 → 确认移除 → 列表更新
上移/下移 → 数组重排 → 列表更新
编辑 → prompt 弹窗 → 文本更新
```

### 预览区
```
占位状态 → 选中包装点 → 预览渲染
播放 → 进度条动画 → 3秒后自动停止
模板切换 → 预览内容更新
强调色切换 → 预览重新渲染
```

### 导出控制台
```
就绪 → 点击导出 → 按钮 loading → 进度条更新
→ 渲染中 → 任务列表更新
→ 完成 → 下载按钮激活
→ 失败 → Toast 错误 + 任务标记失败
```

## 交互反馈清单

| 交互 | 反馈方式 |
|------|----------|
| 按钮 hover | 背景色变化 + 边框高亮 + 阴影 |
| 按钮 active | translateY(1px) 下压 |
| 按钮 loading | 文字消失 + 旋转圆环 |
| 按钮 disabled | opacity 0.5 + cursor not-allowed |
| 卡片 hover | 边框变强调色 + 背景微亮 |
| 卡片 selected | 边框强调色 + 发光背景 + 外发光 |
| 输入框 focus | 边框变强调色 + 外发光 |
| Toast | 滑入动画 + 状态色左边框 + 自动消失 |
| 进度条 | 平滑过渡 + 百分比文字 |
| 空状态 | 虚线边框 + 引导文字 |

## 技术债务 & 后续优化

1. **预览区模板渲染**：当前为内联 CSS 模拟，需替换为真实模板 HTML/CSS
2. **拖拽排序**：当前为上移/下移按钮，后续可升级为 HTML5 Drag & Drop
3. **批量导出**：当前仅导出第一个包装点，后续需支持全队列导出
4. **键盘快捷键**：如 Ctrl+Enter 触发识别、空格键播放/暂停
5. **响应式**：当前 900px 以下为折叠布局，但移动端体验需进一步优化
6. **本地持久化**：文稿和结果可存入 localStorage，刷新不丢失
7. **导出格式**：分辨率和帧率当前固定显示，后续可开放自定义

## 浏览器兼容性

- 目标浏览器：Chrome 90+, Edge 90+, Safari 15+
- 使用 CSS 变量、Flexbox、ES6+ 语法
- 不支持 IE 11
