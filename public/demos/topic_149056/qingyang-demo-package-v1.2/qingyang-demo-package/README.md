# 轻养助手 · 健康管理应用 Demo

> 基于AI的个性化饮食与运动健康管理系统

---

## 📋 项目简介

轻养助手是一款集饮食调养、运动健身、AI智能推荐于一体的健康管理应用。
系统基于用户的健康档案（BMI、血压、血糖、血脂等指标），结合67道精选食谱和44项专业运动，
为用户提供个性化的健康管理方案。

### 核心功能

| 功能模块 | 说明 |
|---------|------|
| 🍲 饮食调养 | 67道精选食谱，支持按健康状况和餐次筛选 |
| 🏃 运动健身 | 44项专业运动，含新手入门专区 |
| ✨ AI智能推荐 | 根据健康档案智能推荐，按分类清晰展示 |
| 📊 健康档案 | 记录身高、体重、血压、血糖等健康指标 |
| 📅 方案生成 | 自动生成30天个性化健康方案 |
| ✅ 打卡追踪 | 每日任务打卡，追踪完成进度 |
| 👥 社区互动 | 发帖、评论，与其他用户交流 |
| 🏆 成就系统 | 积分、排行榜、成就解锁 |

## 🚀 快速开始

### 环境要求

- **Node.js**：版本 14.x 或更高（推荐 18.x / 20.x / 22.x / 26.x）
- **操作系统**：Windows / macOS / Linux 均可
- **浏览器**：Chrome / Edge / Firefox 等现代浏览器

> 💡 本项目使用 **sql.js**（纯JavaScript实现的SQLite），**无需编译**，任何系统都能直接运行。

### 安装与启动

1. **解压项目** 到任意目录，例如 `C:\qingyang-demo`

2. **打开命令行**（CMD或PowerShell），进入项目目录：
   ```bash
   cd C:\qingyang-demo
   ```

3. **安装依赖**（首次运行需要，后续可跳过）：
   ```bash
   npm install
   ```

4. **启动服务**：
   ```bash
   npm start
   ```

5. **看到以下输出表示启动成功**：
   ```
   ========================================
     轻养助手APP - 测试版后端服务
     服务器运行中: http://localhost:3000
   ========================================
   ```

6. **打开浏览器访问**：http://localhost:3000

## ❓ 常见问题

### Q: 端口3000被占用怎么办？
A: 设置环境变量后启动：
```bash
# Windows CMD
set PORT=3001 && npm start

# PowerShell
$env:PORT=3001; npm start
```

### Q: npm install 失败怎么办？
A: 检查网络连接，或使用国内镜像：
```bash
npm install --registry=https://registry.npmmirror.com
```

### Q: 页面显示空白怎么办？
A: 按F12打开控制台查看错误，确认后端服务是否正常启动。

### Q: 忘记演示账号密码怎么办？
A: 演示账号：`demo` / `demo123`。也可以自行注册新账号。

### Q: 数据库文件在哪里？
A: 数据库文件位于 `data/qingyang.db`，删除后重新启动会自动重建（含演示账号）。

### Q: 数据会自动保存吗？
A: 会的。系统每30秒自动保存一次数据库，程序退出时也会自动保存。
