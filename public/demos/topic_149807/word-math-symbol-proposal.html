方案介绍

基于纯 C 后端、JSON 符号库与浏览器/VBA 双端客户端的轻量级数学符号工具。

01 · 创意名称与介绍

Word 数学符号智能插入与管理插件（Word Math Symbol Quick Insert）解决理工科论文、实验报告与作业中频繁输入希腊字母、积分号、上下标、矩阵符号的痛点。项目以纯 C 语言 HTTP 服务为后端，维护一个 3321 条符号的 JSON 数据库；前端提供浏览器客户端与 Word VBA 宏插件两种入口，支持拼音/英文名/LaTeX 搜索、分类浏览、上下标组合、收藏与最近使用，并以富文本一键复制到 Word。

02 · 目标用户与痛点

目标用户：高校学生、科研人员、教师与助教。核心痛点是 Word 自带公式编辑器操作路径长、LaTeX 支持有限，输入一个 “α̂ₖ₊₁” 往往需要多次菜单点选与格式调整，打断写作思路。

03 · 价值与意义

效率价值：把 20–30 秒的符号插入流程压缩到 3 秒以内；通过 LaTeX 别名与智能搜索降低记忆成本。学习价值：纯 C 实现网络服务、手写 JSON 解析与 HTTP 路由，是低外部依赖、高系统理解的编程实践。社会价值：工具零外部依赖，仅占用本地回环端口，适合机房、图书馆等公共环境。

04 · 产品形态与技术实现

产品形态为 “本地微服务 + 双端客户端”。提交包解压后双击 start_demo.bat 即可启动服务并打开浏览器。

  • mathsymbol.exe：监听 127.0.0.1:9876，提供 /search、/symbol、/compose、/categories 等 REST 接口。
  • symbols.json：覆盖 24 个分类、3321 个符号；已清洗 1876 个被编码的符号名称并保留旧名作为别名。
  • MathSymbolClient.html：浏览器端搜索面板，支持 HTML 富文本复制。
  • MathSymbolInserter.bas：Word VBA 宏源码，支持快捷键快速插入、批量插入与 LaTeX 转换。
  • start_demo.bat / README_DEMO.md：一键启动脚本与 1 分钟快速体验指南。

05 · Demo 交付与复现性

当前 Demo 已升级为 可独立运行、可复现 的提交包。解压 WordMathSymbolPlugin_提交版.zip 后双击 start_demo.bat，脚本会自动启动后端服务并打开浏览器。在 “符号组合器” 中输入 base=x、sup=2、sub=i，即可看到组合结果 x²ᵢ 并一键复制。

06 · 项目迭代亮点

  • 数据清洗：修复 1876 个被编码的符号名称，保留旧名作为 alias。
  • 功能完善：新增上下标自动转换，/compose/text 可直接输出 Unicode 组合。
  • 缺陷修复：修复 /compose 单字符别名冲突、HTML 收藏同步、XSS、VBA URL 编码、服务端启动目录等 7 处问题。
  • 复现性保障：服务端启动时自动切换工作目录，任意目录启动均可加载资源。
  • 体验优化：新增一键启动脚本、Demo 指南与演示截图，1 分钟内即可上手。

07 · 未来展望

下一步计划引入更智能的拼音联想、手写公式识别接口、Word 加载项（Office.js）以及符号收藏云端同步，持续降低学术写作与排版的技术门槛。
