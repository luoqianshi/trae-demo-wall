粘贴聊天记录

把你们的聊天记录复制粘贴到下面。Devil 会从中分析 30 个维度，判断你们的关系状态。

🔒 所有数据仅在本地分析，通过你的 API 直接调用大模型，不会经过任何第三方服务器。
📱 不知道怎么导出微信聊天记录？点这里看教程 ▼
问题：手机上的微信聊天记录，电脑版微信经常没有完整同步过来。
原因：微信电脑版只同步最近几天的消息，更早的记录只在手机本地存着。
解决：下面提供了 4 种方法，从最简单到最完整，按你的情况选。
😈 Devil 说：聊天记录越多，我分析得越准。少于 500 字我基本没法判断，少于 2000 字我只能给个大概。想要精准分析，至少给我 1-2 周的完整对话。表情包多的对话也没关系，我能从上下文推断。
方法一：电脑版微信直接拖选复制（最简单，适合近期聊天）
适用：你们最近几天聊得多，电脑版微信能看到
1. 打开电脑版微信，进入和她的聊天窗口
2. 鼠标在消息上拖选（像选文字），从第一条拖到最后一条
3. 右键 → 复制
4. 回到这里粘贴
缺点：只能拿到电脑版同步过来的消息，可能不全
😈 Devil 建议：如果你们聊了超过一周，电脑版大概率只有最近几天的。这种情况下直接看方法二，别浪费时间拖选了。
方法二：留痕 / WeChatMsg 等开源工具导出（最完整，推荐）
适用：聊天记录很多，想要完整导出几个月甚至几年的记录

原理：这类工具在电脑上运行，通过扫码获取手机微信的本地数据库，把所有聊天记录一次性导出成文本文件。

步骤：
1. 在电脑上下载工具（推荐开源工具"WeChatMsg" / "留痕"，GitHub 搜索即可）
2. 运行工具，它会显示一个二维码
3. 手机微信扫码授权（和微信登录电脑版一样的操作）
4. 工具自动读取手机里的聊天记录数据库
5. 选择要导出的聊天对象，导出为 txt 文本
6. 打开导出的 txt 文件，Ctrl+A 全选 → Ctrl+C 复制
7. 回到这里粘贴

优点：能拿到手机上所有聊天记录，包括很早之前的
缺点：需要下载安装工具，有一定操作门槛
😈 Devil 强烈推荐：这是唯一能拿到完整聊天记录的方法。手机微信多选合并转发限制 100 条，还有表情包根本转不出来，别费那个劲了。下个工具扫码导出，几分钟搞定几个月的记录，数据量越大我分析越准。
方法三：微信聊天记录迁移到电脑再导出
适用：手机存储不够，想把记录迁移到电脑
1. 手机微信 → 我 → 设置 → 聊天 → 聊天记录迁移与备份
2. 选择"迁移到电脑"
3. 等待迁移完成
4. 迁移完成后，电脑版微信就能看到所有历史消息
5. 再用方法一拖选复制即可
缺点：迁移过程需要一些时间，取决于聊天记录大小
😈 Devil 建议：迁移完之后还得用方法一拖选复制，等于多了一步。如果你已经打算折腾了，不如直接用方法二，一步到位。
方法四：QQ / 牵手 / 陌陌 / Soul 等其他平台
QQ：电脑版 QQ 聊天窗口直接 Ctrl+A 全选 → Ctrl+C 复制，最简单
牵手 / 陌陌 / Soul：这些 App 没有电脑版，建议用手机截长屏功能截图，然后用 OCR 工具（如微信扫一扫）识别文字，手动整理后粘贴
😈 Devil 建议：牵手、陌陌这类平台的聊天记录一般不长，直接截图 + 微信扫一扫 OCR 识别就行。不用搞太复杂。
格式说明
不需要特殊格式，只要能看出谁说的就行。比如：
我：在干嘛
她：刚下班
我：晚上一起吃饭？
她：再说吧
Devil 会自动识别"我"和"她/他/对方/对方昵称"等说话人标识。如果导出的记录带时间戳也没关系，不影响分析。
😈 Devil 提醒：表情包、图片消息、语音转文字的内容我都能处理。如果导出的记录里写着"[图片]""[语音]""[表情]"也没关系，我会结合上下文判断。
已输入 0 字（建议 500 字以上）
