# 美食捕手 Demo

一款轻量级美食收藏与打卡小程序 Demo，基于纯原生 HTML/CSS/JS 开发，模拟手机端体验。

## 技术栈

| 类别 | 技术 |
|------|------|
| HTML5 | 语义化标签 + 模板字符串渲染 |
| CSS3 | CSS 变量、Flexbox、动画、响应式 |
| JavaScript | ES2020+，IIFE 模块化，无框架依赖 |
| 数据持久化 | localStorage |
| 路由方案 | Hash 路由 + 页面栈管理 |

**零依赖** — 无需 npm install，无需构建工具，开箱即用。

## 环境要求

- 任意现代浏览器（Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+）
- Python 3.x（用于启动本地 HTTP 服务器，也可替换为 Node.js / Live Server 等）

## 快速启动

### 方式一：Python 服务器（推荐）

```bash
# 进入项目目录
cd food-catcher-demo

# 启动 HTTP 服务器
python -m http.server 8090

# 浏览器打开
# http://localhost:8090/index.html
```

### 方式二：Node.js 服务器

```bash
cd food-catcher-demo
npx serve -p 8090
```

### 方式三：VS Code Live Server

安装 Live Server 插件 → 右键 `index.html` → Open with Live Server

### 方式四：直接打开

直接双击 `index.html` 即可在浏览器中运行（部分浏览器可能限制 localStorage 的 file:// 协议，推荐使用 HTTP 服务器）。

## 功能演示路径

### 核心流程

1. **首页浏览** — 打开页面自动跳转首页，展示美食列表、统计栏、筛选标签
2. **添加美食** — 点击右下角橙色 `+` 按钮 → 填写名称（必填）、地点、分类、备注 → 保存
3. **查看详情** — 点击任意美食卡片 → 进入详情页，查看完整信息
4. **编辑美食** — 详情页点击「编辑」→ 修改信息 → 保存
5. **打卡评分** — 详情页点击「去打卡」→ 选择星级 → 提交打卡
6. **删除美食** — 详情页点击「删除」→ 确认弹窗 → 删除
7. **快捷操作** — 首页列表中点击 ✓/↩ 按钮快速切换状态，点击 🗑 快速删除

### Tab 切换

- **首页** — 美食列表，支持「全部 / 待探索 / 已尝试」筛选
- **发现** — 按分类浏览美食（中餐、日料、韩餐、火锅、甜品、咖啡等）
- **我的** — 个人打卡历史，时间线展示已尝试美食及评分

### 边界场景

- 表单未填名称 → 红色边框 + 错误提示
- 访问不存在的美食 → 显示「美食不存在」空状态
- 列表为空 → 显示空状态引导

## 架构设计

### 状态管理

采用中心化 Store + 发布订阅模式：

```
Store (state) ──subscribe──> Page.render()
     ↑                            |
     |                            | 更新 DOM
     |                            ↓
Actions (CRUD) ──setState──> Store.notify() ──> 所有订阅者
```

- `Store` 持有全局状态，每次变更自动写入 localStorage
- `Actions` 封装所有业务逻辑，调用 `Store.setState()` 触发更新
- 页面通过 `Store.subscribe(render)` 订阅状态变化，自动重渲染

### 路由系统

- **Tab 页面**（首页/发现/我的）：切换时清空页面栈
- **Stack 页面**（详情/表单/打卡）：支持 push/pop，返回上一页
- URL 格式：`#/home`、`#/detail/1`、`#/add`、`#/edit/1`、`#/checkin/1`

### 数据模型

```javascript
// FoodItem
{
  id: 1,              // 唯一 ID
  name: "兰州牛肉面",  // 名称（必填）
  place: "城关区张掖路", // 地点（可选）
  tag: "中餐",         // 分类
  done: false,         // 是否已尝试
  createdAt: 1234567,  // 创建时间戳
  note: "汤清面劲道",   // 备注（可选）
  checkIn: {           // 打卡信息（null 表示未打卡）
    date: 1234567,     // 打卡日期
    rating: 5,         // 评分 1-5
    photo: "",         // 照片（预留）
    note: "名副其实"    // 打卡备注
  }
}
```
