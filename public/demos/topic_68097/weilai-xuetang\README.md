# 未来学堂 - AI驱动的沉浸式学习协作平台

## 快速开始

### 方式一：一键启动（推荐）

双击运行 `start.bat` 即可自动启动前后端服务。

### 方式二：手动启动

**启动后端：**
```bash
cd backend
npm install
node server.js
```

**启动前端：**
```bash
cd frontend
npm install
npm run dev
```

## 访问地址

- 前端页面：http://localhost:3001
- 后端接口：http://localhost:3003

## 功能体验

1. **首页**：浏览教室主题卡片，查看核心功能入口
2. **教室**：点击教室主题卡片预览效果，创建教室进入沉浸式学习空间
3. **课程**：浏览AI课程和文化课，选择课程开始学习
4. **我的课程**：查看已选课程和学习进度
5. **证书**：查看已获得的学习证书

## 核心功能

- 🎨 **沉浸式主题教室**：海滨、森林、山林、书房四种主题，全屏背景+背景音乐
- 📹 **摄像头/麦克风**：支持开启摄像头和麦克风，实现面对面学习交流
- ⏱️ **专注计时器**：透明玻璃拟态设计，支持多档时长选择
- 📝 **AI智能判卷**：拍照上传试卷，自动判分并讲解错题
- 📚 **系统化课程**：AI课程+文化课双轨并行，完整学习路径

## 技术栈

- 前端：Vue3 + Vite + Element Plus + Vue Router
- 后端：Node.js + Express + SQLite + Socket.io
- 认证：JWT
