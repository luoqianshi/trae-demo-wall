# 串点路书 — 旅行路线自由编排工具

## 体验方式

双击 `index.html`，用浏览器（推荐 Chrome / Edge）打开即可使用，无需安装任何软件，无需注册或填写 API Key。

## 功能说明

1. **添加候选点**：在顶部搜索框输入地名（如"天安门"），或在地图上直接点击任意位置
2. **串联路线**：依次点击底部候选点卡片，按你想要的顺序串成驾车路线
3. **自动算耗时**：每段路程的距离和开车时间自动计算，显示总耗时
4. **保存多路线**：不同顺序的方案可分别保存为"路线1""路线2"，点击切换对比
5. **抽屉拖拽**：拖动底部面板把手，可停靠在收起 / 半屏 / 全屏三档位置

## 技术栈

全部基于免费开源服务，打开即用：

- 地图瓦片：OpenStreetMap
- 地点搜索：Nominatim
- 驾车路线：OSRM 公共路由服务器

## 备注

- 需要联网使用（地图瓦片和路线计算依赖在线服务）
- 数据保存在浏览器本地，刷新不会丢失
- 首次打开预置了 7 个北京景点作为演示数据
