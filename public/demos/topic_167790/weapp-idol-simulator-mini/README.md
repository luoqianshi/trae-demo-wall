# 星耀 · 偶像成长手账 — 微信小程序

养成系偶像生活模拟游戏。10 季 15 天一循环,10 季毕业。每天 2-5 段随机公司日程,粉丝群聊 + 1v1 邮件 5 天时限,15 天排名结算。

## 项目结构

```
weapp-idol-simulator-mini/
├── app.js              # 全局状态 + 持久化
├── app.json            # 路由 + tabBar
├── app.wxss            # 全局样式
├── sitemap.json
├── project.config.json
├── utils/
│   └── game.js         # 共享游戏逻辑(日程/邮件/房间/排名)
├── wxs/
│   └── utils.wxs       # WXML 工具
├── pages/
│   ├── index/          # 首页:今日日程
│   ├── flip/           # 翻牌:1v1 信箱
│   ├── room/           # 房间:粉丝群聊
│   └── me/             # 我的:属性面板
└── assets/             # tabBar 图标(可放本地图片)
```

## 在微信开发者工具中运行

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开 → **导入项目**
3. 项目目录:选 `weapp-idol-simulator-mini/`
4. AppID:选择 **测试号** (无 AppID 也能跑)
5. 项目名称:`星耀`
6. 点击 **导入**
7. 编译即可在模拟器中体验

## 核心机制

| 模块 | 说明 |
|------|------|
| 时间 | 1 秒 = 1 游戏分钟,10:00–24:00 |
| 日程 | 每天 2-5 段随机,每段 90-180 分钟,段间 30 分钟休息 |
| 提前参加 | 10:00 可点后续活动,直接跳到结束时间 |
| 邮件 | 5 天未回 → 粉丝好感 -5 |
| 房间 | 持久聊天记录,心情/人气高时刷屏更频繁 |
| 排名 | 每季 15 天结算,50 人排名,前 16 入围 |
| 退团 / 毕业 | 不入围可选退团或继续下季,10 季后毕业 |

## 核心属性

- 🎤 **唱功** · 💃 **舞蹈** · 💗 **心情** · 📈 **人气(隐藏)** · 🫶 **粉丝好感(隐藏)**
- 玩家可见 3 个(唱功/舞蹈/心情),人气和粉丝好感隐藏
- 属性变化有随机性(±50% 浮动,20% 概率反转),心情/人气高时房间更活跃

## 状态持久化

所有数据通过 `wx.setStorageSync('idolState', ...)` 存本地,关掉小程序再打开继续。
