# 我的宝贝房子 - 离线版

## 使用说明

1. 解压本压缩包到任意文件夹
2. 使用浏览器打开 index.html 文件
3. 即可离线使用全部核心功能

## 项目信息

- 导出日期: 2026-07-13
- 版本: v1.0.0
- 项目类型: 装修进度管理与养成系统

## 功能特点

- 装修流程管理 (SOP)
- 预算管理
- 知识库
- 工具箱
- 我的家 (2.5D场景 + 角色养成)
- 成就系统
- 每日任务
- 收集图鉴
- 资产装扮

## 离线使用说明

### 完全离线可用的功能
- 装修流程管理
- 预算管理
- 知识库
- 工具箱
- 我的家 2.5D 场景
- 成就系统
- 每日任务
- 数据导入导出

### 需要联网的功能
以下功能需要联网才能正常使用：
- Tailwind CSS 样式（CDN加载）
- PDF 导出功能（jsPDF CDN）
- 截图分享功能（html2canvas CDN）
- 3D 小灯泡角色（Three.js CDN，已内置本地版本，优先本地加载）

### 如果样式不显示怎么办？
本项目使用 Tailwind CSS CDN 版本，如果离线环境无法加载 CDN，
部分样式可能无法正常显示。核心功能仍然可用。

## 浏览器兼容性

推荐使用以下浏览器：
- Chrome / Edge 90+ （推荐）
- Firefox 88+
- Safari 14+

注意：不建议使用 IE 浏览器。

## 数据存储

本应用使用浏览器本地存储 (localStorage) 保存数据，
数据存储在您的浏览器中，不会上传到任何服务器。

建议定期使用「设置」-「导出数据」功能备份您的数据。
