# 视觉规范速查 · 小满的夜灯（深夜暖光风）

> 与 PRD §5 完全一致的单页速查。氛围 = 深夜里为孩子亮起的一盏暖灯：深蓝夜色底 + 暖黄灯光 + 暖玫点缀。这是一个**聊天界面**——IM 质感，但配色走暖光夜色。

## 色板（CSS 变量，严格照抄）

```css
:root {
  --ink:         #0e1626;  /* 群聊背景·墨蓝夜色 */
  --ink-2:       #13203a;  /* 次级深蓝 */
  --bubble-in:   #1b2742;  /* 别人/机器人气泡底 */
  --bubble-me:   #3a2e1a;  /* 我发的气泡底（暖调） */
  --card:        #1b2742;  /* 卡片消息底 */
  --glow:        #ffd592;  /* 夜灯暖黄·机器人主色/记录线 */
  --glow-strong: #ffb65c;  /* 暖橙·紧急模式/判重高亮 */
  --milk:        #fff6e6;  /* 奶白 */
  --milkgreen:   #bfe3c8;  /* 奶绿·循证标 */
  --rose:        #f6b9c6;  /* 暖玫·记忆线/相册子屏主色 */
  --rose-deep:   #e88aa0;
  --text:        #f3ede0;  /* 主文字·暖白 */
  --text-dim:    #b9c2d6;  /* 次文字 */
  --r: 22px;  --r-sm: 14px;
}
```

- 气泡圆角 `18px`；卡片阴影 `0 18px 50px -20px rgba(0,0,0,.7)`
- 字体：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`

## 组件速查

| 组件 | 要点 |
|---|---|
| 手机外框 | 375–430px 竖屏，圆角 ~44px，顶部状态栏示意；桌面居中夜色渐晕 |
| 夜灯头像 | 纯 CSS `radial-gradient` 发光小夜灯 + 底座，3s 呼吸光晕，群里最亮 |
| 成员头像 | 32–36px 圆形渐变底 + emoji（👩👨👵🤱） |
| 气泡 | 他人左 `--bubble-in` / 我方右 `--bubble-me`，最大宽 78% |
| 卡片消息 | `--card` + `--r` + 统一阴影，宽 ~88% |
| 日龄滑块 | 轨道 `--ink-2`、已滑段 `--glow` 渐变、拇指=夜灯光点 |
| 倒计时卡 | `--glow-strong` 描边 + 半透明暖橙底，`tabular-nums` 数字 |
| 徽章 | 循证=奶绿底、辟谣=暖黄底、维度=描边胶囊，12px 圆角胶囊 |

## 两束光颜色纪律

- **记录线**（拍照判重/早报/紧急/问答）→ `--glow` / `--glow-strong`
- **记忆线**（相册子屏/回声彩蛋）→ `--rose` / `--rose-deep`

## 动效清单（全 CSS/最小 JS，禁大型动画库）

扫描光带 · 判重合并收拢 · 回执 stagger 淡入（150ms 递增）· 倒计时呼吸脉冲 · 屏间横滑（translateX 300ms ease）· 回声条淡入淡出。动画只动 `transform`/`opacity`。
