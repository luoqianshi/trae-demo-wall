KnowFlow · 个人知识库 RAG 智能问答 Agent - 交互演示版
================================================

【使用方法】
直接用浏览器打开 index.html 即可体验，无需安装任何环境。

【可体验的功能】
1. 欢迎页 — 展示产品功能介绍
2. 模拟对话 — 点击功能卡片或建议问题触发对话
3. Agent 工具调用动画 — 展示 Agent 思考和调用工具的过程
4. Markdown 渲染 — 支持标题、代码块、表格、引用等格式
5. 深色/浅色主题切换 — 点击右上角月亮/太阳按钮
6. 侧边栏 — 展示会话列表、上传区域、服务状态

【预设演示问题】
- RAG 的工作流程是什么？
- Agent 有哪些工具？
- 今天有什么需要复习的？
- 最近一周学了什么？
- 什么是混合检索？

也可以在输入框输入其他问题，会返回通用演示回答。

【关于完整版】
本演示版本仅包含前端交互效果，数据为预设示例。
完整版本包含：
- 真实的后端服务（NestJS）
- PostgreSQL + pgvector 向量数据库
- 支持上传 PDF/Markdown/TXT 文档
- 真实的 LLM 对话和 Agent 工具调用
- 用户认证系统
- SM-2 间隔复习算法

完整项目源码：https://github.com/LXKovo/KnowFlow
