# 体育场地智能布置助手 - Demo使用说明

## 快速开始
1. 解压zip文件
2. 用浏览器打开 index_pro.html
3. 无需联网，无需安装，打开即用

## 核心功能体验路径

### 1. 场地切换
页面顶部或左侧选择场地类型：足球全场/半场/5人制、篮球全场/半场、排球、田径跑道

### 2. 器材摆放
左侧面板点击器材（标志筒/跨栏架/绳梯/呼啦圈等9种）→ 在场地上点击放置

### 3. 队员管理
- 点击队员图标 → 场地上点击添加
- 8色切换：选中队员后点击颜色
- 快速添加：4人组/6人组/8人组一键生成
- 一键排队：横队/纵队/多路纵队/散开

### 4. 战术绘制
- 箭头工具：绘制跑动路线
- 曲线工具：绘制变速跑动
- 框选工具：批量选中
- 撤销/重做：反复调整

### 5. 导出保存
- 📷 PNG：高清截图，直接粘贴到教案
- 📹 视频：录制布置动画
- 💾 保存：存到资料库，下次复用

### 6. AI辅助
- 多模型切换：通义千问/DeepSeek/GPT-4/Claude 3/文心一言
- 语音输入：说出需求，AI辅助生成练习方案
