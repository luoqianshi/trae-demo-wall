# 爸妈说明书 - 老人手机说明书生成器

## 项目简介

子女上传 App 界面截图 + 说一句想教什么 → AI 识别界面元素、推理操作路径 → 生成超大字号、一步一图、箭头标注的教程。

## 核心特性

- **30秒极速生成**：AI识别截图+推理路径+标注箭头
- **互动练习模式**：爸妈端屏幕亮起提示点哪里，点对才进下一步（最佳演示点）
- **子女可编辑**：修改提示语、调整标注位置、录制语音解说
- **微信一键分享**：大字图文长图/解说视频/小程序卡片
- **教程广场飞轮**：优质教程共享，创作者积分激励
