## 三、关键风险与应对

### 高风险项（3项）

1. **AI标注准确率不足**（概率:中高, 影响:高）
   - 应对：POC阶段设置严格go/no-go标准（首次可用率≥50%）；编辑器调整体验做到极致；低置信度明确标注

2. **老人不会用互动练习**（概率:中, 影响:高）
   - 应对：元教程设计（教老人怎么用教程）；看图模式作为纯阅读备选；种子用户充分测试

3. **隐私安全**（概率:中, 影响:高）
   - 应对：PII自动脱敏（手机号/身份证/金额模糊）；用户可手动涂抹；隐私政策明确

### 中风险项（3项）

4. **微信小程序审核/限制**（概率:中, 影响:高）
   - 应对：提前了解类目要求；UGC审核机制；H5备选方案

5. **冷启动内容不足**（概率:高, 影响:中）
   - 应对：MVP阶段预置30-50个高频教程；种子创作者邀请；前期不依赖广场

6. **App版本更新导致识别率下降**（概率:高, 影响:中）
   - 应对：模型泛化训练；不绑定特定App版本；用户可随时重新生成

## 四、Go/No-Go决策标准

### POC阶段（3周）必须回答的问题：

- [ ] OmniParser/CogAgent在中文主流App截图上的元素检测准确率是否≥80%？
- [ ] GPT-4o/Claude推理出的操作步骤正确率是否≥70%？
- [ ] 端到端生成一份可用教程（箭头基本正确）的比例是否≥50%？
- [ ] 单次生成耗时是否≤30秒？
- [ ] 互动练习模式的Demo演示效果是否令人信服（团队内测评价≥4/5分）？

**Go决策**: 5项中≥4项通过 → 进入MVP开发  
**No-Go决策**: ≤3项通过 → 调整方案（如缩小到"AI辅助手动标注"模式）或暂停

## 七、演示建议（路演/评审场景）

**5分钟最佳演示路径**：

1. **痛点引入（30秒）**："大家有没有过在电话里教爸妈用手机的经历？'点那个蓝色按钮''哪个蓝色的？''就是那个...'半小时过去了还是没教会。"
2. **快速生成（1分钟）**：现场打开小程序，选3张微信截图，输入"教我妈挂协和的号"，AI 30秒生成带箭头教程。
3. **核心演示——互动练习（2分钟）**："现在请评委老师拿出手机扮演我妈——屏幕上只显示一个红圈在闪，您点那里。对！点对了出绿色对勾，点错了它会说'再试试'。就像玩游戏一样，练2遍就会了。"（这是最有记忆点的环节）
4. **一键分享（30秒）**：展示生成的小程序卡片直接微信发送，爸妈点开就能用。
5. **愿景收尾（1分钟）**："中国有3亿老年人，1.6亿已经上网但68%会因为操作复杂放弃功能。蓝马甲们人工录制了3000个教程，覆盖100个软件。但每个老人手机里有几百个App，长尾需求永远覆盖不完。我们让每个子女用30秒的耐心，服务全国的爸妈。"

## 八、最终建议

**结论：推荐立项，立即启动POC**

理由：
1. 痛点真实且普遍，情感共鸣强，社会价值大
2. 差异化清晰，无直接竞品
3. 互动练习模式是极具演示效果的杀手级功能
4. 技术方案虽有AI准确率风险，但有明确的验证标准和降级方案
5. MVP周期可控（3个月），投入产出比合理

**下一步行动**：
1. 组建3人POC小组（1名AI工程师+1名前端+1名产品）
2. 用2周时间跑通OmniParser+GPT-4o的端到端Demo
3. 第3周用20个真实场景测试准确率，做出Go/No-Go决策
