# 考研学习路线图生成器

一句话类比：把考研复习想成"盖房子"——先画图纸（盘需求），再按楼层分阶段施工（路线图），每层配工具清单和验收标准（资源+作业），最后贴一张全景进度图（Mermaid）。

## 工作流程

### 步骤 0：本 Skill 不联网（重要）
本 Skill 不依赖任何外部搜索 API（不需要 Exa、不需要 API Key、不需要联网）。所有路线图、题型、资源推荐都由 AI 助手基于通用考研知识直接生成。原因：沙盒环境无外网，且刘工不需要去申请任何付费 Key。

### 步骤 1：盘需求（收集用户信息）
用大白话问用户（可用 ask_user_question）：
1. 考什么科目：英二 / 管综（199）/ 还是都要？
2. 当前水平：零基础（比如逻辑从没学过）/ 有底子（比如数学忘得差不多了）
3. 目标：过线就行 / 冲高分
4. 每周学时（可选）：用户说"到时候再说"就跳过 ✅
5. 总周数（可选）：用户没说就跳过 ✅

若 4、5 都未填 → 自动套用"标准5个月四阶段通用路线图"：基础(7-8月)→强化(9-10月)→冲刺(11月)→模考(12月)。并在结尾提示"后续填上学时，可微调各阶段时长"。

### 步骤 2：AI 直接列资源（替代原 Exa 搜索）
不调脚本、不搜索。AI 基于知识直接给出每个科目的资源渠道，例如：
- B站课：数学/逻辑/写作名师系统课（列类型，不保证具体最新链接）
- 教材：官方/主流辅导书（标注"以你手头教材版本为准"）
- 真题：历年真题获取渠道（研招网/报考院校/主流教辅）
- 每个资源后标【待核对】：关键公式、年份、题型分值以你的教材和真题为准。

### 步骤 3：生成分阶段路线图
规划 4 个阶段（管综/英二通用四阶段；也可 4-8）。每阶段含：
阶段名称 / 学习目标 / 预计时长（有学时按学时算，无学时写"约X月"） / 推荐资源（带【待核对】） / 知识作业（选择题+问答题） / 实战作业（如做真题套卷、写论说文）。

阶段划分遵守"前一阶段是后一阶段地基"。具体模板见 references/考研科目与资源.md 的"分阶段模板示例"（管综逻辑=假言推理→论证逻辑→真题刷题；英二=单词→阅读长难句→翻译→作文）。

### 步骤 4：创建项目文件夹
工作目录下建 `考研路线图_<科目>/`，含总览 `学习路线图.md` + 每阶段子文件夹（学习指南.md / 知识作业.md / 实战作业.md）。文件名用中文，UTF-8。

### 步骤 5：输出 Mermaid 路线图
总览文档内放 Mermaid 图（graph TD），把四阶段串成一条线，起点=当前水平，终点=目标。

## 关键规则
1. 不编造内容：资源是 AI 推荐，凡关键定义/公式/题型分值/真题年份，一律以用户教材和真题为准，AI 引申内容须标【待核对】。
2. 作业具体可执行：选择题/问答题紧扣本阶段真知识点；实战作业给验收标准（如"限时做完1套管综逻辑30题，错≤5"）。
3. 时间可空：用户没填学时/周数，不得卡住，直接出通用路线图并提示补充。
4. 不联网承诺：全程不调用搜索脚本、不要求任何 Key。
5. 扩展性：图情(MLIS)专业课预留为扩展位，模板结构可照搬英二/管综，待用户启用。
