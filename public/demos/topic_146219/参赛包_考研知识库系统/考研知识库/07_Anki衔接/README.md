# 07 AI 助手 → Anki 衔接框架

> 这一层解决最后一步：**让我（AI 助手）帮你整理好的考点，变成手机上能刷的 Anki 卡**。
> 原理 = 两层：① AI 助手 生成卡 → 进电脑 Anki；② 电脑 Anki 通过 AnkiWeb 自动同步手机。

## 架构（两层）

```
[AI 助手 对话学考点]
        │ ① 生成卡片（见 卡片生成规范.md）
        ▼
[电脑 Anki]  ←── 方式A：手动导入 .txt/.apkg
        │         方式B：AnkiConnect 自动推送（见 anki_connect_push.py，待启用）
        │
        │ ② AnkiWeb 云同步（官方免费）
        ▼
[手机 Anki / AnkiDroid]  ← 随时刷
```

## 两条落地路线

| 路线 | 做法 | 自动化 | 现在就能用？ |
|---|---|---|---|
| **A 手动导入** | 我每天输出 Anki 可导入的卡片文件（TSV/CSV），你导入电脑 Anki，自动同步手机 | 半自动（导入点一下） | ✅ 现在 |
| **B 自动推送** | 电脑装 AnkiConnect 插件，我直接把卡写进 Anki，秒同步手机 | 全自动 | ⏸️ 待你装好 Anki + AnkiConnect |

## 本目录内容

| 文件 | 用途 |
|---|---|
| `卡片生成规范.md` | 卡片长什么样、标签怎么打、我每天怎么给你出卡 |
| `示例卡片_管综逻辑.txt` | 一份真考点 TSV，直接在 Anki 里"文件→导入"就能用 |
| `anki_connect_push.py` | 路线B 的自动推送脚本草案（待启用，需先装 Anki+AnkiConnect） |
| `启用清单.md` | 你啥时候环境齐了，按这个清单把自动推送打开 |
