# 考研知识库系统 · 使用说明

## 怎么打开

**方式一（推荐，最简单）**：双击 `index.html`，浏览器直接打开即可。无需安装任何东西。

**方式二（Flask启动）**：
```
pip install flask
python app.py
```
然后浏览器打开 http://127.0.0.1:5000

## 怎么玩（3分钟体验路径）

1. **打开页面** → 看到仪表盘，有欢迎语、进度条、连续打卡天数、今日推荐考点
2. **点「🚀 开始今日学习」** → 进入对话学习页面
3. **选一个考点**（比如"假言命题"）→ AI给出3要点+1道自测题
4. **答自测题** → AI给反馈
5. **点「📁 存入知识库」** → 笔记归档到对应分类
6. **点「🃏 生成Anki卡」** → 弹出卡片预览，点击卡片可翻转正面/背面
7. **回到仪表盘** → 点「📝 今日打卡」→ 连续天数+1
8. **自由探索** → 看知识库目录、翻Anki卡片、切换路线图四阶段

## 功能说明

- **仪表盘**：学习进度、连续打卡、每日推荐、四阶段进度条
- **对话学习（核心）**：6个考研考点（逻辑2+英二2+数学1+图情1），3要点+1自测结构化教学，学完可存库/做卡
- **知识库浏览**：7大分类目录树，预置11篇笔记，可切换Anki卡片列表
- **学习路线图**：基础/强化/冲刺/模考四阶段，显示目标/任务/资源

## 技术栈

- 后端：Python Flask（极简启动壳，纯静态文件服务）
- 前端：原生HTML/CSS/JavaScript（SPA单页应用）
- 数据持久化：localStorage（打卡/进度，刷新不丢）
- 无需API Key、无需联网、纯本地运行
