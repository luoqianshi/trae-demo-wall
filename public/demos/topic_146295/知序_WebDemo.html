命名规范

从混乱到有序，只需一套命名规则

Before - 混乱命名
📄 最终版.docx
📄 真的最终版 (2).docx
📄 新建文本文档.txt
📄 方案新新新新新.pdf
📄 复制 方案 - 副本.docx
📄 （无标题）新建文档.md
After - 规范命名
📄 20260712_产品方案_v2_done.docx
📄 20260710_需求文档_v3_wip.md
📄 20260708_会议记录_v1_done.md
📄 20260705_技术评审_v1_review.pdf
📄 20260701_资源整理_v2_done.xlsx
📄 20260628_学习笔记_v1_draft.md
规则 格式说明 示例
日期 格式 YYYYMMDD，确保按时间排序 20260712
主题 简短描述文件内容，用下划线分隔 产品方案
版本 v + 数字，从 v1 开始递增 v2
状态 wip(进行中) / done(完成) / draft(草稿) / review(待审) done
分隔符 所有字段用下划线 _ 连接 20260712_产品方案_v2_done
扩展名 保持原始扩展名小写 .docx / .md / .pdf

功能演示

四大核心功能，覆盖知识管理全流程

智能扫描 - 深度遍历指定目录，自动识别文件类型、大小、命名规范、重复文件等问题，生成全面的诊断报告。支持按文件类型过滤，可配置忽略规则。
命令行用法
# 扫描指定目录 zhixu scan --path ./my-knowledge-base # 扫描并输出详细报告 zhixu scan --path ./docs --report report.json # 扫描特定类型文件 zhixu scan --path ./notes --ext .md,.pdf
模拟运行输出
[INFO] 知序 v1.0.0 - 知识库扫描工具 [INFO] 开始扫描目录: ./my-knowledge-base [SCAN] 正在遍历目录结构... [SCAN] 发现 18 个文件, 20 个目录 [SCAN] 文件类型: .md(7) .pdf(2) .jpg(2) .zip(2) .exe(1) .txt(1) .py(2) .json(1) [SCAN] 总大小: 10.0 MB [WARN] 发现 1 组重复文件 (SHA256匹配) [WARN] 发现 14 个文件命名不规范 [WARN] 发现 3 个空目录 [DONE] 扫描完成，报告已保存至 report.json [DONE] 诊断得分: 62/100 - 建议进行优化
扫描完成后，知序会生成一份详细的诊断报告，包含文件统计、类型分布、大小分布、问题清单和优化建议。报告支持 JSON 格式导出，方便与其他工具集成。
自动归类 - 基于 PARA 方法论，智能将文件分类到 Projects（项目）、Areas（领域）、Resources（资源）、Archives（归档）四个维度。根据文件内容和命名自动推断类别。
命令行用法
# 自动归类（预览模式） zhixu classify --path ./my-knowledge-base --dry-run # 执行归类（实际移动文件） zhixu classify --path ./my-knowledge-base --execute # 自定义归类规则 zhixu classify --path ./docs --rules rules.yaml
模拟运行输出

归类引擎基于文件名日期、内容关键词和目录层级进行智能推断。默认使用 dry-run 模式，确认无误后加 --execute 才会实际移动文件，确保安全可控。
重复清理 - 通过 SHA256 哈希值精确识别内容完全相同的文件。支持按修改时间保留最新版本，自动清理冗余副本，释放磁盘空间。
命令行用法
# 查找重复文件 zhixu dedup --path ./my-knowledge-base # 自动清理重复（保留最新） zhixu dedup --path ./my-knowledge-base --clean # 交互式选择保留哪个 zhixu dedup --path ./docs --interactive
模拟运行输出

去重功能使用 SHA256 加密哈希确保精确匹配。默认保留修改时间最新的版本。使用 --interactive 模式可以在每组重复文件中手动选择保留哪一个。
知识索引 - 自动提取 Markdown 文件的标题、标签和摘要，生成可全文搜索的知识索引。支持按标签过滤、按日期排序，快速定位知识资产。
命令行用法
# 生成知识索引 zhixu index --path ./my-knowledge-base # 按标签搜索 zhixu index --path ./notes --search "产品" # 导出为 JSON zhixu index --path ./docs --output index.json

为什么做知序

一个关于数字秩序的故事

起
起点
文件混乱的真实痛点
每个人的电脑里都有一个"黑洞目录"——下载文件夹里堆积着无数"新建文本文档"、桌面上散落着"最终版""真的最终版""打死不改版"的文件。 我们花了大量时间在文件管理上，却始终找不到想要的那一份。学习笔记、工作文档、收藏的资源混在一起， 数字世界的混乱正在侵蚀我们的效率和专注力。这个问题看似微小，日积月累却成为创造力最大的隐形杀手。
思
思考
PARA 方法论 + AI 辅助开发
Tiago Forte 的 PARA 方法论给了我们灵感——将知识按生命周期分为 Projects、Areas、Resources、Archives 四个维度。 但方法论本身需要强大的工具来落地执行。我们利用 AI 辅助开发，打造了一个自动化工具： 它能智能扫描文件、自动分类、识别重复、生成索引。让 PARA 方法论不再是停留在书本上的理论， 而是每个人都能轻松使用的数字秩序引擎。
愿
愿景
让每个人都能建立自己的数字秩序
知序的愿景很简单：让每个人都能用最少的精力管理好自己的数字知识资产。 我们相信，当知识的存储变得有序，思考的质量就会提升，创造力就会自然涌现。 知序不仅是一个文件管理工具，更是一种思维方式——帮助你在信息爆炸的时代， 重新找回掌控感，让每一份知识都在需要的时候出现在需要的地方。
