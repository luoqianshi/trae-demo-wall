理论根基

不是拍脑袋想出来的——有经济学和博弈论的深层支撑

信号理论 · Spence (2001诺奖)

▼

发布成本相同（¥20对所有人一样），但回报分化——真实信息获解锁收益，虚假信息只亏损。信号从结果自然分离，不需要中心化的判断者。Spence 因此理论获 2001 年诺贝尔经济学奖。

分离均衡 · Separating Equilibrium

▼

¥20 对所有人一样，但回报分化导致行为分化：真实信息发布者持续获利、继续发布；虚假信息发布者持续亏损、退出市场。最终达到分离均衡——市场只剩下真实信息。

演化稳定策略 · ESS

▼

"发布真实信息"是演化稳定策略（ESS）——即使有少量虚假信息入侵，市场机制也会将其淘汰，真实信息主导的均衡不会被打破。虚假信息无法扩散。

哈耶克自发秩序

▼

规则不规定谁可信，规则只让不可信者自己离开。不设审核、不设门槛、不设中心化的信用判断——市场通过价格机制自发筛选信息质量，形成自发秩序。

三种信任机制对比

从中心化验证到经济激励，是信任范式的根本转变

中心化验证（传统平台）

  • 我替你判断 → 平台审核信息真实性
  • 腐败风险 → 审核权可被收买
  • 扩展性瓶颈 → 审核团队是人力瓶颈
  • 平台即守门人 → 信息垄断
  • 抽佣 25-30% → 验证成本转嫁用户

经济激励（情报站）

  • 你自己判断 → 市场定价信息价值
  • 无腐败可能 → 没有审核权可以收买
  • 无限扩展 → 规则不变，规模任意
  • 无守门人 → 信息归信息，交易归交易
  • 平台仅得 ¥2/次 → 维持运转，不暴利

server/src/routes/intel.ts — 解锁计费核心逻辑 
// 计算解锁费用：情报总收入 ¥20 为分界线
const totalIncome = intel.total_income;
let requiredBalance: number;

if (totalIncome < 20) {
  requiredBalance = 10;  // 前 ¥20 收入阶段，解锁者付 ¥10
} else {
  requiredBalance = 3;   // ¥20 封顶后，解锁者仅付 ¥3
}

// ===== 核心分账逻辑 =====
const daysN = Math.min(intel.publish_days + 3, 7);
let publisherGet: number, refundAmount: number, platformGet: number;

if (totalIncome >= 20) {
  // 发布者已获 ¥20 封顶，后续解锁返还解锁者 ¥7
  publisherGet = 0;  refundAmount = 7;  platformGet = 3;
} else if (totalIncome + daysN <= 20) {
  // 发布者按天获得收益（daysN 元/天），平台补差
  publisherGet = daysN;  refundAmount = 0;  platformGet = 10 - daysN;
} else {
  // 跨界情况：发布者补到 ¥20 封顶
  publisherGet = 20 - totalIncome;  refundAmount = 0;
  platformGet = 10 - publisherGet;
}
server/src/index.ts — 每日定时结算任务 
// 每小时执行一次（MVP 阶段），正式版每日 0 点
async function dailyTask() {
  const activeIds = dataCache.getActiveIntelIds('active');

  for (const intelId of activeIds) {
    const intel = dataCache.getIntel(intelId);
    if (!intel || intel.status !== 'active') continue;

    // 每天扣减 ¥1 发布费
    if (intel.balance > 0) {
      intel.balance -= 1;
      intel.publish_days += 1;
    }

    // 余额耗尽进入免费展示期
    if (intel.balance === 0 && !intel.is_free_phase) {
      intel.is_free_phase = true;
    }

    // 免费展示 10 天后无人解锁 → 过期退场
    if (intel.unlock_count >= 1 && intel.is_free_phase && intel.free_days > 10) {
      intel.status = 'expired';  // 虚假信息自然淘汰
    }
  }

  // 一次性持久化（内存缓存 → JSON 文件）
  await Promise.all([
    dataCache.saveNow('intels'),
    dataCache.saveNow('users'),
  ]);
}
