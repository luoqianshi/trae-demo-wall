【两种使用方式】

★ 方式一：本地启动（推荐，所有功能可用）
  Windows：双击 start.bat
  Mac/Linux：双击 start.sh，或终端执行 bash start.sh
  脚本会自动启动本地服务并打开浏览器

★ 方式二：直接打开 index.html
  双击 index.html 即可在浏览器打开
  注意：此方式下「体态检测」的摄像头功能不可用
  （浏览器安全策略禁止 file:// 协议访问摄像头）
  其他功能（记录、康复训练、社区、报告、我的）均可正常使用

【环境要求】
  · 本地启动方式：需安装 Python 3 或 Node.js
  · 直接打开方式：现代浏览器（Chrome / Edge / Safari / Firefox）
  · 摄像头检测：需 HTTPS 或 localhost 环境

【功能清单】
  · 首页：产品介绍、检测流程引导、快速入口
  · 体态检测：AI 端侧姿态识别，自动检测 4 项体态指标
  · 体态人格：基于检测结果生成个性化体态画像与分享卡片
  · 记录：体态趋势追踪、历史检测报告
  · 康复训练：ODI/VAS 自评、个性化训练方案、打卡日历
  · 患者社区：腰突/颈椎/脊柱侧弯患者交流、分享经验
  · 我的：个人资料、数据导出、隐私说明

【技术说明】
  · React 18 + TypeScript + Vite + TailwindCSS
  · @mediapipe/tasks-vision 端侧姿态推理（数据不出设备）
  · Zustand + localStorage 本地持久化（无后端）
  · 所有 JS/CSS 已内联到单个 HTML，离线可用（除字体和模型）
