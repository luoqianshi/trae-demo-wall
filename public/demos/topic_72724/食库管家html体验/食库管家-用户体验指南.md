# 食库管家 用户体验指南

> 面向首次体验者，覆盖三大核心功能：添加食材、配置 API Key、AI 菜谱生成。所有按键位置均已标注。

---

## 一、开始体验

1. 双击 `index.html`，用浏览器（推荐 Chrome / Edge）打开
2. 登录页输入用户名 `admin`、密码 `123`；也可点击页面中部的「点击填充」标签一键填入
3. 点击底部圆角「登录」按钮，进入首页

首页底部的导航栏固定显示四个 Tab，贯穿全程使用：

| 位置 | Tab | 用途 |
|------|-----|------|
| 左一 | 首页 | 总览、快捷入口 |
| 左二 | 库存 | 食材清单、新增食材 |
| 左三 | 菜谱 | AI 菜谱、AI 设置 |
| 左四 | 报表 | 库存与消耗统计 |

---

## 二、添加食材

食材入库由内置 439 种食材知识库驱动，输入名称即可自动填充保质期、分类、存放分区，省去逐项手填。

### 入口（任选其一）

- **首页**：点击页面中部的大号绿色按钮「新增食材入库」
- **库存页**：点击底部 Tab「库存」，再点右上角绿色「新增」按钮

### 操作步骤

1. 在「食材名称」输入框输入名称（如「西红柿」「牛奶」），输入约 0.4 秒后系统自动匹配知识库。名称下方会出现绿色「已匹配」提示，且「分类」「单位」「保质期天数」「存放分区」四个字段会闪烁高亮并自动填好，可手动覆盖
2. 填写「数量」（必须大于 0）和「单位」（如个、斤、克）
3. 「采购日期」默认为今天；如需修改，点击该行打开仿真日历选择，支持键盘方向键 ← → ↑ ↓ 移动、Enter 确认
4. 「保质期截止」由采购日期 + 保质期天数自动计算，无需填写
5. 「单价」「总价」为选填项，可跳过
6. 点击底部绿色「确认入库」按钮，提示「入库成功」后约 1.5 秒自动跳转库存页

> 若输入的名称不在知识库中，会显示「未匹配到知识库条目」，此时需手动填写下方各字段，不影响入库。

## 三、配置 API Key

AI 菜谱需调用大模型，首次使用前需配置一次 API Key。Key 仅保存在本地浏览器，不上传任何服务器。未配置时也可体验（自动降级为本地菜谱，见下一节）。

### 入口

点击底部 Tab「菜谱」，再点页面右上角赤陶橙色的「AI设置」按钮。

### 操作步骤

1. 在弹出的「AI 接口设置」面板，点击「服务商」一行，底部弹出选择器，推荐选 **DeepSeek** 或 **智谱清言**（中文菜谱质量好、成本低，智谱有免费额度）
2. 选中后下方会实时显示「当前模型」名称
3. 在「API Key」输入框粘贴密钥：
   - DeepSeek / OpenAI / Moonshot：需 `sk-` 开头且不少于 20 字符
   - 智谱：不少于 10 字符
   - 输入框右侧的「眼睛」图标可切换明文/密文显示，格式错误会即时红色提示
4. （可选）在「自定义端点」填写自建代理地址，用于规避浏览器的 CORS 限制（DeepSeek 原生支持 CORS，可不填）
5. 点击蓝色「测试连接」按钮，发送一次轻量请求验证 Key 是否可用，结果以浮层提示
6. 点击绿色「保存配置」按钮，配置写入本地；之后再次进入菜谱页会自动读取
7. 如需更换或清除，点击红色「清除已保存的 Key」

## 四、AI 菜谱生成

根据冰箱现有食材 + 口味偏好，调用大模型生成 5-6 道定制菜谱，并优先消耗临期食材。

### 前置条件

库存中可用食材（数量大于 0 且未过期）至少 3 种；不足时页面会提示「去采购入库」。

### 操作步骤

1. 点击底部 Tab「菜谱」进入菜谱页
2. 点击顶栏左侧的「重新生成」按钮；若列表为空，则点击页面中央的「生成菜谱」按钮
3. 等待约 20-40 秒，期间显示「AI 正在为您定制菜谱...」与已等待秒数，可点「取消」中断
4. 生成完成后，菜谱以卡片列表展示，每张卡片包含：菜名、分类标签、时长 / 热量 / 难度、「冰箱已有」食材（临期标红、即将过期标黄）、「需购买」食材及估价
5. 点击菜谱卡片或「X 步 · 点击查看详细做法」，底部弹出详情（85% 屏高）：含食材清单、零基础分步做法、小贴士
6. 在详情底部点击「添加到我的菜谱」收藏；或在卡片右下角点「收藏」
7. 顶部 Tab 可切换分类：全部 / 快手懒人餐 / 减脂轻食餐 / 家常正餐 / 我的菜谱

### 两个实用技巧

- **口味偏好**：点击菜谱页顶部右侧的「口味偏好」按钮，设置忌口、菜系、辣度，会注入 AI 提示词影响推荐结果
- **完成食谱**：在菜谱详情底部点击「完成食谱」，系统按菜谱用量自动扣减对应食材库存，临期食材优先消耗，实现「推荐 → 烹饪 → 出库」闭环

### 降级兜底

未配置 API Key、或请求超时 / 被拦截 / 失败时，系统自动返回 5 道本地经典菜谱（西红柿炒鸡蛋、青椒炒猪肉等），页面顶部显示黄色提示条告知当前为本地菜谱，确保断网也能完整体验。

## 五、常用入口速查

| 想做的事 | 点击位置 |
|---------|---------|
| 添加食材 | 首页「新增食材入库」或 库存 Tab 右上角「新增」 |
| 配置 AI Key | 菜谱 Tab 右上角「AI设置」 |
| 生成 AI 菜谱 | 菜谱 Tab 左上角「重新生成」 |
| 设置口味 | 菜谱 Tab 顶部「口味偏好」或首页「口味偏好」 |
| 查看临期食材 | 首页「临期汇总」或临期提醒区「查看全部」 |
| 出库消耗 | 首页「食材出库」 |
| 备份/重置数据 | 首页「系统设置」 |
