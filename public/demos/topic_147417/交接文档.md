## 一、项目概述

HomeWizard 是一个基于 **Streamlit** 的智能家居场景规划工具，帮助用户通过 **3 步引导**快速生成个性化的智能家居设备推荐方案，并导出可执行的购物清单（Excel/CSV）。

**核心定位**：纯 DIY 家庭用户工具，聚焦"选户型 → 选场景 → 拿清单"的简洁流程。

**最新升级**（2026-06-28）：
- 全局深色毛玻璃主题（参考米家风格）
- 设备按户型房间分组展示
- 设备按类别一键聚合（同类设备折叠/展开）
- 全屋动态看板（实时统计）
- 预算命名升级为 L1/L3/L5

### 详细步骤说明

#### Step 1：选户型

用户从三个预设户型中选择：
- **一室一厅**：适合单身/情侣，5 个区域（客厅、卧室、厨房、卫生间、阳台）
- **两室一厅**：适合小家庭，7 个区域（增加次卧、玄关）
- **三室一厅**：适合大家庭，10 个区域（增加书房、餐厅等）

选中后高亮蓝色边框，自动进入 Step 2。

#### Step 2：选场景

用户从四个场景类型中**多选**：
- **照明**（💡）：智能灯光控制
- **安防**（🔒）：传感器 + 摄像头 + 门锁
- **舒适**（🛋️）：窗帘 + 空调 + 音箱
- **节能**（🌱）：插座 + 定时 + 能耗监控

#### Step 3：选预算

用户从三个预算档位中**单选**：
- **L1 基础智能**（< 3000 元）：基础设备组合
- **L3 场景智能**（3000 - 8000 元）：主流设备组合
- **L5 高阶智能**（> 8000 元）：旗舰设备组合

> 注意：UI 显示名称已替换为 L1/L3/L5，但内部 session_state 存储的值仍为 "经济"/"平衡"/"高端"。

#### 生成方案

点击"生成方案"后：
1. 调用 `core/router.py` 的 `generate_plan()` 生成单方案
2. 调用 `generate_multi_plans_route()` 生成三档方案（L1/L3/L5）
3. 加载户型模板，为每个设备分配默认坐标
4. 所有数据存入 `st.session_state`
5. 跳转到推荐方案页

#### 推荐方案页

- 使用 radio 组件替代 tabs 作为方案选择器，默认选中用户所选预算档位
- 设备清单按房间分组展示（客厅、主卧、次卧等）
- 每个房间内，同类设备 >=2 时折叠为聚合卡片，点击展开
- 单设备保持原有独立卡片样式
- 支持增减设备数量、导出 Excel/CSV、添加自定义设备

## 四、核心数据流

### Session State 变量清单

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `wizard_step` | int | 当前引导步骤（1/2/3） |
| `selected_floorplan` | str | 选中的户型（一室一厅/两室一厅/三室一厅） |
| `selected_scenes` | list | 选中的场景列表 |
| `selected_budget_tier` | str | 选中的预算档位（经济/平衡/高端） |
| `budget` | int | 预算上限金额 |
| `user_input` | str | 用户输入的需求描述 |
| `submitted_user_input` | str | Step 2 提交的原始需求（独立 key） |
| `plan_result` | dict | 生成的单方案结果 |
| `multi_plans` | dict | 三档方案（economy/balanced/premium） |
| `devices` | list | 当前方案的设备列表 |
| `favorites` | list | 收藏的设备列表 |
| `edited_devices_economy` | list | L1 编辑后的设备 |
| `edited_devices_balanced` | list | L3 编辑后的设备 |
| `edited_devices_premium` | list | L5 编辑后的设备 |
| `setup_plan_devices` | list | 传递给安装向导的设备列表 |
| `setup_plan_scene` | str | 传递给安装向导的场景名 |
| `pending_plan_devices` | list | 传递给平面图的设备列表（含坐标） |
| `flatplan_devices` | list | 平面图设备数据 |
| `floorplan_template` | dict | 户型模板数据（含 rooms） |

### 数据来源

所有数据来自 **本地 JSON 文件**，不涉及任何真实设备或 API 调用：

- `data/device_library.json` — 42 个设备条目，覆盖灯光、传感器、开关、网关、摄像头五大类
- `data/rule_library.json` — 自动化规则库
- `data/floorplan_templates/` — 3 个户型模板（一室/两室/三室）

## 五、各模块说明

### 5.1 app.py — 应用入口

**职责**：
- 页面配置（标题、图标、布局）
- 全局 CSS 样式注入（深色毛玻璃主题）
- 侧边栏品牌标识 + 导航菜单
- 多页面路由（首页 + 推荐方案）

**导航菜单**：
- 📋 首页
- 📦 推荐方案

**全局 CSS 样式**（共 ~540 行）：
- 全局背景：深色渐变 `linear-gradient(135deg, #0a0a1a, #1a1a2e, #16213e)`
- 毛玻璃卡片：`backdrop-filter: blur(20px)` + 半透明背景
- 设备卡片：毛玻璃 + 悬停上浮效果
- 聚合卡片：折叠/展开样式
- 看板统计卡片：毛玻璃 + 悬停发光
- 按钮：毛玻璃背景 + 渐变 primary
- 输入框/下拉框/复选框/进度条/警告框/展开器/表格/日期输入：全部深色适配
- 滚动条美化：细条 + 半透明
- 侧边栏：深色毛玻璃

### 5.2 views/home.py — 首页

**职责**：
- 三步引导流程（户型 → 场景 → 预算）
- 调用 `core/router.py` 生成方案
- 加载户型模板设备坐标
- 跳转到推荐方案页

**关键函数**：
- `show_matching_process()` — 匹配过程动画展示（4 步日志）
- `render_step_progress()` — 步骤进度条渲染

**预算档位**：
- 内部 key：`"经济"` / `"平衡"` / `"高端"`
- UI 显示：`"L1 基础智能"` / `"L3 场景智能"` / `"L5 高阶智能"`

### 5.3 views/recommend.py — 推荐方案页

**职责**：
- 方案选择器（radio 组件，支持默认选中）
- 全屋动态看板渲染
- 设备按房间分组 + 按类别聚合
- 设备卡片渲染（DIY 精简版）
- 场景叙事生成（生活化描述）
- 自定义设备添加（简化表单）
- 导出功能（Excel + CSV）
- 平面图只读预览

**关键函数**：
- `render_dashboard(devices)` — 渲染全屋动态看板
- `load_floorplan_rooms()` — 加载户型房间列表
- `group_devices_by_room(devices, rooms)` — 设备按房间分组
- `group_devices_by_category(room_devices)` — 设备按类别聚合
- `render_aggregate_card(category, devices, ...)` — 渲染聚合卡片（expander）
- `render_device_card(device, idx, plan_key)` — 渲染单个设备卡片
- `generate_scene_narration(plan, devices)` — 生成场景叙事
- `generate_markdown(plan, plan_name)` — 生成 Markdown 方案文档

**设备聚合逻辑**：
- 同一房间内，同类别设备 >=2 台 → 折叠为聚合卡片（`st.expander`）
- 同类设备仅 1 台 → 保持独立卡片
- 聚合卡片标题：`💡 照明 × 3`，点击展开后逐个渲染设备卡片
- 每个 expander 有唯一 key（`agg_{plan_key}_{room_name}_{category}`）避免跨房间冲突

**房间分组逻辑**：
- 通用名→具体名映射：设备 `applicable_area` 中的 "卧室" 映射到户型模板中的 "主卧"/"次卧"
- 无 `applicable_area` 或值为 "全屋" 的设备归入 "通用" 区域
- 特殊关键词匹配：入户/门口/门窗/走廊 → 玄关；电视墙/氛围 → 客厅

### 5.4 views/setup.py — 安装步骤提示卡

**职责**：
- 根据设备列表自动生成 5 步安装指引
- 展示设备清单摘要
- 提供返回推荐页的导航

### 5.5 views/floorplan.py — 设备位置示意图

**职责**：
- 只读 HTML 画布展示设备位置
- 显示房间区域（客厅/卧室/厨房/卫生间）
- 显示设备图标和名称
- 提供返回导航

### 5.6 core/router.py — 路由调度

**职责**：
- 方案生成入口（`generate_plan()`）
- 多预算方案生成（`generate_multi_plans_route()`）
- 设备排名标签（`get_device_rank_label()`）
- 关键词提取（`keyword_extraction()`）

**调用链**：
```
router.py
  ├── rule_engine.match_by_rules()     # 规则匹配
  ├── local_ai.match_by_local_ai()     # 本地 AI 匹配
  └── local_ai.generate_multi_plans_with_budget()  # 多预算方案
```

### 5.7 core/local_ai.py — 本地 AI 推荐

**职责**：
- 关键词提取（从用户输入中提取场景关键词）
- 设备匹配（基于关键词匹配设备库）
- 多预算方案生成（按预算档位筛选设备）

### 5.8 core/rule_engine.py — 规则引擎

**职责**：
- 加载规则库（`data/rule_library.json`）
- 基于规则匹配设备

### 5.9 utils/export.py — 导出功能

**职责**：
- `export_excel()` — 生成 Excel 购物清单（openpyxl，带格式）
- `export_csv()` — 生成 CSV 购物清单（UTF-8 BOM）

### 5.10 utils/helpers.py — 通用工具

**职责**：
- `get_data_path()` — 获取数据文件路径
- `load_json()` / `save_json()` — JSON 读写
- `calculate_total_price()` — 计算总价
- `get_devices_by_tags()` — 按标签筛选设备
- `init_database()` — 初始化 SQLite 数据库
- `save_history()` / `get_history()` — 历史记录管理

## 十、已知问题

1. **组件缓存**：Streamlit 的 `__pycache__` 可能导致代码更新后不生效，删除 `__pycache__/` 目录后重启即可
2. **端口占用**：如 8502 端口被占用，使用 `--server.port 8503` 更换端口
3. **设备库更新**：修改 `data/device_library.json` 后需重启应用才能生效
4. **dashboard.py**：文件仍在 `views/` 目录下，但已从侧边栏导航移除，如需恢复可将其重新加入 `app.py` 的 `pg.add_page()`
