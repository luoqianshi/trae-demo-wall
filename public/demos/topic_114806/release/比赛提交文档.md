## 1. Demo 简介

**是什么：**  
基于 ESP32-S3 的智能示波器+波形发生器，集成 LCD 显示和 Web 远程控制。

**面向谁：**  
电子爱好者、学生、工程师——需要便携测量工具的人群。

**主要功能：**

### 功能一：波形发生器
- 支持 **4 种波形**：正弦波、方波、三角波、锯齿波
- 频率范围：**1Hz ~ 20kHz**（连续可调）
- 振幅范围：**0 ~ 1000mV**（通过 PCM5102A I2S DAC 输出）
- 相位累加器算法，输出稳定无抖动

### 功能二：智能示波器
- **独立 ADC 探头**（GPIO1，ADC1_CH0），12-bit 精度
- **触发模式**：上升沿、下降沿、自动触发
- **垂直档位**：10mV/div ~ 2V/div（8档 + 自动缩放）
- **水平时基**：10us/div ~ 100ms/div（13档 + 自动适配）
- **测量参数**：频率、峰峰值、峰值、谷值、RMS、直流偏置、占空比
- **余晖效果**：0-10 级可调

### 功能三：Web 远程控制
- **WiFi 双模式**：AP（热点名 `scope-gen`，密码 `12345678`）+ STA（连接家庭 WiFi）
- **mDNS 服务**：局域网内直接访问 `http://waveform_gen.local`
- **响应式界面**：支持手机/平板/电脑，GitHub 暗色主题
- **NVS 持久化**：所有参数断电不丢失

## 2. Demo 创作思路

**灵感来源：**  
我之前做过一个简单的波形发生器项目，但没有示波器功能。调试电路时经常需要外接示波器，很不方便。于是想把两个功能合二为一，做一个便携的测量工具。

**想解决的问题：**
1. **便携性问题**：传统示波器体积大、价格高，不适合日常调试
2. **自采自测需求**：波形发生器输出的信号需要验证，内置示波器可以直接查看
3. **远程控制**：实验台上的设备可以通过手机调节参数，不用来回插拔线

**为什么做这个方向：**
- ESP32-S3 有双核 CPU，可以同时处理波形生成和信号采集，互不干扰
- I2S 接口驱动 PCM5102A DAC 输出高质量模拟信号
- 12-bit ADC 精度足够日常测量（最大误差约 0.8mV）
- WiFi + mDNS 让远程控制变得简单

## 5. 额外部分：经验总结

### 5.1 技术亮点

1. **双核并行处理**：Core 0 负责 ADC 采集和 LCD 显示，Core 1 负责 I2S 波形输出，互不干扰
2. **相位累加器算法**：无查表、无浮点运算，生成波形稳定高效
3. **自动缩放功能**：基于上一帧频率测量结果自动调整垂直/水平档位
4. **余晖效果**：模拟真实示波器的视觉效果，便于观察信号变化

### 5.2 未来改进方向

1. 添加双通道示波器功能
2. 支持信号存储和回放
3. 添加 FFT 频谱分析
4. 支持蓝牙连接控制
