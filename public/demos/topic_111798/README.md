# Spatial Photo — 空间照片

让每一张照片都拥有空间的深度。

## 🚀 快速开始

### 使用Node.js服务器（推荐）

```bash
node server.js
# 打开浏览器访问: http://127.0.0.1:9000
```

### 使用Python服务器

```bash
python -m http.server 9000
# 打开浏览器访问: http://127.0.0.1:9000
```

## 📁 项目结构

```
3d 摄影/
├── index.html          # 主页面（核心代码）
├── server.js           # Node.js本地服务器
├── three.esm.min.js    # Three.js库（本地内置）
└── README.md           # 项目说明
```

## 🎮 使用说明

### 基础操作

1. **上传照片**：点击首页"上传照片"按钮，选择JPG或PNG图片
2. **拖拽旋转**：使用鼠标左键拖拽，从不同角度查看照片
3. **滚轮缩放**：使用鼠标滚轮放大或缩小视图

### 控制按钮

| 按钮 | 功能 |
|------|------|
| ↺ | 重置视角 |
| ◎ | 切换自动播放 |
| + | 上传新照片 |
| ▣ | 深度效果开关 |

### 体验演示

点击"体验演示图片"按钮，系统会自动加载一张风景照片，无需上传即可体验3D效果。

## ✨ 核心功能

- **实时渲染**：基于 WebGL 技术，60fps 流畅呈现
- **自由探索**：拖拽旋转，从任意角度欣赏你的照片
- **自动微动**：缓慢摆动增强沉浸感
- **实时统计**：显示分辨率和帧率信息

## 🔧 技术栈

- **前端框架**: 原生HTML5 + CSS3 + JavaScript
- **3D渲染**: Three.js (WebGL)

## 📋 运行需求

- ✅ **无需网络**：所有功能离线可用
- ✅ **无需安装**：打开浏览器即可运行
- ✅ **跨平台**：支持Windows、Mac、Linux
- ✅ **现代浏览器**：Chrome、Firefox、Safari、Edge
