## 一、Demo 简介

### 是什么

**轻燃餐盘教练 Pro** 是一款面向减脂新手的"游戏化饮食管理"交互式 Web 应用。它把枯燥的减脂过程变成一场轻燃宗门的养成冒险——用户不再是被动记录热量，而是像玩 RPG 游戏一样"接任务、闯关卡、养精灵、争排行"。

### 面向谁

- 想减脂但不知道从何下手的新手（"热量小白"）
- 尝试过多次减肥但难以坚持的"反复横跳者"
- 喜欢游戏化体验、需要正向激励的年轻用户（18-35岁）
- 学生党、上班族等有减脂需求但时间碎片化的人群

### 主要功能

| 模块 | 功能描述 |
|------|----------|
| **餐食记录** | 按场景（早餐店/食堂/便利店/外卖）选择食物，实时计算热量、蛋白质、稳定度评分，支持智能推荐和随机踩坑 |

## 二、Demo 创作思路

### 灵感来源

在健身和减脂领域，市面上有大量"热量计算器"和"饮食记录"类应用，但它们普遍存在一个致命问题：**枯燥**。用户需要手动输入每一样食物的克数和热量，坚持3天就放弃了。

我观察到：
- 很多想减脂的人其实不需要精确到"克"的记录，他们只需要知道"这一顿选什么更合适"
- 游戏化是提升用户粘性最有效的方式——Duolingo（多邻国）用游戏化把学语言变成了日活数千万的超级应用
- 健身类应用缺乏"养成感"和"社交激励"

### 想解决的问题

1. **减脂入门门槛高**：新手不知道如何计算热量、搭配营养，导致无从下手
2. **坚持率极低**：传统饮食记录枯燥乏味，用户在3-7天内流失
3. **缺乏正向激励**：减脂是长期过程，短期看不到效果容易放弃
4. **知识获取分散**：减脂知识散布在各类文章/视频中，缺乏系统化学习路径

### 为什么做这个方向

- **市场验证**：中国健康减脂市场规模超千亿，但"游戏化饮食管理"赛道几乎空白
- **差异化**：不是又一个"热量计算器"，而是"减脂界的多邻国"
- **用户粘性**：宗门任务+养成系统+社交排行形成行为闭环，让用户"离不开"
- **商业潜力**：可从免费工具升级为付费会员（解锁更多课程、道具、AI分析），或与健康食品品牌合作

## 三、Demo 体验地址

### 体验方式

本 Demo 为**交互式可体验 HTML 格式文件**，已打包为 ZIP 压缩包，可直接上传到 TRAE 社区。

### 体验步骤

1. 下载 ZIP 文件并解压
2. 用浏览器（Chrome / Edge / Safari）打开 `trae_creativity_lightburn_plate_coach.html`
3. 首次进入会弹出引导弹窗，填写基本信息（或直接跳过使用默认值）
4. **推荐操作：** 点击页面底部的「加载演示数据」按钮，或按 `Ctrl+Shift+D` 加载完整演示数据
5. 体验完整功能：切换顶部 Tab 标签，浏览仪表盘 / 餐食记录 / 宗门任务 / 好友排行等模块

### 技术说明

- 纯前端实现，无需服务器，所有数据存储在浏览器 LocalStorage
- 响应式设计，支持桌面端和移动端
- 使用 Canvas 绘制转盘、体重趋势图、彩带特效
- Google Fonts 加载中文字体，确保视觉一致性

### 踩坑与解决方案

1. **LocalStorage 数据迁移问题**：每次新增字段时，需要兼容旧数据。解决方案是在 `loadState()` 中为每个新字段添加默认值检查。
2. **Canvas 绘制时机问题**：体重趋势图在 Tab 未显示时 Canvas 尺寸为0。解决方案是在 `switchTab` 时重新渲染图表。
3. **跨天状态重置**：宗门任务、转盘等需要每日重置。解决方案是在 `updateStreak()` 中统一处理跨天逻辑并保存状态。

- 游戏化体验是最大差异化壁垒
