# 双人记忆摆渡船

一款双人互动记忆漂流瓶小程序，让两个人一起记录美好回忆，通过关键词匹配找到共鸣。

## ✨ 功能特点

### 核心功能
- 🚢 **记忆长河**：创建专属双人记忆长河，支持多种关系类型
- 📝 **漂流瓶编辑器**：文字录入、图片上传、模板选择
- 🌊 **河道场景**：2D静态场景、小船滑动跟随、漂流瓶浮动动效
- 🎯 **关键词匹配**：自动匹配双人记忆，发现共鸣瞬间
- 💬 **双人互动**：记忆详情对照、瓶子收纳/放流

### 技术亮点
- 轻量化关键词分词匹配算法
- 双人专属可见的数据隔离
- 四季皮肤切换效果

## 🛠️ 技术栈

- **框架**：微信小程序原生框架
- **后端**：腾讯云开发（云函数 + 云数据库）
- **前端**：WXML + WXSS + JavaScript
- **数据库**：MongoDB（云开发）

## 🚀 快速开始

### 环境要求
- 微信开发者工具
- 微信小程序账号

### 运行步骤

1. **打开项目**
   ```bash
   # 使用微信开发者工具打开项目
   ```

2. **配置云开发环境**
   - 在微信开发者工具中点击「云开发」按钮
   - 创建云开发环境，获取环境 ID
   - 修改 `cloudbaserc.json` 和 `app.js` 中的环境 ID

3. **创建数据库集合**
   - 在云开发控制台创建以下集合：
     - `users`
     - `rivers`
     - `bottles`
   - 设置集合权限为「所有用户可读、创建者可读写」

4. **上传云函数**
   - 右键点击 `cloudfunctions/api`
   - 选择「上传并部署：云端安装依赖」

5. **编译运行**
   - 点击编译按钮，开始测试

```
│   └── api.js             # API 调用模块

```
