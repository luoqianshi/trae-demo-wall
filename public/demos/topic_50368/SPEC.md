# 鲁匠智联 - 机械类职业院校教师企业案例智能对接微信小程序

## 1. Concept & Vision

**鲁匠智联**是一款面向职业院校、技工院校机械类教师的微信小程序，定位为"企业案例获取 + 教学资源转化 + 校企需求匹配"三位一体的智能对接平台。整体风格追求现代、简洁、科技感，呈现智慧工业与职业教育的融合之美。情感上给用户传递"专业、高效、便捷"的信任感，让教师能够轻松获取真实企业案例，提升教学与竞赛质量。

## 2. Design Language

### 色彩系统
- **主色调**: `#1E3A5F` (深海蓝) - 传递专业与信任
- **辅助色**: `#FFFFFF` (纯白) - 简洁底色
- **强调色**: `#FF6B35` (工业橙) - 活力点缀，用于CTA按钮和重要标识
- **成功色**: `#10B981` (科技绿) - 成功状态与匹配标识
- **背景色**: `#F5F7FA` (浅灰蓝) - 页面背景
- **卡片背景**: `#FFFFFF`
- **次要文字**: `#6B7280`
- **边框色**: `#E5E7EB`

### 字体系统
- **主字体**: "PingFang SC", "Microsoft YaHei", -apple-system, sans-serif
- **标题字重**: 600 (Semibold)
- **正文字重**: 400 (Regular)
- **标题字号**: 20px / 18px / 16px
- **正文字号**: 14px / 12px

### 空间系统
- **基础单位**: 8px
- **页面内边距**: 16px
- **卡片间距**: 12px
- **卡片内边距**: 16px
- **圆角**: 12px (卡片), 8px (按钮), 50% (头像)

### 动效哲学
- **过渡时长**: 200ms - 300ms
- **缓动函数**: ease-out
- **卡片悬浮**: translateY(-2px) + box-shadow增强
- **按钮点击**: scale(0.98) + 透明度变化
- **页面切换**: slide-in from right, 300ms
- **数据加载**: fadeIn + translateY(10px), staggered 50ms
- **匹配动画**: 脉冲光晕效果，强调智能感

### 视觉资源
- **图标库**: Lucide Icons (线性风格，2px描边)
- **装饰元素**: 几何图形、渐变光晕、网格背景暗示工业感
- **空状态**: 简笔画风格插图 + 引导文案

## 3. Layout & Structure

│   ├── 三大入口卡片
│   ├── 推荐案例轮播

│   ├── 分类筛选标签
│   ├── 企业卡片列表
│   └── 企业详情页
│       └── 案例详情页
├── 教学资源库 (resources)
│   ├── 资源分类导航
│   ├── 资源卡片列表
│   └── 资源详情页
├── 校企智配 (matching)

### 响应式策略
- 模拟微信小程序 375px 宽度视图
- 最大内容宽度: 100%
- 卡片列表: 单列或双列网格
- 底部导航: 固定5栏

## 4. Features & Interactions

### 首页
- **Logo动画**: 初次加载时淡入 + 缩放
- **搜索框**: 点击展开，支持关键词联想
- **入口卡片**: 点击时缩放反馈，跳转对应模块
- **轮播图**: 自动播放 + 手动滑动，指示器同步
- **推荐内容**: 点击进入详情，长按唤起收藏

### 企业案例库
- **筛选标签**: 点击切换，active状态高亮，支持多选
- **企业卡片**: 显示企业名称、地区、类型、主营方向、案例数量
- **企业详情**: 企业信息 + 案例列表 + 联系入口
- **案例详情**: 完整案例内容 + 收藏/分享/一键匹配按钮
- **收藏**: 心形图标动画，toast提示

### 教学资源库
- **分类导航**: 横向滚动，当前选中项高亮
- **资源卡片**: 封面图 + 标题 + 适用专业 + 收藏数
- **资源详情**: 完整资源信息 + 下载/收藏/推荐按钮
- **下载模拟**: 进度条动画 + 成功提示

### 校企智配
- **身份切换**: 教师端/企业端 Tab切换
- **需求发布**: 多步骤表单，选择需求类型 + 填写详情
- **AI匹配动画**: 扫描线动画 + 标签匹配高亮
- **匹配结果**: 卡片式展示推荐内容，支持查看详情

### 我的
- **用户信息**: 头像 + 名称 + 身份标识
- **身份切换**: 教师/企业，单选切换
- **标签设置**: 可编辑的专业方向、工艺类型等标签
- **记录列表**: 收藏、发布、匹配记录的Tab切换

## 5. Component Inventory

### 底部导航栏
- 5个Tab: 首页、企业案例库、教学资源库、校企智配、我的
- 当前项高亮(主色)，带选中动效
- 固定在底部，背景白色 + 顶部细线分隔

### 卡片组件
- **企业卡片**: 白色背景，12px圆角，微阴影，hover上浮
- **资源卡片**: 带封面图，标题在图下方
- **案例卡片**: 强调色标签，收藏按钮

### 按钮组件
- **主按钮**: 主色背景，白色文字，8px圆角
- **次要按钮**: 白色背景，主色边框和文字
- **图标按钮**: 40px圆形，图标居中

### 表单组件
- **输入框**: 白色背景，灰色边框，聚焦时主色边框
- **选择器**: 下拉箭头，点击展开选项列表
- **标签选择器**: 胶囊式标签，多选高亮

### 空状态组件
- 居中图标 + 主文案 + 副文案 + 操作按钮

## 6. Technical Approach

### 技术栈
- **前端**: 纯HTML5 + CSS3 + Vanilla JavaScript
- **架构**: SPA (Single Page Application) 模拟小程序多页面
- **路由**: Hash-based路由 (#/home, #/cases, etc.)
- **状态管理**: LocalStorage持久化用户状态
- **动画**: CSS Transitions + Keyframe Animations

### 数据模拟
- 静态JSON数据模拟后端接口
- 模拟AI匹配算法基于标签权重计算
- 延迟加载模拟网络请求
