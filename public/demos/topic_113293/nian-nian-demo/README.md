# 念念 NianNian｜AI 家庭记忆陪伴 Demo 最终版 v3

这是 TRAE AI 创造力大赛初赛作品「念念 NianNian」的可交互最终版 Demo。

## 最快打开方式

1. 解压 zip。
2. 双击 `index.html`。
3. 点击首页「进入体验」。
4. 按步骤体验：选择照片 → 生成回忆卡 → 发送给老人 → 老人听回忆 → 一键报平安 → 生成通话话题 → 回复关心 → 查看陪伴周报。

## 本次最终版修改重点

- 已加入你提供的三张真实照片：春节全家福、年轻时工作照、老家院子合影。
- 用户可以直接点击图片进行选择。
- 每张图片旁边都有文字提示，明确标注：春节全家福、团圆、年夜饭、老屋；年轻时工作、手艺、奋斗；老家院子、老树、乘凉、老友。
- 点击不同照片会生成不同的回忆卡、通话话题、老人端朗读文案和陪伴周报。
- 保留双端一屏联动结构：左侧子女端，中间家庭连接中心，右侧老人端。

## 本地运行方式

```bash
npm install
npm run dev
```

如果只是提交或展示，直接打开 `index.html` 即可，不需要安装依赖。

## 表达边界

本 Demo 只表达陪伴、生活照护提醒、家庭记忆唤醒和亲情沟通辅助，不承诺任何超出日常陪伴范围的能力。
