# 【社会服务｜社会公益】念念 NianNian：AI 家庭记忆陪伴助手

「念念 NianNian」是一款面向空巢老人和异地子女的 AI 家庭记忆陪伴 Demo。作品通过老照片、家庭成员关系和日常陪伴场景，生成老人能听懂、子女能接着聊的回忆卡、通话话题和陪伴摘要。

本次 Demo 内置三张真实照片场景：春节全家福、年轻时工作照、老家院子合影。用户可以点击照片选择记忆场景，并在图片旁看到“团圆、年夜饭、老屋、手艺、老树、乘凉”等文字提示。选择不同照片后，系统会生成不同回忆卡，并同步到老人端。

作品目标是帮助家人把散落在照片、记忆和日常问候中的爱重新组织起来，让老人被看见、被记得、被陪伴。

核心体验链路：子女选择老照片 → AI 生成回忆卡 → 发送给老人 → 老人听回忆 → 一键报平安 → 子女生成今晚通话话题 → 回复一句关心 → 查看陪伴周报。
