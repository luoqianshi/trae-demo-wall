# 知缺学堂-KNOWA · 智能试卷学情诊断小程序

> 参赛作品：智学卷诊学生学情分析小程序

## 📖 产品介绍

知缺学堂是一款轻量化的微信小程序智能体，支持拍照上传试卷、自动识别错题、拆解考点，一键生成专属补弱方案。

### 核心功能
- 📷 **拍照识别试卷** - 支持拍照/相册上传，自动裁剪识别
- 📝 **错题智能识别** - 自动批改，标记错题和正确答案
- 📊 **考点拆解分析** - 知识点雷达图、薄弱点排行、错误原因分布
- 🎯 **专属补弱方案** - 针对性练习题 + 3天复习计划

### 目标用户
- 小学至高中全年级学生
- 辅导作业的家长
- 在校任课教师

## 🛠 技术架构

- **前端**: 微信小程序原生开发
- **后端**: 微信云开发（云函数 + 云数据库 + 云存储）
- **识别方案**: Mock模拟（可对接真实OCR + AI服务）

## 🚀 快速开始

### 环境准备
1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册小程序账号（或使用测试号）

### 运行项目
1. 用微信开发者工具打开项目根目录 `Race/`
2. 在 `project.config.json` 中配置你的 AppID
3. 开通云开发（可选，不开通则使用Mock数据）
4. 点击"编译"即可预览

### 云函数部署（可选）
1. 在微信开发者工具中开通云开发
2. 修改 `app.js` 中的 `env` 为你的云环境ID
3. 右键 `cloudfunctions/analyzePaper` → 上传并部署
4. 右键 `cloudfunctions/getHistory` → 上传并部署

## 🔄 核心流程

```
首页 → 拍照/相册选择 → 选择年级科目 → 开始识别
  ↓
识别中（扫描动画） → 识别结果（错题列表）
  ↓
学情分析（雷达图+薄弱点） → 补弱方案（练习+计划）
```
