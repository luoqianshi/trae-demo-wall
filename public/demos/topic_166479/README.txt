心灵沙境 Demo 使用说明

一、项目简介

「心灵沙境」是一个基于浏览器运行的在线心理沙盘诊疗系统 Demo。
当前版本重点展示标准心理沙盘的核心交互，包括入口页、标准沙盘、轴测/俯视视角切换、沙具拖拽和理沙模式。


二、文件说明

解压 Zip 后，你会看到以下文件：

1. entry.html
   Demo 入口页。建议从这个文件开始体验。

2. sandbox-standard.html
   标准沙盘主交互页。入口页点击 New Case 并选择“标准沙盘”后会跳转到这个页面。

3. snapshot-preview.png
   入口页使用的沙盘预览图，请不要删除，否则入口页预览图会缺失。

4. README.txt
   当前使用说明文件。


三、如何体验

推荐使用 Chrome、Edge、Safari 等现代浏览器打开。

1. 解压 Zip 文件。
2. 双击打开 entry.html。
3. 在入口页点击 New Case。
4. 在弹窗中选择“标准沙盘 72cm × 57cm × 7cm”。
5. 进入沙盘后，可以体验以下功能：
   - 在“轴测视角”和“俯视视角”之间切换。
   - 拖动沙盘中的宇航员、牛、仙人掌等沙具。
   - 点击左下角理沙按钮，开启理沙模式。
   - 在理沙模式下移动沙子，观察沙面高度变化。
   - 切换视角，比较不同视角下的沙盘呈现效果。


四、注意事项

1. 请保持 entry.html、sandbox-standard.html 和 snapshot-preview.png 在同一个文件夹中。
2. 如果入口页无法跳转，请确认 sandbox-standard.html 没有被移动或重命名。
3. 当前 Demo 是纯前端静态页面，不需要安装依赖，也不需要启动服务器。
4. 若浏览器提示本地文件安全限制，可尝试将文件夹拖入浏览器，或使用本地静态服务器打开。
5. 当前版本主要用于初赛 Demo 展示，实时协同、动作记录、会话存档和 AI 辅助分析属于后续规划能力。


五、建议展示方式

如果用于 TRAE 社区初赛作品帖，建议配合以下截图一起展示：

1. 入口页截图：展示「心灵沙境」标题和 New Case 按钮。
2. 标准沙盘轴测视角截图：展示 2.5D 沙面、沙具和木质边框。
3. 俯视视角截图：展示沙盘整体布局和沙具空间分布。
4. 理沙模式截图：展示沙面高度变化或交互后的结果。
