墨拾笔记 — 桌面端极致美学笔记工具

墨拾笔记是一款专为桌面端打造的本地优先笔记应用，致力于在极致美学与高效生产力之间找到完美平衡。

一、设计理念

在信息过载的时代，我们需要的不是更多的功能，而是更专注的记录体验。墨拾笔记的设计遵循以下原则：

  • 美学优先 — 每一个像素都经过精心打磨，让记录成为一种享受
  • 本地优先 — 数据存储在本地，隐私有保障，离线也能用
  • 极简高效 — 核心功能做到极致，多余功能一概不要
  • 开放格式 — 支持导出为纯文本，数据永远属于你

二、核心功能

1. 树状笔记管理

通过多级目录结构，轻松构建你的知识体系。支持拖拽排序，让笔记整理像整理书架一样直观。

好的笔记工具应该像一本活的字典 —— 你想找什么，一翻就到。

2. 全局搜索

输入关键字，瞬间定位到任何笔记。支持标题搜索、正文搜索、标签筛选，让信息触手可及。

3. 灵活导出

支持单篇导出和批量导出，全部导出为纯净的 TXT 格式。你的数据不应该被锁在任何平台里。

// 导出示例
const exportNote = (note) => {
  const content = `# ${note.title}\n\n${note.body}`;
  downloadFile(`${note.title}.txt`, content);
};

4. 多端同步

基于云端的加密同步，让你的笔记在 Windows、macOS、Linux 之间无缝流转。端到端加密，只有你能看到你的内容。

三、技术栈

  1. 前端：Electron + React + TypeScript
  2. 编辑器：ProseMirror 富文本引擎
  3. 数据存储：SQLite + IndexedDB
  4. 同步服务：自建 WebDAV 兼容协议

四、写在最后

墨拾笔记不只是一个工具，它更是你思考的延伸。我们相信，好的工具能让思想流动得更顺畅，让灵感不被错过。

从今天开始，用墨拾，拾起每一个闪光的想法。
