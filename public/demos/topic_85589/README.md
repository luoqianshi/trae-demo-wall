# 暖邻 WarmNeighbor - 独居青年邻里互助应急小程序

## 📱 项目概述

暖邻 WarmNeighbor 是一款面向城市独居青年的同小区认证邻里互助平台，致力于构建安全、可靠、温暖的社区互助网络。

### 🏆 参赛赛道
生活服务 + 社会公益

### 🎯 核心功能

**1. 日常便民互助**
- 宠物照看、代买药品生鲜、大件搬运、结伴休闲等日常生活需求
- 让独居青年不再孤单

**2. 一键紧急应急求助**
- 突发状况时一键求助
- 基于 LBS 定位推送给周边 500 米内认证邻居
- 快速响应的应急救援网络

## 🚀 启动部署

### 前置条件

- Node.js >= 18.0.0
- npm >= 9.0.0
- 微信开发者工具（用于小程序预览）

### 步骤

#### 1. 安装依赖

```bash
cd WarmNeighbor
npm install
```

#### 2. 开发模式

**H5 开发**:
```bash
npm run dev:h5
```

**微信小程序开发**:
```bash
npm run dev:mp-weixin
```

#### 3. 构建生产版本

**H5 构建**:
```bash
npm run build:h5
```

**微信小程序构建**:
```bash
npm run build:mp-weixin
```

#### 4. 微信开发者工具导入

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目根目录 `WarmNeighbor`
4. AppID 选择"测试号"或填入自己的 AppID
5. 点击"确定"即可预览

## 🔄 业务流程模拟

### 应急求助链路
用户点击一键求助 → 获取模拟 LBS 定位 → 推送消息给周边 500 米小区邻居 → 邻居收到求助消息、查看位置详情 → 邻居线上接单沟通 → 线下上门帮扶 → 互助完成双方互评 → 更新用户邻里信用分

### 日常互助链路
用户发布互助任务 → 全小区认证邻居收到推送 → 邻居浏览任务接单 → 线上沟通需求 → 线下完成服务 → 互评积累信用分

## 📄 赛事作品简介

### 🌟 暖邻 - 让独居不再孤单

**参赛赛道**: 生活服务 + 社会公益

**产品亮点**:

1. **精准定位推送**：基于 LBS 定位技术，紧急求助信息精准推送给周边 500 米内的认证邻居，实现快速响应

2. **实名认证机制**：通过小区门禁验证、身份认证等多重手段，确保邻里关系真实可靠

3. **信用评分体系**：互助完成后双方互评，积累信用积分，构建社区信任生态

4. **温暖设计语言**：暖红色主色调传递温暖与安全，紧急按钮醒目易触达，交互简洁直观

**技术实现**: uni-app Vue3 + TypeScript + Vite，一套代码多端运行
