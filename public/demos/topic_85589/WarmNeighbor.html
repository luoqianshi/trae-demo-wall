三、产品说明

🎯 产品定位

暖邻 WarmNeighbor 是一款面向城市独居青年的同小区认证邻里互助平台，致力于构建安全、可靠、温暖的社区互助网络。通过实名认证、小区门禁验证等多重机制，确保邻里关系的真实性和安全性。

两大核心业务：

① 日常便民互助：涵盖宠物照看、代取快递、物资代买、家政帮忙、生鲜拼单、运动组队等日常生活需求，让独居青年不再孤单。

② 一键紧急应急求助：当用户遇到突发状况时，只需点击一键求助按钮，系统立即获取 LBS 定位并推送给周边 500 米内的认证邻居，形成快速响应的应急救援网络。

⚠️ 演示说明：

- 本原型为 TRAE 赛事作品演示 Demo，纯静态 HTML 实现，无外部依赖，浏览器直接打开即可使用

- 所有交互均为前端模拟，无需对接真实后端接口，数据为示例数据

- 页面采用模拟手机竖屏容器（375×812），还原微信小程序视觉尺寸

- 主色调暖红色 #ff6b6b，区分紧急红色警示按钮与普通灰色功能按钮

四、赛事作品介绍

🌟 暖邻 - 让独居不再孤单

参赛赛道：生活服务 + 社会公益

产品亮点：

1. 精准定位推送：基于 LBS 定位技术，紧急求助信息精准推送给周边 500 米内的认证邻居，实现快速响应

2. 实名认证机制：通过小区门禁验证、身份认证等多重手段，确保邻里关系真实可靠

3. 信用评分体系：互助完成后双方互评，积累信用积分，构建社区信任生态

4. 温暖设计语言：暖红色主色调传递温暖与安全，紧急按钮醒目易触达，交互简洁直观

技术实现：原生 HTML + CSS + JavaScript 开发，无第三方依赖，可直接运行演示
