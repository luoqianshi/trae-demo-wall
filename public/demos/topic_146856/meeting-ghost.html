🪄 会议幽灵如何运作

1
上传录音 / 实时接入
浏览器直接录音，或上传 MP3/M4A/WAV 文件。Chrome 插件可一键接入腾讯会议、Zoom、飞书会议。
2
实时语音转写
Web Speech API 实时识别中文普通话，边说边出文字。可选接入火山引擎 ASR 获得更强识别能力。
3
AI 智能提取
大语言模型提取 3 句话摘要、结构化行动项（谁 / 做什么 / 截止时间）、待确认问题清单。
4
一键导出 & 历史检索
导出 Markdown 纪要，会议自动存入 LocalStorage，按关键词搜索历史摘要和行动项。
