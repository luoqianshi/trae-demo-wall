# 幽灵相册小程序实现计划

## Summary

本项目是一个原生微信小程序，用于把照片和视频导入到小程序本地沙盒中，作为不依赖云端的私密相册工具。产品流程为：首次进入展示产品介绍页，用户设置本地密码后进入首页；后续启动先解锁；首页管理相册集；相册详情页展示照片和视频，支持导入、预览、播放和删除。

UI 风格基于 `/Users/tianyou/Desktop/my-profile/Ghost Album UI Design` 中的 Figma 代码工程迁移，保留暗色隐私工具风格、幽灵 logo、紫色主色、青色强调色、发光边框、相册卡片和媒体网格布局。

## Product Flow

1. 首次启动进入产品介绍页。
2. 介绍页展示产品简要亮点和使用弊端。
3. 点击开始使用后弹出设置密码窗口。
4. 密码保存到小程序本地沙盒，不保存明文。
5. 设置成功后进入首页。
6. 后续启动进入解锁页，密码验证通过后进入首页。
7. 首页展示顶部 logo、添加相册集按钮、搜索框和相册集列表。
8. 点击相册集进入详情页。
9. 相册详情页展示本相册内照片和视频。
10. 用户可从系统相册或微信聊天中选择照片、视频导入。
11. 点击照片进行预览，点击视频进行播放。

## Intro Page Content

介绍页需要明确输出产品亮点：

- 无需上传云端，照片和视频仅保存在本机小程序沙盒。
- 适合存放不希望出现在系统相册中的私密照片和视频。
- 使用本地密码保护，进入小程序前需要解锁。
- 支持从系统相册和微信聊天选择照片、视频导入。

介绍页也必须明确输出使用弊端：

- 清除小程序、清理微信缓存、卸载微信或更换设备，可能导致数据永久丢失。
- 第一版不提供云备份、跨设备同步或密码找回能力。
- 重要文件需要用户自行确认已有其他备份。

## UI Direction

- 使用原生微信小程序实现，不引入 React、Tailwind、Taro 或 uni-app。
- 将 Figma 设计中的视觉语言迁移为 WXML/WXSS。
- 主题色：
  - Background: `#070714`
  - Card: `#0d0e1e`
  - Primary: `#7c6fff`
  - Accent: `#00d4ff`
  - Foreground: `#e8eaf6`
- 保留圆形图标按钮、发光主按钮、暗色搜索框、底部导航、隐私 badge 和三列媒体网格。
- 小程序界面不直接使用 logo 切图，继续使用 `components/ghost-logo` 组件。
- `assets/` 中保留 Figma logo 规范导出的独立设计资产。

## Pages

- `pages/intro/intro`：首次介绍页和设置密码弹窗。
- `pages/unlock/unlock`：密码解锁页。
- `pages/index/index`：相册集首页。
- `pages/album/album`：相册详情页和媒体导入入口。
- `pages/preview/preview`：图片预览和视频播放页。

## Data And Storage

- 密码保存为本地摘要，不保存明文。
- 相册索引使用 `wx.setStorageSync` 保存。
- 媒体索引使用 `wx.setStorageSync` 保存。
- 导入媒体后复制到小程序本地沙盒，并保存持久文件路径。
- 删除媒体时同步删除本地文件和索引记录。
- 删除相册时同步删除该相册下的媒体索引和本地文件。

## Media Import

- 从系统相册导入：使用 `wx.chooseMedia`。
- 从微信聊天导入：使用 `wx.chooseMessageFile`。
- 导入入口使用底部弹窗，让用户选择导入来源。
- 支持图片和视频。
- 图片进入预览，视频使用小程序 `video` 组件播放。

## Out Of Scope For V1

- 不实现云同步。
- 不实现账号体系。
- 不实现备份恢复。
- 不实现跨设备迁移。
- 不实现密码找回。
- 不实现生物识别。
- 不承诺真实媒体文件加密；文案使用“本地保存”“密码保护”“不上传云端”。
