# Ghost Album / 幽灵相册

原生微信小程序 MVP，用于把照片和视频导入到小程序本地沙盒中，避免继续出现在系统相册中。

## 功能

- 首次进入展示产品介绍页，说明产品亮点和本地存储弊端。
- 首次使用设置本地密码，后续进入小程序需要先解锁。
- 创建相册集、搜索相册集、进入相册详情。
- 从系统相册选择照片/视频导入。
- 从微信聊天文件选择照片/视频导入。
- 导入文件会复制到小程序沙盒，并保存本地索引。
- 图片可预览，视频可播放，支持删除媒体或相册集。

## 重要说明

本项目第一版不使用云开发、不上传云端、不提供跨设备同步或备份恢复。清除小程序、清理微信缓存、卸载微信或更换设备都可能导致已导入内容永久丢失。
