Architecture · 技术架构

Pipeline Industriel · 3 Modules

TRAE comme chef d'orchestre. Chaque module testé avant passage au suivant. Fallback offline garanti sur chaque étape.
TRAE作为总控，三模块流水线。逐个验证方可推进。每一步均有离线兜底。

Module 02 · Atomiseur

atomize.py · 章节拆解

Prend un chapitre texte brut. Demande au LLM (DeepSeek) de générer un manifest JSON : 5 beats narratifs, émotion, pause, paire FR/ZH.

  • INPUT : .txt (chapitre UTF-8)
  • OUTPUT : manifest.json (5 beats FR+ZH)
  • API : DeepSeek Chat · fallback sample.json
  • VALIDATION : JSON Schema + re-ask
  • TEMPS : ~18s · retry 3x max
Module 01 · Audio

render_audio.py · 音频合成

Pour chaque beat, appelle MiniMax TTS. Si échec, bascule sur demo_cache/. Mesure la durée réelle avec ffprobe. Génère les 2 SRT.

  • INPUT : manifest.json
  • OUTPUT : episode.mp3 · fr.srt · zh.srt
  • API : MiniMax T2A V2 · fallback mp3
  • SYNC : ffprobe ms offset cumulatif
  • NORMALISATION : loudnorm I=-16 LUFS
Module 03 · Vidéo

render_video.py · 视频渲染

Assemble l'illustration + l'audio + les sous-titres. 1080×1920 vertical. Ken Burns 8s cycle. ZH en haut, FR en bas. H.264 + AAC.

  • INPUT : episode.mp3 · fr.srt · zh.srt · .png
  • OUTPUT : episode.mp4 (9:16 · H.264)
  • MOTEUR : FFmpeg libx264 · AAC 192k
  • EFFETS : zoompan Ken Burns · burn-in subs
  • LOUDNESS : loudnorm I=-14 · TP=-1

① 过去 · 开发踩坑
失败教训 · Chronologie des échecs
API 域名错误
MiniMax TTS 连续 3 次误用 .chat / .io 镜像域，导致 登录失败 1004 与 跨域 2049，排查 45 分钟才定位到官方 .com 主域。
TTS 余额归零
返回错误码 1008「余额不足」，降级 demo_cache 文件夹素材实际是 ffmpeg anullsrc 静音帧，音量 < −91 dB，完全听不到声音，音频管线看起来正常却无声。
法语语音 ID 无效
语音模型 speech-2.8-hd 无认证法语女声库，调用返回 2054「voice_id 不存在」，最终按官方规范统一回退到 1 位认证中文男声作为备用规范实现。
UI 1~3 版全崩
版本 1~3：12+ 混乱色值；视频硬烧字幕叠加 DOM 字幕双写；负空间几乎为 0；Web Speech API 同时触发法语 + 中文合成双轨，严重串音叠读。

③ 未来 · 开发路线图
Roadmap · 三阶段规模化
[1] MiniMax 账户充值
补全余额后无需改动任何管线代码即可直接启用法语原声 TTS 男声声优列表，架构层对 speech-2.8-hd 已完成官方规范实现。
[2] 垂直视频渲染管线
render_video.py 产出 1080 × 1920 9:16 竖屏，每 8 秒 Ken Burns 推拉运镜，硬烧字幕（中文字幕上排，法文字幕下排），响度归一化 −14 LUFS。
[3] LLM 自动拆拍
atomize.py 接入 DeepSeek LLM，由任意原文章节原文自动生成 5 拍 JSON manifest，含情感标签、停顿时长 pause_after_ms、法中翻译句对。
[4] 平台级扩展
多语言覆盖（德/西/俄/阿），作品万神殿画廊陈列页，自托管 VOD 点播流媒体，社区用户逐拍打分 + 推荐系统形成飞轮。
[5] 出版变现节奏
每周 1 集公版经典微短剧发行，长章节扩至 10 分钟付费模式，沉淀为可重复可扩展的微短剧内容工厂。
