## 项目简介

**乐游伴侣**是一款面向银发群体的智能出游助手，基于 TRAE AI 平台开发。核心目标是帮助老年人解决"想出游但不会规划、不愿麻烦子女"的痛点，让银发族也能安心、舒适、有尊严地享受旅行乐趣。

## 适老化设计原则

1. **大字体、大按钮**：正文≥18px，按钮高度≥48px
2. **高对比度配色**：深绿色主色调(#1d6b4a)，清晰易辨
3. **简化操作流程**：点选为主，减少文字输入
4. **容错设计**：关键操作有确认提示，防止误触
5. **隐私保护**：不强制要求真实身份信息
6. **多模态呈现**：文字、语音、纸质卡片多种方式

## 产品亮点

### 1. 渐进式资料完善
不强迫老人一开始填写敏感信息，先体验行程规划，体验后再温柔引导补充资料，更符合老年人的使用心理。

### 2. AI驱动的个性化规划
基于 TRAE AI 能力，综合考虑用户的身体状况、步速、轮椅需求、视力听力等因素，自动生成最适合的行程方案。

### 3. 多模态适老化呈现
- 文字版：大字体、高对比度
- 语音版：语速可调、随时暂停
- 纸质版：一键打印，手机没电也能用

### 4. 子女协同机制
子女不只是被动查看行程，还可以参与标注修改，形成更顺畅的家庭沟通，让"父母想出去走走"变成一件更安心的事情。

### 5. 全方位安全保障
- 紧急求助入口：一键展示120和子女电话
- 出行前确认：清单式检查，降低出行风险
- 防骗提醒：针对老年游客的常见骗局预警

## 目标用户

### 第一优先级：老年人（55岁+）
- 有短途出游意愿
- 想自己规划行程，不想总麻烦子女
- 关心路线强度、休息点、卫生间、医疗点等实际问题

### 第二优先级：子女
- 希望父母多出去走走，但担心安全
- 想了解父母的行程安排
- 节假日/纪念日想为父母规划旅行

## 使用场景

1. **老人独自规划**：周末去附近公园或古镇，打开应用选择目的地即可生成慢节奏行程
2. **边走边听**：出行当天查看文字行程，或使用语音播报边走边听
3. **子女协同**：子女收到共享版后快速了解父母行程，可提出修改建议
4. **备用方案**：担心手机没电，提前打印纸质行程卡随身携带
5. **跟团辅助**：报团出游前，用乐游伴侣提前了解行程和注意事项

## 价值与意义

### 对老人
能够自己决定去哪里、怎么走、在哪里休息，是一种更有尊严的生活体验。乐游伴侣把复杂的查攻略、选路线、找设施，变成简单的点选和清晰的行程卡，让老人少一点不确定，多一点掌控感。

### 对子女
乐游伴侣能把父母的出游安排清楚地呈现出来，减少反复询问和担心，让"父母想出去走走"变成一件更安心、更容易支持的事情。

### 对社会
推动智慧助老，让老年群体也能享受到AI技术带来的便利，促进积极老龄化。
