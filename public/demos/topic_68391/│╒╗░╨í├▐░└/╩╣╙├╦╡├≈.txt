痴话小棉袄 —— 使用说明
========================


一、准备工作
------------

1. 安装 Ollama
   - 下载地址：https://ollama.com/download
   - 安装完成后，打开命令行输入以下命令确认安装成功：
     ollama --version

2. 下载模型
   - 打开命令行，执行：
     ollama pull granite4.1:3b
   - 等待下载完成（约 2GB）
   - 下载其他模型同理，例如：
     ollama pull qwen3:4b

3. 启动 Ollama 服务
   - 安装完成后 Ollama 默认自动后台运行
   - 如果没有自动运行，在命令行输入：
     ollama serve
   - 保持该窗口不要关闭


二、启动小棉袄
--------------

方式一：双击启动（推荐）
  直接双击目录里的「启动小棉袄.bat」
  浏览器会自动打开 http://localhost:3456

方式二：命令行启动
  1. 打开命令提示符（cmd）
  2. 切换到本目录，例如：
     cd /d "E:\Trae SOLO Files\痴话小棉袄"
  3. 运行：
     node server.js
  4. 浏览器手动访问 http://localhost:3456


三、操作手册
------------

【对话空间】—— 和伴灵聊天
  - 打开页面后直接在底部输入框输入心事，回车或点击发送
  - 左侧显示历史会话列表，点击可切换，点 + 新建对话
  - 右侧显示本次对话的标签、心情、字数等信息
  - 对话结束后系统会自动分析生成标题、摘要和标签

【伴灵设置】—— 配置你的伴灵
  - 点击左侧导航第二个图标进入设置
  - 模型连接：默认使用本地 Ollama，地址 http://localhost:11434，模型 granite4.1:3b
  - 切换公网 API：关闭「使用本地模型」开关，填写 API 地址和密钥
  - 性格预设：温柔倾听 / 哲理引导 / 灵感碰撞，选择后点保存即生效
  - 伴灵名字：可自定义，比如把「天一」改成你喜欢的名字
  - 系统提示词：可以微调伴灵的说话风格，修改后点保存

【思绪归档】—— 翻阅过往
  - 点击左侧导航第二个图标进入归档
  - 按月份分组展示所有历史对话
  - 支持按标签筛选：全部 / 深夜倾诉 / 灵感记录 / 情绪梳理 / 哲学思考
  - 支持关键词搜索
  - 点击「写一条思绪」可手动记录想法、感悟、心情，不需要和伴灵对话
  - 点击归档中的对话可跳转回对话空间查看详情

【懂你的心】—— 伴灵更懂你
  - 点击左侧导航第三个图标进入画像
  - 聊够一定量后，点「重新分析」可自动生成你的专属画像
  - 画像包含：常聊话题、情绪倾向、表达风格、内心关注点、陪伴建议
  - 画像内容可手动编辑修改
  - 开启「将画像融入对话」后，伴灵回复时会参考你的画像，越聊越懂你
  - 融入强度可选：轻度 / 中度 / 深度


四、常见问题
------------

Q: 打开页面后左侧状态显示「离线」？
A: 说明 Ollama 没有运行。打开命令行输入 ollama serve 启动它。

Q: 发送消息后报错「Ollama 连接失败」？
A: 检查 Ollama 是否在运行，端口是否为默认的 11434。
   在命令行测试：ollama list
   如果能看到模型列表说明 Ollama 正常。

Q: 想换其他模型怎么操作？
A: 先用 ollama pull 模型名 下载，然后在「伴灵设置」里修改模型名称，保存即可。

Q: 所有数据存在哪里？
A: 全部在目录下的 data\chat.db 文件中，纯本地，不会上传任何网络。
   备份这个文件即可备份所有对话和设置。

Q: 怎么停止服务？
A: 双击 bat 启动的，直接关闭黑色窗口。
   命令行启动的，按 Ctrl+C。
