# 轻诗阁 Demo 版本

## 简介
这是「轻诗阁」诗词学习应用的纯前端演示版本，无需安装本地服务器，可直接在浏览器中打开运行。

## 快速开始
1. 双击 `index.html` 即可在浏览器中打开
2. 建议使用 Chrome、Edge、Firefox 等现代浏览器
3. 无需联网（图片和数据均已内置

## 包含页面
- **index.html** - 首页：诗词展示、快捷入口、诗词库、诗人大全
- **poem.html** - 诗词详情页：原文、译文、赏析、诗人简介
- **search.html** - 搜索页：按关键词搜索诗词
- **feihualing.html** - 飞花令游戏：关键字诗词对战
- **ai-vision.html** - AI识图：看图猜诗（模拟版）
- **poet.html** - 诗人页：诗人列表与详情

## 技术特点
- 纯前端实现，无需后端服务器
- 80首经典诗词，配高清意境背景图
- 古韵水墨风格UI设计
- 粒子动画与背景装饰效果
- 响应式布局，支持移动端
