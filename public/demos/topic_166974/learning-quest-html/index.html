第3章：封装与访问控制

Python进阶之路 · 3/8

封装的概念

理解数据隐藏和访问控制

封装是面向对象编程的三大特性之一。它指的是将数据和操作数据的方法绑定在一起，并隐藏对象内部的实现细节，只通过公开的接口与外界交互。

class Person:
    def __init__(self, name, age):
        self.__name = name  # 私有属性
        self.__age = age    # 私有属性
    
    def get_name(self):
        return self.__name
    
    def set_name(self, name):
        if len(name) > 0:
            self.__name = name

在Python中，使用双下划线 __ 开头的属性或方法会被解释器改名，形成所谓的"名称修饰"，从而实现数据隐藏。

访问控制级别

公

公开属性

使用普通变量名，如 self.name，可以被外部直接访问。

保

保护属性

使用单下划线 _ 开头，如 self._name，表示不建议外部访问。

私

私有属性

使用双下划线 __ 开头，如 self.__name，会被名称修饰。

知识总结

  • 封装可以保护数据完整性，防止外部直接修改对象内部状态
  • 通过getter和setter方法提供受控的访问接口
  • Python的私有属性通过名称修饰实现，并非真正的强制私有

代码示例

class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # 私有属性
    
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return True
        return False
    
    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            return True
        return False
    
    def get_balance(self):
        return self.__balance

# 使用示例
account = BankAccount(1000)
account.deposit(500)
print(account.get_balance())  # 输出: 1500

什么是封装？

封装是面向对象编程的三大特性之一（封装、继承、多态）。封装指的是将数据（属性）和操作数据的方法（行为）绑定在一起，并对外部隐藏对象的内部实现细节。

核心概念

封装的目的是为了保护数据，防止外部直接访问和修改对象的内部状态，只通过公开的接口与对象进行交互。

封装的优点

  • 数据安全性：防止外部直接修改对象内部状态
  • 代码复用：封装的方法可以被多次调用
  • 易于维护：修改内部实现不影响外部代码

Python中的访问控制

在Python中，虽然没有严格的访问控制修饰符（如Java的private、protected），但通过命名约定实现了类似的效果。 

class Person:
    def __init__(self, name, age):
        self.name = name      # 公共属性
        self._age = age       # 受保护属性
        self.__salary = 5000  # 私有属性
    
    def get_salary(self):
        return self.__salary
    
    def set_salary(self, value):
        if value > 0:
            self.__salary = value

getter和setter方法

对于私有属性，我们通常通过getter和setter方法来访问和修改它们。Python也提供了property装饰器来实现更优雅的属性访问方式。 

class Person:
    def __init__(self, name, age):
        self.name = name
        self._age = age
    
    @property
    def age(self):
        return self._age
    
    @age.setter
    def age(self, value):
        if 0 <= value <= 120:
            self._age = value
        else:
            raise ValueError("年龄必须在0-120之间")

p = Person("张三", 25)
print(p.age)   # 25
p.age = 30     # 设置年龄
print(p.age)   # 30

题目描述

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。

示例

输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1]。
输入：nums = [3,2,4], target = 6
输出：[1,2]

提示

  • 2 <= nums.length <= 10^4
  • -10^9 <= nums[i] <= 10^9
  • -10^9 <= target <= 10^9
  • 只会存在一个有效答案

代码编辑器

简单 两数之和 Python
solution.py 
class Solution:
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        hash_map = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in hash_map:
                return [hash_map[complement], i]
            hash_map[num] = i
        return []

class Solution:
    def twoSum(self, nums, target):
        hash_map = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in hash_map:
                return [hash_map[complement], i]
            hash_map[num] = i
        return []

算法分析

时间复杂度
O(n) - 线性遍历数组

算法只遍历数组一次，每次查找和插入操作都是 O(1)，因此总时间复杂度为 O(n)。

空间复杂度
O(n) - 使用哈希表存储

最坏情况下，需要将所有 n 个元素存入哈希表，因此空间复杂度为 O(n)。

代码优化建议

优点

使用哈希表实现了最优的时间复杂度，代码简洁清晰，变量命名规范。

优化建议

可以添加类型提示增强代码可读性，使用更具描述性的变量名如 seen 替代 hash_map。

解题思路

1

哈希表存储

使用哈希表（字典）存储已经遍历过的数字及其索引，key 为数字值，value 为索引。

2

查找补数

对于每个数字，计算 target - num，检查补数是否在哈希表中，如果存在则返回结果。

3

存储当前值

如果补数不在哈希表中，将当前数字和索引存入哈希表，继续遍历。

复杂度分析

时间复杂度
O(n)
只遍历数组一次
空间复杂度
O(n)
最坏情况存储所有元素

扩展思路

如果需要处理多个解，可以返回所有符合条件的索引对，使用列表存储结果。

如果数组已排序，可以使用双指针法，空间复杂度优化为 O(1)。

可以使用 collections.defaultdict 简化代码，但性能略低于普通字典。

Python装饰器怎么理解？

陈

装饰器本质上是一个函数，它接受一个函数作为参数并返回一个新函数。

简单理解：

def log(func):
  def wrapper(*args, **kw):
    print('call %s()' % func.__name__)
    return func(*args, **kw)
  return wrapper

@log
def hello():
  print('hello world')

@log 就是装饰器语法糖，等同于 hello = log(hello)
