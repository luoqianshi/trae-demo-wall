📚 期末复习规划助手 - 项目说明
=============================================

【这是什么】
一个纯前端的期末复习时间规划 Web 应用（PWA）。
把你的可用时间段、考试日期、科目难度、复习重点输入进去，
自动生成排到考前每一天的复习计划。

【技术栈】
- 纯 HTML + CSS + JavaScript（ES Module）
- localStorage 持久化（数据存浏览器本地，不联网）
- PDF.js / Tesseract.js / JSZip（CDN 加载，做重点提取）
- Service Worker（支持离线 + 安装到桌面）

【目录结构】
index.html            主页面
styles.css            全部样式
service-worker.js     离线缓存（PWA）
manifest.json         PWA 清单
js/                   14 个 JS 模块
  ├ app.js            主入口，串联所有模块
  ├ scheduler.js      智能排程算法（艾宾浩斯曲线 + 4 维权重）
  ├ storage.js        localStorage 读写
  ├ time-grid.js      7×24 时间热力图
  ├ points-generator.js  重点知识库（60+ 大学科目）
  ├ points-picker.js  重点选择弹窗
  ├ extractor.js      PDF/Word/图片/文本 重点提取
  ├ demo-data.js      演示数据生成器
  ├ dashboard.js      仪表盘图表
  ├ ai-assistant.js   AI 助手对话
  ├ focus-mode.js     番茄钟专注模式
  ├ reminder.js       提醒通知
  ├ particles.js      背景动画
  └ utils.js          工具函数（XSS 防护、转义等）
demo.html             静态展示页（不开服务器也能看）
启动.bat              Windows 双击启动脚本
README.md             详细使用说明

【怎么运行】
方法 1（最简单）：
  双击 "启动.bat" 即可
  （会检查 Node.js，没有的话请先装 https://nodejs.org/）

方法 2（VSCode 用户）：
  1. 用 VSCode 打开本文件夹
  2. 安装插件 "Live Server"
  3. 右键 index.html -> "Open with Live Server"

方法 3（手动）：
  1. 安装 Node.js (https://nodejs.org/)
  2. 在本目录下打开 PowerShell
  3. 运行: npx http-server -p 8765 -c-1
  4. 浏览器打开 http://localhost:8765

【主要功能】
1. 科目管理
   - 添加科目（名称、难度、模拟考分、复习重点）
   - AI 推荐重点（60+ 科目知识库，"高数"自动匹配"高等数学"）
   - 上传 PDF/Word/图片/文本，自动提取重点
   - 右键重点可标记为弱项

2. 时间设置
   - 7×24 时间热力图，可视化点击设置每天可复习时间
   - 列表视图更精细
   - 设置开始日期 + 结束日期（考试日）

3. 复习计划（核心）
   - 智能算法：4 维权重（难度 + 弱项 + 模拟考分 + 完成率）
   - 艾宾浩斯遗忘曲线：第 0/1/3/7/15 天自动复习
   - 自定义曲线间隔
   - "❌ 不会"按钮：标记做错的，自动插入"补课"项
   - 标记完成/未完成，跟踪进度

4. 仪表盘
   - 每日复习时长分布
   - 科目完成度
   - 弱项集中度

5. AI 助手
   - 自然语言对话，问复习策略
   - 基于你的科目数据给出建议

6. 专注模式
   - 番茄钟（25/5/15 分钟）
   - 白噪音（雨声/咖啡馆/森林）
   - 屏蔽其他 tab 干扰

7. 其他
   - 演示数据（7/14/30 天场景）
   - 导入/导出 JSON
   - 暗色模式
   - PWA 安装到桌面
   - 离线可用

【使用流程示例】
1. 打开应用 -> 点 "演示数据" -> 选 "中期备考（14天）"
2. 切到 "复习计划" -> 点 "🚀 生成复习计划"
3. 看到 14 天排好的计划，每条都有 "标记已完成" + "❌ 不会"
4. 复习时点 "❌ 不会" -> 确认 -> 系统自动在下一个空位插入"补课"项
5. 点 "间隔调整" -> 调整艾宾浩斯曲线 -> "应用并重新生成"

【数据安全】
- 所有数据存在浏览器 localStorage
- 不上传任何服务器
- "导出数据"按钮可生成 JSON 备份
- "导入数据"可恢复备份

【已知限制】
- 必须用 HTTP 服务器（不能双击 index.html 打开）
  - 因为用了 ES Module import，浏览器 file:// 协议不支持
- 提取图片重点用的是 Tesseract.js（CDN），需要联网
  - 其他功能完全离线可用

【常见问题】
Q: 启动.bat 闪退？
A: 打开 cmd（不是 PowerShell）运行，或检查 Node.js 是否装好

Q: 浏览器打开是空白？
A: 大概率是 SW 缓存问题，访问 http://localhost:8765/clear-sw.html
   点"立即清理"即可

Q: AI 推荐重点没结果？
A: 知识库覆盖 60+ 大学常见科目，少数小众科目需要手动输入
