# 〖学习工作赛道〗WeatherLoad Pilot：天气驱动的企业负荷与光伏影响分析 Demo

## 1. 项目背景

在智慧用能和电力交易领域，企业的平台负荷并不直接等于真实用电需求。分布式光伏会在中午时段抵消大量用电，使平台负荷出现"中午下凹"的现象；而高温、梅雨、闷热夜间等天气因素又会显著改变真实用电需求。对于刚进入该领域的实习生和分析人员来说，如果只看单一的负荷曲线，很难解释清楚负荷变化的真实原因。

WeatherLoad Pilot 正是为解决这一问题而生——它把天气情景、分布式光伏、企业真实用电和平台负荷放到同一个页面里，用可交互的方式帮助用户快速理解负荷变化背后的逻辑。

### 面向人群

- 刚接触智慧用能、电力交易、负荷预测的实习生
- 需要向业务同事解释负荷变化原因的能源分析人员
- 关注分布式光伏对企业用电曲线影响的园区管理人员
- 希望快速理解"真实用电、光伏抵消、平台负荷"三者关系的非专业用户

### 选题价值

- 选题来自真实工作场景，不是为了比赛硬凑功能
- 把复杂的电力负荷概念拆成三条可对比的曲线，降低理解门槛
- 自动生成可复制的业务解读文本，直接满足日报/周报需求

## 2. 功能介绍

### 2.1 参数输入区

支持调整以下参数，实时联动所有图表和指标：

| 参数 | 说明 | 范围 |
|------|------|------|
| 测试城市 | 选择分析城市（苏州/无锡/南京/常州） | 下拉选择 |
| 天气情景 | 预设天气模式（晴热高辐照/多云/梅雨/闷热夜间） | 下拉选择 |
| 日基准用电量 | 企业单日基础用电规模 | 40-260 MWh |
| 分布式光伏装机 | 企业屋顶光伏装机容量 | 0-5000 kW |
| 日最高气温 | 当日最高气温 | 22-42 ℃ |
| 日降水量 | 当日降水量 | 0-80 mm |

### 2.2 24小时负荷拆解图表

使用 Canvas 绘制三条核心曲线，直观展示全天负荷变化：

- **真实用电（紫色）**：企业实际消耗的电量，受气温、降水和生产节奏影响
- **光伏抵消（橙色）**：分布式光伏产生的电量，主要集中在白天
- **平台负荷（蓝色）**：企业实际从电网购买的电量，即真实用电减去光伏抵消

### 2.3 关键指标卡片

展示四个核心指标，适合放在汇报第一页：

- 真实用电预测（MWh）
- 光伏抵消量（MWh）
- 平台负荷（MWh）
- 天气修正影响（%）

### 2.4 相似日解释

根据气温、降水和光伏情景匹配历史相似日，辅助解释当前负荷变化：

- 自动计算相似度得分（综合气温45%、降水25%、光伏情景30%）
- 展示相似日的日期、天气标签、气温、降水和历史真实用电

### 2.5 业务解读文本

自动生成可复制的业务解释文本，包含：

- 当前天气和光伏情景的定性描述
- 核心指标的量化预测
- 小时曲线的关键时段分析
- 业务判断建议

## 4. 安全说明

### 4.1 数据说明

⚠️ **重要声明**：本项目使用模拟数据，不涉及真实企业系统、真实用电数据或真实光伏出力数据。

- 所有天气情景和历史数据均为模拟生成
- 负荷计算基于简化的数学模型，不代表真实预测结果
- 不存储任何用户输入数据，不发送到外部服务器

### 4.2 使用限制

- 本 Demo 仅用于演示天气对负荷影响的分析方法
- 不构成任何投资或运营决策建议
- 不得用于实际生产环境的负荷预测或电力交易

### 4.3 隐私保护

- 所有计算均在浏览器本地完成
- 不收集任何用户信息
- 不依赖外部 API（除 Canvas 渲染外）
