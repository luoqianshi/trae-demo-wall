# 归位 App - 功能演示包

> 这是一个纯前端演示包，用于展示「归位」App 的核心功能与交互体验。
> 所有数据保存在浏览器本地（localStorage），无需后端、无需联网、无需安装。

## 快速开始（3 种方式任选）

### 方式一：双击打开（最简单）
直接双击 `index.html`，用浏览器打开即可。
> 注：部分浏览器对本地文件有限制，推荐使用下面两种方式获得最佳体验。

### 方式二：Python（推荐）
需要已安装 Python 3。在解压后的文件夹中运行：
```bash
python -m http.server 8090
```
然后浏览器访问 http://localhost:8090

### 方式三：Node.js
需要已安装 Node.js。在解压后的文件夹中运行：
```bash
npx serve .
# 或
npx http-server -p 8090
```
然后访问终端提示的地址。

## 演示流程建议

1. 打开后会自动进入「功能演示」首页
2. 点击 **加载示例数据** —— 一键填入房子/楼层/房间/容器/物品的示例数据
3. 在「功能演示」卡片网格中依次体验：
   - 添加房子 / 楼层 / 房间 / 容器 / 物品（含 4 级位置选择器）
   - 浏览层级、查看物品列表、扫码识别、查看物品详情
4. 点击 **清空数据** 可随时重置

## 功能清单

| 模块 | 说明 |
|------|------|
| 房子 House | 最顶层空间 |
| 楼层 Floor | 房子下分层（支持负数楼层） |
| 房间 Room | 楼层内的房间 |
| 容器 Container | 房间内收纳物，支持任意深度嵌套（柜子→抽屉→分隔盒） |
| 物品 Item | 最终被收纳的对象，位置可为「房间」或「容器」之一 |
| 一物一码 | 每个实体拥有专属二维码，扫码即跳转详情 |
| 层级浏览 | 按房子→楼层→房间逐层钻取 |
| 物品搜索 | 按名称、备注、标签全文搜索 |
| 多端适配 | 手机 / 平板 / 桌面 / 大屏自适应 |

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖、零构建
- 数据存储于浏览器 localStorage，关闭浏览器后仍保留
- 不同浏览器、不同标签页的数据相互独立

## 常见问题

**Q：数据存在哪里？会被上传吗？**
A：全部存在你本地浏览器的 localStorage 中，不会上传到任何服务器。清空浏览器缓存或点击「清空数据」即可删除。

**Q：换一台电脑数据还在吗？**
A：不在。数据仅存在于当前浏览器中。

**Q：手机上能用吗？**
A：可以。页面已做移动端适配，用手机浏览器打开即可。

**Q：二维码怎么扫？**
A：演示页的「扫码识别」会随机选取一个已有实体的码并模拟扫码跳转。真实扫码功能需配合 App 端使用。
