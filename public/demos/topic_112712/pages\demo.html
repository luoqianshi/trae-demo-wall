SECTION 3

数据模型

归位 App 的核心数据结构：5 层嵌套、多态 Code 表、XOR 位置不变量。

5 层嵌套结构 层级
House → Floor → Room → Container（可自引用嵌套）→ Item
House 房子 → Floor 楼层 → Room 房间 → Container 容器 → Item 物品
↻ Container 通过 parentContainerId 自引用，支持任意深度嵌套（如 柜子 → 抽屉 → 分隔盒）
多态 Code 表 一物一码
每个实体拥有一个 QR code，payload 格式 guiwei://code/<uuid>
Code 表
(ownerType, ownerId) →
house floor room container item
扫码后由 ownerType 路由到对应实体详情，多态关联任一表。
XOR 位置不变量 约束
物品的位置必须且仅能归属于"容器"或"房间"之一
Item 物品 →
containerId（放在某个容器内） roomId（散放于房间中）
XOR：containerId 与 roomId 有且仅有一个非空，由 validateXor 在写入时强制校验。
