# 成长漂流瓶

一款以「成长 + 陪伴」为核心的轻量级 H5 应用，帮助用户通过每日打卡、任务管理、挑战坚持、漂流瓶互动等方式记录成长足迹，并与搭子互相鼓励、共同进步。

## 项目功能

### 核心模块

- **今日打卡** — 创建每日任务，完成打卡（支持图片上传与心情记录），查看当月打卡日历与成长指数
- **漂流海洋** — 浏览/发布漂流任务，随机捞瓶（带打捞动画），点赞评论，我也要做
- **挑战营** — 参与成长挑战，每日打卡推进进度，查看挑战详情与营友动态
- **往年今日** — 回顾历年同一天的打卡记录，时间轴形式呈现成长足迹
- **时间胶囊** — 给未来的自己写信，设定开启时间（1个月/3个月/6个月/1年/2年/3年后），到期开启
- **沉浸式专注计时器** — 全屏背景专注计时，支持退出二次确认
- **成长等级** — 经验值积累升级，等级详情展示
- **徽章墙** — 展示已获得徽章与未解锁徽章
- **每周成长报告** — 汇总本周打卡、任务、专注时长等数据

### 社交功能

- **搭子系统** — 申请结伴、互相查看打卡、消息通知
- **消息中心** — 系统通知、搭子申请/通过、挑战动态

### 个人中心

- **个人主页** — 头像、昵称、个性签名、成长数据
- **编辑资料** — 修改头像、昵称、性别、个性签名、打卡提醒设置
- **找搭子** — 匹配合适的成长搭子

## 快速启动

### 1. 安装后端依赖

```bash
cd server
npm install
```

### 2. 启动后端服务

```bash
# 在 server 目录下执行
node server.js
```

## 技术说明

- **端口**：默认 `4736`（可在 `server/server.js` 中通过环境变量 `PORT` 修改）
- **数据库**：SQLite，文件位于 `server/data/growth_bottle.db`，首次启动自动建表
- **文件上传**：用户头像、打卡图片保存在 `uploads/` 目录
- **API 基地址**：前端通过 `nav.js` 中的 `API_BASE` 访问后端接口，默认 `http://localhost:4736/api`
- **页面路由**：前端为多页面应用（MPA），各页面通过 `nav.js` 统一管理导航与事件绑定

## 常见问题

**Q: 修改了 db.js 后数据库没更新？**
A: 需要重启 `node server.js`，数据库迁移在启动时执行。

**Q: 前端页面不生效？**
A: 强制刷新浏览器（Ctrl+Shift+R）清除缓存，或检查 `nav.js` 是否为最新版本。

**Q: 端口被占用？**
A: 修改 `server/server.js` 中的 `PORT` 常量，同时修改 `dist/nav.js` 中的 `API_BASE` 对应端口。
