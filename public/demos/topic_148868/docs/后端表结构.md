# 成长漂流瓶 — 后端表结构文档

## 项目说明

- **数据库类型**：SQLite
- **数据库文件路径**：`server/data/growth_bottle.db`
- **数据库驱动**：better-sqlite3
- **PRAGMA 设置**：
  - `journal_mode = WAL`（启用 WAL 日志模式，提升并发性能）
  - `foreign_keys = ON`（启用外键约束）
- **默认测试账号**：demo / 123456
- **密码哈希算法**：bcryptjs（cost = 10）

| email | TEXT | UNIQUE | NULL | 邮箱 |
| password_hash | TEXT | NOT NULL | - | 密码哈希值（bcrypt） |
| nickname | TEXT | - | NULL | 昵称 |
| avatar | TEXT | - | NULL | 头像路径 |
| level | INTEGER | - | 1 | 用户等级 |
| xp | INTEGER | - | 0 | 经验值 |
| bio | TEXT | - | '' | 个人简介 |
| gender | TEXT | - | 'secret' | 性别（male/female/secret，迁移新增） |
| birthday | TEXT | - | NULL | 生日 YYYY-MM-DD（迁移新增） |
| city | TEXT | - | NULL | 所在城市（迁移新增） |
| created_at | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | - | CURRENT_TIMESTAMP | 更新时间 |

| completed_at | DATETIME | - | NULL | 完成时间 |

### 迁移新增字段（ALTER TABLE ADD COLUMN）

| 字段名 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| show_in_ocean | INTEGER | 0 | 是否在漂流海洋展示（与基础字段重复，迁移脚本会判断是否存在） |

| tasks | description | TEXT DEFAULT "" | 任务描述 |
| tasks | task_date | TEXT | 任务日期 YYYY-MM-DD |
| tasks | completion_note | TEXT DEFAULT "" | 完成感受 |
| tasks | completion_images | TEXT | 完成图片（JSON 数组字符串） |
| tasks | is_cancelled | INTEGER DEFAULT 0 | 是否取消 |
| tasks | is_deleted | INTEGER DEFAULT 0 | 是否软删除 |
| challenge_participants | status | TEXT DEFAULT 'in_progress' | 参与状态 |
| users | gender | TEXT DEFAULT 'secret' | 性别 |
| users | birthday | TEXT | 生日 |
| users | city | TEXT | 所在城市 |
| messages | icon | TEXT | 消息图标 |

> 迁移是幂等的，重复执行不会报错。新增字段均使用默认值，不影响已有数据。
