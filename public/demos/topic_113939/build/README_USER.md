# PrivateCoach 使用说明

## 简介

PrivateCoach 是一款 AI-First 的健身记录 Web 应用。用自然语言（文字或语音）记录训练、查询数据、获取个性化建议——像和私教聊天一样完成所有操作。

## 快速开始

### 0. 启动

PrivateCoach无法通过双击html打开，需要http服务器进行解析，在文件夹所在的终端里运行以下任意一条命令即可：
> 方式 1（推荐，零依赖）：
> python -m http.server 8080

> 方式 2（如果没有 python）：
> npx serve . '''


### 1. 配置 API Key

使用 AI 功能前，需要配置 LLM API：

1. 点击底部 **设置** Tab
2. 填入你的 API Key（支持任意 OpenAI 兼容 API）
3. 如需调整模型，修改 **模型 ID**
4. 点击 **"测试并保存"** 验证连接

> 推荐使用 OpenAI API（`https://api.openai.com/v1/chat/completions`）或兼容的第三方服务。

### 2. 记录训练

打开 **AI助手** Tab，用自然语言记录训练：

| 表达方式 | AI 会做什么 |
|---------|------------|
| "今天练胸，卧推60kg 4组8次，深蹲80kg 4组8次" | AI 解析动作、重量、组数、次数，生成确认卡 |
| "今天练背，硬拉100kg 3组5次，感觉不错" | AI 同时解析训练数据和感受 |

点击确认卡上的 **"确认保存"** 即可写入训练记录。

### 3. 查询数据

在输入框直接提问：

| 问题 | 返回结果 |
|------|---------|
| "这周练了几次" | 训练次数统计 |
| "深蹲最近趋势怎么样" | 趋势图表 |
| "这个月和上个月比怎么样" | 月度对比卡片 |
| "这周练了什么" | 训练详情列表 |

### 4. 查看日历

点击 **日历** Tab，查看每月训练记录。点击日期可展开当天训练详情（动作 → 组数/次数/重量）。

> 也可以说 **"打开日历"** 或 **"看看这个月的训练"**。

### 5. 获取建议

说 **"给我一些训练建议"**，AI 会结合你的训练历史给出定制化方案。

### 6. 支持的操作

| 类型 | 示例 | 说明 |
|------|------|------|
| 记录 | "今天练腿，深蹲80kg 4组8次" | AI 解析后确认保存 |
| 查询 | "这周练了几次"、"深蹲最大重量进步了吗" | 返回数据/图表卡 |
| 复盘 | "这周练得怎么样" | AI 生成综合复盘 |
| 建议 | "给我一些训练建议" | 基于历史的个性化建议 |

## 技术说明

- **数据存储**：所有训练记录保存在浏览器本地（IndexedDB），无需注册账号
- **隐私**：API Key 仅保存在你的浏览器中，不会上传到任何服务器
- **离线可用**：已记录的训练数据可离线查看
- **支持 PWA**：可添加到手机主屏幕，像原生 App 一样使用
