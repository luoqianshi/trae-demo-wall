# 打工人的工具箱 🎮

一个像素风主题的Chrome浏览器扩展程序，提供多种实用工具，以侧边栏模式展示。

## ✨ 功能特性

### 1. 📱 二维码生成
- 输入文字或网址生成二维码
- 支持下载二维码图片
- 历史记录持久化保存

### 2. 📋 JSON格式化
- JSON格式化/压缩
- 语法高亮显示
- 一键复制结果
- 历史记录持久化保存

### 3. 📸 网页截屏
- 一键截取当前页面可见区域
- 支持下载保存和复制图片
- 保存路径可在设置中配置

### 4. 📝 TODO List
- 添加、完成、删除待办事项
- 统计已完成/未完成数量
- 一键清除已完成事项
- 数据持久化保存

### 5. 🍅 番茄钟
- 工作/休息计时循环
- 自定义工作时长和休息时长
- 长休息/短休息智能切换
- 今日番茄数和总工作时长统计

### 6. 📑 标签页管理
- 保存当前标签页到列表
- 点击快速打开保存的标签页
- 支持删除和清空操作

### 7. 📁 文件信息查看
- 支持拖拽或点击上传文件
- 支持图片（含GIF）、视频格式
- 显示文件大小、格式、分辨率、时长等信息
- 实时预览文件内容

### 8. ⬇️ 下载器
- 输入链接下载文件
- 自定义文件名
- 下载历史记录
- 保存路径可配置

## 🎨 界面特性

- **像素风主题**：复古8-bit风格设计
- **侧边栏模式**：不影响正常浏览
- **工具排序**：长按拖拽调整工具顺序
- **工具隐藏**：在设置中可隐藏不需要的工具
- **数据导入导出**：本地数据备份和恢复

## 🚀 安装方法

### 开发者模式安装

1. 打开Chrome浏览器，进入 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目的 `worker-toolbox` 文件夹
5. 安装完成后，点击工具栏中的扩展图标即可打开侧边栏

## ⚙️ 设置说明

### 通用设置
- **下载保存路径**：截屏和下载文件的保存目录（默认：Downloads）

### 番茄钟设置
- **工作时长**：每个番茄的工作时间（默认：25分钟）
- **短休息时长**：短休息时间（默认：5分钟）
- **长休息时长**：长休息时间（默认：15分钟）
- **长休息间隔**：每完成几个番茄进行一次长休息（默认：4个）

### 工具管理
- 拖拽调整工具显示顺序
- 点击开关显示/隐藏工具

### 数据管理
- **导出数据**：将所有数据导出为JSON文件
- **导入数据**：从JSON文件恢复数据
- **重置数据**：清空所有数据，恢复默认设置

## 🔧 技术栈

- Chrome Extension Manifest V3
- 原生 JavaScript (ES6+)
- HTML5 / CSS3
- QRCode.js (CDN引入)
- Chrome Storage API
- Chrome Downloads API
- Chrome Tabs API

## 📝 注意事项

1. 截屏功能仅截取当前标签页的可见区域
2. 下载功能受Chrome下载API限制，保存路径为浏览器默认下载目录
3. 数据保存在浏览器本地，清除浏览器数据会导致数据丢失
4. 建议定期导出数据进行备份

## 🎯 使用技巧

- **快速打开**：点击扩展图标或使用快捷键打开侧边栏
- **工具排序**：在首页长按工具卡片500ms即可拖拽排序
- **快捷操作**：很多工具支持回车键快速操作
- **数据备份**：定期在设置中导出数据以防丢失
