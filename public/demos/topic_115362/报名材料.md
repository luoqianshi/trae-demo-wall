## 0. 先和大家打个招呼 👋

我是一名全栈开发者，日常工作中要写大量的「增删改查」页面——前端表单、后端接口、建表 SQL，三件套反复搬砖。每次字段一改，前后端就得同步改一遍，枯燥又容易出错。

我用 TRAE 把这个想法变成了现实。整个过程最让我感慨的是：我只需要把脑子里的「三栏布局 + 拖拽 + 代码生成」讲给它听，它就能一步步把组件、状态管理、代码模板引擎搭起来。原本我以为「在浏览器里生成一整套 SpringBoot 工程」会很难搞定，结果 TRAE 帮我把模板拆成一个个小函数，跨过去的那个坎比我想象中简单太多——这种「原来这么简单」的瞬间，是这次开发里最爽的体验。

## 1. Demo 简介

**是什么**：砌码 CodeBricks 是一个网页端（Web App）低代码研发平台，通过可视化拖拽 + AI 自然语言对话，一键生成 Vue 前端（PC 端 / 移动端）与 Java SpringBoot 后端完整工程代码。

**面向谁**：全栈开发者、后端/前端工程师、技术效率团队——所有被重复 CRUD 页面折磨过的人。

**主要功能**：
1. **可视化拖拽设计器**：左侧配置项目信息（包名、输出路径、前端类型、模块名、表名），中间画布拖拽排版，右侧控件库（输入框、文本域、数字、下拉、单选、多选、日期、时间、日期时间、开关、附件上传、表格等）+ 属性面板（字段名、标签、必填、默认值、数据库列类型、校验规则）。
2. **AI 对话生成页面**：用一句自然语言描述需求（如"做一个用户管理，包含用户名、手机号、年龄、状态、注册时间、头像"），平台自动解析并在画布生成对应控件、回填字段属性。
3. **一键生成全栈代码**：点击生成按钮，输出 Vue3 前端（表单页 + 列表页 + API 封装 + 路由）与 SpringBoot 后端（Entity / Mapper / XML / Service / Controller / 建表 SQL / 配置），支持代码预览、单文件复制、整包 ZIP 下载，复制进工程即可使用。

## 2. Demo 创作思路

**灵感来源**：工作中反复编写结构高度相似的表单页与列表页，字段在前端、后端、数据库三处来回对齐，耗时且易错。我一直在想：既然这些页面有固定范式，为什么不把「字段定义」作为唯一数据源，让代码自动生成？

**想解决的问题**：
- 中后台 CRUD 页面重复编码，单页耗时 1–2 小时；
- 前后端字段类型不一致导致联调返工；
- 新人上手项目时，搭建一个完整模块门槛高。

**为什么做这个方向**：低代码平台不少，但大多面向非技术人员、输出受限。我想要的是「面向开发者的低代码」——生成的是标准、可读、可二次修改的原生 Vue/SpringBoot 代码，而不是黑盒运行时。这样既提效，又不剥夺开发者对代码的掌控力。同时加入 AI 对话入口，让「想到就能生成」成为现实。

## 4. TRAE 实践过程

完整开发流程如下：

**第一步：需求拆解与文档生成**
向 TRAE 描述「三栏布局低代码平台 + 代码生成 + AI 对话」的完整构想，TRAE 帮我生成了 PRD 与技术架构文档，明确了控件类型映射、文件生成清单、状态数据结构。

**第二步：项目初始化与三栏布局**
用 TRAE 初始化 React + TypeScript + Vite + Tailwind 项目，搭建左侧项目配置面板、中间蓝图网格画布、右侧控件库/属性 Tab 面板与顶部工具栏。

**第三步：拖拽交互与状态管理**
引入 @dnd-kit 实现从控件库拖入画布、画布内排序、选中、删除；用 Zustand 集中管理项目配置与控件列表，属性面板双向绑定选中控件。

**第四步：代码生成引擎**
这是核心难点。TRAE 帮我把生成逻辑拆成 `vueGenerator`（PC 端 Element Plus / 移动端 Vant）、`javaGenerator`（Entity/Mapper/Service/Controller）、`sqlGenerator`（建表语句）三个模块，按字段类型映射表统一生成前后端一致的字段。

**第五步：AI 对话与代码预览导出**
实现基于关键词解析的 AI 对话抽屉，输入自然语言自动生成控件；用 prismjs 做代码高亮预览，jszip + file-saver 实现整包下载。
