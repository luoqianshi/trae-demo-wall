# 遗忘录 - 创造者大赛 Demo

一个帮助老年人记住物品存放位置的智能应用 Demo。

## 功能特点

### 🎤 语音录入与查询
- 语音录入：说出"手机放在卧室床上"，自动识别物品和位置
- 语音查询：说出"手机在哪"，自动查找并回答
- 智能解析：支持多种口语表达（放在、放到、搁在、存放在等）

### 🏠 我的家
- 户型图展示：6个房间（卧室、客厅、厨房、卫生间、门口、阳台）
- 房间管理：支持自定义房间名称、图标、颜色
- 物品统计：每个房间显示物品数量
- 房间详情：点击房间查看该房间的所有物品
- 智能识别：语音录入时自动识别房间位置

### ⏰ 提醒功能
- 物品提醒：录入物品时可设置提醒时间
- 多种重复：支持一次、每天、工作日、周末提醒
- 提醒弹窗：到时间自动弹出提醒

### 📱 APP 风格
- 底部 Tab 导航：首页、我的家、提醒
- 首次引导：新用户进入先设置房间布局
- 数据持久化：所有数据保存在本地

## 技术实现

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **样式**: Tailwind CSS
- **语音**: Web Speech API + 百度语音识别 API
- **存储**: localStorage
- **后端**: Node.js (API 代理)

## 运行方式

### 方式一：Node.js 服务器（推荐）
```bash
# 安装依赖（如果需要）
npm install

# 启动服务器
node server.js

# 访问地址
http://localhost:8000
```

### 方式二：静态文件服务器
```bash
# Python
python3 -m http.server 8000

# 访问地址
http://localhost:8000/forgetting-record-demo.html
```

> 注意：方式二不支持语音识别功能，仅能使用手动输入模式。

## 使用说明

1. **首次进入**: 设置家里的房间布局
2. **记物品**: 点击"记一下"按钮，说出"XX放在XX"
3. **找物品**: 点击"找一下"按钮，说出"XX在哪"
4. **管理房间**: 在"我的家"页面点击设置按钮管理房间
5. **设置提醒**: 手动录入物品时可设置提醒
