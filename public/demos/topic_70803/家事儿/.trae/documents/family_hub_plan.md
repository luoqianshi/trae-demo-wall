# 家庭统一管理助手 (Family Hub) - HTML Demo 实施方案

## 一、项目概述

### 1.1 项目定位
为家庭打造的移动端一站式生活管理工具，解决家庭成员（老人、孩子、夫妻）之间信息互通、生活协作的问题。初版使用纯HTML实现移动端Demo，数据存储在本地localStorage，后续可迁移至微信小程序+云服务器架构。

### 1.2 核心价值
- 无需复杂操作，手机端即用
- 家庭信息统一管理，不分散在各个APP/群聊中
- 老人孩子都能轻松上手
- 生活事项不遗漏，协作更顺畅

## 二、功能模块详细设计

### 模块0：基础框架
- **底部Tab导航**：首页、待办、家庭圈、我的（共4个主入口，其他功能从首页进入）
- **家庭成员切换**：顶部显示当前使用者，可切换身份（爸爸/妈妈/孩子/老人等）
- **字体自适应**：切换家庭成员时，自动应用该成员的字体大小设置（老人用大字，其他人正常）
- **本地数据持久化**：使用localStorage存储所有数据
- **移动端适配**：响应式设计，最大宽度480px居中显示

### 模块1：首页仪表盘
聚合展示当日重要信息：
- 今日待办事项（快速勾选完成）
- 近期大事件提醒（生日、节日倒计时）
- 购物提醒（近期需要关注的活动/需购买物品）
- 最新家庭圈动态预览
- 快捷入口：相册、书库、购物清单、大事件

### 模块2：家庭相册
解决问题：替代网盘，方便家人随时查看分享照片视频
- 相册列表：支持创建/分类相册（旅行、日常、孩子成长、节日等）
- 照片网格：按时间倒序展示，支持图片预览
- 上传功能：本地文件选择模拟上传，支持多图选择
- 照片详情：查看大图、添加描述、点赞
- 视频支持：本地视频文件预览（Demo用URL或本地文件模拟）

### 模块3：家庭书库
解决问题：家里纸质书、电子书统一管理，避免重复购买或找不到
- 书籍分类：全部/纸质书/电子书/想读/在读/已读
- 书籍信息：封面、书名、作者、分类、阅读状态、存放位置（纸质书）
- 电子书：支持链接或本地文件存储
- 借阅管理：记录谁借走了哪本书
- 添加书籍：手动录入信息 + 封面上传

### 模块4：购物清单/想买清单
解决问题：防止遗忘物品购买，不错过电商活动
- 物品列表：按状态分类（想买/待购/已买）
- 物品信息：名称、分类（家清/食品/衣物/数码等）、目标价格、添加人、负责人
- 提醒设置：可设置活动提醒时间，到期首页提醒
- 优先级标记：高/中/低
- 快速添加：一句话快速录入

### 模块5：当日待办/家庭协作
解决问题：家庭事务协作，下班回家前一眼看到需要做的事
- 今日待办列表：按时间排序
- 指派功能：可指派给特定家庭成员
- 完成状态：一键勾选完成
- 备注功能：添加详细说明（如"买馒头要在小区门口那家"）
- 历史记录：查看已完成的待办
- 待办来源：显示谁添加的、谁负责

### 模块6：家庭日历/大事件
解决问题：家人生日（尤其是阴历）、纪念日、节日不忘记
- 日历视图：月历展示，标注大事件
- 事件类型：
  - 生日：支持选择阴历/阳历，自动计算每年对应的阳历日期
  - 节日：预设母亲节、父亲节、春节、中秋等
  - 纪念日：结婚纪念日等自定义日期
- 提醒设置：提前N天提醒
- 倒计时显示：距离事件还有多少天
- 阴历转换：内置简单阴历算法，支持1900-2100年范围

### 模块7：家庭圈
解决问题：家庭群消息容易被淹没，家人分享的内容得不到及时反馈
- 时间线展示：类似朋友圈，按时间倒序
- 发布动态：文字+图片（支持多图）
- 互动功能：点赞、评论
- 已读状态：显示谁看过
- 发布者信息：头像+昵称+发布时间
- 空状态友好提示：鼓励家人分享生活

### 模块8：个人中心（我的）
- 家庭成员管理：添加/编辑家庭成员（头像、昵称、角色、字体大小设置）
  - 字体大小选项：正常（标准）、大（老人模式）
  - 可根据角色预设字体大小：老人角色默认大字，夫妻/孩子角色默认正常
  - 也可手动调整每个成员的字体偏好
- 快速字体切换：在个人中心提供字体大小快捷切换按钮
- 数据管理：导出数据、清空数据（为后续云同步预留接口）
- 使用说明：简单的功能介绍
- 关于信息

## 三、技术方案

### 3.1 技术栈（Demo版）
- **HTML5**：语义化标签
- **CSS3**：Flex布局、移动端适配、CSS变量（主题色、字体大小分级）
- **原生JavaScript (ES6+)**：不依赖框架，保持轻量，通过切换根元素class实现字体大小切换
- **localStorage**：本地数据持久化
- **File API**：本地文件选择与预览（图片/视频）
- **Date API**：日期处理、阴历转换算法

### 3.1.1 字体大小分级方案
使用CSS变量控制全局字体，切换成员时动态修改`:root`的class：
- **正常模式（normal）**：正文14px，次要文字12px，标题16-18px，按钮文字16px
- **大字模式（large，老人用）**：正文18px，次要文字16px，标题20-24px，按钮文字20px，行高同步放大
- 所有字体大小、间距、按钮高度都通过CSS变量定义，一键切换全局生效

### 3.2 不引入外部依赖
- 不使用Vue/React等框架
- 不使用Tailwind等CSS框架
- 不使用第三方UI库
- 所有代码手写，保证简单易懂，方便后续迁移

### 3.4 数据结构设计

#### 家庭成员 (family_members)
```javascript
{
  id: string,           // 唯一ID
  name: string,         // 姓名
  role: string,         // 角色：爸爸/妈妈/儿子/女儿/爷爷/奶奶等
  avatar: string,       // 头像base64
  fontSize: 'normal' | 'large',  // 字体大小：正常/大（老人模式）
  createdAt: number
}
```

#### 相册 (albums)
```javascript
{
  id: string,
  name: string,         // 相册名称
  cover: string,        // 封面图片
  createdAt: number
}
```

#### 照片 (photos)
```javascript
{

  url: string,          // base64或本地URL
  description: string,
  likes: string[],      // 点赞成员ID
  uploadedBy: string,   // 上传者ID
  createdAt: number

```

#### 书籍 (books)
```javascript
{
  id: string,

  cover: string,
  type: 'paper' | 'ebook',  // 纸质/电子

  createdAt: number

```

#### 购物项 (shopping_items)
```javascript
{
  id: string,
  name: string,
  category: string,     // 分类
  targetPrice: number,  // 目标价格
  priority: 'high' | 'medium' | 'low',
  remindAt: number,     // 提醒时间戳
```

#### 待办 (todos)
```javascript
{
  id: string,

  completed: boolean,
  completedAt: number,
  note: string,
```

#### 大事件 (events)
```javascript
{

  title: string,
```

#### 家庭圈动态 (moments)

## 四、UI/UX设计原则

1. **字体分级自适应**：
   - 正常模式：正文14px，适合夫妻、孩子日常使用
   - 大字模式：正文18px+，按钮和点击区域同步放大，专门照顾老人视力
   - 切换家庭成员时自动切换对应字体大小，无需手动设置
2. **按钮够大**：可点击区域不小于44px，大字模式下不小于52px
3. **色彩温暖**：使用暖色系主题（橙色/米色/暖棕色），营造家庭温馨感
4. **操作简单**：主要功能最多2步点击到达，减少层级
5. **图标+文字**：所有功能入口既有图标也有文字，老人容易理解
6. **反馈明确**：操作后有明显的成功/提示反馈（大字模式下提示文字也放大）
7. **空状态引导**：没有内容时显示友好提示和添加按钮

## 六、风险与应对

| 风险 | 应对方案 |
|------|----------|
| 图片/视频base64存储占用localStorage空间过大 | Demo阶段限制上传数量和大小，提示用户；后续云服务器版解决 |
| 阴历转换算法复杂容易出错 | 使用成熟的开源阴历算法简化实现，覆盖常用年份范围 |
| 模块过多工作量大 | 按优先级分阶段实现，优先保证核心流程可用 |
| 纯HTML代码组织混乱 | 按模块拆分JS文件，使用统一的模块注册和渲染机制 |

## 七、后续升级路径（Demo之后）

1. **迁移到微信小程序**：按小程序规范重写，复用逻辑和数据结构
2. **云服务器后端**：搭建API服务（Node.js/Python均可），使用云数据库
3. **文件存储**：使用对象存储（OSS/COS）存放图片视频
4. **消息推送**：微信模板消息提醒待办、事件
5. **实时同步**：家人操作实时同步
6. **账号体系**：微信授权登录，家庭组邀请机制
