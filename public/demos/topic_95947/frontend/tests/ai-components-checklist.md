# 前端 AI 组件测试清单

## 首页 AI 简报

- [x] 进入首页后展示“今日经营简报”区块。
- [x] 点击“重新诊断”时，请求 `/api/ai/daily-brief`。
- [x] 无数据时展示补数据引导，不输出确定性经营结论。
- [x] 推荐行动可生成行动卡。
- [x] 推荐行动可继续生成执行素材并跳转 AI 任务中心。

## AI 行动卡

- [x] 行动卡展示标题、优先级、预期影响和执行步骤。
- [x] “生成任务”按钮调用行动卡创建接口，携带 `confirmed: true`。
- [x] “生成素材”按钮调用素材生成接口。
- [x] 失败时展示明确错误提示。

## AI 任务中心

- [x] 支持按状态筛选行动卡。
- [x] 支持编辑负责人和截止时间。
- [x] 支持生成营销文案、会员短信、员工话术和短视频脚本。
- [x] 支持任务完成后触发 AI 复盘。

## 模块内 AI

- [x] 订单页展示模块 AI 助手入口。
- [x] 菜品页展示模块 AI 助手入口。
- [x] 会员页展示模块 AI 助手入口。
- [x] 营销页展示模块 AI 助手入口。

## 空态和错误态

- [x] AI 暂不可用时展示中文提示。
- [x] 空数据场景展示引导步骤。
- [x] loading 状态不阻塞页面基础数据查看。
