# 半阕风月 - 宋词生成与格律校验系统

## 项目简介

「半阕风月」是 TRAE AI 创造力大赛项目，致力于让用户输入大白话，生成严格合律的宋词并配上水墨风格词画图。

## 核心功能

- **宋词生成**: 将用户输入的大白话转化为合律的宋词
- **字数校验**: 检查每句字数是否符合词牌规定
- **平仄校验**: 使用 pypinyin 判断平仄，结合古入声字表修正
- **韵脚校验**: 基于平水韵韵部判断押韵一致性
- **词画图合成**: 使用 Canvas API 生成水墨风格的词画图，支持下载

## 快速开始

### 依赖安装

```bash
pip install pypinyin
```

### 命令行使用

```bash
python3 scripts/validate_ci.py --cipai "词牌名" --text "宋词文本" --verbose
```

**参数：**
- `--cipai`: 词牌名（如：卜算子、浣溪沙）
- `--text`: 宋词文本
- `--verbose`: 显示详细校验信息

### Python API

```python
from scripts.validate_ci import validate_ci

result = validate_ci("卜算子", "缺月挂疏桐，漏断人初静...", verbose=True)
# 返回: {"word_count": True, "pingze": True, "rhyme": True, "valid": True}
```

## 技术原理

### 平仄判断
1. 优先查询古入声字表（入声字归为仄声）
2. 使用 pypinyin 获取拼音声调
3. 声调1、2为平声，3、4为仄声
4. 无法判断时标记为"中"（可平可仄）

### 韵脚判断
1. 提取每句最后一个字作为韵脚候选
2. 查询平水韵韵部数据
3. 比较所有押韵句的韵部是否一致

## 演示页面 (demo.html)

### 特点

- **零依赖**: 纯静态 HTML 文件，所有 CSS 和 JS 内联，双击即可在浏览器中打开
- **水墨风格 UI**: 宣纸底色、宋体字体、赭石主题色、朱红印章
- **预置示例**: 内置 10 个常用场景示例，覆盖加班晚归、春日赏花、深夜孤独等

### 使用方法

1. **直接打开**: 双击 `demo.html` 文件，使用任意现代浏览器打开
2. **选择示例**: 点击快捷示例按钮（加班晚归、春日赏花等）快速加载预置内容
3. **自定义输入**: 在输入框中输入大白话，选择词牌后点击「生成词作」
4. **生成词画图**: 在结果区点击「生成词画图」按钮，自动生成并下载 1024×1600 的水墨风格图片

### 页面结构

- **标题区**: 「半阕风月」标题 + 副标题
- **输入区**: 文本输入框 + 词牌下拉选择 + 快捷示例按钮
- **结果区**: 词作正文 + 原话对应注释 + 格律校验通过徽章 + 生成词画图按钮

### 词画图布局

生成的图片为 1024×1600 像素，包含：

- 顶部标题区：项目名称 + 副标题
- 用户原话区：显示用户输入的原始文本
- 一一对应区：左栏大字宋体词作，右栏小字原话，圆圈序号，箭头连接
- 底部印章：朱红色「宋词」印章

> 
> 由于后端部署与模型成本限制，`demo.html` 页面生成的词作内容为**预置示例数据**，**与用户当前输入的文字无关**。

> 正式版本将接入 AI 大模型，实现真正的大白话转宋词功能。

- demo.html 使用前端预置数据模拟宋词生成，实际项目中需接入后端 AI 生成服务
- 格律校验徽章为模拟显示，实际使用时需调用 validate_ci.py 进行真实校验
