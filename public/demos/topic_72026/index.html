SECTION · 04

TRAE 实践过程

整个项目从 0 到 1 全程使用 TRAE IDE 完成，90% 工作在一个窗口里搞定。

STEP · 01

生成 FastAPI 微服务骨架

我对 TRAE 说："帮我用 FastAPI + SQLAlchemy 2.0 async + Alembic 搭一个 project-service，要包含 Project / MonitoringScheme / Keyword / Platform 四个模型，并提供 CRUD API。" TRAE 一次性生成了模型、路由、main.py 工厂、初始迁移文件。

# services/project/main.py — TRAE 生成 from fastapi import FastAPI from services.project.api.projects import router as projects_router from services.project.api.schemes import router as schemes_router def create_app() -> FastAPI: app = FastAPI(title="Project Service", version="0.1.0") app.include_router(projects_router) app.include_router(schemes_router) return app
STEP · 02

调试 SQLAlchemy 异步关系 + SQLite FK 约束

迁移 0006 报错：SQLite does not support ALTER TABLE ADD CONSTRAINT。把错误贴进 TRAE Chat，它诊断出 SQLite 不支持单独 create_foreign_key，必须把 FK 约束内联到 create_table 里。TRAE 自动改写并在后续迁移主动应用同一模式。

# alembic/versions/0006_monitoring_templates.py — TRAE 修复 op.create_table( "monitoring_templates", sa.Column("id", sa.Integer, primary_key=True), sa.Column("name", sa.String(100), nullable=False), # FK 内联（SQLite 兼容） sa.ForeignKeyConstraint(["created_by"], ["users.id"], ondelete="SET NULL"), )
STEP · 03

重构前端为"墨韵情报"编辑美学

我对 TRAE 描述："把整个前端重做成'墨韵情报'编辑级美学：Noto Serif SC 衬线中文 + 朱砂红信号色 #B91C1C，要有罗马数字 I-IV 的严重度徽章，参考《纽约时报》编辑部。" TRAE 一次性输出了 SCSS 变量、PageHeader 组件、严重度徽章、6 个核心页面重写。最让我意外的是后续生成 KeywordPackList、AlertRuleList 时它主动沿用同一套变量，不需要重复描述。

// styles/variables.scss — TRAE 生成 $signal: #B91C1C; // 朱砂红 $paper: #FBF8F1; // 纸基色 $ink-900: #1C1A17; // 墨色 $font-serif: 'Noto Serif SC', serif; $font-mono: 'JetBrains Mono', monospace;
SECTION · 05

踩坑 & 解决方案

真实创作过程中的 4 个坑，每个都有 TRAE 协助诊断的痕迹。

PITFALL · 01 Sandboxed iframe 阻断 target="_blank"
点击"查看原文"无反应，浏览器控制台无报错。
三级降级：window.open → 剪贴板 + 弹窗 → 弹窗内显示 URL
PITFALL · 02 npm run build OOM 被杀
构建中进程被 Killed，内存峰值超沙箱限制。
改用 dev server（HMR）验证，绕过构建期内存峰值
PITFALL · 03 FastAPI 路由参数顺序错误
code: str = Query(...) 在 db: DbSession 之前报"non-default after default"。
调整为 path → db → user → query 顺序
PITFALL · 04 测试 DB 关系懒加载报错
greenlet spawn has not been called —— selectinload 在测试中未生效。
用 app.dependency_overrides 注入 FakeUser，跳过 roles 关系加载
