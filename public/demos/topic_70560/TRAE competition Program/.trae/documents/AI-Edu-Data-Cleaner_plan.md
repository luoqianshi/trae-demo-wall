# AI智能教务数据清洗与视频转码桌面程序 - 开发计划

## 一、项目概述

开发一款面向中小学教务的离线本地AI智能数据清洗+AI视频转码矫正桌面程序。核心特点：
- **纯本地运行**：所有数据处理在本地完成，不上传任何师生数据
- **AI驱动**：支持直接导入杂乱无标准格式的原始素材，AI全自动识别、矫正、标准化输出
- **三大核心模块**：视频转码归一化、Excel数据清洗、学生特征指纹匹配

## 三、核心模块设计

### 3.1 AI智能多媒体编码归一化模块

**功能需求**：
- 自动识别MP4、MOV、AVI等各类混乱视频编码
- AI自适应分配转码策略，统一转为H.264通用格式
- 自动修复损坏、不兼容视频文件
- 批量处理支持

**实现方案**：
```python
class VideoTranscoder:
    # 编码识别：使用ffprobe分析视频元数据
    # 转码策略：根据分辨率、帧率、编码类型智能选择转码参数
    # 损坏修复：尝试重新封装、帧级修复
    # 输出格式：统一H.264 + AAC，MP4容器
```

**文件结构**：
- `python/services/video_transcoder.py` - 视频转码核心逻辑
- `python/utils/ffmpeg_wrapper.py` - FFmpeg调用封装

### 3.2 AI智能模糊字段映射清洗模块

**功能需求**：
- 识别无固定格式Excel成绩表
- 自动识别乱列、空列、多余表头
- 自动剔除脏数据、对齐数据字段
- 不限制表格排版

**实现方案**：
```python
class DataCleaner:
    # 表头识别：基于规则+ML的表头检测算法
    # 字段映射：智能匹配常见字段（姓名、学号、班级、各科成绩）
    # 脏数据检测：异常值检测、格式验证、缺失值处理
    # 标准化输出：统一字段顺序、数据类型
```

**文件结构**：
- `python/services/data_cleaner.py` - 数据清洗核心逻辑
- `python/utils/excel_parser.py` - Excel解析工具
- `python/algorithms/field_matching.py` - 字段匹配算法

### 3.3 AI班级姓名特征指纹匹配算法

**功能需求**：
- 以班级+姓名生成独立学生特征指纹
- 同名不同学生自动隔离避免数据错乱
- 识别学生转班记录
- 自动拼接多阶段完整成绩

**实现方案**：
```python
class StudentMatcher:
    # 特征指纹生成：班级+姓名+可选特征的哈希组合
    # 相似度计算：编辑距离+加权匹配
    # 转班追踪：跨学期数据关联分析
    # 数据合并：多阶段成绩自动拼接
```

**文件结构**：
- `python/services/student_matcher.py` - 学生匹配核心逻辑
- `python/algorithms/fingerprint.py` - 特征指纹算法
- `python/algorithms/similarity.py` - 相似度计算算法

## 九、验证标准

1. **视频转码测试**：导入10种不同编码格式视频，验证全部成功转码为H.264
2. **数据清洗测试**：导入5种不同格式Excel成绩表，验证字段正确识别和数据标准化
3. **学生匹配测试**：导入包含同名学生、转班记录的多学期数据，验证匹配准确率>99%
4. **批量处理测试**：同时处理10个文件，验证进度显示正常、无崩溃
5. **离线测试**：断网环境下运行，验证所有功能正常
