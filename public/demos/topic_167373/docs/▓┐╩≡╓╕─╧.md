# 部署指南 - 微信小程序

## 一、前置准备

### 1. 注册小程序账号

- 访问 [微信公众平台](https://mp.weixin.qq.com)
- 选择"小程序"类型注册
- 完成主体认证（个人/企业）

### 2. 获取 AppID

- 进入"开发管理" → "开发设置"
- 复制 **AppID(小程序 ID)**

### 3. 安装微信开发者工具

- 下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 当前推荐版本：**稳定版 Stable Build (1.06.x)**

## 二、本地开发

### 步骤 1：导入项目

1. 打开微信开发者工具
2. 点击左侧"小程序"图标 → "导入项目"
3. 项目目录：选择 `poop_tracker_miniprogram/` 根目录
4. AppID：填入你获取的 AppID（也可用"测试号"）
5. 项目名称：自定义，例如"排便健康记录"

### 步骤 2：调整 project.config.json

打开 `project.config.json`，确认：

```json
{
  "appid": "wx你的AppID",
  "projectname": "poop_tracker_miniprogram",
  "libVersion": "2.32.0"
}
```

> 如果使用"测试号"，appid 字段可保留默认 `touristappid`。

### 步骤 3：编译运行

- 点击工具栏"编译"按钮（或按 Ctrl/Cmd + B）
- 模拟器中应看到"引导页"
- 第一次进入会进入 3 步引导
- 完成后可正常使用所有功能

## 三、真机预览

1. 工具栏点击"预览"按钮
2. 微信扫描二维码
3. 即可在手机上体验完整功能

> 预览模式无需后端配置，所有数据存储在手机本地。

## 四、上传代码（提交审核前）

1. 点击工具栏"上传"按钮
2. 版本号：`1.0.0`
3. 项目备注：例如"MVP P0 首发版本"

## 五、提交审核

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 进入"版本管理"
3. 在"开发版本"中找到刚上传的版本，点击"提交审核"
4. 填写审核信息：
   - 功能页面截图（首页、记录页、洞察页、设置页）
   - 测试账号（如有登录功能）
   - 类目：选择"工具 > 健康管理"
5. 等待审核（通常 1-3 个工作日）

## 六、发布上线

审核通过后：
1. 在"审核版本"中点击"发布"
2. 等待 5-10 分钟，全网生效

## 七、订阅消息配置（提醒功能）

提醒功能需要订阅消息权限：

1. 公众平台 → "功能" → "订阅消息"
2. 申请模板：搜索"健康提醒"或自定义
3. 模板内容示例：
   ```
   标题：排便记录提醒
   内容：今天还没有记录哦，记得打开小程序记一笔吧
   关键词：温馨提示、{{thing1.DATA}}、{{time2.DATA}}
   ```
4. 获取模板 ID 后，填入 `pages/reminder-settings/reminder-settings.js` 的 `templateId` 字段

## 八、常见问题

### Q1: 提示"不在以下 request 合法域名列表中"

**A**: 本项目**不发起任何网络请求**，所有数据本地存储。如果遇到此提示：
- 检查 `project.config.json` 中 `urlCheck` 是否为 `false`（开发期可临时关闭）
- 正式上线后开启 `urlCheck: true`（因为不发起网络请求，不会影响功能）

### Q2: 提醒功能不触发

**A**: 微信小程序的定时提醒依赖：
- 用户授权 `wx.requestSubscribeMessage`
- 系统推送通道（不是定时器）
- 必须先在 `app.json` 申请 `subscribeMessage` 权限

### Q3: iOS 端 wx.setStorageSync 容量限制

**A**: 单个 key 最大 1MB，整体最大 10MB。
本项目即使 1 年每天 5 条记录也远低于 1MB。

## 九、生产环境检查清单

- [ ] `project.config.json` 中 `miniprogramRoot` 指向正确目录
- [ ] 关闭 ES6 转 ES5（如不需要兼容性）以减小包体积
- [ ] 关闭代码压缩上传时勾选"压缩代码"
- [ ] 替换测试用的 `touristappid` 为正式 AppID
- [ ] 域名白名单：生产环境不发起请求，可全部留空
- [ ] 隐私协议：在 `app.json` 或自定义页面中声明"本应用不收集任何个人信息"

## 十、回滚方案

如发现严重问题需紧急下架：
1. 公众平台 → "版本管理" → "线上版本"
2. 点击"下架"或"回退"
3. 5 分钟内全网生效
