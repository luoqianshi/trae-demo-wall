# 智友 App 后端技术方案设计

## 一、项目概述

智友 App 是一个基于 AI 的虚拟陪伴应用，用户可以创建具有不同身份、形象和个性的 AI 智友，与它们进行聊天互动。

### 核心功能

- 用户注册/登录
- 智友创建与管理（身份、形象、个性）
- AI 聊天对话
- 智友记忆系统
- 智友档案管理

---

## 二、技术栈选型

### 2.1 后端框架

**FastAPI**

选型理由：
- 高性能：基于 Starlette 和 Pydantic，异步支持优秀
- 开发效率：自动生成 OpenAPI 文档，类型提示友好
- 生态丰富：Python 生态完善，AI 库支持好
- 现代化：符合现代 Python 开发规范

### 2.2 数据库

**PostgreSQL 16**

选型理由：
- 支持 JSONB 字段，适合存储智友形象配置（发型、脸型、服装等灵活结构）
- 支持全文搜索，便于智友搜索和记忆检索
- 事务支持完善，数据一致性有保障
- 扩展性强，可通过 PGVector 扩展支持向量存储（未来记忆向量搜索）
- Python 生态完善（SQLAlchemy、asyncpg 等）

### 2.3 ORM

**SQLAlchemy 2.0 + asyncpg**

选型理由：
- 功能强大，支持异步操作
- 类型提示友好
- 与 FastAPI 集成度高

### 2.4 AI 服务集成

**OpenAI 兼容接口**

选型理由：
- 标准化接口，可切换不同大模型供应商
- 支持流式输出，聊天体验好
- 生态成熟，工具链完善

### 2.5 缓存

**Redis**

选型理由：
- 用户会话/Token 缓存
- 聊天上下文缓存
- 接口限流

### 2.6 认证方案

**JWT (JSON Web Token)**

选型理由：
- 无状态，便于水平扩展
- 跨端适配性好
- 与移动端配合体验佳

- `idx_chat_messages_session_time`: chat_messages(session_id, created_at)
- `idx_memories_friend_time`: memories(friend_id, recorded_at DESC)
- `idx_users_phone`: users.phone 唯一索引

## 五、AI 服务集成方案

### 5.1 整体架构

```
用户消息 → 后端服务 → 构建系统Prompt（身份+个性+记忆）→ 大模型API → 流式返回 → 自动提取记忆
```

### 5.2 Prompt 构建策略

**系统提示词结构：**

```
你是一个名叫{name}的AI朋友，你的身份是{identity_label}。

【你的性格】
{personality_traits}

【你的说话风格】
{speaking_style_description}

【关于用户的记忆】
{relevant_memories}

【对话规则】
- 保持身份一致性，不要跳出角色
- 用自然、口语化的方式交流
- 适度使用表情符号增加亲切感
- 记住用户说过的重要信息
- ...
```

### 5.3 记忆提取机制

每次对话结束后，调用大模型分析对话内容，提取值得记忆的信息：

```
请分析以下对话，提取关于用户的重要信息（如喜好、重要事件、个人信息等）。
如果没有值得记忆的内容，返回空数组。

输出格式：JSON数组
[
  {
    "content": "记忆内容",
    "importance": 3
  }
]
```

### 5.4 相关记忆检索

- 短期记忆：最近 N 条对话（直接拼接）
- 长期记忆：基于向量相似度检索 Top-K 条相关记忆（可选，用 PGVector）

### 5.5 模型配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| model | gpt-4o-mini / 等价模型 | 主模型 |
| temperature | 0.7 | 创造性 |
| max_tokens | 1000 | 单次回复最大长度 |
| top_p | 0.9 | 核采样 |

## 七、技术实现细节

### 7.1 密码安全

- 使用 bcrypt 进行密码哈希
- 哈希强度：12 rounds

### 7.2 JWT 配置

- Access Token 有效期：24 小时
- Refresh Token 有效期：30 天
- 算法：HS256

### 7.3 限流策略

- 登录接口：同一手机号 5次/分钟
- 发送验证码：同一手机号 1次/分钟，10次/天
- 聊天接口：用户维度 60次/分钟

### 7.4 数据校验

- 手机号格式校验
- 密码强度校验（最少8位，包含字母和数字）
- 智友名称长度限制（2-20字符）

### 7.5 错误码规范

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 40001 | 参数错误 |
| 40101 | 未登录 / Token 无效 |
| 40102 | Token 已过期 |
| 40301 | 无权限 |
| 40401 | 资源不存在 |
| 40901 | 手机号已注册 |
| 40902 | 验证码错误或过期 |
| 50001 | 服务器内部错误 |
| 50002 | AI 服务调用失败 |
