# 宝宝成长积分管家 · 项目说明文档

> 一款面向家庭场景的纯前端单页应用，帮助家长通过「积分制」记录与引导宝宝的良好行为习惯，让成长过程可量化、可追踪、可激励。

---

## 一、项目简介

「宝宝成长积分管家」是一款轻量级 Web 应用，旨在用游戏化的积分机制帮助家长科学管理宝宝的日常行为。应用围绕「行为 → 积分 → 奖励 → 成长记录」的闭环设计，让每一次好行为都被看见、每一次进步都被记录。

### 核心能力

- **家庭成员管理**：支持创建多个宝宝档案，每个宝宝拥有独立的行为记录、积分账户与成长时间线。
- **行为积分系统**：家长可自定义「加分行为」与「扣分行为」，并通过快捷按钮一键记录，实时累计积分。
- **积分看板**：以可视化方式呈现总积分、今日摘要，以及 7 天 / 30 天的积分趋势图，帮助家长洞察宝宝的行为变化。
- **奖励兑换系统**：宝宝可使用积攒的积分申请兑换预设奖励，家长确认后自动扣除对应积分，形成完整的激励闭环。
- **成长记录时间线**：按时间倒序展示所有行为与兑换记录，支持按日期筛选，方便回顾成长点滴。

### 技术特点

- 🟢 **纯前端实现**：无需后端服务，打开即用。
- 💾 **本地存储**：所有数据保存在浏览器 localStorage 中，无需账号、无需联网。
- 🔒 **隐私安全**：数据不离开本地设备，完全由用户掌控。
- 📱 **移动端优先**：响应式布局，适配手机、平板与桌面浏览器。
- ⚡ **零依赖**：不依赖任何外部库或构建工具，加载迅速。

## 三、启动方式

本应用为纯前端项目，无需安装依赖，提供以下两种启动方式：

### 方式一：直接用浏览器打开（最简单）

双击 `index.html` 文件，或将其拖入浏览器窗口即可运行。

> ⚠️ 注意：部分浏览器在 `file://` 协议下可能对 localStorage 或某些 API 存在限制，建议优先使用方式二。

### 方式二：使用本地服务器（推荐）

通过本地服务器运行可避免浏览器对本地文件的限制，获得更稳定的体验。

#### Python 方式

```bash
# 进入项目根目录
cd /Users/nifsnas/Desktop/TRAE_Race

# 启动 HTTP 服务器（Python 3）
python3 -m http.server 8000
```

#### Node.js 方式

```bash
# 进入项目根目录
cd /Users/nifsnas/Desktop/TRAE_Race

# 使用 npx 临时启动 serve（无需全局安装）
npx serve
```

#### 访问应用

启动服务器后，在浏览器中访问：

```
http://localhost:8000
```

## 五、核心功能说明

### 1. 家庭成员管理

- 支持创建多个宝宝档案（姓名、头像、生日等信息）。
- 每个宝宝拥有独立的行为记录、积分账户与成长时间线，互不干扰。
- 支持在多个宝宝之间快速切换，聚焦当前查看的对象。

### 2. 行为积分系统

- 家长可自定义「加分行为」（如：按时完成作业 +5）与「扣分行为」（如：发脾气 -3）。
- 提供快捷操作按钮，一键记录行为并实时更新积分。
- 行为可随时增删改，灵活适应不同家庭的教育规则。

### 3. 积分看板

- 展示当前宝宝的总积分与今日行为摘要。
- 使用 Canvas 绘制 7 天与 30 天的积分趋势图，直观呈现积分变化趋势。
- 帮助家长发现宝宝行为习惯的周期性规律。

### 4. 奖励兑换系统

- 家长预设奖励池（如：看一集动画片 20 分、去游乐园 100 分）。
- 宝宝可使用积分申请兑换奖励，进入待确认状态。
- 家长确认后自动扣除对应积分，完成兑换闭环；支持拒绝申请。

### 5. 成长记录

- 以时间线形式倒序展示所有行为记录与兑换记录。
- 支持按日期范围筛选，快速定位特定时段的成长点滴。
- 记录是宝宝成长的数字档案，可作为家庭回忆的载体。

## 六、数据存储说明

### 存储位置

所有数据均保存在浏览器的 **localStorage** 中，键名为：

```
baby_points_data
```

### 数据结构

`baby_points_data` 对应一个 JSON 对象，主要包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `babies` | Array | 宝宝档案列表 |
| `behaviors` | Array | 自定义行为规则列表（加/扣分项） |
| `records` | Array | 行为发生记录（每次加减分的流水） |
| `rewards` | Array | 奖励池列表（可兑换的奖励项） |
| `exchanges` | Array | 奖励兑换记录（含申请与确认状态） |
| `operators` | Array | 操作人（家长）列表 |

### 注意事项

- ⚠️ **数据本地化**：所有数据仅存储在当前浏览器中，不会上传到任何服务器。
- ⚠️ **清除即丢失**：清除浏览器缓存、Cookie 或网站数据将导致数据永久丢失，请谨慎操作。
- ⚠️ **跨设备隔离**：不同设备或不同浏览器的数据相互独立，无法自动同步。
- 💡 **建议定期备份**：可结合后续规划的「数据导出」功能定期备份重要数据。

## 七、下一步扩展方向

以下是未来可考虑的扩展方向，按优先级排列：

1. **数据导出 / 导入**
   支持将全部数据导出为 JSON 文件，便于备份与迁移；支持从 JSON 文件导入恢复数据。

2. **PWA 离线使用**
   引入 Service Worker 与 Web App Manifest，使应用可安装到主屏幕并完全离线运行。

3. **多端同步**
   接入云数据库（如 Firebase、Supabase），实现多设备数据实时同步与账号体系。

4. **数据统计与分析**
   提供月度报告、行为习惯分析、积分分布饼图等深度洞察，辅助家长优化教育策略。

5. **多宝宝对比看板**
   在看板中支持同时展示多个宝宝的积分与行为对比，激发良性竞争。

6. **提醒功能**
   支持定时提醒家长记录宝宝行为（如每日睡前提醒），避免遗漏重要记录。

7. **主题切换**
   提供深色模式与多种配色主题，适应不同场景与个人偏好。

8. **成就系统**
   引入连续打卡、里程碑徽章等成就机制，增强宝宝坚持好行为的动力与趣味性。
