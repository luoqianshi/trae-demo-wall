# 新中式奢华婚宴统筹系统 - UI 使用指南

## 概览

本设计系统是一套完整的高端中式婚宴统筹UI界面，采用**新中式奢华**设计风格，以中国红（#C41E3A）和帝王金（#D4A847）为核心色彩，融合传统中式美学与现代交互体验。

---

## 适用场景

### 1. 婚礼统筹平台 / SaaS 系统
- 面向婚庆公司的数字化管理平台
- 婚礼全流程在线协作工具
- 多角色（新人、宾客、服务员、司仪）协同系统

### 2. 高端酒店婚宴服务系统
- 五星级酒店婚宴数字化解决方案
- 宴会厅智能管理系统
- 客户现场体验提升工具（宴桌端平板）

### 3. 婚礼APP / 小程序
- 新人端：婚礼筹备进度追踪
- 宾客端：电子请柬、座位查询、祝福墙
- 工作人员端：现场执行管理

### 4. 活动统筹系统扩展
- 企业年会、发布会等高端活动
- 寿宴、满月宴等中式庆典
- 任何需要红金配色 + 中式元素的正式场合

## 组件库使用指南

### 按钮组件

**主按钮（红金渐变）**
- 场景：主要操作、确认、下一步、提交
- 规格：padding 12px 28px，圆角 16px
- 状态：default / hover（上移+光晕）/ active（缩放0.95）/ disabled（灰化）

**金色按钮**
- 场景：次级强调操作、成功确认、喜庆场景
- 规格：同主按钮，金色渐变背景 + 深色文字

**描边按钮**
- 场景：次要操作、返回、取消
- 规格：2px 金色边框 + 透明背景 + 红色文字

**幽灵按钮**
- 场景：工具栏操作、导航链接
- 规格：无背景 + 金色/红色文字

### 卡片组件

**标准卡片**
- 白色背景 + 1px 金色边框 + 底部红色渐变条
- 悬停：上移 4px + 暖色阴影
- 适用：列表项、功能入口、信息展示

**毛玻璃卡片**
- `backdrop-filter: blur(20px)` + 半透明白色背景
- 适用：图片背景上的信息层、沉浸式页面

**统计卡片**
- 大号数字 + 标签文字
- 4种变体：红色渐变 / 金色渐变 / 绿色渐变 / 蓝色渐变
- 适用：仪表盘核心数据展示

### 输入组件

**标准输入框**
- 2px 金色边框 + 16px 圆角
- 聚焦：金色光晕 + 边框加深
- 适用：表单输入、搜索框

**发光输入框**
- 3px 金色边框 + 持续发光动效
- 适用：重要输入、数量确认、重点操作

### 装饰元素

**回形纹背景**
- CSS repeating-linear-gradient 实现
- 透明度 6%，不干扰内容阅读

**双喜字水印**
- 200px 大号"囍"字，透明度 6%
- 居中放置，不影响交互

**金色分隔线**
- 左右渐变透明，中间金色
- 高度 1-2px

**角花装饰**
- 4个角落的L形金色装饰
- 适用：重要卡片、弹窗、邀请函风格页面

## 页面使用建议

### 首页（home.html）
**使用场景**：系统入口、角色选择、婚礼主视觉展示
- 适合作为电子请柬的入口页
- 可嵌入婚礼邀请函网站
- 多角色系统的统一入口

### 主人端仪表盘（dashboard.html）
**使用场景**：新人/婚礼管家全局监控
- 婚礼当天的指挥中心
- 实时查看各环节进度
- 宾客出席情况总览

### 桌位布局（table-layout.html）
**使用场景**：座位安排、入座情况监控
- 婚礼前：座位规划和调整
- 婚礼中：实时监控哪些桌已入座
- 点击桌位查看详细座位图

### 迎宾端（welcome.html → welcome-register.html → welcome-success.html）
**使用场景**：签到台宾客接待
- 搜索宾客信息
- 登记礼金和随行人员
- 引导宾客就座
- 建议在签到台配平板设备使用

### 传菜端（serve.html → serve-tables.html → serve-confirm.html → serve-success.html）
**使用场景**：厨房/传菜部上菜管理
- 三步操作流程：选菜 → 选桌 → 确认
- 追踪每道菜的上桌进度
- 适合传菜员用手机操作
- 成功页有强烈视觉反馈，减少误操作

### 宴桌端（table.html → table-calling.html）
**使用场景**：每桌放置的平板/桌牌
- 横屏设计，适合桌牌设备
- 宾客可呼叫服务员
- 查看菜单和婚礼流程
- 浏览婚礼照片
- 背景轮播营造氛围

## 自定义与扩展

### 更换品牌色
修改 `colors_and_type.css` 中的 CSS 变量即可全局换色：
```css
:root {
  --color-primary: #你的主色;
  --color-gold: #你的金色;
  --color-bg: #你的背景色;
}
```

### 调整奢华程度
- **增加奢华感**：增加金色元素、角花装饰、毛玻璃效果
- **简约风格**：减少装饰元素、降低金色透明度、移除角花和回形纹

### 适配不同设备
- **PC端**：侧边栏 + 主内容区布局，最大宽度1200px
- **平板**：折叠侧边栏为图标模式
- **手机**：底部导航栏替代侧边栏
- **桌牌**：横屏全屏，大字体大按钮

## 动效规范

| 动效类型 | 时长 | 缓动函数 | 适用场景 |
|---------|------|---------|---------|
| 页面切换 | 0.4s | ease-out | 页面淡入上滑 |
| 卡片悬停 | 0.3s | ease-out | 上移+阴影加深 |
| 按钮点击 | 0.15s | cubic-bezier(0.34,1.56,0.64,1) | 缩放回弹 |
| 脉冲动画 | 2s | ease-in-out infinite | 进行中状态、呼叫铃 |
| 成功反馈 | 0.6s | cubic-bezier(0.34,1.56,0.64,1) | 弹跳入场 |
| 轮播切换 | 1s | ease-in-out | 照片淡入淡出 |

---

## 注意事项

1. **无障碍访问**：确保文字与背景对比度达标，红色文字不要用在红色背景上
2. **性能优化**：毛玻璃效果（backdrop-filter）在低端设备可能卡顿，可降级为半透明背景
3. **动效节制**：动画以"优雅"为原则，避免过多过滥，重要操作才用强调动效
4. **中式元素使用**：囍字、祥云、回形纹等元素作为装饰点缀，不要过度堆砌
5. **金色使用**：金色主要用于装饰和强调，不要大面积使用，保持高级感
