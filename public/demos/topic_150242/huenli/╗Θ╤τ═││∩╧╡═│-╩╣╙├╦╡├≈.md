# 婚宴统筹系统 · 使用说明

> 新中式奢华婚宴现场管理平台 · 单页应用版

---

## 一、系统简介

婚宴统筹系统是一套**局域网多角色协同管理 Web 系统**，覆盖婚宴全流程的数字化管理。通过一台电脑运行，现场所有设备（手机、平板、电脑）连接同一网络即可访问，无需公网服务器、零部署成本。

### 核心亮点

- **8 个角色端 + 1 个管理后台**，各司其职
- **新中式奢华设计**，中国红 + 帝王金配色，适配高端婚宴场景
- **响应式布局**，手机、平板、桌面均可流畅使用
- **单文件架构**，无需安装，双击 HTML 即可运行

---

## 二、快速启动

1. 直接双击 `婚宴统筹系统-完整版.html` 文件，用浏览器打开
2. 首页展示婚礼主视觉、倒计时和 8 个角色入口
3. 点击对应角色卡片进入功能页面
4. 所有数据预置在文件中，开箱即用

## 五、功能使用指南

### 5.1 主人端

点击首页 **👑 主人端** 进入，包含 5 个标签页：

| 标签 | 功能 |
|------|------|
| 📊 总览 | 4 个统计卡片 + 环节进度时间线 + 上菜进度环 |
| 👥 宾客管理 | 完整宾客名单表格，显示签到状态 |
| 🪑 桌位管理 | 主席台 + 圆形桌位布局，点击查看详情 |
| 🍽️ 菜品管理 | 12 道菜品上菜进度列表 |
| 📅 环节管理 | 6 个婚礼环节时间线，支持推进/回退操作 |

### 5.2 主持人端

点击首页 **🎤 主持人端** 进入，包含 3 个标签页：

| 标签 | 功能 |
|------|------|
| 📅 环节控制 | 大字显示当前环节，支持推进/回退，与主人端实时同步 |
| 📜 主持稿 | 完整婚礼主持稿（开场白→新人入场→仪式→敬酒→游戏→送客） |
| 💌 祝福审核 | 待审核的祝福语列表，支持通过/拒绝 |

### 5.3 迎宾端

点击首页 **👋 迎宾端** 进入，完整流程：

1. **搜索宾客** — 输入姓名或手机号，实时过滤
2. **点击宾客** — 进入登记页面
3. **录入礼金** — 输入金额（支持快捷金额按钮），选择礼金方式
4. **确认签到** — 点击确认，跳转成功页
5. **继续接待** — 点击"继续接待下一位"返回搜索

### 5.4 传菜端

点击首页 **🍽️ 传菜端** 进入，三步向导流程：

1. **选择菜品** — 从 12 道菜品中选择要上的菜
2. **选择桌号** — 选择目标桌号（已上菜的桌号置灰不可选）
3. **确认上菜** — 输入 6 位传菜码验证，确认后上菜
   - 传菜码：主桌01=010123，亲友桌02=020456，同学桌03=030789，同事桌04=040234，贵宾桌05=050567

### 5.5 宴桌端

点击首页 **🪑 宴桌端** 进入，沉浸式全屏体验：

1. 选择桌号进入
2. 查看本桌菜单、人员、照片墙、婚礼流程
3. 点击 🔔 按钮呼叫服务员（带脉冲动画）
4. 背景自动轮播

### 5.6 摄影师端

点击首页 **📷 摄影师端** 进入，包含 2 个标签页：

| 标签 | 功能 |
|------|------|
| 🖼️ 照片墙 | 仅显示已上架的照片，点击查看详情 |
| 📋 照片管理 | 全部照片列表，支持单张上架/下架、批量上架/批量下架 |

### 5.7 宾客端

点击首页 **👤 宾客端** 进入：

1. 输入手机号和密码（默认 1234）
2. 登录后查看个人信息、桌号、座位号
3. 查看同桌人员、菜品进度、照片墙、祝福留言

## 八、常见问题

**Q：文件无法打开？**
A：确保使用现代浏览器（Chrome / Edge / Safari 最新版），直接双击 HTML 文件即可。

**Q：数据能修改吗？**
A：所有数据在 HTML 文件中的 `DATA` 对象里，用文本编辑器打开即可修改宾客、菜品、桌位等信息。

**Q：能部署到服务器吗？**
A：当前是纯前端单页应用，如需联网部署，建议用 FastAPI + Nginx 托管，并接入后端数据库。

**Q：如何让其他设备访问？**
A：在同一局域网内，记下主机 IP 地址，其他设备在浏览器中输入 `http://主机IP:端口号` 即可访问。可配合 Python 的 `http.server` 模块快速启动：
```
python -m http.server 8080
```
