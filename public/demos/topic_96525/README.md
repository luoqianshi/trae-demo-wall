# 网页转PDF工具

本地运行的网页转PDF工具，支持在线URL和本地HTML文件转换。

## 特性

- ✅ 支持在线网页URL转PDF
- ✅ 支持本地HTML文件转PDF
- ✅ **自动检测并加载本地相对路径资源**（图片、CSS、图标等）
- ✅ 支持自定义页面大小（A4/A3/A5/Letter等）
- ✅ 支持横/纵向设置
- ✅ 支持预览PDF后下载
- ✅ 完全本地运行，数据安全
- ✅ 基于Puppeteer，渲染质量高，支持现代CSS/JS

## 使用方法

### 启动服务

```bash
npm start
```

首次启动Edge会自动加载，稍等一会儿。

然后浏览器打开：`http://localhost:3000`

### 两种转换方式

**1. 在线URL**
- 输入网页地址
- 选择参数
- 点击转换 → 预览 → 下载

**2. 本地HTML文件**
- 拖拽或点击选择本地 `.html` 文件
- HTML中引用的相对路径图片/CSS会被正常加载
- 转换后下载PDF

### 关于本地文件

本工具对本地HTML文件支持完善：
- 相对路径 `./images/logo.png` 正常加载
- 绝对路径 `C:\xxx\icon.svg` 正常加载
- 外部CDN资源也能正常加载

所有依赖自动加载，无需额外处理。

## 配置参数

| 参数 | 说明 | 默认 |
|------|------|------|
| 页面大小 | A4/A3/A5/Letter/Legal/Tabloid | A4 |
| 方向 | 纵向 / 横向 | 纵向 |
| 缩放 | 0.5 ~ 3 | 1 |

## 技术栈

- Node.js + Express 服务端
- Puppeteer + 系统Edge浏览器 渲染
- 纯原生JS前端，无需编译

## 注意事项

- 生成的PDF文件保存在 `output` 目录，1小时自动清理
- 本地文件最大限制 50MB
