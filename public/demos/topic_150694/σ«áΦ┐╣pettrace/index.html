ADOPTION GUIDE

领养须知

领养前请务必仔细阅读，了解您的责任与义务

重要提醒

领养宠物是一份长达十几年甚至更久的责任。请在决定领养前，与家人充分沟通，确保全家人都支持并愿意共同照顾这个小生命。

日常喂养

  • 提供优质猫/狗粮，保证营养均衡
  • 每天定时喂食，不要随意投喂人类食物
  • 准备干净的饮用水，随时保持充足
  • 幼宠需要少量多餐，成宠定时定量

居住环境

  • 为宠物准备专属的休息区域
  • 保持室内清洁，定期消毒
  • 封窗封阳台，防止坠楼或走失
  • 准备好窝垫、笼子等生活用品

健康管理

  • 定期接种疫苗（狂犬、联苗等）
  • 每月进行体内外驱虫
  • 定期体检，早发现早治疗
  • 宠物生病时及时就医，不拖延

日常照顾

  • 狗狗每日至少遛弯2-3次，每次30分钟以上
  • 猫咪每日清理猫砂盆，保持干净
  • 定期洗澡、梳毛、修剪指甲
  • 关注宠物情绪，给予足够的陪伴

经济准备

  • 每月狗粮/猫粮费用：200-800元
  • 每年疫苗+驱虫：300-800元
  • 常规体检：200-500元/次
  • 生病治疗费用：数百至数千元不等
  • 宠物用品（窝、玩具、牵引绳等）
  • 美容/寄养等额外支出

家庭沟通

  • 与家人充分讨论，获得一致同意
  • 确认无人对宠物毛发过敏
  • 考虑其他家庭宠物是否接受新成员
  • 明确照顾分工，全家共同参与

领养承诺

我承诺：

  1. 为宠物提供安全、舒适的居住环境，不离不弃
  2. 科学喂养，保证宠物的身体健康
  3. 定期带宠物进行健康检查和疫苗接种
  4. 给予宠物足够的关爱和陪伴
  5. 如因特殊原因无法继续抚养，会联系平台协助重新安置
  6. 遵守当地宠物饲养相关法律法规
