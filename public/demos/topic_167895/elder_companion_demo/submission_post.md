# 【社会服务赛道】基于传统文化 IP 的老龄化多模态陪伴系统 Demo

## 1. Demo 简介

本项目是一个面向老年用户的传统文化 IP 多模态陪伴系统离线 HTML Demo。用户可以选择孙悟空、李白、诸葛亮三位传统文化角色进行文字聊天，并支持字号调整、高对比度、本地图片预览、浏览器原生语音朗读与可选语音输入。当用户输入涉及胸痛、摔倒、自伤等高风险关键词时，系统会优先弹出“系统安全提醒”，引导用户联系家人或专业救助人员。

## 2. 用户痛点与创作思路

老年用户普遍面临以下问题：

- **孤独感强**：独居、空巢老人缺少随时可聊的伙伴。
- **界面不友好**：市面上的应用字体小、按钮小，老人看不清、点不准。
- **情绪与安全交织**：老人在表达情绪时可能同时提及身体不适或自伤等高风险信息，需要系统优先处理安全提示。
- **隐私顾虑**：老人担心语音、照片、聊天内容被上传到网络。

因此，我们决定以三位家喻户晓的传统文化角色作为陪伴形象，用大字体、大按钮、高对比度、离线运行的方式降低使用门槛，并在高风险场景下切断角色扮演，优先给出明确的安全提醒。

## 3. 核心功能及真实能力边界

### 3.1 角色陪伴
- 可选择孙悟空、李白、诸葛亮三个角色。
- 回复由页面内置的本地关键词和预设规则生成，**不具备真正的自然语言理解能力，也不请求在线大模型**。

### 3.2 无障碍交互
- 支持 8 档字号放大/缩小、高对比度模式、键盘聚焦、大按钮与大输入框。

### 3.3 安全提醒
- 当输入包含高风险关键词时，优先弹出“系统安全提醒”，不显示任何角色头像、名称或角色归因。
- **该提醒不能替代医疗诊断、紧急救助或专业判断**。

### 真实能力边界
- 图片仅做本地预览，**不进行真实视觉识别、VLM 分析或摄像头分析**。
- 朗读使用浏览器原生 `speechSynthesis`，可用性取决于浏览器。
- 语音输入依赖浏览器原生 `SpeechRecognition`，**仅在支持的浏览器中可用**，识别准确度和处理方式由浏览器决定。
- **当前没有接入真实 C++ 后端、OpenCV、libcurl、VLM、ASR、TTS 模块或医学诊断能力**。

## 4. Demo 体验方法

1. 将 `elder_companion_demo` 文件夹打包为 ZIP。
2. 下载并解压到本地任意目录。
3. 双击目录中的 `index.html`，即可在浏览器中离线体验。

核心文字陪伴、图片预览和语音朗读无需安装、无需 API Key，可离线运行；可选语音识别是否需要联网取决于浏览器实现。

## 9. 真实性、隐私和安全说明

- **真实性**：本 Demo 的所有回复均由浏览器本地关键词规则生成，未接入任何在线大模型、VLM、ASR、TTS 服务或 C++ 后端；图片仅做本地预览，不做真实视觉识别。
- **隐私保护**：本 Demo 不向开发者服务器上传文字输入或图片，也不自建语音服务器；用户主动启用浏览器语音识别时，音频是否联网处理取决于浏览器实现与隐私政策。页面不使用 Cookie 或本地持久化存储。
- **安全边界**：高风险安全提醒仅作为提示用户寻求专业帮助的参考，**不能替代医疗诊断、紧急救助或专业判断**。如遇紧急情况，请立即联系家人、照护者或当地急救机构。
