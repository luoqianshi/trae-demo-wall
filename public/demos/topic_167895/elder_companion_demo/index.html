体验说明
  • 本页面是免密钥、可离线运行的 HTML 交互体验 Demo。
  • 回复由本地关键词和预设规则生成，不会请求在线大模型。
  • 本 Demo 不向开发者服务器上传用户输入或图片，不使用 API Key；如主动使用语音识别，音频处理方式由浏览器决定。
  • 语音朗读使用浏览器原生 speechSynthesis，实际可用性取决于浏览器。
  • 语音识别由浏览器提供（SpeechRecognition / webkitSpeechRecognition），是否可用、识别准确度和处理方式均取决于浏览器；本 Demo 没有自建语音服务器，也不保证语音一定在本地完成。
  • 当前没有接入真实 VLM、摄像头分析、医学诊断或 C++ 后端。
  • 后续真实工程计划由 C++、OpenCV、libcurl 和 VLM 模块逐步实现。
