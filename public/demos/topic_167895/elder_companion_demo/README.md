# 基于传统文化 IP 的老龄化多模态陪伴系统（离线 HTML Demo）

## 项目背景

随着我国老龄化程度加深，独居、空巢老人对日常陪伴、情感慰藉和安全关注的需求日益增长。本项目尝试以深受大众喜爱的传统文化 IP 为载体，构建一个面向老年用户的多模态陪伴系统 Demo，让“孙悟空、李白、诸葛亮”三位角色以贴近老人语言习惯的方式提供情感陪伴，同时在出现高风险表达时优先给出安全提醒。

## 老年用户痛点

- **孤独感强**：子女不在身边，缺少可以随时聊天的对象。
- **操作门槛高**：普通 App 字体小、按钮小、界面复杂，老年人看不清、点不准。
- **情绪与安全问题交织**：老人可能在聊天中提及身体不适、摔倒、自伤等高风险情况，需要系统优先提示求助，而不是继续角色扮演。
- **对隐私和网络的顾虑**：担心个人信息、照片、语音被上传到服务器。

## 三个传统文化角色

| 角色 | 特点 | 适合场景 |
|------|------|----------|
| 孙悟空 | 开朗、勇敢、鼓励行动 | 没精神、需要鼓劲 |
| 李白 | 温和、诗意、擅长情绪陪伴 | 孤独、想聊天、想听诗词 |
| 诸葛亮 | 沉稳、理性、帮助梳理问题 | 焦虑、遇到困难、需要建议 |

## 当前功能说明

- **角色切换**：点击卡片选择孙悟空、李白或诸葛亮。
- **文字输入与本地回复**：输入想说的话后点击“开始陪伴”，回复由页面内置的关键词规则和预设文案生成。
- **朗读回复**：点击“朗读回复”使用浏览器原生语音合成朗读当前消息。
- **清空对话**：一键清空当前对话记录。
- **字号调整**：提供“字号放大 / 缩小”按钮，共 8 档字号可选。
- **高对比度**：一键切换黑黄高对比度模式，方便视力不佳的用户。
- **图片本地预览**：可选择本地图片在页面内预览，不会上传或发送。
- **语音输入（可选）**：在支持的浏览器中，可点击“语音输入”将语音转为文字填入输入框；不支持时自动降级为文字输入。
- **一键重置**：清空输入、对话、图片、角色选择，并恢复默认字号和高对比度设置。
- **高风险优先处理**：当输入包含胸痛、呼吸困难、摔倒、自伤、自杀、想死、不想活等关键词时，优先弹出“系统安全提醒”，不显示任何角色头像、名称或角色归因。

## 体验方法

1. 将 `elder_companion_demo` 文件夹打包为 ZIP。
2. 下载并解压到本地。
3. 双击 `index.html`，即可在浏览器中离线体验。

核心文字陪伴、图片预览和语音朗读无需安装、无需 API Key，可离线运行；可选语音识别是否需要联网取决于浏览器实现。

## 无障碍设计

- 默认采用较大的字体和行高，减少阅读疲劳。
- 按钮尺寸宽大，留白充足，便于点击。
- 提供字号放大/缩小，适应不同视力需求。
- 提供高对比度模式，增强文字与背景的区分。
- 角色卡片、输入框、按钮均支持键盘聚焦和明显的聚焦轮廓。

## 安全边界说明

- 本 Demo 的“系统安全提醒”仅用于提示用户及时联系家人、照护者或专业急救人员，**不能替代医疗诊断、紧急救助或专业判断**。
- 如遇身体不适或紧急情况，请立即拨打当地急救电话或联系专业人员。

## 隐私说明

- 本 Demo 不向开发者服务器上传文字输入或图片，也不自建语音服务器；用户主动启用浏览器语音识别时，音频是否联网处理取决于浏览器实现与隐私政策。
- 页面不收集用户身份、位置、健康数据，也不使用 Cookie 或本地持久化存储。
- 语音识别是否本地完成、如何处理，完全取决于浏览器自身实现，本 Demo 不自建语音服务器。

## 当前离线 HTML Demo 的真实能力

- 这是一个**纯前端、离线可运行**的 HTML 体验页面。
- 回复由**本地关键词匹配和预设规则**生成，**不会请求在线大模型**，也不具备真正的语义理解能力。
- 图片仅做**本地预览**，**不进行真实视觉识别、VLM 分析或摄像头分析**，也不会根据图片伪造分析结论。
- 朗读使用浏览器原生 `speechSynthesis`，实际音色、语速、可用性取决于浏览器。
- 语音输入依赖浏览器原生的 `SpeechRecognition` / `webkitSpeechRecognition`，**仅在浏览器支持时可用**；其识别准确度、是否联网、处理方式均由浏览器决定。
- **当前没有接入真实 C++ 后端、OpenCV、libcurl、VLM、ASR、TTS 模块或医学诊断能力**。
