## 1. 产品概述

「BACKROOMS ESCAPE · 后室逃生」是一款像素风格的俯视角恐怖生存小游戏。两名身着黄色防化服、佩戴防毒面具与氧气瓶的探险者被困在无限循环的后室楼层中，需要在丧尸、毒气、飞虫等威胁下寻找出口，一层层向下深入，尝试逃离这片诡异空间。

- 核心体验：紧张的资源管理 + 房间探索 + 即时战斗
- 目标用户：后室/怪谈文化爱好者、像素恐怖游戏玩家

## 2. 核心功能

### 2.1 玩家角色
| 角色 | 名称 | 配色 | 定位 |
|------|------|------|------|
| 1P | ALPHA | 亮黄防化服 + 红滤毒罐 | 均衡型，近战稍强 |
| 2P | BRAVO | 暗黄防化服 + 蓝滤毒罐 | 支援型，攻速稍快 |

### 2.2 功能模块
1. **标题界面**：游戏 Logo、模式选择（单人/双人）、开始按钮、操作说明
2. **游戏界面**：俯视角地图、双角色、HUD（血量/氧气/楼层/弹药）
3. **战斗系统**：近战挥击 + 投掷闪光弹（眩晕敌人）+ 格挡减伤
4. **敌人系统**：丧尸（近战追击）、飞虫（空中盘旋俯冲）、毒气云（环境持续伤害）
5. **关卡系统**：程序化生成房间与走廊，每层有出口通往下一层，难度递增
6. **结算界面**：死亡/胜利展示、到达层数、重玩按钮

### 2.3 页面详情
| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 标题界面 | Logo 区 | 黄色像素标题、摇曳灯光效果、"不要相信墙壁"副标题 |
| 标题界面 | 模式选择 | 1P 单人 / 2P 本地合作 |
| 标题界面 | 操作说明 | 双方按键列表 |
| 游戏界面 | 地图层 | 房间+走廊、墙体、门、出口楼梯 |
| 游戏界面 | 实体层 | 玩家、丧尸、飞虫、毒气云、道具 |
| 游戏界面 | HUD | 左上角色1状态、右上角色2状态、底部楼层信息 |
| 结算界面 | 展示区 | 死亡/逃生画面、到达层数、存活时间 |

## 3. 核心流程

玩家进入标题 → 选择模式 → 进入 Level 0 → 在迷宫房间中探索寻找出口 → 沿途消灭/躲避敌人、拾取氧气罐补给 → 到达楼梯口进入下一层 → 楼层越高敌人越多越强 → 血量归零则游戏结束。

### 3.1 操作设计

**1P（ALPHA）**
| 按键 | 动作 |
|------|------|
| W / A / S / D | 上/下/左/右 移动 |
| J | 近战攻击（警棍） |
| K | 投掷闪光弹（范围内敌人眩晕） |
| L | 格挡（正面减伤 60%） |

**2P（BRAVO / AI）**
| 按键 | 动作 |
|------|------|
| ↑ / ↓ / ← / → | 上/下/左/右 移动 |
| 数字键 1 | 近战攻击 |
| 数字键 2 | 投掷闪光弹 |
| 数字键 3 | 格挡 |

### 3.2 战斗数值
| 属性 | 数值 |
|------|------|
| 初始血量 | 100 |
| 氧气上限 | 100（每层消耗，拾取补给） |
| 氧气消耗 | 每秒 0.3（毒气区域 3/秒） |
| 近战伤害 | 15（挥击） |
| 闪光弹数量 | 起始 3 枚，每层随机补给 |
| 格挡减伤 | 正面 60% |
| 丧尸伤害 | 接触 8/秒 |
| 飞虫伤害 | 俯冲 12 |
| 毒气伤害 | 5/秒（需防毒面具减缓） |
| 楼层数 | 无限，每 3 层难度跃升 |

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：后室标志性芥末黄 `#d4c86a`、暗褐色墙体 `#6b5a2e`、腐坏米色 `#c9b981`
- **次色调**：血红色 `#c0392b`、防毒绿 `#2ecc71`、幽暗灰 `#2c2416`、警示橙 `#e67e22`
- **恐怖氛围**：黄色闪烁灯光、角落阴影、屏幕噪点、呼吸声波纹
- **字体**：像素等宽体 `VT323`（主字体）+ `Press Start 2P`（标题）
- **按钮风格**：黄色斑驳像素边框按钮，悬停时荧光绿描边

### 4.2 页面设计概览
| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 标题界面 | Logo | 扭曲像素标题字、摇曳光晕、噪点背景 |
| 标题界面 | 模式按钮 | 两枚黄色像素按钮，带裂纹纹理 |
| 标题界面 | 说明 | 底部半透明黄底说明框 |
| 游戏界面 | HUD | 左右角色头像 + 血量条 + 氧气条 + 闪光弹数 |
| 游戏界面 | 小地图 | 右下角迷你地图显示已探索区域 |
| 游戏界面 | 楼层指示 | 顶部中央 "LEVEL X" 像素字 |
| 结算界面 | 死亡画面 | 血溅效果 + "YOU DIED" + 到达层数 |

### 4.3 恐怖氛围要点
- 光照系统：角色周围有锥形手电光（视野受限），远处昏暗
- 环境音效：远处低沉嗡鸣、偶尔水滴声、丧尸低吼（可选 WebAudio 生成简单音色）
- 视觉干扰：屏幕边缘暗角、随机噪点闪烁、低血量时画面变红脉动
- 心理暗示：墙上偶尔出现模糊人影、走廊尽头不明身影一闪而过

### 4.4 像素美术指引
- 角色：16×20 像素精灵，放大 2.5 倍（40×50 显示）
- 防化服：黄色主体、黑色防毒面具、圆形滤毒罐、背上氧气瓶
- 丧尸：灰色皮肤、撕裂衣服、红色眼睛、歪斜姿态
- 飞虫：黑色躯体 + 透明翅膀 + 红眼
- 墙体：黄色斑驳纹理，随机污渍与裂纹
- 地面：米色地毯，随机花纹斑点
