# 品牌红黑榜

AI守护每一次消费决策 - 品牌信誉查询公益应用

## 项目简介

品牌红黑榜是一款面向大众消费者的移动端应用，通过扫码即可查询品牌信誉评分和消费安全预警。帮助用户在购物决策前快速了解品牌是否"能放心买"。

## 技术栈

- **框架**: uni-app (Vue 3) + TypeScript
- **状态管理**: Pinia
- **构建工具**: Vite
- **样式**: SCSS
- **多端支持**: H5、微信小程序、Android App、iOS App

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 运行开发服务器

```bash
# H5 模式
npm run dev:h5

# 微信小程序模式
npm run dev:mp-weixin
```

### 3. 构建生产版本

```bash
# H5
npm run build:h5

# 微信小程序
npm run build:mp-weixin
```

## 功能模块

| 功能 | 说明 |
|------|------|
| 扫码查询 | 扫描商品条码，返回品牌信任分和评级 |
| 分类榜单 | 食品/药品/化妆品/母婴四大分类榜单 |
| 品牌搜索 | 关键词搜索品牌，快速定位 |
| 预警推送 | 315曝光、质检通报等消费预警 |

```
└── manifest.json    # 应用配置
```

## 公益属性

本项目为社会公益性质，旨在：
- 降低消费者获取品牌安全信息的门槛
- 打通官方质检公告与普通消费者的信息壁垒
- 让每一次购物决策都有数据支撑
