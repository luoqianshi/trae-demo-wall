// MEMORY ARCHITECTURE

四层记忆系统

AI 真正"记住"你的项目，而非每次从零开始

LAYER 1

指令注入

读取 .mewcode/instructions.md，将项目规范注入 System Prompt。用户偏好和项目规则始终生效。

LAYER 2

自动记忆提取

每 5 轮对话自动分析，提取用户偏好、纠正反馈、项目知识、参考资料，写入 memories.md。

LAYER 3

按需召回

根据当前对话内容，智能检索历史记忆中相关的条目，注入上下文。只召回相关信息。

LAYER 4

会话回放

对话自动落盘为 JSONL，支持 /resume 断点恢复。意外关闭也不丢失上下文。

### 用户偏好
- 用户偏好简洁代码风格，不要过度注释
- commit message 用英文
- 变量命名用 snake_case

### 纠正反馈
- 不要用 print 调试，用 logging
- 测试文件放在 tests/ 目录下

### 项目知识
- 项目使用 Python 3.11+ / Textual 框架
- 包管理工具是 uv + Hatchling
- AI Provider 配置在 .mewcode/config.yaml

### 参考资料
- Textual 文档: textual.textualize.io
- MCP 协议: modelcontextprotocol.io

quickstart.py 
# 安装 MewCode
$ uv sync

# 配置 AI Provider
$ cat .mewcode/config.yaml
providers:
  - name: "deepseek"
    protocol: "openai-compat"
    base_url: "https://api.deepseek.com/v1"
    model: "deepseek-v4-pro"
    api_key: "${DEEPSEEK_API_KEY}"
    context_window: 128000

# 启动 MewCode
$ python -m mewcode

# 或使用入口脚本
$ ./mewcode.cmd
