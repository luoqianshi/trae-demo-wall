# 水电到家 Web 前端

这个目录是可独立运行的 Web 版本，不依赖上级目录中的小程序源码。

## 一键启动（Windows）

先将压缩包完整解压，再双击 `启动前端.bat`。脚本使用 Windows 自带的 PowerShell 启动本地静态服务器，并自动用默认浏览器打开页面。

- 默认地址：`http://127.0.0.1:8080/`
- 如果 8080 端口已被占用，会依次尝试后续端口
- 关闭命令窗口或按 `Ctrl+C` 即可停止服务
- 免安装、无第三方依赖，不需要 Node.js、Python 或其他开发环境
- 支持 Windows 10 和 Windows 11

整个 `web` 文件夹可以单独复制到其他位置使用。
