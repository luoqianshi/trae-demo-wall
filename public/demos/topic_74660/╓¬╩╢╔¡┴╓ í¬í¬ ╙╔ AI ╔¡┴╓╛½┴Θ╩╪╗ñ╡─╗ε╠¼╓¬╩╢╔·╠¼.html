痛点洞察

在信息爆炸的时代，我们收集了无数知识，却如同散落的种子，无法生根发芽。 更致命的是——每一次提问，模型都像第一次接触这些材料一样重新搜索，知识永远无法沉淀。

🦋 收藏夹吃灰症

看到好文章、好课程就收藏，收藏了几百篇却再也没打开过。"马了等于会了"成为自我安慰的借口。

🧩 知识碎片化 · 无法沉淀

抖音、公众号、知乎、B站...每天接收零散信息。传统 RAG 每次查询都从零检索，知识之间没有连接，无法形成体系，更无法迭代进化。

😵 学了就忘 · 重复劳动

花了很多时间学习，但过几天就忘光了。同一个问题问了五次 AI，每次都要把上下文重新讲一遍，回答还略有出入。

📉 输出困难 · 维护成本高

读了很多书、听了很多课，真要写点东西时脑子一片空白。某个概念之前在哪出现过？新文档是否推翻了旧结论？这些琐碎维护工作对人成本极高。

🔄 孤岛知识 · 没人打理

哪些页面已成为孤岛，没被任何地方引用？哪些知识点之间存在意外关联？哪些领域还缺少连接？没有人为你主动巡检这些。

核心理念：编译，而非检索

知识森林吸收了 LLM Wiki 的核心范式革命——不让你每次提问都"现查现答"， 而是让森林精灵把零散资料预先"编译"成互联的知识林，查询时直接读取已理解的成果。 知识只编译一次，却能持续生长、复利积累。

❌ 传统 RAG：临时检索型

每次查询都从零开始重新检索、重新理解、重新综合。查询结束，知识消失，毫无积累。

文档 → 分块 → 向量化 → 提问 → 检索片段 → LLM 临时拼接答案 → 知识丢失 ❌
→

✅ 知识森林：预编译型

森林精灵一次性把资料编译成结构化知识页面，后续查询直接复用编译成果。新增资料持续丰富森林，定期自检修正矛盾，知识复利增长。

文档 → 精灵编译提炼 → 生成互联知识页面 → 提问 → 直接读取已理解内容 → 知识累积 ✅ 复利增长

三层森林架构

吸收 LLM Wiki 的三层职责分离设计，知识森林把整个系统切成三个层次： 种子永不篡改、林木由精灵维护、法则约束精灵行为。每一层各司其职，透明可溯源。

精灵是谁？

森林精灵是驻扎在你知识森林中的 AI 守护者。它跨越文档阅读、跨页面改写、批量更新、重复执行—— 这些对人维护成本极高、对模型却轻而易举的工作，全交给它。

你负责筛选信息、把控方向；精灵承担摘要、关联、纠错、归档、巡检。 人机协同，让知识随时间复利增长，而非反复消耗。

"你只管往森林里丢种子，剩下的事——发芽、扎根、修剪、连根、巡山、引路——都交给我。"

精灵身兼两职：猎犬负责一次性把证据链追深（SAG 式深追踪）， 守林人负责把高价值理解长期沉淀（LLM Wiki 式养护）。 猎犬追完线索，守林人把结论写进档案——下次遇到类似问题，组织不用从头查起。

🌱

播种 · 摄入

Ingest

读取新种子资料，抽取核心概念、实体、关系、待解问题。多轮深读而非一次了事，自动判别声明来源并打上 extracted / inferred / ambiguous 标签，写入元数据可追溯。

🧭

引路 · 查询

Query

三重视野检索：分词搜索 + 语义向量 + 图谱 2 跳扩展。先读索引定位相关页面，再读取页面综合回答并附引用。答案还能回写成新页面，结晶为长期资产。

🔍

巡林 · 健康检查

Lint

周期性巡检整片森林：发现枯枝（过时知识）、孤岛树（孤儿页面）、断根（缺失交叉引用）、冲突枝（矛盾内容）、养分空白（知识空白），主动通知你修复。

🗺️

绘图 · 知识图谱

Graph

基于四信号关联度（直接链接、来源重叠、Adamic-Adar、类型亲和）+ Louvain 社区检测，构建知识图谱。主动发现"惊奇连接"与"知识空白"，告诉你哪些领域还缺连接。

🔗

连根 · 扎根合并

Resolve

新知识与现有林木合并：判断该新建页面还是并入已有概念，自动补全双向根脉链接到相关知识点，维护 schema 一致性。增量更新，只处理新增/修改过的种子。

💎

结晶 · 对话沉淀

Digest

你和精灵的对话中提炼出的结论，不再消失在上下文窗口里——它会结晶为综合报告页，沉淀为长期资产。让一次性对话变成可复用的知识结晶。

🐕

追踪 · 深挖证据链

Hunt · SAG

借鉴 SAG 思路，精灵把每份种子拆成"事件+实体"存入关系索引。提问时通过共享实体动态追线索——从指标追到事件、从事件追到供应商、再回到原始证据。不预建全局大图，查询时临时拼出局部关系链，穿过实体→事件→指标的链路。猎犬追完，守林人再把结论写回林木。

🧬

向量索引 · 语义视野

Embedding

为林木页生成语义向量索引，支撑三重视野检索的"语义相似"视野。配置 LLM API Key 时使用真 embedding 模型，无 Key 时自动降级为字符 3-gram 哈希向量——检索始终可用，语义性按需增强。

⚖️

可信度评分 · 多源印证

Credibility

对每条声明聚合多来源交叉印证：N 个独立种子支持同一陈述则共识度高、来源多样性越丰富越可信，并叠加时间衰减——陈旧声明需新证据刷新。每个判断都标注可信度分值，避免单一来源误导。

🧭

学习路径 · 拓扑推导

Learning Path

基于知识图谱拓扑自动推导学习路径：入度低的实体是基础先学、桥节点是关键枢纽、稀疏连接的"知识岛"提示认知盲区。不依赖人工编排，森林结构变化时路径自动更新。

📊

阶段性综述 · 时段汇总

Synthesis

指定时间段（如本月、本季度），精灵汇总该阶段新增/更新的林木页面与对话结晶，生成一篇综述页沉淀为长期资产。让"这段时间学了什么"不再靠记忆翻找。

🤖

智能体接入 · MCP 风格

Agent Gateway

为龙虾类智能体（Trae Agent / Claude / ChatGPT / 任意 MCP 客户端）提供统一接入：读取工具清单后可调用知识森林全部能力——查询、搜索、追踪、导入、图谱、可信度、学习路径、综述。人机协同，精灵即工具。

💬

微信对话 · 种子化沉淀

Chat Import

支持把微信群聊、私聊导出文本作为种子导入——解析发言人、时间戳、消息体，自动剔除系统消息与噪声。聊天中散落的知识点（结论、决策、答疑）同样被编译进森林，不再蒸发在聊天记录里。

查询闭环 · 一次完整的森林之旅

精灵的七大能力不是孤立的，在一次查询中协同形成闭环： 先读已编译的林木页获得上下文，再用猎犬追事件链回到原始证据， 综合回答后把高价值结论写回森林——知识就这样复利增长。

双向根脉链接

吸收 Obsidian 双向链接 + 反向索引的精华，知识森林中每棵树的根脉相互连接—— 正向根脉记录"这棵树连向谁"，反向根脉记录"谁连向这棵树"，还有隐藏的地下菌丝等待显化。

根脉如何相连

🔗

正向根脉 · 出链

这棵树主动连向哪些树？体现内容的广度与延伸方向。

🔁

反向根脉 · 反链

哪些树连向这棵树？反映这个知识点的重要度与枢纽地位。

🍄

地下菌丝 · 未关联提及

精灵识别出未显式链接但提到了某概念的内容，提示你"这里可能藏着一条新根脉"，模拟人类意义协商的知识建构过程。

📍

块级定位 · 精准引用

根脉可精准连到某棵树的特定枝节（段落块），像函数调用一样精确调用知识片段。

森林健康巡检

知识库和人一样需要定期体检。森林精灵会周期性巡林，主动发现六类健康问题并通知你修复—— 这正是传统知识管理工具最缺失的"自我维护"能力。
底线：林木是生成层，不是事实源。每个判断都要能回到种子（raw source），精灵定期巡检断链、无来源结论、新旧冲突。
