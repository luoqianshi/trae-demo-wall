Type Echo (纸上回响) - Offline Demo
====================================

How to Run:
-----------
1. Unzip this package
2. Double-click "about.html" to view the introduction page
3. Click "START TYPING" button to go to the writing experience
   OR directly open "index.html" for the writing experience
4. Click anywhere on the page to enable audio (browser autoplay policy)

Important Notes:
----------------
- Sound requires user interaction first: click anywhere on the page to enable audio
- All data is stored locally in your browser (localStorage)
- Works offline - no internet connection needed

Features:
---------
- 8 classic typewriter models with unique sound profiles
- Cover-type typing logic (new characters overwrite existing ones)
- Mechanical linkage visual animations
- Gallery, history, and works management sections
- Introduction page with full project story

Browser Compatibility:
----------------------
- Chrome / Edge (recommended)
- Firefox
- Safari

Files:
------
- about.html   - Project introduction page
- index.html   - Main writing experience
- README.txt   - This file

Troubleshooting:
----------------
- No sound? Click anywhere on the page first (browser autoplay policy)
- Page not opening? Try using a different browser or opening from a local server
