# 老板今天几点走 —— 项目介绍

> 科学预测 · 精准摸鱼

---

## 一、项目简介

一款用数据科学预测老板下班时间的轻量级 Web 应用。

**痛点**：想下班又不敢走，怕老板突然找过来。

**解决**：记录老板实际下班时间，系统自动学习规律，预测次日下班时间。

**特点**：纯前端、零后端、数据本地 JSON 文件存储、隐私安全。

---

## 二、核心功能

| 功能 | 说明 |
|------|------|
| 今日预测 | 显示预测时间、置信度、影响因素标签 |
| 一键记录 | 记录实际下班时间，支持 10 种标签 |
| 本周视图 | 7 天网格展示，点击记录 |
| 历史翻页 | 查看任意周历史数据 |
| 统计面板 | 准确率、平均时间、连续命中 |
| 自定义规则 | 设置固定模式，命中置信度 95% |
| 考勤配置 | 工作制度、弹性工时、加班日 |
| 等级系统 | 实习生→预言家→时间领主 |
| 节假日识别 | 自动识别并显示趣味文案 |
| 多峰分析 | 识别老板多种作息模式 |

---

## 三、统计原理

### 规则匹配层

- **自定义规则优先**：预设固定模式，直接返回
- **趣味修正因子**：周五效应、月末效应、季末冲刺、周一综合征等 8 条职场常识规则

### 统计计算层

- **6 维度加权融合**：同星期(25%)、月内周次(20%)、近期趋势(18%)、线性回归(17%)、双周模式(12%)、标签影响(8%)
- **中位数自适应**：标准差 > 30min 时自动切换，抵抗异常值
- **标准差置信度调整**：数据波动大则降低置信度
- **概率校准**：基于历史误差分布校准，使置信度更真实
- **自适应权重**：记录 ≥ 10 条时动态调整各维度权重
- **核密度估计(KDE)**：检测多峰模式，识别多种作息

## 四、使用流程

1. 双击 `index.html` 打开
2. 首次配置考勤信息
3. 日常查看预测 → 记录实际时间
4. 分享 `boss-time-data.json` 给同事
