FEATURES

核心功能

三个关键能力，覆盖从发票文件到会计凭证的完整链路。

DRAG

拖拽即提取

把发票文件夹或 ZIP 拖到窗口，自动扫描 PDF/XML 发票并开始解析。无需手动点按钮，拖入即触发，拖拽区域实时高亮反馈。

PARSE

多格式发票解析

支持增值税电子普通/专用发票、数电票、全电发票。PDF 用 pdfplumber + PyMuPDF 双引擎容错，XML 支持 EInvoice 国税标准三层降级。

EXPORT

凭证分录自动生成

导出 Excel 包含三个工作表：发票明细（19列完整字段）、凭证分录（自动借贷方分录，含税额科目）、统计信息（金额合计、税额合计、发票类型分布）。

INTERFACE

应用界面
