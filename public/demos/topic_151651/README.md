# 🪞 镜灵 Mirror Spirit

> 你的数字心理镜子，越照越懂你

## 📖 产品介绍

镜灵是一款基于 AI 的「数字自我镜像」成长陪伴系统。它不直接给你答案，而是像一面镜子——你写的每一篇日记、说的每一句话、走过的每一条路，都会被温柔地折射回来，让你慢慢看见真实的自己。

### 设计理念

- **不灌输、不评判**：AI 不说「你应该」，只帮你看见
- **越用越懂你**：数据越多，分析越准，洞察越深
- **克制、干净、不打扰**：苹果风极简设计，温柔陪伴

## 🚀 快速开始

### 方式一：一键启动（推荐）

双击 `启动.bat`，脚本会自动：
1. 检查 Node.js 和 Python 环境
2. 安装依赖
3. 启动前后端服务

启动成功后访问：
- 🌐 **前端页面**: http://localhost:3000
- 📖 **后端文档**: http://localhost:8000/docs

### 方式二：手动启动

#### 启动后端

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

#### 启动前端

```bash
cd mirror-spirit
npm install
npm run dev
```

访问 http://localhost:3000

## 💡 体验指南

### 快速体验模式（推荐！）

镜灵不是那种「一用就哇塞」的产品。它更像真实的心理咨询——需要时间，那面镜子才会慢慢清晰。

4. 感受「越用越懂你」的产品理念

1. 打开首页，点击「立即写日记分析」
2. 前往「日记」页面，写一篇日记
3. 查看 AI 分析结果和偏差值

5. 前往「地图」页面，看看今天的成长任务
6. 第二天再来，偏差值会越来越准

## 🧩 功能模块

### 1. 📖 文字之镜 — 日记分析
- 自由书写，AI 自动分析情绪维度
- 6 维情绪雷达图（能量/焦虑/幸福/平静/动力/自信）
- 自动生成人格特质标签
- 「镜中洞察」金句，温柔地点醒你

### 2. 📊 数据之镜 — 偏差值系统
- 偏差值 = 理想自我 vs 真实自我 的差距
- 7 日 / 30 日趋势曲线
- 成长可视化，让抽象感受变具体

### 3. 💬 对话之镜 — 镜像式对话
- AI 不说「你应该」，只问「你觉得呢？」
- 引导式提问，帮你自己找到答案
- 每次对话附带深度洞察

### 4. 🗺️ 空间之镜 — 地图式成长
- 基于情绪状态生成空间行动任务
- 结合高德地图 POI，知行合一
- 把觉察变成真实的生活改变

### 5. ⏰ 自动成长系统
- 晨间问候 / 晚间总结 / 日报生成
- 危机检测 / 里程碑提醒
- 你只要记录，剩下的交给时间

## ⚙️ 配置说明

### API 密钥配置

在 `backend/.env` 文件中配置：

```env
OPENAI_API_KEY=sk-xxx      # DeepSeek API Key
OPENAI_API_BASE=https://api.deepseek.com/v1
AMAP_API_KEY=xxx           # 高德地图 Web服务 Key
```

- **DeepSeek API**：用于 AI 分析和对话
- **高德地图 API**：用于 POI 搜索和空间任务
- 不配置也可以，系统会使用 Mock 数据

### 系统要求

- Node.js >= 18
- Python >= 3.10
- Windows / macOS / Linux

## ❓ 常见问题

**Q: 第一次体验感觉平平，正常吗？**
A: 完全正常！镜灵的设计就是「越用越懂你」。建议使用「快速体验模式」直接感受第7天和第30天的效果。

**Q: 不配置 API 密钥可以用吗？**
A: 可以。系统会自动使用 Mock 数据，不影响体验产品设计和UI交互。

**Q: 数据存在哪里？**
A: 所有数据都存在本地 SQLite 数据库中（backend/mirror_spirit.db），不上传任何服务器。

**Q: 如何重置数据？**
A: 删除 `backend/mirror_spirit.db` 文件即可，重启后会自动创建新数据库。
