# 智护家园 - 家庭健康小管家 Demo

这是一个为Trae AI创意大赛设计的家庭健康与社区互助平台的演示Demo。

## 功能特性

### 🏠 首页
- 健康评分展示
- 今日用药进度跟踪
- 待办提醒统计
- 快捷服务入口（药品识别、报告解读、语音问诊、社区互助）

### 📷 智能识读
- 药品识别：拍照识别药品包装，AI解读药品信息
- 报告解读：拍照识别体检报告，AI分析健康指标
- 处方识别：拍照识别医生处方，自动添加到用药计划
- 识别历史记录

### 💊 用药管理
- 添加、编辑、删除药品
- 设置用药时间和剂量
- 服药记录跟踪
- 用药提醒功能
- 注意事项显示

### 📋 健康档案
- 家庭成员管理
- 健康趋势图表
- 识读记录查看
- 健康指标跟踪

### 🤝 社区互助
- 发布紧急求助
- 发布普通互助需求
- 响应他人求助
- 社区志愿者展示
- 求助状态跟踪

## 技术特点

### 数据持久化
- 使用localStorage实现本地数据存储
- 支持数据重置功能
- 自动保存用户操作

### 交互体验
- 丰富的动画效果（浮动、脉冲、波纹等）
- 响应式设计，适配移动端
- 实时通知提醒
- 流畅的页面切换

### 模拟数据
- 内置丰富的模拟数据
- 支持一键添加更多演示数据
- 真实场景模拟

## 使用方法

1. 启动本地服务器：
   ```bash
   cd demo
   python -m http.server 8000
   ```

2. 在浏览器中打开：
   ```
   http://localhost:8000/index.html
   ```

3. 开始体验：
   - 点击底部导航栏切换不同功能模块
   - 点击"添加药品"按钮管理用药计划
   - 点击"发布求助"按钮体验社区互助
   - 点击"添加更多模拟数据"丰富演示内容

## 主要功能演示

### 用药管理
1. 进入"用药"标签页
2. 点击"+ 添加药品"按钮
3. 填写药品信息（名称、用量、时间等）
4. 点击"保存"完成添加
5. 可以编辑或删除已有药品

### 社区互助
1. 进入"社区"标签页
2. 点击"紧急求助"或"发布互助需求"
3. 填写求助信息
4. 点击"发布求助"
5. 其他用户可以点击"我来帮忙"响应

### 数据管理
1. 进入"社区"标签页
2. 滚动到底部"设置"区域
3. 点击"添加更多模拟数据"丰富演示内容
4. 点击"重置所有数据"恢复初始状态

## 技术栈

- **前端框架**：原生JavaScript + HTML5
- **样式框架**：Tailwind CSS
- **数据存储**：localStorage
- **动画效果**：CSS3 Animations
- **图标**：Emoji

## 注意事项

- 这是一个演示Demo，数据存储在本地浏览器中
- AI识别功能为模拟演示，实际使用需要接入真实API
- 通知提醒功能基于浏览器本地时间
- 建议使用现代浏览器（Chrome、Edge、Firefox等）获得最佳体验
