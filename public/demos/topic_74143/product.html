技术实现

纯 HTML + CSS + JS + SVG
零外部依赖

整个应用由两个 HTML 文件构成：demo.html 提供完整的解析 → 导图交互流程，product.html 为比赛展示页。两者均内联 CSS 与 JS，无任何 npm 依赖、无构建步骤。

核心是启发式文本结构解析器——通过正则规则识别中文章节（一、二、）、"第X章/条"、多级编号（1.1.1）、Markdown 标题（#）与列表项（-），按层级构建树形数据，再用原生 SVG 渲染为可交互的横向思维导图。

交互层基于原生事件实现节点折叠、原文双向联动、画布拖拽与滚轮缩放；导出层通过 XMLSerializer 与 Canvas 实现 SVG / PNG 下载。可扩展接入大模型 API 提升语义理解精度。
