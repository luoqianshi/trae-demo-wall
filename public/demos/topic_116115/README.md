# 智游规划 - AI 智能旅游规划助手 DEMO v1.3.0

一个可交互体验的旅游规划服务 HTML DEMO，移动端 APP 风格，基于 AI 模拟生成个性化旅行行程。

## 项目介绍

智游规划是一款 AI 智能旅游规划助手，用户只需填写出行需求，即可快速生成专属旅行方案。DEMO 采用纯前端实现，所有数据均为 Mock 模拟，无需后端服务即可完整体验。v1.3.0 版本新增行程左滑操作、拖拽排序、文件夹收纳等管理功能。

## 功能列表

### 整体架构
- 底部 3 Tab 导航（旅游计划 / 发现 / 我的）
- 移动端 APP 风格，最大宽度 430px，桌面端居中显示
- 毛玻璃效果底部 Tab 栏
- 页面滑入滑出切换动画

### Tab 1：旅游计划
- 规划列表页（卡片式展示，6 条我的规划）
- 悬浮按钮（FAB）新建规划
- 规划状态标签（规划中 / 已完成 / 已收藏）
- 新建规划表单（出发地、目的地、日期、天数、人数、预算、偏好、风格）
- AI 生成行程加载动画（7 步流程）
- 行程详情页（4 个 Tab：行程 / 预算 / 贴士 / 地图）
- 每日行程时间轴（上午 / 下午 / 晚上）
- 景点、餐厅、交通、住宿推荐
- **左滑操作**：行程卡片左滑露出分享/收藏/删除三个操作按钮
- **拖拽排序**：编辑模式下拖拽手柄调整行程顺序，拖动时有视觉反馈
- **文件夹收纳**：顶部横向滚动文件夹筛选栏，支持新建文件夹、移动行程到文件夹

### Tab 2：发现
- 发现首页（大标题 + 搜索图标）
- 横向滚动分类标签（热门 / 国内 / 周边 / 美食 / 亲子 / 情侣 / 自然风光）
- 双列瀑布流卡片布局（10 条精选社区行程）
- 发现详情页（封面图、作者信息、标签、行程简介、行程概览）
- 复用行程功能（一键添加到我的规划）
- 点赞、收藏、分享交互

### Tab 3：我的
- 顶部渐变背景用户卡（头像、昵称、简介）
- 数据统计栏（规划数 / 收藏数 / 关注 / 粉丝）
- 分组菜单列表
  - 第一组：我的规划、我的收藏、我的足迹
  - 第二组：出行偏好、消息通知
  - 第三组：帮助与反馈、关于我们、设置
- 菜单项点击 Toast 反馈

### 地图增强（重点功能）
- SVG 矢量地图，带网格和道路背景
- 三级缩放功能（L1 城市级 → L2 区级 → L3 街道级）
- 缩放时平滑过渡动画
- 不同缩放级别显示不同密度的 POI
- 地点分类筛选（全部 / 景点 / 餐厅 / 酒店 / 购物 / 交通）
- 分类标签横向滚动，选中高亮
- 不同类型不同颜色标记点
  - 景点：蓝色 #2563EB
  - 餐厅：橙色 #F97316
  - 酒店：紫色 #8B5CF6
  - 购物：粉色 #EC4899
  - 交通：绿色 #22C55E
- 圆形标记 + 中心 emoji 图标
- 点击标记点弹出 Bottom Sheet 信息卡
- Bottom Sheet：图片 + 名称 + 评分 + 地址 + 简介
- 信息卡按钮：加入行程 + 导航（示意）
- 点击背景或下拉关闭 Bottom Sheet

### AI 生成过程
- 全屏加载动画
- 三环旋转加载图标
- 7 步 AI 分析流程
- 步骤进度实时展示（进行中 / 已完成）
- 状态文字动态更新

### 交互体验
- 所有按钮点击反馈（缩放效果）
- Toast 轻提示
- 卡片渐入动画
- 页面滑入滑出动画
- 滚动条美化

## 如何打开和体验

### 方式一：直接打开
1. 解压 Zip 包
2. 双击 `index.html` 文件
3. 在浏览器中即可体验

### 方式二：本地服务器（推荐）
如果遇到图片加载问题，可以启动本地服务器：

```bash
# 进入项目目录
cd travel-planner-demo

# 使用 Python 启动
python3 -m http.server 8000

# 或使用 Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8000`

### 体验步骤

#### 旅游计划 Tab
1. 进入默认显示「旅游计划」Tab，查看我的规划列表
2. 点击右下角「+ 新建规划」按钮
3. 填写出行需求（出发地、目的地、日期、天数、人数、预算、偏好、风格）
4. 点击「一键生成最优路线」按钮
5. 观看 AI 生成过程动画
6. 进入行程详情页，查看生成的行程方案
7. 切换顶部 Tab 查看行程、预算、贴士和地图
8. 在地图 Tab 中体验缩放、筛选、点击标记点等功能
9. 点击左上角返回按钮返回规划列表

#### 发现 Tab
1. 点击底部 Tab 切换到「发现」
2. 浏览双列瀑布流的社区行程
3. 点击顶部分类标签筛选不同类型的行程
4. 点击任意卡片进入发现详情页
5. 查看行程详情、作者信息、行程亮点
6. 点击底部「复用此行程」按钮，可添加到我的规划
7. 点赞、收藏等交互

#### 我的 Tab
1. 点击底部 Tab 切换到「我的」
2. 查看个人信息和数据统计
3. 点击各菜单项，查看 Toast 提示「功能开发中」

## 技术栈

- **HTML5**：页面结构
- **CSS3**：样式与动画（CSS Variables、Flexbox、Grid、Media Queries、backdrop-filter）
- **原生 JavaScript**：交互逻辑（无框架依赖，IIFE 封装）
- **SVG**：地图可视化
- **Mock 数据**：内联 JSON 数据，确保离线可用
- **picsum.photos**：占位图片服务（可选，离线时图片不显示但不影响功能）

## 设计规范

- CSS BEM 命名规范
- 移动端优先响应式设计

## 注意事项

1. **离线使用**：所有核心数据已内联在 `app.js` 中，双击 `index.html` 即可正常运行，无需网络连接。
2. **图片资源**：使用 picsum.photos 作为占位图，离线时图片可能无法加载，但不影响功能体验。
3. **浏览器兼容**：建议使用 Chrome、Firefox、Safari、Edge 等现代浏览器。
4. **移动端适配**：已做响应式适配，最大宽度 430px，桌面端居中显示模拟手机效果。
5. **数据说明**：所有数据均为模拟数据，仅供演示使用，不构成真实旅行建议。
6. **AI 模拟**：AI 行程生成为模板匹配，非真实大模型调用。
7. **file:// 协议**：所有数据内联在 JS 中，支持直接双击 index.html 打开运行。
