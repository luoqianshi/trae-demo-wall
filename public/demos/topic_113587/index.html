🎯 功能概述

QuickCircuit 是一个轻量级的硬件仿真平台，支持 Verilog HDL 代码的语法检查和仿真波形生成。

📁 文件管理

  • 上传文件：点击左侧上传区域或拖拽 .v 文件到上传区域
  • 上传文件夹：支持上传包含多个 .v 文件的文件夹
  • 删除文件：点击文件列表右侧的 × 按钮
  • 文件标签：上传多个文件时，通过顶部标签切换编辑

🔍 语法检查

  • 检查范围：模块结构、括号匹配、敏感信号列表、注释闭合等
  • 错误提示：显示错误位置（行号）和详细描述
  • 警告提示：时序逻辑缺少复位、case缺少default分支等
  • 使用方式：点击工具栏的「语法检查」按钮

📊 仿真波形

  • 信号提取：自动从代码中提取 input、output、wire、reg 信号
  • 波形类型：时钟信号（方波）、数据信号（随机变化）、常量信号（固定值）
  • 波形信息：显示信号数量、时间刻度、采样点
  • 使用方式：点击工具栏的「仿真」按钮

💡 使用示例

module AND_GATE(
    input A,
    input B,
    output Y
);
    assign Y = A & B;
endmodule

上传以上代码后，点击「仿真」按钮即可生成波形图。

❓ 常见问题

Q: 为什么上传文件后没有显示？
A: 请确保上传的是 .v 文件，非 .v 文件会被自动过滤。
Q: 语法检查显示错误怎么办？
A: 根据错误提示定位到具体行号，检查括号、分号、关键字拼写等。
Q: 波形图没有显示信号？
A: 请检查代码中是否有正确的 module 声明和端口定义。

📝 支持的Verilog语法

  • 模块声明：module ... endmodule
  • 端口定义：input、output、inout
  • 数据类型：wire、reg、parameter
  • 赋值语句：assign、always @(...)
  • 条件语句：if、else、case、default
  • 运算符：&、|、^、~、&&、||、!
