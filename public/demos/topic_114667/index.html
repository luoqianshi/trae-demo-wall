5 · 双模式架构

为不同水平的用户提供匹配的专业度
🌟 基础模式
  • 回答控制在 3-5 句话，简洁清晰
  • 避免专业术语，使用生活化比喻
  • 适合跑步初学者和爱好者
  • 直观易懂的训练指导
⚡ 高端模式
  • 引用周期化训练理论、Jack Daniels跑步公式
  • 提供配速区间、心率区间、训练负荷(ACWR)等量化指标
  • 适合有训练基础的进阶跑者
  • 深入的专业数据分析

9 · AI集成方案

智能路由，三级响应机制，保证离线可用

智能路由核心逻辑

function getResponse(question: string, mode: string): Promise<string> {
  // 1. 优先匹配本地知识库
  const matched = findInKnowledgeBase(question);
  if (matched) return formatResponse(matched, mode);

  // 2. 启用AI且配置API时，调用大模型
  if (settings.aiEnabled && hasApiKey()) {
    return callAiApi(question, mode);
  }

  // 3. 兜底：本地Mock智能响应
  return getMockResponse(question, mode);
}

10 · 安全与隐私

用户数据完全可控，零上传，可离线使用
  • API Keys 仅本地保存：用户配置的 AI API 密钥只保存在浏览器 localStorage，不向任何第三方上传
  • 数据不上传：所有训练记录、计划、对话数据都保存在用户本地，不发送到外部服务器
  • 免责声明：内置医疗建议免责声明，明确告知本应用不替代专业医疗和训练指导
  • XSS防护：使用 React 渲染机制自动转义用户输入，防止跨站脚本攻击
