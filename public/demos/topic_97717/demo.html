TRAE CAPABILITY

TRAE 在本项目中的能力运用

本项目从创意构思到 Demo 实现，全程借助 TRAE 平台的 AI 辅助能力。TRAE 不仅是代码生成工具，更是产品思维的协作伙伴——从 PRD 撰写、架构设计到代码实现与测试验证，形成了"需求→设计→开发→测试"的完整 AI 辅助闭环。

  • 需求阶段：通过对话式引导，从"找好点子"方法论出发，完成需求文档与 PRD 自动生成，结构化输出产品方案
  • 设计阶段：AI 生成创意展示 HTML 与可交互 Demo，自动设计视觉风格与交互流程，支持多轮迭代优化
  • 开发阶段：基于 MCP 多智能体架构，TRAE 辅助编写 Agent 编排逻辑、RAG 检索流程与前端组件
  • 测试阶段：AI 生成测试数据与自动化断言脚本，14 项验证点一键执行，确保渲染逻辑正确性
MCP ARCHITECTURE

四 Agent 协作流程

采用 MCP（Model Context Protocol）多智能体架构，将查证任务拆分为四个专职 Agent，各司其职、串联流转，确保每一步都可追溯、可干预。

壹
Triage Agent · 分诊
识别链接类型，判断是否触发查证（域名特征 + 关键词）
贰
Scraper Agent · 抓取
提取链接正文、标题、配图，清洗广告与干扰元素
叁
RAG Agent · 检索
向量化正文，在权威信源库中语义匹配（非 LLM 推理判定）
肆
Summary Agent · 摘要
将匹配结果生成中立、温和的科普话术，附信源链接
TECH STACK

技术选型与数据流

DECISION LOGIC

查证结果的三种分支逻辑

RAG 检索基于相似度阈值（0.75）做分支决策，每种分支对应不同的回应策略，不做主观判定：

✓ 命中辟谣
相似度 ≥ 0.75，权威信源已辟谣。输出"已查证"卡片 + 信源链接 + 温和话术。
⚠ 规则命中
RAG 未命中但规则引擎命中高风险词。输出"风险提示"卡片 + 拨打 96110 建议。
ℹ 暂无定性
RAG 与规则均未命中。诚实回复"暂无权威定性" + 谨慎建议。诚实即差异化。
