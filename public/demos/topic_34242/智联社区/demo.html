📖 启动运行说明

01
启动后端服务
打开 PowerShell，进入后端目录后启动： cd d:\新建文件夹\智联社区\backend python app.py 服务地址：http://127.0.0.1:5000
02
启动居民小程序端
另开一个 PowerShell 窗口： cd d:\新建文件夹\智联社区\miniprogram python -m http.server 8080 浏览器访问：http://127.0.0.1:8080
03
启动管理后台端
再开一个 PowerShell 窗口： cd d:\新建文件夹\智联社区\admin python -m http.server 8081 浏览器访问：http://127.0.0.1:8081
