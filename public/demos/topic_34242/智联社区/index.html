📖 如何体验本 Demo

01
直接打开方式（推荐）
双击 index.html 用浏览器打开本页面，点击上方的「进入居民端」或「进入管理后台」按钮即可。

✨ 无需安装任何依赖，无需启动服务。
02
本地服务器方式
如需对接后端 Flask 服务，启动命令： cd d:\新建文件夹\智联社区\backend python app.py 默认端口 http://127.0.0.1:5000
03
本地 HTTP 服务方式
另开两个 PowerShell 启动前端（可选）： cd d:\新建文件夹\智联社区\miniprogram python -m http.server 8080 cd d:\新建文件夹\智联社区\admin python -m http.server 8081
