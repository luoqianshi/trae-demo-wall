【项目简介】
----------------
邻里智联是面向老旧小区的社区治理一体化平台，包含「居民小程序端」
和「管理后台端」两个子系统，覆盖以下核心能力：

  🔧 AI 隐患工单管理（自动识别 · 分级预警 · 闭环流程）
  💬 居民诉求管理（在线报修 · 政务咨询）
  🤝 邻里共享与积分体系（物品互通 · 行为激励）
  📢 社区通知推送（精准推送 · 已读追踪）
  👴 独居老人监测（活动监测 · 预警关怀）
  ✅ 账号注册审核机制（实名验证 · 分级管理）


【如何体验 Demo · 推荐方式】
----------------

【可选：完整后端模式】
----------------
如需体验真实前后端联调流程（非 Demo Mock 模式）：

1. 安装 Python 依赖
   cd d:\新建文件夹\智联社区\backend
   pip install -r requirements.txt

2. 启动 Flask 后端
   python app.py
   (默认监听 http://127.0.0.1:5000)

3. 启动前端服务（可选）
   另开 PowerShell 1 → miniprogram > python -m http.server 8080
   另开 PowerShell 2 → admin      > python -m http.server 8081

4. 浏览器访问
   居民端： http://127.0.0.1:8080/login.html
   管理端： http://127.0.0.1:8081/login.html

【常见问题 Q&A】
----------------
Q: 直接双击打开 index.html 可以吗？
A: 可以。本 Demo 经过特殊设计，支持直接双击打开体验。

Q: 打开页面显示空白怎么办？
A: 请检查是否为完整解压，确认 js/api.js、js/app.js、css/style.css
   文件存在；并尝试使用 Chrome / Edge 浏览器打开。

Q: 登录提示账号/密码错误？
A: 请使用上方【测试账号】中的手机号与密码；
   小程序端也可自行输入 11 位手机号 + 6 位以上密码登录。

Q: 能否修改 mock 数据？
A: 可以，数据集中在 miniprogram/js/api.js 和 admin/js/api.js
   中的 Mock 数据部分，修改这些数据后刷新页面即可。

Q: 如何恢复初始数据？
A: 清除浏览器 localStorage（按 F12 → Application → Local Storage
   → 右键清除），或换一个浏览器/无痕模式打开即可。
