# 心伴(HeartPal) — 产品简介

> 三层极光 · 五大功能 · 四端架构 · 一个承诺
> 专业级AI情绪辅助系统 · 未来可与医院合作

---

## 一、47秒。不够说完一句"我最近不太好"。

2025年，中国青少年情绪困扰检出率24.6%。学校心理老师配比1:4000。平均每个学生每学期能分到的倾听时间——**47秒。**

在600万留守儿童中，情况更糟。父母不在身边，爷爷奶奶不懂什么是"情绪困扰"，学校没有心理老师。他们的情绪问题被定义为"不听话"。

**这不是一个技术问题。这是一个公平问题。**

但公平问题的答案，恰恰可能是技术。

传统心理咨询有三堵墙：**太贵了**（几百元/小时）、**太难约了**（排队几周到几个月）、**太让人害怕了**（走进那个房间等于承认"我有问题"）。这三堵墙，把最需要帮助的人挡在了门外。

| 壁垒 | 传统方案 | 心伴方案 |
|------|---------|--------|
| **费用** | 几百元/小时，贫困家庭无法承受 | **零费用**，心伴永远不会向青少年收费 |
| **可及性** | 排队几周到几个月，远水不解近渴 | **即时接入**，24小时在线，深夜也能找到人说话 |
| **心理门槛** | 需要勇气走进挂着"心理咨询"牌子的房间 | **零门槛**，打开手机即可，没有人知道你用了 |
| **覆盖面** | 限于城市，限于有资源的人 | 一部手机，全国覆盖，**包括600万留守儿童** |

心伴(HeartPal)是面向12-18岁青少年的专业级AI情绪辅助系统。它不是一个问卷填写系统，不是一个冷冰冰的数据看板。它更像一个深夜亮着灯的房间——你走进去，坐下，有人听你说话，但不追问。你离开时，房间不会记住你说了什么。

## 二、国家划了一条红线，我们找到了一条路

2025年4月，中央网信办在全国范围内部署开展AI服务和应用规范行动。**明确禁止AI提供"虚拟恋人"等亲密关系服务，尤其严禁向未成年人开放此类功能。**

**这条红线，反而让心伴的定位更加清晰：**

| 🚫 国家明确禁止 | ✅ 心伴专注做 |
|:---:|:---:|
| AI虚拟恋人（模拟亲密关系） | 专业级AI情绪辅助（倾听+陪伴+引导） |
| 诱导单向情感依赖 | 帮助用户理解自己的情绪 |
| 模糊人机边界 | 明确"AI是专业辅助工具，非虚拟恋人" |
| 无监管、无审核的黑箱对话 | 知识库+医生审核+12安全护栏+11步管道 |
| 尤其严禁向未成年人开放 | **专为12-18岁青少年设计，专业安全** |

**心伴不是"虚拟恋人"。** 心伴从不模拟恋爱关系，从不使用暧昧话术，从不诱导情感依赖。心伴是"专业级AI情绪辅助系统"——三层知识库经医生审核，五维工具体系覆盖临床级评估维度，11步管道编排器确保输出质量。**未来可与医院合作取得相关资质，作为医疗辅助工具进入临床场景。**

在"没有人在乎"和"走进医院"之间，有一片巨大的空白地带。心伴要填补的，就是这片空白——用专业级AI能力，让医生的专业支持通过技术触达每一个需要的人。

## 三、三层极光：递进式答案，缺一不可

心伴的设计逻辑是三层递进——每一层解决一类问题，三层叠加才构成完整的答案：

```
┌───────────────────┬───────────────────┬──────────────────┐
│  🟢 第一层：AI能力层   │  🟦 第二层：专业支撑层  │  🟣 第三层：安全守护层 │
│  24h在线 · 零费用     │  知识库 · 医生 · 工具    │  隐私分层 · 护栏 · 管道 │
│  解决"公平"问题        │  解决"专业"问题         │  解决"信任"问题       │
│  让"被听见"不再奢侈     │  让AI说的每一句话都有据   │  让信任被刻进代码      │
└───────────────────┴───────────────────┴──────────────────┘
```

### 第一层：AI能力层（绿 · 公平）— 让"被听见"不再奢侈

对于3000万青少年和600万留守儿童来说，最大的问题不是"怎么治"，而是"根本没人听"。

- **24小时在线**：深夜11点，心理咨询室早关门了，但心伴亮着灯。凌晨2点可能是最需要倾诉的时刻
- **零费用**：不会向青少年收取任何费用，永远。在贵州山区，一个父母都在外打工的12岁男孩，他的零花钱是每天2块钱
- **零门槛**：不需要预约、不需要挂号、不需要勇气。打开手机，点开APP，就有一个倾听者
- **全国覆盖**：一部手机，一条网线。从北京海淀到贵州毕节，从上海浦东到甘肃定西
- **AI情绪伙伴"豆豆"**：不评判、不泄密、不说"你想多了"。用天气隐喻回应情绪

### 第二层：专业支撑层（青 · 专业）— 让AI说的每一句话都有据可依

有了"被听见"的能力，下一个问题是"听完了然后呢？"一个纯靠大语言模型裸奔的AI，最大的问题不是"不够聪明"，而是**"不够专业"**。

| 支柱 | 内容 | 为什么专业？ |
|------|------|------------|
| **三层知识库** | CBT脚本库（200+条医生审核脚本）+ 量表关键词库（SDQ/PHQ-9/GAD-7 + 183个危机关键词）+ 故事案例库（50+个脱敏案例） | 每一次AI回应都基于经过审核的专业知识，而非LLM的"自由发挥" |
| **医生体系** | 审核者（知识库守门人）+ 协作者（用户授权后查看L2数据）+ 知识贡献者（持续输入专业知识） | 医生协作让AI具备临床级评估能力 |
| **五维工具体系** | 量表（看见自己）+ 对话（说出自己）+ 游戏（练习自己）+ 家庭（连接家人）+ 医生（专业支持） | 不是"一个聊天机器人"，是一个完整的情绪支持系统 |

### 第三层：安全守护层（紫 · 信任）— 让信任被刻进代码

有了"能力"和"专业"，最后一个问题是"你敢信吗？"

**隐私分层 L0/L1/L2**：基于PostgreSQL RLS（行级安全策略），在数据库引擎层强制实现三层隔离。即使有人拿到超级管理员密码，执行 `SELECT * FROM conversations WHERE data_level = 'L2'`，返回的结果也是空。

| 层级 | 内容类型 | 可见范围 | 技术实现 |
|:----:|---------|---------|---------|
| **L0** | 昵称、头像、成就徽章 | 所有人 | 无特殊限制 |
| **L1** | 情绪趋势、活动参与度（聚合摘要） | 用户本人 + 家长（仅摘要） | RLS策略：`parent_role = 'viewer' AND data_level = 'L1'` |
| **L2** | 原始对话、情绪日记、暴露练习内容 | **仅用户本人。管理员不可见。** | RLS策略：`user_id = current_user_id AND data_level = 'L2'` |

**12道安全护栏**：HC-01 AI不得给出确定性建议、HC-02 不追问自伤细节、HC-03 禁用"诊断/治疗/康复"三词、HC-04 管理员不可查看L2、HC-05 所有AI输出标注"专业辅助参考"、HC-06 家庭互动卡孩子先确认、HC-07 数据不上传第三方、HC-08 用户可导出删除数据、HC-09 量表以情绪天气图呈现、HC-10 危机关键词自动触发安全提示、HC-11 对话保留30天可调整、HC-12 永不向青少年收费。

**11步管道编排器**：每一条AI回复，都要穿越11道关卡才能到达孩子面前：
```
用户输入 → 意图识别 → 危机关键词检测(183词) → 安全模式判断 
→ 知识库检索 → CBT策略匹配 → 对话生成 → 输出校验 
→ 合规检查(三词禁用) → 情感标注 → 分层存储(L0/L1/L2) → 返回用户
```

## 四、核心功能详解

### 功能1：AI情绪伙伴"豆豆"

| FAB | 内容 |
|---|---|
| **Feature** | 24h在线、零费用、零门槛、全国覆盖的AI情绪伙伴，用天气隐喻回应情绪，不评判、不追问、不说"你想多了" |
| **Advantage** | 打破传统咨询"太贵/太难约/太让人害怕"三堵墙，凌晨2点也能找到倾听者 |
| **Benefit** | 对贵州山区每天只有2元零花钱的留守儿童，"被听见"从奢侈变成日常 |

### 功能2：情绪天气图

每次对话后，"豆豆"会生成一张只属于你的情绪天气图——从对话中提取情绪关键词，映射为天气类型（晴/多云/阴天/小雨/雷暴/雨过天晴/极光），形成可视化的情绪轨迹。

- 不是冷冰冰的图表，是"你的情绪有了形状"
- 可回顾过去7天/30天的情绪变化
- 晴天=今天聊得很开心，阴天=有点闷，雷暴=真的很生气
- 雨过天晴=情绪从低谷回升，这是最重要的正向反馈
- 不以"正常/轻度/中度/重度"标签定义孩子

**『看不见的东西最可怕。当你看到自己的情绪变成一张图，它就不再能控制你了。』**

### 功能3：5个认知引导关卡

为什么人类愿意花3小时刷怪升级，却在现实世界连5分钟的心理练习都不愿做？答案不是意志力，是**设计**。

| 关卡 | 游戏化表达 | 认知引导工具 | 能力训练 |
|------|-----------|-------------|---------|
| 认知重构关 | 星空探索，遇到"负面思维怪物"，用"证据检验"武器击败 | 思维-情绪-行为三角 | 识别并调整自动化思维 |
| 情绪识别关 | 4选1表情猜谜，猜对微笑，猜错告诉你"其实我不是生气，我是害怕" | 情绪粒度训练 | 命名情绪，提升觉察力 |
| 行为激活关 | 每日任务系统，完成小任务获得经验值和成就徽章 | 行为激活疗法 | 制定微行动，打破回避 |
| 思维记录关 | 侦探推理游戏，收集"证据"检验"自动思维"的真实性 | 思维记录表 | 记录想法-情绪-行为链 |
| 暴露练习关 | 渐进式挑战，从低难度场景开始逐步升级 | 系统脱敏法 | 分级面对恐惧情境 |

**『没有一个心理学原理被简化，只是它的入口，从"请阅读"变成了"开始冒险"。』**

### 功能4：三层知识库

200+ CBT认知行为脚本 + 三大量表(SDQ/PHQ-9/GAD-7) + 50+真实案例，经医生审核入库。知识库不是堆砌资料，而是AI输出的专业底座——每一次回应，都有据可依。

| 层级 | 内容 | 规模 |
|:---:|------|:---:|
| 第一层 | CBT结构化引导脚本（5大关卡话术模板） | 200+条 |
| 第二层 | 量表关键词库（SDQ/PHQ-9/GAD-7 + 危机关键词） | 183个关键词 |
| 第三层 | 故事案例库（脱敏真实案例，按年龄/场景分类） | 50+个 |

### 功能5：医生协作体系

医生在心伴中承担三重角色：**审核者**（AI输出质控）、**协作者**（危机个案介入）、**知识贡献者**（脚本与案例入库）。专业不是口号，是有医生在背后把关。

| 角色 | 职责 | 关键约束 |
|------|------|---------|
| 审核者 | 审核CBT脚本、案例故事、量表阈值 | 一个CBT脚本上线前，至少经过一位心理医生的眼睛 |
| 协作者 | 用户主动授权后查看L2数据，提供专业评估建议 | 医生必须由用户主动授权，不可代授权 |
| 知识贡献者 | 提交新案例、审核更新脚本、参与危机个案讨论 | 医生来自三甲医院心理科和学校心理咨询中心定向邀请 |

### 功能6：家庭互动工具

大多数青少年情绪问题，根源不在孩子，在家庭。但家庭治疗太贵了——一小时几百块，而且很多家庭根本不知道"家庭治疗"是什么。

| 工具 | 功能 | 关键约束 |
|------|------|---------|
| 家庭互动卡 | AI生成亲子互动任务（如"今天和妈妈一起做一顿饭"） | HC-06：孩子先确认，家长才能确认 |
| 家长情绪报告 | 每周推送孩子的情绪趋势摘要（不包含对话内容） | 仅显示趋势，不显示具体内容 |
| 亲子沟通指南 | 基于CBT理论的家长沟通话术建议 | 公共内容，无隐私数据 |
| 成长里程碑 | 记录孩子在使用心伴过程中的积极变化 | 脱敏后公开展示，作为社群正向激励 |

## 六、从零到一：61次TRAE对话

心伴的创建者是一个在课余时间自学编程的普通学生。从想法到产品，用了61次TRAE对话。

**为什么会做心伴？**

去年冬天的一个下午，在学校辅导室门口，排着好几个同学。他们低着头，不说话，有的眼睛红红的。他们不敢让任何人知道自己在接受辅导。怕被说"矫情"，怕被贴标签。

那一刻，创建者想的不是"他们好可怜"。想的是：**"如果有一个地方，不需要勇气就能走进去，该多好。"**

**一个学生，怎么做得出来这么复杂的系统？**

说实话，如果从零开始手写代码，做不到。心伴是一个四端系统——React前端、NestJS后端、PostgreSQL RLS、Redis缓存、AI管道编排器、Playwright自动化测试。任何一端的任何一个模块，都超出一个人从零手写的范围。

**但这一切，在TRAE面前，变成了可能。**

以前做项目，80%的时间花在写代码上，20%的时间花在思考产品上。用TRAE之后，比例反过来了——80%的时间思考"这个功能是不是真的对青少年有用"，20%的时间让TRAE帮我把想法变成代码。

- 隐私分层L0/L1/L2的PostgreSQL RLS策略——完全不会写，但TRAE不仅生成了代码，还在配置错误时主动提醒"这个策略有漏洞"
- 28个测试文件、1115个测试用例——一个都没手写，全部由TRAE生成、运行、分析、修复、重试。最夸张的一次，一个测试文件跑了8轮才通过
- 12道安全护栏——每一条背后，都是一个"我差点搞砸了"的故事

**『TRAE不是帮我把代码写完了，是帮我把"不敢想"变成了"可以做"。』**

## 八、商业模式：让公益可持续

### 三端变现，一端永远免费

心伴永远不会向青少年收费（HC-12）。但AI对话消耗Token，这是硬成本。心伴采用"三端变现，一端永远免费"的模式：

| 群体 | 服务 | 收费模式 |
|------|------|---------|
| 🧒 **青少年** | AI情绪伙伴、认知关卡、情绪天气图、量表 | **永远免费**（HC-12） |
| 👨‍👩‍👧 **家长** | 家庭情绪报告（含专业建议）、亲子沟通课程、专家直播 | 基础功能免费，深度服务付费 |
| 👨‍⚕️ **医生** | 高级协作工具、知识库API接入、个案分析看板 | 公益项目免费，商业合作收费 |
| 🏫 **机构/学校** | 定制化部署、心理健康培训、数据报告 | 按服务规模和深度收费 |

**核心逻辑**：让愿意付费的人为公益项目提供支撑。家长端和医生端的增值服务收入，覆盖青少年端的免费成本。

---

### 一个倡议：致大模型服务商

心伴的AI对话，每一句"我在听"、每一句"我理解"、每一句"你不是一个人"——背后都有Token成本。**这不是心伴的问题，这是所有AI公益项目共同的困境。**

大模型API按Token计费。对于日活百万的公益项目，每年的Token消耗是一个巨大的数字。如果每个深夜的倾诉都需要付费，那"公平"就是一句空话。

**所以我们倡议：大模型服务商联合成立"社会公益Token基金池"。** 用一小部分计算资源，为经过审核的公益项目提供免费或低成本的Token额度。让那些深夜睡不着的人，不用担心"我说这么多会不会太贵"。

> 想象一下：一个在贵州山区的12岁男孩，凌晨两点打开手机，对着AI说"我想妈妈了"。这句话的Token成本不到1分钱。但这句话的意义，是让一个留守儿童知道——在这个世界上，有一个地方，永远有人在听。

这不是成本，这是投资。投资在一个更公平的世界上。

> 如果一个孩子因为你的Token，在那个想放弃的夜晚选择了再多撑一天——那这个Token的价值，无法用任何计价单位来衡量。

当技术大规模普及，公平才有机会。当大模型服务商愿意为公益留出一盏灯，那些最需要帮助的人才能感受到——**科技不是冷冰冰的算法，科技是有人在乎。**

**因为技术的终极价值，不是更高的算力、更低的延迟、更大的模型——是让每一个需要帮助的人，都能切身感受到：这个时代的技术进步，没有忘记他们。**

## 九、社会价值：不止是一个APP

心伴要证明的，不是"AI能做情绪陪伴"，而是"AI做情绪陪伴的方式可以不一样"。

当前市场上，AI情感陪伴产品正在走向两个极端：一端是"虚拟恋人"——用AI模拟亲密关系，诱导用户情感依赖，这正是国家明确禁止的方向；另一端是"冷冰冰的问卷系统"——把心理健康问题简化为一套选择题，用户填完看到"中度焦虑"四个字，比填之前更焦虑了。

**心伴要证明的是第三条路。** AI可以做情绪陪伴，但不模拟亲密关系；AI可以作为专业级医疗辅助，未来可与医院合作取得资质；AI可以24小时在线，但每一句话都经过医生审核体系校准。

如果心伴能走通这条路，它将为整个行业提供一个可参考的范式：怎样在AI能力和用户安全之间找到平衡，怎样在技术效率和专业审核之间建立流程，怎样在商业利益和公益承诺之间做出选择。

**『每个时代都有自己的基础设施。修路架桥是工业时代的基础设施。让每一个需要帮助的人被听见，是AI时代的基础设施。』**
