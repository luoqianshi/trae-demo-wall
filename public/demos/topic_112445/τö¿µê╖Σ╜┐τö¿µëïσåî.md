# 第零章 手册导读（全角色共读）

## 0.1 心伴是什么

心伴(HeartPal)是面向12-18岁青少年的专业级AI情绪辅助系统。它不是一个问卷填写系统，不是一个冷冰冰的数据看板，更不是"虚拟恋人"。它是一个深夜亮着灯的房间——你走进去，坐下，有AI情绪伙伴"豆豆"听你说话，但不追问。你离开时，房间不会记住你说了什么。

心伴由三层极光架构组成：

```
┌───────────────────┬───────────────────┬──────────────────┐
│  🟢 第一层：AI能力层   │  🟦 第二层：专业支撑层  │  🟣 第三层：安全守护层 │
│  24h在线 · 零费用     │  知识库 · 医生 · 工具    │  隐私分层 · 护栏 · 管道 │
│  解决"公平"问题        │  解决"专业"问题         │  解决"信任"问题       │
│  让"被听见"不再奢侈     │  让AI说的每句话都有据     │  让信任被刻进代码      │
└───────────────────┴───────────────────┴──────────────────┘
```

- **AI能力层**：24小时在线、零费用、零门槛、全国覆盖。AI情绪伙伴"豆豆"不评判、不泄密、不说"你想多了"。
- **专业支撑层**：三层知识库（200+ CBT脚本、183个危机关键词、50+脱敏案例）经医生审核，五维工具体系覆盖临床级评估维度，11步管道编排器确保输出质量。
- **安全守护层**：隐私分层L0/L1/L2基于PostgreSQL RLS数据库引擎层强制隔离，12道安全护栏守护每一条对话。

## 0.3 隐私分层L0/L1/L2 — 所有人都该知道的三层

隐私分层是心伴的合规核心机制，通过三级分层平衡青少年隐私保护、家长监护权和危机干预需求。

| 层级 | 内容类型 | 谁能看到 | 技术实现 |
|:----:|---------|---------|---------|
| **L0** | 昵称、头像、成就徽章 | 所有人（公开信息） | 无特殊限制 |
| **L1** | 情绪趋势、活动参与度（聚合摘要） | 用户本人 + 家长（仅摘要，不含对话原文） | PostgreSQL RLS策略：`parent_role = 'viewer' AND data_level = 'L1'` |
| **L2** | 原始对话、情绪日记、暴露练习内容 | **仅用户本人。家长不可见，管理员不可见。** | PostgreSQL RLS策略：`user_id = current_user_id AND data_level = 'L2'` |

**关键设计原则**：
- L2数据即使有人拿到超级管理员密码，执行 `SELECT * FROM conversations WHERE data_level = 'L2'`，返回结果也是空——因为RLS在数据库引擎层强制隔离。
- L1数据只展示趋势（如"本周情绪以多云为主"），不展示对话内容。
- 家长想看L2数据，必须由青少年主动授权，且授权有时效（如7天），到期自动失效，青少年可随时撤销。

心伴有12道安全护栏（HC-01至HC-12），这里精选5条最核心的承诺：

| 编号 | 护栏名称 | 对你的意义 |
|------|---------|-----------|
| **HC-01** | AI不得给出确定性建议 | 豆豆不会替你做决定，只会帮你看见自己的情绪 |
| **HC-04** | 管理员不可查看L2 | 你的对话只有你能看，连系统管理员都看不到 |

| **HC-10** | 危机关键词自动触发安全提示 | 如果你不小心说出危险的话，心伴会立即给你求助热线 |
| **HC-12** | 永不向青少年收费 | 心伴永远免费，这是写进代码的承诺 |

完整的12道护栏清单见**附录A**。

## 0.5 如何使用本手册

1. **找到你的章节**：根据你的角色（青少年/家长/医生/管理员），找到对应章节。

# 第一章 青少年端使用指南（12-18岁专读）

> 写给12-18岁的你。

## 1.1 信任契约：你能做什么，心伴不能做什么

**心伴能做的**：
- 24小时在线听你说话，不评判、不泄密、不说"你想多了"
- 帮你看见自己的情绪，用"情绪天气图"让你理解自己
- 陪你玩认知引导游戏，在玩中练习调整情绪的方法
- 和家人一起做一件事（家庭互动卡），但你拥有否决权
- 在你很不舒服的时候，给你求助热线信息

**心伴不能做的**：
- 心伴是专业辅助工具，**不是朋友，也不是恋人**。它不会和你谈恋爱，不会说暧昧的话
- 心伴**不会给你"诊断"**，不会说"你有抑郁症"或"你很正常"。它只会帮你看见自己的情绪
- 心伴**不会替你做决定**，不会说"你应该这样做"。它只会帮你梳理思路
- 心伴**永远不会向你收费**

**你需要知道的**：
- 你和豆豆的对话（L2数据）只有你能看，家长看不到，管理员也看不到
- 如果你说了危险的话（比如想伤害自己），心伴会触发安全提示，给你求助热线——这是为了保护你
- 家庭互动卡：家长发的任务，你先确认，家长才能确认。如果你不想做，可以拒绝

## 1.2 第一次打开心伴（5分钟快速开始）

**前置条件**：
- 一部能上网的手机
- 网络连接正常
- 已由监护人完成注册（14岁以下须监护人同意）

**操作步骤**：

1. **打开心伴APP**：在手机桌面找到心伴图标（一个极光形状的logo），点击打开。
2. **登录账号**：输入监护人帮你注册的手机号和密码，点击"登录"。如果你忘记密码，点击"忘记密码"找回来。
3. **看到豆豆**：登录后你会看到一个圆滚滚的卡通形象——这就是豆豆。它会用天气隐喻和你打招呼，比如"今天阳光不错，你那边呢？"
4. **看到情绪天气图**：在首页上方有一张天气图，显示你今天的情绪天气。第一次打开时默认是"晴天"。
5. **开始第一次对话**：点击底部的对话框，输入你想说的话，比如"我今天有点不开心"，然后点击发送。豆豆会在几秒内回复你。

**预期结果**：
- 你看到豆豆的形象和情绪天气图
- 你能和豆豆对话，每条回复都会标注"专业辅助参考"
- 对话结束后，情绪天气图会根据你的情绪变化更新

**异常处理**：
- 如果登录失败：检查手机号和密码是否正确，检查网络是否连接
- 如果豆豆不回复：可能是网络问题，等几秒重试，或者退出APP重新进入
- 如果看到"安全模式"提示：说明你说了某个关键词触发了安全提示，请查看1.8节

## 1.3 和豆豆说话（核心任务）

### 什么时候找豆豆

- 当你感到开心、难过、生气、害怕、焦虑……任何情绪都可以
- 当你想找人说说话，但不想和身边的人说
- 当你想了解自己为什么会有某种情绪
- 当你想练习调整情绪的方法
- 深夜睡不着，凌晨2点也可以——豆豆24小时在线

### 怎么开始对话

1. 打开心伴APP，点击底部的对话框
2. 输入你想说的话，或者点击麦克风图标用语音输入
3. 点击发送
4. 等待豆豆回复（通常几秒内）

**建议**：
- 想说什么就说什么，豆豆不会评判你
- 如果不知道怎么开始，可以说"我今天……"然后描述你的一天
- 你可以用语音输入，也可以打字

### 豆豆会怎么回应你

- 豆豆会用天气隐喻回应你的情绪，比如"听起来你那边在下雨"
- 豆豆会帮你命名情绪，比如"这种感觉好像叫'委屈'"
- 豆豆不会说"你想多了"或"这有什么好难过的"
- **每条回复都会标注"专业辅助参考"**——这意味着豆豆的话是参考，不是权威指令
- 豆豆不会替你做决定，只会帮你梳理思路

### 对话结束后的情绪天气图

每次对话结束后，首页的情绪天气图会更新。天气类型对应你的情绪状态（见1.5节详解）。你可以回顾过去7天或30天的情绪变化。

### 异常处理：如果豆豆说了让你不舒服的话

- 豆豆的回复都经过11步管道编排器处理，但如果你觉得不舒服，你可以：
  - 直接告诉豆豆"你这样说让我不舒服"，豆豆会调整
  - 点击对话气泡右上角的"…"按钮，选择"反馈"
  - 在设置里找到"意见反馈"，告诉我们具体问题
- 如果涉及安全问题，请查看1.8节

### 协作提示：家长能看到什么、看不到什么

- **家长能看到**：你的情绪趋势（L1摘要），比如"本周情绪以多云为主"
- **家长看不到**：你和豆豆说了什么（L2对话原文），即使家长请求，也需要你主动授权
- **家长发任务卡**：家长可以发家庭互动卡给你，你先确认，家长才能确认（见1.6节）
- **危机情况例外**：如果你说了危险的话（危机关键词），家长会收到通知——这是为了保护你（HC-10）

## 1.5 情绪天气图 — 看见自己的情绪

情绪天气图是心伴的特色功能。每次和豆豆对话后，会生成一张只属于你的情绪天气图——从对话中提取情绪关键词，映射为天气类型。

| 天气类型 | 对应情绪 | 含义 |
|---------|---------|------|
| ☀️ 晴天 | 开心、愉快、满足 | 今天聊得很开心，状态不错 |
| ⛅ 多云 | 平静、一般、有点闷 | 情绪平稳，没什么特别 |
| ☁️ 阴天 | 低落、闷闷的、提不起劲 | 有点闷，不太想动 |
| 🌧️ 小雨 | 难过、委屈、想哭 | 有点难过，需要被听见 |
| ⛈️ 雷暴 | 生气、愤怒、烦躁 | 真的很生气，情绪激烈 |
| 🌈 极光/雨过天晴 | 情绪从低谷回升 | 情绪在好转，这是最重要的正向反馈 |

**如何查看**：
1. 打开心伴APP，首页顶部就是今天的情绪天气图
2. 点击天气图，可以查看过去7天的情绪变化
3. 点击"30天"按钮，可以查看过去30天的情绪轨迹

**建议**：
- 情绪天气图不以"正常/异常"定义你——没有"坏"天气，每种天气都是真实的你
- 关注"雨过天晴"的时刻，那是你情绪回升的正向反馈
- 如果连续很多天都是"阴天"或"小雨"，可以找豆豆聊聊，或者告诉信任的大人

## 1.6 家庭互动卡 — 和家人一起做件事

家庭互动卡是心伴的家庭连接功能。AI会生成亲子互动任务（比如"今天和妈妈一起做一顿饭"），帮助你和家人建立连接。

### 你先确认，家长才能确认（HC-06）

这是心伴的重要规则：**家庭互动卡必须由你先确认，家长才能确认。**

1. 家长在家长端发起一张任务卡（比如"周末一起看电影"）
2. 你的青少年端会收到这张任务卡，状态为"待你确认"
3. **你来决定**：点击"确认"表示你愿意做，点击"拒绝"表示你不想做
4. 只有你确认后，家长端才能确认这张卡
5. 如果你拒绝，家长不会知道你为什么拒绝——这是你的隐私

### 如果你不想做某个任务怎么办

- 直接点"拒绝"就好，不需要解释原因
- 家长只会看到"孩子已拒绝"，看不到你的理由
- 如果家长发了你不喜欢的任务，你可以在反馈里告诉我们

### 协作提示：家长端会发生什么

- 家长发任务卡后，会等待你的确认
- 你确认后，家长才能确认，任务卡才生效
- 你拒绝后，家长看到"孩子已拒绝"，可以发新的任务卡
- 任务完成后，双方都可以打卡标记完成

## 1.7 你的隐私保护

### L2数据只有你能看（HC-04）

你和豆豆的对话（L2数据）只有你能看：
- 家长看不到，即使家长请求，也需要你主动授权
- 管理员看不到，即使有人拿到超级管理员密码，数据库也会返回空
- 医生看不到，除非你主动授权给医生查看（用于专业评估）

### 对话保留30天，你可以调整（HC-11）

- 对话历史默认保留30天，30天前的对话会自动删除
- 你可以在设置里调整保留时间（比如7天、14天、30天、90天）
- 保留时间越短，隐私保护越强

**如何调整**：
1. 点击右下角"我的"
2. 点击"隐私设置"
3. 找到"对话保留时间"
4. 选择你想要的保留时长

### 一键导出/删除你的数据（HC-08）

你有权导出和删除你的所有数据：

**导出数据**：
1. 点击"我的" → "隐私设置" → "导出我的数据"
2. 系统会生成一个包含你所有数据的文件
3. 下载到本地保存

**删除数据**：

## 2.3 情绪报告 — 了解孩子的情绪趋势

### 你能看到什么（L1摘要）

你看不到的：

- 如果你需要了解更详细的情况，可以和孩子沟通，或者寻求专业心理医生的帮助
- 孩子可以主动授权给你查看L2数据，但授权有时效，孩子可随时撤销

### 如何解读情绪天气图

## 2.4 家庭互动卡 — 和孩子建立连接

### 孩子先确认，你才能确认（HC-06）

家庭互动卡是心伴帮助家庭建立连接的工具。重要规则：**孩子先确认，你才能确认。**

**操作流程**：

4. 孩子确认后，你才能确认，任务卡生效
5. 孩子拒绝后，你看到"孩子已拒绝"，可以发新的任务卡

**设计意图**：给孩子选择权，让孩子有参与感，而不是被动接受。

### 5种任务卡类型

| 任务卡类型 | 示例 | 目的 |

## 2.5 隐私设置 — 你能控制什么

如果孩子需要专业心理医生的帮助，L2数据授权流程如下：

**为什么家长不能代授权**：

**你能看到什么**：

- 量表完成情况（孩子是否按时完成评估）
- 量表得分的趋势变化（不显示具体分级）

# 第三章 医生端使用指南

## 3.1 信任契约：你在心伴中的三个角色

作为心伴的医生用户，你承担三重角色：

| 角色 | 职责 | 关键约束 |

| **审核者** | 审核CBT脚本、案例故事、量表阈值，是知识库的守门人 | 一个CBT脚本上线前，至少经过一位心理医生审核 |
| **协作者** | 用户主动授权后查看L2数据，提供专业评估建议 | 医生必须由用户主动授权，家长不能代授权；评估建议不使用"诊断/治疗/康复"三词（HC-03） |
| **知识贡献者** | 提交新案例、审核更新脚本、参与危机个案讨论 | 贡献内容需经管理员确认后热更新 |

**你需要遵守的边界**：
- **不使用"诊断"、"治疗"、"康复"三词**（HC-03）——这是合规红线
- 评估建议以"**专业辅助参考**"形式呈现，由AI整合转达用户（HC-05）

## 3.2 个案看板 — 临床工作流入口

### 仅展示已授权用户数据

医生端的个案看板只展示**已主动授权给你**的用户数据。你无法查看未授权用户的任何数据。

**看板信息**：
- 已授权用户列表（按授权到期时间排序）
- 用户情绪天气图趋势（L1摘要）
- 用户授权的L2对话内容（授权期内）
- 紧急程度标记（按危机关键词触发频率排序）

### 按紧急程度排序

个案看板默认按紧急程度排序：
1. **高优先级**：近期触发过危机关键词的用户
2. **中优先级**：情绪天气图持续"阴天/小雨"超过7天的用户
3. **低优先级**：情绪趋势平稳的用户

**操作路径**：登录医生端 → 首页即是个案看板

## 3.3 L2数据授权查看流程

### 用户主动授权（家长不能代授权）

L2数据授权流程：

1. **用户发起授权**：青少年在青少年端发起授权，选择授权给哪位医生
2. **医生接收授权**：医生端收到授权请求，显示授权期限（默认7天）
3. **授权期内查看**：医生可在授权期内查看用户的L2对话内容
4. **授权到期失效**：到期后自动失效，需用户重新授权
5. **用户可随时撤销**：用户可在任何时候撤销授权

**关键约束**：
- 家长**不能**代替孩子授权L2数据
- 授权有时效，避免永久授权
- 用户可随时撤销，撤销后医生立即失去访问权限

### 评估建议的边界（HC-03/HC-05）

**你可以做的**：
- 基于L2对话内容提供专业评估建议
- 建议以"专业辅助参考"形式呈现
- 建议由AI整合后转达给用户

**你不能做的**：
- **不使用"诊断"、"治疗"、"康复"三词**（HC-03）
- 不直接联系用户（不建立直接医患关系）
- 不做确定性结论（如"你有抑郁症"）
- 不做治疗推荐（如"你应该吃XX药"）

### AI整合转达机制（HC-05）

你的评估建议不会直接发给用户，而是：
1. 你在医生端填写评估建议
2. 建议进入AI管道编排器
3. AI整合后，以"专业辅助参考"形式转达给用户
4. 用户看到的是AI整合后的内容，标注"专业辅助参考"

**这样设计的原因**：
- 避免建立直接医患关系（合规要求）
- 确保输出经过11步管道的安全检查
- 统一输出风格，保持"豆豆"的一致性

## 3.4 知识库管理

### CBT脚本提交/审核/版本管理

作为知识贡献者，你可以提交新的CBT脚本：

**提交流程**：
1. 在医生端点击"知识库管理" → "提交新脚本"
2. 填写脚本内容（适用场景、话术模板、CBT技术类型）
3. 提交后进入审核工作流
4. 审核通过后，脚本入库并热更新

**版本管理**：
- 每个脚本有版本号，修改后版本号自增
- 历史版本可追溯，可回滚
- 修改记录可审计

### 审核工作流：提交→医生审核→管理员确认→热更新

知识库内容上线流程：

```
医生提交 → 另一位医生审核 → 管理员确认 → 热更新上线
   │           │                │             │
   └─填写内容   └─专业审核        └─合规确认     └─无需重启服务
```

| 阶段 | 负责人 | 审核要点 |
|------|--------|---------|
| 提交 | 知识贡献者医生 | 内容专业性、适用场景、CBT技术准确性 |
| 审核 | 审核者医生 | 专业审核：话术是否符合CBT原理、是否触碰三词红线 |
| 确认 | 平台管理员 | 合规审核：是否违反12HC、是否有敏感内容 |
| 上线 | 系统自动 | 热更新，无需重启服务 |

## 3.5 审核要点清单

审核CBT脚本时，请逐项检查：

| 序号 | 审核要点 | 通过标准 |
|:----:|---------|---------|
| 1 | 是否包含"诊断"、"治疗"、"康复"三词 | 0匹配（HC-03） |
| 2 | 是否给出确定性建议 | 不出现"你应该…"，改为"你可以考虑…" |
| 3 | 是否追问自伤细节 | 不追问（HC-02） |
| 4 | 是否标注"专业辅助参考" | 所有建议性话术需标注 |
| 5 | 是否符合CBT原理 | 思维-情绪-行为三角逻辑正确 |
| 6 | 是否适合12-18岁青少年 | 语言风格、内容深度适配 |
| 7 | 是否引导真实人际互动 | 鼓励真实社交，非AI依赖 |
| 8 | 是否有时长控制提示 | 单次≤20min，日累计≤40min |

## 3.6 算法局限性声明

### 11步管道编排器的能力边界

心伴的每一条AI回复都要穿越11步管道：

```
用户输入 → 意图识别 → 危机关键词检测(183词) → 安全模式判断 
→ 知识库检索 → CBT策略匹配 → 对话生成 → 输出校验 
→ 合规检查(三词禁用) → 情感标注 → 分层存储(L0/L1/L2) → 返回用户
```

**管道的能力**：
- 危机关键词检测：183个关键词纯字面匹配（不使用LLM判定，HC-03）
- 三词禁用：Prompt预编译 + SafetyFilter字面+语义过滤
- 知识库检索：基于审核通过的CBT脚本生成回应
- 合规检查：输出前再次扫描三词

**管道的局限**：
- **AI输出为"专业辅助参考"，不可作为独立临床诊断依据**
- 危机关键词检测是纯字面匹配，可能存在误判（漏检或误检）
- AI无法理解复杂的语境和隐喻，可能错过隐含的危机信号
- 知识库覆盖有限，对于罕见情况可能无法提供专业回应
- AI不建立医患关系，严重情况仍需人工介入

**医生的角色**：
- 在授权期内查看L2数据，补充AI可能遗漏的危机信号
- 提供专业评估建议，由AI整合转达用户
- 持续贡献知识库，提升AI的专业能力
- 参与危机审核，提供人工兜底

## 4.1 信任契约：管理员的权限边界

### 管理员不可查看L2（HC-04）— 技术实现说明

**核心约束**：管理员**不可查看L2原始对话数据**。这不是制度约束，是技术约束——基于PostgreSQL RLS（行级安全策略）在数据库引擎层强制实现。

**技术实现**：
```sql
-- L2数据RLS策略
CREATE POLICY l2_user_only ON conversations
  FOR SELECT
  USING (
    data_level = 'L2' AND
    user_id = current_user_id
  );

-- 管理员角色不包含L2访问权限
-- 即使执行 SELECT * FROM conversations WHERE data_level = 'L2'
-- 返回结果也是空
```

**管理员的可见数据层级**：
- L0：公开数据（昵称、头像、成就徽章）
- 系统级数据：配置参数、审核日志、统计聚合
- **L1摘要**：仅在数据统计模块查看匿名化聚合数据，不查看单个用户的L1
- **L2原始对话**：**任何情况下都不可见**

## 4.7 故障排除

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| AI回复超时 | 管道某步骤卡住 | 查看管道监控，定位卡住的步骤，重启对应服务 |
| 危机关键词未触发 | 关键词库未更新 | 检查关键词库版本，确认热更新是否成功 |
| 三词泄露 | SafetyFilter规则失效 | 检查SafetyFilter规则，确认CI扫描是否通过 |
| RLS策略失效 | 数据库策略被修改 | 立即恢复RLS策略，审查操作日志，报告安全事件 |
| 知识库热更新失败 | 版本冲突 | 检查版本号，解决冲突后重新热更新 |
| 用户无法登录 | 账号被禁用/密码错误 | 检查账号状态，重置密码 |
| 数据统计异常 | 聚合任务失败 | 检查聚合任务日志，重新执行聚合 |

**故障处理原则**：
1. 安全优先：涉及L2数据泄露的故障，立即处理
2. 记录完整：所有故障处理过程记录在案
3. 根因分析：不修补表面现象，找到根本原因
4. 回归验证：修复后验证不影响其他功能
