📊 数据特征分析

                
当前数据集为多维时空数据，包含：

                
    
                    
  • 时间维度：2020-2024年（5年）× 4季节
    • 
                    
  • 地理维度：北京、上海、广州、深圳、成都（5城市）
    • 
                    
  • 指标维度：气温、湿度、降水量、AQI、日照时数、风速（6项指标）
    • 
                


                
✅ 推荐图表类型与适用场景

                
    
                    
  • 折线图：展示2020-2024年各城市年均气温的时间趋势，最能体现气候变化方向
    • 
                    
  • 柱状图：对比5城市在4个季节的气温差异，双Y轴可同时展示降水量
    • 
                    
  • 热力图：以矩阵形式呈现"城市×季节"的气温分布，适合快速定位极值
    • 
                    
  • 散点图：分析气温与AQI的相关性，点大小可映射降水量实现四维展示
    • 
                    
  • 雷达图：六维度指标综合对比各城市的气候特征画像
    • 
                    
  • 饼图：展示各城市年度降水总量的占比关系（仅适合单一维度）
    • 
                


                
⚠️ 使用注意

                
    
                    
  • 饼图不适合展示时间序列，无法体现趋势变化
    • 
                    
  • 雷达图建议城市数量不超过3个，避免图形过于复杂
    • 
                    
  • 多指标量纲不同（°C / % / mm / AQI），雷达图需先归一化
    • 
                


                
💡 设计建议

                
    
                    
  • 配色建议采用冷暖色系区分气温高低（如蓝色=冷、红色=热）
    • 
                    
  • 双Y轴图表需在图例中明确标注各系列所属坐标轴
    • 
                    
  • 散点图添加趋势线可量化变量间的相关系数
    • 
                    
  • 热力图色阶建议细化为5-7段，增强数据梯度辨识度
    • 
                    
  • tooltip 中建议同时展示多维数据，辅助深度分析
