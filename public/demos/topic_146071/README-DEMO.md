# 小说同人创作工具 · 演示版

## 快速开始

1. 解压 zip 到任意目录
2. 双击 `demo-serve.bat`
3. 浏览器自动打开 http://localhost:8765
4. 首次访问需配置 DeepSeek API Key：
   - 访问 https://platform.deepseek.com/ 注册
   - 新用户有免费额度，足够体验本 demo
   - Key 仅保存在你的浏览器，不上传任何服务器

## 你能体验到的功能

- 💬 **聊天对话**：与 AI 聊一部预置示例小说，体验 RAG 检索增强对话
  - ⚡ AI 对话真实可用；检索为预置 mock（6 个主题）
- 🎨 **风格分析**：分析示例小说的文字风格 + 叙事风格，生成风格档案
  - ⚡ 完全真实可用（上传你自己的废稿，DeepSeek 真实分析）
- 📋 **大纲共创**：三层流程生成同人故事大纲（总纲 → 单元 → 章纲）
  - ⚡ 完全真实可用
- ✍️ **逐段写作**：基于大纲流式生成 500 字段落，可中断/重写
  - ⚡ 完全真实可用
- 💡 **灵感收集**：从聊天中保存金句，反哺大纲
  - ⚡ 完全真实可用
- 📚 **项目管理**：管理你的书 / 故事 / 项目进度
  - ⚡ 完全真实可用

## 已知限制

- 上传的小说原文不会进入检索（演示版检索为预置 mock，覆盖 6 个固定主题）
- 所有数据存在浏览器 localStorage，清空浏览器数据会丢失项目；换浏览器/换电脑数据不互通
- API Key 仅本机保存，演示完成后建议在 DeepSeek 控制台吊销
- 所有 AI 生成功能都消耗 DeepSeek API 额度（新用户免费额度足够完整体验一次）

## 推荐体验路径

1. **配置 API Key**：首次访问弹窗中输入 DeepSeek Key
2. **风格分析**：新建方案 → 粘贴一段你写过的废稿 → 分析文字风格 → 输入偏好描述 → 分析叙事风格
3. **大纲共创**：新建故事 → 生成总纲 → 生成单元大纲 → 生成章纲 → 锁定
4. **逐段写作**：选刚才的故事 → 选章节 → 生成细纲 → 逐段生成（可中断/重写）
5. **聊天对话**：问"主角性格"、"林远和苏晚什么关系"等预置主题，看 RAG 引用效果

## 系统要求

- Windows 10/11
- Python 3.8+（用于启动本地服务器；若未安装会提示）
- 现代浏览器（Chrome / Edge / Firefox）
- 网络可访问 DeepSeek API（platform.deepseek.com）
