为什么需要 lg？

SVN 用户迁移到 Git 的三大痛点，lg 如何解决

📁

SVN

简单但过时

  • 集中式心智，命令直观
  • checkout / update / commit
  • 生态萎缩，工具链老旧
  • 依赖中心服务器
  • 分支管理能力弱
🔧

Git

强大但复杂

  • 分布式能力，社区主流
  • 分支轻量，merge/rebase 强大
  • 概念抽象：暂存区/分支/远端
  • 工作流繁琐：add → commit → push
  • 学习曲线陡峭
⚡

lg

Git 能力 + SVN 心智

  • 保留 Git 底层全部能力
  • 重塑上层命令语义对齐 SVN
  • SVN 用户零学习成本
  • Git 生态完整可用
  • 轻量按需检出 + 断点续传

命令对照表

SVN → Git → lg，同一个操作三个工具的命令对比

操作 SVN Git lg
检出 svn checkout URL git clone URL && cd repo lg checkout URL
更新 svn update git pull lg update
提交 svn commit -m "msg" git add → git commit -m → git push lg commit msg
查看状态 svn status git status lg status
查看历史 svn log git log lg log
撤销修改 svn revert file git checkout -- file lg revert file
添加文件 svn add file git add file lg add file
删除文件 svn delete file git rm file lg delete file
切换分支 svn switch URL git checkout branch lg switch branch
