# 2026-07-08 刷题应用优化

## 修复关键Bug
- **数据丢失缺陷（严重）**：`state.bank` 原来既是主题库又是刷题集，重做错题/模拟考试/收藏刷题/重做单题会覆盖主库并 saveBank()。引入 `state.quizBank` + `getQuizList()`，主库 `state.bank` 永不被子集覆盖。所有子集创建函数改为设置 quizBank 而非修改 bank。
- **死代码→实功能**：`updateTopProgress()`/`setConnBadge()` 引用了不存在的 DOM → 在 index.html 新增顶栏细进度条 + 连接状态点，style.css 补充样式，函数接到真实节点。
- `_doSaveResults()` 落盘前剥离 `_undo` 临时字段。
- `pruneSyntheticState()` 清理合成分组（`__` 前缀）避免泄漏到上传视图。
- `switchView('upload')` 清空 quizBank + 重置 currentGroup + 清理合成状态。

## 性能优化
- 侧栏题目列表：从每次切题全量重建 `renderSideGrid()` 改为进入刷题时构建一次 `buildSideGrid()`，切题仅 `updateSideCurrent()` + `updateSideCell()` 增量更新。维护 `_sideStat` 计数变量去掉 O(n) querySelectorAll。
- quiz 函数统一用 `getQuizList()` 减少重复调用。

## 界面与交互打磨
- 顶栏进度条 + 连接状态点（进度随作答实时增长）。
- 模态框焦点管理：`modalFocusIn/modalFocusOut` + 全局 Tab 焦点陷阱 + Esc 关闭（覆盖 quiz 视图之外场景）。
- nav/button 补 `aria-label`。

## 关键改动文件
- `js/api.js`: state.quizBank, getQuizList(), updateTopProgress/setConnBadge 接线, _undo 剥离
- `js/app.js`: quizBank 替代 state.bank 覆盖, buildSideGrid/updateSideCurrent, pruneSyntheticState, modalFocusIn/Out, 侧栏增量
- `index.html`: 进度条/连接点 DOM, aria-label
- `style.css`: 进度条/连接点样式
