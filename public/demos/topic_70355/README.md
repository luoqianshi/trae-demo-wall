# 人员身份卡及工作牌管理系统

这是一个可直接在本机启动演示的 Java Web 项目，用于施工现场或项目部人员信息管理、二维码工作牌生成、手机扫码身份卡查看和本地基础人脸核验。

## 启动方式

环境要求：Java 8。

```bat
scripts\build.bat
scripts\start.bat
```

启动后访问：

- 登录页：http://localhost:8080/login
- 人员列表：http://localhost:8080/persons

## 默认账号

- 管理员：admin / admin123
- 内业员：neiye / neiye123

## 本地数据位置

- 人员数据库：`data/persons.db`
- 账号数据库：`data/accounts.db`
- 上传图片目录：`uploads/`
- 上传图片访问 URL：`http://localhost:8080/uploads/{相对路径}`

## 已实现功能

- 登录、退出、后台访问拦截。
- 管理员管理全部人员；内业员只管理自己录入的人员。
- 人员新增、编辑、删除、搜索、工区筛选、岗位筛选、排序。
- 前后端双重校验：姓名、年龄、岗位长度、安全考试成绩、技术职称专业、必传人员照片和保险图片。
- 人员照片最大 20MB，其他证件图片单张最大 5MB，并校验图片类型。
- 保险图片最多 20 张，执业资格动态新增/删除，最多 5 项，每项 1 到 3 张证书图片。
- 保险和执业资格有效期预警：不足 30 天“即将到期”，已过期“已过期”。
- 单人二维码工作牌 PNG 下载，批量二维码 ZIP 下载。
- 手机扫码公开身份卡页无需登录，支持图片点击放大。
- 微信兼容拍照识别：点击头像或“微信拍照识别”会调起拍照上传。
- 人脸核验接口 `/api/face/verify` 返回 `success`、`matched`、`score`、`threshold`、`message`。
- 每年 1 月 1 日自动年龄加 1，使用本地文件标记避免重复执行。

说明：二维码图片由后端绘制为带文字的 PNG，底部包含“姓名 + 岗位”和“公司”。人脸核验采用本地基础图像特征算法，不依赖云服务。
