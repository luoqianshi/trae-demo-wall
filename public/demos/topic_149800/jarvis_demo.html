完整对话流程的 11 步数据流管道。在仪表盘中发送消息时，此处将实时高亮当前执行步骤。

Wake Word Detection
OpenWakeWord ONNX 离线检测，每帧 80ms，2s 确认窗口内需 2 次检测
wake_word/detector.py
2
Wake Feedback
880Hz + 1320Hz 双音正弦波反馈，GUI 触发白色爆闪 + 双层波纹扩散
Web Audio API
3
Background Music + Greeting
后台线程启动音乐循环播放，TTS 播报 "At your service, sir."
audio/music.py + tts
4
VAD Recording
PyAudio 16kHz 录音 + numpy RMS 能量 VAD，静音 1.5s 停止，最长 15s
audio/recorder.py
5
ASR Recognition
火山引擎豆包语音大模型，WAV base64 编码 -> submit -> 轮询 query
asr/volcengine_asr.py
6
Stop Music Check
检测"停止音乐/stop music"关键词，命中则结束会话
agent/runtime.py
7
Skill Routing + Security
关键词匹配技能 -> SecurityGuard 校验操作类别 (QUERY/NOTIFICATION/CONTROL/DANGEROUS)
agent/skills.py + utils/security.py
8
LLM Streaming Generation
DeepSeek stream=True，逐 token yield，6 字符增量推送 GUI 打字机效果，首字 ~500ms
llm/client.py
9
Bilingual Parse + Honorific
正则解析 [中]/[英] 标记拆分双语，中文补全"先生"，英文补全"sir"
agent/runtime.py
10
TTS Streaming + Playback
WebSocket 双向流式 TTS（首音 ~300ms），后台收 chunk 入 queue，主线程 play_stream 实时播放
tts/tts_ws_client.py + audio/player.py
11
Loop / End Session
TTS 完成 -> 回到步骤 4 继续录音。用户说"停止音乐"或手势 FIST -> 结束会话 -> 回 IDLE
agent/runtime.py
