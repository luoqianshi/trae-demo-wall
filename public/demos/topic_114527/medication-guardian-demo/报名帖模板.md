# 【报名】用药安全卫士 - 社会公益·智慧助老

## 项目名称
用药安全卫士

## 参赛赛道
社会公益 - 智慧助老

## 项目简介
一款专为老年人设计的智能用药辅助应用，通过AI技术帮助老人轻松、安全地管理日常用药。采用大字体、高对比度、语音交互等老年人友好设计，结合智能硬件实现健康监测与跌倒保护，让老人用药更安心，让子女远程更放心。

---

## 已实现功能清单

### 一、用药管理模块

#### 1. 📷 拍照识药
- 支持拍摄药品包装或说明书识别
- AI自动解析药品信息
- 显示药品名称、品牌、用法用量
- 自动识别药物相互作用风险

#### 2. 🔊 语音播报
- 一键语音播报用药指导
- 语速适中，适合老年人听取
- 大字显示+语音双重呈现

#### 3. ⏰ 服药提醒
- 智能设置服药闹钟
- 显示待服用/已服用状态
- **与库存联动**：确认服药后自动扣减库存

#### 4. 💊 药品库存管理
- 记录每种药品剩余数量
- 库存不足自动预警（黄色/红色提示）
- 一键通知家人购买药品
- 与服药提醒实时同步

#### 5. ⚠️ 安全预警
- 自动检测药物相互作用（如阿司匹林+布洛芬）
- 显示禁忌症和注意事项
- 药品过期提醒

---

### 二、健康监测模块

#### 6. ❤️ 健康数据监测
- 连接智能手环、血压计、血糖仪
- 实时显示血压、心率、血糖、步数
- 近7天趋势图表展示
- 异常数据红色高亮预警

#### 7. 🛡️ 跌倒检测保护
- 智能手环实时监测
- 检测到跌倒自动弹窗确认
- 30秒倒计时后自动通知紧急联系人
- 支持手动取消（防止误报）
- 一键测试功能演示

#### 8. 🏥 复诊/体检提醒
- 记录医院预约信息
- 显示日期、医院、医生
- 提前1天/3天提醒
- 一键导航到医院

---

### 三、安全与沟通模块

#### 9. 🆘 紧急求助
- 右上角醒目红色按钮
- 一键呼叫紧急联系人
- 大字体确认弹窗

#### 10. 🎤 语音助手
- 右下角绿色语音按钮
- 支持"识别药品"、"查看健康数据"等语音命令
- 语音反馈操作结果

#### 11. 👁️ 远程监控（子女端）
- 查看父母今日健康数据
- 查看父母用药情况（已服/待服）
- 查看库存预警信息
- 查看今日活动记录时间线
- 一键视频通话
- 远程发送服药提醒

---

### 四、设置与个性化

#### 12. 🔤 字体大小调节
- 三档选择：标准、大、特大
- 实时预览效果
- 自动保存偏好设置

#### 13. ⚙️ 通知设置
- 服药提醒开关
- 健康预警通知开关
- 库存不足提醒开关
- 复诊提醒开关

#### 14. 🛡️ 安全设置
- 跌倒检测开关
- 位置共享开关

## 老年人友好设计亮点

| 设计要点 | 实现方式 |
|----------|----------|
| 大字体 | 基础字号18px，标题24-40px |
| 高对比度 | 深色文字+浅色背景，边框3px |
| 大按钮 | 最小点击区域60px，大按钮72px |
| 语音交互 | 语音播报+语音助手双重入口 |
| 状态反馈 | Toast提示+语音播报确认 |
| 库存联动 | 确认服药自动扣减库存 |
| 异常预警 | 黄色/红色醒目标识 |

## 目标用户
- 60岁以上需要长期服药的老年人
- 关注父母健康的子女
- 独居老人及其家属

## 解决的问题
- 老人看不清药品说明书 → 大字显示+语音播报
- 多种药物容易漏服或错服 → 智能提醒+库存联动
- 不理解专业医嘱 → AI解析通俗化说明
- 独居老人缺乏用药指导 → 远程监控+紧急求助
- 老人跌倒无人知晓 → 智能检测+自动报警

## 技术方案
- TRAE IDE 开发
- 纯前端HTML/CSS/JavaScript实现
- Web Speech API 语音合成
- LocalStorage 本地数据存储
- 智能硬件蓝牙连接（模拟）
