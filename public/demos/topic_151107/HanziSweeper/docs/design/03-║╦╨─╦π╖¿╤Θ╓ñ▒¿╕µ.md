## 三、棋盘生成算法

### 3.1 算法流程

```
1. 从数据库选取 N 个汉字（组件全局唯一）
2. 将 2N 个组件随机放置在棋盘上 → Radical 格（≈ 地雷）
3. 其余格子为 Number 格，数字 = 周围 8 格中 Radical 格的数量
4. 检查是否有至少一个 0 格（保证玩家有起点）
5. 用求解器验证可解性
6. 如果不可解 → 重新生成（最多 50 次）
7. 仍然失败 → 降低 Radical 数量重试
8. 最终保底 → 生成角落布局的简单棋盘
```

### 3.2 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Radical 占比上限 | 30% | 留足推理空间 |
| 最大生成尝试 | 50 次 | 保证找到可解棋盘 |
| 降级策略 | 减少 1 个汉字 | 降低难度重试 |
| 保底策略 | 角落布局 | 确保一定 playable |

### 3.3 单盘测试（8×8，5 个汉字）

```
棋盘布局（R = Radical，数字 = Number 格，. = 0 格）：

      0  1  2  3  4  5  6  7
    ------------------------
 0 |  1  2  R  2  R  2  1  .
 1 |  1  R  2  2  2  R  1  .
 2 |  2  2  2  .  1  1  1  .
 3 |  2  R  1  1  1  1  .  .
 4 |  R  2  2  2  R  1  .  .
 5 |  1  1  2  R  3  1  .  .
 6 |  .  .  2  R  2  .  1  1
 7 |  .  .  1  1  1  .  1  R

Radical 格：10
Number 格：54
0 格数量：16（充足的起点）
```

### 3.4 结论

棋盘生成算法工作正常，布局合理，0 格充足。

## 四、求解器验证

### 4.1 求解器设计

模拟真实扫雷游戏过程，使用三层推理规则：

| 规则 | 说明 | 类型 |
|------|------|------|
| **规则 1** | 数字 N = 周围未知格数 → 全是 Radical | 基础推理 |
| **规则 2** | 数字 N 已满足 → 周围全是安全的 | 基础推理 |
| **规则 3** | 子集约束：A ⊂ B 且 remaining 相同 → B-A 安全 | 高级推理 |

### 4.2 求解流程

```
1. 找到一个 0 格 → 点击翻开（自动展开相连的 0 格区域）
2. 基于已翻开的 Number 格，应用规则 1 和 2
3. 如果无进展，应用规则 3（子集约束）
4. 新确认的安全格 → 翻开并扩展
5. 重复直到所有 Radical 被确定或无法继续
```

### 4.3 单盘求解结果

| 指标 | 数值 |
|------|------|
| 可解 | true |
| 迭代次数 | 3 |
| 找到 Radical | 10/10 |
| 确认安全格 | 39 |

### 4.4 结论

求解器能在 3-8 次迭代内完成推理，效率极高。

## 七、算法架构

### 7.1 文件结构

```
src/
├── core/
│   ├── types.ts              # 类型定义（Cell, Board, CellType, CellState）
│   ├── board-generator.ts    # 棋盘生成算法（含重试和保底）
│   └── solver.ts             # 求解器（三层推理规则）
├── data/
│   └── hanzi-db.ts           # 汉字拆解数据库（38 个汉字）
└── validate.ts               # 验证脚本
```

### 7.2 核心类型

```typescript
// 格子类型
enum CellType { Radical, Number }

// 格子状态
enum CellState { Hidden, Revealed, Flagged }

// 格子
interface Cell {
  type: CellType;
  state: CellState;
  number: number;         // Number 格：周围 Radical 数量
  radicalIndex: number;   // Radical 格：组件索引
}

// 棋盘
interface Board {
  width: number;
  height: number;
  grid: Cell[][];
  totalRadicals: number;
  characters: CharDecomp[];  // 本局使用的汉字拆解
}
```

### 7.3 关键算法

**棋盘生成**：随机放置 → 计算数字 → 验证可解性 → 重试/降级/保底

**求解器**：找 0 格起点 → 展开 → 规则 1&2 推理 → 规则 3 子集约束 → 循环

**配对匹配**：遍历数据库，查找 left+right 或 right+left 匹配
