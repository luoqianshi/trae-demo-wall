# 汉字扫雷 — 核心玩法设计文档

> 版本：v1.0 | 日期：2026-06-19

---

## 一、游戏概述

**汉字扫雷**是一款将经典扫雷的数字推理与汉字偏旁部首组字相结合的创意益智游戏。玩家在棋盘上通过数字线索推理定位隐藏的部首，然后组合部首构成汉字，体验推理与组字的双重乐趣。

**核心体验**：烧脑推理 + 组字成就感 + 连锁消除爽感

---

## 二、核心玩法

### 2.1 棋盘构成

棋盘由若干格子组成，每个格子下方隐藏以下内容之一：

| 格子类型 | 说明 |
|---------|------|
| **部首格** | 藏有一个偏旁部首（氵、木、口、扌、讠...） |
| **数字格** | 显示一个数字，提供周围信息 |
| **空格** | 什么都没有，安全但无信息 |

### 2.2 游戏流程

游戏分为两个阶段：

#### 阶段一：推理定位（扫雷逻辑）

1. 玩家点击一个格子
2. 如果是**数字格** → 显示数字，开始推理
3. 如果是**空格** → 安全翻开，无信息
4. 如果是**部首格** → 触发"爆炸"，扣除生命值（除非已用 flag 标记）

**推理目标**：通过数字线索，推断哪些格子下面藏着部首，用 flag 标记。

**标记即揭示**：flag 标记后，该格自动翻开，显示部首内容。标记错误（实际是空格）则扣一条命。

#### 阶段二：组字消除（汉字逻辑）

所有部首格被标记翻开后，进入组字阶段：

1. 棋盘上所有标记的部首**全局可见**
2. 玩家**任意选择两个部首**尝试组字（不要求相邻）
3. 组合成功 → 部首消除，显示组成的汉字，获得分数
4. 组合失败 → 扣分，不扣血
5. 消除所有部首（或达到通关条件） → 通关

### 2.3 数字格的定义

每个数字格有一个隐藏的**关联部首**（玩家不可见），数字表示：

> **数字 N = 周围 8 格中，能与"关联部首"配对成字的部首格数量**

**示例**：
```
数字格显示 2，关联部首是「氵」
→ 周围 8 格中，恰好有 2 个部首是「可」「工」「去」等能与氵配对的
```

玩家通过多个数字格的交叉推理，逐步锁定每个部首格的位置。

### 2.4 通关与失败

| 条件 | 说明 |
|------|------|
| **通关** | 满足关卡目标（消除所有部首 / 达到目标分数 / 组出指定汉字） |
| **失败** | 生命值归零 |

## 三、动态系统

### 3.1 动态数字系统

数字不是固定的，会随棋盘状态变化：

- 每次组字消除后，周围数字重新计算
- 消除了一个部首 → 相关数字 -1
- 新增了部首（掉落） → 相关数字 +1
- 玩家可以根据数字变化，推理出更多信息

### 3.2 连锁消除系统

组字后触发连锁检测：

1. 玩家主动组字消除后
2. 检查棋盘上剩余部首，如果有两个相邻部首也能组字 → 自动消除
3. 连锁继续向四周扩散
4. 连锁数越多，分数倍率越高

| 连锁数 | 分数倍率 |
|--------|---------|
| 2 连锁 | ×1.5 |
| 3 连锁 | ×2 |
| 4 连锁 | ×3 |
| 5+ 连锁 | ×4 |

### 3.3 部首进化系统

3 个相同部首相邻 → 自动进化为高级部首：

```
基础部首 → 进阶部首 → 高级部首
  氵    →    水    →    淼
  木    →    林    →    森
  人    →    从    →    众
```

进化后的部首功能更强，可以和更多字组合。

### 3.4 汉字合成树

不只是两个部首组字，还可以多步合成：

```
基础合成：氵 + 可 = 河
进阶合成：河 + 水 = 河流（词语）
高级合成：日 + 月 = 明 → 明 + 日 = 晶（特殊进化）
```

## 四、资源系统

### 4.1 生命值（血条）

| 状态 | 效果 |
|------|------|
| 满血（3 格） | 可以犯 3 次错误 |
| 半血（1-2 格） | 容错减少 |
| 濒死（0 格） | 游戏结束 |

**血量变化**：

| 行为 | 血量变化 |
|------|---------|
| 踩到部首格（未标记） | -1 |
| 标记错误（flag 标到空格） | -1 |
| 成功组字 | +0.5（少量回复） |
| 连锁消除 | +0.5 |
| 使用血瓶道具 | +1 |

### 4.2 能量系统

组字获得能量，能量用于释放技能：

| 行为 | 能量变化 |
|------|---------|
| 成功组字 | +20 |
| 连锁消除 | +10/次 |
| 通关奖励 | +50 |

### 4.3 技能系统

| 技能 | 能量消耗 | 效果 |
|------|---------|------|
| **透视** | 20 | 显示一个未翻开格子的内容 |
| **爆破** | 30 | 直接消除一个部首格（不组字） |
| **替换** | 40 | 把一个部首变成另一个可配对的部首 |
| **时间暂停** | 50 | 限时模式暂停 30 秒 |
| **部首召唤** | 60 | 从卡组召唤一个指定部首到棋盘 |
| **棋盘重置** | 80 | 重新生成棋盘（保留已组字） |
| **连锁引爆** | 100 | 强制触发全棋盘连锁检测 |

## 五、卡牌系统

### 5.1 卡组构建

每局游戏前，玩家选择 3 张卡牌带入：

| 卡牌类型 | 示例 | 效果 |
|---------|------|------|
| **部首卡** | 氵×3 | 开局自带 3 个氵 |
| **技能卡** | 透视×2 | 自带 2 次透视技能 |
| **道具卡** | 血瓶×1 | 自带 1 个血瓶 |
| **特殊卡** | 连锁大师 | 连锁消除分数×2 |
| **诅咒卡** | 迷雾 | 棋盘有 3 格永远看不见（高分补偿） |

### 5.2 卡牌获取

- 通关奖励
- 每日挑战
- 成就解锁
- 商店购买

## 六、难度体系

### 6.1 基础难度

| 难度 | 棋盘大小 | 部首数量 | 部首占比 | 特殊机制 |
|------|---------|---------|---------|---------|
| **入门** | 8×8 | 8-10 | 15% | 简单配对（氵+可=河） |
| **进阶** | 10×10 | 15-20 | 20% | 多义部首，需要推理 |
| **专家** | 12×12 | 25-35 | 25% | 形近部首干扰（己/已/巳） |
| **大师** | 15×15 | 50+ | 30% | 部首进化 + 词语连锁 |

### 6.2 多阶段制

一局游戏分 3 个阶段，每阶段棋盘不同：

```
阶段 1：初级部首（氵、木、口、扌）
  ↓ 完成后
阶段 2：中级部首（讠、饣、纟、忄）+ 新部首掉落
  ↓ 完成后
阶段 3：高级部首 + 特殊格子（通配、锁定）
```

每阶段完成后保留分数和技能点，棋盘重新生成。

**一局游戏时长**：10-15 分钟

## 七、关卡目标

| 关卡类型 | 目标 | 说明 |
|---------|------|------|
| **消除关** | 消除所有部首 | 基础关卡 |
| **收集关** | 组出指定汉字 | 如：必须组出「江河湖海」 |
| **分数关** | 达到目标分数 | 通过连锁和技能刷分 |
| **限时关** | 时间内完成 | 增加紧张感 |
| **步数关** | 限定步数内完成 | 考验策略 |
| **生存关** | 坚持尽可能久 | 部首不断掉落 |
| **Boss 关** | 击败 Boss | Boss 会干扰棋盘 |

## 十二、保底机制（逻辑自洽）

### 12.1 棋盘生成保证

```
1. 选择目标汉字集合（如：河、相、打、明、林）
2. 拆解为部首对（氵+可、木+目、扌+丁、日+月、木+木）
3. 收集所有部首，在棋盘上放置
4. 计算数字格的值
5. 用求解器验证可解性
6. 如果不可解 → 重新生成
```

### 12.2 三层保底

| 层级 | 机制 | 说明 |
|------|------|------|
| **第一层** | 棋盘生成算法 | 保证可解性和可配对性 |
| **第二层** | 技能保底 | 卡关时使用透视/替换/召唤等技能 |
| **第三层** | 灵活通关 | 不要求 100% 消除，进度关 80% 即可 |

### 12.3 容错设计

- 标记错误扣血，不立即失败
- 组字失败扣分，不扣血
- 能量积累保证玩家有足够技能使用
- 血瓶道具可以恢复生命

## 十三、技术要点

| 技术点 | 说明 |
|--------|------|
| **汉字数据库** | 完整的「部首→可配对部首→汉字」映射表 |
| **棋盘生成算法** | 先放部首对，再填数字，用求解器验证可解性 |
| **求解器** | 验证棋盘是否可通过逻辑推理唯一确定 |
| **前端框架** | 推荐 Web（React/Vue）或小程序（Taro） |
| **跨平台** | Taro 支持微信/支付宝/H5/React Native 多端 |
