### 一、核心概念

这是一款**扫雷式汉字拼合 + 多层地牢探险游戏**。你将穿梭于多个地牢房间，棋盘上隐藏着各类偏旁部首，需要用扫雷的数字推理法定位它们，承受笔画伤害将其收集，再拼成完整汉字来解锁新区域、收集神器碎片，最终回主城锻造神器通关。

**一句话：数字不是告诉你"雷在哪"，而是告诉你"周围有多少笔画"。**

------

### 二、棋盘与格子

棋盘为矩形网格，每格翻开后都会显示一个数字，棋盘由两类格子构成：

| 格子类型 | 翻开效果 | 扣血 |
| :------- | :------------------------------------------ | :----------------------- |
| **数字格**（痕迹格） | 显示数字（周围 8 格部首笔画总和） | 不扣血 |
| **部首格**（字元格） | 显示偏旁部首 + 其笔画数 + 周围数字 | 扣除该部首笔画数的血量 |

- 部首笔画范围 **1-8 画**
- 数字 = 周围 8 格所有部首格的笔画总和
- 所有数字基于开局时棋盘静态生成，不随部首被收集而改变
- 数字为 0 的格子翻开时，自动递归翻开相邻格（安全区）

**格子状态**（共 6 种）：

| 状态 | 说明 |
| :--- | :--- |
| hidden | 隐藏未翻开 |
| revealed | 已翻开（数字格） |
| flagged | 旗帜标记（探测/技能标记） |
| peeked | 透视状态（临时显示 3 秒） |
| matched | 合成成功（左格显示完整汉字，绿色高亮） |
| consumed | 已消耗（右格虚线显示合成字） |

### 四、房间系统

共 7 个房间，初始只解锁主城，通过合成入口字解锁其他房间：

| 房间 | 图标 | 棋盘 | 字数 | 特性 | 入口字 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 主城 | 🏰 | 6×6 | 4 | 神器锻造地 | — |
| 外郭 | 🏯 | 6×6 | 4 | 碎片房 1 | 郭（享+阝） |
| 宫殿 | 🏛️ | 7×7 | 5 | 碎片房 2 + Boss | 闯（门+马） |
| 港口 | ⚓ | 6×6 | 4 | 碎片房 3 | 海（氵+每） |
| 市集 | 🏪 | 6×6 | 4 | 词条房 | 活（氵+舌） |
| 密林 | 🌲 | 7×7 | 5 | 词条房 | 林（木+木） |
| 矿洞 | ⛏️ | 8×8 | 6 | 分数 +50% | 岩（山+石） |

- 主城合成 6 个入口字（郭/闯/海/活/林/岩）分别解锁对应房间
- 跨房间字去重：已用字不会在其他房间重复出现（入口字除外）
- 生命值、技能栏、分数等状态跨房间保持

### 六、合成系统

**触发方式**：点击棋盘上已翻开部首格，或点击侧边栏背包中的部首。选满 2 个后 **400ms 自动合成**，也可点击"合成汉字"按钮立即合成。

**匹配规则**：先查 HANZI_DB（294 字），匹配失败再回退到拆字库（3265 个部首组合）。

**分数计算**：

```
总分 = floor((基础分 + 连击加成) × 倍率 × 房间加成)
```

| 项目 | 说明 |
| :--- | :--- |
| 基础分 | 合成字笔画数 × 10 |
| 连击加成 | 连击 ≥3 时加 50% 基础分 |
| 倍率 | xpBoost 词条激活后 1.2 或 1.3 倍 |
| 房间加成 | 矿洞房间 ×1.5，其他 ×1.0 |

**合成后效果**：
- left 格 `matched` 状态，显示完整汉字（绿色高亮发光）
- right 格 `consumed` 状态，虚线显示同一字
- 从背包移除两个部首
- 检测入口字 → 解锁房间
- 检测神器字 → 收集碎片
- 检测词条 → 提示"点击该字收集技能"

### 七、五行被动技能

按汉字部首自动判断五行属性（钅/金=金，木=木，氵/水=水，火/灬=火，土=土），合成对应字后永久激活被动技能，占用技能栏位。**仅在翻开数字格时触发**：

| 五行 | 触发条件 | 效果 | 翻格数 |
| :--- | :--- | :--- | :--- |
| 金 | 拥有金词条 | 十字翻开（上下左右数字格） | 最多 4 |
| 木 | 拥有木词条 | 向棋盘中心方向连续翻 | 3 |
| 水 | 拥有水 + 火词条 | 周围一圈全翻 | 最多 8 |
| 火 | 拥有火词条 | 激活水的蔓延（本身无独立效果） | 0 |
| 土 | 拥有土词条 | 随机翻开隐藏数字格 | 3 |

### 八、词条系统

- **3 个技能槽位**，五行被动与一次技能共享
- 栏满时新技能进入 `pendingTrait` 待替换状态，点击空槽放入或点击占用槽替换
- 合成含技能的汉字后，点击棋盘上的合成字收集技能

**15 种一次技能**：

| 类型 | 技能 | 说明 |
| :--- | :--- | :--- |
| 战斗 | heal | 回复 1-2 点生命 |
| 战斗 | fullHeal | 回复所有生命 |
| 战斗 | shield | 下次翻部首格不扣血 |
| 战斗 | reduceStroke | 下次翻部首格伤害减半 |
| 战斗 | weakenAll | 所有未翻开部首格笔画 -1 |
| 战斗 | eliminateRadical | 消除目标部首格 → 变数字格（瞄准） |
| 探索 | revealRadicals | 标记 3 个未翻开部首格 |
| 探索 | peekArea | 透视周围 8 格 3 秒（瞄准） |
| 探索 | energy | 翻开 3 个随机数字格 |
| 探索 | revealRow | 翻开一整行数字格（瞄准） |
| 探索 | revealArea | 显示周围 8 格中部首位置（瞄准） |
| 探索 | resetCell | 重置已翻数字格为隐藏（瞄准） |
| 探索 | spread | 接下来 3 次翻格附带蔓延效果 |
| 探索 | peekStart | 立即翻开 3 个随机隐藏格（含部首格） |
| 成长 | xpBoost | 本局分数 +20%/30% |

**瞄准模式**：5 个技能（peekArea/revealArea/revealRow/resetCell/eliminateRadical）激活后需点击棋盘选择目标格子施放。

**稀有度**：common（普通）/ rare（稀有）/ epic（史诗）。

### 九、右键探测与 Chord

**右键探测**（隐藏格）：
- 猜对（部首格）→ 免费收集 + 显示部首内容 + 提示"发现部首！免费标记"
- 猜错（数字格）→ 扣 2 血 + 翻开 + 提示"不是部首，消耗 2 血"
- HP 不足 → 无法探测，提示"生命不足"

**Chord 操作**（已翻开数字格）：
- 右键已翻开数字格，若周围已标记格子的笔画数总和等于该数字 → 自动翻开周围所有未标记格子
- 用于快速展开安全区域

### 十、策略核心

- **规划路线**：优先碎片房（外郭/宫殿/港口）收集神器碎片，还是先去词条房（市集/密林）增强技能？
- **控血节奏**：平衡翻部首扣血与合成回血，避免血量危机时无法翻格
- **五行搭配**：收集金木水火土被动技能增强翻格效率，水+火组合可翻开 8 格
- **词条组合**：3 槽位搭配战斗/探索技能应对不同局面，瞄准技能可解死局
- **矿洞刷分**：分数 ×1.5 加成，适合冲分但棋盘大（8×8）风险高
- **数字是成本预览**：看到数字"8"，意味着周围取件的总成本是 8 笔伤害，需判断是否值得
- **合成即自救**：血量危机时，优先合成容易的字来回 3 点血续命

------

### 十一、一局游戏的体验弧线

> 开局（主城）：合成入口字解锁房间，获得初始技能 →
> 探索：选择路线进入碎片房或词条房，用数字推理定位部首，承受伤害积累部件 →
> 成长：合成汉字回血，收集五行被动和一次技能词条，搭配技能组合 →
> 转折：集齐 3 片碎片，返回主城 →
> 终局：锻造神器，通关结算，在"再翻一格就死"的紧张中完成冒险
