## 详细测试记录

### 测试1: 五行遮蔽修复（最关键）

**修复内容**: `getCharTrait()` 优先返回 HANZI_DB 中显式定义的一次技能，避免五行被动遮蔽。

**测试方法**:
- 合成「河」(氵+可) -> 调用 `getCharTrait('河')` 验证返回 `{effect: 'spread', name: '蔓延'}`
- 合成「休」(亻+木) -> 调用 `getCharTrait('休')` 验证返回 `{effect: 'heal', name: '歇息', value: 2}`

**结果**:
```
河 -> { name: '蔓延', type: 'explore', effect: 'spread', desc: '接下来3次翻格附带蔓延效果', rarity: 'rare' }
休 -> { name: '歇息', type: 'combat', effect: 'heal', desc: '回复2点生命', rarity: 'common', value: 2 }
```

**结论**: PASS - 五行被动不再遮蔽 HANZI_DB 中定义的一次技能。

### 测试10: 一次性词条不可重复收集

**结果**:

- 状态栏显示: 词条信息（非待放置状态）

**代码验证**: [game.js](file:///e:/Development/AI/Workspace/HanziSweeper/stroke-v2/js/game.js) 第 931-935 行，放置词条时同步标记 `sourceCell.traitCollected` 和 `sourceCell.pairCell.traitCollected`。第 308-313 行，点击已收集格仅显示信息。

**结论**: PASS - 词条收集后双格标记，不可重复收集。

## 控制台错误

| 类型 | 内容 | 影响 |
|------|------|------|
| 404 | Failed to load resource | 低 - 可能是 favicon 等静态资源 |
| TypeError | `Cannot set properties of null (setting 'textContent')` at `js/strokes.js:347` (updateTimer) | 中 - 旧版 `StrokeSweeperGame` 的定时器在 v2 页面找不到 DOM 元素 |

**分析**: 控制台错误来自旧版 `js/strokes.js` 中的 `StrokeSweeperGame.updateTimer()` 方法，尝试设置 `strokeTimer` 等 DOM 元素，但这些元素在 v2 HTML 中不存在（v2 使用 `dungeonTimer` 等 ID）。这是旧版游戏实例的定时器未被正确清理导致的，**不影响 v2 游戏功能**。

**建议**: 在 v2 页面中避免加载旧版 `js/strokes.js`，或在旧版 `StrokeSweeperGame` 中添加 DOM 元素存在性检查。
