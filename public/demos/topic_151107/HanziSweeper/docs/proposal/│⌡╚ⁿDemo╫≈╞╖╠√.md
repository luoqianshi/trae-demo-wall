# 【生活娱乐赛道】汉字扫雷——当经典扫雷遇上汉字部首

---

## 一、Demo 简介

**是什么**：一个纯前端的网页游戏（HTML + CSS + JavaScript，零依赖，打开即玩），将经典扫雷玩法与汉字部首学习深度融合。

**面向谁**：
- 中文学习者（外国学习者、海外华人子女）
- 小学生及识字阶段的儿童
- 喜欢益智类游戏的玩家

**主要功能**（3 种游戏模式）：

### 1. 经典模式 — 传统扫雷 + 组字

- 棋盘上隐藏着部首而非地雷，数字提示周围部首的笔画总和
- 推理定位部首，收集后两两组合成完整汉字
- 3 种难度：简单(6×6) / 中等(8×8) / 困难(10×10)
- 右键探测：猜对部首格免费收集，猜错数字格消耗能量
- Chord 操作：右键数字格周围旗帜数=数字时翻开邻居
- 连击奖励阶梯 + 能量技能（透视/提示/回血/连锁/消除）

> **配图位置**：[经典模式棋盘截图]

### 2. 无尽模式 — 波次递增 Roguelike

- 每波字数递增（上限 12 字），波次间选 Buff 强化
- 11 个 Buff 按稀有度分布（普通/稀有/史诗/传说）
- 每 3 波首选项强制为史诗/传说品质
- 连击阶梯奖励：3 连闪白+10 分 → 5 连翻 2 格+30 分 → 8 连高亮+50 分 → 10 连自动完成

> **配图位置**：[无尽模式 Buff 选择截图]

### 3. 笔划模式（地牢探险）— 多层地牢 + RPG 成长

- **7 个房间**：主城 / 外郭 / 宫殿 / 港口 / 市集 / 密林 / 矿洞，合成入口字解锁新区域
- **HP 血量系统**：翻部首格扣笔画数（1-8），右键探测猜错扣 2 血，合成回 3 血
- **神器碎片收集**：3 片碎片散落地牢，集齐回主城锻造通关
- **五行被动技能**：金·十字(4格) / 木·延伸(3格) / 水·蔓延(8格,需火激活) / 火·激活 / 土·落石(3格)
- **15 种一次技能词条** + 3 槽位技能栏 + 瞄准模式
- Canvas 粒子特效 + Web Audio API 音效系统

> **配图位置**：[笔划模式地牢探险截图]

**数据规模**：294 个汉字（含拼音、释义、难度分级），3265 个部首组合的拆字库

## 二、Demo 创作思路

### 灵感来源

扫雷的核心玩法是"根据数字推理地雷位置"，而汉字的结构恰好可以拆解为部首组合。两者结合——把地雷换成部首，把推理变成组字，就能创造一种全新的"边玩边学"体验。

**一句话：数字不是告诉你"雷在哪"，而是告诉你"周围有多少笔画"。**

### 想解决的问题

- 汉字部首学习枯燥乏味，尤其是对外国学习者和小学生，反复抄写效率低、兴趣差
- 现有汉字学习工具大多是"闪卡+测验"模式，缺乏趣味性
- 扫雷类游戏没有语言版本，无法承载教育内容
- 学习者很难直观理解汉字的部首结构和组合规律

### 为什么做这个方向

- **教育游戏化是趋势**，但多数产品只是"加了个游戏外壳"，玩法与学习割裂
- **"文字扫雷"是全新品类**——把扫雷的推理机制和教育内容深度融合，不是简单叠加
- **每次翻格都是一次"成本决策"**：看到数字"8"意味着周围取件总成本是 8 笔伤害，需判断是否值得
- **从单棋盘到多层地牢探险**，用 RPG 成长机制（五行技能、词条系统、神器收集）增强长期吸引力
- 扫雷有上亿用户基础，"文字扫雷"天然具备传播潜力

## 三、Demo 体验地址

项目为纯前端网页游戏，零依赖，打包为 Zip 上传社区。

**体验方式**：

1. 下载附件 Zip 包
2. 解压到任意目录
3. 双击 `standalone.html` 在浏览器中打开即可体验

> `standalone.html` 是单文件打包版（v1.13.3 新增），所有 CSS 和 JavaScript 都内联到一个 HTML 文件中，**无需启动服务器，双击即玩**。
>
> 如需查看模块化源码或进行二次开发，可使用 `npm start` 启动开发服务器（端口 3000）加载 `index.html`。

**附件**：`HanziSweeper.zip`（包含 `standalone.html` 单文件版 + `index.html` + `css/` + `js/` 源码目录）
