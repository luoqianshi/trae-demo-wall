Concept

让每个人
都能讲故事

每个人都有值得记录的故事，
缺的是把它变成画面的能力。

AI 分镜师 是一款基于自然语言处理的创意工具。你只需要用文字描述一个场景——一段情绪、一个画面、一个想法——AI 就会自动分析其中的场景类型、情绪基调和环境特征，匹配专业的分镜模板，生成包含景别、运镜、时长、画面描述、声音设计、拍摄建议和转场方式的完整分镜方案。

不需要懂摄影，不需要会剪辑。从编剧到导演的最后一公里，AI 分镜师 帮你跨越。

Features

三个核心能力

从文本理解到方案生成，从分镜可视化到方案导出， AI 分镜师为创作者提供一站式的影视前期解决方案。

01 / SMART PARSE

智能文本分析

基于关键词识别与场景理解，自动判断场景类型（剧情/对话/动作/广告/Vlog/口播/纪录片）、情绪基调和环境特征。

02 / TEMPLATE MATCH

专业分镜模板

7 种景别（EWS/WS/FS/MS/MCU/CU/ECU）× 9 种运镜方式 × 7 种转场方式，内置 7 套分镜模板库，按场景智能匹配。

03 / VISUAL STORYBOARD

可视化呈现

每个镜头自动生成 SVG 分镜示意图，支持卡片视图、时间轴视图、分镜表三种模式，可打印导出。

Tech & Craft

用技术为创意服务

  • 01

    零依赖纯前端

    仅使用原生 HTML / CSS / JavaScript，无任何外部库或 CDN 依赖。 打开 HTML 文件即可使用，离线可用，单文件 94KB。

  • 02

    规则引擎 + 模板库

    自研文本分析引擎：6 种场景类型 × 7 种情绪模式 × 4 种环境特征， 配合 7 套专业分镜模板（剧情/对话/动作/产品/Vlog/口播/纪录片）。

  • 03

    动态画面描述

    基于原文关键词、情绪、环境的动态画面生成算法， 6 种叙事阶段（建立/人物引入/动作/情绪/发展/结尾）× 3 套备选模板。

  • 04

    SVG 分镜可视化

    针对 7 种景别（EWS/WS/FS/MS/MCU/CU/ECU）独立设计的 SVG 分镜框， 颜色编码 + 景别分布图表 + 时间轴 + 分镜表多视图呈现。
