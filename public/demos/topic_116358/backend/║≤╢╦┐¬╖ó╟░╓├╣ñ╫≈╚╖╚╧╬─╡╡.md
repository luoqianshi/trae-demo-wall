# 驼翁再世 - 后端开发前置工作确认文档（腾讯云开发版）

## 一、项目概述

### 1.1 项目名称
「驼翁再世」AI 植物养护助手

### 1.2 后端定位
基于 FastAPI 的植物健康状态识别后端服务，部署在腾讯云开发（TCB）平台，提供图片上传、AI 推理、养护建议返回等核心功能。

### 1.3 核心价值主张
「养植物，也是在滋养自己」

### 1.4 目标用户
都市白领、家庭主妇、办公室绿植养护者、园艺新手、植物爱好者

---

## 二、后端功能模块

### 2.1 核心功能
| 模块 | 功能描述 | 优先级 |
|------|----------|--------|
| AI 识别接口 | 接收图片，调用 OpenCLIP 推理，返回植物状态 | P0 |
| 养护建议 | 根据识别结果匹配中文养护建议 | P0 |
| 用户养护记录 | 存储用户上传记录和识别结果（TCB云数据库） | P1 |
| 浇水日历 | 管理用户浇水施肥记录（TCB云数据库） | P1 |
| 图片存储 | 用户照片上传至 TCB 云存储 | P1 |

### 2.2 功能流程图
```
用户上传照片 → TCB云存储 → /predict 接口 → OpenCLIP 推理 → 返回识别结果和养护建议 → 保存到TCB云数据库
```

## 四、API 接口设计

### 4.1 接口列表（云函数形式）
| 接口 | 方法 | 描述 |
|------|------|------|
| `/predict` | POST | 上传图片，返回植物状态识别结果 |
| `/records` | GET | 获取用户养护记录列表 |
| `/records` | POST | 保存养护记录 |
| `/records/{id}` | GET | 获取单条养护记录 |
| `/records/{id}` | DELETE | 删除养护记录 |
| `/calendar` | GET | 获取用户浇水日历 |
| `/calendar` | POST | 添加浇水/施肥记录 |
| `/health` | GET | 服务健康检查 |

### 4.2 `/predict` 接口详情

**请求：**
- 方法：POST
- Content-Type: multipart/form-data
- 参数：file (图片文件)

**响应：**
```json
{
    "success": true,
    "prediction": {
        "status": "water_shortage",
        "message": "叶片黄化，疑似缺水",
        "suggestion": "植物可能缺水，请及时补充水分",
        "color": "#FF9800"
    },
    "all_results": [
        {"label": "yellow leaf caused by water shortage", "probability": 0.75}
    ],
    "confidence": 0.75,
    "image_url": "cloud://xxx/xxx.jpg"
}
```

### 4.3 识别状态列表
| 状态代码 | 中文描述 | 颜色 |
|----------|----------|------|
| healthy | 植物状态健康 | #4CAF50 |
| water_shortage | 叶片黄化，疑似缺水 | #FF9800 |
| nutrient_deficiency | 叶片黄化，疑似缺肥 | #FF9800 |
| withered | 叶片枯萎 | #F44336 |
| disease | 叶片出现病斑 | #F44336 |
| curled | 叶片卷曲 | #FFC107 |
| stressed | 植物处于胁迫状态 | #FFC107 |
| normal | 植物生长正常 | #4CAF50 |

## 九、注意事项

1. **模型加载**：OpenCLIP 模型首次加载需要下载约 300MB 权重文件，云函数冷启动可能较慢，建议使用模型持久化或预热机制
2. **推理性能**：CPU 推理约 1-2 秒/张，建议设置云函数超时时间为 30 秒
3. **图片格式**：支持 JPG、PNG 格式，建议图片大小不超过 5MB
4. **云开发配置**：需要在 TCB 控制台配置云函数、云数据库、云存储权限
5. **用户认证**：小程序端通过云开发 SDK 自动获取用户 openid，无需额外登录
6. **网络部署**：使用 TCB 云开发，自动提供 HTTPS 访问能力，无需额外配置域名

---

## 十、风险提示

1. **模型准确率**：零样本模型对细粒度病害识别精度有限，建议后续引入少样本微调
2. **冷启动延迟**：云函数冷启动时加载模型可能导致首次请求较慢，建议优化模型加载策略
3. **依赖兼容性**：TCB 云函数 Python 运行环境版本需与本地开发环境一致（Python 3.10）
4. **存储空间**：用户上传的图片会占用云存储空间，需要注意存储费用和清理策略
