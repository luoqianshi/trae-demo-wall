# 截图目录说明

请在此目录下放置以下截图文件：

| 文件名 | 说明 |
|--------|------|
| home.png | 首页截图 - 小程序启动后的主界面 |
| recognition.png | 食物识别结果页截图 - AI 识别食物后的页面 |
| dice.png | 骰子决策页截图 - 3D 骰子动画效果 |
| poem.png | 诗意生成页截图 - AI 生成的古诗词 |
| tts.png | 语音朗读页截图 - TTS 播放界面 |
| share.png | 分享卡片截图 - 生成的精美分享海报 |

## 截图要求

- 推荐尺寸：750 × 1334 (iPhone 标准分辨率)
- 格式：PNG
- 数量：6 张
- 内容：需清晰展示软件核心功能

## 截图步骤

1. 在微信开发者工具或真机上运行小程序
2. 依次打开各个功能页面
3. 使用系统截图功能截取页面
4. 将截图重命名为上述文件名
5. 放置在本目录下

## 注意事项

- 截图中不要包含敏感信息
- 确保界面清晰完整，无遮挡
- 建议使用深色背景或彩色背景展示
- 所有截图保持一致的分辨率和风格
