## 1. Demo 简介

### 是什么

晴雨同学是一个面向中学生的 **AI 情绪天气记录小程序**（单页 HTML 可离线运行）。学生输入一句话描述今天的心情，AI 会把它转化为一种"情绪天气"（晴天/多云/小雨/暴风雨等），同时给出温柔的建议卡和今天可以完成的一个小任务。

### 面向谁

- **核心用户：** 初高中学生（13-18 岁）
- **场景：** 课间、晚自习前、放学路上——任何"心里有点堵但不知道怎么说"的时刻
- **使用门槛：** 不需要注册，不需要写长日记，一句话就够了

### 主要功能

| 功能 | 说明 |
|---|---|
| **情绪天气生成** | 输入一句话，AI 自动匹配天气类型、给出解读和建议 |
| **温柔建议卡** | 根据不同天气，提供当天可操作的小方法（如"深呼吸 3 次""写下一件今天完成的小事"） |
| **今日小任务** | 每天一个简单任务，完成后获得"晴能量"积累 |
| **匿名班级趋势** | 学生可选择匿名加入班级趋势，老师只能看到整体数据，看不到个人内容 |
| **一周情绪趋势图** | 用折线图可视化展示周一至周日的情绪波动，标出最高点和最低点 |
| **四季主题切换** | 春/夏/秋/冬四种主题配色，让页面随时间流转保持新鲜感 |
| **动态天气背景** | 根据情绪天气自动切换阳光、雨滴、雪花、闪电等动画效果 |
| **小动物陪伴员** | 每个天气状态对应不同表情和动作的小动物，起到温暖安抚的作用 |

## 2. Demo 创作思路

### 灵感来源

这个想法来自于一个观察：中学生不是"不想表达情绪"，而是"不知道怎么开口"。

- 写长篇日记太花时间，而且写着写着容易变成自我批评
- 跟朋友说怕被觉得"矫情"
- 心理咨询室门太难推开

所以我想：能不能做一个**门槛极低、无评判、还有一点可爱**的工具？让学生像查天气一样，轻松地"查一查自己的心情"。

### 想解决的问题

| 痛点 | 晴雨同学的解法 |
|---|---|
| "心里不舒服但说不清" | 用天气做隐喻，降低表达门槛 |
| 写日记有压力 | 一句话即可，不需要完整句子 |
| 担心被看到 | 隐私开关，默认仅自己可见 |
| 情绪低落时不知道做什么 | 自动给出可操作的小建议和小任务 |
| 老师想了解班级整体状态 | 匿名趋势，只看数据不看人 |

### 为什么做这个方向

在做取舍时，我坚定地选择了"轻量"和"温暖"两个关键词：

- **不做** 复杂的量表测评（学生会觉得在"做题"）
- **不做** 严肃的医学诊断（会产生距离感）
- **不做** 社交功能（避免攀比和表演）
- **做** 天气隐喻（自然、无评判、有画面感）
- **做** 小动物陪伴（增加情感连接）
- **做** 一分钟记录（降低使用阻力）
