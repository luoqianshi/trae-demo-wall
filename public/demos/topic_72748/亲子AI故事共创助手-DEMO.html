📝 PromptEngine — 提示词组装引擎
系统提示词模板，动态注入上下文变量后送入LLM：
你是一个亲子故事共创助手，名叫"小星星"。
你需要根据以下上下文帮助孩子创作故事：
[世界观上下文]
[角色信息]
[故事风格]
[安全规则]
[当前阶段]
创作规则：
1. 必须保持角色状态一致性
2. 语言适合3-10岁儿童
3. 传递积极价值观
4. 每段对话30-80字
5. 引导孩子参与创作
注入来源：MemoryGraph → WorldviewExtractor → PromptEngine → LLM

🧠 MemoryGraph — 记忆图谱数据结构
MemoryGraph
├─ Nodes (节点)
├─ Character {id, name, role, traits, status, avatar}
├─ Location {id, name, description, features}
├─ Item {id, name, owner, properties, significance}
└─ Story {id, title, chapters, timeline, moral}
├─ Edges (关系边)
├─ Relationship {source, target, type, strength, description}
└─ Event {source, target, event_type, timestamp, description}
