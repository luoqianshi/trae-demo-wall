【完整 AI 体验（可选）】
如需体验 DeepSeek AI 实时生成功能：

1. 确保已安装 Python 3（https://python.org）
2. 打开终端/命令行，进入本文件夹
3. 运行：python proxy.py
4. 看到"代理已启动"提示后，保持窗口不关
5. 用浏览器打开 index.html
6. 输入任意词语，等待 2-5 秒
7. 结果区显示"由 AI 生成（DeepSeek）"即为成功

注意：proxy.py 需要网络连接（访问 DeepSeek API 服务器）。
