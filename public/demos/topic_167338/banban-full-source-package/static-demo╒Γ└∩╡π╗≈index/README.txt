
========================================
  伴伴 Banban - AI时间伙伴 静态演示版
========================================

【使用方法】
1. 解压 zip 文件到任意文件夹
2. 双击 index.html 即可在浏览器中打开
3. 推荐使用 Chrome / Edge / Firefox 现代浏览器

【功能说明】
- 完整包含所有界面页面
- 内置模拟数据，无需后端服务器即可体验
- 支持页面间导航跳转
- 包含问卷调查引导流程
- 包含门户、今日计划、时间线、时间罗盘、
  无限画布、周统计、早晚复盘、设置、聊天等页面

【页面列表】
- index.html          入口页面（自动跳转）
- onboarding_new.html 欢迎/问卷调查页（首次打开）
- portal.html         门户导航页
- today.html          今日计划页
- today_timeline.html 今日时间线
- compass.html        时间罗盘
- canvas_v4.html      无限画布
- weekly.html         周统计
- review_morning.html 早复盘
- review_evening.html 晚复盘
- review_summary.html 复盘总结
- chat.html           AI聊天
- settings.html       设置
- cognition.html      认知洞察
- behavior.html       行为分析
- overview.html       总览
- lab.html            实验室
- help.html           帮助

【注意事项】
- 这是静态演示版本，部分功能（语音、真实AI对话、截图识别）使用模拟数据
- 如需完整体验，请运行完整版 Python 应用
- 如果想重置演示数据，可在浏览器控制台输入：BanbanStatic.resetDemo()
