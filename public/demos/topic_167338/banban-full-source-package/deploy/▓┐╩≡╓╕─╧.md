## 快速开始（3步搞定）

### 第1步：买服务器（5分钟）

1. 打开：https://cloud.tencent.com/product/lighthouse
2. 点击 "立即选购"
3. 配置选择：
   - **地域**：选离你最近的（上海/广州/北京）
   - **镜像**：Ubuntu 22.04 LTS（不要选别的！）
   - **套餐**：2核2G 4M带宽（¥38/月左右）
   - **时长**：1个月
4. 付款，等待创建完成（一般1-2分钟）

### 第2步：上传文件（5分钟）

#### 方式A：用宝塔面板（推荐，可视化操作）

1. 在腾讯云控制台找到你的服务器
2. 点击 "应用管理" 标签
3. 点击 "重置应用"
4. 选择 "宝塔Linux面板"（在应用市场里找）
5. 确认重置，等待2分钟
6. 重置后页面会显示面板地址、用户名和密码，保存好
7. 打开面板地址登录
8. 登录后会推荐安装套件，选 Nginx + Python，点安装
9. 左侧菜单点 "文件"，进入 `/opt/` 目录
10. 新建文件夹 `banban`
11. 进入 `banban` 文件夹，点 "上传"，把整个项目的文件都上传
12. 上传完成后，点左侧 "终端"，输入：
    ```bash
    cd /opt/banban && bash deploy.sh
    ```
13. 等待安装完成，看到 "部署完成" 就好了

#### 方式B：用命令行（快一点，需要会用SSH）

1. 下载 FinalShell：http://www.hostbuf.com/t/988.html
2. 安装后新建连接：
   - 主机：你的服务器公网IP
   - 端口：22
   - 用户名：root
   - 密码：腾讯云控制台里设置的密码
3. 连接成功后，把项目打包成zip上传到服务器
4. 解压后运行：
   ```bash
   cd /opt/banban && bash deploy.sh
   ```

### 第3步：访问

部署完成后，在浏览器输入你的服务器公网IP就能访问了！

## 常用运维命令

部署在服务器上后，常用操作（SSH登录后执行）：

```bash
# 查看服务状态
systemctl status banban

# 查看实时日志
journalctl -u banban -f

# 重启服务
systemctl restart banban

# 停止服务
systemctl stop banban

# 查看Nginx状态
systemctl status nginx

# 查看Nginx错误日志
tail -f /var/log/nginx/error.log

# 重启Nginx
systemctl restart nginx
```

## 数据备份

所有数据存在 `/opt/banban/data/.banban/` 目录下，定期下载备份即可。

```bash
# 在服务器上打包备份
tar -czf /root/banban-backup-$(date +%Y%m%d).tar.gz /opt/banban/data/

# 下载到本地（本地电脑执行）
scp root@你的IP:/root/banban-backup-xxx.tar.gz .\
```

## 配置 HTTPS（可选，有域名才需要）

如果有域名，可以配置免费的SSL证书：

```bash
# 安装 certbot
apt-get install certbot python3-certbot-nginx -y

# 申请证书（替换为你的域名）
certbot --nginx -d your-domain.com
```

没有域名就不用管，直接用IP访问就行。

## 常见问题

**Q: 部署后访问不了？**
A: 检查腾讯云防火墙是否开放了80端口，在控制台 "防火墙" 里添加规则。

**Q: 页面加载很慢？**
A: 第一次加载可能慢一点，因为要初始化数据。如果一直慢，检查服务器配置。

**Q: 数据会丢吗？**
A: 数据存在服务器的 SQLite 数据库里，只要服务器不重装就不会丢。建议定期备份。

**Q: 可以用阿里云吗？**
A: 可以，步骤一样，阿里云轻量应用服务器也是类似的操作。

**Q: 每月多少钱？**
A: 2核2G配置大约 ¥38/月，新用户首月可能更便宜（¥10左右）。
