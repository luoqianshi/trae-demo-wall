## 方案一：雨云（最便宜，¥10/月）

### 第1步：注册雨云账号（2分钟）

1. 打开：https://www.rainyun.com/
2. 用手机号注册一个账号
3. 登录后进入控制台

### 第2步：买服务器（3分钟）

1. 左侧菜单选 "云服务器" → "创建云服务器"
2. 配置选择：
   - **地域**：选国内的（华东/华南都行）
   - **配置**：1核1G（最便宜的，约¥10/月）
   - **系统**：Ubuntu 22.04（一定要选这个！）
   - **时长**：1个月
3. 付款（支持微信/支付宝）
4. 等待创建完成（一般1-2分钟）

### 第3步：用宝塔面板上传文件（3分钟）

1. 在服务器列表里找到你刚买的服务器
2. 点击 "管理" 或 "详情"
3. 找到 "应用管理" 或 "预装应用"
4. 选择安装 "宝塔面板"（如果有的话）
5. 如果没有宝塔面板，就用下面的方法：
   - 找到 "远程连接" 或 "VNC"
   - 打开后输入 root 和密码（在控制台里能找到）
   - 复制下面这行命令粘贴进去，回车：
     ```
     wget -O install.sh http://download.bt.cn/install/install-ubuntu_6.0.sh && bash install.sh
     ```
   - 等待安装完成（约3分钟）
   - 安装完成后会显示面板地址、用户名、密码，保存好

6. 打开宝塔面板地址，登录
7. 登录后会推荐安装套件，选 **Nginx**，点安装（快速安装就行）
8. 安装完成后，点左侧 "文件" 菜单
9. 进入 `/opt/` 目录
10. 点 "新建" → "文件夹"，名字填 `banban`
11. 进入 `banban` 文件夹
12. 点 "上传"，把 `banban-cloud-deploy.zip` 传上去
13. 上传完成后，右键这个zip文件，点 "解压"

### 第4步：一键部署（2分钟）

1. 在宝塔面板里点 "终端"
2. 输入下面的命令，回车：
   ```bash
   cd /opt/banban && bash deploy-oneclick.sh
   ```
3. 等待运行完成（约2-3分钟）
4. 看到 "部署完成" 就成功了！

### 第5步：访问

在浏览器输入你的服务器公网IP（在雨云控制台能看到），就能访问了！

## 常用操作（以后可能用到）

### 重启服务
在宝塔终端里输入：
```bash
supervisorctl restart banban
```

### 查看错误日志
```bash
tail -50 /opt/banban/logs/error.log
```

### 备份数据
数据都在 `/opt/banban/data/` 目录里，用宝塔的文件管理器下载就行。

## 常见问题

**Q: 访问不了怎么办？**
A: 检查雨云控制台的"安全组"/"防火墙"，确保开放了80端口。

**Q: 1核1G够用吗？**
A: 完全够用！我们的程序很轻，同时几十个人访问都没问题。

**Q: 可以用支付宝/微信付款吗？**
A: 可以，雨云支持微信和支付宝。

**Q: 不想用了可以随时停吗？**
A: 可以，不续费就行，按天计费。
