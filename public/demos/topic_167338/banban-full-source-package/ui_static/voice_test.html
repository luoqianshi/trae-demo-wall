📋 豆包语音识别开通步骤

1. 打开 火山引擎语音控制台
2. 创建应用 → 开通「流式语音识别」服务
3. 在应用详情页复制：App ID、Token、Cluster
4. 把三个值填入上方 → 保存凭据 → 即可开始使用

💡 豆包中文识别效果业界顶尖，免费试用额度慷慨！
📋 阿里云百炼开通步骤

1. 打开 百炼控制台，选择语音识别模型
2. 点击「开通服务」→ 创建 API Key
3. 把 API Key 填入上方 → 保存凭据 → 即可开始使用

💡 只需要一个 API Key，不用 AccessKey，不用 AppKey！
⚠ 讯飞关键步骤

1. 讯飞控制台 → 进入应用 → 添加服务
2. 开通「语音听写（流式版）」服务
3. 复制 APPID、APIKey、APISecret 填入上方保存
