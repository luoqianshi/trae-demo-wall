## 1. 产品定位

### 1.1 一句话定位

> **面向中小学生的线上项目制学习（PBL）平台**，让教育机构一键开展标准化PBL课程，让学生在"做中学"的过程中培养科学探究、动手实践和协作能力。

### 1.2 核心差异化

对比市面所有PBL产品，本平台独占三个差异化：

| 维度 | 竞品现状 | 本平台 |
|------|----------|--------|
| 内容深度 | 通用模板，无细化任务 | 100+个精心设计的K-12项目任务，覆盖科学、人文、编程、创意等多类别 |
| 教学过程 | 线下为主，缺乏线上过程管控 | 完整的线上闭环：任务发布→步骤引导→作品提交→评分反馈→证书生成 |
| 技术融合 | 纯线下或简单文档 | AI生成封面图+视频、在线交互实验、多端支持（Web+小程序） |

### 1.3 解决的核心痛点

1. **机构端**：PBL教学缺乏标准化线上平台，课程开设成本高、过程难管控
2. **教师端**：项目过程难管控、作业难收集、评价难量化、成果难展示
3. **学生端**：参与项目无成果沉淀、无证书激励、无作品集展示
4. **家长端**：不了解孩子在项目中的参与情况和成长轨迹

## 3. 核心业务模块

### 3.1 项目任务体系

平台预置 **100+个K-12项目任务**，覆盖以下类别：

| 类别 | 示例任务 | 适用年级 |
|------|----------|----------|
| 科学实验 | 水质检测、火山喷发、植物毛细现象 | 3-8年级 |
| 自然探索 | 昆虫观察、天气记录、星空观测 | 2-6年级 |
| 创意制作 | 手工DIY、环保装置、模型搭建 | 1-6年级 |
| 编程入门 | Scratch游戏、Python基础、AI初体验 | 4-9年级 |
| 人文社科 | 古诗词探秘、非遗传承、城市文化探索 | 3-7年级 |
| 生活实践 | 社区观察、公益实践、商业模拟 | 3-9年级 |

每个任务包含：
- 任务封面图（AI生成，风格统一）
- 任务标题、描述、类别、难度、适合年级
- 项目原则（核心概念讲解）
- 分步骤引导（图文+视频参考）
- 交互式Demo（部分任务）
- 提交要求与评价标准

### 3.2 营期管理

机构可创建和管理不同类型的PBL营期：

| 营期类型 | 时长 | 说明 |
|----------|------|------|
| 单日营 | 1天 | 单次项目体验 |
| 7天营 | 1周 | 短期项目学习 |
| 14天营 | 2周 | 中期深度学习 |
| 冬夏令营 | 假期 | 集中式项目学习 |
| 周末营 | 周末 | 课余兴趣培养 |

### 3.3 小组分工

所有项目小组统一设置四个标准化岗位：

| 岗位 | 职责 |
|------|------|
| 管理岗（组长） | 进度统筹、人员协调、任务分配 |
| 执行岗（核心成员） | 技术开发、方案落地、任务执行 |
| 质检岗 | 任务审核、错误排查、标准核对 |
| 宣传归档岗 | 过程记录、资料整理、成果展示 |

### 3.4 过程管控

| 类型 | 频率 | 说明 |
|------|------|------|
| 日报 | 每日 | 各团队提交当日进度 |
| 周报 | 每周 | 团队负责人汇总本周成果 |
| 复盘会 | 阶段性 | 导师组织团队回顾总结 |

### 3.5 考核与激励

**评分体系**：
- 自评 + 互评 + 导师评 三维评分
- 团队奖励：最佳攻坚、最佳协作、最佳成果、最佳创新

**证书体系**：
- 实践证明
- 项目贡献证书
- 优秀贡献者证书
- 自动生成证书编号

**学分认定**：
- 实践学分：按任务完成度认定
- 综合学分：按项目贡献度认定

### 3.6 通知与消息

关键业务节点自动推送通知：
- 任务分配通知
- 审核完成通知
- 成果整合通知

支持：通知列表、未读计数、标记已读、全部已读。

### 3.7 数据看板

#### 平台管理后台

- 核心指标：入驻机构数、营期数、用户数、营收、订单数
- 成果指标：成果总数、已通过成果数

#### 教师看板

- 项目进度概览
- 待处理事项

### 3.8 资源与模板

- 资源库（文档/标准/模板/材料/工具/其他）
- 项目模板（已完成项目可模板化复用）

## 7. 未来规划

### 7.1 企业需求对接（OPC校企合作）

> 本功能为未来扩展方向，当前版本未实现，以下为规划蓝图。

计划实现企业真实需求进校园的三级拆分协作模式：

```
企业完整项目
├── 一级：企业顶层规划（企业导师+高校导师主导）
├── 二级：核心攻坚模块（大学团队承接）
└── 三级：辅助落地模块（中小学团队承接）
```

涉及的新用户角色：
- 企业导师（enterprise_mentor）：企业方代表，发布需求、提供指导、验收成果
- 高校导师（university_mentor）：大学指导教师，统筹大学团队、培训中小学

详细规划见 [企业需求对接-未来规划](../.trae/documents/企业需求对接-未来规划.md)

### 7.2 其他规划方向

- **AI赋能**：AI辅助项目生成、AI自动点评、智能推荐学习路径
- **全学段贯通**：扩展到大学、研究生层次
- **实习就业联动**：优秀学生自动推荐企业实习
