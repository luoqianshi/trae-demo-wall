# PBL K-12 项目制学习平台 - 项目文档体系

## 文档分类说明

项目文档按用途分为两类：

### PRD（Product Requirements Document）— 产品需求文档

**面向业务方**，回答"**要做什么、为什么做**"。包含：业务背景、用户需求、功能定义、商业逻辑、验收标准。由产品经理产出，在开发开始前定稿。

| 文档 | 说明 |
|------|------|
| [PRD.md](./PRD.md) | 完整产品需求文档（v2.1 定位修正版） |

### 详细设计文档（Low-Level Design）— 技术设计文档

**面向开发者**，回答"**怎么改代码、改什么文件**"。包含：差距分析、数据库设计、API设计、前端组件修改清单、实施顺序。由技术负责人在PRD确认后产出，指导开发实施。

| 文档 | 位置 | 说明 |
|------|------|------|
| 详细设计文档 v1 | `.trae/documents/详细设计文档-v1.md` | 核心流程闭环：岗位分工、五阶段状态机、日报周报、学分、联合证书、考核激励、进度可视化、资源库 |
| 详细设计文档 v2 | `.trae/documents/详细设计文档-v2.md` | 前端补全+场景案例：admin-web路由补全、小程序前端页面、分场景案例 |
| 详细设计文档 v3 | `.trae/documents/详细设计文档-v3.md` | 三阶段深度优化：培训指导、成果整合、小程序UI/UX、项目模板、数据看板、通知系统 |

### 未来规划
