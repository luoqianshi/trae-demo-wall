# 《我是皇帝》时空作息管理工具

> 生活娱乐向古风角色扮演时间管理网页工具  
> 绑定时区 · 匹配清康雍乾起居 · 御批奏折 · 三轴养成

## 📜 项目简介

《我是皇帝》是一款以**清康雍乾起居注**为史料基准的趣味时间管理工具。用户在登基时绑定起床时间与常住城市时区,系统自动换算为紫禁城标准时辰,授予「东京皇帝」「伦敦皇帝」「纽约皇帝」等专属称号;按本地实时时间推送当前时辰对应的「帝王事务」(御批奏折、晨读圣训、宫闱休闲等),并以**勤政值/仁德值/享乐值**三轴养成帝王人设。

## ✨ 核心功能

| 模块 | 功能 |
|------|------|
| 🕐 钦天监(多时区时钟) | 本地/紫禁城/已添加城市实时时钟,十二时辰对照 |
| 👑 登基大典 | 输入起床时间+时区 → 授予专属称号 |
| 📜 帝王一日起居 | 卷轴式 8 阶段时间轴,进度条流光,时辰到点传旨 |
| 📜 奏折待办 | ToDo 与"御批奏折"联动,勾选累计属性 |
| 🐉 帝王三德 | 勤政/仁德/享乐 三轴,累计解锁勋章与皮肤 |
| 🎭 宫廷随机事件 | 政务/后宫/祭祀三类,选择处理后属性变化 |
| 📚 科举(科普) | 十二时辰/更鼓/《清实录》节选/康雍乾对比 |
| ⏳ 御批奏章·番茄钟 | 25 分钟专注,完成 +2 勤政值 |
| 🎨 换肤系统 | 乾清宫(红墙)/御花园(玉绿)/圆明园(湖蓝)三套主题 |
| 💾 存档管理 | 导出/导入 JSON,跨设备同步 |

## 🏗 技术栈

- **HTML5 + Tailwind CSS CDN** — 零构建,单文件离线运行
- **原生 JavaScript (ES6+)** — 无框架,模块化拆分
- **霞鹜文楷 + 思源宋体 + Cinzel** — 古风字体方案
- **Intl.DateTimeFormat** — 原生时区 API
- **localStorage** — 本地存档
- **Web Audio API** — 合成古风音效(打更/传旨/上朝)
- **Python zipfile** — 一键打包

## 🚀 快速开始

### 方式一:直接运行

1. 解压 `我是皇帝_v1.0_*.zip`
2. 双击 `index.html`,浏览器中即可使用
3. **首次打开会弹出"登基大典"弹窗,选择时区+起床时间即可登基**

### 方式二:本地开发

```bash
# 进入项目目录
cd emperor-time-manager

# 用 Python 启动一个简易 HTTP 服务器(可选,某些浏览器对 file:// 下的 fetch 有限制)
python -m http.server 8080

# 浏览器访问 http://localhost:8080
```

## 📦 一键打包

### Windows

双击运行 `打包.bat`,会自动调用 `打包.py` 生成 `dist/我是皇帝_v1.0_<时间戳>.zip`。

如果 `打包.bat` 出现中文乱码或闪退,运行一次 `python 生成打包脚本.py` 重新生成 CRLF 编码的 bat。

### macOS / Linux

```bash
python3 打包.py
```

输出文件:`dist/我是皇帝_v1.0_<时间戳>.zip`

## 🕹 使用流程

1. **登基**:首次打开弹出弹窗 → 选择时区城市 → 输入起床时间 → 授予称号

## 🛠 故障排查

| 问题 | 解决 |
|------|------|
| 双击 `index.html` 时 fetch 失败 | 部分浏览器对 `file://` 的 `fetch` 有限制,改用 `python -m http.server` 启动 |
| 字体显示为系统默认 | 联网首次加载 CDN 字体,后续会缓存 |
| 时间轴不更新 | 检查浏览器控制台,确保 `setInterval` 未被节能模式暂停 |
| 打包 bat 闪退 | 运行 `python 生成打包脚本.py` 重新生成,确保 CRLF 换行 |
