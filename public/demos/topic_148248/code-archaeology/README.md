# Code Archaeology · AI 代码考古学

> **让每一行代码，都能讲出自己的故事。**
>
> 目标：把新人读懂成熟项目的时间从 3 个月压到 3 周。
> 用可解释的 ROI 模型展示"组织记忆税"如何被量化。
> 从 TRAE IDE 插件切入，让 AI 继承团队代码历史。

这是为 **TRAE AI 创意 Demo 大赛** 准备的作品 —— 一个面向研发组织的 AI 代码考古工具。

---

## 🎯 这次改版的核心变化

相比 v1 概念化、PPT 化的呈现，v2 完全转向**接地气、案例驱动、可算账**：

| 维度 | v1 ❌ | v2 ✓ |
|------|-------|------|
| 价值主张 | "组织记忆基础设施" | "3 个月 → 3 周，展示清晰收益路径" |
| 案例 | 编的"小张入职" | 复合型脱敏案例：星河零售 5 年演化 |
| 业务价值 | 模糊的"提效" | 实时可调的 ROI 计算器，明确说明估算假设 |
| 视觉演示 | 静态 mockup | **可点击的 TRAE 插件交互原型** |
| 组织洞察 | 无 | AI 主动发现的 5 个组织记忆断点 |
| 落地路线 | 4 阶段抽象描述 | 从 TRAE 插件试点到企业研发知识图谱 |

---

## 💡 设计的 6 个"哇塞瞬间"

评委滑到这 6 个地方应该会停下来：

1. **第一屏反常识数字**：「3 个月 → 3 周」+ 可解释的组织记忆税估算
2. **完整复合案例**：一家 800 人公司 2019-2025 的支付中心演化，每个关键时刻都有具体数字
3. **可玩的 Live Demo**：TRAE 插件交互原型，点一下 AI 输出样例案卷
4. **大奖高光**：把代码历史变成 PR 风险提示、回滚 Runbook、复盘补丁和新人导读卡
5. **5 个组织记忆断点**：AI 主动发现代码、工单、事故、人员流动之间的断裂
6. **可拖动的 ROI 计算器**：把 Onboarding、事故、协作成本讲成评委能理解的收益路径

## 📐 页面结构

1. **Hero** — "让每一行代码都能讲出自己的故事" + Live 案卷预览
2. **复合案例** — 星河零售 5 年演化，5 个关键时刻
3. **Live Demo** — TRAE 插件工作流，样例数据模拟真实接入效果
4. **大奖高光** — 把历史变成生产护栏，形成可复用行动包
5. **组织记忆断点** — AI 主动发现的 5 个洞察
6. **价值模型** — 可交互的 ROI 计算器
7. **落地路线** — 从 TRAE 插件试点到组织级知识图谱
8. **评委投票理由** — 创意新、痛点真、落地强
9. **CTA** — 从一个高风险老模块开始 POC
