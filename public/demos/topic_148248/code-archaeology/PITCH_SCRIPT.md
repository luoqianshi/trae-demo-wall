# Code Archaeology 答辩讲稿

## 30 秒开场

当 AI 工具都在解决"代码怎么写"，成熟研发组织真正痛的，往往是没人记得"这段代码为什么会变成今天这样"。

Code Archaeology 想做的是 TRAE 里的 AI 代码考古插件：开发者选中一段老代码，AI 自动把 Git、Jira、事故复盘、设计文档和群聊纪要串成一份代码案卷，告诉你它的历史原因、风险来源和下一步行动。

一句话：不是让 AI 多写一段代码，而是让 TRAE 帮团队继承代码背后的组织记忆。

## 4 分钟演示路线

1. Hero 区：先讲核心反差

   "新人读懂成熟项目为什么要 3 个月？不是代码本身难，而是代码背后的事故、妥协、迁移和口口相传的经验没有被结构化。"

2. 主案例：讲星河零售 5 年支付中心演化

   "这个案例是复合型脱敏案例。重点不是某家公司，而是成熟系统的共性：第一版为了快上线，后面每一次事故都叠一个补丁，几年后没人敢改。"

3. 在线 Demo：一定要现场点击

   建议点击顺序：
   - 点击"在线 Demo"
   - 选择"代码考古器"
   - 保持默认退款重试代码
   - 点击"让 AI 分析"
   - 等 AI 思考步骤跑完后，强调它不是只解释代码，而是在模拟跨 Git、Jira、复盘的证据追溯

4. 大奖高光：讲出真正眼前一亮的点

   "如果只是解释代码，那它只是一个更会总结的 Copilot。真正的创意是：它把历史变成生产护栏。比如我改一行重试逻辑，TRAE 不只是告诉我这段代码为什么存在，还能在 PR 前提示：这个改动会不会踩回 2021 年的事故；上线前生成回滚 Runbook；事故复盘后把结论回写到代码案卷里。"

   这一页一定要讲慢一点，核心句是：

   "TRAE 不只帮你写下一行代码，也帮你判断这一行代码会不会踩回 3 年前的坑。"

5. 组织记忆断点：讲评委最容易共鸣的部分

   "我们发现，很多技术债不是没人知道，而是没人能完整讲清：事故记在复盘里，原因在 commit 里，决策在老员工脑子里。AI 的价值是把这些断点接起来。"

6. 价值模型：讲收益路径，不强调绝对金额

   "这个计算器不是承诺收益，而是说明成本从哪里来：新人 Onboarding、跨团队返工、重复事故、关键员工离职 context 损失。真实接入后可以用企业自己的数据校准。"

7. 投票理由：最后收束

   "这个作品的创意点不是又一个代码生成器，而是让 TRAE 从写代码助手，进化成研发组织记忆层。创意新、痛点真、落地路径清楚。"

## 大奖版记忆点

评委真正要记住的不是"AI 会总结历史"，而是这三个升级：

- 从写代码到懂代码历史：AI 不只生成新代码，也理解旧代码为什么存在。
- 从知识问答到生产护栏：AI 把事故、工单、commit 变成 PR 风险提示、回滚 Runbook 和复盘补丁。
- 从个人效率到组织资产：每次事故、每次架构决策、每次补丁都能沉淀为下一次可复用的组织记忆。

一句高光表达：

"Code Archaeology 让 TRAE 从开发者的编码助手，升级成研发组织的记忆继承者。"

## 评委可能追问

### 这是不是只是 RAG 总结？

不是。普通 RAG 是把文档搜出来总结，Code Archaeology 的核心是把代码演化当成因果链来建模：谁在什么时候改了什么、对应哪个工单、修过哪次事故、后来产生了什么风险。最终输出不是摘要，而是带证据链的决策建议。

### 眼前一亮的地方到底是什么？

不是查到一段历史，而是把历史变成生产动作。比如同一份代码案卷可以生成 PR 风险评论、上线回滚 Runbook、事故复盘补丁和新人导读卡。它不是一个"知道过去"的工具，而是让过去在下一次改代码时真正发挥作用。

### Demo 里的数据是真的吗？

比赛 Demo 使用复合型脱敏案例和样例知识库，目的是展示真实接入后的产品体验。企业版会接入 Git、Jira、Confluence、事故平台和飞书群记录，按权限生成案卷。

### 为什么一定要放在 TRAE 里？

因为问题发生在写代码和改代码的现场。开发者最需要 context 的时刻，是他在 IDE 里看到一段不敢改的老代码时。TRAE 插件能把案卷放在代码旁边，不打断工作流。

### 如何避免 AI 胡说？

页面里强调的是证据链：每个结论都要挂到 commit、Jira、事故复盘、设计文档或聊天记录。没有证据的内容应该降置信度，不能作为治理建议直接输出。

### 第一阶段怎么落地？

不要一开始做全公司平台。先选一个高风险老模块，比如支付、库存、权限、实验平台，接入 Git + Jira + 事故复盘，验证三件事：案卷准确率、证据可追溯率、Onboarding 周期变化。

## 一句话收束

当 AI 都在帮你写代码，Code Archaeology 让 TRAE 帮团队记住代码为什么这么写。
