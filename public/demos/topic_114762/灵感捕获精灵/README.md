## 📦 项目简介

- 🧠 **5 大分析框架** — SWOT / 精益画布 / 4P 市场策略 / 技术评估 / 生活决策

- 📦 **7 大输出模块** — 分类打标 / 提示词优化 / 知识图谱 / 框架分析 / 行动建议 / 时间线 / AI追问
- 🌍 **7 种语言支持** — 中 / 英 / 日 / 韩 / 法 / 德 / 西

## 🚀 快速开始

### 前置要求

1. 安装 **Ollama**（本地大模型运行环境）
   - 下载地址：https://ollama.com/
2. 拉取一个模型，例如：
   ```bash
   ollama pull qwen2.5:7b
   # 或
   ollama pull llama3.1:8b
   ```

### 使用方法

1. 解压本压缩包
2. 双击打开 `demo.html`
3. 点击右上角「⚙️ 设置 Ollama」配置模型名称
4. 在输入框描述你的灵感
5. 点击「✨ 捕获灵感」，AI 将为你生成完整的结构化分析报告

### 默认配置

- **Ollama 地址**：`http://localhost:11434`
- **默认模型**：`qwen2.5:7b`（可在设置中修改）
- **搜索引擎**：OpenSERP（可选，用于联网搜索增强）

## 🛠️ 技术栈

- 前端：原生 HTML5 / CSS3 / ES6+ JavaScript
- 大模型：Ollama（支持 Llama / Qwen / DeepSeek 等）
- 搜索：OpenSERP 本地搜索引擎
- 文件解析：pdf.js + mammoth.js
- 语音：Web Speech API
- 存储：localStorage 纯本地

## 📝 注意事项

1. 本软件需要本地运行 Ollama 才能使用 AI 功能
2. 未连接 Ollama 时会使用本地模板模式（仅供参考框架结构）
3. 所有数据存储在浏览器 localStorage，清除浏览器数据会丢失
4. 建议使用 Chrome / Edge 等现代浏览器获得最佳体验
