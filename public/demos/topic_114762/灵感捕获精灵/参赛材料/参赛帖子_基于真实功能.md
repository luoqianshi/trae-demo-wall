## 一、创意名称 + 创意介绍

### 创意名称

**灵感捕获精灵（Inspiration Catcher）** —— 基于本地大模型的 AI 结构化思考助手。

### 想解决什么问题？

你有没有过这样的经历：
- 洗澡时突然想到一个绝妙的产品 idea，擦干手拿起手机时已经忘了一半
- 读论文时冒出一个研究假设，当时没记下来，后来怎么都想不起来
- 收藏了一堆文章和资料，但从来没整理过，灵感散落在各处

**灵感的生命周期只有几分钟**，但从"想法"到"可执行方案"之间，隔着巨大的鸿沟：
- 记下来了，但只是零散的一句话
- 想深入分析，但不知道从哪个角度切入
- 想付诸行动，但拆解不出具体步骤

### 为什么用 AI 来解决？

传统的笔记工具只是"记录"，而 AI 可以做到"**理解 + 结构化 + 行动建议**"。灵感捕获精灵不只是帮你记下想法，而是帮你**把想法想清楚、想全面、想落地**。

### 产品形态

一个 **单文件 HTML 应用**——打开浏览器就能用，无需安装，无需注册，数据全在本地。

## 三、核心功能（全部已实现 ✅）

> 以下功能均可在 demo.html 中实际操作体验，不是 PPT 产品。

### 1. 五维灵感捕获 🎯

**5 种输入方式**，覆盖灵感产生的所有场景：

| 输入方式 | 支持格式 | 适用场景 |
|---------|---------|---------|
| 🔍 **搜索** | 联网搜索（OpenSERP） | 想调研某个方向时，先搜再想 |
| 📎 **文件** | TXT / PDF / DOCX / MD | 读报告、读论文时产生灵感 |
| 🔗 **链接与图片** | URL / PNG / JPG / GIF / WebP | 看到好文章、好设计想记录 |
| 📝 **文字** | 自由文本 | 直接写下你的想法 |
| 🎙️ **语音** | 实时语音识别（Chrome） | 不方便打字时直接说出来 |

搜索还支持 **5 种范围筛选**：全部 / 产品 / 学术 / 商业 / 技术，精准定位你需要的信息。

### 2. 四大分析框架 📐

不只是记录，更要帮你**想清楚**。4 种经典商业分析框架，一键切换：

| 分析框架 | 适用场景 | 分析维度 |
|---------|---------|---------|
| 📊 **SWOT 分析** | 通用战略分析 | 优势 / 劣势 / 机会 / 威胁 |
| 📐 **精益画布** | 商业模式设计 | 9 宫格：客户、价值主张、收入... |
| 🎯 **4P 市场策略** | 营销方案设计 | 产品 / 价格 / 渠道 / 促销 |
| ⚙️ **技术评估** | 技术可行性分析 | 可行性 / 难度 / 风险 / 技术栈建议 |

无论你想到的是产品 idea、研究方向还是创业计划，都能找到合适的分析框架。

### 3. 从灵感到行动的完整闭环 🔄

每次捕获灵感，AI 会输出 **7 大分析模块**：

1. 💡 **灵感卡片** —— 自动分类、打标签
2. ✍️ **提示词优化** —— 对比原始输入 vs AI 优化版本，教你把想法说清楚
3. 📋 **资料分析** —— 如果上传了文件/链接，自动提炼核心要点
4. 🔗 **知识关联图谱** —— 发现灵感之间的隐含联系
5. 📊 **框架分析** —— SWOT / 精益画布 / 4P / 技术评估（4 选 1）
6. 🎯 **行动建议** —— 可勾选的任务清单，分高/中/低优先级
7. 📅 **执行时间线** —— 按阶段拆解的执行计划

还支持 **💬 追问 AI** —— 对分析结果有疑问？继续深入探讨。

### 4. 团队协作模式 👥

不止是个人工具，还支持团队版：

- **👤 个人版 / 👥 团队版** 一键切换
- 数据完全隔离（不同 localStorage 命名空间）
- 成员管理：添加 / 删除 / 编辑团队成员
- 一键分享灵感到团队空间
- 支持发送资料给指定成员

## 四、技术亮点

### 100% 本地运行，隐私优先

- **本地大模型**：基于 Ollama，支持任意开源模型（Llama 3、Qwen、DeepSeek 等）
- **本地搜索**：基于 OpenSERP，联网搜索无需 API Key
- **本地存储**：所有数据存在浏览器 localStorage，不上传任何服务器
- **离线可用**：即使没有 Ollama，也能用内置模板体验完整流程

### 纯前端单文件架构

- 一个 HTML 文件 + 一个 CSS + 一个 JS，总共 3 个文件
- 无需后端、无需数据库、无需部署
- 打开浏览器就能跑，双击 demo.html 即可使用
- 基于 pdf.js + mammoth.js 实现前端文件解析

### 技术栈

| 层级 | 技术 |
|-----|------|
| 前端 | 原生 HTML / CSS / JavaScript（零框架依赖） |
| AI 引擎 | Ollama（本地大模型推理） |
| 搜索 | OpenSERP（开源搜索引擎） |
| 文件解析 | pdf.js（PDF）/ mammoth.js（DOCX） |
| 存储 | localStorage（浏览器本地存储） |

## 六、使用方式

### 快速体验（30 秒上手）

1. 双击打开 `demo.html`
2. 在"文字/语音"标签页，点击任意"快速体验示例灵感"按钮
3. 点击"✨ 捕获灵感"按钮
4. 查看 AI 生成的完整分析报告

### 完整功能体验

1. 安装 Ollama：`brew install ollama`（macOS）或从 [ollama.com](https://ollama.com) 下载
2. 拉一个模型：`ollama pull llama3`
3. 启动 Ollama：`OLLAMA_ORIGINS=* ollama serve`（允许浏览器跨域访问）
4. 打开 demo.html，点击右上角"⚙️ 设置 Ollama"
5. 测试连接成功后，就可以用真实 AI 分析你的灵感了！

### 联网搜索体验

1. 运行 OpenSERP：`docker run -p 7000:7000 karust/openserp serve`
2. 在"搜索"标签页输入关键词
3. AI 会自动搜索并整合搜索结果进行分析
