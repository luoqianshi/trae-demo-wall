React 项目里怎么优化长列表性能？请给代码示例和复杂度公式。

React 长列表优化常用 虚拟滚动。核心思路：只渲染可视区域的元素。推荐用 react-window：

tsx 
import { FixedSizeList } from 'react-window';

const Row = ({ index, style }) => (
  <div style={style}>{items[index]}</div>
);

<FixedSizeList
  height={600}
  itemCount={items.length}
  itemSize={40}
  width="100%"
>{Row}</FixedSizeList>

复杂度：渲染 O(n) → O(k)，其中 k 为可视元素数。性能上限公式：

$$T(n) = O(k) + O(n)_{\text{mount}}$$

补充一下，虚拟列表的时间复杂度怎么算？

虚拟列表只渲染 k 个可视项，时间复杂度为 $O(k)$，其中 $k \approx \lceil H/h \rceil$，$H$ 为容器高度，$h$ 为单项高度
