## 1. 产品概述

### 1.1 产品简介

**瞳伴（TongBan）** 是一款面向视障人士、低视力人群的智能出行导航 App，融合 AI 计算机视觉、自然语音交互和精准路径导航能力，为视障用户提供从家门到目的地的全流程安全出行陪伴。

当前版本为 **Demo 版本**，采用纯前端实现，包含 32 个独立屏幕、361 个功能函数、12 大功能模块，可作为完整功能演示与交互验证的载体。

### 1.2 核心价值

| 维度 | 价值主张 |
| --- | --- |
| 安全陪伴 | 实时盲道检测、危险预警、紧急求助、家人守护四重安全网 |
| 智能感知 | 30+ 中国特色路况 AI 识别，覆盖步行/公交/打车/室内全场景 |
| 极简交互 | Apple 极简设计 + 全局手势 + 语音播报三层反馈机制 |
| 双角色协同 | 视障用户与家人用户差异化 UI，远程守护一键直达 |
| 全程语音 | 唤醒词监听 + 状态播报 + 速度可调，弱化视觉依赖 |

### 1.3 目标用户

| 用户群体 | 画像描述 | 核心诉求 |
| --- | --- | --- |
| 主要用户：视障人士 | 全盲或低视力，使用读屏软件习惯者 | 独立安全出行、避障提示、最后一公里引导 |
| 主要用户：低视力人群 | 存在残余视力，需要大字体/高对比 | 清晰视觉提示、可放大阅读、语音辅助 |
| 次要用户：家人/监护人 | 视障用户的家人、志愿者、社区服务者 | 远程位置查看、围栏守护、紧急联络 |
| 关联用户：社区成员 | 路线分享者、危险标记上报者、出行贴士发布者 | 信息贡献、互助沟通、共建社区地图 |

### 1.4 设计理念

- **Apple 极简美学**：留白克制、信息层级清晰、动效自然流畅。
- **无障碍优先（Accessibility First）**：所有可操作元素具备 ARIA 属性，支持键盘与读屏操作。
- **三层反馈机制**：语音 + 震动 + 视觉同步反馈，确保信息触达。
- **角色差异化**：同一应用为视障用户与家人用户提供定制化界面与功能集。
- **场景化智能**：根据出行模式与进度节点自动启用 AI 识别，避免无效打扰。

## 3. 用户角色与权限

### 3.1 角色对比表

| 维度 | 视障用户（主要角色） | 家人用户（守护角色） |
| --- | --- | --- |
| 登录后默认页 | 首页（导航入口） | 家人守护页 |
| 角色注册可选 | ✅ | ✅ |
| 语音播报 | 启用，speak() 实际播报 | 禁用，speak() 调用被跳过 |
| 语音唤醒词 | "你好，瞳伴" | 不支持 |
| AI 摄像头识别 | 全功能 | 不可用 |
| 导航功能 | 全功能 | 仅查看被监护人位置并导航前往 |
| 安全围栏 | 仅查看自己被设置的围栏 | 创建/管理围栏 |
| 紧急求助 | 摇一摇触发 + 联系人呼叫 | 接收紧急通知 |
| 手势教程 | 显示完整教程 | 隐藏 |
| 语音唤醒按钮 | 首页显示 | 隐藏 |
| 设置项差异 | 语音/导航/AI摄像头/安全 | 守护/通知/通用 |
| 出行设置 | 语音播报、震动、盲道检测、危险预警 | 不展示 |
| 个人信息卡 | 实名认证入口 | 实名认证入口 |
| 数据统计卡片 | 累计出行/安全守护/紧急联系人/社区贡献 | 累计出行/安全守护/紧急联系人/社区贡献 |

### 3.2 角色切换

- 用户在登录时可选择角色；
- 切换角色后，App 自动重新生成对应角色的设置内容、首页布局与可见功能模块；
- 同一账号可同时绑定视障角色与家人角色（如低视力用户既是被监护人也是守护者）。

## 4. 功能模块详细需求

### 4.1 登录注册模块

#### 4.1.1 功能描述

提供完整的账号体系，支持视障用户与家人用户角色化登录、注册、找回密码、第三方登录及会话管理。家人版登录后默认进入家人守护页（非唤醒页）。

#### 4.1.2 功能列表与优先级

| 功能项 | 优先级 | 说明 |
| --- | --- | --- |
| 角色选择 | P0 | 视障用户 / 家人用户二选一，影响后续 UI 与权限 |
| 短信验证码登录 | P0 | 手机号 + 6 位验证码 |
| 密码登录 | P0 | 手机号 + 密码 |
| 快速登录 | P1 | 已登录设备本地 Token 一键登录 |
| 注册 | P0 | 手机号 + 验证码 + 密码 |
| 忘记密码 | P0 | 重置码 + 新密码 |
| 第三方登录 | P1 | 微信 / Apple ID / QQ / 支付宝 / 微博 |
| 用户协议 / 隐私政策 | P0 | 登录页可查看，注册需勾选同意 |
| 会话管理 | P0 | 本地存储 Token，启动自动登录 |
| 退出登录 | P0 | 清理本地会话，返回登录页 |
| 用户信息脱敏显示 | P0 | 手机号中间 4 位以 `****` 显示 |
| 家人版默认页 | P0 | 家人角色登录后默认进入家人守护页 |

#### 4.1.3 交互细节

- 角色选择卡片左右排布，选中态采用主色 `#007AFF` 描边；
- 验证码输入框为 6 格分离式，支持自动填充；
- 登录页底部提供"用户协议"与"隐私政策"链接，点击弹出底部 Sheet；
- 第三方登录按钮居中横排，每个按钮为圆形图标；
- 退出登录二次确认弹窗，避免误操作；
- 切换角色后，设置项与首页内容自动重新生成。

### 4.2 导航功能模块

#### 4.2.1 功能描述

提供从路线规划到实时导航、到达引导的全流程出行能力，覆盖步行、公交、打车、室内 4 种出行方式。融合盲道检测、路线偏离重算、最后一公里模式与到达模式，确保视障用户全程安全陪伴。

#### 4.2.2 功能列表与优先级

| 功能项 | 优先级 | 说明 |
| --- | --- | --- |
| 路线规划 | P0 | 起终点输入、目的地搜索建议、键盘导航 |
| 4 种出行方式 | P0 | 步行 / 公交 / 打车 / 室内 |
| 路线卡片展示 | P0 | 时间、距离、步骤、标签 |
| 路线选择高亮 | P1 | 选中路线卡片描边 + 主色填充 |
| 危险标记检查 | P0 | 导航前自动检查社区危险标记 |
| 实时导航 | P0 | 语音播报、进度条、距离显示 |
| 盲道偏离检测 | P0 | 摄像头检测 + 连续语音指引 + 自动纠正 |
| 路线偏离重算 | P0 | 自动重新规划 |
| 最后一公里模式 | P0 | 85% 进度触发，步阶式指引 |
| 暂停 / 恢复 / 结束 | P0 | 控制面板按钮暂停、右滑 / 按钮结束 |
| 到达模式 | P0 | 环境描述、入口指引、附近 POI、AI 摄像头辅助 |
| 室内楼层导航 | P1 | 楼层选择器、POI 列表、商场/医院楼层地图 |
| 单击播报当前进度 | P1 | 不暂停导航 |
| 双击重播当前指令 | P1 | 重播当前语音指令 |
| 右滑直接结束 | P0 | 返回首页 |

#### 4.2.3 交互细节

- 导航开始后自动进行，不自动暂停；
- 控制面板默认半透明底部固定，包含暂停 / 结束按钮；
- 进度条采用主色填充，剩余距离实时更新；
- 盲道偏离检测触发连续语音（间隔 1.5s）指引"请向左/右调整"；
- 最后一公里触发时切换为步阶式卡片，每完成一步自动进入下一步；
- 到达模式启动结构化语音播报：目的地确认 → 环境描述 → 入口位置 → 操作提示；
- 室内楼层导航支持楼层选择器（上下箭头切换），POI 列表垂直滚动；
- 单击导航页播报当前进度，不触发暂停；
- 双击导航页重播当前语音指令；
- 右滑导航页直接结束导航并返回首页。

### 4.3 AI摄像头识别模块

#### 4.3.1 功能描述

通过摄像头实时识别前方路况，覆盖 30+ 中国特色场景，支持 4 级危险预警与场景模式自动启用策略，为视障用户提供"第三只眼"。

#### 4.3.2 功能列表与优先级

| 功能项 | 优先级 | 说明 |
| --- | --- | --- |
| 摄像头开启 / 关闭 | P0 | 用户可手动开关 |
| 自动开启策略 | P0 | 按出行模式和进度节点自动启用 |
| AI 识别框 | P0 | 多目标检测，实时框选 |
| 识别结果展示 | P0 | 文字 + 标签 |
| 30 种路况识别 | P0 | 见下表 |
| 危险预警覆盖层 | P0 | 4 级：low / medium / high / critical |
| 场景模式识别 | P0 | 步行 / 打车找车 / 公交上车 / 地铁入口 / 室内入口 |
| AI 语音提示 | P0 | 识别结果实时语音播报 |
| 非导航时识别 | P1 | 行人、台阶、水坑、障碍物、盲道 |
| 步行导航识别 | P0 | 盲道状态、红绿灯、电动车、坑洞、开门危险、施工围栏 |
| 摄像头开启播报 | P0 | "摄像头已开启，正在识别前方环境，识别结果会实时播报" |
| 左滑打开摄像头 | P0 | 全局手势随时触发 |

#### 4.3.3 30 种路况识别清单

| 类别 | 识别项 |
| --- | --- |
| 行人相关 | 行人、人群、儿童 |
| 路面相关 | 台阶、水坑、坑洞、井盖、坡道、盲道状态（连续/中断/偏移） |
| 障碍物 | 静态障碍物、施工围栏、共享单车、垃圾桶 |
| 交通信号 | 红绿灯（红/绿/黄）、斑马线 |
| 车辆相关 | 电动车、机动车、停车车辆、开门危险 |
| 室内相关 | 电梯、扶梯、楼梯、玻璃门、旋转门 |
| 场景标识 | 商场入口、医院入口、地铁入口、公交站牌、出租车 |

#### 4.3.4 场景模式自动启用策略

| 出行模式 | 触发进度 | 识别重点 |
| --- | --- | --- |
| 步行 | 开始即启用 | 盲道状态、红绿灯、电动车、坑洞、开门危险、施工围栏 |
| 打车 | 30%–50% | 网约车找车、车牌识别 |
| 公交 | 20%–40% | 车辆识别、上车门 |
| 地铁 | 5%–30% | 地铁入口 |
| 室内 | 0%–30% | 入口、电梯、扶梯 |

#### 4.3.5 危险预警等级

| 等级 | 颜色 | 触发场景 | 反馈强度 |
| --- | --- | --- | --- |
| low | 绿色 | 信息提示（如斑马线、商场入口） | 语音播报 |
| medium | 黄色 | 一般注意（如行人、台阶） | 语音 + 轻震动 |
| high | 橙色 | 较强注意（如电动车、施工围栏） | 语音 + 强震动 |
| critical | 红色 | 紧急危险（如开门危险、坑洞临近） | 语音 + 强震动 + 全屏预警 |

#### 4.3.6 交互细节

- 摄像头开启时全屏播报固定文案；
- 识别框采用半透明主色描边，标签悬浮于框上方；
- 预警覆盖层为全屏半透明蒙版，critical 级别含震动 + 语音双重提醒；
- 左滑手势随时可打开摄像头，不依赖当前页面。

## 6. 无障碍功能规范

### 6.1 ARIA 属性要求

| 元素类型 | 必需 ARIA 属性 |
| --- | --- |
| 按钮 | `role="button"`、`aria-label`、`tabindex` |
| 链接 | `role="link"`、`aria-label`、`tabindex` |
| 输入框 | `aria-label`、`aria-placeholder`、`aria-required` |
| 列表 | `role="list"`、子项 `role="listitem"` |
| 对话框 | `role="dialog"`、`aria-modal="true"`、`aria-labelledby` |
| 进度条 | `role="progressbar"`、`aria-valuenow`、`aria-valuemin`、`aria-valuemax` |
| 实时区域 | `aria-live="polude"` 或 `assertive`、`aria-atomic="true"` |
| 图标按钮 | 必须有 `aria-label` 描述功能 |

### 6.2 键盘导航

| 按键 | 行为 |
| --- | --- |
| Tab | 焦点顺序前进 |
| Shift + Tab | 焦点顺序后退 |
| Enter / Space | 激活当前焦点元素 |
| 方向键 ↑ ↓ | 列表内移动 |
| 方向键 ← → | Tab 切换 / 卡片切换 |
| Esc | 关闭对话框 / 取消操作 |

### 6.3 ARIA Live 区域

- 全局隐藏 div，id="aria-live-region"；
- `aria-live="polude"` 默认，紧急信息切换为 `assertive`；
- 写入内容后自动触发屏幕阅读器播报；
- 与语音播报模块联动，确保信息一致性。

### 6.4 焦点管理

- `showScreen` 函数增强：页面切换后焦点自动转移至新页面首个可交互元素；
- 对话框打开后焦点锁定在对话框内；
- 对话框关闭后焦点返回触发元素；
- 焦点框样式：2px 主色描边 + 4px 透明偏移。

### 6.5 三层反馈机制

| 层级 | 反馈方式 | 触发场景 |
| --- | --- | --- |
| 视觉 | 状态变化、动画、Toast | 所有操作 |
| 震动 | 短震动 / 长震动 / 模式震动 | 关键操作、危险预警 |
| 语音 | speak() 播报 | 视障版所有关键操作、危险预警、导航状态 |

### 6.6 颜色与对比度

- 文本与背景对比度 ≥ 4.5:1（WCAG AA 标准）；
- 焦点框对比度 ≥ 3:1；
- 不依赖颜色单独传递信息（如危险等级同时使用颜色 + 文字 + 图标）。

### 7.1 用户数据（User）

```typescript
interface User {
  id: string;              // 用户唯一 ID
  phone: string;          // 手机号（脱敏显示）
  name: string;           // 用户名
  avatarColor: string;    // 头像颜色（#RRGGBB）
```

### 7.2 路线数据（Route）

```typescript
interface Route {
  id: string;
  mode: 'walk' | 'bus' | 'taxi' | 'indoor'; // 出行方式
  start: { name: string; lat: number; lng: number };
  end: { name: string; lat: number; lng: number };
  duration: number;        // 预计时长（秒）
  distance: number;        // 距离（米）
  steps: RouteStep[];      // 步骤列表
  tags: string[];          // 标签（如"无障碍"、"少台阶"）
  isHighlighted?: boolean; // 是否高亮选中
}

interface RouteStep {
  index: number;
  instruction: string;    // 指令文案
  distance: number;        // 该段距离
  duration: number;         // 该段时长
  type: 'walk' | 'bus' | 'taxi' | 'transfer';
}
```

## 8. 非功能需求

### 8.1 性能

| 指标 | 要求 |
| --- | --- |
| 首屏加载时间 | ≤ 3s（4G 网络） |
| 页面切换响应 | ≤ 300ms |
| 语音播报延迟 | ≤ 500ms（自触发到发声） |
| AI 识别响应 | ≤ 1s（单帧识别） |
| 手势识别延迟 | ≤ 100ms |
| 内存占用 | ≤ 200MB（含摄像头流） |
| 滚动帧率 | ≥ 50fps |

### 8.2 兼容性

| 维度 | 要求 |
| --- | --- |
| 操作系统 | iOS 13+、Android 8.0+ |
| 浏览器 | Safari 14+、Chrome 90+、Edge 90+ |
| 屏幕阅读器 | VoiceOver、TalkBack 完整支持 |
| 设备类型 | 手机为主，平板适配 |
| 屏幕尺寸 | 4.7"–6.7" 主流尺寸 |
| 横竖屏 | 默认竖屏，不强制横屏 |

### 8.3 安全

| 维度 | 要求 |
| --- | --- |
| 数据传输 | 全链路 HTTPS，敏感字段加密 |
| 本地存储 | Token 加密存储，敏感信息不落盘明文 |
| 用户隐私 | 手机号脱敏显示，位置数据用户授权后采集 |
| 第三方登录 | OAuth 2.0 标准，不存储第三方密码 |
| 围栏数据 | 仅用户本人与被授权家人可见 |
| 紧急求助 | 求助记录仅用户本人与紧急联系人可见 |
| 数据导出 | 用户可一键导出个人数据（GDPR 兼容） |
| 会话超时 | 30 天无操作自动登出 |

### 8.4 可用性

- 单手操作友好：主要操作集中在屏幕下半部分；
- 误触防护：危险操作（如退出登录、结束导航）需二次确认；
- 离线降级：网络不可用时保留本地缓存路线与常用地址；
- 容错性：手势误触发可撤销（如紧急求助 3 秒倒计时）。
