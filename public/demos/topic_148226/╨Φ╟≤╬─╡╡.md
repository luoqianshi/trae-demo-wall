# 人生轨迹 - 旅行记录可视化平台需求文档

## 1. 项目概述

### 1.1 项目背景
「人生轨迹」是一款帮助用户记录、整理和回顾旅行经历的可视化平台。用户可以通过录入旅行信息，在地图上生成个人专属的旅行轨迹，并以相册和时光回放等多种方式回顾旅途故事。

### 1.2 核心价值主张
> 把每一步，变成一生的故事

### 1.3 目标用户
- 热爱旅行的个人用户
- 希望记录生活足迹的用户
- 追求个性化回顾体验的用户

## 2. 产品功能需求

### 2.1 首页（index.html）

| 功能模块 | 描述 | 交互说明 |
|---------|------|---------|
| Hero 区域 | 品牌展示，标题「把每一步，变成一生的故事」 | 渐入动画效果 |
| 核心功能介绍 | 三大核心功能卡片：动态地图轨迹、时间轴回放、智能行程录入 | 悬停动画，卡片上浮 |
| 使用步骤指引 | 三步引导：录入行程 → 生成轨迹 → 时光回放 | 滚动触发渐显效果 |
| 品牌语录 | 旅行主题语录展示 | 居中展示，优雅排版 |

### 2.2 轨迹地图（map-timeline.html）

| 功能模块 | 描述 | 交互说明 |
|---------|------|---------|
| 世界地图展示 | 带背景图的地图，标记用户去过的城市 | 响应式地图缩放 |
| 城市标记点 | 在地图上标记旅行城市位置 | 点击高亮，脉冲动画 |
| 城市信息卡片 | 悬停显示城市名称、日期、描述、照片数量 | 气泡式卡片，箭头指示 |
| 路线连接线 | SVG 曲线连接各城市轨迹 | 虚线流动动画 |
| 旅行统计数据 | 四个统计卡片：走过的城市、旅行次数、总行程、旅途照片 | 数字展示 |
| 时间轴控制 | 播放/暂停按钮，进度条，城市节点 | 自动播放，手动跳转 |
| 旅途足迹列表 | 横向滚动的城市卡片列表 | 点击联动地图高亮 |

### 2.3 录入行程（trip-entry.html）

| 功能模块 | 描述 | 交互说明 |
|---------|------|---------|
| 面包屑导航 | 当前位置导航 | 点击返回上一页 |
| 基本信息表单 | 出发日期、返回日期、城市/地点 | 日期选择器，城市标签快捷选择 |
| 交通方式选择 | 5种交通方式：飞机、高铁、自驾、大巴、步行/骑行 | 卡片式选择，单选 |
| 照片上传区域 | 拖拽上传或点击选择文件 | 拖拽高亮效果 |
| 行程备注 | 文本输入，最多500字 | 实时字符计数 |
| 迷你地图预览 | 展示已有轨迹和新添加的城市位置 | 动态更新 |
| 时间轴预览 | 展示已有行程和新行程预览 | 实时更新 |
| 表单验证 | 必填项校验，日期逻辑校验 | Toast 提示错误信息 |
| 保存操作 | 保存行程 / 保存并继续添加 / 取消 | 保存成功 Toast 提示 |

### 2.4 旅途相册（album.html）

| 功能模块 | 描述 | 交互说明 |
|---------|------|---------|
| 相册统计 | 照片数量、城市数量、时光跨度 | 数字展示 |
| 精选推荐横幅 | 全屏横幅展示精选照片 | 渐变遮罩 |
| 筛选功能 | 按年份、城市、交通方式筛选 | 侧边栏筛选面板 |
| 排序功能 | 日期从新到旧、日期从旧到新、按城市排序 | 下拉选择 |
| 视图切换 | 网格视图 / 时间轴视图 | 切换动画 |
| 网格视图 | 瀑布流布局展示照片卡片 | 悬停旋转效果 |
| 时间轴视图 | 按年份分组展示照片 | 年份分隔线 |
| 照片卡片 | 拍立得风格，显示城市、日期 | 城市 Emoji 图标 |
| 底部统计栏 | 照片总数、城市数量、旅行次数、总行程 | 数字展示 |
| 时光回放入口 | 跳转至回放页面 | 渐变按钮 |

### 2.5 时光回放（playback.html）

| 功能模块 | 描述 | 交互说明 |
|---------|------|---------|
| 全屏沉浸式体验 | 暗色主题，背景图片模糊处理 | 背景缩放动画 |
| 顶部导航 | 返回按钮、标题、设置按钮 | 毛玻璃效果 |
| 章节列表（侧边栏） | 按顺序展示各旅行章节 | 点击跳转，进度状态 |
| 章节内容展示 | 当前章节的年份、季节、城市、语录 | 渐入动画 |
| 拍立得照片 | 右侧拍立得风格照片展示 | 旋转动画，悬停放大 |
| 底部时间轴 | 所有章节节点，进度条 | 点击跳转节点 |
| 播放控制 | 上一章节、播放/暂停、下一章节 | 按钮交互 |
| 键盘快捷键 | Space 播放/暂停，←上一章，→下一章 | 键盘事件监听 |

## 3. 数据模型

### 3.1 行程数据（TRIP_DATA）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |

| startDate | string | 出发日期（YYYY-MM-DD） |
| endDate | string | 返回日期（YYYY-MM-DD） |

## 5. 交互体验需求

### 5.1 动画效果

| 动画名称 | 触发条件 | 效果描述 |
|---------|---------|---------|
| 滚动渐显 | 元素进入视口 | opacity 0→1，translateY 24px→0 |
| 卡片悬停 | 鼠标悬停卡片 | translateY -4px，阴影加深 |
| 地图点脉冲 | 加载完成 | 同心圆向外扩散 |
| 路线流动 | 地图加载 | 虚线流动动画 |
| 拍立得旋转 | 悬停照片卡片 | 轻微旋转效果 |
| Toast 提示 | 操作反馈 | 顶部滑入，2.5秒后消失 |
| 章节切换 | 播放/点击章节 | 内容渐入，拍立得弹入 |

### 5.2 响应式适配

| 断点 | 宽度 | 适配策略 |
|------|------|---------|
| 桌面端 | >1024px | 完整布局，多列显示 |
| 平板端 | 768px-1024px | 双列布局，部分元素缩小 |
| 移动端 | <768px | 单列布局，隐藏侧边栏，调整字体大小 |

### 5.3 无障碍支持

- 语义化 HTML 结构
- 焦点状态可见
- 键盘导航支持（时光回放页面）
- 对比度符合 WCAG 标准

## 7. 性能要求

- 首屏加载时间 < 2秒
- 图片懒加载（可扩展）
- CSS 动画流畅，无卡顿
- 响应式布局切换无缝

- 静态网站部署
- 支持本地开发服务器（Python HTTP Server）
- 无需后端依赖
