【标题】生活娱乐 · AI 兴趣探索伙伴

【正文】

### 1. Demo 简介

- **是什么**：一款面向年轻人的兴趣探索 Web 应用，融合二次元虚拟角色陪伴与游戏化技能树系统，帮助用户发现和梳理自己的兴趣方向。
- **面向谁**：感到无聊、想尝试新事物但不知从何入手的 16-30 岁年轻群体。
- **主要功能**：
  - **AI 角色陪伴对话**：二次元角色"小樱"通过聊天对话推荐兴趣活动，用户输入活动名称即可解锁技能树中对应的最小单元，实现"聊着天就探索了兴趣"；
  - **三维度兴趣思维导图**：从感官通道、心理需求、功能导向三个互补视角，以无限画布思维导图展示 67 个兴趣最小单元，每个标签带锁图标，点击解锁并在三个分类间联动同步；
  - **游戏化解锁机制**：最小单元初始锁定，通过聊天输入名称或在思维导图中点击逐个解锁，营造探索成就感。

### 2. Demo 创作思路

- **灵感来源**：很多人说"我不知道自己喜欢什么"，但兴趣不是凭空想出来的，而是需要被"看见"和"激发"。现有的兴趣测试都是问卷式、一次性的，缺乏持续探索的引导。
- **想解决的问题**：用户有探索兴趣的意愿，但缺乏一个能持续引导、分类梳理、且有正向反馈的工具。
- **为什么做这个方向**：将"兴趣探索"本身做成一个有游戏化体验的产品，用 AI 对话降低使用门槛，用多维分类帮助用户建立对兴趣的结构化认知，而非单一标签式的定义。

### 3. 技术实现

- **纯前端单页应用**：零依赖框架，一个 HTML 文件 + 一个 JSON 数据文件 + CSS 设计系统，打开即用；
- **无限画布思维导图**：绝对定位 + CSS Transform 实现拖拽平移和滚轮缩放，SVG 贝塞尔曲线连线与 DOM 节点共用像素坐标系，三个画布各自独立维护视图状态；
- **数据驱动**：67 个最小单元内容存储在外部 JSON 文件中，HTML 通过 Fetch API 动态加载，修改内容无需改动页面代码；
- **跨分类联动解锁**：使用 Set 数据结构记录已解锁标签，在任一分类中解锁"蹦极"，三个分类画布中所有"蹦极"标签同步解锁。

### 4. 创新亮点

- **对话即探索**：聊天框不再是独立功能，而是与技能树联动的入口。用户和小樱聊天时输入兴趣活动名称，直接解锁技能树中对应单元，打通了"对话"与"探索"的边界；
- **三维分类全覆盖**：三个分类维度（感官通道 / 心理需求 / 功能导向）各有侧重且互补，每个维度都覆盖全部 67 个最小单元，让同一个活动在不同视角下被重新理解；
- **游戏化渐进式披露**：锁图标显示在每个最小单元上，解锁过程给予持续的微小成就感，而非一次性展示所有内容造成信息过载。
