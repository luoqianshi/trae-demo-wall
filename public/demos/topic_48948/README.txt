DevEnv Inspector - 演示报告
============================

本压缩包包含一份独立的 HTML 演示报告，内嵌真实环境扫描数据。

使用方式：
  解压后双击 index.html，用浏览器打开即可查看完整报告。

报告内容：
  1. 概览：8 大类 55 项检测统计 + 类别分布 + 平台信息
  2. 工具详情：可按类别/安装状态/关键字筛选
  3. 数据库：四层深度检测（服务端/客户端/端口/服务状态）+ 智能问题分析
  4. PATH 分析：失效/重复/版本冲突检测 + 工具归属标注
  5. 版本升级：联网比对最新版本，标记可升级/已 EOL

数据来源：在一台 Windows 11 开发机上用 DevEnv Inspector v0.1 真实扫描采集。
扫描耗时约 2-4 秒，全部数据均为真实检测结果。

技术栈：Flask 后端 + 原生 JS 前端，零第三方依赖（除 Flask）。
开发工具：TRAE IDE。
