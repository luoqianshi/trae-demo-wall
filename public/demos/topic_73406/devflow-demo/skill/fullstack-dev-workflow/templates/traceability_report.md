# 可追溯性报告标准结构

每阶段产出的 `*_可追溯性报告.md` 必须包含以下四个部分：

## 1. 输入引用清单
列出本阶段读取的所有输入文件（绝对/相对路径）。

## 2. 输出 → 输入映射表
以表格形式展示每一项产出对应引用了输入文档中的哪一节/哪一条。

示例：
| 输出项 | 关联输入 |
|--------|----------|
| REQ-001 用户登录 | 需求规格说明书.md 第3.1节 |
| API: POST /auth/login | API设计文档.md 第4.2节 |
| DB: users, sessions | 数据库设计文档.md 第5.1节 |

## 3. 符合项核对清单（✅/❌）
- [ ] 是否符合项目需求
- [ ] 是否依据指定需求点（列出具体编号）
- [ ] 是否符合架构设计
- [ ] 是否符合 API 设计（若适用）
- [ ] 是否符合数据库设计（若适用）

## 4. 差异与风险
列出输入中尚未被本阶段产出覆盖的点、潜在风险。
