# 原页记 NovelMemo · 初赛演示 Demo

一个**纯前端、无后端**的可交互 demo，用于初赛现场演示核心功能模块。

## 怎么打开

**最简单**：双击 `novelmemo-demo.html`，用浏览器打开即可。

**或者**（推荐，本地起服务避免某些限制）：

```bash
cd d:\讯飞实习\yuanyeji\demo
python -m http.server 8080
# 浏览器访问 http://localhost:8080/novelmemo-demo.html
```

## 演示流程（5–7 分钟）

1. **首页** — 介绍"原页记 = 英文原版书 + AI 每页复盘"
2. **进入《小王子》** — 点"立即体验"或书架卡片
3. **双栏阅读** — 左英文右中文
4. **生词高亮 + 查词典** — 点黄色/红色单词，弹出悬浮词典，可收藏
5. **翻页** — 展示"AI 翻译"loading → 落地
6. **点"复盘"** — 弹出本页总结 + 出场人物
7. **点"关系"** — 弹出人物关系图（6 个角色 + 6 条关系）
8. **切词汇等级** — 顶部下拉切到 A2/C1，观察高亮数量变化
9. **切暗色主题** — 右上角 🌙 按钮

## 包含什么

- **4 本示例书**：《小王子》6 页 /《爱丽丝》4 页 /《秘密花园》4 页 /《傲慢与偏见》4 页
- **6 个角色** + **6 条关系**（小王子相关）
- **50+ 生词**，每个都有音标、词性、释义
- **3 个页面**：首页 / 阅读页 / 生词本
- **4 个核心交互**：词汇等级切换、暗色主题、生词点击查词典、收藏到生词本
- **3 个 mock AI**：翻页翻译 loading、复盘弹层、关系图
- **localStorage 持久化**：收藏的词刷新还在

## 全部都是本地 mock

- 词典：内置 `DICT` 对象（~50 词），**非真实有道/Oxford**
- 翻译：内置中文段落，**非真实 AI 生成**（仅模拟 loading 1.2s）
- 复盘：内置 summary + 角色数据，**非真实 AI 提取**
- 关系图：内置 6 条关系，**非真实 AI 分析**

## 局限

- 只有 1 本书（《小王子》）有完整角色和关系；其他 3 本只有文本
- 不能上传新书（弹个 alert 提示）
- 数据全在浏览器本地，换浏览器/清缓存就丢
- TTS 用浏览器内置 speechSynthesis（需联网或本地有语音包）
