# CosLens · 二次元角色美瞳还原推荐

上传二次元角色图 → AI 识别眼睛的美瞳视觉特征（瞳色主色 / 显色度 / 直径 / 风格）
→ 从真实美瞳商品库匹配并推荐 Top-3，并给出推荐理由。

## 快速开始（评审推荐方式 · 无需 API Key）

1. 直接**双击 `index.html`**，用浏览器打开（Chrome / Edge 均可），无需安装任何环境、无需启动服务器。
2. 点击 **「示例特征测试」** 按钮 —— 立即走通「识别特征 → 匹配 → Top-3 推荐 + 理由」完整链路。
3. 也可以点「点击选择 / 拖入」上传 `assets/samples/` 里的示例角色图，再点「开始分析」。
   - 未配置 API Key / 未启动本地服务时，「开始分析」会**自动降级为示例特征**演示，不会报错。

## 可选：启用真实 AI 识别（本包已内置 Key，开箱即用）

真实多模态识别需要一个本地代理（浏览器不能直连大模型、也不应在前端暴露 Key）。
**本包已内置 `api-key.txt` 和上游地址，无需额外配置：**

1. 在 `CosLens/` 目录运行 `python server.py`（仅用 Python 标准库，无需 pip 依赖）。
2. 浏览器打开 `http://127.0.0.1:8123/`，上传角色图 → 「开始分析」即走真实 AI，
   状态显示「分析完成」即为真实识别（而非降级示例）。
3. 想换 Key：直接编辑 `api-key.txt`；想换模型：在 `config.js` 设 `window.COSLENS_MODEL`；
   想换上游地址：改 `server.py` 的 `UPSTREAM`（或设环境变量 `COSLENS_BASE_URL`）。

> ⚠️ 安全提示：本包内的 `api-key.txt` 含真实密钥，请勿公开分享/上传公网；演示结束后建议到平台重置该 Key。

## 目录结构

```
CosLens/
├── index.html          # 入口，双击即可运行
├── style.css           # 样式
├── config.js           # 前端可选配置（不含 Key）
├── match.js            # 匹配打分（纯函数）
├── ai.js               # 多模态调用（经本地代理，可选）
├── main.js             # 主流程编排
├── server.py           # 可选：本地代理，启用真实 AI 时使用（内置上游地址）
├── api-key.txt         # 真实 AI 用的 API Key（已内置，可自行替换）
├── data/
│   ├── products.js     # 内嵌商品库（供双击离线加载）
│   ├── products.json   # 商品库数据源
│   └── README.md       # 数据字段说明
└── assets/
    ├── products/       # 25 款美瞳商品图
    └── samples/        # 示例角色图（可上传体验）
```
