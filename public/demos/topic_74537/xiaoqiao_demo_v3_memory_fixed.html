小桥·AI亲子沟通翻译助手
让孩子说得出自己，让父母听得懂孩子，让爱在日常里被正确表达。
当孩子或家长有情绪、有压力、有困惑、有说不清的话时，可以找小桥聊一聊。
当前 Demo 为体验版，通过前端规则模拟小桥的核心交互流程；后续可接入教育成长与家庭沟通知识库，生成更个性化建议。
💡 核心定位：小桥不是医疗或心理诊断工具，不替代专业服务。它提供的是家庭日常沟通支持、表达整理和关系提醒。

💭 孩子想说，但不知道怎么说
描述孩子的状态或孩子说过的话，小桥会帮忙"翻译"出孩子真正想表达的内容，并给出几种可以说出口的表达方式。
🤲 家长想帮，但不知道怎么说
你想帮孩子，但不知道怎么开口、怕说错话。小桥会帮你找到更合适的表达方式。
👁️ 家长观察端
你注意到孩子最近有些变化或行为让你担心。小桥不会贴标签，而是帮你从"需要被理解"的角度来看这些信号。
🌊 刚刚吵架了，帮我们复盘
描述刚才发生了什么，小桥会帮你翻译双方的情绪和需求，找到一个可以重新开口的方式。
🔍 成长记忆洞察
小桥会根据近期的亲子沟通记录，帮助家庭看见正在重复出现的情绪、表达方式和误解点，并给出下一周可以尝试的沟通建议。它不是为了评价谁对谁错，而是帮助家庭在冲突变严重前，更早调整表达方式。
1. 不只处理冲突，也支持日常情绪表达小桥不只是"吵架了才用"的工具，孩子在日常中有困惑、有压力、有说不清的感受时，都可以来找小桥。
2. 同时支持孩子端、家长端、家长观察端不同角色有不同需求，小桥提供多个入口，让每个家庭成员都能找到适合自己的方式。
3. 通过"小桥翻译卡"把情绪、需求和表达方式可视化翻译卡把隐藏在冲突背后的情绪、需求和表达方式清晰呈现出来，让双方都能被看见。
4. 通过成长记忆，让建议越来越贴合具体家庭每次对话都会被记录，小桥会根据积累的记忆，给出更贴合这个孩子、这个家庭的建议。
5. 小桥不给标准答案，而是一步步更贴合先提供可选表达，再允许家长补充家庭情况，让建议一步步更贴合这个孩子、这个家庭。
6. 成长记忆不只是记录过去，而是提前看见沟通风险通过洞察近期反复出现的情绪和误解模式，小桥帮助家庭在冲突变严重之前就做出调整，给出可直接执行的沟通建议。
⚠️ 安全边界说明：小桥不是医疗或心理诊断工具，不替代专业服务。它提供的是家庭日常沟通支持、表达整理和关系提醒。如果家庭遇到超出日常沟通支持范围的复杂情况，建议及时寻求线下专业人士或可信赖成年人帮助。
