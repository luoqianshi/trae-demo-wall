```
# 多邻国风格 H5 英语单词学习应用 - 完整开发需求

## 一、项目概述
开发一个单页 H5 英语单词学习应用，风格完全对标多邻国（Duolingo），具有强烈的游戏化、趣味性和沉浸式学习体验。应用采用纯前端技术实现，数据存储在 localStorage，无需后端。

## 二、技术栈
- HTML5 + CSS3 + Vanilla JavaScript（单文件或模块化均可）
- 响应式设计，优先适配移动端（375px-428px宽度），同时兼容平板和桌面端
- CSS 动画使用 CSS Keyframes + Transition，不使用外部动画库
- 图标使用 SVG 内联或 Font Awesome CDN
- 音效使用 Web Audio API 或简单的 HTML5 Audio（准备正确/错误/升级/完成等音效占位）

## 三、视觉风格（必须严格遵循）
1. **配色方案**：
   - 主色：#58CC02（多邻国绿）
   - 辅色：#1CB0F6（天空蓝）、#FF9600（活力橙）、#FF4B4B（错误红）、#FFD900（金币黄）
   - 背景：#F7F7F7（浅灰）、#FFFFFF（卡片白）
   - 文字：#3C3C3C（主文字）、#AFAFAF（次要文字）

2. **圆角风格**：所有按钮和卡片使用大圆角（12px-16px），主按钮使用 16px 圆角

3. **字体**：使用系统默认无衬线字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`，中文优先使用 PingFang SC / Microsoft YaHei

4. **吉祥物**：在页面顶部或加载页面放置一个可爱的猫头鹰（Owl）SVG 吉祥物，会根据学习状态变化表情（开心、难过、鼓励、庆祝）

## 四、核心功能模块

### 模块 A：用户系统与游戏化进度
1. **用户档案**：
   - 用户名、头像（预设 8 个卡通头像可选）
   - 总经验值（XP）、当前等级
   - 连胜天数（Streak）、宝石/金币数量
   - 已掌握单词数、学习天数

2. **每日目标**：
   - 用户可设置每日 XP 目标（10/20/30/50）
   - 环形进度条展示今日完成度
   - 完成每日目标时触发庆祝动画（彩带 + 猫头鹰跳舞）

3. **排行榜（模拟）**：
   - 展示本周学习排行榜，用户排在其中
   - 前三名有金/银/铜皇冠标识

### 模块 B：课程地图（主页）
1. **关卡地图**：
   - 采用垂直路径式关卡地图，类似多邻国的世界地图
   - 每个关卡是一个圆形节点，状态包括：未解锁（灰色）、可学习（彩色发光）、已完成（金色皇冠）
   - 关卡之间用虚线或实线连接
   - 当前关卡有脉动动画效果

2. **单元（Unit）结构**：
   - 课程分为多个单元（Unit 1: 基础问候、Unit 2: 家庭、Unit 3: 食物 等）
   - 每个单元包含 5-8 个关卡
   - 完成一个单元解锁下一个

3. **关卡类型标识**：
   - 普通关卡（书本图标）
   -  Boss 关卡（皇冠图标，难度更高，包含多种题型混合）
   - 复习关卡（循环箭头图标，巩固已学单词）

### 模块 C：学习界面（核心）
进入关卡后，全屏进入学习模式，采用卡片式一题一屏设计：

#### 题型 1：单词翻译选择
- 上方显示中文释义，下方 3-4 个英文选项卡片
- 点击选项后即时反馈：正确→绿色+音效，错误→红色抖动+显示正确答案
- 选项卡片点击时有按压效果（scale 0.95）

#### 题型 2：看图选词
- 显示一张图片（使用占位图或 emoji 代替真实图片），下方 4 个英文单词选项
- 图片区域使用圆角矩形，带轻微阴影

#### 题型 3：听音选义 / 看词选义
- 播放单词发音（使用 Web Speech API 的 speechSynthesis 实现，fallback 显示音标）
- 用户从 4 个中文释义中选择

#### 题型 4：单词拼写 / 补全
- 显示中文释义和乱序字母或字母空格
- 用户点击字母拼出单词，或输入框补全单词
- 提供提示按钮（花费 10 金币显示一个字母）

#### 题型 5：配对题（每课最后一题）
- 左侧 4 个英文单词，右侧 4 个中文释义
- 用户点击左右两侧进行连线配对
- 配对正确连线变绿色，错误时连线变红色并抖动

#### 题型 6：句子翻译（进阶）
- 提供乱序单词卡片，用户拖拽或点击排序组成正确英文句子
- 卡片可拖动，放置区域高亮

### 模块 D：学习过程中的交互细节
1. **生命值系统（Hearts）**：
   - 每关开始 5 颗心
   - 答错一题扣 1 心，心扣完则本关失败，可选择用宝石续命或重新开始
   - 心会随时间恢复（每 4 小时恢复 1 颗，离线也计时）

2. **即时反馈动画**：
   - 答对：选项变绿，出现大大的 "Correct!" 文字，+10 XP 飘字动画，猫头鹰开心表情
   - 答错：选项变红并左右抖动（shake 动画），出现 "Oops!" 和正确答案，猫头鹰难过表情
   - 连续答对 3 题触发 "Combo x3!" 火焰特效，XP 加成

3. **进度条**：
   - 屏幕顶部显示本课进度条，每答一题进度前进
   - 进度条颜色从橙到绿渐变

4. **连击与双倍积分**：
   - 连续答对触发连击计数器
   - 5 连击后进入 "双倍积分" 状态，持续 3 题

5. **跳过与提示**：
   - 右下角"提示"按钮：花费 20 金币显示一个提示
   - 右下角"跳过"按钮：花费 50 金币跳过本题（不得 XP）

### 模块 E：关卡结束与奖励
1. **结算页面**：
   - 完成关卡后全屏结算页
   - 显示获得的总 XP、是否正确率、用时
   - 星级评价：根据正确率给 1-3 星
   - 经验条增长动画，可能升级

2. **升级系统**：
   - 累计 XP 达到阈值升级
   - 升级时触发全屏庆祝：彩带动画、猫头鹰举奖杯、等级数字跳动放大
   - 升级奖励：+3 颗心、+50 金币、解锁新头像

3. **宝箱奖励**：
   - 连续完成 3 个关卡获得一个宝箱
   - 点击开箱动画（宝箱摇晃打开），随机获得金币、双倍 XP 卡、额外生命

### 模块 F：单词本与复习
1. **单词本**：
   - 所有学过的单词按单元分类
   - 每个单词显示：英文、音标、中文释义、例句
   - 标记掌握程度（生疏/熟悉/掌握）
   - 点击单词播放发音

2. **错题本**：
   - 自动收集答错的单词
   - 可进入"错题挑战"模式专项复习

3. **每日复习**：
   - 根据艾宾浩斯遗忘曲线推送需复习的单词
   - 复习模式采用快速闪卡（Flashcard）形式：正面英文，点击翻转显示中文

## 五、页面结构与路由（单页应用，Hash 路由）

1. **#/splash** - 启动页：猫头鹰 Logo + 应用名称，2秒后自动进入首页
2. **#/home** - 首页/课程地图：顶部用户信息栏 + 关卡地图
3. **#/lesson/:id** - 学习界面：全屏学习，顶部进度条+生命值
4. **#/lesson-result** - 关卡结算页
5. **#/profile** - 个人中心：统计图表、成就、设置
6. **#/wordbook** - 单词本
7. **#/shop** - 商店（用金币购买心、双倍卡、皮肤等，纯前端模拟）
8. **#/leaderboard** - 排行榜

## 六、动画与微交互要求

1. **页面过渡**：所有页面切换使用滑动过渡（slide），300ms，ease-out
2. **按钮交互**：所有可点击元素必须有 active 状态（scale 0.95 + 颜色加深）
3. **加载状态**：按钮点击后显示旋转加载器，防止重复提交
4. **浮动元素**：首页猫头鹰会偶尔眨眼、点头；完成关卡时猫头鹰跳跃
5. **成就弹出**：获得成就时从顶部滑入一个横幅，3秒后自动消失
6. **数字滚动**：XP、金币等数值变化时使用数字滚动动画

## 九、音效设计（使用 Web Audio API 生成简单音效，无需外部文件）

1. **正确音**：高频率短促的"叮"声（C5 音符，100ms）
2. **错误音**：低频率"嘟"声（A3 音符，200ms）
3. **点击音**：极短促的"嗒"声（类似气泡音）
4. **升级音**：上行音阶（C4-E4-G4-C5，快速连续）
5. **完成音**：胜利和弦（C4-E4-G4 同时播放，500ms）
6. **心恢复音**：柔和的"啵"声
