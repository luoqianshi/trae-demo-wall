今天吃什么 HTML 演示包

打开方式一：直接打开
1. 进入 interactive-html 文件夹
2. 双击 index.html

打开方式二：本地服务预览（推荐）
1. 双击 start-preview.bat
2. 浏览器访问 http://127.0.0.1:5180/interactive-html/

说明：
- 这是纯前端演示版，不需要微信开发者工具。
- 数据保存在浏览器 localStorage 中，刷新后仍会保留。
- 包内包含菜品图片资源，保持 assets 和 interactive-html 在同一级目录即可。
- 此演示包不包含微信云开发密钥和后台管理配置。
