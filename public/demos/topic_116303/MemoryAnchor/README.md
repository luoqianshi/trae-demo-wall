# Memory Anchor

> Local-first smart bookmark manager for knowledge workers

## Development

### Prerequisites

- Node.js >= 18
- npm >= 9

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Distribution

```bash
npm run dist
```
