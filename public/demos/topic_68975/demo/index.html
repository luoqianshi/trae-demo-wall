OffDiff

Office 文档结构化解析工具 · 保留格式的 Git Diff 方案

什么是 OffDiff？

OffDiff 是一个用 Rust 编写的跨平台命令行工具，能够将 .docx 文档解析为结构化 JSON 数据，同时保留文本内容和格式信息（标题、粗体、斜体、字号、字体等），解决 Git 无法有意义地对比 Office 文档的问题。

DOCX 解析 样式提取 JSON 输出 Rust + WebAssembly

在线体验

上传一个 .docx 文件，立即查看解析结果。所有处理在浏览器本地完成，文件不会上传到服务器。

技术亮点

                

                    

                        
🦀

                        
Rust 实现

                        
使用 Rust 编写，高性能、内存安全、零依赖 Microsoft Office，支持 Windows/macOS/Linux 跨平台编译。

                    

                    

                        
⚡

                        
WebAssembly

                        
通过 Wasm 将 Rust 代码编译到浏览器端运行，无需服务器，解析完全在本地完成，保护文档隐私。

                    

                    

                        
📄

                        
结构化解析

                        
基于 Office Open XML 标准，流式解析 word/document.xml，提取段落级和运行级样式信息。

                    

                    

                        
🔧

                        
Git 集成

                        
可作为 Git textconv/diff driver 使用，让 Office 文档的版本变更在 Git 中清晰可见。
