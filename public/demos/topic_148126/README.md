# VibeX - AI 技能需求撮合平台 | 交互式 Demo

## 简介

VibeX 是一个 AI Native 的技能需求撮合平台，让非技术背景的需求方通过自然语言描述业务目标，AI 自动生成完整项目方案并推荐合适的 AI Builder。

**本包是比赛提交用静态交互 Demo，不依赖后端和数据库，解压后双击 `index.html` 即可体验。**

## 使用方式

1. 解压 `vibex-html-demo.zip`
2. 双击 `index.html` 在浏览器中打开
3. 不需要启动任何服务、不需要安装任何依赖

## 演示流程

### Step 1: 输入需求
- 页面默认填入示例需求「我要做客服机器人」
- 可以编辑输入框内容，或点击「使用演示需求」恢复默认
- 点击「生成 AI 需求蓝图」按钮

### Step 2: AI 生成蓝图
- 等待 1-2 秒，AI 完成需求分析
- 左侧展示 AI 需求诊断卡（行业、核心目标、痛点、推荐方向、涉及能力）
- 右侧展示完整蓝图：
  - 需求分类（AI客服Agent）
  - 技术方案
  - 技能标签
  - 预算范围 / 开发周期 / 复杂度
  - 技术蓝图节点
  - 任务拆解（5 个子任务）
  - 推荐 Builder（3 位，带匹配分数和理由）

### Step 3: 一键转化为项目
- 点击蓝图底部的「一键转化为悬赏任务」
- 页面切换到项目详情视图
- 完整展示：诊断卡、技术方案、指标、蓝图、任务拆解、推荐 Builder
- 在右侧推荐 Builder 区域，点击「用 XX 身份接单」可模拟接单

### Step 4: Builder 工作台
- 点击顶部导航「Builder 工作台」
- 当前身份：林澈（企业知识库与 RAG 应用专家）
- 展示四列指标：推荐项目数、平均匹配度、可接预算、进行中项目
- 展示推荐项目卡片：匹配分数、预算、周期、AI 推荐理由、技能标签
- 点击「申请接单」，按钮变为「已申请」
- 左下角出现进行中项目
- 右侧 AI Match Insight 展示余弦相似度和适配度条形图

## 技术说明

- 纯静态 HTML / CSS / JavaScript，无构建步骤
- 不依赖 React、Next.js 或任何框架
- 不访问任何 API 或数据库
- 所有数据写死在 `app.js` 中
- 字体使用 Google Fonts（Space Grotesk + JetBrains Mono），需联网加载

## 风格

- 深色科技感背景（#0B0F19）
- 玻璃拟态卡片（backdrop-blur + 半透明）
- 霓虹青色 #00F2FE + 电光紫 #7F00FF 渐变
- AI Native SaaS 风格
