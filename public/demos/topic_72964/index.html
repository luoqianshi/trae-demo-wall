CORE VALUE

它不是诊断工具，是日常沟通的翻译器

回声卡片不替代心理咨询，也不评判谁对谁错。它只是帮你把没说出口的情绪翻译成对方能听懂的话，把伤人的话改成能被听懂的话。

01

减少误会

看懂文字背后的真实情绪与需求，不再各说各的、越解释越远。

02

降低沟通成本

不用反复试探和猜忌，一句话就能说到位，把时间留给真正重要的事。

03

帮助更好表达

把"想在乎"变成"会在乎"，让爱有合适的出口，让边界有温柔的说法。

PRIVACY

隐私与边界

你的对话只属于你，EchoCard 不替你判断谁对谁错。

不上传聊天记录，所有分析均在浏览器本地完成。
不保存用户输入，刷新页面后所有内容清空，无任何持久化存储。
不做心理诊断，EchoCard 只辅助日常表达，不提供任何心理或医学判断。
不替用户判断谁对谁错，系统只分析表达方式，不评价关系中的对错。
不建议用于紧急危机或严重心理困扰场景，如遇危机请立即联系专业机构。
HTML 转义保护，所有用户输入在展示前均经过转义，防止 XSS 与页面异常。
