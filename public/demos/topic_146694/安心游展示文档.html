真正懂老年人的旅游助手

"安心游"是一款面向 50 岁以上老年群体的微信小程序，针对银发族在旅游过程中面临的视力不佳、操作困难、安全顾虑等痛点，提供从行程规划到紧急救援的一站式服务。

系统采用"微信小程序 + Flask 后端 + MySQL 数据库"的三端架构，支持用户端与管理端双向联动，确保数据实时同步、服务稳定可靠。

API 接口

完整的 RESTful API 设计

后端提供 30+ 个接口，覆盖认证、用户、住宿、旅游团、收藏、消息等全部业务场景

GET /api/hotels/<id> 酒店详情
旅游团 GET /api/tour-groups 旅游团列表
POST /api/tour-groups/join 报名旅游团
其他 GET /api/favorites 收藏管理（增删查）
GET /api/messages 消息通知
GET /api/emergency-contacts 紧急联系人管理
GET /api/trips 行程管理
