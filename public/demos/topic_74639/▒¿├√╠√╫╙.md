【正文】

## 1. 创意名称 + 创意介绍

**创意名称**：宝贝回家 · 公益寻亲平台

**想解决什么问题**：
中国每年仍有大量失踪儿童和走失人员未被找到，现有的寻亲信息多以纯文字形式散布在社交平台，缺乏统一的、可视化的信息聚合渠道，难以形成有效的传播和线索反馈闭环。

**为什么会想到做这个**：
看到真实的"宝贝回家"志愿者协会已帮助数以万计的家庭团聚，每一条团圆新闻背后都是无数人的转发和关注。希望通过前端可视化技术，让寻亲信息在地图上直观分布、让已团聚的成功故事被更多人看到，让每一次分享都能转化为有用的线索。

**大概是什么产品**：
纯前端寻亲信息网站（SPA 单页应用），8 个功能页面 + 2 个表单弹窗，约 3750 行原生代码。数据存储在浏览器 localStorage，无需后端、无需注册登录，双击 index.html 即可运行。

## 2. 目标用户及痛点

**面向哪些用户**：
- 寻找失踪亲人的家属 —— 需要快速发布信息、管理线索
- 愿意提供线索的普通网民 —— 希望就近浏览、方便留言
- 寻亲志愿者和公益组织 —— 需要追踪进展、统计成果

**在什么场景下使用**：
- 家属在平台发布寻亲信息（上传照片、填写体貌特征、失踪地点、联系方式）
- 网民打开地图页，查看身边的寻亲标记（红色为失踪中，绿色为已团聚），点击标记查看详情
- 发现线索后在详情页留言（支持标记为"疑似线索"或"确认线索"）
- 查阅已团聚的完整故事（含时间线、家庭留言、关键线索追溯），转发传播

**当前痛点**：
- 寻亲信息以文字为主，缺乏地图可视化，位置分布不直观
- 已团聚的正面案例缺少独立展示模块，无法形成"希望感"和社会证明
- 评论与线索没有类型区分，真正帮助团聚的关键信息难以被追溯和突出
- 联系方式直接暴露存在隐私风险

## 3. 价值与意义

**社会价值**：

本项目着重体现"技术向善"，通过以下设计传递社会公益价值：

- **以"已团聚"为核心亮点**：首页焦点轮播区展示最新团聚故事 → 独立"团聚故事"页面（照片左右对比、事件时间线、家庭留言） → SVG 环形统计图（已团聚 vs 寻找中比例） → 详情页绿色团聚横幅 → 关键线索追溯高亮，五层递进展示平台的社会价值
- **地图双色标记体系**：红色标记 = 失踪中，绿色标记 + 金色边框 = 已团聚（更大更醒目），从失踪地到团聚地绘制绿色虚线连线，直观呈现"回家之路"
- **社区参与感**：留言支持"普通留言 / 疑似线索 / 确认线索"三类型标记，确认线索可在团聚故事中被追溯为"关键线索"，形成正向激励闭环
- **隐私保护**：手机号自动脱敏展示为 138****8888，邮箱脱敏为 wa***@example.com
- **零门槛使用**：全部数据本地存储，无需注册登录，发布信息和提供线索均可匿名
- **预置团聚案例**：内置 5 条完整团聚故事示例（DNA 比对、人脸识别、志愿者寻找、好心人发现、离家出走找回等多种真实找回场景），首次打开自动加载，让访客第一时间感受到平台的温度

## 4. 附件

已上传创意产物 HTML 文件（即本项目的 index.html），包含完整的寻亲平台功能：

| 模块 | 功能 |
|------|------|
| 首页 | 团聚故事焦点轮播、4 张统计动画卡片（数字滚动递增）、最新团聚 / 最新发布双列表 |
| 团聚故事 ⭐ | 卡片网格（失踪时 vs 团聚后照片左右对比）、SVG 环形统计图、筛选排序、详情弹窗（时间线+家庭留言+关键线索） |
| 地图寻亲 🗺️ | 高德地图全屏、双色标记（失踪红 / 团聚绿）、状态切换开关、团聚地连线、侧边栏列表 |
| 发布寻亲 📝 | 照片拖拽上传（自动压缩 800px）、表单校验、联系方式脱敏存储 |
| 详情页 | 状态横幅（红=寻找中 / 绿=已团聚）、团聚故事区块、评论留言（带线索类型标签）、收藏、复制联系方式 |
| 搜索筛选 🔍 | 关键词搜索 + 性别/年龄/失踪时间/状态多条件筛选、防抖自动搜索 |
| 数据管理 💾 | 导出/导入 JSON、清空数据（双重确认）、存储用量监控、一键加载示例数据 |
| 关于 | 项目介绍、使用指南（5 步流程）、公益理念、免责声明 |

**技术栈**：原生 HTML + CSS + JavaScript / Tailwind CSS / 高德地图 JS SDK v2.0 / Font Awesome 6.5 / localStorage

**运行方式**：双击 index.html 即可运行，或本地启动服务器后访问

**示例数据**：首次打开自动加载 11 条数据（5 个已团聚故事 + 6 个正在寻找中），开箱即体验
